We’re building a sprint-planning app in Rust for Harborline’s Northstar checkout launch. Start with an empty sprint, add tasks with their own routes, then create and move work through the board. Each step leaves a working screen, and the browser’s Back button restores the task for the route you return to.

The preview stays collapsed while you read. Open a step to try its screen, then close it to get the full reading width back. The app keeps changes in memory. Its validation and state transitions are real, but adding a backend is outside this tutorial.

Install the Fission CLI and scaffold a Web project:

```sh
cargo install cargo-fission
fission init harbour-workspace
cd harbour-workspace
cargo add serde_yaml
fission add-target web --project-dir .
```

## Project layout

```text
harbour-workspace/
├── Cargo.toml                 # generated dependencies
├── fission.toml               # app identity, targets and capabilities
├── src/
│   ├── main.rs                 # generated Web entrypoint
│   ├── lib.rs                  # shared app setup
│   ├── app.rs                  # reusable Fission components
│   ├── state.rs                # sprint data and reducers
│   ├── router.rs               # routes and browser history
│   ├── pages/task_list.rs      # workspace screen
│   └── pages/task_detail.rs    # task detail screen
├── platforms/                  # generated host files after add-target
└── tests/                      # project-specific flow checks
```

`fission init` creates the project and starter app; `fission add-target web` adds the browser target. Keep the shared task model and reducers in `state.rs`, and put each screen or reusable component in its own module. The board and detail route share task data through `GlobalState`; short-lived text and filter choices belong to their component. Views describe what to render. Reducers make the state changes after user actions.

## Lay out the workspace and explain the empty sprint

A blank board is still a real state, not a reason to show an empty scaffold. Someone opening Northstar should know which project and sprint they’re looking at, whether work has been planned, and what will appear after the first task is added. Build that layout first; we’ll add task cards in the next step.

`SprintMetric` is reusable for the three summaries. `NorthstarSprintBoard` gives the Northstar checkout launch its own project header, sprint dates and an empty state that explains what belongs on this board. We will add the real task-creation action in the final step rather than show a button that does nothing.

    let mut env = Env::default();
    env.locale = Locale::from("en-US");

        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

## Open a task from the sprint board

Now add tasks a teammate can open. `TaskBoardState` implements `GlobalState` because both the list and detail page read the same records. Each card links to `/tasks/:id`. The route carries the task ID; shared state supplies its title, owner, and delivery context.

`RouterParams` reads the ID from a URL such as `/tasks/241`, so the detail screen doesn’t need a second copy of the task. Fission’s Web shell reports browser history changes to `route_changed`, which updates the router’s path. Open a card, then try Back and Forward. The URL and screen should move together.

use fission::prelude::*;
use std::sync::Arc;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum TaskStatus {
    Ready,
    InProgress,
    InReview,
}

impl TaskStatus {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::Ready => "sprint.status.ready",
            Self::InProgress => "sprint.status.in_progress",
            Self::InReview => "sprint.status.in_review",
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct SprintTask {
    pub id: u32,
    pub title: String,
    pub team: String,
    pub owner: String,
    pub context: String,
    pub status: TaskStatus,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct TaskBoardState {
    pub current_path: String,
    pub tasks: Vec<SprintTask>,
}

impl Default for TaskBoardState {
    fn default() -> Self {
        Self {
            current_path: "/projects/northstar".into(),
            tasks: Vec::new(),
        }
    }
}

impl GlobalState for TaskBoardState {}

pub fn route_changed(
    state: &mut TaskBoardState,
    action: fission::core::action::ShellRouteChanged,
    _cx: &mut ReducerContext<TaskBoardState>,
) {
    state.current_path = action.location.pathname;
}

fission_component! {
    pub SprintTaskCard<TaskBoardState> { task: SprintTask }
    view(card, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let task_path = format!("/tasks/{}", card.task.id);
    } =>
    Container(
        Column(gap: tokens.spacing.s, children: [
            Link::to(card.task.title.clone(), task_path),
            Text(format!("NS-{} · {}", card.task.id, card.task.team))
                .color(tokens.colors.text_secondary),
            Text(card.task.context.clone()),
            Row(gap: tokens.spacing.s, children: [
                Text(card.task.owner).weight(tokens.typography.font_weight_semibold),
                Spacer(flex_grow: 1.0),
                Text(cx.tr(card.task.status.translation_key())).color(tokens.colors.text_secondary),
            ]),
        ]),
    )
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
}

fission_component! {
    pub SprintTaskBoard<TaskBoardState> {}
    view(_board, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(
        Column(gap: tokens.spacing.l, children: [
            Column(gap: tokens.spacing.xs, children: [
                Text(cx.tr("sprint.workspace.name")).weight(tokens.typography.font_weight_bold),
                Text(cx.tr("sprint.board.title"))
                    .color(tokens.colors.text_secondary),
            ]),
            Text(cx.tr("sprint.board.intro"))
                .color(tokens.colors.text_secondary),
            Grid(
                columns: vec![GridTrack::auto_fit(
                    GridTrack::minmax(GridTrack::Points(280.0), GridTrack::Fr(1.0))
                )],
                rows: vec![GridTrack::Auto],
                column_gap: tokens.spacing.m,
                row_gap: tokens.spacing.m,
                children: [
                    if state.tasks.is_empty() {
                        EmptyState(
                            title: cx.tr("sprint.empty.title"),
                            description: Some(cx.tr("sprint.empty.explanation")),
                        )
                    } else {
                        for task in state.tasks.iter() {
                            SprintTaskCard(task.clone(), key: task.id)
                        }
                    },
                ],
            ),
        ]),
    )
    .padding_all(tokens.spacing.l)
    .bg(tokens.colors.background)
}

fission_component! {
    pub SprintTaskDetail<TaskBoardState> { props { task_id: u32 } }
    view(page, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let task = state.tasks.iter().find(|task| task.id == page.task_id).cloned();
    } =>
    if let Some(task) = task {
        Center(Container(Column(gap: tokens.spacing.m, children: [
            Link::to(cx.tr("sprint.link.board"), "/projects/northstar"),
            Text(format!("NS-{} · {}", task.id, cx.tr(task.status.translation_key())))
                .color(tokens.colors.text_secondary),
            Text(task.title.clone()).weight(tokens.typography.font_weight_bold),
            Text(format!(
                "{}: {} · {}: {}",
                cx.tr("sprint.task.team"),
                task.team,
                cx.tr("sprint.task.owner"),
                task.owner,
            ))
                .color(tokens.colors.text_secondary),
            Text(cx.tr("sprint.task.context_label")).weight(tokens.typography.font_weight_semibold),
            Text(task.context.clone()),
        ])).width_length(Length::percent(100.0)).max_width(760.0)
            .padding_all(tokens.spacing.l)
            .bg(tokens.colors.surface)
            .border(tokens.colors.border, 1.0)
            .border_radius(tokens.radii.medium))
    } else {
        Center(Container(Column(gap: tokens.spacing.m, children: [
            Text(cx.tr("sprint.task.missing"))
                .weight(tokens.typography.font_weight_semibold),
            Link::to(cx.tr("sprint.link.return_board"), "/projects/northstar"),
        ])).width_length(Length::percent(100.0)).max_width(760.0)
            .padding_all(tokens.spacing.l)
            .bg(tokens.colors.surface)
            .border(tokens.colors.border, 1.0)
            .border_radius(tokens.radii.medium))
    }
}

fission_component! {
    pub TaskNotFound<TaskBoardState> {}
    view(_page, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Center(Container(Column(gap: tokens.spacing.m, children: [
        Text(cx.tr("sprint.page.missing"))
            .weight(tokens.typography.font_weight_bold),
        Link::to(cx.tr("sprint.link.return_board"), "/projects/northstar"),
    ])).width_length(Length::percent(100.0)).max_width(760.0)
        .padding_all(tokens.spacing.l)
        .bg(tokens.colors.surface)
        .border(tokens.colors.border, 1.0)
        .border_radius(tokens.radii.medium))
}

fission_component! {
    pub TaskBoardApp<TaskBoardState> {}
    view(_app, state, _cx) {
        let router = Router::<TaskBoardState>::new()
            .with_path(state.current_path.clone())
            .route("/", SprintTaskBoard::new)
            .route("/projects/northstar", SprintTaskBoard::new)
            .route("/tutorials/single-page-web-app-rust/:step", SprintTaskBoard::new)
            .route_builder("/tasks/:id", Arc::new(|_, _, params| {
                match params.get("id").and_then(|id| id.parse::<u32>().ok()) {
                    Some(task_id) => SprintTaskDetail::new(task_id).into(),
                    None => TaskNotFound::new().into(),
                }
            }))
            .not_found(TaskNotFound::new);
    } =>
    router
}

## Add validated work and move it through the sprint

The board also needs to accept new work. Keep title and context drafts in `SprintTaskBoard`; no other screen needs them before submission. Keep saved tasks and feedback in `TaskBoardState`, so the board and detail route see the same result.

`AddSprintTask` checks the title and requires a short context before changing the sprint. Invalid input leaves the list alone. A valid title creates a Ready task with no due date and reports its ID. From the detail route, `AdvanceSprintTask` moves it to the next lane. The preview exercises real validation and state changes without pretending to contact a server. A production app can request an asynchronous save from the same reducer boundary.

use fission::prelude::*;
use std::sync::Arc;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum TaskStatus {
    Ready,
    InProgress,
    InReview,
    Done,
}

impl TaskStatus {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::Ready => "sprint.status.ready",
            Self::InProgress => "sprint.status.in_progress",
            Self::InReview => "sprint.status.in_review",
            Self::Done => "sprint.status.done",
        }
    }

    pub fn next(self) -> Self {
        match self {
            Self::Ready => Self::InProgress,
            Self::InProgress => Self::InReview,
            Self::InReview => Self::Done,
            Self::Done => Self::Done,
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum TaskPriority {
    High,
    Normal,
}

impl TaskPriority {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::High => "sprint.priority.high",
            Self::Normal => "sprint.priority.normal",
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum SprintFilter {
    All,
    Mine,
    HighPriority,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct SprintTask {
    pub id: u32,
    pub title: String,
    pub team: String,
    pub owner: String,
    pub priority: TaskPriority,
    pub due: String,
    pub context: String,
    pub status: TaskStatus,
}

fn task(
    id: u32,
    title: &str,
    team: &str,
    owner: &str,
    priority: TaskPriority,
    due: &str,
    context: &str,
    status: TaskStatus,
) -> SprintTask {
    SprintTask {
        id,
        title: title.into(),
        team: team.into(),
        owner: owner.into(),
        priority,
        due: due.into(),
        context: context.into(),
        status,
    }
}

fn task_matches(
    task: &SprintTask,
    query: &str,
    filter: SprintFilter,
    current_user: Option<&str>,
) -> bool {
    let query = query.trim().to_lowercase();
    let matches_query = query.is_empty()
        || task.title.to_lowercase().contains(&query)
        || task.owner.to_lowercase().contains(&query)
        || task.team.to_lowercase().contains(&query)
        || format!("NS-{}", task.id).to_lowercase().contains(&query);
    let matches_filter = match filter {
        SprintFilter::Mine => current_user.map(|name| task.owner == name).unwrap_or(false),
        SprintFilter::HighPriority => task.priority == TaskPriority::High,
        SprintFilter::All => true,
    };
    matches_query && matches_filter
}

#[derive(Clone, Debug, PartialEq)]
pub struct TaskBoardState {
    pub current_path: String,
    pub tasks: Vec<SprintTask>,
    pub current_user: Option<String>,
    pub feedback: Option<String>,
    pub feedback_is_error: bool,
}

impl Default for TaskBoardState {
    fn default() -> Self {
        Self {
            current_path: "/projects/northstar".into(),
            tasks: Vec::new(),
            current_user: None,
            feedback: None,
            feedback_is_error: false,
        }
    }
}

impl GlobalState for TaskBoardState {}

#[fission_reducer(AddSprintTask)]
pub fn on_add_sprint_task(state: &mut TaskBoardState, title: String, context: String) {
    let title = title.trim();
    if title.chars().count() < 5 {
        state.feedback = Some("sprint.feedback.title_too_short".into());
        state.feedback_is_error = true;
        return;
    }
    let context = context.trim();
    if context.is_empty() {
        state.feedback = Some("sprint.feedback.context_required".into());
        state.feedback_is_error = true;
        return;
    }

    let Some(owner) = state.current_user.clone() else {
        state.feedback = Some("sprint.feedback.owner_required".into());
        state.feedback_is_error = true;
        return;
    };

    let Some(id) = state
        .tasks
        .iter()
        .map(|task| task.id)
        .max()
        .unwrap_or_default()
        .checked_add(1)
    else {
        state.feedback = Some("sprint.feedback.id_exhausted".into());
        state.feedback_is_error = true;
        return;
    };
    state.tasks.insert(
        0,
        task(
            id,
            title,
            "Product",
            &owner,
            TaskPriority::Normal,
            "",
            context,
            TaskStatus::Ready,
        ),
    );
    state.feedback = Some("sprint.feedback.task_added".into());
    state.feedback_is_error = false;
}

#[fission_reducer(AdvanceSprintTask)]
pub fn on_advance_sprint_task(state: &mut TaskBoardState, task_id: u32) {
    if let Some(task) = state.tasks.iter_mut().find(|task| task.id == task_id) {
        if task.status == TaskStatus::Done {
            state.feedback = Some("sprint.feedback.already_done".into());
            state.feedback_is_error = true;
            return;
        }
        task.status = task.status.next();
        state.feedback = Some("sprint.feedback.task_moved".into());
        state.feedback_is_error = false;
    } else {
        state.feedback = Some("sprint.feedback.task_missing".into());
        state.feedback_is_error = true;
    }
}

    state: &mut TaskBoardState,
    action: fission::core::action::ShellRouteChanged,
    _cx: &mut ReducerContext<TaskBoardState>,
) {
    state.current_path = action.location.pathname;
}

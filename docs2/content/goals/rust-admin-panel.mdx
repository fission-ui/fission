When a support supervisor opens the workbench, they need to know who is waiting, what happened, who owns the issue, and what they can safely do next. A table of labels is not enough. We’ll build a small workspace with the queue and selected conversation side by side, then make the boundary between a UI preview and server-authorized resolution explicit.

The browser preview seeds sample records and a supervisor permission result outside the dashboard component. That lets you try the screen without an account or server; it is not authentication or an authorization check. In the app, tickets and the selected ticket belong in shared state because both panes use them. A real service loads the records and makes the permission decision on the server.

## Create the Web project

Install the Fission CLI if needed, then scaffold the Web target. The generated shell starts the app; the screen belongs in shared Rust code.

## Start with the support queue

Start with the queue. Each row should show who raised the issue, what it is about, its category and priority, and who owns the next action. Summary cards give a sense of the backlog, but the ticket list is still the main work surface.

The queue is a named component with a clear job. The preview supplies sample records through `with_state_init`; the production default remains empty until a service loads real tickets into shared state.

#[derive(Clone, Debug, PartialEq)]

    pub tickets: Vec<SupportTicket>,
    pub selected_ticket: Option<u32>,
    pub can_resolve: bool,
    pub current_agent: String,
}

impl Default for SupportState {
    fn default() -> Self {
        Self { tickets: Vec::new(), selected_ticket: None, can_resolve: false, current_agent: String::new() }
    }
}

impl GlobalState for SupportState {}

    Urgent,
    High,
    Normal,

impl TicketPriority {

        match self {
            Self::Urgent => "support.priority.urgent",
            Self::High => "support.priority.high",
            Self::Normal => "support.priority.normal",
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum TicketStatus {
    Open,
    Waiting,
}

impl TicketStatus {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::Open => "support.status.open",
            Self::Waiting => "support.status.waiting",
        }
    }
}

#[derive(Clone, Debug, PartialEq)]
pub struct SupportTicket {
    pub id: u32,
    pub reference: String,
    pub subject: String,
    pub customer: String,
    pub category: String,
    pub priority: TicketPriority,
    pub status: TicketStatus,
    pub assignee: String,
    pub age: String,

fission_component! {
    pub SupportQueueRow<()> { ticket: SupportTicket }
    view(row, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let priority_label = cx.tr(row.ticket.priority.translation_key());
        let status_label = cx.tr(row.ticket.status.translation_key());
    } =>
    Container(
        Column(gap: tokens.spacing.xs, children: [
            Row(gap: tokens.spacing.m, wrap: ir_op::FlexWrap::Wrap,
                children: [

                        .weight(tokens.typography.font_weight_semibold),
                    Text(priority_label),

                row.ticket.reference, row.ticket.customer, row.ticket.category)),
            Row(gap: tokens.spacing.m, wrap: ir_op::FlexWrap::Wrap,
                children: [
                    Text(format!("{} · {}", status_label, row.ticket.assignee))
                        .color(tokens.colors.text_secondary),
                    Text(row.ticket.age.clone()).color(tokens.colors.text_secondary),
                ]),
        ]),
    )
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)

fission_component! {
    pub SupportOperationsDashboard<SupportState> {}
    view(_page, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let tickets = &state.tickets;
        let open_count = tickets.iter().filter(|ticket| ticket.status == TicketStatus::Open).count();

                            .weight(tokens.typography.font_weight_semibold),
                        Text(cx.tr("support.metric.urgent"))

                    Column(children: [
                        Text(format!("{} {}", waiting_count, cx.tr("support.metric.tickets")))

                        Text(cx.tr("support.metric.waiting"))

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

const SOURCES: [(&str, &str); 2] = [
    ("en-US", include_str!("../i18n/en-US.yaml")),
    ("es-ES", include_str!("../i18n/es-ES.yaml")),
];

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in SOURCES {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid support panel translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

## Find a ticket and inspect its history

Supervisors often start with a name, ticket number, or queue such as “urgent” or “assigned to me.” Search customer and issue text so a partial name finds the right conversation. Keep the detail panel visible when filters change; otherwise the person reviewing a case can lose their place.

Search text and the active filter only affect this screen, so retain them locally. The selected ticket ID belongs in `SupportState` because both the queue and detail pane depend on it. Give each row a stable key based on the ticket ID; filtering or sorting must not change which ticket owns its retained state.

use fission::prelude::*;

#[derive(Clone, Debug, PartialEq)]
pub struct SupportState {
    pub tickets: Vec<SupportTicket>,
    pub selected_ticket: Option<u32>,
    pub can_resolve: bool,
    pub current_agent: String,
}

impl Default for SupportState {
    fn default() -> Self {
        Self { tickets: Vec::new(), selected_ticket: None, can_resolve: false, current_agent: String::new() }
    }
}

impl GlobalState for SupportState {}

#[fission_reducer(SelectSupportTicket)]
pub fn select_support_ticket(state: &mut SupportState, ticket_id: u32) {
    state.selected_ticket = Some(ticket_id);
}

#[derive(Clone, Debug, PartialEq)]
pub struct SupportTicket {
    pub id: u32,
    pub reference: String,
    pub subject: String,
    pub customer: String,
    pub category: String,
    pub priority: TicketPriority,
    pub status: TicketStatus,
    pub assignee: String,
    pub age: String,
    pub summary: String,
    pub customer_message: String,
    pub agent_message: String,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum TicketPriority {
    Urgent,
    High,
    Normal,
}

impl TicketPriority {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::Urgent => "support.priority.urgent",
            Self::High => "support.priority.high",
            Self::Normal => "support.priority.normal",
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum TicketStatus {
    Open,
    Waiting,
}

impl TicketStatus {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::Open => "support.status.open",
            Self::Waiting => "support.status.waiting",
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum TicketFilter {
    Open,
    Urgent,
    AssignedToMe,
}

fission_component! {
    pub SupportOperationsDashboard<SupportState> {
        state {
            query: String = String::new(),
            active_filter: TicketFilter = TicketFilter::Open,
        }
    }
    view(page, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let tickets = &state.tickets;
        let query = page.query.trim().to_lowercase();
        let visible_tickets: Vec<SupportTicket> = tickets.iter()
            .filter(|ticket| {
                let matches_query = query.is_empty()
                    || ticket.customer.to_lowercase().contains(&query)
                    || ticket.subject.to_lowercase().contains(&query)
                    || ticket.reference.to_lowercase().contains(&query);
                let matches_filter = match page.active_filter {
                    TicketFilter::Urgent => ticket.priority == TicketPriority::Urgent,
                    TicketFilter::AssignedToMe => ticket.assignee == state.current_agent,
                    TicketFilter::Open => ticket.status == TicketStatus::Open,
                };
                matches_query && matches_filter
            })
            .cloned()
            .collect();
        let selected = tickets.iter()
            .find(|ticket| Some(ticket.id) == state.selected_ticket)
            .or_else(|| tickets.first());
        let open_count = tickets.iter().filter(|ticket| ticket.status == TicketStatus::Open).count();
        let urgent_count = tickets.iter().filter(|ticket| ticket.priority == TicketPriority::Urgent).count();
    } =>
    Container(
        Column(gap: tokens.spacing.l, children: [
            Row(gap: tokens.spacing.m, wrap: ir_op::FlexWrap::Wrap, children: [
                Column(gap: tokens.spacing.xs, children: [
                    Text(cx.tr("support.brand")).weight(tokens.typography.font_weight_bold),
                    Text(cx.tr("support.region"))
                        .color(tokens.colors.text_secondary),
                ]),
                Text(format!("{} · {}", state.current_agent, cx.tr("support.role.supervisor"))),
            ]),
            Grid(
                columns: vec![GridTrack::auto_fit(GridTrack::minmax(
                    GridTrack::Points(180.0), GridTrack::Fr(1.0),
                ))],
                rows: vec![GridTrack::Auto],
                column_gap: tokens.spacing.m,
                row_gap: tokens.spacing.s,
                children: [
                    Column(children: [
                        Text(format!("{} {}", open_count, cx.tr("support.status.open"))),
                        Text(cx.tr("support.queue.heading")).color(tokens.colors.text_secondary),
                    ]),
                    Column(children: [
                        Text(format!("{} {}", urgent_count, cx.tr("support.priority.urgent"))),
                        Text(cx.tr("support.metric.urgent")).color(tokens.colors.text_secondary),
                    ]),
                ],
            ),
            TextInput(
                label: Some(cx.tr("support.search.label").into()),
                placeholder: Some(cx.tr("support.search.placeholder").into()),
                bind: page.query,
                semantics_identifier: "support.search".to_string(),
            ),
            Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                Button(child: Text(cx.tr("support.filter.all_open")), key: "filter-open",
                    on_press: reduce { page.active_filter = TicketFilter::Open; })
                    .semantics_identifier("support.filter.open".to_string()),
                Button(child: Text(cx.tr("support.filter.urgent")), key: "filter-urgent",
                    on_press: reduce { page.active_filter = TicketFilter::Urgent; })
                    .semantics_identifier("support.filter.urgent".to_string()),
                Button(child: Text(cx.tr("support.filter.assigned")), key: "filter-mine",
                    on_press: reduce { page.active_filter = TicketFilter::AssignedToMe; })
                    .semantics_identifier("support.filter.assigned".to_string()),
            ]),
            Text(format!("{} {}", visible_tickets.len(), cx.tr("support.search.matches")))
                .color(tokens.colors.text_secondary),
            Grid(
                columns: vec![GridTrack::auto_fit(GridTrack::minmax(
                    GridTrack::Points(270.0), GridTrack::Fr(1.0),
                ))],
                rows: vec![GridTrack::Auto],
                column_gap: tokens.spacing.l,
                row_gap: tokens.spacing.m,
                children: [
                    Column(gap: tokens.spacing.s, children: [
                        Text(cx.tr("support.queue.heading")).weight(tokens.typography.font_weight_semibold),
                        for ticket in visible_tickets.iter() {
                            Button(
                                child: Container(Column(gap: tokens.spacing.xs, children: [
                                    Text(ticket.subject.clone())
                                        .weight(tokens.typography.font_weight_semibold),
                                    Text(format!("{} · {}", ticket.reference, ticket.customer)),
                                    Text(format!("{} · {} · {}",
                                        cx.tr(ticket.priority.translation_key()),
                                        cx.tr(ticket.status.translation_key()),
                                        ticket.assignee))
                                        .color(tokens.colors.text_secondary),
                                ]))
                                .padding_all(tokens.spacing.m)
                                .bg(tokens.colors.surface)
                                .border(tokens.colors.border, 1.0)
                                .border_radius(tokens.radii.medium),
                                key: format!("ticket-{}", ticket.id),
                                handler: "select-ticket",
                                on_press: with_reducer!(
                                    cx.build,
                                    SelectSupportTicket(ticket.id),
                                    select_support_ticket,
                                ),
                            )
                            .semantics_identifier(format!("support.ticket.{}", ticket.id))
                        },
                    ]),
                    if let Some(selected) = selected {
                        Container(Column(gap: tokens.spacing.s, children: [
                        Text(format!("{} · {}", selected.reference,
                            cx.tr(selected.status.translation_key())))
                            .color(tokens.colors.text_secondary),
                        Text(selected.subject.clone())
                            .weight(tokens.typography.font_weight_bold),
                        Text(format!("{} · {} · {}", selected.customer, selected.category,
                            cx.tr(selected.priority.translation_key()))),
                        Text(selected.summary.clone()),
                        Text(cx.tr("support.conversation.heading")),
                        Text(cx.tr("support.conversation.customer")),
                        Text(format!("“{}”", selected.customer_message)),
                        Text(cx.tr("support.conversation.agent")),
                        Text(format!("“{}”", selected.agent_message)),
                        Text(format!("{} {}", cx.tr("support.assigned_to"), selected.assignee))
                            .color(tokens.colors.text_secondary),
                    ]))
                    .padding_all(tokens.spacing.l)
                    .bg(tokens.colors.surface)
                    .border(tokens.colors.border, 1.0)
                    .border_radius(tokens.radii.medium)
                    } else {
                        EmptyState(
                            title: cx.tr("support.empty.title"),
                            description: Some(cx.tr("support.empty.description")),
                        )
                    },
                ],
            ),
        ]),
    )
    .padding_all(tokens.spacing.l)
    .bg(tokens.colors.background)
}

## Connect the screen to real application data

The preview uses a fixed set of tickets so you can try the workbench immediately. In your app, move `SupportTicket` and data loading into model and service modules, and put records shared by routes in `GlobalState`. Search text, the selected row, and an unfinished note still belong to this screen.

To make this a production workflow, connect the UI to a ticket service: an action should queue an async effect, the service should check the signed-in user’s permission, and a reducer should record the returned status and activity event. Show a loading state while the request runs. If the service rejects it, keep the note and selected ticket and explain what the operator can do next. The preview’s seeded permission only controls what the browser displays; never use it as the permission check.

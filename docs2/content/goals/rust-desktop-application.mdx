Repair work gets hard to follow when the queue, checklist and shift notes each tell a different story. The app needs to show which machine needs attention, where it is, what has already been checked and what still needs to happen before it goes back into service.

We will build **Harbour Desk**, a desktop work-order app for a warehouse maintenance team. It has four jobs, a searchable queue, locations and due windows, safety and repair checks, status changes, and notes attached to the selected order. The buttons change the work order in app state; none of them pretend to save or use hardware. The browser preview keeps its sample data in memory for the current session. The native desktop window runs the same Rust app, where a production version can connect a real store or service.

The app is split into named `fission_component!` components. `ServiceDeskState` owns the work orders because the queue, summary cards and detail panel all need the same records. A small selection change stays beside its button in an inline `reduce` block; the inspection and status rules remain named reducers because they validate and update related work-order data. That keeps simple UI transitions concise without hiding the domain rules.

## Create the desktop project

`fission init` creates the desktop project and its entrypoint. We will add the work-order model, shared state and focused component modules under `src/`. You can run the empty scaffold first; after adding the app, `fission run` opens Harbour Desk as a desktop window.

## Shape the work orders and the first screen

Start with a work order: give it a stable ID, a reference such as `WO-2483`, a location, a requester, a due window, a priority, a status, an inspection checklist and any notes from the previous shift. The queue and detail panel should read the same record. If each keeps its own copy, they can disagree.

The first checkpoint is read-only, with the first work order selected. The queue shows what needs attention; the detail panel shows the selected job's location, due window, checklist and notes. We will use theme tokens for spacing, surfaces, borders and type. The queue and detail panel sit side by side on a desktop and stack when the preview narrows.

These snippets make up one project. Add the work-order records and default state first, then the reusable cards and sidebar, and finally compose them in `WorkOrderDesk`. Each component has one job: `WorkOrderQueueCard` summarizes a repair, `WorkOrderDetailPanel` shows the selected repair, and `ServiceDeskSidebar` identifies the workspace.

The queue and detail components receive a work order as a typed prop. Keep the record serializable across that component boundary, and use owned strings so it can be deserialized as well as displayed.

```rust
use serde::{Deserialize, Serialize};

#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub enum WorkOrderStatus {
    Open,
    InProgress,
    WaitingForParts,
    ReadyForPickup,
    Closed,
}

impl WorkOrderStatus {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::Open => "service_desk.status.open",
            Self::InProgress => "service_desk.status.in_progress",
            Self::WaitingForParts => "service_desk.status.waiting_for_parts",
            Self::ReadyForPickup => "service_desk.status.ready_for_pickup",
            Self::Closed => "service_desk.status.closed",
        }
    }

}

#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub enum InspectionCategory {
    Safety,
    Inspection,
    Repair,
    Verification,
}

impl InspectionCategory {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::Safety => "service_desk.category.safety",
            Self::Inspection => "service_desk.category.inspection",
            Self::Repair => "service_desk.category.repair",
            Self::Verification => "service_desk.category.verification",
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub enum WorkOrderPriority {
    High,
    Normal,
}

impl WorkOrderPriority {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::High => "service_desk.priority.high",
            Self::Normal => "service_desk.priority.normal",
        }
    }

}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct InspectionStep {
    pub id: String,
    pub title_key: String,
    pub category: InspectionCategory,
    pub complete: bool,
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct ShiftNote {
    pub id: String,
    pub author: Option<String>,
    pub time: Option<String>,
    pub message: String,
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct WorkOrder {
    pub id: u32,
    pub reference: String,
    pub title: String,
    pub description: String,
    pub location: String,
    pub requested_by: String,
    pub due_window: String,
    pub due_today: bool,
    pub priority: WorkOrderPriority,
    pub status: WorkOrderStatus,
    pub steps: Vec<InspectionStep>,
    pub shift_notes: Vec<ShiftNote>,
}
```

```rust
use crate::models::WorkOrder;
use crate::state::ServiceDeskState;
use fission::prelude::*;

fission_component! {
    pub WorkOrderDetailPanel<ServiceDeskState> { order: WorkOrder }
    view(panel, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let complete_count = panel.order.steps.iter().filter(|step| step.complete).count();
        let total_count = panel.order.steps.len();
        let progress = if total_count == 0 { 0.0 } else { complete_count as f32 / total_count as f32 };
    } =>
    Container(
        Column(gap: tokens.spacing.l, children: [
            Column(gap: tokens.spacing.xs, children: [
                Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, align_items: ir_op::AlignItems::Center, children: [
                    Text(format!("{} · {}", panel.order.reference, panel.order.title))
                        .weight(tokens.typography.font_weight_bold),
                    Spacer(flex_grow: 1.0),
                    Badge(text: cx.tr(panel.order.priority.translation_key())),
                ]),
                Text(panel.order.description.clone()).color(tokens.colors.text_secondary),
            ]),
            Grid(
                columns: vec![GridTrack::auto_fit(GridTrack::minmax(
                    GridTrack::Points(150.0), GridTrack::Fr(1.0),
                ))],
                rows: vec![GridTrack::Auto],
                column_gap: tokens.spacing.m,
                row_gap: tokens.spacing.s,
                children: [
                    Column(gap: tokens.spacing.xs, children: [Text(cx.tr("service_desk.location")), Text(panel.order.location.clone())]),
                    Column(gap: tokens.spacing.xs, children: [Text(cx.tr("service_desk.requested_by")), Text(panel.order.requested_by.clone())]),
                    Column(gap: tokens.spacing.xs, children: [Text(cx.tr("service_desk.due_window")), Text(panel.order.due_window.clone())]),
                ],
            ),
            Divider(),
            Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, align_items: ir_op::AlignItems::Center, children: [
                Text(cx.tr("service_desk.checklist.title")).weight(tokens.typography.font_weight_semibold),
                Spacer(flex_grow: 1.0),
                Text(format!("{} {} {}", complete_count, cx.tr("service_desk.checklist.of"), total_count))
                    .color(tokens.colors.text_secondary),
            ]),
            ProgressBar(
                value: progress,
                label: format!("{} {} {} {}", complete_count, cx.tr("service_desk.checklist.of"), total_count, cx.tr("service_desk.checklist.steps_complete")),
            ),
            Column(gap: tokens.spacing.s, children: [
                for step in panel.order.steps.iter() {
                    Row(key: format!("{}-step-{}", panel.order.id, step.id),
                        gap: tokens.spacing.s,
                        align_items: ir_op::AlignItems::Center,
                        children: [
                        Badge(text: cx.tr(if step.complete {
                            "service_desk.checklist.done"
                        } else {
                            "service_desk.checklist.next"
                        })),
                        Column(gap: tokens.spacing.xs, children: [
                            Text(cx.tr(&step.title_key)),
                            Text(cx.tr(step.category.translation_key())).color(tokens.colors.text_secondary),
                        ]),
                    ])
                },
            ]),
            Divider(),
            Text(cx.tr("service_desk.shift_notes.title")).weight(tokens.typography.font_weight_semibold),
            Column(gap: tokens.spacing.s, children: [
                for note in panel.order.shift_notes.iter() {
                    Column(key: note.id.clone(),
                        gap: tokens.spacing.xs,
                        children: [
                        if let (Some(author), Some(time)) = (&note.author, &note.time) {
                            Text(format!("{} · {}", author, time))
                                .weight(tokens.typography.font_weight_semibold)
                        } else {
                            Text(cx.tr("service_desk.shift_notes.draft"))
                                .weight(tokens.typography.font_weight_semibold)
                        },
                        Text(note.message.clone()).color(tokens.colors.text_secondary),
                    ])
                },
            ]),
        ]),
    )
    .padding_all(tokens.spacing.l)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.large)
}
```

```rust
use std::collections::HashMap;

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid Harbour Desk translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}
```

## Select jobs and enforce the repair workflow

Now add the actions staff use during a shift. **Open details** selects a work order by its stable ID. The queue and detail panel both read the selection from `ServiceDeskState`, so one change updates the whole screen. We do not store the selected row inside each card; every part of the screen needs to agree on the same selection.

The checklist can change, but it still belongs to the work order. **Mark ready for pickup** stays available while a repair is in progress. If someone selects it before the checks are done, the reducer says what remains and leaves the order in progress. Once the checks are complete, the same action moves it to **Ready for pickup**.

The reducer receives the current state and action, finds the work order, then applies one transition. The UI calls it through `with_reducer!`; it does not change a record while the component is being converted into a view. The same rule applies whether the action comes from a mouse, a keyboard shortcut or another screen.

```rust
use crate::models::{InspectionStep, WorkOrderStatus};
use fission::prelude::*;

#[derive(Clone, Debug, PartialEq)]
pub struct ServiceDeskState {
    pub work_orders: Vec<crate::models::WorkOrder>,
    pub selected_work_order: Option<u32>,
    pub feedback: String,
    pub feedback_is_error: bool,
}

impl Default for ServiceDeskState {
    fn default() -> Self {
        Self {
            work_orders: Vec::new(),
            selected_work_order: None,
            feedback: String::new(),
            feedback_is_error: false,
        }
    }
}

impl GlobalState for ServiceDeskState {}

#[fission_reducer(ToggleInspectionStep)]
pub fn on_toggle_inspection_step(
    state: &mut ServiceDeskState,
    order_id: u32,
    step_id: String,
) {
    let updated = state
        .work_orders
        .iter_mut()
        .find(|order| order.id == order_id)
        .and_then(|order| {
            order.steps.iter_mut().find(|step| step.id == step_id.as_str()).map(|step| {
                step.complete = !step.complete;
            })
        })
        .is_some();
    state.feedback = if updated {
        "service_desk.feedback.step_updated".to_string()
    } else {
        "service_desk.feedback.step_missing".to_string()
    };
    state.feedback_is_error = !updated;
}

#[fission_reducer(AdvanceWorkOrder)]
pub fn on_advance_work_order(state: &mut ServiceDeskState, order_id: u32) {
    let Some(order) = state.work_orders.iter_mut().find(|order| order.id == order_id) else {
        state.feedback = "service_desk.feedback.order_missing".to_string();
        state.feedback_is_error = true;
        return;
    };

    let (feedback, is_error) = match order.status {
        WorkOrderStatus::Open => {
            order.status = WorkOrderStatus::InProgress;
            ("service_desk.feedback.started", false)
        }
        WorkOrderStatus::WaitingForParts => {
            order.status = WorkOrderStatus::InProgress;
            ("service_desk.feedback.parts_received", false)
        }
        WorkOrderStatus::InProgress if order.steps.iter().all(|step| step.complete) => {
            order.status = WorkOrderStatus::ReadyForPickup;
            ("service_desk.feedback.ready", false)
        }
        WorkOrderStatus::InProgress => ("service_desk.feedback.checklist_incomplete", true),
        WorkOrderStatus::ReadyForPickup => {
            order.status = WorkOrderStatus::Closed;
            ("service_desk.feedback.pickup_recorded", false)
        }
        WorkOrderStatus::Closed => ("service_desk.feedback.order_closed", true),
    };
    state.feedback = feedback.to_string();
    state.feedback_is_error = is_error;
}

pub fn completed_steps(steps: &[InspectionStep]) -> usize {
    steps.iter().filter(|step| step.complete).count()
}
```

## Add shift notes without losing the selected job

The next technician needs to know what part was fitted, what still needs another look, or why a job is waiting. Keep each note on its work order rather than adding a message that floats at the top of the page.

The draft is keyed by work-order ID in `ServiceDeskState`. A technician can start a note, open another job and return without losing the first draft. `TextInput` sends edits to a reducer. **Add note** trims and validates the text before adding it to the selected work order. An empty note shows a useful message; a saved note appears in that order's history and clears only that order's draft.

The browser example keeps notes in app memory, so closing the preview resets the sample data. For durable storage or a service, keep the reducer boundary and request the work through an asynchronous effect or job. Then the UI can show loading or an error without blocking the desktop event loop. This tutorial keeps the workflow in memory so the state changes are easy to see and test.

```rust
use crate::models::{InspectionStep, WorkOrderStatus};
use fission::prelude::*;
use std::collections::HashMap;

#[derive(Clone, Debug, PartialEq)]
pub struct ServiceDeskState {
    pub work_orders: Vec<crate::models::WorkOrder>,
    pub selected_work_order: Option<u32>,
    pub note_drafts: HashMap<u32, String>,
    pub next_note_id: u64,
    pub feedback: String,
    pub feedback_is_error: bool,
    pub search_query: String,
}

impl Default for ServiceDeskState {
    fn default() -> Self {
        Self {
            work_orders: Vec::new(),
            selected_work_order: None,
            note_drafts: HashMap::new(),
            next_note_id: 1,
            feedback: String::new(),
            feedback_is_error: false,
            search_query: String::new(),
        }
    }
}

impl GlobalState for ServiceDeskState {}

#[fission_reducer(ToggleInspectionStep)]
pub fn on_toggle_inspection_step(
    state: &mut ServiceDeskState,
    order_id: u32,
    step_id: String,
) {
    let updated = state
        .work_orders
        .iter_mut()
        .find(|order| order.id == order_id)
        .and_then(|order| {
            order.steps.iter_mut().find(|step| step.id == step_id.as_str()).map(|step| {
                step.complete = !step.complete;
            })
        })
        .is_some();
    state.feedback = if updated {
        "service_desk.feedback.step_updated".to_string()
    } else {
        "service_desk.feedback.step_missing".to_string()
    };
    state.feedback_is_error = !updated;
}

#[fission_reducer(AdvanceWorkOrder)]
pub fn on_advance_work_order(state: &mut ServiceDeskState, order_id: u32) {
    let Some(order) = state.work_orders.iter_mut().find(|order| order.id == order_id) else {
        state.feedback = "service_desk.feedback.order_missing".to_string();
        state.feedback_is_error = true;
        return;
    };

    let (feedback, is_error) = match order.status {
        WorkOrderStatus::Open => {
            order.status = WorkOrderStatus::InProgress;
            ("service_desk.feedback.started", false)
        }
        WorkOrderStatus::WaitingForParts => {
            order.status = WorkOrderStatus::InProgress;
            ("service_desk.feedback.parts_received", false)
        }
        WorkOrderStatus::InProgress if order.steps.iter().all(|step| step.complete) => {
            order.status = WorkOrderStatus::ReadyForPickup;
            ("service_desk.feedback.ready", false)
        }
        WorkOrderStatus::InProgress => ("service_desk.feedback.checklist_incomplete", true),
        WorkOrderStatus::ReadyForPickup => {
            order.status = WorkOrderStatus::Closed;
            ("service_desk.feedback.pickup_recorded", false)
        }
        WorkOrderStatus::Closed => ("service_desk.feedback.order_closed", true),
    };
    state.feedback = feedback.to_string();
    state.feedback_is_error = is_error;
}

#[fission_reducer(UpdateShiftNoteDraft)]
pub fn on_update_shift_note_draft(
    state: &mut ServiceDeskState,
    order_id: u32,
    ctx: &mut ReducerContext<ServiceDeskState>,
) {
    let Some(change) = ctx.input.text_change() else {
        return;
    };
    if change.new_text.is_empty() {
        state.note_drafts.remove(&order_id);
    } else {
        state.note_drafts.insert(order_id, change.new_text.clone());
    }
    state.feedback.clear();
    state.feedback_is_error = false;
}

#[fission_reducer(AddShiftNote)]
pub fn on_add_shift_note(state: &mut ServiceDeskState, order_id: u32) {
    let message = state.note_drafts.get(&order_id).cloned().unwrap_or_default();
    if message.trim().is_empty() {
        state.feedback = "service_desk.feedback.note_empty".to_string();
        state.feedback_is_error = true;
        return;
    }
    let Some(order_index) = state.work_orders.iter().position(|order| order.id == order_id) else {
        state.feedback = "service_desk.feedback.order_missing".to_string();
        state.feedback_is_error = true;
        return;
    };
    let note_id = format!("shift-note-{}", state.next_note_id);
    state.next_note_id += 1;
    state.work_orders[order_index]
        .shift_notes
        .push(crate::models::ShiftNote::draft(note_id, message.trim().to_string()));
    state.note_drafts.remove(&order_id);
    state.feedback = "service_desk.feedback.note_added".to_string();
    state.feedback_is_error = false;
}

pub fn completed_steps(steps: &[InspectionStep]) -> usize {
    steps.iter().filter(|step| step.complete).count()
}

#[fission_reducer(UpdateWorkOrderSearch)]
pub fn on_update_work_order_search(
    state: &mut ServiceDeskState,
    ctx: &mut ReducerContext<ServiceDeskState>,
) {
    if let Some(change) = ctx.input.text_change() {
        let query = change.new_text.clone();
        if let Some(order) = state
            .work_orders
            .iter()
            .find(|order| order.matches_search(&query))
        {
            state.selected_work_order = Some(order.id);
        }
        state.search_query = query;
        state.feedback.clear();
        state.feedback_is_error = false;
    }
}
```

```rust
    fn search_term(self) -> &'static str {
        match self {
            Self::High => "high",
            Self::Normal => "normal",
        }
    }
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct InspectionStep {
    pub id: String,
    pub title_key: String,
    pub category: InspectionCategory,
    pub complete: bool,
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct ShiftNote {
    pub id: String,
    pub author: Option<String>,
    pub time: Option<String>,
    pub message: String,
}

impl ShiftNote {
    pub(crate) fn draft(id: impl Into<String>, message: impl Into<String>) -> Self {
        Self {
            id: id.into(),
            author: None,
            time: None,
            message: message.into(),
        }
    }
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct WorkOrder {
    pub id: u32,
    pub reference: String,
    pub title: String,
    pub description: String,
    pub location: String,
    pub requested_by: String,
    pub due_window: String,
    pub due_today: bool,
    pub priority: WorkOrderPriority,
    pub status: WorkOrderStatus,
    pub steps: Vec<InspectionStep>,
    pub shift_notes: Vec<ShiftNote>,
}

impl WorkOrder {
    pub fn matches_search(&self, query: &str) -> bool {
        let query = query.trim().to_lowercase();
        if query.is_empty() {
            return true;
        }
        [
            self.reference.as_str(),
            self.title.as_str(),
            self.description.as_str(),
            self.location.as_str(),
            self.requested_by.as_str(),
            self.priority.search_term(),
            self.status.search_term(),
        ]
        .iter()
        .any(|field| field.to_lowercase().contains(&query))
    }
}
```

Search is the last piece of the workspace. It checks the reference, equipment description, location, requester, priority and status, so staff can start with whatever information they have. As the query changes, the first matching job is selected. If there is no match, the queue says so and the detail panel offers a way to clear the search.

The draft stays keyed by work-order ID, so a search or selection change cannot attach it to the wrong repair. The browser preview and desktop window use the same reducers.

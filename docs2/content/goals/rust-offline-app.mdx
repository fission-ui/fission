Say a technician updates a compressor inspection on a train and later finds a newer version from another device. This tutorial models the local edit, pending queue and conflict choice in a small field-work screen. It is an in-memory state model: it does not write to Fission Store or contact a server. If you want the complete Store-backed notes app and sync flow, continue with the [mobile field-notes tutorial](/blog/build-an-offline-first-notes-app-for-android-and-ios/).

Keep the local edit usable while sync is pending. When a reply arrives, compare it with the current task state before applying it so an older request cannot overwrite newer work.

Install the Fission CLI and scaffold a Web project for the interactive preview:

```sh
cargo install cargo-fission
fission init harbour-offline
cd harbour-offline
cargo add serde_yaml
fission add-target web --project-dir .
```

`fission init` creates the Rust app and `fission add-target` adds the Web host. The tutorial adds the two translation files and `src/i18n.rs`. The inspection note, revision counters and sync status are app data, so they live in `GlobalState`; a retained disclosure or input-only UI state would belong to its component. Real database and network operations belong in effects requested by reducers, not in component conversion.

The page preview compiles the screen into WebAssembly and seeds an example work order. It lets you try the state transitions, but reloading resets the preview. There is no storage provider or sync service in this model.

```rust
impl GlobalState for OfflineState {}

fission_component! {
    pub OfflineNotes<OfflineState> {}

            ]),

            Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                Badge(text: queue),
                Text(cx.tr("sync.preview_queue"))
                    .color(tokens.colors.text_secondary),
            ]),
            Container(Column(gap: tokens.spacing.xs, children: [
                Text(cx.tr("work.order"))
                    .weight(tokens.typography.font_weight_semibold),
                Text(cx.tr("work.due"))
                    .color(tokens.colors.text_secondary),
                Text(if state.pump_check_complete {
                    cx.tr("work.pressure_complete")
                } else {
                    cx.tr("work.pressure_next")
                }),
            ]))
                .padding_all(tokens.spacing.m)
                .bg(tokens.colors.background)
                .border(tokens.colors.border, 1.0)
                .border_radius(tokens.radii.medium),

                    child: Text(if state.pump_check_complete { cx.tr("work.check_complete") } else { cx.tr("work.complete_check") }),
                    key: "pump-pressure-check",
                    disabled: state.pump_check_complete,
                    on_press: reduce {
                        if !state.pump_check_complete {
                            state.pump_check_complete = true;
                            state.queued_changes = state.queued_changes.saturating_add(1);
                        }
                    },
                ),
            ]),
        ])
    )
    .padding_all(tokens.spacing.l)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.large)
}
```

## Edit a note and model the pending revision

The reducer below checks the note, advances its revision and updates the in-memory pending count. That is the whole scope of this step: it does not save to disk or enqueue a network request. To turn this model into an offline app, hydrate Store once during startup and only begin sync after the local write succeeds. The linked mobile field-notes tutorial shows that full flow.

### Production flow: persist before syncing

For the real app, render from the local record, persist an edit first, then queue a sync effect. Include the revision in the request and ignore a response that no longer matches the latest revision. That prevents a slow response from replacing newer work.

After you connect a real service, show distinct **Saved on this device**, **Syncing**, **Synced**, and **Could not sync** states. Keep the edit after a failed request and offer **Retry sync** without making the user re-enter it. On restart, hydrate the local queue before starting network work.

The linked mobile field-notes tutorial shows the SQLite write path and the reducer that rejects a stale sync completion. It deliberately leaves out the HTTP service; until you add one, test local persistence and dispatch out-of-order completion actions directly rather than claiming a sync or retry works end to end.

```rust
use fission::prelude::*;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
enum NoteNotice {
    Empty,
    Queued,
}

#[derive(Debug, Default, PartialEq)]
pub struct OfflineState {
    pub pressure_checked: bool,
    pub note: String,
    pub note_revision: u64,
    pub queued_changes: u32,
    note_notice: Option<NoteNotice>,
}

impl GlobalState for OfflineState {}

#[fission_reducer(CompletePressureCheck)]
fn complete_pressure_check(state: &mut OfflineState) {
    state.pressure_checked = true;
    state.queued_changes = state.queued_changes.saturating_add(1);
}

#[fission_reducer(QueueInspectionNote)]
fn queue_inspection_note(state: &mut OfflineState) {
    if state.note.trim().is_empty() {
        state.note_notice = Some(NoteNotice::Empty);
        return;
    }

    state.note_revision = state.note_revision.saturating_add(1);
    state.queued_changes = state.queued_changes.saturating_add(1);
    state.note_notice = Some(NoteNotice::Queued);
}

fission_component! {
    pub OfflineNotes<OfflineState> {}
    view(_notes, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let complete = with_reducer!(cx.build, CompletePressureCheck, complete_pressure_check);
        let queue_note = with_reducer!(cx.build, QueueInspectionNote, queue_inspection_note);
        let queued = format!("{} {}", state.queued_changes, cx.tr("sync.waiting"));
        let note_notice = state.note_notice.map(|notice| match notice {
            NoteNotice::Empty => cx.tr("note.empty"),
            NoteNotice::Queued => cx.tr("note.queued"),
        });
    } =>
    Container(Column(gap: tokens.spacing.m, children: [
        Row(gap: tokens.spacing.m, wrap: ir_op::FlexWrap::Wrap, align_items: ir_op::AlignItems::Center, children: [
            Column(gap: tokens.spacing.xs, flex_grow: 1.0, children: [
                Text(cx.tr("app.name")).weight(tokens.typography.font_weight_bold),
                Text(cx.tr("work.today")).color(tokens.colors.text_secondary),
            ]),
            Badge(text: cx.tr("sync.offline")),
        ]),
        Divider(),
        Text(cx.tr("work.order")).weight(tokens.typography.font_weight_semibold),
        TextInput(label: Some(cx.tr("note.label").into()), bind: state.note, required: true),
        Row(gap: tokens.spacing.s, children: [
            Badge(text: queued),
            Text(format!("{} {}", cx.tr("sync.revision"), state.note_revision))
                .color(tokens.colors.text_secondary),
        ]),
        if let Some(notice) = note_notice {
            Text(notice).color(tokens.colors.text_secondary)
        },
        Text(if state.pressure_checked { cx.tr("note.pressure_done") } else { cx.tr("note.pressure_todo") }),
        Button(
            child: Text(cx.tr("note.queue")),
            key: "queue-inspection-note",
            on_press: queue_note,
        ),
        Button(
            child: Text(cx.tr("work.complete_check")),
            key: "pressure-check",
            disabled: state.pressure_checked,
            on_press: complete,
        ),
        Text(cx.tr("note.preview")).color(tokens.colors.text_secondary),
    ]))
    .padding_all(tokens.spacing.l)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.large)
}
```

## Resolve a conflict without losing local work

Give every local change a stable id and revision. When local and remote writes finish in a different order, compare revisions before accepting a completion so an old response cannot overwrite a newer edit. If the server has a newer version, show both copies and let the technician choose which one to keep.

Keep I/O outside component conversion. Use reducers for explicit state transitions, then queue host work through an asynchronous effect, capability, job or service so the UI stays responsive. This in-memory preview seeds a newer server revision so you can exercise the conflict choices; it does not pretend to contact a server.

```rust
use fission::prelude::*;

#[derive(Debug, Default, PartialEq)]
pub struct OfflineState {
    pub note: String,
    pub local_revision: u64,
    pub server_note: Option<String>,
    pub server_revision: u64,
    pub queued_changes: u32,
    sync_status: SyncStatus,
}

impl GlobalState for OfflineState {}

#[derive(Debug, Default, Clone, Copy, PartialEq, Eq)]
enum SyncStatus {
    #[default]
    PreviewData,
    NoteRequired,
    LocalQueued,
    ServerReview,
    LocalKept,
    ServerSelected,
}

#[fission_reducer(SaveLocalRevision)]
fn save_local_revision(state: &mut OfflineState) {
    if state.note.trim().is_empty() {
        state.sync_status = SyncStatus::NoteRequired;
        return;
    }

    state.local_revision = state.local_revision.saturating_add(1);
    state.queued_changes = 1;
    state.sync_status = SyncStatus::LocalQueued;
}

#[fission_reducer(PreviewServerRevision)]
fn preview_server_revision(state: &mut OfflineState) {
    state.server_revision = state
        .local_revision
        .max(state.server_revision)
        .saturating_add(1);
    state.server_note = Some("Pressure rose to 2.8 bar after the second inspection.".into());
    state.sync_status = SyncStatus::ServerReview;
}

#[fission_reducer(KeepLocalRevision)]
fn keep_local_revision(state: &mut OfflineState) {
    state.server_note = None;
    state.local_revision = state
        .local_revision
        .max(state.server_revision)
        .saturating_add(1);
    state.queued_changes = 1;
    state.sync_status = SyncStatus::LocalKept;
}

#[fission_reducer(UseServerRevision)]
fn use_server_revision(state: &mut OfflineState) {
    if let Some(server_note) = state.server_note.take() {
        state.note = server_note;
        state.local_revision = state.server_revision;
        state.queued_changes = 0;
        state.sync_status = SyncStatus::ServerSelected;
    }
}

fission_component! {
    pub OfflineNotes<OfflineState> {}
    view(_notes, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let save_local = with_reducer!(cx.build, SaveLocalRevision, save_local_revision);
        let preview_server = with_reducer!(cx.build, PreviewServerRevision, preview_server_revision);
        let keep_local = with_reducer!(cx.build, KeepLocalRevision, keep_local_revision);
        let use_server = with_reducer!(cx.build, UseServerRevision, use_server_revision);
        let sync_message = match state.sync_status {
            SyncStatus::PreviewData => cx.tr("sync.preview_data"),
            SyncStatus::NoteRequired => cx.tr("sync.note_required"),
            SyncStatus::LocalQueued => cx.tr("sync.local_waiting"),
            SyncStatus::ServerReview => cx.tr("sync.server_review"),
            SyncStatus::LocalKept => cx.tr("sync.local_selected"),
            SyncStatus::ServerSelected => cx.tr("sync.server_selected"),
        };
        let status = if state.server_note.is_some() {
            cx.tr("sync.conflict")
        } else {
            cx.tr("sync.connected")
        };
        let local_revision = format!("{} {}", cx.tr("sync.revision"), state.local_revision);
        let server_revision = format!("{} {}", cx.tr("sync.server_revision"), state.server_revision);
        let queued = format!("{} {}", state.queued_changes, cx.tr("sync.waiting"));
    } =>
    Container(Column(gap: tokens.spacing.m, children: [
        Row(gap: tokens.spacing.m, wrap: ir_op::FlexWrap::Wrap, align_items: ir_op::AlignItems::Center, children: [
            Column(gap: tokens.spacing.xs, flex_grow: 1.0, children: [
                Text(cx.tr("app.name")).weight(tokens.typography.font_weight_bold),
                Text(cx.tr("work.today")).color(tokens.colors.text_secondary),
            ]),
            Badge(text: status),
        ]),
        Divider(),
        Text(cx.tr("work.order")).weight(tokens.typography.font_weight_semibold),
        TextInput(
            label: Some(cx.tr("note.device_label").into()),
            bind: state.note,
            enabled: state.server_note.is_none(),
            required: true,
        ),
        Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
            Badge(text: local_revision),
            Badge(text: queued),
        ]),
        if let Some(server_note) = &state.server_note {
            Container(Column(gap: tokens.spacing.s, children: [
                Text(server_revision)
                    .weight(tokens.typography.font_weight_semibold),
                Text(server_note.clone()).color(tokens.colors.text_secondary),
                Text(cx.tr("sync.local_preserved")),
                Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                    Button(child: Text(cx.tr("sync.keep_local")), key: "keep-local", on_press: keep_local),
                    Button(
                        child: Text(cx.tr("sync.use_server")),
                        key: "use-server",
                        variant: ButtonVariant::Outline,
                        on_press: use_server,
                    ),
                ]),
            ]))
                .padding_all(tokens.spacing.m)
                .bg(tokens.colors.background)
                .border(tokens.colors.border, 1.0)
                .border_radius(tokens.radii.medium)
        } else {
            Column(gap: tokens.spacing.s, children: [
                Text(sync_message).color(tokens.colors.text_secondary),
                Button(
                    child: Text(cx.tr("sync.queue_revision")),
                    key: "save-local-revision",
                    disabled: state.note.trim().is_empty(),
                    on_press: save_local,
                ),
                Button(
                    child: Text(cx.tr("sync.preview_server")),
                    key: "server-revision",
                    variant: ButtonVariant::Outline,
                    on_press: preview_server,
                ),
            ])
        },
        Text(cx.tr("sync.preview_only"))
            .color(tokens.colors.text_secondary),
    ]))
    .padding_all(tokens.spacing.l)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.large)
}
```

## Run and test the state model

From the project root, run the checks in order:

```sh
fission doctor --project-dir .
cargo test
fission build --target web --project-dir .
fission test --target web --project-dir .
```

Expected result: the preview lets you model a local edit, pending sync state and conflict choice. It does not persist changes or contact a server. Follow the [mobile field-notes tutorial](/blog/build-an-offline-first-notes-app-for-android-and-ios/) for the SQLite-backed workflow.

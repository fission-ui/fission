A documentation site has two different jobs: teach a task from start to finish and let developers look up a specific API. Put everything in one flat menu and neither job is easy to scan. We will build a static site that separates Learn from Reference and still generates crawlable HTML.

Create Atlas Docs with a left navigation tree, a readable article column and a right-hand page outline. Separate learning guides from reference pages so readers know whether to follow a task or look up a type.

Install the Fission CLI and scaffold the Static site project:

```sh
cargo install cargo-fission
fission init atlas-docs --template website
cd atlas-docs
cargo add serde_yaml
```

The website template creates a Static site project with a static entrypoint in `src/main.rs`, route registration and the Web shell in `src/lib.rs`, and reusable page, navigation and footer components in their own modules. Add the task files shown in the tree as you work. The preview's `src/app.rs` is a separate, compiled browser harness for the interactive lesson; the production website uses the template modules and `fission.toml`. Do not copy `preview/lib.rs` into the website.

### Mount guide and reference content

Merge the site settings into the template’s existing `[site]` table and add explicit content routes. Do not create a second `[site]` table. The documentation template supplies the left navigation, article column, page outline and footer; a reader can open a saved route without running a search script.

```toml
[site]
title = "Atlas Docs"
description = "Guides and reference for Atlas users."
base_url = "https://docs.atlas.example.com"
out_dir = "dist/site"
asset_dirs = ["assets"]
generate_sitemap = true
generate_robots = true

[site.code_highlighting]
enabled = true

[site.search]
enabled = true
output_path = "search"
min_token_len = 2

[[site.routes]]
kind = "content"
path = "/docs"
source = "content/docs"
template = "fission::site::documentation"
sidebar = "site/docs-sidebar.toml"

[[site.routes]]
kind = "content"
path = "/reference"
source = "content/reference"
template = "fission::site::documentation"
sidebar = "site/reference-sidebar.toml"
```

Give each guide a descriptive title and description in Markdown front matter. Keep the sidebar order intentional instead of relying on alphabetical file names:

```toml
# site/docs-sidebar.toml
[[items]]
title = "Start here"
href = "/docs/overview/"
level = 1
group = true

[[items]]
title = "Quickstart"
href = "/docs/learn/quickstart/"
level = 2
```

Use the same sidebar format for the reference route, but link it to `/reference/` pages. Run a search for an exact API name, then disable JavaScript and open one guide URL directly; the article and route should remain readable. Code highlighting is an enhancement, not a requirement for finding or copying the example.

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

const SOURCES: [(&str, &str); 2] = [
    ("en-US", include_str!("../i18n/en-US.yaml")),
    ("es-ES", include_str!("../i18n/es-ES.yaml")),
];

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in SOURCES {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid tutorial translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

## Add search beside explanations and code

Mount Markdown directories at explicit paths and define sidebars in TOML. Keep the page title and description in frontmatter, use heading levels in order, and put versioned or related API links after the working instructions.

Keep the search query and selected guide local; they only affect this view. The guides and their routes are site content, configured separately so each URL can be opened directly.

use fission::prelude::*;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
enum Guide {
    Quickstart,
    Website,
    Routing,
}

fn matches_all_terms(query: &str, translated_terms: &str) -> bool {
    let translated_terms = translated_terms.to_lowercase();
    query
        .split_whitespace()
        .all(|term| translated_terms.contains(term))
}

fission_component! {
    GuideArticle<()> {
        props {
            title: String,
            description: String,
            requirements_title: String,
            requirements_body: String,
            build_title: String,
            build_body: String,
        }
    }
    view(article, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(
        Column(gap: tokens.spacing.s, children: [
            Text(article.title.clone()).size(tokens.typography.heading1_size),
            Text(article.description.clone()),
            Divider(),
            Text(article.requirements_title.clone())
                .weight(tokens.typography.font_weight_semibold),
            Text(article.requirements_body.clone()),
            Text(article.build_title.clone())
                .weight(tokens.typography.font_weight_semibold),
            Text(article.build_body.clone()),
        ])
    )
    .padding_all(tokens.spacing.l)
    .bg(tokens.colors.surface_raised)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
}

fission_component! {
    GuideOutline<()> {
        props {
            requirements_title: String,
            build_title: String,
            run_label: String,
        }
    }
    view(outline, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(
        Column(gap: tokens.spacing.s, children: [
            Text(cx.tr("toc.title"))
                .weight(tokens.typography.font_weight_semibold),
            Text(outline.requirements_title.clone()),
            Text(outline.build_title.clone()),
            Text(outline.run_label.clone()),
        ])
    )
    .width(160.0)
    .padding_all(tokens.spacing.m)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
}

fission_component! {
    pub DocumentationSite<()> {
        state {
            query: String = String::new(),
            active_guide: Guide = Guide::Quickstart,
        }
    }
    view(docs, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let query = docs.query.to_lowercase();
        let quickstart_terms = cx.tr("search.terms.quickstart");
        let routing_terms = cx.tr("search.terms.routing");
        let website_terms = cx.tr("search.terms.website");
        let quickstart_match = matches_all_terms(&query, &quickstart_terms);
        let routing_match = matches_all_terms(&query, &routing_terms);
        let website_match = matches_all_terms(&query, &website_terms);
        let has_results = quickstart_match || routing_match || website_match;
        let selected_guide_matches = match docs.active_guide {
            Guide::Quickstart => quickstart_match,
            Guide::Website => website_match,
            Guide::Routing => routing_match,
        };
        let active_guide = if selected_guide_matches {
            docs.active_guide
        } else if quickstart_match {
            Guide::Quickstart
        } else if website_match {
            Guide::Website
        } else {
            Guide::Routing
        };
        let (active_guide_title, active_guide_description) = match active_guide {
            Guide::Quickstart => (
                cx.tr("guide.quickstart"),
                cx.tr("article.quickstart.description"),
            ),
            Guide::Website => (
                cx.tr("guide.website"),
                cx.tr("article.website.description"),
            ),
            Guide::Routing => (
                cx.tr("guide.routing"),
                cx.tr("article.routing.description"),
            ),
        };
        let requirements_title = cx.tr("article.requirements.title");
        let requirements_body = cx.tr("article.requirements.body");
        let build_title = cx.tr("article.build.title");
        let build_body = cx.tr("article.build.body");
        let run_label = cx.tr("toc.run");
        let guide_article = || GuideArticle::new(
            active_guide_title.clone(),
            active_guide_description.clone(),
            requirements_title.clone(),
            requirements_body.clone(),
            build_title.clone(),
            build_body.clone(),
        );
        let responsive_results = Responsive::new_with_id(
            WidgetId::explicit("atlas-docs.results"),
            || guide_article(),
        )
        .case_min_width_with(960.0, || Row {
            children: widgets![
                guide_article(),
                GuideOutline::new(
                    requirements_title.clone(),
                    build_title.clone(),
                    run_label.clone(),
                ),
            ],
            gap: Some(tokens.spacing.m),
            ..Default::default()
        });
    } =>
    SemanticsRegion(
        identifier: Some("atlas-docs.site".to_string()),
        label: Some(cx.tr("site.a11y")),
        child: Container(
            Column(gap: tokens.spacing.m, children: [
                Row(gap: tokens.spacing.m, align_items: ir_op::AlignItems::Center, children: [
                    Text(cx.tr("brand")).size(tokens.typography.heading2_size),
                    Spacer(flex_grow: 1.0),
                    Text(cx.tr("nav.learn")).weight(tokens.typography.font_weight_semibold),
                    Text(cx.tr("nav.reference")).color(tokens.colors.text_secondary),
                ]),
                TextInput(
                    label: Some(cx.tr("search.label").into()),
                    placeholder: Some(cx.tr("search.placeholder").into()),
                    bind: docs.query,
                    semantics_identifier: "atlas-docs.search".to_string(),
                ),
                if quickstart_match || website_match || routing_match {
                    Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                        if quickstart_match {
                            Button(child: Text(cx.tr("guide.quickstart")), key: "guide-quickstart",
                                on_press: reduce { docs.active_guide = Guide::Quickstart; })
                                .semantics_identifier("atlas-docs.guide.quickstart")
                        },
                        if website_match {
                            Button(child: Text(cx.tr("guide.website")), key: "guide-website",
                                on_press: reduce { docs.active_guide = Guide::Website; })
                                .semantics_identifier("atlas-docs.guide.website")
                        },
                        if routing_match {
                            Button(child: Text(cx.tr("guide.routing")), key: "guide-routing",
                                on_press: reduce { docs.active_guide = Guide::Routing; })
                                .semantics_identifier("atlas-docs.guide.routing")
                        },
                    ])
                },
                if has_results {
                    responsive_results
                } else {
                    Column(gap: tokens.spacing.s, children: [
                        Text(cx.tr("empty.title"))
                            .weight(tokens.typography.font_weight_semibold),
                        Text(cx.tr("empty.description"))
                            .color(tokens.colors.text_secondary),
                        Button(child: Text(cx.tr("search.clear")), key: "clear-search",
                            on_press: reduce { docs.query = String::new(); }),
                    ])
                },
            ])
        )
        .padding_all(tokens.spacing.l)
        .bg(tokens.colors.surface),
    )
}

        let website_match = matches_all_terms(&query, &website_terms);
        let has_results = quickstart_match || routing_match || website_match;
        let selected_guide_matches = match docs.active_guide {
            Guide::Quickstart => quickstart_match,
            Guide::Website => website_match,
            Guide::Routing => routing_match,
        };
        let active_guide = if selected_guide_matches {
            docs.active_guide
        } else if quickstart_match {
            Guide::Quickstart
        } else if website_match {
            Guide::Website
        } else {
            Guide::Routing
        };
        let (active_guide_title, active_guide_description) = match active_guide {
            Guide::Quickstart => (
                cx.tr("guide.quickstart"),
                cx.tr("article.quickstart.description"),
            ),
            Guide::Website => (
                cx.tr("guide.website"),
                cx.tr("article.website.description"),
            ),
            Guide::Routing => (
                cx.tr("guide.routing"),
                cx.tr("article.routing.description"),
            ),
        };
        let requirements_title = cx.tr("article.requirements.title");
        let requirements_body = cx.tr("article.requirements.body");
        let build_title = cx.tr("article.build.title");
        let build_body = cx.tr("article.build.body");
        let run_label = cx.tr("toc.run");
        let guide_article = || GuideArticle::new(
            active_guide_title.clone(),
            active_guide_description.clone(),
            requirements_title.clone(),
            requirements_body.clone(),
            build_title.clone(),
            build_body.clone(),
        );
        let responsive_results = Responsive::new_with_id(
            WidgetId::explicit("atlas-docs.results"),
            || guide_article(),

            children: widgets![
                guide_article(),
                GuideOutline::new(
                    requirements_title.clone(),
                    build_title.clone(),
                    run_label.clone(),
                ),
            ],
            gap: Some(tokens.spacing.m),
            ..Default::default()
        });

                    Text(cx.tr("brand")).size(tokens.typography.heading2_size),
                    Spacer(flex_grow: 1.0),
                    Text(cx.tr("nav.learn")).weight(tokens.typography.font_weight_semibold),
                    Text(cx.tr("nav.reference")).color(tokens.colors.text_secondary),

                TextInput(
                    label: Some(cx.tr("search.label").into()),
                    placeholder: Some(cx.tr("search.placeholder").into()),
                    bind: docs.query,
                    semantics_identifier: "atlas-docs.search".to_string(),

                        Text(cx.tr("empty.description"))

                            on_press: reduce { docs.query = String::new(); }),
                    ])
                },
            ])
        )
        .padding_all(tokens.spacing.l)
        .bg(tokens.colors.surface),
    )

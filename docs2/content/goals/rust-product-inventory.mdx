A delivery arrives before the stockroom opens. The receiver needs to match each carton to a product, find its storage bin and record the number of units received. Searching by name alone is not sufficient: similar products can occupy different bins, and adding stock to the wrong record leaves the physical shelf and the inventory system disagreeing.

We'll build that receiving screen. Product records belong in shared application state because the rows, stock total and reorder summary all describe the same catalogue. The search, stock filter and unsubmitted quantity belong to the dashboard; they describe what the receiver is doing, not what the warehouse owns.

This example is an in-memory receiving workbench, not a warehouse service. The normal app accepts a catalogue export. The embedded preview loads five fictional products from a separate fixture file so you can try the receiving flow immediately. Neither path writes to a database, shares stock with another session or survives a reload. A successful receipt here means the local state changed; it does not mean a warehouse service accepted a transaction.

## Create the app

Use the generated project and add the Web target. The shared components also run through the native launcher.

```sh
cargo install cargo-fission
fission init harbour-inventory
cd harbour-inventory
cargo add serde --features derive
cargo add serde_json serde_yaml
fission add-target web --project-dir .
```

## Load a catalogue and make its stock readable

A stock keeping unit, or SKU, identifies the product the receiver recognises on the carton. The numeric ID identifies its record and remains stable when the list is searched or reordered. Keep both: a visible SKU helps the person, while a stable record ID ties interactions to the right data.

The product also has a supplier, storage bin, reorder point and unit cost. This catalogue uses USD throughout, with costs stored as integer cents. That avoids fractional-cent rounding in the model; it does not implement currency conversion or a general money type.

The import accepts a JSON array of complete products. Its category values are `drinkware`, `stationery`, `cooking`, `water-treatment` and `shelter`. Numeric values are unsigned whole numbers. Copy the shape shown in `preview/fixtures.rs` when preparing an export, but supply your own records to the normal app. The preview serialisation and the production import use the same product type.

Validate the whole catalogue before assigning it. Duplicate IDs or SKUs, incomplete records, malformed JSON and oversized input leave the existing state alone. Once a catalogue is loaded, the import cannot silently replace stock that someone has already adjusted. The test module checks those boundaries independently of the UI.

pub struct InventoryProduct {
    pub id: u32,
    pub sku: String,
    pub name: String,
    pub category: ProductCategory,
    pub supplier: String,
    pub bin: String,
    pub stock: u32,
    pub reorder_point: u32,
    pub unit_cost_cents: u32,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq, serde::Serialize, serde::Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum ProductCategory {
    Drinkware,
    Stationery,
    Cooking,
    WaterTreatment,
    Shelter,
}

impl ProductCategory {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::Drinkware => "inventory.category.drinkware",
            Self::Stationery => "inventory.category.stationery",
            Self::Cooking => "inventory.category.cooking",
            Self::WaterTreatment => "inventory.category.water_treatment",
            Self::Shelter => "inventory.category.shelter",
        }
    }
}

use crate::models::InventoryProduct;
use fission::prelude::*;
use std::collections::HashSet;

#[derive(Clone, Debug, PartialEq)]
pub enum InventoryFeedback {
    Loaded(usize),
    Received { sku: String, quantity: u32 },
    Rejected(&'static str),
}

#[derive(Clone, Debug, Default, PartialEq)]
pub struct InventoryState {
    pub products: Vec<InventoryProduct>,
    pub feedback: Option<InventoryFeedback>,
}

impl GlobalState for InventoryState {}

impl InventoryState {
    pub fn import_catalogue(&mut self, source: &str) {
        // Do not replace a catalogue after staff have started receiving stock.
        if !self.products.is_empty() {
            self.feedback = Some(InventoryFeedback::Rejected("inventory.import.already_loaded"));
            return;
        }
        match parse_catalogue(source) {
            Ok(products) => {
                self.feedback = Some(InventoryFeedback::Loaded(products.len()));
                self.products = products;
            }
            Err(key) => self.feedback = Some(InventoryFeedback::Rejected(key)),
        }
    }
}

fn parse_catalogue(source: &str) -> Result<Vec<InventoryProduct>, &'static str> {
    if source.len() > 128 * 1024 {
        return Err("inventory.import.invalid");
    }
    let mut products: Vec<InventoryProduct> =
        serde_json::from_str(source).map_err(|_| "inventory.import.invalid")?;
    if products.is_empty() || products.len() > 500 {
        return Err("inventory.import.invalid");
    }
    let mut ids = HashSet::new();
    let mut skus = HashSet::new();
    for product in &mut products {
        product.sku = product.sku.trim().to_owned();
        product.name = product.name.trim().to_owned();
        product.supplier = product.supplier.trim().to_owned();
        product.bin = product.bin.trim().to_owned();
        if product.id == 0
            || [&product.sku, &product.name, &product.supplier, &product.bin]
                .iter().any(|value| value.is_empty() || value.chars().count() > 160)
            || !ids.insert(product.id)
            || !skus.insert(product.sku.to_lowercase())
        {
            return Err("inventory.import.invalid");
        }
    }
    Ok(products)
}
#[cfg(test)]
mod tests {
    use super::*;
    fn product(id: u32, sku: &str, stock: u32) -> InventoryProduct {
        InventoryProduct {
            id, sku: sku.into(), name: "Steel mug".into(),
            category: crate::models::ProductCategory::Drinkware,
            supplier: "Supplier".into(), bin: "A-01".into(),
            stock, reorder_point: 4, unit_cost_cents: 1800,
        }
    }
    #[test]
    fn duplicate_skus_and_ids_reject_the_whole_import() {
        for invalid in [
            vec![product(1, "MUG-A", 4), product(2, "mug-a", 6)],
            vec![product(1, "MUG-A", 4), product(1, "MUG-B", 6)],
        ] {
            let mut state = InventoryState::default();
            state.import_catalogue(&serde_json::to_string(&invalid).unwrap());
            assert!(state.products.is_empty());
            assert!(matches!(state.feedback, Some(InventoryFeedback::Rejected(_))));
        }
    }
    #[test]
    fn catalogue_is_loaded_once_and_keeps_source_ids() {
        let products = vec![product(104, "MUG-104", 4)];
        let mut state = InventoryState::default();
        state.import_catalogue(&serde_json::to_string(&products).unwrap());
        assert_eq!(state.products, products);
        state.import_catalogue("[]");
        assert_eq!(state.products, products);
    }
    #[test]
    fn empty_malformed_and_oversized_imports_do_not_load_products() {
        for source in ["[]", "not JSON", "{}"] {
            assert!(parse_catalogue(source).is_err());
        }
        assert!(parse_catalogue(&" ".repeat(128 * 1024 + 1)).is_err());
    }
    #[test]
    fn blank_fields_reject_the_whole_import() {
        let mut invalid = product(2, "MUG-B", 0);
        invalid.bin = " ".into();
        let source = serde_json::to_string(&vec![product(1, "MUG-A", 4), invalid]).unwrap();
        assert!(parse_catalogue(&source).is_err());
    }
}

                    columns: vec![GridTrack::auto_fit(GridTrack::minmax(

                            Text(cx.tr("inventory.metric.products")).color(tokens.colors.text_secondary),
                            Text(format!("{} {}", state.products.len(), cx.tr("inventory.metric.active")))

use crate::models::InventoryProduct;
use crate::state::InventoryState;
use fission::prelude::*;

fission_component! {
    pub InventoryProductRow<InventoryState> { props { product: InventoryProduct } }
    view(row, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let stock_status = if row.product.stock == 0 {
            cx.tr("inventory.status.out")
        } else if row.product.stock <= row.product.reorder_point {
            cx.tr("inventory.status.reorder")
        } else {
            cx.tr("inventory.status.in_stock")
        };
        let status_color = if row.product.stock == 0 {
            tokens.colors.error
        } else if row.product.stock <= row.product.reorder_point {
            tokens.colors.warning
        } else {
            tokens.colors.success
        };
    } =>
    Container(
        Grid(
            columns: vec![GridTrack::auto_fit(GridTrack::minmax(
                GridTrack::Points(180.0),
                GridTrack::Fr(1.0),
            ))],
            rows: vec![GridTrack::Auto],
            column_gap: tokens.spacing.l,
            row_gap: tokens.spacing.m,
            children: [
                Column(gap: tokens.spacing.xs, children: [
                    Text(row.product.name)
                        .weight(tokens.typography.font_weight_semibold),
                    Text(format!("{} · {}", row.product.sku, cx.tr(row.product.category.translation_key())))
                        .color(tokens.colors.text_secondary),
                    Text(format!("{}: {} · {}: {}", cx.tr("inventory.supplier"), row.product.supplier, cx.tr("inventory.bin"), row.product.bin))
                        .color(tokens.colors.text_secondary),
                ]),
                Column(gap: tokens.spacing.xs, children: [
                        Text(format!("{} {} · {}", row.product.stock, cx.tr("inventory.units"), stock_status))
                        .color(status_color)
                        .weight(tokens.typography.font_weight_semibold),
                    Text(format!("{} {} {}", cx.tr("inventory.reorder.at"), row.product.reorder_point, cx.tr("inventory.units")))
                        .color(tokens.colors.text_secondary),
                    Text(format!(
                        "USD {}.{:02} · {}",
                        row.product.unit_cost_cents / 100,
                        row.product.unit_cost_cents % 100,
                        cx.tr("inventory.cost.per_unit"),
                    )),
                ]),
            ],
        ),
    )
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
}

use crate::state::{InventoryFeedback, InventoryState};
use fission::prelude::*;

fission_component! {
    pub ReceiptNotice<InventoryState> {}
    view(_notice, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let message = match &state.feedback {
            None => cx.tr("inventory.receive.prompt"),
            Some(InventoryFeedback::Loaded(count)) => cx.tr("inventory.import.success")
                .replace("{count}", &count.to_string()),
            Some(InventoryFeedback::Received { sku, quantity }) => cx.tr("inventory.receipt.success")
                .replace("{sku}", sku).replace("{count}", &quantity.to_string()),
            Some(InventoryFeedback::Rejected(key)) => cx.tr(key),
        };
        let is_error = matches!(state.feedback, Some(InventoryFeedback::Rejected(_)));
    } =>
    SemanticsRegion(
        identifier: Some("inventory-stock-feedback".to_owned()),
        label: Some(cx.tr("inventory.semantics.receipt")),
        child: Text(message).color(if is_error { tokens.colors.error } else { tokens.colors.text_secondary }),
    )
}

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

const SOURCES: [(&str, &str); 2] = [
    ("en-US", include_str!("../i18n/en-US.yaml")),
    ("es-ES", include_str!("../i18n/es-ES.yaml")),
];

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in SOURCES {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid inventory translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

## Find a product and change only its stock

The receiver may have a supplier name or bin label rather than the product name. Search therefore checks those fields, the SKU and the translated category. The stock filter is applied as well: “Needs reorder” means the count is at or below that product's reorder point, not below an arbitrary global threshold.

For this intermediate step, the receive button adds five units. It demonstrates the transition before we add the packing-slip quantity field. The handler reads its own row's product ID and calls an ordinary Rust state method through `reduce`. It does not capture a borrowed loop variable or need a separate action type for a one-line transition.

The state method checks zero, a missing product and integer overflow before changing stock. Its typed result records the SKU and quantity, or a specific rejection. This keeps the message and its error styling consistent without storing a separate boolean that could contradict the message.

#[serde(deny_unknown_fields)]
pub struct InventoryProduct {
    pub id: u32,
    pub sku: String,
    pub name: String,
    pub category: ProductCategory,
    pub supplier: String,
    pub bin: String,
    pub stock: u32,
    pub reorder_point: u32,
    pub unit_cost_cents: u32,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq, serde::Serialize, serde::Deserialize)]
#[serde(rename_all = "kebab-case")]
pub enum ProductCategory {
    Drinkware,
    Stationery,
    Cooking,
    WaterTreatment,
    Shelter,
}

impl ProductCategory {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::Drinkware => "inventory.category.drinkware",
            Self::Stationery => "inventory.category.stationery",
            Self::Cooking => "inventory.category.cooking",
            Self::WaterTreatment => "inventory.category.water_treatment",
            Self::Shelter => "inventory.category.shelter",
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum InventoryFilter {
    All,
    NeedsReorder,
    OutOfStock,
}

pub fn matches_inventory_filter(
    product: &InventoryProduct,
    query: &str,
    filter: InventoryFilter,
    category_label: &str,
) -> bool {
    let query = query.trim().to_lowercase();
    let matches_query = query.is_empty()
        || product.name.to_lowercase().contains(&query)
        || product.sku.to_lowercase().contains(&query)
        || category_label.to_lowercase().contains(&query)
        || product.supplier.to_lowercase().contains(&query)
        || product.bin.to_lowercase().contains(&query);
    let matches_stock = match filter {
        InventoryFilter::NeedsReorder => product.stock <= product.reorder_point,
        InventoryFilter::OutOfStock => product.stock == 0,
        InventoryFilter::All => true,
    };

    matches_query && matches_stock
}

use crate::models::InventoryProduct;
use fission::prelude::*;
use std::collections::HashSet;

#[derive(Clone, Debug, PartialEq)]
pub enum InventoryFeedback {
    Loaded(usize),
    Received { sku: String, quantity: u32 },
    Rejected(&'static str),
}

#[derive(Clone, Debug, Default, PartialEq)]
pub struct InventoryState {
    pub products: Vec<InventoryProduct>,
    pub feedback: Option<InventoryFeedback>,
}

impl GlobalState for InventoryState {}

impl InventoryState {
    pub fn import_catalogue(&mut self, source: &str) {
        // Do not replace a catalogue after staff have started receiving stock.
        if !self.products.is_empty() {
            self.feedback = Some(InventoryFeedback::Rejected("inventory.import.already_loaded"));
            return;
        }
        match parse_catalogue(source) {
            Ok(products) => {
                self.feedback = Some(InventoryFeedback::Loaded(products.len()));
                self.products = products;
            }
            Err(key) => self.feedback = Some(InventoryFeedback::Rejected(key)),
        }
    }
}

fn parse_catalogue(source: &str) -> Result<Vec<InventoryProduct>, &'static str> {
    if source.len() > 128 * 1024 {
        return Err("inventory.import.invalid");
    }
    let mut products: Vec<InventoryProduct> =
        serde_json::from_str(source).map_err(|_| "inventory.import.invalid")?;
    if products.is_empty() || products.len() > 500 {
        return Err("inventory.import.invalid");
    }
    let mut ids = HashSet::new();
    let mut skus = HashSet::new();
    for product in &mut products {
        product.sku = product.sku.trim().to_owned();
        product.name = product.name.trim().to_owned();
        product.supplier = product.supplier.trim().to_owned();
        product.bin = product.bin.trim().to_owned();
        if product.id == 0
            || [&product.sku, &product.name, &product.supplier, &product.bin]
                .iter().any(|value| value.is_empty() || value.chars().count() > 160)
            || !ids.insert(product.id)
            || !skus.insert(product.sku.to_lowercase())
        {
            return Err("inventory.import.invalid");
        }
    }
    Ok(products)
}
impl InventoryState {
    pub fn receive_stock(&mut self, product_id: u32, quantity: u32) {
        let result = if quantity == 0 {
            Err("inventory.receipt.invalid_quantity")
        } else if let Some(product) = self.products.iter_mut().find(|product| product.id == product_id) {
            match product.stock.checked_add(quantity) {
                Some(next_stock) => {
                    product.stock = next_stock;
                    Ok(InventoryFeedback::Received { sku: product.sku.clone(), quantity })
                }
                None => Err("inventory.receipt.overflow"),
            }
        } else {
            Err("inventory.receipt.missing_product")
        };
        self.feedback = Some(result.unwrap_or_else(InventoryFeedback::Rejected));
    }
}

## Enter the receipt quantity and recover from mistakes

A fixed five-unit receipt is not a receiving workflow. The final dashboard starts with an empty quantity field so staff must enter the amount on the packing slip. Parsing happens while building the view; the state method still validates the dispatched number, since disabling a control is not a substitute for protecting the transition.

A reorder point is not a storage capacity. We show the count and threshold directly instead of drawing a progress bar against an invented maximum. The summary uses the entire catalogue, not just the visible search results, so filtering cannot appear to remove warehouse stock.

There are also two different empty states. Before import, there are no catalogue records. After import, a search or filter may match none. Only the latter offers “Show all products”; clearing filters must not undo receipts. Metric identifiers use fixed meaning-based values rather than translated labels, so changing language does not change their identity.

The import, feedback and row remain separate components. This step replaces the dashboard and row and adds the metric component; the startup, domain checks and tests from earlier steps are unchanged.

## Run and test the workbench

```sh
cargo test --lib
fission doctor --project-dir .
fission run --target web --project-dir .
```

The tests exercise catalogue atomicity, duplicate identifiers, search and stock filters, valid receipts and rejected updates. They do not prove the layout or browser interactions. Check those in the running app, including a rejected import followed by a corrected one.

To turn this workbench into a shared inventory service, persist receipts through an asynchronous repository operation. The server must authenticate the receiver, authorise the warehouse and validate each transaction against current stock. Keep the request pending until that service accepts or rejects it; do not present this local increment as durable success. An SSR shell alone does not supply that repository or its concurrency rules.

At Northbank Food Hub, Ada is inspecting **compressor bank A7** before the evening delivery window. The access panel is cracked near its lower hinge. The next technician needs a clear photo and a short note explaining why the compressor must remain isolated until the guard is replaced.

We will build that work order screen rather than a button that merely says “photo captured.” A reference schematic identifies the compressor; the evidence area stays empty until the camera returns a real image. In the Android app, Fission requests camera permission and then captures through the native provider. In a browser that supports `getUserMedia`, the same preview asks the browser for access to its actual camera. When a camera or flashlight is unavailable, the report remains available and the screen explains what can still be done.

The photo is kept as a Fission data stream while the app reads it for display. **Save inspection draft** records the current draft in app state for this tutorial session. It does not upload the image or claim that a server received it; a production service would persist the report and stream separately.

## Create the Android work-order app

Create the shared Rust project, add Android, and declare the camera capability. Fission uses that declaration when generating the Android camera permission configuration. The app code below stays in the shared crate, so the same report screen can run in the browser preview and on Android.

## Build the work order and capture real photo evidence

The first time the page opens, the report contains one example work order so there is a useful task on screen. That order is tutorial data; the camera result is not. On startup, the app asks the host which camera features are available. It only shows a flashlight control when a camera reports a torch, so the browser preview does not offer a hardware action it cannot perform. **Capture site photo** requests camera permission and calls `capture_photo` only after the host returns `Granted`.

The app state keeps the current note, photo bytes, capability availability, pending operations, and saved-draft status together because they all belong to this open work order. A startup action checks camera availability without blocking the first screen. The camera returns a stream id rather than a large byte vector. A registered job reads the stream asynchronously, then the evidence component renders those actual bytes with `Image::memory`.

#[fission_reducer(CheckCameraAvailability)]
pub fn on_check_camera_availability(
    _state: &mut WorkOrderReportState,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    let on_ok = ctx.effects.bind(
        CameraAvailabilityReceived,
        reduce_with!(on_camera_availability_received),
    );
    let on_err = ctx.effects.bind(
        CameraAvailabilityFailed,
        reduce_with!(on_camera_availability_failed),
    );
    ctx.effects.camera().availability().on_ok(on_ok).on_err(on_err);

#[fission_reducer(CameraAvailabilityReceived)]
pub fn on_camera_availability_received(
    state: &mut WorkOrderReportState,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    state.camera_availability_checked = true;
    state.flashlight_available = ctx
        .input
        .capability_ok(GET_CAMERA_AVAILABILITY)
        .map(|availability| availability.devices.iter().any(|device| device.has_flashlight))
        .unwrap_or(false);
}

#[fission_reducer(CameraAvailabilityFailed)]
pub fn on_camera_availability_failed(
    state: &mut WorkOrderReportState,
    _ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    state.camera_availability_checked = true;
    state.flashlight_available = false;
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct EvidenceBytesRequest {
    pub stream: DataStreamId,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct EvidenceBytes {
    pub bytes: Vec<u8>,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct EvidenceReadError {
    pub message: String,
}

#[derive(Debug)]
pub struct ReadEvidenceBytesJob;

impl JobSpec for ReadEvidenceBytesJob {
    type Request = EvidenceBytesRequest;
    type Ok = EvidenceBytes;
    type Err = EvidenceReadError;

    const NAME: &'static str = "northbank.work-order.read-evidence";
}

pub const READ_EVIDENCE_BYTES_JOB: JobRef<ReadEvidenceBytesJob> =
    JobRef::new(ReadEvidenceBytesJob::NAME);

pub async fn read_evidence_bytes(
    request: EvidenceBytesRequest,
    ctx: JobCtx,
) -> Result<EvidenceBytes, EvidenceReadError> {
    let stream = ctx.open_data_stream(request.stream).map_err(|error| EvidenceReadError {
        message: error.to_string(),
    })?;
    let bytes = collect_data_stream(stream).await.map_err(|error| EvidenceReadError {
        message: error.to_string(),
    })?;
    Ok(EvidenceBytes { bytes: bytes.to_vec() })
}

#[fission_reducer(InspectionNoteChanged)]
pub fn on_inspection_note_changed(
    state: &mut WorkOrderReportState,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    if let Some(change) = ctx.input.text_change() {
        state.inspection_note = change.new_text.clone();
        state.draft_saved = false;
        state.notice = None;
        state.error = None;
    }
}

#[fission_reducer(SaveInspectionDraft)]
pub fn on_save_inspection_draft(state: &mut WorkOrderReportState) {
    if state.work_order.is_none() {
        state.error = Some("Open a work order before saving an inspection note.".into());
        state.notice = None;
        return;
    }
    if state.inspection_note.trim().is_empty() {
        state.error = Some("Add a note about the access panel before saving this draft.".into());
        state.notice = None;
        return;
    }
    state.draft_saved = true;
    state.error = None;
    state.notice = Some("Draft saved in this app session. It still needs current photo evidence before supervisor review.".into());
}

#[fission_reducer(CaptureEvidencePhoto)]
pub fn on_capture_evidence_photo(
    state: &mut WorkOrderReportState,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    if state.photo_pending || state.flashlight_pending {
        return;
    }
    if state.work_order.is_none() {
        state.error = Some("Open a work order before attaching evidence.".into());
        state.notice = None;
        return;
    }
    state.photo_pending = true;
    state.error = None;
    state.notice = Some("Checking camera access…".into());
    let on_ok = ctx.effects.bind(CameraPermissionReceived, reduce_with!(on_camera_permission_received));
    let on_err = ctx.effects.bind(CameraPermissionFailed, reduce_with!(on_camera_permission_failed));
    ctx.effects
        .camera()
        .request_permission(CameraPermissionRequest {
            reason: Some("Photograph the damaged compressor access panel for work order WO-1048".into()),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

fn queue_photo_capture(
    state: &mut WorkOrderReportState,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    state.notice = Some("Opening the camera…".into());
    let on_ok = ctx.effects.bind(PhotoCaptureCompleted, reduce_with!(on_photo_capture_completed));
    let on_err = ctx.effects.bind(PhotoCaptureFailed, reduce_with!(on_photo_capture_failed));
    ctx.effects
        .camera()
        .capture_photo(CameraCaptureRequest {
            camera_id: None,
            facing: CameraFacing::Back,
            resolution: Some(CameraResolution { width: 1600, height: 1200 }),
            format: CameraImageFormat::Jpeg,
            flash: CameraFlashMode::Auto,
            quality: Some(86),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(CameraPermissionReceived)]
pub fn on_camera_permission_received(
    state: &mut WorkOrderReportState,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    let Some(permission) = ctx.input.capability_ok(REQUEST_CAMERA_PERMISSION) else {
        state.photo_pending = false;
        state.notice = None;
        state.error = Some("The camera did not return a permission result. The work order is still available without a photo.".into());
        return;
    };
    match permission {
        CameraPermission::Granted => queue_photo_capture(state, ctx),
        CameraPermission::Denied | CameraPermission::Restricted => {
            state.photo_pending = false;
            state.notice = None;
            state.error = Some("Camera access was not granted. Keep the inspection note and enable camera access in settings when a photo is required.".into());
        }
        CameraPermission::Unknown => {
            state.photo_pending = false;
            state.notice = None;
            state.error = Some("Camera permission is still unknown. Try the request again or save the note as a draft.".into());
        }
    }
}

#[fission_reducer(CameraPermissionFailed)]
pub fn on_camera_permission_failed(
    state: &mut WorkOrderReportState,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    state.photo_pending = false;
    state.notice = None;
    let Some(error) = ctx.input.capability_error(REQUEST_CAMERA_PERMISSION) else {
        state.error = Some("The camera permission request failed. The work order remains unchanged.".into());
        return;
    };
    state.error = Some(match error.code.as_str() {
        "permission_denied" | "notallowederror" => "Camera access was denied. Allow camera access in the browser or system settings, then try again; you can also save the inspection note without a photo.".into(),
        "unsupported" | "unavailable" | "notfounderror" => "No usable camera is available on this host. The note and work order remain available without a photo.".into(),
        "notreadableerror" => "The camera is already in use by another app. Close that app before trying again, or save the inspection note without a photo.".into(),
        _ => format!("The camera request failed: {}. No photo was attached; try again or save the inspection note as a draft.", error.message),
    });
}

#[fission_reducer(PhotoCaptureCompleted)]
pub fn on_photo_capture_completed(
    state: &mut WorkOrderReportState,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    state.photo_pending = false;
    let Some(capture) = ctx.input.capability_ok(CAPTURE_PHOTO) else {
        state.notice = None;
        state.error = Some("The camera returned no image. The inspection note is unchanged.".into());
        return;
    };
    state.photo_details = Some(format!(
        "{} × {} · {} · {} KiB",
        capture.width,
        capture.height,
        capture.content_type,
        capture.byte_len.unwrap_or_default() / 1024,
    ));
    state.photo_bytes = None;
    state.error = None;
    state.notice = Some("Photo captured. Preparing the evidence preview…".into());
    let on_ok = ctx.effects.bind(PhotoBytesLoaded, reduce_with!(on_photo_bytes_loaded));
    let on_err = ctx.effects.bind(PhotoBytesFailed, reduce_with!(on_photo_bytes_failed));
    ctx.effects
        .app(READ_EVIDENCE_BYTES_JOB, EvidenceBytesRequest { stream: capture.stream })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(PhotoCaptureFailed)]
pub fn on_photo_capture_failed(
    state: &mut WorkOrderReportState,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    state.photo_pending = false;
    state.notice = None;
    let Some(error) = ctx.input.capability_error(CAPTURE_PHOTO) else {
        state.error = Some("The camera did not return an image. No evidence was attached.".into());
        return;
    };
    state.error = Some(match error.code.as_str() {
        "permission_denied" | "notallowederror" => "Camera access was denied. No image was attached; allow camera access or save the inspection without a photo.".into(),
        "cancelled" | "canceled" | "user_cancel" => "Photo capture was cancelled. No image was attached, and the inspection note is unchanged.".into(),
        "unsupported" | "unavailable" | "notfounderror" => "This host has no usable camera. The work order remains available without evidence.".into(),
        "notreadableerror" => "The camera is already in use by another app. Close it before trying again; no image was attached.".into(),
        _ => format!("The photo could not be captured: {}. No image was attached; try again or save the current inspection as a draft.", error.message),
    });
}

#[fission_reducer(PhotoBytesLoaded)]
pub fn on_photo_bytes_loaded(
    state: &mut WorkOrderReportState,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    if let Some(evidence) = ctx.input.job_ok(READ_EVIDENCE_BYTES_JOB) {
        state.photo_bytes = Some(evidence.bytes.clone());
        state.error = None;
        state.notice = Some("Current photo attached to this work order. It has not been uploaded.".into());
    }
}

#[fission_reducer(PhotoBytesFailed)]
pub fn on_photo_bytes_failed(
    state: &mut WorkOrderReportState,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    let message = ctx.input.job_err(READ_EVIDENCE_BYTES_JOB)
        .map(|error| error.message.clone())
        .or_else(|| ctx.input.job_error_message(READ_EVIDENCE_BYTES_JOB).map(str::to_string))
        .unwrap_or_else(|| "The captured image stream could not be read.".into());
    state.error = Some(format!("The camera returned a photo, but its preview could not be prepared: {message}"));
    state.notice = None;
}

#[fission_reducer(SetFlashlight)]
pub fn on_set_flashlight(
    state: &mut WorkOrderReportState,
    enabled: bool,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    if state.photo_pending || state.flashlight_pending {
        return;
    }
    state.flashlight_pending = true;
    state.error = None;
    state.notice = Some(if enabled { "Checking camera access for the flashlight…".into() } else { "Turning the flashlight off…".into() });
    let on_ok = ctx.effects.bind(FlashlightPermissionReceived(enabled), reduce_with!(on_flashlight_permission_received));
    let on_err = ctx.effects.bind(FlashlightPermissionFailed(enabled), reduce_with!(on_flashlight_permission_failed));
    ctx.effects
        .camera()
        .request_permission(CameraPermissionRequest {
            reason: Some("Use the camera flashlight while photographing the compressor access panel".into()),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(FlashlightPermissionReceived)]
pub fn on_flashlight_permission_received(
    state: &mut WorkOrderReportState,
    enabled: bool,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    let Some(permission) = ctx.input.capability_ok(REQUEST_CAMERA_PERMISSION) else {
        state.flashlight_pending = false;
        state.notice = None;
        state.error = Some("The camera did not return a permission result. The flashlight state is unchanged.".into());
        return;
    };
    match permission {
        CameraPermission::Granted => queue_flashlight_change(state, enabled, ctx),
        CameraPermission::Denied | CameraPermission::Restricted | CameraPermission::Unknown => {
            state.flashlight_pending = false;
            state.notice = None;
            state.error = Some("Camera access is required before this host can use a flashlight. The inspection note is unchanged.".into());
        }
    }
}

fn queue_flashlight_change(
    state: &mut WorkOrderReportState,
    enabled: bool,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    let on_ok = ctx.effects.bind(FlashlightChanged(enabled), reduce_with!(on_flashlight_changed));
    let on_err = ctx.effects.bind(FlashlightFailed(enabled), reduce_with!(on_flashlight_failed));
    ctx.effects
        .camera()
        .set_flashlight(CameraFlashlightRequest {
            camera_id: None,
            enabled,
            intensity: Some(if enabled { 75 } else { 0 }),
        })
        .on_ok(on_ok)
        .on_err(on_err);
    state.notice = Some(if enabled { "Turning the flashlight on…".into() } else { "Turning the flashlight off…".into() });
}

#[fission_reducer(FlashlightPermissionFailed)]
pub fn on_flashlight_permission_failed(
    state: &mut WorkOrderReportState,
    enabled: bool,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    state.flashlight_pending = false;
    state.notice = None;
    let requested_state = if enabled { "on" } else { "off" };
    let Some(error) = ctx.input.capability_error(REQUEST_CAMERA_PERMISSION) else {
        state.error = Some(format!(
            "The camera did not confirm access, so the flashlight could not be turned {requested_state}. Its previous state is unchanged."
        ));
        return;
    };
    state.error = Some(match error.code.as_str() {
        "permission_denied" | "notallowederror" => format!(
            "Camera access was denied, so the flashlight could not be turned {requested_state}. Its previous state is unchanged. Enable camera access and try again."
        ),
        "unsupported" | "unavailable" | "notfounderror" => format!(
            "This host has no camera available for the flashlight request. Its previous state is unchanged; continue the inspection without it."
        ),
        "notreadableerror" => format!(
            "Another app is using the camera, so the flashlight could not be turned {requested_state}. Close the other app and try again."
        ),
        _ => format!(
            "The flashlight request failed: {}. Its previous state is unchanged; continue the inspection or try again.",
            error.message
        ),
    });
}

#[fission_reducer(FlashlightChanged)]
pub fn on_flashlight_changed(
    state: &mut WorkOrderReportState,
    enabled: bool,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    state.flashlight_pending = false;
    if ctx.input.capability_ok(SET_CAMERA_FLASHLIGHT).is_some() {
        state.flashlight_on = enabled;
        state.error = None;
        state.notice = Some(if enabled { "Flashlight is on.".into() } else { "Flashlight is off.".into() });
    } else {
        state.notice = None;
        state.error = Some("The host did not confirm the flashlight change. Its previous state is unchanged.".into());
    }
}

#[fission_reducer(FlashlightFailed)]
pub fn on_flashlight_failed(
    state: &mut WorkOrderReportState,
    _enabled: bool,
    ctx: &mut ReducerContext<WorkOrderReportState>,
) {
    state.flashlight_pending = false;
    state.notice = None;
    let Some(error) = ctx.input.capability_error(SET_CAMERA_FLASHLIGHT) else {
        state.error = Some("The host did not confirm a flashlight change. The report is unchanged.".into());
        return;
    };
    state.error = Some(match error.code.as_str() {
        "unsupported" | "unavailable" | "notfounderror" => "This camera does not expose a flashlight. Continue the inspection without it.".into(),
        "permission_denied" | "notallowederror" => "Camera access was denied, so the flashlight could not be used. The work order is unchanged.".into(),
        _ => format!("The flashlight could not be changed: {}. Its previous state is unchanged; continue without it or try again.", error.message),
    });
}

## Test permission, capture, and flashlight on Android

A browser preview checks the shared Fission reducers against the browser camera provider. It cannot prove that Android has a camera, that the OS permission is configured correctly, or that a physical flashlight is available. Test the installed app on an Android emulator for layout and permission behavior, then use a physical device for the actual camera and torch.

On the emulator or phone, open **WO-1048**, wait for the availability check, capture the damaged panel, and make sure the photo appears before saving the draft. Deny camera access and repeat: the report note should remain, no photo should be counted, and the screen should explain how to recover. Cancel a capture if the system UI offers cancellation. On hardware without a torch, confirm no flashlight action is shown while photo evidence remains available.

The example stores its note and current photo bytes in app state for the duration of this tutorial session. A production work-order system should persist the note and stream, associate them with the authenticated technician, and submit them to an authorized service. Keep that network request in an asynchronous effect or job; do not mark the work order submitted just because a local camera capture succeeded.

For the exact request and error types, continue to the [camera capability reference](/reference/capabilities/camera/). The [camera guide](/docs/capabilities/camera/) covers target setup, and the [state and effects guide](/docs/guides/state-handles-and-providers/) explains how permission and capture results return to reducers.

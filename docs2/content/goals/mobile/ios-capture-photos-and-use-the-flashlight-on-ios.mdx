At Cedar Bay Nurseries, Morgan is checking in Riverbend Nursery’s olive sapling shipment, purchase order **RB-5684**. Two trays arrived with crushed crate corners. Before the plants are moved into the greenhouse, the receiving record needs a clear photograph and a note that tells the supplier what to inspect.

The screen will show the order, the affected quantity, the note, and the evidence status together. **Capture arrival photo** asks the active host for its camera. A successful response becomes a real image in the record; a denial or missing camera leaves the note in place. The flashlight control appears only when a camera reports that it has one.

**Prepare supplier review** checks that a photo and note are present, then marks the record ready in app state. It does not send a claim. That distinction gives this example a useful end-to-end receiving flow while keeping server work outside the browser preview.

## Create an iOS project and declare camera access

Create a Rust app, add the iOS target, then declare the camera capability. Fission uses that declaration to add `NSCameraUsageDescription` to the generated `Info.plist`; replace the generated sentence with the reason a receiving clerk will understand.

The shipment, note, hold status, and photo belong to the receiving record, so shared `GlobalState` owns them. Camera permission and capture are different: they are host operations that can take time or fail, so reducers request them after a button press and leave the screen responsive while Fission waits for the result.

## Build the receiving screen and attach real evidence

`DeliveryReceipt` describes the order that arrived. `ReceivingInspectionState` also keeps the local work in progress: the note, the actual photo bytes, whether a request is pending, and whether the record is ready for review. These fields stay together because they describe one active receipt.

The camera returns a Fission data-stream id rather than a large image vector. The app hands that stream to a registered job, which reads it asynchronously; `Image::memory` then displays the returned bytes. This keeps image preparation away from the UI thread, and the empty evidence card remains honest until that process succeeds.

The component file is split by what the clerk sees. The order card identifies the shipment, the crate diagram marks the reported damage, the evidence card owns camera actions, and the decision card owns the note and receiving transitions. Every control dispatches an action; reusable widgets do not hold unrelated screen state in a helper function.

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct DeliveryPhotoRequest {
    pub stream: DataStreamId,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct DeliveryPhoto {
    pub bytes: Vec<u8>,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct DeliveryPhotoReadError {
    pub message: String,
}

#[derive(Debug)]
pub struct ReadDeliveryPhotoJob;

impl JobSpec for ReadDeliveryPhotoJob {
    type Request = DeliveryPhotoRequest;
    type Ok = DeliveryPhoto;
    type Err = DeliveryPhotoReadError;

    const NAME: &'static str = "cedar-bay.receiving.read-delivery-photo";
}

pub const READ_DELIVERY_PHOTO_JOB: JobRef<ReadDeliveryPhotoJob> =
    JobRef::new(ReadDeliveryPhotoJob::NAME);

pub async fn read_delivery_photo(
    request: DeliveryPhotoRequest,
    ctx: JobCtx,
) -> Result<DeliveryPhoto, DeliveryPhotoReadError> {
    let stream = ctx
        .open_data_stream(request.stream)
        .map_err(|error| DeliveryPhotoReadError {
            message: error.to_string(),
        })?;
    let bytes = collect_data_stream(stream)
        .await
        .map_err(|error| DeliveryPhotoReadError {
            message: error.to_string(),
        })?;
    Ok(DeliveryPhoto {
        bytes: bytes.to_vec(),
    })
}

#[fission_reducer(SaveReceivingDraft)]
pub fn on_save_receiving_draft(state: &mut ReceivingInspectionState) {
    if state.receipt.is_none() {
        state.error = Some("Open a receiving record before saving a draft.".into());
        state.notice = None;
        return;

    if state.receiving_note.trim().is_empty() {
        state.error = Some("Add what you observed before saving this receiving draft.".into());
        state.notice = None;
        return;

    state.draft_saved = true;
    state.error = None;
    state.notice = Some(
        "Receiving draft saved on this device for this session. No supplier request was sent."
            .into(),
    );
}

    state.draft_saved = false;
    state.review_ready = false;
    state.error = None;
    state.notice = Some(if held {

#[fission_reducer(PrepareSupplierReview)]
pub fn on_prepare_supplier_review(state: &mut ReceivingInspectionState) {
    if state.receipt.is_none() {
        state.error = Some("Open a receiving record before preparing a supplier review.".into());
        state.notice = None;
        return;
    }
    if state.photo_bytes.is_none() {
        state.error = Some("Attach a current photo of the crushed crate corner before preparing a supplier review.".into());
        state.notice = None;
        return;
    }
    if state.receiving_note.trim().is_empty() {
        state.error =
            Some("Add a note explaining the damage before preparing a supplier review.".into());
        state.notice = None;
        return;
    }
    state.review_ready = true;
    state.draft_saved = true;
    state.error = None;
    state.notice = Some("The receiving record is ready for a supplier review. No claim was sent from this app session.".into());
}

#[fission_reducer(CaptureDeliveryPhoto)]
pub fn on_capture_delivery_photo(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    if state.photo_pending || state.flashlight_pending {
        return;
    }
    if state.receipt.is_none() {
        state.error = Some("Open a receiving record before attaching photo evidence.".into());
        state.notice = None;
        return;
    }
    state.photo_pending = true;
    state.error = None;
    state.notice = Some("Checking camera access…".into());
    let on_ok = ctx.effects.bind(
        CameraPermissionReceived,
        reduce_with!(on_camera_permission_received),
    );
    let on_err = ctx.effects.bind(
        CameraPermissionFailed,
        reduce_with!(on_camera_permission_failed),
    );
    ctx.effects
        .camera()
        .request_permission(CameraPermissionRequest {
            reason: Some(
                "Photograph the damaged Riverbend Nursery crates for receiving record RCV-275"
                    .into(),
            ),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

fn queue_photo_capture(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    state.notice = Some("Opening the camera…".into());
    let on_ok = ctx.effects.bind(
        PhotoCaptureCompleted,
        reduce_with!(on_photo_capture_completed),
    );
    let on_err = ctx
        .effects
        .bind(PhotoCaptureFailed, reduce_with!(on_photo_capture_failed));
    ctx.effects
        .camera()
        .capture_photo(CameraCaptureRequest {
            camera_id: None,
            facing: CameraFacing::Back,
            resolution: Some(CameraResolution {
                width: 1600,
                height: 1200,
            }),
            format: CameraImageFormat::Jpeg,
            flash: CameraFlashMode::Auto,
            quality: Some(88),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(CameraPermissionReceived)]
pub fn on_camera_permission_received(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    let Some(permission) = ctx.input.capability_ok(REQUEST_CAMERA_PERMISSION) else {
        state.photo_pending = false;
        state.notice = None;
        state.error = Some("The camera did not return a permission result. The receiving record is still available without a photo.".into());
        return;
    };
    match permission {
        CameraPermission::Granted => queue_photo_capture(state, ctx),
        CameraPermission::Denied | CameraPermission::Restricted => {
            state.photo_pending = false;
            state.notice = None;
            state.error = Some("Camera access was not granted. Keep the receiving note and allow camera access in Settings when a photo is required.".into());
        }
        CameraPermission::Unknown => {
            state.photo_pending = false;
            state.notice = None;
            state.error = Some("Camera permission is still unknown. Try the request again or save the receiving note as a draft.".into());
        }
    }
}

#[fission_reducer(CameraPermissionFailed)]
pub fn on_camera_permission_failed(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    state.photo_pending = false;
    state.notice = None;
    let Some(error) = ctx.input.capability_error(REQUEST_CAMERA_PERMISSION) else {
        state.error = Some(
            "The camera permission request failed. The receiving record remains available.".into(),
        );
        return;
    };
    state.error = Some(match error.code.as_str() {
        "permission_denied" | "notallowederror" => "Camera access was denied. No photo was attached; allow access or continue with the receiving note.".into(),
        "unsupported" | "unavailable" | "notfounderror" => "No usable camera is available on this host. The receiving note remains available without a photo.".into(),
        "notreadableerror" => "Another app is using the camera. Close it before trying again, or continue with the receiving note.".into(),
        _ => format!("The camera request failed: {}. No photo was attached; try again or save the receiving draft.", error.message),
    });
}

#[fission_reducer(PhotoCaptureCompleted)]
pub fn on_photo_capture_completed(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    state.photo_pending = false;
    let Some(capture) = ctx.input.capability_ok(CAPTURE_PHOTO) else {
        state.notice = None;
        state.error = Some("The camera returned no image. The receiving note is unchanged.".into());
        return;
    };
    state.photo_details = Some(format!(
        "{} × {} · {} · {} KiB",
        capture.width,
        capture.height,
        capture.content_type,
        capture.byte_len.unwrap_or_default() / 1024,
    ));
    state.photo_bytes = None;
    state.draft_saved = false;
    state.review_ready = false;
    state.error = None;
    state.notice = Some("Photo captured. Preparing the receiving evidence preview…".into());
    let on_ok = ctx
        .effects
        .bind(PhotoBytesLoaded, reduce_with!(on_photo_bytes_loaded));
    let on_err = ctx
        .effects
        .bind(PhotoBytesFailed, reduce_with!(on_photo_bytes_failed));
    ctx.effects
        .app(
            READ_DELIVERY_PHOTO_JOB,
            DeliveryPhotoRequest {
                stream: capture.stream,
            },
        )
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(PhotoCaptureFailed)]
pub fn on_photo_capture_failed(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    state.photo_pending = false;
    state.notice = None;
    let Some(error) = ctx.input.capability_error(CAPTURE_PHOTO) else {
        state.error = Some("The camera did not return an image. No evidence was attached.".into());
        return;
    };
    state.error = Some(match error.code.as_str() {
        "permission_denied" | "notallowederror" => "Camera access was denied. No image was attached; allow access or continue with the written receiving note.".into(),
        "cancelled" | "canceled" | "user_cancel" => "Photo capture was cancelled. No image was attached, and the receiving note is unchanged.".into(),
        "unsupported" | "unavailable" | "notfounderror" => "This host has no usable camera. The receiving record remains available without evidence.".into(),
        "notreadableerror" => "The camera is already in use by another app. Close it before trying again; no image was attached.".into(),
        _ => format!("The photo could not be captured: {}. No image was attached; try again or save the receiving draft.", error.message),
    });
}

#[fission_reducer(PhotoBytesLoaded)]
pub fn on_photo_bytes_loaded(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    if let Some(photo) = ctx.input.job_ok(READ_DELIVERY_PHOTO_JOB) {
        state.photo_bytes = Some(photo.bytes.clone());
        state.draft_saved = false;
        state.review_ready = false;
        state.error = None;
        state.notice =
            Some("Photo attached to this receiving record. It has not been uploaded.".into());
    }
}

#[fission_reducer(PhotoBytesFailed)]
pub fn on_photo_bytes_failed(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    let message = ctx
        .input
        .job_err(READ_DELIVERY_PHOTO_JOB)
        .map(|error| error.message.clone())
        .or_else(|| {
            ctx.input
                .job_error_message(READ_DELIVERY_PHOTO_JOB)
                .map(str::to_string)
        })
        .unwrap_or_else(|| "The captured image stream could not be read.".into());
    state.error = Some(format!(
        "The camera returned a photo, but its preview could not be prepared: {message}"
    ));
    state.notice = None;
}

#[fission_reducer(SetFlashlight)]

            reason: Some(

            ),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(FlashlightPermissionReceived)]
pub fn on_flashlight_permission_received(
    state: &mut ReceivingInspectionState,
    enabled: bool,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    let Some(permission) = ctx.input.capability_ok(REQUEST_CAMERA_PERMISSION) else {
        state.flashlight_pending = false;
        state.notice = None;
        state.error = Some(
            "The camera did not return a permission result. The flashlight state is unchanged."
                .into(),
        );
        return;
    };
    match permission {
        CameraPermission::Granted => queue_flashlight_change(state, enabled, ctx),
        CameraPermission::Denied | CameraPermission::Restricted | CameraPermission::Unknown => {
            state.flashlight_pending = false;
            state.notice = None;
            state.error = Some("Camera access is required before this host can use a flashlight. The receiving record is unchanged.".into());
        }
    }
}

fn queue_flashlight_change(
    state: &mut ReceivingInspectionState,
    enabled: bool,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    let on_ok = ctx.effects.bind(
        FlashlightChanged(enabled),
        reduce_with!(on_flashlight_changed),
    );
    let on_err = ctx.effects.bind(
        FlashlightFailed(enabled),
        reduce_with!(on_flashlight_failed),
    );
    ctx.effects
        .camera()
        .set_flashlight(CameraFlashlightRequest {
            camera_id: None,
            enabled,
            intensity: None,
        })
        .on_ok(on_ok)
        .on_err(on_err);
    state.notice = Some(if enabled {
        "Turning the flashlight on…".into()
    } else {
        "Turning the flashlight off…".into()
    });
}

#[fission_reducer(FlashlightPermissionFailed)]
pub fn on_flashlight_permission_failed(
    state: &mut ReceivingInspectionState,
    enabled: bool,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    state.flashlight_pending = false;

        state.error =

        return;

    state.error = Some(format!("Camera access could not be confirmed, so the flashlight could not be turned {requested_state}. The receiving record is unchanged: {}", error.message));

#[fission_reducer(FlashlightChanged)]
pub fn on_flashlight_changed(
    state: &mut ReceivingInspectionState,

        state.notice = None;
    }
}

## Test the permission and receiving decisions on iOS

The browser preview exercises the same Rust reducers through Fission’s web camera provider. It can request your browser’s real camera, but it cannot prove that the generated iOS privacy text is correct or that an iPhone’s flashlight works. Run the target app on an iOS Simulator to check layout and permission handling, then test the camera and torch on a physical iPhone.

Start by opening **RCV-275** and capturing the damaged corner. Confirm that the picture shown is the image returned by the camera. Edit the note and save it; the app should say that the draft is saved in this session without claiming that a supplier service received anything. Mark the two affected trays on hold, then prepare a supplier review. The review action should remain unavailable until both a photo and a non-empty note are present.

Next deny camera access in the system prompt or in iOS Settings and try again. No photo should be counted, the previous note should remain, and the app should explain how the clerk can continue. If the iPhone reports no flashlight, the flashlight control should stay out of the interface while photo capture still works.

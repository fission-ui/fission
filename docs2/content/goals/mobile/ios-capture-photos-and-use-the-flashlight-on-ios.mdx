A supplier review needs the photograph which was actually taken, not a diagram which looks like evidence. It also needs to remain associated with the delivery it describes. If the clerk changes the reference whilst the camera is working, the returned image must not silently attach itself to a different shipment.

We will create a receiving draft from user input, capture a real photograph and prepare an in-memory review snapshot. For example, enter Riverbend Nursery's delivery reference and describe the crushed crates you are inspecting. The normal iOS app and browser preview start empty and support the same workflow; neither depends on a preview-only receipt.

## Create the app and declare camera access

Complete [iOS setup](/blog/set-up-rust-ios-development-with-fission/) first.

```sh
cargo install cargo-fission
fission init ios-capture-photos-and-use-the-flashlight-on-ios
cd ios-capture-photos-and-use-the-flashlight-on-ios
fission add-target ios --project-dir .
fission add-capability camera --project-dir .
cargo add serde --features derive
cargo add serde_yaml
```

Inspect `platforms/ios/Info.plist` and replace the generic `NSCameraUsageDescription` with an accurate purpose. Declaring the capability does not make that explanation product-specific. Keep Fission's generated `src/main.rs`; the shared library below supplies its actual app.

## Capture and consume the real image

The permission response, camera features, capture result and image bytes are different stages. Every completion is a bound unit action which decodes actual input. The job consumes the one-shot stream asynchronously and applies explicit byte, dimension and MIME limits. A failed replacement leaves the previous photograph intact.

The delivery reference is captured when the request starts. Preparing a review requires that the current reference matches the photograph's reference. The review is a snapshot of the actual note and image, so editing the draft later does not rewrite a review already prepared.

use fission::core::{CameraCapture, JobCtx, JobRef, JobSpec};
use serde::{Deserialize, Serialize};

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct PhotoRequest {
    pub reference: String,
    pub capture: CameraCapture,
}
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct ArrivalPhoto {
    pub reference: String,
    pub bytes: Vec<u8>,
    pub content_type: String,
}
pub struct CollectPhoto;
impl JobSpec for CollectPhoto {
    type Request = PhotoRequest;
    type Ok = ArrivalPhoto;
    type Err = String;
    const NAME: &'static str = "receiving.collect-photo";
}
pub const COLLECT_PHOTO: JobRef<CollectPhoto> = JobRef::new(CollectPhoto::NAME);

pub async fn collect_photo(request: PhotoRequest, cx: JobCtx) -> Result<ArrivalPhoto, String> {
    let mut stream = cx
        .open_data_stream(request.capture.stream)
        .map_err(|error| error.to_string())?;
    // Consume the one-shot handle even when its metadata fails these bounds.
    let pixels = u64::from(request.capture.width) * u64::from(request.capture.height);
    if pixels == 0 || pixels > 16_000_000 {
        return Err("Unsupported image dimensions".into());
    }
    if !matches!(
        request.capture.content_type.as_str(),
        "image/jpeg" | "image/png"
    ) {
        return Err("Only JPEG and PNG arrival photos are accepted".into());
    }
    let mut bytes = Vec::new();
    while let Some(chunk) = std::future::poll_fn(|cx| stream.as_mut().poll_next(cx)).await {
        let chunk = chunk.map_err(|error| error.to_string())?;
        let length = bytes
            .len()
            .checked_add(chunk.len())
            .ok_or("Image is too large")?;
        if length > 8 * 1024 * 1024 {
            return Err("Image exceeds the eight-MiB limit".into());
        }
        bytes.extend_from_slice(&chunk);
    }
    if bytes.is_empty() {
        return Err("The camera returned an empty image".into());
    }
    Ok(ArrivalPhoto {
        reference: request.reference,
        bytes,
        content_type: request.capture.content_type,
    })
}

use super::jobs::{ArrivalPhoto, PhotoRequest, COLLECT_PHOTO};
use fission::prelude::*;

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct ReviewSnapshot {
    pub reference: String,
    pub note: String,
    pub photo: ArrivalPhoto,
}
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct ReceivingState {
    pub locale: Locale,
    pub reference: String,
    pub note: String,
    pub busy: bool,
    pub status_key: String,
    pub error: Option<String>,
    pub device: Option<CameraDevice>,
    pub photo: Option<ArrivalPhoto>,
    pub capture_reference: Option<String>,
    pub torch_on: bool,
    pub torch_requested: Option<bool>,
    pub review: Option<ReviewSnapshot>,
}
impl Default for ReceivingState {
    fn default() -> Self {
        Self {
            locale: Locale::from("en-US"),
            reference: String::new(),
            note: String::new(),
            busy: false,
            status_key: "receiving.ready".into(),
            error: None,
            device: None,
            photo: None,
            capture_reference: None,
            torch_on: false,
            torch_requested: None,
            review: None,
        }
    }
}
impl GlobalState for ReceivingState {}

fn unexpected(state: &mut ReceivingState) {
    state.busy = false;
    state.capture_reference = None;
    state.torch_requested = None;
    state.status_key = "receiving.unexpected".into();
}

pub fn check_camera(state: &mut ReceivingState, cx: &mut ReducerContext<ReceivingState>) {
    if state.busy || state.torch_on {
        return;
    }
    state.busy = true;
    state.error = None;
    state.status_key = "receiving.permission_pending".into();
    let ok = cx
        .effects
        .bind(PermissionReturned, reduce_with!(permission_returned));
    let err = cx.effects.bind(CameraFailed, reduce_with!(camera_failed));
    cx.effects
        .camera()
        .request_permission(CameraPermissionRequest { reason: None })
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(PermissionReturned)]
fn permission_returned(state: &mut ReceivingState, cx: &mut ReducerContext<ReceivingState>) {
    match cx.input.capability_ok(REQUEST_CAMERA_PERMISSION) {
        Some(CameraPermission::Granted) => {
            state.status_key = "receiving.features_pending".into();
            let ok = cx
                .effects
                .bind(FeaturesReturned, reduce_with!(features_returned));
            let err = cx.effects.bind(CameraFailed, reduce_with!(camera_failed));
            cx.effects.camera().availability().on_ok(ok).on_err(err);
        }
        Some(CameraPermission::Denied | CameraPermission::Restricted) => {
            state.busy = false;
            state.device = None;
            state.status_key = "receiving.denied".into();
        }
        Some(CameraPermission::Unknown) => {
            state.busy = false;
            state.device = None;
            state.status_key = "receiving.unknown".into();
        }
        None => unexpected(state),
    }
}

#[fission_reducer(FeaturesReturned)]
fn features_returned(state: &mut ReceivingState, cx: &mut ReducerContext<ReceivingState>) {
    let Some(features) = cx.input.capability_ok(GET_CAMERA_AVAILABILITY) else {
        unexpected(state);
        return;
    };
    state.busy = false;
    if features.permission != CameraPermission::Granted {
        state.device = None;
        state.status_key = "receiving.denied".into();
        return;
    }
    state.device = features
        .devices
        .iter()
        .find(|device| device.facing == CameraFacing::Back)
        .or_else(|| features.devices.first())
        .cloned();
    state.status_key = if state.device.is_some() {
        "receiving.camera_ready"
    } else {
        "receiving.unavailable"
    }
    .into();
}

pub fn capture(state: &mut ReceivingState, cx: &mut ReducerContext<ReceivingState>) {
    if state.busy || state.reference.trim().is_empty() {
        return;
    }
    let Some(device) = state.device.clone() else {
        return;
    };
    state.capture_reference = Some(state.reference.trim().to_owned());
    state.busy = true;
    state.error = None;
    state.status_key = "receiving.capture_pending".into();
    let ok = cx.effects.bind(Captured, reduce_with!(captured));
    let err = cx.effects.bind(CameraFailed, reduce_with!(camera_failed));
    cx.effects
        .camera()
        .capture_photo(CameraCaptureRequest {
            camera_id: Some(device.id),
            facing: device.facing,
            resolution: Some(CameraResolution {
                width: 1600,
                height: 1200,
            }),
            format: CameraImageFormat::Jpeg,
            flash: CameraFlashMode::Off,
            quality: Some(88),
        })
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(Captured)]
fn captured(state: &mut ReceivingState, cx: &mut ReducerContext<ReceivingState>) {
    let Some(capture) = cx.input.capability_ok(CAPTURE_PHOTO) else {
        unexpected(state);
        return;
    };
    let Some(reference) = state.capture_reference.take() else {
        unexpected(state);
        return;
    };
    state.status_key = "receiving.image_pending".into();
    let ok = cx
        .effects
        .bind(PhotoCollected, reduce_with!(photo_collected));
    let err = cx.effects.bind(PhotoFailed, reduce_with!(photo_failed));
    cx.effects
        .app(COLLECT_PHOTO, PhotoRequest { reference, capture })
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(PhotoCollected)]
fn photo_collected(state: &mut ReceivingState, cx: &mut ReducerContext<ReceivingState>) {
    state.busy = false;
    match cx.input.job_ok(COLLECT_PHOTO) {
        Some(photo) => {
            state.photo = Some(photo);
            state.status_key = "receiving.attached".into();
        }
        None => unexpected(state),
    }
}

#[fission_reducer(PhotoFailed)]
fn photo_failed(state: &mut ReceivingState, cx: &mut ReducerContext<ReceivingState>) {
    state.busy = false;
    state.status_key = "receiving.failed".into();
    state.error = cx.input.job_err(COLLECT_PHOTO);
    if state.error.is_none() {
        unexpected(state);
    }
}

pub fn toggle_torch(state: &mut ReceivingState, cx: &mut ReducerContext<ReceivingState>) {
    if state.busy {
        return;
    }
    let Some(device) = state.device.as_ref().filter(|device| device.has_flashlight) else {
        return;
    };
    let request = CameraFlashlightRequest {
        camera_id: Some(device.id.clone()),
        enabled: !state.torch_on,
        intensity: None,
    };
    state.torch_requested = Some(request.enabled);
    state.busy = true;
    state.error = None;
    state.status_key = "receiving.torch_pending".into();
    let ok = cx.effects.bind(TorchChanged, reduce_with!(torch_changed));
    let err = cx.effects.bind(CameraFailed, reduce_with!(camera_failed));
    cx.effects
        .camera()
        .set_flashlight(request)
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(TorchChanged)]
fn torch_changed(state: &mut ReceivingState, cx: &mut ReducerContext<ReceivingState>) {
    state.busy = false;
    match (
        cx.input.capability_ok(SET_CAMERA_FLASHLIGHT),
        state.torch_requested.take(),
    ) {
        (Some(()), Some(enabled)) => {
            state.torch_on = enabled;
            state.status_key = "receiving.torch_changed".into();
        }
        _ => unexpected(state),
    }
}

#[fission_reducer(CameraFailed)]
fn camera_failed(state: &mut ReceivingState, cx: &mut ReducerContext<ReceivingState>) {
    state.busy = false;
    state.capture_reference = None;
    state.torch_requested = None;
    let error = cx
        .input
        .capability_error(REQUEST_CAMERA_PERMISSION)
        .or_else(|| cx.input.capability_error(GET_CAMERA_AVAILABILITY))
        .or_else(|| cx.input.capability_error(CAPTURE_PHOTO))
        .or_else(|| cx.input.capability_error(SET_CAMERA_FLASHLIGHT));
    match error {
        Some(error) => {
            state.status_key = if error.code == "unsupported" {
                "receiving.unavailable"
            } else {
                "receiving.failed"
            }
            .into();
            state.error = Some(format!("{}: {}", error.code, error.message));
        }
        None => unexpected(state),
    }
}

pub fn prepare_review(state: &mut ReceivingState) {
    if state.busy {
        return;
    }
    let Some(photo) = state.photo.as_ref() else {
        return;
    };
    let reference = state.reference.trim();
    if reference.is_empty() || state.note.trim().is_empty() || photo.reference != reference {
        return;
    }
    state.review = Some(ReviewSnapshot {
        reference: reference.to_owned(),
        note: state.note.trim().to_owned(),
        photo: photo.clone(),
    });
}

use super::state::{capture, check_camera, prepare_review, toggle_torch, ReceivingState};

fission_component! {
    pub ReceivingScreen<ReceivingState> {}
    view(_screen, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let matching_photo = state.photo.as_ref()
            .is_some_and(|photo| photo.reference == state.reference.trim());
        let can_prepare = !state.busy && !state.reference.trim().is_empty()
            && !state.note.trim().is_empty() && matching_photo;
        let image_width = (cx.view.viewport_size().width - 2.0 * tokens.spacing.l).clamp(1.0, 560.0);
    } => SafeArea(child: Scroll(child: Container(Column(gap: tokens.spacing.m, children: [
        Text(cx.tr("receiving.title")).size(tokens.typography.heading2_size),
        Text(cx.tr("receiving.explanation")),
        Row(gap: tokens.spacing.s, children: [
            Button(child: Text(cx.tr("language.english")), key: "english",
                on_press: reduce { state.locale = Locale::from("en-US"); }),
            Button(child: Text(cx.tr("language.spanish")), key: "spanish",
                on_press: reduce { state.locale = Locale::from("es-ES"); }),
        ]),
        FormControl(
            label: Some(cx.tr("receiving.reference")),
            required: true,
            child: TextInput(
                value: state.reference.clone(),
                bind(on_input): to(state.reference),
            ),
        ),
        FormControl(
            label: Some(cx.tr("receiving.note")),
            required: true,
            child: TextInput(
                value: state.note.clone(),
                bind(on_input): to(state.note),
                multiline: true,
                keyboard_type: TextInputType::Multiline,
            ),
        ),
        Button(child: Text(cx.tr("receiving.check_camera")), key: "camera-access",
            disabled: state.busy || state.torch_on,
            on_press: reduce { check_camera(state, cx); }),
        Button(child: Text(cx.tr("receiving.capture")), key: "capture",
            disabled: state.busy || state.device.is_none() || state.reference.trim().is_empty(),
            on_press: reduce { capture(state, cx); }),
        if state.device.as_ref().is_some_and(|device| device.has_flashlight) {
            Button(child: Text(cx.tr(if state.torch_on { "receiving.torch_off" } else { "receiving.torch_on" })),
                key: "torch", disabled: state.busy,
                on_press: reduce { toggle_torch(state, cx); })
        } else { Text(cx.tr("receiving.no_torch")) },
        if state.busy {
            Spinner(motion: Some(SpinnerMotion::Default), label: Some(cx.tr(&state.status_key)))
        },
        Text(cx.tr(&state.status_key)),
        if let Some(error) = &state.error { Code(text: error.clone()) },
        if let Some(photo) = &state.photo {
            Column(gap: tokens.spacing.s, children: [
                Text(cx.tr("receiving.photo_for").replace("{reference}", &photo.reference)),

            ])
        },
        Text(cx.tr("receiving.scope")).color(tokens.colors.text_secondary),
    ])).padding_all(tokens.spacing.l)))
}

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid voice note translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

pub fn sync_env(state: &crate::app::ReceivingState, env: &mut Env) {
    env.locale = state.locale.clone();
}

## Verify capture, failure and flashlight behaviour separately

The selected camera ID is used for both capture and torch requests. A flashlight button appears only when that actual camera reports a torch, and its last confirmed state changes only after `SET_CAMERA_FLASHLIGHT` succeeds. Permission, hardware support and a successful operation are still distinct checks.

Only one operation runs at a time, including stream consumption. A second capture cannot race a first collection job. This avoids needing a second generation-ID protocol in the small example. An app which allows several captures or navigation between receipts whilst work runs needs explicit operation identity and lifecycle policy.

Run on macOS:

```sh
fission doctor ios --project-dir .
fission devices --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
```

Use [a signed physical iPhone build](/blog/install-a-fission-app-on-a-physical-iphone/) for camera and torch qualification. The simulator checks neither real sensor output nor torch illumination. The browser's provider may report no flashlight even when a phone's native provider supports one.

Test denial, a restricted device, unavailable hardware, a failed capture and a failed image read. Keep the note, previous photo and prepared snapshot available. Turn the torch off after use and verify that failure does not produce a false off/on confirmation. Check background/foreground behaviour on the phone; the boolean in this example records the last confirmed request, not continuous hardware telemetry.

Preparing the snapshot does not save a receipt or send a supplier claim. A production service must authenticate and authorize the operation, persist the actual image and report submission success only after its own completion confirms it.

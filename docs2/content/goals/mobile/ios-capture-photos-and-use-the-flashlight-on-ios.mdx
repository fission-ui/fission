At Cedar Bay Nurseries, Morgan is checking in Riverbend Nursery’s olive sapling shipment, purchase order **RB-5684**. Two trays arrived with crushed crate corners. Before the plants are moved into the greenhouse, the receiving record needs a clear photograph and a note that tells the supplier what to inspect. The browser preview seeds this receipt only to make the camera flow easy to try; the iOS app starts empty and should receive its active receipt from the app’s receiving queue.

The screen will show the order, the affected quantity, the note, and the evidence status together. **Capture arrival photo** asks the active host for its camera. A successful response becomes a real image in the record; a denial or missing camera leaves the note in place. The flashlight control appears only when a camera reports that it has one.

**Prepare supplier review** checks that a photo and note are present, then marks the record ready in memory for this session. It does not save the record or send a claim. That distinction gives this example a useful receiving flow while keeping persistence and supplier submission outside the browser preview.

## Create an iOS project and declare camera access

Create a Rust app, add the iOS target, then declare the camera capability. Fission uses that declaration to add `NSCameraUsageDescription` to the generated `Info.plist`; replace the generated sentence with the reason a receiving clerk will understand.

The shipment, note, hold status, and photo belong to the receiving record, so shared `GlobalState` owns them. Camera permission and capture are different: they are host operations that can take time or fail, so reducers request them after a button press and leave the screen responsive while Fission waits for the result.

## Build the receiving screen and attach real evidence

`DeliveryReceipt` describes the order that arrived. `ReceivingInspectionState` also keeps the local work in progress: the note, the actual photo bytes, whether a request is pending, and whether the record is ready for review. These fields stay together because they describe one active receipt.

The camera returns a Fission data-stream id rather than a large image vector. The app hands that stream to a registered job, which reads it asynchronously; `Image::memory` then displays the returned bytes. This keeps image preparation away from the UI thread, and the empty evidence card remains honest until that process succeeds.

The component file is split by what the clerk sees. The order card identifies the shipment, the crate diagram marks the reported damage, the evidence card owns camera actions, and the decision card owns the note and receiving transitions. Every control dispatches an action; reusable widgets do not hold unrelated screen state in a helper function.

#[fission_reducer(CheckCameraAvailability)]
pub fn on_check_camera_availability(
    _state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    let on_ok = ctx.effects.bind(
        CameraAvailabilityReceived,
        reduce_with!(on_camera_availability_received),
    );
    let on_err = ctx.effects.bind(
        CameraAvailabilityFailed,
        reduce_with!(on_camera_availability_failed),
    );
    ctx.effects
        .camera()
        .availability()
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(CameraAvailabilityReceived)]
pub fn on_camera_availability_received(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    state.camera_availability_checked = true;
    state.camera_availability_failed = false;
    state.flashlight_available = ctx
        .input
        .capability_ok(GET_CAMERA_AVAILABILITY)
        .map(|availability| {
            availability
                .devices
                .iter()
                .any(|device| device.has_flashlight)
        })
        .unwrap_or(false);
}

#[fission_reducer(CameraAvailabilityFailed)]
pub fn on_camera_availability_failed(state: &mut ReceivingInspectionState) {
    state.camera_availability_checked = true;
    state.camera_availability_failed = true;
    state.flashlight_available = false;
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct DeliveryPhotoRequest {
    pub stream: DataStreamId,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct DeliveryPhoto {
    pub bytes: Vec<u8>,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq, Eq)]
pub struct DeliveryPhotoReadError {
    pub message: String,
}

#[derive(Debug)]
pub struct ReadDeliveryPhotoJob;

impl JobSpec for ReadDeliveryPhotoJob {
    type Request = DeliveryPhotoRequest;
    type Ok = DeliveryPhoto;
    type Err = DeliveryPhotoReadError;

    const NAME: &'static str = "cedar-bay.receiving.read-delivery-photo";
}

pub const READ_DELIVERY_PHOTO_JOB: JobRef<ReadDeliveryPhotoJob> =
    JobRef::new(ReadDeliveryPhotoJob::NAME);

pub async fn read_delivery_photo(
    request: DeliveryPhotoRequest,
    ctx: JobCtx,
) -> Result<DeliveryPhoto, DeliveryPhotoReadError> {
    let stream = ctx
        .open_data_stream(request.stream)
        .map_err(|error| DeliveryPhotoReadError {
            message: error.to_string(),
        })?;
    let bytes = collect_data_stream(stream)
        .await
        .map_err(|error| DeliveryPhotoReadError {
            message: error.to_string(),
        })?;
    Ok(DeliveryPhoto {
        bytes: bytes.to_vec(),
    })
}

#[fission_reducer(ReceivingNoteChanged)]
pub fn on_receiving_note_changed(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    if let Some(change) = ctx.input.text_change() {
        state.receiving_note = change.new_text.clone();
        state.review_ready = false;
        state.notice = None;
        state.error = None;
    }
}

#[fission_reducer(SetAffectedTraysOnHold)]
pub fn on_set_affected_trays_on_hold(state: &mut ReceivingInspectionState, held: bool) {
    state.affected_trays_on_hold = held;
    state.review_ready = false;
    state.error = None;
    state.notice = Some(if held {
        ReceivingNotice::TraysHeld
    } else {
        ReceivingNotice::TraysReleased
    });
}

#[fission_reducer(PrepareSupplierReview)]
pub fn on_prepare_supplier_review(state: &mut ReceivingInspectionState) {
    if state.receipt.is_none() {
        state.error = Some(ReceivingIssue::ReceiptMissing);
        state.notice = None;
        return;
    }
    if state.photo_bytes.is_none() {
        state.error = Some(ReceivingIssue::PhotoMissing);
        state.notice = None;
        return;
    }
    if state.receiving_note.trim().is_empty() {
        state.error = Some(ReceivingIssue::NoteMissing);
        state.notice = None;
        return;
    }
    state.review_ready = true;
    state.error = None;
    state.notice = Some(ReceivingNotice::ReviewPrepared);
}

#[fission_reducer(CaptureDeliveryPhoto)]
pub fn on_capture_delivery_photo(
    state: &mut ReceivingInspectionState,
    reason: String,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    if state.photo_pending || state.flashlight_pending {
        return;
    }
    if state.receipt.is_none() {
        state.error = Some(ReceivingIssue::ReceiptMissing);
        state.notice = None;
        return;
    }
    state.photo_pending = true;
    state.error = None;
    state.notice = Some(ReceivingNotice::CheckingCamera);
    let on_ok = ctx.effects.bind(
        CameraPermissionReceived,
        reduce_with!(on_camera_permission_received),
    );
    let on_err = ctx.effects.bind(
        CameraPermissionFailed,
        reduce_with!(on_camera_permission_failed),
    );
    ctx.effects
        .camera()
        .request_permission(CameraPermissionRequest {
            reason: Some(reason),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

fn queue_photo_capture(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    state.notice = Some(ReceivingNotice::OpeningCamera);
    let on_ok = ctx.effects.bind(
        PhotoCaptureCompleted,
        reduce_with!(on_photo_capture_completed),
    );
    let on_err = ctx
        .effects
        .bind(PhotoCaptureFailed, reduce_with!(on_photo_capture_failed));
    ctx.effects
        .camera()
        .capture_photo(CameraCaptureRequest {
            camera_id: None,
            facing: CameraFacing::Back,
            resolution: Some(CameraResolution {
                width: 1600,
                height: 1200,
            }),
            format: CameraImageFormat::Jpeg,
            flash: CameraFlashMode::Auto,
            quality: Some(88),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(CameraPermissionReceived)]
pub fn on_camera_permission_received(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    let Some(permission) = ctx.input.capability_ok(REQUEST_CAMERA_PERMISSION) else {
        state.photo_pending = false;
        state.notice = None;
        state.error = Some(ReceivingIssue::PermissionResultMissing);
        return;
    };
    match permission {
        CameraPermission::Granted => queue_photo_capture(state, ctx),
        CameraPermission::Denied | CameraPermission::Restricted => {
            state.photo_pending = false;
            state.notice = None;
            state.error = Some(ReceivingIssue::PermissionDenied);
        }
        CameraPermission::Unknown => {
            state.photo_pending = false;
            state.notice = None;
            state.error = Some(ReceivingIssue::PermissionUnknown);
        }
    }
}

#[fission_reducer(CameraPermissionFailed)]
pub fn on_camera_permission_failed(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    state.photo_pending = false;
    state.notice = None;
    let Some(error) = ctx.input.capability_error(REQUEST_CAMERA_PERMISSION) else {
        state.error = Some(ReceivingIssue::PermissionRequestFailed);
        return;
    };
    state.error = Some(match error.code.as_str() {
        "permission_denied" | "notallowederror" => ReceivingIssue::PermissionDenied,
        "unsupported" | "unavailable" | "notfounderror" => ReceivingIssue::CameraUnavailable,
        "notreadableerror" => ReceivingIssue::CameraInUse,
        _ => ReceivingIssue::PermissionRequestFailed,
    });
}

#[fission_reducer(PhotoCaptureCompleted)]
pub fn on_photo_capture_completed(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    state.photo_pending = false;
    let Some(capture) = ctx.input.capability_ok(CAPTURE_PHOTO) else {
        state.notice = None;
        state.error = Some(ReceivingIssue::CaptureResultMissing);
        return;
    };
    state.photo_details = Some(PhotoDetails {
        width: capture.width,
        height: capture.height,
        content_type: capture.content_type.clone(),
        kibibytes: capture.byte_len.map(|bytes| bytes / 1024),
    });
    state.photo_bytes = None;
    state.review_ready = false;
    state.error = None;
    state.notice = Some(ReceivingNotice::PhotoCaptured);
    let on_ok = ctx
        .effects
        .bind(PhotoBytesLoaded, reduce_with!(on_photo_bytes_loaded));
    let on_err = ctx
        .effects
        .bind(PhotoBytesFailed, reduce_with!(on_photo_bytes_failed));
    ctx.effects
        .app(
            READ_DELIVERY_PHOTO_JOB,
            DeliveryPhotoRequest {
                stream: capture.stream,
            },
        )
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(PhotoBytesLoaded)]
pub fn on_photo_bytes_loaded(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    if let Some(photo) = ctx.input.job_ok(READ_DELIVERY_PHOTO_JOB) {
        state.photo_bytes = Some(photo.bytes.clone());
        state.review_ready = false;
        state.error = None;
        state.notice = Some(ReceivingNotice::PhotoAttached);
    }
}

#[fission_reducer(PhotoBytesFailed)]
pub fn on_photo_bytes_failed(
    state: &mut ReceivingInspectionState,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    let _ = ctx.input.job_err(READ_DELIVERY_PHOTO_JOB);

    state.notice = None;
}

#[fission_reducer(SetFlashlight)]
pub fn on_set_flashlight(
    state: &mut ReceivingInspectionState,
    enabled: bool,
    reason: String,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    if state.photo_pending || state.flashlight_pending {
        return;

    state.flashlight_pending = true;
    state.error = None;

        reduce_with!(on_flashlight_permission_received),
    );
    let on_err = ctx.effects.bind(
        FlashlightPermissionFailed(enabled),
        reduce_with!(on_flashlight_permission_failed),
    );
    ctx.effects
        .camera()
        .request_permission(CameraPermissionRequest {
            reason: Some(reason),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(FlashlightPermissionReceived)]
pub fn on_flashlight_permission_received(
    state: &mut ReceivingInspectionState,
    enabled: bool,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    let Some(permission) = ctx.input.capability_ok(REQUEST_CAMERA_PERMISSION) else {
        state.flashlight_pending = false;
        state.notice = None;
        state.error = Some(ReceivingIssue::FlashlightPermissionResultMissing);
        return;
    };
    match permission {
        CameraPermission::Granted => queue_flashlight_change(state, enabled, ctx),
        CameraPermission::Denied | CameraPermission::Restricted | CameraPermission::Unknown => {
            state.flashlight_pending = false;
            state.notice = None;
            state.error = Some(ReceivingIssue::FlashlightPermissionDenied);
        }
    }
}

fn queue_flashlight_change(
    state: &mut ReceivingInspectionState,
    enabled: bool,
    ctx: &mut ReducerContext<ReceivingInspectionState>,
) {
    let on_ok = ctx.effects.bind(
        FlashlightChanged(enabled),
        reduce_with!(on_flashlight_changed),
    );
    let on_err = ctx.effects.bind(
        FlashlightFailed(enabled),
        reduce_with!(on_flashlight_failed),
    );
    ctx.effects
        .camera()
        .set_flashlight(CameraFlashlightRequest {
            camera_id: None,
            enabled,
            intensity: None,
        })
        .on_ok(on_ok)
        .on_err(on_err);
    state.notice = Some(ReceivingNotice::ChangingFlashlight(enabled));
}

## Test the permission and receiving decisions on iOS

The browser preview exercises the same Rust reducers through Fission’s web camera provider. It can request your browser’s real camera, but it cannot prove that the generated iOS privacy text is correct or that an iPhone’s flashlight works. Run the target app on an iOS Simulator to check layout and permission handling, then test the camera and torch on a physical iPhone.

On the browser preview, open the preview-only **RCV-275** receipt and capture the damaged corner. Confirm that the picture shown is the image returned by the camera. Edit the note and mark the two affected trays on hold, then prepare a supplier review. The review action should remain unavailable until both a photo and a non-empty note are present; its ready state is in-memory only and does not mean the record was saved or sent. On iOS, first pass a real receipt from the app’s receiving queue into this screen.

Next deny camera access in the system prompt or in iOS Settings and try again. No photo should be counted, the previous note should remain, and the app should explain how the clerk can continue. If the iPhone reports no flashlight, the flashlight control should stay out of the interface while photo capture still works.

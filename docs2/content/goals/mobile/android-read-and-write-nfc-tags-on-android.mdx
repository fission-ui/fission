## Current boundary: this goal is not implemented by the default Android host

Fission has typed NFC requests and results, but the current Android provider does not implement tag scanning, writing or emulation. It can inspect the adapter. Its availability response currently sets the read/write flags from the adapter's enabled state even though the corresponding operations return `unsupported`.

That is an upstream implementation gap, not something an application should work around by displaying a sample tag. This page therefore provides an integration and diagnostic outline. It does **not** fulfil a working Android read/write tutorial yet. The code keeps unsupported results visible and does not install `MemoryNfcHost` in the runnable app.

An NFC tag is also not an authentication mechanism. A successful read provides untrusted bytes; a production app must validate their format and apply its own authorisation before acting on them. Writing can replace data on a tag, so only use an owned, disposable test tag when a real provider becomes available.

## Inspect the adapter through the typed capability

Availability is a request, not a value inferred from the presence of a manifest declaration. The reducer queues it, and the completion reducer decodes `GET_NFC_AVAILABILITY` from `ctx.input`.

A missing response is a failure. A disabled adapter is different from missing hardware, and neither should be presented as a successful tag read. These are the useful working diagnostics available from the default Android host today.

use fission::prelude::*;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Pending { Check, Read, Write }

#[derive(Debug, Default)]
pub struct NfcState {
    pub availability: Option<NfcAvailability>,
    pub pending: Option<Pending>,
    pub records_read: Option<usize>,
    pub status_key: Option<&'static str>,
}
impl GlobalState for NfcState {}

pub fn check(state: &mut NfcState, ctx: &mut ReducerContext<NfcState>) {
    if state.pending.is_some() { return; }
    state.pending = Some(Pending::Check);
    state.status_key = None;
    let ok = ctx.effects.bind(NfcChecked, reduce_with!(nfc_checked));
    let err = ctx.effects.bind(NfcFailed, reduce_with!(nfc_failed));
    ctx.effects.nfc().availability().on_ok(ok).on_err(err);
}

pub fn read(state: &mut NfcState, ctx: &mut ReducerContext<NfcState>) {
    if state.pending.is_some() { return; }
    state.pending = Some(Pending::Read);
    state.status_key = None;
    let ok = ctx.effects.bind(NfcRead, reduce_with!(nfc_read));
    let err = ctx.effects.bind(NfcFailed, reduce_with!(nfc_failed));
    ctx.effects.nfc().scan_tag(NfcScanRequest {
        technologies: vec![NfcTechnology::Ndef],
        read_multiple_records: true,
        ..Default::default()
    }).on_ok(ok).on_err(err);
}

pub fn write(
    state: &mut NfcState,
    ctx: &mut ReducerContext<NfcState>,
    text: String,
) {
    if state.pending.is_some() { return; }
    if text.trim().is_empty() || text.len() > 256 {
        state.status_key = Some("nfc.invalid_text");
        return;
    }
    state.pending = Some(Pending::Write);
    state.status_key = None;
    let ok = ctx.effects.bind(NfcWritten, reduce_with!(nfc_written));
    let err = ctx.effects.bind(NfcFailed, reduce_with!(nfc_failed));
    ctx.effects.nfc().write_tag(NfcWriteRequest {
        // The author explicitly enters English text in this integration example.
        records: vec![NfcRecord::text("en", text)],
        make_read_only: false,
        ..Default::default()
    }).on_ok(ok).on_err(err);
}

#[fission_reducer(NfcChecked)]
fn nfc_checked(state: &mut NfcState, ctx: &mut ReducerContext<NfcState>) {
    if state.pending != Some(Pending::Check) { return; }
    state.pending = None;
    match ctx.input.capability_ok(GET_NFC_AVAILABILITY) {
        Some(value) => { state.availability = Some(value); state.status_key = None; }
        None => state.status_key = Some("nfc.failed"),
    }
}

#[fission_reducer(NfcRead)]
fn nfc_read(state: &mut NfcState, ctx: &mut ReducerContext<NfcState>) {
    if state.pending != Some(Pending::Read) { return; }
    state.pending = None;
    match ctx.input.capability_ok(SCAN_NFC_TAG) {
        Some(tag) => {
            state.records_read = Some(tag.records.len());
            state.status_key = Some("nfc.read_result");
        }
        None => state.status_key = Some("nfc.failed"),
    }
}

#[fission_reducer(NfcWritten)]
fn nfc_written(state: &mut NfcState, ctx: &mut ReducerContext<NfcState>) {
    if state.pending != Some(Pending::Write) { return; }
    state.pending = None;
    state.status_key = Some(match ctx.input.capability_ok(WRITE_NFC_TAG) {
        Some(receipt) if receipt.completed => "nfc.write_result",
        _ => "nfc.failed",
    });
}

#[fission_reducer(NfcFailed)]
fn nfc_failed(state: &mut NfcState, ctx: &mut ReducerContext<NfcState>) {
    let code = match state.pending.take() {
        Some(Pending::Check) => ctx.input.capability_error(GET_NFC_AVAILABILITY).map(|error| error.code),
        Some(Pending::Read) => ctx.input.capability_error(SCAN_NFC_TAG).map(|error| error.code),
        Some(Pending::Write) => ctx.input.capability_error(WRITE_NFC_TAG).map(|error| error.code),
        None => return,
    };
    state.status_key = Some(match code.as_deref() {
        Some("unsupported") => "nfc.unsupported",
        Some("cancelled") => "nfc.cancelled",
        Some("permission_denied") => "nfc.denied",
        _ => "nfc.failed",
    });
}

use fission::prelude::*;
use crate::state::{self, NfcState};

fission_component! {
    pub NfcDiagnostics<NfcState> {
        state {
            write_text: String = String::new(),
            own_tag_confirmed: bool = false,
        }
    }
    view(screen, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    SafeArea(
        child: Scroll(
            child: Container(
                child: Column(gap: tokens.spacing.m, children: [
                    Text(cx.tr("nfc.title")).size(tokens.typography.heading2_size),
                    Text(cx.tr("nfc.boundary")),
                    Button(
                        child: Text(cx.tr("nfc.check")),
                        key: "check-nfc",
                        disabled: state.pending.is_some(),
                        on_press: reduce { state::check(state, cx); },
                    ).semantics_identifier("nfc.check"),
                    if let Some(availability) = &state.availability {
                        Column(gap: tokens.spacing.s, children: [
                            Text(cx.tr(if availability.supported {
                                "nfc.hardware_present"
                            } else { "nfc.no_hardware" })),
                            Text(cx.tr(if availability.enabled {
                                "nfc.enabled"
                            } else { "nfc.disabled" })),
                            Text(cx.tr("nfc.flags_warning")),
                        ])
                    },
                    if state.pending.is_some() {
                        Spinner(
                            motion: Some(SpinnerMotion::Default),
                            label: cx.tr("nfc.pending"),
                        )
                    },
                    if let Some(key) = state.status_key { Text(cx.tr(key)) },
                    if let Some(count) = state.records_read {
                        Text(cx.tr("nfc.record_count").replace("{count}", &count.to_string()))
                    },
                ]),
            ).padding_all(tokens.spacing.l),
        ),
    )
}

            serde_yaml::from_str(source).expect("valid checked-in translations");
        env.i18n.add_bundle(TranslationBundle { locale: Locale::from(locale), messages });
    }
    env
}

## Keep read and write results explicit

The screen below exposes the public request contract so an application can verify a provider integration without changing its state model. With the current default Android provider, both requests return unsupported; no physical read or write occurs.

Read success reports only the record count. It does not render arbitrary record bytes or open a URI found on a tag. Write uses the public `NfcRecord::text` helper and leaves `make_read_only` false. The user must confirm ownership and replacement before the button becomes available.

## What remains before this becomes a completed tutorial

```sh
fission doctor android --project-dir .
adb devices -l
fission run --target android --device <adb-serial> --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```

A real Android provider must implement read/write sessions, cancellation and relevant failure paths before the title's goal can be met. Once that exists, verify an owned writable tag on a phone, then test disabled NFC, incompatible or read-only tags, user dismissal and loss of contact during writing.

After a successful write, read the tag back and compare its records before claiming the expected content is present. If a write fails halfway through, do not assume the old records survived or automatically retry: the actual tag may have changed before the error arrived.

The generated host starting or an emulator rendering the screen is not evidence for those behaviours. Keep this native-provider gap visible until the real flow is implemented and qualified.

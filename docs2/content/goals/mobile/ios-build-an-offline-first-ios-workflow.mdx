A note is not offline-safe because its editor stays visible without a connection.
The accepted edit has to reach local storage, and startup has to recover that
same record after the process stops.

This companion runs the [shared field-notes app](/blog/build-an-offline-first-notes-app-for-android-and-ios/)
on iOS. The complete final source is repeated below so this checkpoint builds
independently. Keep these fourteen files aligned with the final shared lesson
and its Android companion when changing the implementation; there is no second
storage model hidden behind an iOS-only preview.

## Prepare iOS and storage

Complete [iOS development setup](/blog/set-up-rust-ios-development-with-fission/)
on a Mac with Xcode. Then create the project:

```sh
cargo install cargo-fission
fission init field-notes
cd field-notes
fission add-target ios android web --project-dir .
fission add-capability storage --project-dir .
cargo add serde_yaml
```

The storage capability configures the provider and browser assets together.
Keep the generated main launcher and replace the shared modules with these
files. Native app titles and application IDs also affect storage identity;
do not change them as part of a restart test.

## Save and reload actual field notes

The list is the last confirmed SQLite result. The draft is separate. SQLite
assigns new record IDs, and the save reducer checks the previous revision when
updating a note. A failed or uncertain write is not permission to show Saved or
replay an insert blindly.

Startup queues migration and loading through effects. The initial component
tree registers the startup reducer, and each request binds its completion
reducers before borrowing the effect builder. An action declaration by itself
does not register a handler.

The browser checkpoint uses real Web SQLite. It requires the worker, bridge and
cross-origin-isolation headers on both the containing document and embedded app.
An unavailable provider must fail visibly, not switch to a memory substitute.
Browser persistence is still separate from the native iOS database.

```rust
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum NoteSyncStatus {
    Synced,
    WaitingToSync,
}

impl NoteSyncStatus {
    pub fn translation_key(&self) -> &'static str {
        match self {
            Self::Synced => "notes.sync.synced",
            Self::WaitingToSync => "notes.sync.waiting",
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct FieldNote {
    pub id: i64,
    pub site: String,
    pub title: String,
    pub observation: String,
    pub updated_at: String,
    pub revision: u32,
    pub sync_status: NoteSyncStatus,
}

pub fn matches_note(note: &FieldNote, query: &str) -> bool {
    query.is_empty()
        || note.site.to_lowercase().contains(query)
        || note.title.to_lowercase().contains(query)
        || note.observation.to_lowercase().contains(query)
}
#[derive(Clone, Debug, PartialEq)]
pub struct PendingFieldNote {
    pub target_id: Option<i64>,
    pub site: String,
    pub title: String,
    pub observation: String,
    pub revision: u32,
}
```

```rust
use fission::prelude::*;
use crate::models::*;
#[derive(Clone, Debug, PartialEq)]
pub struct FieldNotesState {
    pub notes: Vec<FieldNote>,
    pub selected_note_id: Option<i64>,
        pub pending_note: Option<PendingFieldNote>,
    pub site_draft: String,
    pub title_draft: String,
    pub observation_draft: String,
    pub is_editing: bool,
    pub is_new_note: bool,
    pub is_saving: bool,
    pub is_loading: bool,
    pub requires_reload: bool,
    pub notice: String,
    pub has_error: bool,
    pub validation_error: bool,
}

impl Default for FieldNotesState {
    fn default() -> Self {
        Self {
            notes: Vec::new(),
            selected_note_id: None,
            pending_note: None,
            site_draft: String::new(),
            title_draft: String::new(),
            observation_draft: String::new(),
            is_editing: false,
            is_new_note: false,
            is_saving: false,
            is_loading: true,
            requires_reload: false,
            notice: "notes.notice.ready".into(),
            has_error: false,
            validation_error: false,
        }
    }
}

impl GlobalState for FieldNotesState {}

#[fission_reducer(SelectFieldNote)]
pub fn on_select_field_note(state: &mut FieldNotesState, note_id: i64) {
    if state.is_editing || state.is_saving {
        return;
    }
    if state.notes.iter().any(|note| note.id == note_id) {
        state.selected_note_id = Some(note_id);
        state.notice.clear();
        state.has_error = false;
        state.validation_error = false;
    }
}

pub fn start_new_field_note(state: &mut FieldNotesState) {
    if state.is_editing || state.is_saving {
        return;
    }
    state.site_draft.clear();
    state.title_draft.clear();
    state.observation_draft.clear();
    state.pending_note = None;
    state.is_editing = true;
    state.is_new_note = true;
    state.notice = "notes.notice.new_prompt".into();
    state.has_error = false;
    state.validation_error = false;
}

#[fission_reducer(BeginNewFieldNote)]
pub fn on_begin_new_field_note(
    state: &mut FieldNotesState,
    _ctx: &mut ReducerContext<FieldNotesState>,
) {
    start_new_field_note(state);
}

#[fission_reducer(BeginEditFieldNote)]
pub fn on_begin_edit_field_note(state: &mut FieldNotesState, note_id: i64) {
    if state.is_editing || state.is_saving {
        return;
    }
    let Some(note) = state.notes.iter().find(|note| note.id == note_id).cloned() else {
        state.notice = "notes.notice.missing".into();
        state.has_error = true;
        state.validation_error = false;
        return;
    };
    state.selected_note_id = Some(note_id);
    state.site_draft = note.site;
    state.title_draft = note.title;
    state.observation_draft = note.observation;
    state.is_editing = true;
    state.is_new_note = false;
    state.notice = "notes.notice.editing".into();
    state.has_error = false;
    state.validation_error = false;
}

#[fission_reducer(CancelFieldNoteDraft)]
pub fn on_cancel_field_note_draft(state: &mut FieldNotesState) {
    if state.is_saving {
        return;
    }
    state.site_draft.clear();
    state.title_draft.clear();
    state.observation_draft.clear();
    state.pending_note = None;
    state.is_editing = false;
    state.is_new_note = false;
    state.notice = "notes.notice.draft_discarded".into();
    state.has_error = false;
    state.validation_error = false;
}
```

```rust
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, yaml) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(yaml).expect("valid Harbour Field Notes translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}
```

```rust
use fission::prelude::*;
use crate::{models::*, state::*};
fission_component! {
    pub FieldNoteListItem<FieldNotesState> {
        props {
        note: FieldNote,
        selected: bool,
        editing: bool,
        }
    }
    view(row, _app, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let selected_bg = if row.selected {
            tokens.colors.primary_subtle
        } else {
            tokens.colors.surface
        };
        let selected_border = if row.selected {
            tokens.colors.primary
        } else {
            tokens.colors.border
        };
        let status_color = if row.note.sync_status == NoteSyncStatus::WaitingToSync {
            tokens.colors.warning
        } else {
            tokens.colors.success
        };
        let status = cx.tr(row.note.sync_status.translation_key());
        let selected_label = if row.selected {
            cx.tr("notes.row.selected")
        } else {
            cx.tr("notes.action.open")
        };
    } =>
    SemanticsRegion(
        identifier: Some(format!("field-note.{}", row.note.id)),
        label: Some(format!("{}, {}", row.note.title.clone(), row.note.site.clone())),
        child: Container(
            Column(gap: tokens.spacing.s, children: [
                Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                    Column(gap: tokens.spacing.xs, children: [
                        Text(row.note.title.clone())
                            .weight(tokens.typography.font_weight_semibold),
                        Text(row.note.site.clone())
                            .color(tokens.colors.text_secondary),
                    ]),
                    Spacer(flex_grow: 1.0),
                    Text(status).color(status_color),
                ]),
                Text(row.note.updated_at.clone())
                    .color(tokens.colors.text_secondary),
                Button(
                    child: Text(selected_label),
                    key: format!("open-field-note-{}", row.note.id),
                    disabled: row.editing || row.selected,
                    variant: ButtonVariant::Outline,
                    on_press: with_reducer!(
                        cx.build,
                        SelectFieldNote(row.note.id),
                        on_select_field_note,
                    ),
                ).semantics_identifier(format!("field-notes.open.{}", row.note.id)),
            ]),
        )
        .padding_all(tokens.spacing.m)
        .bg(selected_bg)
        .border(selected_border, 1.0)
        .border_radius(tokens.radii.medium),
    )
}
```

```rust
use fission::prelude::*;
use crate::{models::*, state::*};

#[fission_reducer(PrepareFieldNotes)]
pub fn prepare_field_notes(
    _state: &mut FieldNotesState,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    if _state.is_saving { return; }
    _state.is_loading = true;
    _state.has_error = false;
    let mut migrations = SqlMigrations::new();
    migrations.add(SqlMigration::new(
        1,
        "create field notes",
        "CREATE TABLE field_notes (
            id INTEGER PRIMARY KEY,
            site TEXT NOT NULL CHECK (length(trim(site)) > 0),
            title TEXT NOT NULL CHECK (length(trim(title)) > 0),
            observation TEXT NOT NULL CHECK (length(trim(observation)) > 0),
            revision INTEGER NOT NULL DEFAULT 1 CHECK (revision > 0),
            sync_status TEXT NOT NULL DEFAULT 'waiting',
            updated_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
        );
        CREATE INDEX field_notes_site_updated_idx
            ON field_notes(site, updated_at DESC);",
    )).expect("migration versions are unique");

    let loaded = ctx.effects.bind(LoadFieldNotes, reduce!(load_field_notes));
    let failed = ctx.effects.bind(FieldNotesStorageFailed, reduce!(field_notes_storage_failed));
    ctx.effects.sql().migrate(migrations)
        .on_ok(loaded).on_err(failed);
}

#[fission_reducer(LoadFieldNotes)]
pub fn load_field_notes(
    _state: &mut FieldNotesState,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    let loaded = ctx.effects.bind(FieldNotesLoaded, reduce!(field_notes_loaded));
    let failed = ctx.effects.bind(FieldNotesStorageFailed, reduce!(field_notes_storage_failed));
    ctx.effects.sql().query(SqlStatement::new(
        "SELECT id, site, title, observation, revision, sync_status, updated_at
         FROM field_notes
         ORDER BY updated_at DESC, id DESC LIMIT 501",
    ))
    .on_ok(loaded).on_err(failed);
}

#[fission_reducer(FieldNotesLoaded)]
pub fn field_notes_loaded(
    state: &mut FieldNotesState,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    let Some(rows) = ctx.input.sql_rows() else {
        state.is_loading = false;
        state.has_error = true;
        state.requires_reload = true;
        state.notice = "notes.notice.sqlite_empty".into();
        return;
    };
    if rows.rows.len() > 500 {
        state.is_loading = false;
        state.has_error = true;
        state.requires_reload = true;
        state.notice = "notes.notice.limit".into();
        return;
    }
    let loaded_notes: Result<Vec<FieldNote>, String> = rows.rows.iter().map(|row| {
        let id = row.get::<i64>("id").map_err(|error| error.to_string())?;
        let site = row.get::<String>("site").map_err(|error| error.to_string())?;
        let title = row.get::<String>("title").map_err(|error| error.to_string())?;
        let observation = row.get::<String>("observation")
            .map_err(|error| error.to_string())?;
        let revision = u32::try_from(
            row.get::<i64>("revision").map_err(|error| error.to_string())?,
        )
        .map_err(|_| "revision is outside the supported range".to_string())?;
        let status = row.get::<String>("sync_status")
            .map_err(|error| error.to_string())?;
        let sync_status = match status.as_str() {
            "synced" => NoteSyncStatus::Synced,
            "waiting" => NoteSyncStatus::WaitingToSync,
            other => return Err(format!("unknown sync status `{other}`")),
        };
        let updated_at = row.get::<String>("updated_at")
            .map_err(|error| error.to_string())?;
        Ok(FieldNote {
            id,
            site,
            title,
            observation,
            updated_at,
            revision,
            sync_status,
        })
    }).collect();

    state.notes = match loaded_notes {
        Ok(notes) => notes,
        Err(_error) => {
            state.is_loading = false;
            state.has_error = true;
            state.validation_error = false;
            state.requires_reload = true;
            state.notice = "notes.notice.read_failed".into();
            return;
        }
    };
    state.is_loading = false;
    state.has_error = false;
    state.requires_reload = false;

    if let Some(note) = state.notes.first() {
        state.selected_note_id = Some(note.id);
    }
}

#[fission_reducer(FieldNotesStorageFailed)]
pub fn field_notes_storage_failed(
    state: &mut FieldNotesState,
    _ctx: &mut ReducerContext<FieldNotesState>,
) {
    state.is_loading = false;
    state.is_saving = false;
    state.requires_reload = true;
    state.has_error = true;
    state.validation_error = false;
    state.notice = "notes.notice.storage_failed".into();
}

#[fission_reducer(SaveFieldNoteToSqlite)]
pub fn save_field_note_to_sqlite(
    state: &mut FieldNotesState,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    if state.is_saving || state.is_loading || state.requires_reload || !state.is_editing { return; }
    let site = state.site_draft.trim().to_owned();
    let title = state.title_draft.trim().to_owned();
    let observation = state.observation_draft.trim().to_owned();
    if site.is_empty() || title.is_empty() || observation.is_empty()
        || site.chars().count() > 80 || title.chars().count() > 160 || observation.chars().count() > 4000 {
        state.notice = "notes.notice.required".into();
        state.has_error = true;
        state.validation_error = true;
        return;
    }

    let (target_id, revision) = if state.is_new_note {
        if state.notes.len() >= 500 {
            state.notice = "notes.notice.limit".into();
            state.has_error = true;
            return;
        }
        (None, 1)
    } else {
        let Some(current) = state.notes.iter().find(|note| Some(note.id) == state.selected_note_id) else { return; };
        let Some(revision) = current.revision.checked_add(1) else {
            state.notice = "notes.notice.newer_revision".into();
            state.has_error = true;
            return;
        };
        (Some(current.id), revision)
    };

    let statement = match target_id {
        None => SqlStatement::new(
            "INSERT INTO field_notes (site, title, observation, revision, sync_status, updated_at)
             VALUES (:site, :title, :observation, 1, 'waiting', CURRENT_TIMESTAMP)"
        ),
        Some(id) => SqlStatement::new(
            "UPDATE field_notes SET site = :site, title = :title, observation = :observation,
             revision = :revision, sync_status = 'waiting', updated_at = CURRENT_TIMESTAMP
             WHERE id = :id AND revision = :previous_revision"
        ).bind_named(":id", id)
         .bind_named(":revision", i64::from(revision))
         .bind_named(":previous_revision", i64::from(revision - 1)),
    }.bind_named(":site", site.clone())
     .bind_named(":title", title.clone())
     .bind_named(":observation", observation.clone());

    state.pending_note = Some(PendingFieldNote { target_id, site, title, observation, revision });
    state.is_saving = true;
    state.has_error = false;
    state.validation_error = false;
    state.notice = "notes.notice.saving".into();
    let stored = ctx.effects.bind(FieldNoteStored, reduce!(field_note_stored));
    let failed = ctx.effects.bind(FieldNotesStorageFailed, reduce!(field_notes_storage_failed));
    ctx.effects.sql().execute(statement).on_ok(stored).on_err(failed);
}

#[fission_reducer(FieldNoteStored)]
pub fn field_note_stored(state: &mut FieldNotesState, ctx: &mut ReducerContext<FieldNotesState>) {
    let Some(result) = ctx.input.sql_execute_result() else {
        field_notes_storage_failed(state, FieldNotesStorageFailed, ctx);
        return;
    };
    if result.affected_rows != 1 {
        state.is_saving = false;
        state.has_error = true;
        state.requires_reload = true;
        state.notice = "notes.notice.newer_revision".into();
        return;
    }
    let Some(pending) = state.pending_note.take() else { return; };
    let Some(id) = pending.target_id.or(result.last_insert_rowid) else {
        state.pending_note = Some(pending);
        field_notes_storage_failed(state, FieldNotesStorageFailed, ctx);
        return;
    };
    let note = FieldNote {
        id, site: pending.site, title: pending.title, observation: pending.observation,
        revision: pending.revision, updated_at: String::new(),
        sync_status: NoteSyncStatus::WaitingToSync,
    };
    if pending.target_id.is_none() {
        state.notes.insert(0, note);
    } else if let Some(current) = state.notes.iter_mut().find(|note| note.id == id) {
        *current = note;
    } else {
        state.requires_reload = true;
        state.has_error = true;
        state.notice = "notes.notice.saved_not_visible".into();
        state.is_saving = false;
        return;
    }
    state.selected_note_id = Some(id);
    state.site_draft.clear();
    state.title_draft.clear();
    state.observation_draft.clear();
    state.is_editing = false;
    state.is_new_note = false;
    state.is_saving = false;
    state.has_error = false;
    state.validation_error = false;
    state.notice = "notes.notice.saved_on_device".into();
    state.is_loading = true;
    load_field_notes(state, LoadFieldNotes, ctx);
}

#[fission_reducer(SyncNoteSucceeded)]
pub fn on_sync_note_succeeded(
    state: &mut FieldNotesState,
    note_id: i64,
    sent_revision: u32,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    if state.is_saving || state.is_loading || state.requires_reload {
        return;
    }
    let Some(note) = state.notes.iter().find(|note| note.id == note_id) else {
        return;
    };

    if note.revision != sent_revision {
        return;
    }

    let statement = SqlStatement::new(
        "UPDATE field_notes
         SET sync_status = 'synced'
         WHERE id = :id AND revision = :revision",
    )
    .bind_named(":id", note_id)
    .bind_named(":revision", i64::from(sent_revision));

    let stored = ctx.effects.bind(FieldNoteSyncStatusStored(note_id, sent_revision), reduce!(field_note_sync_status_stored));
    let failed = ctx.effects.bind(FieldNotesStorageFailed, reduce!(field_notes_storage_failed));
    state.is_saving = true;
    ctx.effects.sql().execute(statement).on_ok(stored).on_err(failed);
}

#[fission_reducer(FieldNoteSyncStatusStored)]
pub fn field_note_sync_status_stored(
    state: &mut FieldNotesState,
    note_id: i64,
    sent_revision: u32,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    state.is_saving = false;
    let Some(result) = ctx.input.sql_execute_result() else {
        field_notes_storage_failed(state, FieldNotesStorageFailed, ctx);
        return;
    };
    if result.affected_rows != 1 {
        state.has_error = true;
        state.validation_error = false;
        state.requires_reload = true;
        state.notice = "notes.notice.newer_revision".into();
        return;
    }
    let Some(note) = state.notes.iter_mut().find(|note| note.id == note_id) else {
        state.has_error = true;
        state.validation_error = false;
        state.requires_reload = true;
        state.notice = "notes.notice.saved_not_visible".into();
        return;
    };
    if note.revision != sent_revision {
        state.has_error = true;
        state.validation_error = false;
        state.requires_reload = true;
        state.notice = "notes.notice.newer_revision".into();
        return;
    }
    note.sync_status = NoteSyncStatus::Synced;
}
```

## Check the same source after an iOS process restart

```sh
fission doctor ios --project-dir .
fission devices --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
```

Create or edit a note and wait for **Saved on this device**. Stop the app process,
relaunch it, and confirm the same text and revision return from SQLite. Do not
uninstall it: uninstalling can remove the data and tests a different lifecycle.

Repeat without network access. On an iPhone, enable airplane mode and check the
actual connection is unavailable. Simulator uses the Mac's networking, so a
simulated status icon is not evidence of disconnection; use a controlled network
restriction for that check. Local startup and saving should not need an HTTP
service in either case.

Fission's iOS run path launches Simulator. Follow the
[physical iPhone guide](/blog/install-a-fission-app-on-a-physical-iphone/) for
development signing and installation, then repeat the same saved-note restart
check there. Record which target you exercised. A browser reload and Simulator
launch cannot establish physical-device persistence.

A note still marked **Waiting to sync** is correct. This app defines the local
record and revision boundary but does not implement a remote service. Restoring
connectivity does not mean any server has accepted the note.

```sh
cargo test --lib
fission build --target ios --project-dir . --release
```

Use a disposable app identity when deliberately checking failed migrations or
storage errors. Verify normal restart persistence in the same signed candidate
you intend to ship; changing identity or uninstalling between runs invalidates
that comparison.

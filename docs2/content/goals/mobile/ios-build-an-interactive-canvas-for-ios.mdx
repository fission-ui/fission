Moving a card and moving the view are different operations. A dragged inspection check changes the plan's document data. Panning or zooming changes how we look at that plan; it should not rewrite the checks' positions.

We will build a small inspection-planning board with checks entered by the user. It starts empty on iOS and Web, supports stable node selection and movement, and offers a labelled selection list for people who do not want to target a small canvas card. Arranging a plan does not certify that an inspection has happened.

## Create the app

Complete [iOS setup](/blog/set-up-rust-ios-development-with-fission/) first.

```sh
cargo install cargo-fission
fission init ios-build-an-interactive-canvas-for-ios
cd ios-build-an-interactive-canvas-for-ios
fission add-target ios --project-dir .
cargo add serde_yaml
```

The iOS and Web Fission features enable interactive canvas support. Keep the generated `src/main.rs` and replace the shared library below; no separate native scene is needed.

## Give every check a document identity

A node's ID is allocated when the user creates it, not when the list is rendered. Repeated titles remain distinct checks. The initial offset is only placement geometry; it is not identity and it is never recomputed after a drag.

The built-in `InfiniteCanvas` owns the pan/zoom interaction. The app owns the selected node and document bounds. A named card draws each node, whilst a small event reducer accepts selection and move updates from the actual canvas interaction payload.

use fission::prelude::*;

#[derive(Clone, Debug, PartialEq)]
pub struct PlanItem {
    pub id: u64,
    pub title: String,
    pub bounds: LayoutRect,
}
impl PlanItem {
    pub fn canvas_id(&self) -> CanvasNodeId {
        CanvasNodeId::from_u128(u128::from(self.id))
    }
}
#[derive(Clone, Debug, PartialEq)]
pub struct PlanState {
    pub items: Vec<PlanItem>,
    pub next_id: u64,
    pub selected: Option<u64>,
    pub locale: Locale,
}
impl Default for PlanState {
    fn default() -> Self {
        Self {
            items: Vec::new(),
            next_id: 1,
            selected: None,
            locale: Locale::from("en-US"),
        }
    }
}
impl GlobalState for PlanState {}

pub fn add_item(state: &mut PlanState, title: &str) -> bool {
    let title = title.trim();
    if title.is_empty() || title.chars().count() > 80 {
        return false;
    }
    let Some(next_id) = state.next_id.checked_add(1) else {
        return false;
    };
    let offset = (state.items.len() % 8) as f32 * 24.0;
    state.items.push(PlanItem {
        id: state.next_id,
        title: title.to_owned(),
        bounds: LayoutRect::new(offset, offset, 220.0, 132.0),
    });
    state.selected = Some(state.next_id);
    state.next_id = next_id;
    true
}

#[fission_reducer(EditPlan)]
pub fn edit_plan(state: &mut PlanState, cx: &mut ReducerContext<PlanState>) {
    let Some(event) = cx.input.canvas_interaction() else {
        return;
    };
    match event.kind {
        CanvasInteractionKind::SelectNode { node_id }
            if event.phase == CanvasInteractionPhase::Activate =>
        {
            state.selected = state
                .items
                .iter()
                .find(|item| item.canvas_id().0 == node_id)
                .map(|item| item.id);
        }
        CanvasInteractionKind::MoveNode { .. } if event.phase == CanvasInteractionPhase::Update => {
            for change in &event.node_changes {
                if let Some(item) = state
                    .items
                    .iter_mut()
                    .find(|item| item.canvas_id().0 == change.node_id)
                {
                    let bounds = change.after;
                    if bounds.x().is_finite() && bounds.y().is_finite() {
                        item.bounds = bounds;
                    }
                }
            }
        }
        _ => {}
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn repeated_titles_still_have_distinct_stable_ids() {
        let mut state = PlanState::default();
        assert!(add_item(&mut state, "Inspect the seal"));
        assert!(add_item(&mut state, "Inspect the seal"));
        let first = state.items[0].canvas_id();
        state.items.reverse();
        assert_eq!(state.items[1].canvas_id(), first);
        assert_ne!(state.items[0].canvas_id(), first);
        assert!(!add_item(&mut state, " "));
    }
}

use super::card::PlanCard;
use super::state::{add_item, edit_plan, EditPlan, PlanState};
use fission::prelude::*;

fission_component! {
    pub PlanScreen<PlanState> {
        state { draft: String = String::new(), attempted: bool = false }
    }
    view(form, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let edit = with_reducer!(cx.build, EditPlan, edit_plan);
        let nodes: Vec<InfiniteCanvasNode> = state.items.iter().map(|item| {
            let mut node = InfiniteCanvasNode::new(
                item.canvas_id(), item.bounds,
                PlanCard::new(item.title.clone(), state.selected == Some(item.id)),
            );
            node.resizable = false;
            node
        }).collect();
        let selected_nodes: std::collections::BTreeSet<CanvasNodeId> = state.items.iter()
            .filter(|item| state.selected == Some(item.id)).map(|item| item.canvas_id()).collect();
        let error = (form.attempted && (form.draft.trim().is_empty() || form.draft.trim().chars().count() > 80))
            .then(|| cx.tr("plan.title_error"));
    } => SafeArea(child: Scroll(child: Container(Column(gap: tokens.spacing.m, children: [
        Text(cx.tr("plan.title")).size(tokens.typography.heading2_size),
        Text(cx.tr("plan.explanation")),
        Row(gap: tokens.spacing.s, children: [
            Button(child: Text(cx.tr("language.english")), key: "english",
                on_press: reduce { state.locale = Locale::from("en-US"); }),
            Button(child: Text(cx.tr("language.spanish")), key: "spanish",
                on_press: reduce { state.locale = Locale::from("es-ES"); }),
        ]),
        FormControl(label: Some(cx.tr("plan.new_item")), error: error, required: true,
            child: TextInput(value: form.draft.clone(), bind(on_input): to(form.draft))),
        Button(child: Text(cx.tr("plan.add")), key: "add-item", disabled: state.next_id == u64::MAX,
            on_press: reduce {
                form.attempted = true;
                if add_item(state, &form.draft) {
                    form.draft.clear();
                    form.attempted = false;
                }
            }),
        if state.items.is_empty() { Text(cx.tr("plan.empty")) },
        Container(InfiniteCanvas(
            id: Some(WidgetId::explicit("inspection.plan")),
            nodes: nodes,
            selected_nodes: selected_nodes,
            selection_policy: CanvasSelectionPolicy::Single,
            initial_transform: ViewportTransform::new(24.0, 24.0, 1.0),
            min_scale: 0.4,
            max_scale: 2.5,
            grid: Some(CanvasGrid::lines(32.0, tokens.colors.border, 1.0)),
            actions: InfiniteCanvasActions {
                on_selection_change: Some(edit.clone()),
                on_node_move: Some(edit),
                ..Default::default()
            },
        )).height(360.0).bg(tokens.colors.background)
            .border(tokens.colors.border, 1.0).border_radius(tokens.radii.medium),
        Text(cx.tr("plan.list")).weight(tokens.typography.font_weight_semibold),
        for item in &state.items {
            PlanSelectionRow(item.id, key: item.id)
        },
        Text(cx.tr("plan.scope")).color(tokens.colors.text_secondary),
    ])).padding_all(tokens.spacing.l)))
}

fission_component! {
    pub PlanSelectionRow<PlanState> { props { item_id: u64 } }
    view(row, state, cx) {
        let item = state.items.iter().find(|item| item.id == row.item_id);
    } => if let Some(item) = item {
        Button(
            child: Text(format!("{}: {}", cx.tr(if state.selected == Some(item.id) { "plan.selected" } else { "plan.select" }), item.title)),
            key: "select-item",
            on_press: reduce {
                if state.items.iter().any(|item| item.id == row.item_id) {
                    state.selected = Some(row.item_id);
                }
            },
        ).semantics_identifier(format!("plan.select.{}", row.item_id))
    } else { Text(cx.tr("plan.missing")) }
}

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid task translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

pub fn sync_env(state: &crate::app::PlanState, env: &mut Env) {
    env.locale = state.locale.clone();
}

## Keep interaction state and the plan separate

`initial_transform` sets the starting view; the canvas runtime retains later pan/zoom interaction. Node movement updates the corresponding record's bounds. Selection accepts only an ID which still belongs to the document. Unknown or unrelated interaction kinds do not create records.

The app registers its reusable event reducer when building the canvas and supplies that action to both selection and move callbacks. This is a legitimate shared handler boundary, not an excuse to create one action type per simple button.

The labelled list invokes the same application selection state without relying on coordinates. It is a selection alternative, not a claim of a complete non-gesture movement editor. A product needing equivalent keyboard-only placement should add named movement commands or coordinate fields and test them with the intended assistive tools.

```sh
cargo test --lib
```

The test checks stable identity under reversal and rejects an empty check. It cannot establish that a finger drag, pinch or VoiceOver interaction behaves correctly on iOS.

## Verify touch and small-screen interaction

On macOS, launch an installed simulator:

```sh
fission doctor ios --project-dir .
fission devices --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
```

Repeat on a small iPhone layout and a wider iPad layout. Check dragging near the canvas edge, pan versus selection, pinch zoom limits, an open keyboard, long translated labels and a denser plan. The canvas has its own bounded viewport inside the page's scrolling region; inspect how their gestures interact rather than assuming two scrollable surfaces will feel right.

Use [a physical iPhone](/blog/install-a-fission-app-on-a-physical-iphone/) for final touch and accessibility checks. A browser drag does not establish native gesture behaviour. A passing host smoke test says nothing about whether the right node moved.

At Greenway Market’s receiving dock, the morning shipment arrives against purchase order **PO-4807**. A clerk checks each product label, and the screen keeps a running count beside the quantity the supplier promised. The handheld scanner reads either a QR code or a Code 128 label; a damaged label can still be entered from the keyboard.

We will build the receiving screen around that job. A scan adds one unit only when its SKU belongs to the open order and the expected quantity has not already been reached. A permission denial, cancelled camera sheet, unknown SKU, or full line leaves the existing count intact and tells the clerk what to do next.

The browser preview does not return a canned barcode. It uses the manual SKU path so you can exercise the real purchase-order rules without a camera. The installed iOS app shows a scan action that asks Fission’s configured camera provider to read the label.

## Create the iOS project

Install the Fission CLI, create a shared Rust app, add iOS, then declare the scanner capability. The capability declaration lets Fission add the mobile camera configuration the generated host needs.

## Build the receiving screen and connect the scanner

Keep the order and received quantities in app state because the whole receiving screen needs to see them. The text in the manual SKU field belongs to one screen, so it stays in the `ReceivingDesk` component. Both input paths call the same `record_supplier_sku` rule: a camera result and a typed code therefore cannot disagree about whether a line is valid.

The code is split into the app modules, the component, and the shared startup. Select a tab to follow one file at a time. The browser preview and iOS app begin with the same sample purchase order so you can see the receiving rules immediately. The order is held in memory for this tutorial; a production receiving app would load an open order from its own storage or service.

use fission::prelude::*;

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct PurchaseOrderLine {
    pub sku: String,
    pub product_name: String,
    pub expected_units: u32,
    pub received_units: u32,
}

#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct ReceivingState {
    pub order_reference: Option<String>,
    pub supplier_name: Option<String>,
    pub lines: Vec<PurchaseOrderLine>,
    pub scanner_busy: bool,
    pub notice: Option<String>,
    pub error: Option<String>,
}

impl GlobalState for ReceivingState {}

impl ReceivingState {
    pub fn sample_purchase_order() -> Self {
        Self {
            order_reference: Some("PO-4807".into()),
            supplier_name: Some("Harbor Foods · Harbor Street depot".into()),
            lines: vec![
                PurchaseOrderLine {
                    sku: "GLV-204".into(),
                    product_name: "Nitrile gloves · Large".into(),
                    expected_units: 12,
                    received_units: 3,
                },
                PurchaseOrderLine {
                    sku: "TEA-112".into(),
                    product_name: "Green tea · 20 sachets".into(),
                    expected_units: 8,
                    received_units: 0,
                },
            ],
            ..Default::default()
        }
    }
}

/// Apply the same checks to a manually entered SKU and a decoded barcode.
pub fn record_supplier_sku(state: &mut ReceivingState, value: &str) -> bool {
    let sku = value.trim().to_ascii_uppercase();
    if sku.is_empty() {
        state.error = Some("Enter the SKU printed on the product label.".to_string());
        state.notice = None;
        return false;
    }

    if state.order_reference.is_none() {
        state.error = Some("Open a purchase order before receiving products.".to_string());
        state.notice = None;
        return false;
    }

    let Some(index) = state
        .lines
        .iter()
        .position(|line| line.sku.eq_ignore_ascii_case(&sku))
    else {
        state.error = Some(format!(
            "{sku} is not on this purchase order. Check the label or ask the receiving lead before counting it."
        ));
        state.notice = None;
        return false;
    };

    let result = {
        let line = &mut state.lines[index];
        if line.received_units >= line.expected_units {
            Err((line.product_name.clone(), line.expected_units))
        } else {
            line.received_units += 1;
            Ok((
                line.product_name.clone(),
                line.received_units,
                line.expected_units,
            ))
        }
    };

    let (product_name, received_units, expected_units) = match result {
        Ok(received) => received,
        Err((product_name, expected_units)) => {
            state.error = Some(format!(
                "{product_name} has already reached its ordered quantity of {expected_units} units. No extra unit was added."
            ));
            state.notice = None;
            return false;
        }
    };

    state.error = None;
    state.notice = Some(format!(
        "Recorded {product_name}: {received_units} of {expected_units} units received."
    ));
    true
}

#[fission_reducer(BarcodeLabelRead)]
pub fn on_barcode_label_read(
    state: &mut ReceivingState,
    ctx: &mut ReducerContext<ReceivingState>,
) {
    state.scanner_busy = false;

    let Some(results) = ctx.input.capability_ok(SCAN_BARCODE) else {
        state.error = Some(
            "The scanner returned no result. Try again or enter the SKU manually.".to_string(),
        );
        state.notice = None;
        return;
    };

    let Some(label) = results.items.first() else {
        state.error = Some(
            "No product label was read. Try again with the bars inside the scan frame, or enter the SKU manually."
                .to_string(),
        );
        state.notice = None;
        return;
    };

    record_supplier_sku(state, &label.value);
}

#[fission_reducer(BarcodeScanFailed)]
pub fn on_barcode_scan_failed(
    state: &mut ReceivingState,
    ctx: &mut ReducerContext<ReceivingState>,
) {
    state.scanner_busy = false;
    state.notice = None;

    let Some(error) = ctx.input.capability_error(SCAN_BARCODE) else {
        state.error = Some(
            "The scanner failed before returning a result. The received counts are unchanged; enter the SKU manually or try again."
                .to_string(),
        );
        return;
    };

    if error.code == "cancelled" {
        state.error = None;
        state.notice = Some(
            "Scanning was cancelled. No purchase-order counts changed; you can scan again or enter a SKU."
                .to_string(),
        );
        return;
    }

    state.error = Some(match error.code.as_str() {
        "permission_denied" => {
            "Camera access was denied. Allow camera access in iOS settings or enter the SKU manually.".to_string()
        }
        "unsupported" => {
            "This device cannot scan a live barcode. Enter the SKU manually to keep receiving.".to_string()
        }
        "timeout" => {
            "The scanner did not read a label in time. Move closer, improve the light, or enter the SKU manually.".to_string()
        }
        _ => {
            "The scanner could not read this label. Try again or enter the SKU manually; the received count is unchanged.".to_string()
        }
    });
}

#[fission_reducer(ScanSupplierLabel)]
pub fn on_scan_supplier_label(
    state: &mut ReceivingState,
    ctx: &mut ReducerContext<ReceivingState>,
) {
    if state.scanner_busy || state.order_reference.is_none() {
        return;
    }

    state.scanner_busy = true;
    state.error = None;
    state.notice = Some("Opening the product scanner…".to_string());

    let on_ok = ctx.effects.bind(
        BarcodeLabelRead,
        reduce_with!(on_barcode_label_read),
    );
    let on_err = ctx.effects.bind(
        BarcodeScanFailed,
        reduce_with!(on_barcode_scan_failed),
    );

    ctx.effects
        .barcode_scanner()
        .scan(BarcodeScanRequest {
            formats: vec![BarcodeFormat::Code128, BarcodeFormat::QrCode],
            prompt: Some("Scan one product SKU".into()),
            timeout_ms: Some(20_000),
            allow_multiple: false,
            ..Default::default()
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

The scan reducer marks the camera operation as busy and queues one asynchronous request for Code 128 or QR data. Fission sends the provider response through the reducer context: the success reducer reads `ctx.input.capability_ok(SCAN_BARCODE)`, while the error reducer reads `ctx.input.capability_error(SCAN_BARCODE)`. The small `BarcodeLabelRead` and `BarcodeScanFailed` actions only route the response to the right reducer; they do not carry a made-up result in their payload. `on_barcode_label_read` then sends the decoded value through the same order-line check used by manual entry. The error reducer branches on the stable error code, so cancellation, denied camera access, an unsupported scanner, and a timeout all leave the quantities untouched. The web startup keeps the scan control out of its screen; the iOS startup exposes it and lets the installed host perform a real scan.

The capability declaration adds the camera usage description to the generated iOS project. If iOS does not show a prompt or the provider reports `permission_denied`, inspect `NSCameraUsageDescription` in `platforms/ios/Info.plist` and the app’s camera access in Settings. Replace generated privacy copy with the reason this app needs to scan product labels. If the provider reports `unsupported`, keep the manual SKU path available; a device without a working scanner is still a device where a clerk can finish receiving.

For the typed provider contract and memory-host tests, continue with the [Barcode scanner capability guide](/docs/capabilities/barcode-scanner/) and the [Barcode scanner reference](/reference/capabilities/barcode-scanner/).

At the lunch rush, a barista needs to see which drinks are still being made and which customers can come to the counter. We will build a pickup board for North Pier Coffee. It starts with four believable tickets, counts orders by status, and lets staff move a ticket from preparation to pickup without losing track of the rest of the queue.

The order data stays in memory in this first app, so it resets when the process closes. That keeps the first iOS project focused on the screen and its state changes. The same Rust component runs in the browser preview and in Fission's native iOS shell.

## Create an iOS project

Create a Fission app and add its iOS target. If Xcode, the simulator runtime, or Rust's iOS targets are not installed yet, follow the [Rust and iOS development setup guide](/blog/set-up-rust-ios-development-with-fission/) first.

## Put the pickup details on each order card

A pickup board must answer three questions at a glance: whose order is this, what should be in the bag, and whether it is ready. We will start with four tickets across those statuses. Keeping the order number visible gives the barista a second way to confirm a handoff when two customers have similar names.

Add an order status, a small order record, and a reusable card component. The first screen is read-only; in the next step we will move status changes into shared app state so the summary and each card stay in sync.

An iPhone cannot show a long queue all at once. The board puts its content in a vertical `Scroll` region, then gives that region an accessible name so VoiceOver users can identify and move through the pickup queue.

```rust
use fission::prelude::*;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum OrderStatus {
    Preparing,
    Ready,
    Collected,
}

impl OrderStatus {
    fn label(self) -> &'static str {
        match self {
            Self::Preparing => "Being prepared",
            Self::Ready => "Ready for pickup",
            Self::Collected => "Collected",
        }
    }
}

#[derive(Clone, Debug, PartialEq)]
pub struct PickupOrder {
    pub id: u32,
    pub number: &'static str,
    pub customer: &'static str,
    pub items: &'static str,
    pub status: OrderStatus,

fn starter_orders() -> Vec<PickupOrder> {

            id: 204,

    pub PickupOrderCard<()> { order: PickupOrder }

        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(
        Column(gap: tokens.spacing.xs, align_items: ir_op::AlignItems::Start, children: [
            Text(format!("Order {} · {}", card.order.number, card.order.customer))
                .weight(tokens.typography.font_weight_semibold),
            Text(card.order.items.to_string()).color(tokens.colors.text_secondary),
            Text(format!("Status: {}", card.order.status.label()))
                .color(tokens.colors.text_secondary),

    )
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)

    pub CafePickupBoard<()> {}
    view(_board, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let orders = starter_orders();
        let preparing = orders.iter().filter(|order| order.status == OrderStatus::Preparing).count();
        let ready = orders.iter().filter(|order| order.status == OrderStatus::Ready).count();
        let collected = orders.iter().filter(|order| order.status == OrderStatus::Collected).count();

    SemanticsRegion(
        identifier: Some("cafe-pickup-board".to_string()),
        label: Some("North Pier Coffee pickup board".to_string()),
        child: Scroll(
            flex_grow: 1.0,
            height: cx.view.viewport_size().height,
            semantic_label: Some("North Pier Coffee pickup queue".to_string()),
            child: Container(Column(
                align_items: ir_op::AlignItems::Center,
                children: [Container(
                    Column(gap: tokens.spacing.l, children: [
                        Column(gap: tokens.spacing.xs, children: [
                            Text("North Pier Coffee")
                                .weight(tokens.typography.font_weight_bold),
                            Text("Lunch service · pickup queue")
                                .color(tokens.colors.text_secondary),

                .bg(tokens.colors.background)
                .width_length(Length::clamp(
                    Length::points(0.0),

                    Length::points(760.0),

    )
}
```

## Move orders through the pickup queue

An order's status affects both its card and the counts above the list, so keep those facts together in `CafeQueueState`. A typed reducer advances one order by its stable ID. The board's “hide collected” choice is different: it only changes how this screen is displayed, so it belongs to the board component's local state rather than the shared order data.

The reusable `PickupOrderCard` reads the shared order and offers the next useful action: a preparing order can be marked ready, and a ready order can be marked collected. Once collected, the card replaces its button with a handoff confirmation. Giving each card its order ID keeps its widget identity stable when the filter changes the list.

The screen keeps the vertical scroll region around the whole board, including the counts and filter. On a smaller phone, staff can reach every ticket without shrinking its text or hiding the summary controls.

Try #204 in the preview: its first tap changes the status and moves one count from Preparing to Ready for pickup; its second tap records the handoff. “Hide collected orders” only filters the visible cards. It does not delete tickets or change their status, so the staff member can bring the completed orders back with “Show the full queue.”

```rust
use fission::prelude::*;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum OrderStatus {
    Preparing,
    Ready,
    Collected,
}

impl OrderStatus {
    fn label(self) -> &'static str {
        match self {
            Self::Preparing => "Being prepared",
            Self::Ready => "Ready for pickup",
            Self::Collected => "Collected",
        }
    }

    fn next(self) -> Self {
        match self {
            Self::Preparing => Self::Ready,
            Self::Ready => Self::Collected,
            Self::Collected => Self::Collected,
        }
    }

    fn action_label(self) -> &'static str {
        match self {
            Self::Preparing => "Mark ready",
            Self::Ready => "Mark collected",
            Self::Collected => "Collected",
        }
    }
}

#[derive(Clone, Debug, PartialEq)]
pub struct PickupOrder {
    pub id: u32,
    pub number: &'static str,
    pub customer: &'static str,
    pub items: &'static str,
    pub status: OrderStatus,
}

fn starter_orders() -> Vec<PickupOrder> {
    vec![
        PickupOrder {
            id: 204,
            number: "#204",
            customer: "Maya",
            items: "Oat flat white · filter coffee",
            status: OrderStatus::Preparing,
        },
        PickupOrder {
            id: 205,
            number: "#205",
            customer: "Daniel",
            items: "Two flat whites · cinnamon roll",
            status: OrderStatus::Preparing,
        },
        PickupOrder {
            id: 206,
            number: "#206",
            customer: "Amina",
            items: "Iced mocha · almond croissant",
            status: OrderStatus::Ready,
        },
        PickupOrder {
            id: 207,
            number: "#207",
            customer: "Ezra",
            items: "Batch brew · blueberry muffin",
            status: OrderStatus::Collected,
        },
    ]
}

#[derive(Clone, Debug, PartialEq)]
pub struct CafeQueueState {
    pub orders: Vec<PickupOrder>,
    pub feedback: String,
}

impl Default for CafeQueueState {
    fn default() -> Self {
        Self {
            orders: starter_orders(),
            feedback: "New drinks are being prepared for the lunch pickup window.".to_string(),
        }
    }
}

impl GlobalState for CafeQueueState {}

#[fission_reducer(AdvanceOrder)]
pub fn on_advance_order(state: &mut CafeQueueState, order_id: u32) {
    let update = state
        .orders
        .iter_mut()
        .find(|order| order.id == order_id)
        .map(|order| {
            order.status = order.status.next();
            (order.number, order.customer, order.status)
        });

    if let Some((number, customer, status)) = update {
        state.feedback = format!(
            "Order {} for {} is now {}.",
            number,
            customer,
            status.label().to_lowercase()
        );
    }
}

fission_component! {
    pub PickupOrderCard<CafeQueueState> { order: PickupOrder }
    view(card, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(
        Column(gap: tokens.spacing.s, align_items: ir_op::AlignItems::Start, children: [
            Column(gap: tokens.spacing.xs, children: [
                Text(format!("Order {} · {}", card.order.number, card.order.customer))
                    .weight(tokens.typography.font_weight_semibold),
                Text(card.order.items.to_string()).color(tokens.colors.text_secondary),
                Text(format!("Status: {}", card.order.status.label()))
                    .color(tokens.colors.text_secondary),
            ]),
            if card.order.status != OrderStatus::Collected {
                Button(
                    child: Text(card.order.status.action_label()),
                    key: "advance-order",
                    variant: ButtonVariant::Primary,
                    on_press: with_reducer!(
                        cx.build,
                        AdvanceOrder(card.order.id),
                        on_advance_order,
                    ),
                )
                .semantics_identifier(format!("pickup-order-{}-advance", card.order.id))
            } else {
                Text("Handed to the customer.")
                    .color(tokens.colors.text_secondary)
            },
        ]),
    )
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
    .width_length(Length::percent(100.0))
}

fission_component! {
    pub CafePickupBoard<CafeQueueState> {
        state {
            hide_collected: bool = false,
        }
    }
    view(board, app, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let preparing = app.orders.iter()
            .filter(|order| order.status == OrderStatus::Preparing)
            .count();
        let ready = app.orders.iter()
            .filter(|order| order.status == OrderStatus::Ready)
            .count();
        let collected = app.orders.iter()
            .filter(|order| order.status == OrderStatus::Collected)
            .count();
        let visible_orders: Vec<PickupOrder> = app.orders.iter()
            .filter(|order| !board.hide_collected || order.status != OrderStatus::Collected)
            .cloned()
            .collect();
    } =>
    SemanticsRegion(
        identifier: Some("cafe-pickup-board".to_string()),
        label: Some("North Pier Coffee pickup board".to_string()),
        child: Scroll(
            flex_grow: 1.0,
            height: cx.view.viewport_size().height,
            semantic_label: Some("North Pier Coffee pickup queue".to_string()),
            child: Container(Column(
                align_items: ir_op::AlignItems::Center,
                children: [Container(
                    Column(gap: tokens.spacing.l, children: [
                        Column(gap: tokens.spacing.xs, children: [
                            Text("North Pier Coffee")
                                .weight(tokens.typography.font_weight_bold),
                            Text("Lunch service · pickup queue")
                                .color(tokens.colors.text_secondary),
                        ]),
                        Column(gap: tokens.spacing.xs, children: [
                            Text(format!("Preparing · {}", preparing)),
                            Text(format!("Ready for pickup · {}", ready)),
                            Text(format!("Collected · {}", collected))
                                .color(tokens.colors.text_secondary),
                        ]),
                        Button(
                            child: Text(if board.hide_collected {
                                "Show the full queue"
                            } else {
                                "Hide collected orders"
                            }),
                            key: "toggle-collected-orders",
                            variant: ButtonVariant::Outline,
                            on_press: reduce {
                                board.hide_collected = !board.hide_collected;
                            },
                        )
                        .semantics_identifier("cafe-queue.toggle-collected"),
                        if visible_orders.is_empty() {
                            Text("Every order is collected. Show the full queue to review today's tickets.")
                        } else {
                            Column(gap: tokens.spacing.s, children: [
                                for order in visible_orders.iter() {
                                    PickupOrderCard(order.clone(), key: order.id)
                                },
                            ])
                        },
                        Text(app.feedback.clone()).color(tokens.colors.text_secondary),
                    ]),
                )
                .padding_all(tokens.spacing.l)
                .bg(tokens.colors.background)
                .width_length(Length::clamp(
                    Length::points(0.0),
                    Length::percent(100.0),
                    Length::points(760.0),
                ))],
            ),
        )
        .width_length(Length::percent(100.0))
        .bg(tokens.colors.background),
    ),
    )
}
```

## Run the pickup board in the iOS Simulator

`fission init` points `src/lib.rs` at its starter `CounterApp`. Replace that wiring with `CafePickupBoard` and `CafeQueueState`, then launch the iOS target. The native shell starts the same shared component that you used in the browser preview; no Swift screen needs to duplicate the order rules.

<TabItem label="src/lib.rs">
```rust
pub mod app;

use crate::app::{CafePickupBoard, CafeQueueState};
use fission::prelude::*;

#[cfg(any(target_os = "android", target_os = "ios"))]
fn mobile_app() -> MobileApp<CafeQueueState, CafePickupBoard> {
    MobileApp::<CafeQueueState, _>::new(CafePickupBoard::new())
        .with_title("North Pier Coffee pickup board")
}

#[cfg(target_arch = "wasm32")]
fn web_app() -> WebApp<CafeQueueState, CafePickupBoard> {
    WebApp::<CafeQueueState, _>::new(CafePickupBoard::new())
        .with_title("North Pier Coffee pickup board")
}

#[cfg(not(any(target_arch = "wasm32", target_os = "android", target_os = "ios")))]
pub fn run_desktop() -> anyhow::Result<()> {
    DesktopApp::<CafeQueueState, _>::new(CafePickupBoard::new()).run()
}

#[cfg(any(target_os = "android", target_os = "ios"))]
pub fn run_mobile() -> anyhow::Result<()> {
    mobile_app().run()
}

#[cfg(target_arch = "wasm32")]
#[wasm_bindgen::prelude::wasm_bindgen(start)]
pub fn run_web() -> Result<(), wasm_bindgen::JsValue> {
    console_error_panic_hook::set_once();
    web_app()
        .run()
        .map_err(|error| wasm_bindgen::JsValue::from_str(&error.to_string()))
}
```

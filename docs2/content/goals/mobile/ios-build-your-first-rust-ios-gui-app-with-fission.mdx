During the lunch rush, a barista needs to know which drinks are still being made and which customers can come to the counter. We will build a pickup board for North Pier Coffee with four sample orders, a count for each status, and actions to move an order from preparation to pickup. The sample tickets are seeded only by the browser preview. The shared component renders the orders it receives and shows an empty state when none are loaded; the next step connects it to shared app state.

Order data stays in memory, so it resets when the app closes. That keeps this first iOS project focused on the screen and its state changes. The same Rust component runs in the browser preview and Fission's native iOS shell.

## Create an iOS project

Create a Fission app and add its iOS target. If Xcode, the Simulator runtime, or Rust's iOS targets are not installed yet, start with the [Rust and iOS development setup guide](/blog/set-up-rust-ios-development-with-fission/).

## Put the pickup details on each order card

The pickup board needs to answer three questions: whose order is this, what
goes in the bag, and is it ready? Start with four tickets in different states.
The order number gives the barista another way to confirm a handoff when two
customers have similar names.

Add an order status, a small order record, and a reusable card. This is a static browser-preview checkpoint, not native launch data. In the next step, status changes will go into shared app state so the summary and each card stay in sync; the native app will have an empty state until real order data is loaded.

An iPhone cannot show a long queue at once. The board uses a vertical `Scroll` region and gives it an accessible name, so VoiceOver users can find and move through the pickup queue.

use fission::prelude::*;
use fission::i18n::{Locale, TranslationBundle};

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, yaml) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(yaml).expect("valid North Pier Coffee translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum OrderStatus {
    Preparing,
    Ready,
    Collected,
}

impl OrderStatus {
    fn label(self) -> &'static str {
        match self {
            Self::Preparing => "pickup.status.preparing",
            Self::Ready => "pickup.status.ready",
            Self::Collected => "pickup.status.collected",
        }
    }
}

#[derive(Clone, Debug, PartialEq)]
pub struct PickupOrder {
    pub id: u32,
    pub number: &'static str,
    pub customer: &'static str,
    pub items_key: &'static str,
    pub status: OrderStatus,
}

fission_component! {
    pub PickupOrderCard<()> { order: PickupOrder }
    view(card, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(
        Column(gap: tokens.spacing.xs, align_items: ir_op::AlignItems::Start, children: [
            Text(format!("{} {} · {}", cx.tr("pickup.order"), card.order.number, card.order.customer))
                .weight(tokens.typography.font_weight_semibold),
            Text(cx.tr(card.order.items_key)).color(tokens.colors.text_secondary),
            Text(format!("{}: {}", cx.tr("pickup.status"), cx.tr(card.order.status.label())))
                .color(tokens.colors.text_secondary),
        ]),
    )
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
    .width_length(Length::percent(100.0))
}

fission_component! {
    pub CafePickupBoard<()> { orders: Vec<PickupOrder> }
    view(board, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let orders = &board.orders;
        let preparing = orders.iter().filter(|order| order.status == OrderStatus::Preparing).count();
        let ready = orders.iter().filter(|order| order.status == OrderStatus::Ready).count();
        let collected = orders.iter().filter(|order| order.status == OrderStatus::Collected).count();
    } =>
    SemanticsRegion(
        identifier: Some("cafe-pickup-board".to_string()),
        label: Some(cx.tr("pickup.title")),
        child: SafeArea(
        child: Scroll(
            flex_grow: 1.0,
            semantic_label: Some(cx.tr("pickup.queue.label")),
            child: Container(Column(
                align_items: ir_op::AlignItems::Center,
                children: [Container(
                    Column(gap: tokens.spacing.l, children: [
                        Column(gap: tokens.spacing.xs, children: [
                            Text(cx.tr("pickup.title"))
                                .weight(tokens.typography.font_weight_bold),
                            Text(cx.tr("pickup.subtitle"))
                                .color(tokens.colors.text_secondary),
                        ]),
                        Column(gap: tokens.spacing.xs, children: [
                            Text(format!("{} · {}", cx.tr("pickup.summary.preparing"), preparing)),
                            Text(format!("{} · {}", cx.tr("pickup.summary.ready"), ready)),
                            Text(format!("{} · {}", cx.tr("pickup.summary.collected"), collected))
                                .color(tokens.colors.text_secondary),
                        ]),
                        if orders.is_empty() {
                            Text(cx.tr("pickup.empty"))
                                .color(tokens.colors.text_secondary)
                        } else {
                            Column(gap: tokens.spacing.s, children: [
                                for order in orders.iter() {
                                    PickupOrderCard(order.clone(), key: order.id)
                                },
                            ])
                        },
                    ]),
                )
                .padding_all(tokens.spacing.l)
                .bg(tokens.colors.background)
                .width_length(Length::clamp(
                    Length::points(0.0),
                    Length::percent(100.0),
                    Length::points(760.0),
                ))],
            ),
        )
        .width_length(Length::percent(100.0))
        .bg(tokens.colors.background),
        ),
    ),
    )
}

## Move orders through the pickup queue

An order's status affects its card and the counts above the list, so keep that data together in `CafeQueueState`. An inline `reduce` block advances an order by its stable ID. “Hide collected” only changes this screen, so it belongs in the board component's local state, not in the shared order data.

The reusable `PickupOrderCard` shows the next useful action: mark a preparing order ready, or mark a ready order collected. After collection, the card shows a handoff confirmation instead of a button. The order ID keeps each card's identity stable when the filter changes the list. The inline reducer sends only that ID and updates the current shared order; it does not send an old copy of the whole order back. A named reducer would make sense if this transition were shared elsewhere or needed a richer policy.

The vertical scroll region contains the whole board, including its counts and filter. On a smaller phone, staff can reach every ticket without shrinking the text or losing the summary controls.

Try order #204 in the preview. The first tap changes its status and moves one count from Preparing to Ready for pickup; the second records the handoff. “Hide collected orders” only filters the cards. It does not delete an order or change its status, and “Show the full queue” brings it back.

use fission::i18n::{Locale, TranslationBundle};
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, yaml) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(yaml).expect("valid North Pier Coffee translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum OrderStatus {
    Preparing,
    Ready,
    Collected,
}

impl OrderStatus {
    fn label_key(self) -> &'static str {
        match self {
            Self::Preparing => "pickup.status.preparing",
            Self::Ready => "pickup.status.ready",
            Self::Collected => "pickup.status.collected",
        }
    }

    fn next(self) -> Self {
        match self {
            Self::Preparing => Self::Ready,
            Self::Ready => Self::Collected,
            Self::Collected => Self::Collected,
        }
    }

    fn action_key(self) -> &'static str {
        match self {
            Self::Preparing => "pickup.action.ready",
            Self::Ready => "pickup.action.collect",
            Self::Collected => "pickup.status.collected",
        }
    }
}

#[derive(Clone, Debug, PartialEq)]
pub struct PickupOrder {
    pub id: u32,
    pub number: &'static str,
    pub customer: &'static str,
    pub items_key: &'static str,
    pub status: OrderStatus,
}

#[derive(Clone, Debug, Default, PartialEq)]
pub struct CafeQueueState {
    pub orders: Vec<PickupOrder>,
    pub last_update: Option<(u32, OrderStatus)>,
}

impl GlobalState for CafeQueueState {}

fission_component! {
    pub PickupOrderCard<CafeQueueState> {
        order_id: u32,
        number: &'static str,
        customer: &'static str,
        items_key: &'static str,
        status: OrderStatus,
    }
    view(card, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(
        Column(gap: tokens.spacing.s, align_items: ir_op::AlignItems::Start, children: [
            Column(gap: tokens.spacing.xs, children: [
                Text(format!("{} {} · {}", cx.tr("pickup.order"), card.number, card.customer))
                    .weight(tokens.typography.font_weight_semibold),
                Text(cx.tr(card.items_key)).color(tokens.colors.text_secondary),
                Text(format!("{}: {}", cx.tr("pickup.status"), cx.tr(card.status.label_key())))
                    .color(tokens.colors.text_secondary),
            ]),
            if card.status != OrderStatus::Collected {
                Button(
                    child: Text(cx.tr(card.status.action_key())),
                    key: "advance-order",
                    variant: ButtonVariant::Primary,
                    on_press: reduce {
                        if let Some(order) = state.orders.iter_mut().find(|order| order.id == card.order_id) {
                            let next_status = order.status.next();
                            order.status = next_status;
                            state.last_update = Some((card.order_id, next_status));
                        }
                    },
                )
                .semantics_identifier(format!("pickup-order-{}-advance", card.order_id))
            } else {
                Text(cx.tr("pickup.handed_off"))
                    .color(tokens.colors.text_secondary)
            },
        ]),
    )
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
    .width_length(Length::percent(100.0))
}

fission_component! {
    pub CafePickupBoard<CafeQueueState> {
        state {
            hide_collected: bool = false,
        }
    }
    view(board, app, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let preparing = app.orders.iter()
            .filter(|order| order.status == OrderStatus::Preparing)
            .count();
        let ready = app.orders.iter()
            .filter(|order| order.status == OrderStatus::Ready)
            .count();
        let collected = app.orders.iter()
            .filter(|order| order.status == OrderStatus::Collected)
            .count();
        let visible_orders: Vec<PickupOrder> = app.orders.iter()
            .filter(|order| !board.hide_collected || order.status != OrderStatus::Collected)
            .cloned()
            .collect();
        let feedback = app.last_update
            .and_then(|(order_id, status)| {
                let order = app.orders.iter().find(|order| order.id == order_id)?;
                Some(format!(
                    "{} {} · {}: {}",
                    cx.tr("pickup.feedback.updated"),
                    order.number,
                    order.customer,
                    cx.tr(status.label_key()),
                ))
            })
            .unwrap_or_else(|| cx.tr("pickup.feedback.ready"));
    } =>
    SemanticsRegion(
        identifier: Some("cafe-pickup-board".to_string()),
        label: Some(cx.tr("pickup.title")),
        child: SafeArea(
            child: Scroll(
            flex_grow: 1.0,
            semantic_label: Some(cx.tr("pickup.queue.label")),
            child: Container(Column(
                align_items: ir_op::AlignItems::Center,
                children: [Container(
                    Column(gap: tokens.spacing.l, children: [
                        Column(gap: tokens.spacing.xs, children: [
                            Text(cx.tr("pickup.title"))
                                .weight(tokens.typography.font_weight_bold),
                            Text(cx.tr("pickup.subtitle"))
                                .color(tokens.colors.text_secondary),
                        ]),
                        Column(gap: tokens.spacing.xs, children: [
                            Text(format!("{} · {}", cx.tr("pickup.summary.preparing"), preparing)),
                            Text(format!("{} · {}", cx.tr("pickup.summary.ready"), ready)),
                            Text(format!("{} · {}", cx.tr("pickup.summary.collected"), collected))
                                .color(tokens.colors.text_secondary),
                        ]),
                        Button(
                            child: Text(cx.tr(if board.hide_collected {
                                "pickup.filter.all"
                            } else {
                                "pickup.filter.active"
                            })),
                            key: "toggle-collected-orders",
                            variant: ButtonVariant::Outline,
                            on_press: reduce {
                                board.hide_collected = !board.hide_collected;
                            },
                        )
                        .semantics_identifier("cafe-queue.toggle-collected"),
                        if visible_orders.is_empty() {
                            Text(cx.tr(if app.orders.is_empty() { "pickup.empty" } else { "pickup.all_collected" }))
                        } else {
                            Column(gap: tokens.spacing.s, children: [
                                for order in visible_orders.iter() {
                                    PickupOrderCard(
                                        order.id,
                                        order.number,
                                        order.customer,
                                        order.items_key,
                                        order.status,
                                        key: order.id,

                            ])

## Run the pickup board in the iOS Simulator

`fission init` points `src/lib.rs` at the starter `CounterApp`. Replace it with `CafePickupBoard` and `CafeQueueState`, then launch the iOS target. The native shell starts the same shared component used in the browser preview; there is no need to duplicate the order rules in Swift.

pub mod app;

use crate::app::{CafePickupBoard, CafeQueueState};
use fission::prelude::*;

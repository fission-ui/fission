A pickup queue needs to distinguish an order being prepared from one waiting at the counter. Those states are not interchangeable: marking a drink ready must not also record that its customer collected it.

We will build a small café board with an actual order-entry form. It starts empty on both native and Web targets. Enter the customer and items yourself, then move the order through preparation, readiness and handoff. The counts come from those records rather than a second set of editable totals.

Orders stay in memory for this session. Payment, durable storage and a connected order service are outside this first app; none is implied by recording a handoff.

## Create an iOS project

Complete [Rust and iOS setup](/blog/set-up-rust-ios-development-with-fission/) first. On macOS, create the app and add its target:

```sh
cargo install cargo-fission
fission init ios-build-your-first-rust-ios-gui-app-with-fission
cd ios-build-your-first-rust-ios-gui-app-with-fission
fission add-target ios --project-dir .
cargo add serde_yaml
```

Keep the generated `src/main.rs`. The shared library below replaces the starter app for every normal launch. The browser preview is not seeded with orders which the iOS app cannot create.

## Put the order rules beside the records

`CafeState` owns orders and their stable session IDs. Each card receives only its ID and looks up the current record. The entry draft and display filter belong to the screen because they do not change whether an order has been prepared or collected.

The two status transitions are intentionally separate and idempotent. Replaying “Mark ready” whilst the order is already ready does not hand it over. This matters with quick repeated input; a generic “advance to whatever comes next” action can record a consequence the person did not intend.

```rust
use fission::prelude::*;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum OrderStatus {
    Preparing,
    Ready,
    Collected,
}
impl OrderStatus {
    pub fn label_key(self) -> &'static str {
        match self {
            Self::Preparing => "order.preparing",
            Self::Ready => "order.ready",
            Self::Collected => "order.collected",
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct PickupOrder {
    pub id: u64,
    pub customer: String,
    pub items: String,
    pub status: OrderStatus,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct CafeState {
    pub orders: Vec<PickupOrder>,
    pub next_id: u64,
    pub locale: Locale,
}
impl Default for CafeState {
    fn default() -> Self {
        Self {
            orders: Vec::new(),
            next_id: 1,
            locale: Locale::from("en-US"),
        }
    }
}
impl GlobalState for CafeState {}

pub fn add_order(state: &mut CafeState, customer: &str, items: &str) -> bool {
    let (customer, items) = (customer.trim(), items.trim());
    if customer.is_empty() || items.is_empty() {
        return false;
    }
    let Some(next_id) = state.next_id.checked_add(1) else {
        return false;
    };
    state.orders.push(PickupOrder {
        id: state.next_id,
        customer: customer.to_owned(),
        items: items.to_owned(),
        status: OrderStatus::Preparing,
    });
    state.next_id = next_id;
    true
}

pub fn mark_ready(state: &mut CafeState, id: u64) {
    if let Some(order) = state.orders.iter_mut().find(|order| order.id == id) {
        if order.status == OrderStatus::Preparing {
            order.status = OrderStatus::Ready;
        }
    }
}
pub fn collect_order(state: &mut CafeState, id: u64) {
    if let Some(order) = state.orders.iter_mut().find(|order| order.id == id) {
        if order.status == OrderStatus::Ready {
            order.status = OrderStatus::Collected;
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn order_requires_both_inputs_and_gets_its_own_identity() {
        let mut state = CafeState::default();
        assert!(!add_order(&mut state, " ", "Flat white"));
        assert!(add_order(&mut state, "Maya", "Flat white"));
        assert!(add_order(&mut state, "Maya", "Flat white"));
        assert_ne!(state.orders[0].id, state.orders[1].id);
    }
    #[test]
    fn duplicate_ready_action_does_not_record_a_handoff() {
        let mut state = CafeState::default();
        add_order(&mut state, "Maya", "Flat white");
        let id = state.orders[0].id;
        collect_order(&mut state, id);
        assert_eq!(state.orders[0].status, OrderStatus::Preparing);
        mark_ready(&mut state, id);
        mark_ready(&mut state, id);
        assert_eq!(state.orders[0].status, OrderStatus::Ready);
        collect_order(&mut state, id);
        collect_order(&mut state, id);
        assert_eq!(state.orders[0].status, OrderStatus::Collected);
    }
}
```

```rust
use super::state::{collect_order, mark_ready, CafeState, OrderStatus};
use fission::prelude::*;

fission_component! {
    pub PickupOrderCard<CafeState> { props { order_id: u64 } }
    view(card, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let order = state.orders.iter().find(|order| order.id == card.order_id);
    } => if let Some(order) = order {
        SemanticsRegion(
            identifier: Some(format!("pickup.order.{}", card.order_id)),
            child: Container(Column(gap: tokens.spacing.s, children: [
                Text(format!("#{} · {}", order.id, order.customer))
                    .weight(tokens.typography.font_weight_semibold),
                Text(order.items.clone()),
                Text(cx.tr(order.status.label_key())),
                if order.status == OrderStatus::Preparing {
                    Button(
                        child: Text(cx.tr("order.mark_ready")), key: "mark-ready",
                        on_press: reduce { mark_ready(state, card.order_id); },
                    )
                } else if order.status == OrderStatus::Ready {
                    Button(
                        child: Text(cx.tr("order.collect")), key: "collect",
                        on_press: reduce { collect_order(state, card.order_id); },
                    )
                } else {
                    Text(cx.tr("order.handed_over")).color(tokens.colors.text_secondary)
                },
            ])).padding_all(tokens.spacing.m)
                .bg(tokens.colors.surface)
                .border(tokens.colors.border, 1.0)
                .border_radius(tokens.radii.medium),
        )
    } else { Text(cx.tr("order.missing")) }
}
```

```rust
use super::card::PickupOrderCard;
use super::state::{add_order, CafeState, OrderStatus};
use fission::prelude::*;

fission_component! {
    pub CafeScreen<CafeState> {
        state {
            customer: String = String::new(),
            items: String = String::new(),
            attempted: bool = false,
            hide_collected: bool = false,
        }
    }
    view(form, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let customer_error = (form.attempted && form.customer.trim().is_empty())
            .then(|| cx.tr("order.customer_required"));
        let items_error = (form.attempted && form.items.trim().is_empty())
            .then(|| cx.tr("order.items_required"));
        let preparing = state.orders.iter().filter(|o| o.status == OrderStatus::Preparing).count();
        let ready = state.orders.iter().filter(|o| o.status == OrderStatus::Ready).count();
        let collected = state.orders.iter().filter(|o| o.status == OrderStatus::Collected).count();
        let visible: Vec<_> = state.orders.iter()
            .filter(|o| !form.hide_collected || o.status != OrderStatus::Collected).collect();
    } => SafeArea(child: Scroll(child: Container(
        Column(gap: tokens.spacing.m, children: [
            Text(cx.tr("cafe.title")).size(tokens.typography.heading2_size),
            Text(cx.tr("cafe.explanation")),
            Row(gap: tokens.spacing.s, children: [
                Button(child: Text(cx.tr("language.english")), key: "english",
                    on_press: reduce { state.locale = Locale::from("en-US"); }),
                Button(child: Text(cx.tr("language.spanish")), key: "spanish",
                    on_press: reduce { state.locale = Locale::from("es-ES"); }),
            ]),
            FormControl(
                label: Some(cx.tr("order.customer")), required: true, error: customer_error,
                child: TextInput(value: form.customer.clone(), bind(on_input): to(form.customer)),
            ),
            FormControl(
                label: Some(cx.tr("order.items")), required: true, error: items_error,
                child: TextInput(value: form.items.clone(), bind(on_input): to(form.items)),
            ),
            Button(
                child: Text(cx.tr("order.add")), key: "add-order",
                disabled: state.next_id == u64::MAX,
                on_press: reduce {
                    form.attempted = true;
                    if add_order(state, &form.customer, &form.items) {
                        form.customer.clear();
                        form.items.clear();
                        form.attempted = false;
                    }
                },
            ),
            Text(cx.tr("cafe.summary")
                .replace("{preparing}", &preparing.to_string())
                .replace("{ready}", &ready.to_string())
                .replace("{collected}", &collected.to_string())),
            Button(
                child: Text(cx.tr(if form.hide_collected { "cafe.show_all" } else { "cafe.hide_collected" })),
                key: "filter-orders",
                on_press: reduce { form.hide_collected = !form.hide_collected; },
            ),
            if visible.is_empty() { Text(cx.tr("cafe.empty")) },
            for order in visible {
                PickupOrderCard(order.id, key: order.id)
            },
            Text(cx.tr("cafe.persistence")).color(tokens.colors.text_secondary),
        ])
    ).padding_all(tokens.spacing.l).bg(tokens.colors.background)))
}
```

```rust
use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid task translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

pub fn sync_env(state: &crate::app::CafeState, env: &mut Env) {
    env.locale = state.locale.clone();
}
```

## Move the actual orders through pickup

Mark one order ready and inspect all three counts. The preparing count falls whilst ready increases. Record its handoff separately; the collected count then increases. Hiding collected orders changes presentation, not the records or totals.

The reusable card has a concrete boundary, its own file and required input. It does not contain a second copy of the order. The shared state remains the authority whilst inline `reduce` handlers call the small domain transitions.

Interface labels come from checked-in English and Spanish bundles. Customer names and item descriptions are user data and are not translated. The active environment supplies spacing, colours and typography; this example does not recreate a design system with scattered literal sizes.

```sh
cargo test --lib
```

The tests exercise order input, stable IDs and repeated transitions. They do not establish that the rendered card is readable with the keyboard open.

```sh
fission doctor ios --project-dir .
fission devices --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
```

To select an installed simulator, use its reported ID:

```sh
fission run --target ios --device <device-id> --project-dir .
```

These commands launch or package the simulator app; they do not install it on an iPhone. Follow [physical iPhone installation](/blog/install-a-fission-app-on-a-physical-iphone/) for signing and device checks.

## Create a shared field-notes project

Install Fission, create the project, and add both native targets. Shared screens and note behavior live in Rust so the Android and iOS builds use the same workflow.

<Tabs>
<TabItem label="Create the project">

```sh
cargo install cargo-fission
fission init field-notes
cd field-notes
fission add-target android ios --project-dir .
fission add-capability storage --project-dir .
cargo add serde_yaml
```

</TabItem>
<TabItem label="Where the code lives">

```text
field-notes/
├── Cargo.toml
├── fission.toml
├── src/
│   ├── main.rs
│   ├── lib.rs
│   └── app.rs
└── platforms/
    ├── android/
    └── ios/
```

</TabItem>
</Tabs>

`fission add-capability storage` enables Fission’s SQLite provider on native targets. Keep the model and screens in `src/`; the generated platform folders launch and package the same app. That way Android and iOS don’t grow separate save and edit behaviour.

This tutorial implements local persistence and the reducer boundary for a sync result. It does not make an HTTP request or include a server endpoint. Until you connect a real service, new notes stay **Waiting to sync**; the preview’s sample **Synced** records are only there to show how the list looks.

## Shape a note around a real field visit

Between sites, a technician needs to know which job a note belongs to, what they saw, when they recorded it, and whether it still needs to sync. A title and paragraph stop being enough once the notebook has more than a few entries.

We’ll build **Harbour Field Notes** for a maintenance crew. Each record has a stable ID, worksite, title, observation, update time, local revision, and sync status. The sample notes cover a gate inspection, rooftop inverter, and loading-dock drain. That gives the list and detail view something useful to show before we add editing.

Start with the record type and a screen that helps the technician find a note. `FieldNoteListItem` and `FieldNotesWorkspace` are named `fission_component!` components, so the screen has reusable boundaries instead of one anonymous tree.

```rust
use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, yaml) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(yaml).expect("valid Harbour Field Notes translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum NoteSyncStatus {
    Synced,
    WaitingToSync,
}

impl NoteSyncStatus {
    pub fn translation_key(&self) -> &'static str {
        match self {
            Self::Synced => "notes.sync.synced",
            Self::WaitingToSync => "notes.sync.waiting",
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct FieldNote {
    pub id: i64,
    pub site: String,
    pub title: String,
    pub observation: String,
    pub updated_at: String,
    pub revision: u32,
    pub sync_status: NoteSyncStatus,
}

#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct FieldNotesState {
    pub notes: Vec<FieldNote>,
}

impl GlobalState for FieldNotesState {}

fission_component! {
    pub FieldNoteListItem<()> {
        note: FieldNote,
        selected: bool,
    }
    view(row, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let status = if row.selected { "notes.row.selected" } else { row.note.sync_status.translation_key() };
    } =>
    Container(
        Column(gap: tokens.spacing.xs, children: [
            Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                Text(cx.tr(&row.note.title))
                    .weight(tokens.typography.font_weight_semibold),
                Spacer(flex_grow: 1.0),
                Text(cx.tr(status)),
            ]),
            Text(cx.tr(&row.note.site)).color(tokens.colors.text_secondary),
            Text(cx.tr(&row.note.updated_at)).color(tokens.colors.text_secondary),
        ]),
    )
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
}

fission_component! {
    pub FieldNotesWorkspace<FieldNotesState> {}
    view(_workspace, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let notes = &state.notes;
        let selected = notes.first();
        let selected_id = selected.map(|note| note.id);
        let waiting_count = notes.iter()
            .filter(|note| note.sync_status == NoteSyncStatus::WaitingToSync)
            .count();
    } =>
    SemanticsRegion(
        identifier: Some("harbour-field-notes".to_string()),
        label: Some(cx.tr("notes.app.title")),
        child: Scroll(
            flex_grow: 1.0,
            height: cx.view.viewport_size().height,
            semantic_label: Some(cx.tr("notes.workspace.a11y")),
            child: Container(
                Column(gap: tokens.spacing.l, children: [
                    Row(gap: tokens.spacing.m, wrap: ir_op::FlexWrap::Wrap, children: [
                        Column(gap: tokens.spacing.xs, children: [
                            Text(cx.tr("notes.app.title"))
                                .weight(tokens.typography.font_weight_bold),
                            Text(cx.tr("notes.app.subtitle"))
                                .color(tokens.colors.text_secondary),
                        ]),
                        Spacer(flex_grow: 1.0),
                        Text(cx.tr("notes.device.available")),
                    ]),
                    Grid(
                        columns: vec![GridTrack::auto_fit(GridTrack::minmax(
                            GridTrack::Points(150.0),
                            GridTrack::Fr(1.0),
                        ))],
                        rows: vec![GridTrack::Auto],
                        column_gap: tokens.spacing.m,
                        row_gap: tokens.spacing.s,
                        children: [
                            Column(children: [
                                Text(cx.tr("notes.summary.notes").replace("{count}", &notes.len().to_string()))
                                    .weight(tokens.typography.font_weight_semibold),
                                Text(cx.tr("notes.summary.device"))
                                    .color(tokens.colors.text_secondary),
                            ]),
                            Column(children: [
                                Text(cx.tr("notes.summary.waiting").replace("{count}", &waiting_count.to_string()))
                                    .weight(tokens.typography.font_weight_semibold),
                                Text(cx.tr("notes.summary.sync"))
                                    .color(tokens.colors.text_secondary),
                            ]),
                        ],
                    ),
                    Divider(),
                            Column(gap: tokens.spacing.s, children: [
                                Text(cx.tr("notes.list.title"))
                                    .weight(tokens.typography.font_weight_semibold),
                                Text(cx.tr("notes.list.hint"))
                                    .color(tokens.colors.text_secondary),
                                if notes.is_empty() {
                                    EmptyState(
                                        title: cx.tr("notes.empty.first_title"),
                                        description: Some(cx.tr("notes.empty.first_note")),
                                    )
                                } else {
                                    Column(gap: tokens.spacing.s, children: [
                                        for note in notes.iter() {
                                            FieldNoteListItem(
                                                note.clone(),
                                                Some(note.id) == selected_id,
                                                key: note.id,
                                            ).id(WidgetId::explicit(&format!("field-note.{}", note.id)))
                                        },
                                    ])
                                },
                    ]),
                    if let Some(selected) = selected {
                        Container(
                            Column(gap: tokens.spacing.s, children: [
                                Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                                    Text(cx.tr(&selected.site))
                                        .color(tokens.colors.text_secondary),
                                    Spacer(flex_grow: 1.0),
                                    Text(cx.tr(selected.sync_status.translation_key())),
                                ]),
                                Text(cx.tr(&selected.title))
                                    .weight(tokens.typography.font_weight_bold),
                                Text(cx.tr(&selected.observation)),
                                Text(cx.tr("notes.updated_revision")
                                    .replace("{time}", &cx.tr(&selected.updated_at))
                                    .replace("{revision}", &selected.revision.to_string()))
                                    .color(tokens.colors.text_secondary),
                            ]),
                        )
                        .padding_all(tokens.spacing.l)
                        .bg(tokens.colors.surface)
                        .border(tokens.colors.border, 1.0)
                        .border_radius(tokens.radii.large)
                    } else {
                        Text(cx.tr("notes.detail.none"))
                            .color(tokens.colors.text_secondary)
                    },
                ]),
            )
            .padding_all(tokens.spacing.l)
            .bg(tokens.colors.background),
        ),
    )
}
```

## Create, search, and edit notes without a connection

The list and detail panel both read `FieldNotesState`. Selecting a row changes the selected note ID; editing creates a new revision. **Save on this device** updates the local working copy and marks it waiting to sync. It does not claim a server accepted anything.

Search belongs to the workspace because it only changes which rows are visible. Notes, the selected ID, and edit draft belong in app state because several parts of the screen use them. The selected ID is an `Option<i64>`: `None` means no note is selected, so the app does not reserve a magic database ID such as zero. Starting a new note clears search so the new record stays visible after saving. A technician can write and save before the phone has a signal. A blank title, site, or observation keeps the draft open and explains what to fix.

The save reducer validates the draft, assigns a stable ID to a new note, increments the revision on edit, and keeps sync status truthful. Selecting another row is disabled while a draft is open, so an unfinished observation can’t disappear after an accidental tap.

```rust
#[fission_reducer(SelectFieldNote)]
pub fn on_select_field_note(state: &mut FieldNotesState, note_id: i64) {
    if state.is_editing || state.is_saving {
        return;
    }
    if state.notes.iter().any(|note| note.id == note_id) {

    state.observation_draft.clear();

#[fission_reducer(BeginEditFieldNote)]
pub fn on_begin_edit_field_note(state: &mut FieldNotesState, note_id: i64) {
    if state.is_editing || state.is_saving {
        return;
    }
    let Some(note) = state.notes.iter().find(|note| note.id == note_id).cloned() else {
        state.notice = "notes.notice.missing".into();
        state.has_error = true;
        state.validation_error = false;
        return;
    };
    state.selected_note_id = Some(note_id);
    state.site_draft = note.site;
    state.title_draft = note.title;
    state.observation_draft = note.observation;
    state.is_editing = true;
    state.is_new_note = false;
    state.notice = "notes.notice.editing".into();
    state.has_error = false;
    state.validation_error = false;
}

#[fission_reducer(SaveFieldNote)]
pub fn on_save_field_note(state: &mut FieldNotesState) {
    if state.is_saving {
        return;
    }
    let site = state.site_draft.trim().to_string();
    let title = state.title_draft.trim().to_string();
    let observation = state.observation_draft.trim().to_string();
    if site.is_empty() || title.is_empty() || observation.is_empty() {
        state.notice = "notes.notice.required".into();
        state.has_error = true;
        state.validation_error = true;
        return;
    }

    let saved_id = if state.is_new_note {
        let id = state.next_note_id;
        state.next_note_id = state.next_note_id.saturating_add(1);
        state.notes.push(FieldNote {
            id,
            site,
            title,
            observation,
            updated_at: "notes.time.just_now".into(),
            revision: 1,
            sync_status: NoteSyncStatus::WaitingToSync,
        });
        id
    } else {
        let Some(note) = state.notes.iter_mut()
            .find(|note| Some(note.id) == state.selected_note_id)
        else {
            state.notice = "notes.notice.not_available".into();
            state.has_error = true;
            state.validation_error = false;
            return;
        };
        if note.site == site && note.title == title && note.observation == observation {
            state.site_draft.clear();
            state.title_draft.clear();
            state.observation_draft.clear();
            state.is_editing = false;
            state.is_new_note = false;
            state.notice = "notes.notice.no_changes".into();
            state.has_error = false;
            state.validation_error = false;
            return;
        }
        note.site = site;
        note.title = title;
        note.observation = observation;
        note.updated_at = "notes.time.just_now".into();
        note.revision = note.revision.saturating_add(1);
        note.sync_status = NoteSyncStatus::WaitingToSync;
        note.id
    };

    state.selected_note_id = Some(saved_id);
    state.site_draft.clear();
    state.title_draft.clear();
    state.observation_draft.clear();
    state.is_editing = false;
    state.is_new_note = false;
    state.has_error = false;
    state.validation_error = false;
    let waiting = state.notes.iter()
        .filter(|note| note.sync_status == NoteSyncStatus::WaitingToSync)
        .count();
    state.notice = format!("notes.notice.saved_waiting|{waiting}");
}

#[fission_reducer(CancelFieldNoteDraft)]
pub fn on_cancel_field_note_draft(state: &mut FieldNotesState) {
    if state.is_saving {

    }
    state.site_draft.clear();
    state.title_draft.clear();
    state.observation_draft.clear();
    state.pending_note = None;
    state.is_editing = false;
    state.is_new_note = false;
    state.notice = "notes.notice.draft_discarded".into();
    state.has_error = false;
    state.validation_error = false;
}
```

## Persist each revision and ignore stale sync results

The browser preview keeps edits in memory and starts with three sample site visits. The native app should start with an empty list and load notes from SQLite; sample visits belong in an explicit demo mode, not in a technician’s work history. In the native app, **Saved on this device** means SQLite committed the note. A network effect should only start after that commit succeeds. This tutorial leaves that effect and its server endpoint out, so notes remain waiting to sync. If the local write fails, keep the editor open and report the storage error; don’t say the note was saved.

Start with a migration for the note ID, worksite, title, observation, revision, and sync status. The revision matters: if revision 5 is sent while the technician writes revision 6, a late response for revision 5 must not mark the newer text as synced. SQLite stores `updated_at` as UTC text; format it for the device’s locale before showing it. The browser preview uses shorter display strings to keep the example focused on editing and sync state.

```rust
#[fission_reducer(PrepareFieldNotes)]
pub fn prepare_field_notes(
    _state: &mut FieldNotesState,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    _state.is_loading = true;
    _state.has_error = false;
    let mut migrations = SqlMigrations::new();
    migrations.add(SqlMigration::new(
        1,
        "create field notes",
        "CREATE TABLE field_notes (
            id INTEGER PRIMARY KEY,
            site TEXT NOT NULL CHECK (length(trim(site)) > 0),
            title TEXT NOT NULL CHECK (length(trim(title)) > 0),
            observation TEXT NOT NULL CHECK (length(trim(observation)) > 0),
            revision INTEGER NOT NULL DEFAULT 1 CHECK (revision > 0),
            sync_status TEXT NOT NULL DEFAULT 'waiting',
            updated_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
        );
        CREATE INDEX field_notes_site_updated_idx
            ON field_notes(site, updated_at DESC);",
    )).expect("migration versions are unique");

    ctx.effects.sql().migrate(migrations)
        .on_ok(ActionEnvelope::from(LoadFieldNotes))
        .on_err(ActionEnvelope::from(FieldNotesStorageFailed));
```

```rust
#[fission_reducer(LoadFieldNotes)]
pub fn load_field_notes(
    _state: &mut FieldNotesState,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    ctx.effects.sql().query(SqlStatement::new(
        "SELECT id, site, title, observation, revision, sync_status, updated_at
         FROM field_notes
         ORDER BY updated_at DESC, id DESC",
    ))
    .on_ok(ActionEnvelope::from(FieldNotesLoaded))
    .on_err(ActionEnvelope::from(FieldNotesStorageFailed));
}

#[fission_reducer(FieldNotesLoaded)]
pub fn field_notes_loaded(
    state: &mut FieldNotesState,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    let Some(rows) = ctx.input.sql_rows() else {
        state.is_loading = false;
        state.has_error = true;
        state.notice = "notes.notice.sqlite_empty".into();
        return;
    };
    let loaded_notes: Result<Vec<FieldNote>, String> = rows.rows.iter().map(|row| {
        let id = row.get::<i64>("id").map_err(|error| error.to_string())?;
        let site = row.get::<String>("site").map_err(|error| error.to_string())?;
        let title = row.get::<String>("title").map_err(|error| error.to_string())?;
        let observation = row.get::<String>("observation")
            .map_err(|error| error.to_string())?;
        let revision = u32::try_from(
            row.get::<i64>("revision").map_err(|error| error.to_string())?,
        )
        .map_err(|_| "revision is outside the supported range".to_string())?;
        let status = row.get::<String>("sync_status")
            .map_err(|error| error.to_string())?;
        let sync_status = match status.as_str() {
            "synced" => NoteSyncStatus::Synced,
            "waiting" => NoteSyncStatus::WaitingToSync,
            other => return Err(format!("unknown sync status `{other}`")),
        };
        let updated_at = row.get::<String>("updated_at")
            .map_err(|error| error.to_string())?;
        Ok(FieldNote {
            id,
            site,
            title,
            observation,
            updated_at,
            revision,
            sync_status,
        })
    }).collect();

    state.notes = match loaded_notes {
        Ok(notes) => notes,
        Err(_error) => {
            state.is_loading = false;
            state.has_error = true;
            state.validation_error = false;
            state.notice = "notes.notice.read_failed".into();
            return;
        }
    };
    state.next_note_id = state.notes.iter()
        .map(|note| note.id)
        .max()
        .unwrap_or(0)
        .saturating_add(1);
    state.is_loading = false;
    state.has_error = false;

    if let Some(note) = state.notes.first() {
        state.selected_note_id = Some(note.id);
    }
}

#[fission_reducer(FieldNotesStorageFailed)]
pub fn field_notes_storage_failed(
    state: &mut FieldNotesState,
    _ctx: &mut ReducerContext<FieldNotesState>,
) {
    state.is_loading = false;
    state.is_saving = false;
    state.pending_note = None;
    state.has_error = true;
    state.validation_error = false;
    state.notice = "notes.notice.storage_failed".into();
}
```

```rust
#[fission_reducer(SaveFieldNoteToSqlite)]
pub fn save_field_note_to_sqlite(
    state: &mut FieldNotesState,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    if state.is_saving || !state.is_editing {
        return;
    }

    let site = state.site_draft.trim().to_string();
    let title = state.title_draft.trim().to_string();
    let observation = state.observation_draft.trim().to_string();
    if site.is_empty() || title.is_empty() || observation.is_empty() {
        state.notice = "notes.notice.required".into();
        state.has_error = true;
        state.validation_error = true;
        return;
    }

    let is_new_note = state.is_new_note;
    let (note_id, revision) = if is_new_note {
        (state.next_note_id, 1)
    } else {
        let Some(current) = state.notes.iter()
            .find(|note| Some(note.id) == state.selected_note_id)
        else {
            state.notice = "notes.notice.not_available".into();
            state.has_error = true;
            state.validation_error = false;
            return;
        };
        (current.id, current.revision.saturating_add(1))
    };

    let note = FieldNote {
        id: note_id,
        site,
        title,
        observation,
        updated_at: "notes.time.just_now".into(),
        revision,
        sync_status: NoteSyncStatus::WaitingToSync,
    };
    let statement = SqlStatement::new(
        "INSERT INTO field_notes
            (id, site, title, observation, revision, sync_status, updated_at)
         VALUES (:id, :site, :title, :observation, :revision, 'waiting', CURRENT_TIMESTAMP)
         ON CONFLICT(id) DO UPDATE SET
            site = excluded.site,
            title = excluded.title,
            observation = excluded.observation,
            revision = excluded.revision,
            sync_status = 'waiting',
            updated_at = CURRENT_TIMESTAMP
         WHERE excluded.revision > field_notes.revision",
    )
    .bind_named(":id", note.id)
    .bind_named(":site", note.site.clone())
    .bind_named(":title", note.title.clone())
    .bind_named(":observation", note.observation.clone())
    .bind_named(":revision", i64::from(note.revision));

    state.pending_note = Some(note.clone());
    state.is_saving = true;
    state.has_error = false;
    state.validation_error = false;
    state.notice = "notes.notice.saving".into();
    ctx.effects.sql().execute(statement)
        .on_ok(ActionEnvelope::from(FieldNoteStored(note.id, note.revision)))
        .on_err(ActionEnvelope::from(FieldNotesStorageFailed));
}

#[fission_reducer(FieldNoteStored)]
pub fn field_note_stored(
    state: &mut FieldNotesState,
    note_id: i64,
    revision: u32,
) {
    let Some(note) = state.pending_note.take() else { return; };
    if note.id != note_id || note.revision != revision {
        state.pending_note = Some(note);
        return;
    }
    if state.is_new_note {
        state.next_note_id = state.next_note_id.saturating_add(1);
        state.notes.push(note);
    } else if let Some(current) = state.notes.iter_mut().find(|note| note.id == note_id) {
        *current = note;
    } else {
        state.is_saving = false;
        state.has_error = true;
        state.validation_error = false;
        state.notice = "notes.notice.saved_not_visible".into();
        return;
    }

    state.selected_note_id = Some(note_id);
    state.site_draft.clear();
    state.title_draft.clear();
    state.observation_draft.clear();
    state.is_editing = false;
    state.is_new_note = false;
    state.is_saving = false;
    state.has_error = false;
    state.validation_error = false;
    state.notice = "notes.notice.saved_on_device".into();
}
```

```rust
#[fission_reducer(SyncNoteSucceeded)]
pub fn on_sync_note_succeeded(
    state: &mut FieldNotesState,
    note_id: i64,
    sent_revision: u32,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    let Some(note) = state.notes.iter().find(|note| note.id == note_id) else {
        return;
    };

    if note.revision != sent_revision {
        return;
    }

    let statement = SqlStatement::new(
        "UPDATE field_notes
         SET sync_status = 'synced'
         WHERE id = :id AND revision = :revision",
    )
    .bind_named(":id", note_id)
    .bind_named(":revision", i64::from(sent_revision));

    ctx.effects.sql().execute(statement)
        .on_ok(ActionEnvelope::from(FieldNoteSyncStatusStored(note_id, sent_revision)))
        .on_err(ActionEnvelope::from(FieldNotesStorageFailed));
}

#[fission_reducer(FieldNoteSyncStatusStored)]
pub fn field_note_sync_status_stored(
    state: &mut FieldNotesState,
    note_id: i64,
    sent_revision: u32,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    let Some(result) = ctx.input.sql_execute_result() else { return; };
    if result.affected_rows == 0 {
        state.notice = "notes.notice.newer_revision".into();
        return;
    }
    let Some(note) = state.notes.iter_mut().find(|note| note.id == note_id) else {
        return;
    };
    if note.revision == sent_revision {
        note.sync_status = NoteSyncStatus::Synced;
    }
}
```

The preview’s **Save on this device** reducer updates memory because there is no native storage host. In the native app, bind the button to `SaveFieldNoteToSqlite`. It validates and snapshots the draft, disables editing during the write, and updates the visible note only after `FieldNoteStored` confirms the commit. The SQLite effect runs outside the reducer, so it doesn’t block a frame. On failure, `FieldNotesStorageFailed` re-enables the editor and keeps the draft. This tutorial does not send a sync request. When you add a network effect, send the note ID and revision and dispatch `SyncNoteSucceeded` only after the service confirms that revision. The reducers check that revision before the local status write, in the SQL `WHERE` clause, and again before updating the visible note.

Test the boundary deliberately: store revision 5, edit and store revision 6, then dispatch the `SyncNoteSucceeded` completion for revision 5. The visible text must stay at revision 6 and remain waiting to sync. Also test an empty database, a failed local write, and a process restart with a pending revision. A successful remote sync requires a real service effect, which is outside this tutorial.

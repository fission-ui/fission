## Create a shared field-notes project

Install Fission, create the project, and add both native targets. Shared screens and note behavior live in Rust so the Android and iOS builds use the same workflow.

```sh
cargo install cargo-fission
fission init field-notes
cd field-notes
fission add-target android ios --project-dir .
fission add-capability storage --project-dir .
```

## Shape a note around a real field visit

Between sites, a technician needs to know which job a note belongs to, what they saw, when they recorded it, and whether it still needs to sync. A title and paragraph stop being enough once the notebook has more than a few entries.

We’ll build **Harbour Field Notes** for a maintenance crew. Each record has a stable ID, worksite, title, observation, update time, local revision, and sync status. The sample notes cover a gate inspection, rooftop inverter, and loading-dock drain. That gives the list and detail view something useful to show before we add editing.

Start with the record type and a screen that helps the technician find a note. `FieldNoteListItem` and `FieldNotesWorkspace` are named `fission_component!` components, so the screen has reusable boundaries instead of one anonymous tree.

## Create, search, and edit notes without a connection

The list and detail panel both read `FieldNotesState`. Selecting a row changes the selected note ID; editing creates a new revision. **Save on this device** updates the local working copy and marks it waiting to sync. It does not claim a server accepted anything.

Search belongs to the workspace because it only changes which rows are visible. Notes, the selected ID, and edit draft belong in app state because several parts of the screen use them. Starting a new note clears search so the new record stays visible after saving. A technician can write and save before the phone has a signal. A blank title, site, or observation keeps the draft open and explains what to fix.

The save reducer validates the draft, assigns a stable ID to a new note, increments the revision on edit, and keeps sync status truthful. Selecting another row is disabled while a draft is open, so an unfinished observation can’t disappear after an accidental tap.

```rust
fn matches_note(note: &FieldNote, query: &str) -> bool {
    query.is_empty()
        || note.site.to_lowercase().contains(query)
        || note.title.to_lowercase().contains(query)
        || note.observation.to_lowercase().contains(query)
}

#[derive(Clone, Debug, PartialEq)]
pub struct FieldNotesState {
    pub notes: Vec<FieldNote>,
    pub selected_note_id: i64,
    pub next_note_id: i64,
    pub pending_note: Option<FieldNote>,
    pub site_draft: String,
    pub title_draft: String,
    pub observation_draft: String,
    pub is_editing: bool,
    pub is_new_note: bool,
    pub is_saving: bool,
    pub is_loading: bool,
    pub notice: String,
    pub has_error: bool,
    pub validation_error: bool,
}

impl Default for FieldNotesState {
    fn default() -> Self {
        Self {
            notes: sample_notes(),
            selected_note_id: 501,
            next_note_id: 504,
            pending_note: None,
            site_draft: String::new(),
            title_draft: String::new(),
            observation_draft: String::new(),
            is_editing: false,
            is_new_note: false,
            is_saving: false,
            is_loading: false,
            notice: "Your field notes are available on this device.".into(),
            has_error: false,
            validation_error: false,
        }
    }
}

impl GlobalState for FieldNotesState {}

#[fission_reducer(SelectFieldNote)]
pub fn on_select_field_note(state: &mut FieldNotesState, note_id: i64) {
    if state.is_editing || state.is_saving {
        return;
    }
    if state.notes.iter().any(|note| note.id == note_id) {
        state.selected_note_id = note_id;
        state.notice.clear();
        state.has_error = false;
        state.validation_error = false;
    }
}

fn start_new_field_note(state: &mut FieldNotesState) {
    if state.is_editing || state.is_saving {
        return;
    }
    state.site_draft = "North Yard".into();
    state.title_draft.clear();
    state.observation_draft.clear();
    state.pending_note = None;
    state.is_editing = true;
    state.is_new_note = true;
    state.notice = "Add the site, a short title, and what you observed.".into();
    state.has_error = false;
    state.validation_error = false;
}

#[fission_reducer(BeginNewFieldNote)]
pub fn on_begin_new_field_note(
    state: &mut FieldNotesState,
    _ctx: &mut ReducerContext<FieldNotesState>,
) {
    start_new_field_note(state);
}

#[fission_reducer(BeginEditFieldNote)]
pub fn on_begin_edit_field_note(state: &mut FieldNotesState, note_id: i64) {
    if state.is_editing || state.is_saving {
        return;
    }
    let Some(note) = state.notes.iter().find(|note| note.id == note_id).cloned() else {
        state.notice = "That note is no longer available.".into();
        state.has_error = true;
        state.validation_error = false;
        return;
    };
    state.selected_note_id = note_id;
    state.site_draft = note.site;
    state.title_draft = note.title;
    state.observation_draft = note.observation;
    state.is_editing = true;
    state.is_new_note = false;
    state.notice = "Edits stay on this device until they can sync.".into();
    state.has_error = false;
    state.validation_error = false;
}

#[fission_reducer(SaveFieldNote)]
pub fn on_save_field_note(state: &mut FieldNotesState) {
    if state.is_saving {
        return;
    }
    let site = state.site_draft.trim().to_string();
    let title = state.title_draft.trim().to_string();
    let observation = state.observation_draft.trim().to_string();
    if site.is_empty() || title.is_empty() || observation.is_empty() {
        state.notice = concat!(
            "Add a site, title, and observation ",
            "before saving this note.",
        ).into();
        state.has_error = true;
        state.validation_error = true;
        return;
    }

    let saved_id = if state.is_new_note {
        let id = state.next_note_id;
        state.next_note_id = state.next_note_id.saturating_add(1);
        state.notes.push(FieldNote {
            id,
            site,
            title,
            observation,
            updated_at: "Just now".into(),
            revision: 1,
            sync_status: NoteSyncStatus::WaitingToSync,
        });
        id
    } else {
        let Some(note) = state.notes.iter_mut()
            .find(|note| note.id == state.selected_note_id)
        else {
            state.notice = concat!(
                "That note is no longer available. Keep the text ",
                "and choose another note.",
            ).into();
            state.has_error = true;
            state.validation_error = false;
            return;
        };
        if note.site == site && note.title == title && note.observation == observation {
            state.site_draft.clear();
            state.title_draft.clear();
            state.observation_draft.clear();
            state.is_editing = false;
            state.is_new_note = false;
            state.notice = "No changes to save.".into();
            state.has_error = false;
            state.validation_error = false;
            return;
        }
        note.site = site;
        note.title = title;
        note.observation = observation;
        note.updated_at = "Just now".into();
        note.revision = note.revision.saturating_add(1);
        note.sync_status = NoteSyncStatus::WaitingToSync;
        note.id
    };

    state.selected_note_id = saved_id;
    state.site_draft.clear();
    state.title_draft.clear();
    state.observation_draft.clear();
    state.is_editing = false;
    state.is_new_note = false;
    state.has_error = false;
    state.validation_error = false;
    let waiting = state.notes.iter()
        .filter(|note| note.sync_status == NoteSyncStatus::WaitingToSync)
        .count();
    state.notice = format!(
        "Saved on this device. {} {} waiting to sync.",
        waiting,
        if waiting == 1 { "note is" } else { "notes are" },
    );
}

#[fission_reducer(CancelFieldNoteDraft)]
pub fn on_cancel_field_note_draft(state: &mut FieldNotesState) {
    if state.is_saving {
        return;
    }
    state.site_draft.clear();
    state.title_draft.clear();
    state.observation_draft.clear();
    state.pending_note = None;
    state.is_editing = false;
    state.is_new_note = false;
    state.notice = "The draft was discarded; saved notes are unchanged.".into();
    state.has_error = false;
    state.validation_error = false;
}
```

## Persist each revision and ignore stale sync results

The browser preview keeps edits in memory and starts with three sample site visits. The native app should start with an empty list and load notes from SQLite; sample visits belong in an explicit demo mode, not in a technician’s work history. In the native app, **Saved on this device** means SQLite committed the note. Only then can an upload job sync that revision. If the write fails, keep the editor open and report the storage error; don’t say the note was saved.

Start with a migration for the note ID, worksite, title, observation, revision, and sync status. The revision matters: if revision 5 is sent while the technician writes revision 6, a late response for revision 5 must not mark the newer text as synced. SQLite stores `updated_at` as UTC text; format it for the device’s locale before showing it. The browser preview uses shorter display strings to keep the example focused on editing and sync state.

```rust
    ctx: &mut ReducerContext<FieldNotesState>,

            id INTEGER PRIMARY KEY,
            site TEXT NOT NULL CHECK (length(trim(site)) > 0),
            title TEXT NOT NULL CHECK (length(trim(title)) > 0),
            observation TEXT NOT NULL CHECK (length(trim(observation)) > 0),
            revision INTEGER NOT NULL DEFAULT 1 CHECK (revision > 0),
            sync_status TEXT NOT NULL DEFAULT 'waiting',

            ON field_notes(site, updated_at DESC);",

    ctx.effects.sql().migrate(migrations)
```

```rust
#[fission_reducer(LoadFieldNotes)]
pub fn load_field_notes(
    _state: &mut FieldNotesState,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    ctx.effects.sql().query(SqlStatement::new(
        "SELECT id, site, title, observation, revision, sync_status, updated_at
         FROM field_notes
         ORDER BY updated_at DESC, id DESC",
    ))
    .on_ok(ActionEnvelope::from(FieldNotesLoaded))
    .on_err(ActionEnvelope::from(FieldNotesStorageFailed));
}

#[fission_reducer(FieldNotesLoaded)]
pub fn field_notes_loaded(
    state: &mut FieldNotesState,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    let Some(rows) = ctx.input.sql_rows() else {
        state.is_loading = false;
        state.has_error = true;
        state.notice = "SQLite returned no field-note result.".into();
        return;
    };
    let loaded_notes: Result<Vec<FieldNote>, String> = rows.rows.iter().map(|row| {
        let id = row.get::<i64>("id").map_err(|error| error.to_string())?;
        let site = row.get::<String>("site").map_err(|error| error.to_string())?;
        let title = row.get::<String>("title").map_err(|error| error.to_string())?;
        let observation = row.get::<String>("observation")
            .map_err(|error| error.to_string())?;
        let revision = u32::try_from(
            row.get::<i64>("revision").map_err(|error| error.to_string())?,
        )
        .map_err(|_| "revision is outside the supported range".to_string())?;
        let status = row.get::<String>("sync_status")
            .map_err(|error| error.to_string())?;
        let sync_status = match status.as_str() {
            "synced" => NoteSyncStatus::Synced,
            "waiting" => NoteSyncStatus::WaitingToSync,
            other => return Err(format!("unknown sync status `{other}`")),
        };
        let updated_at = row.get::<String>("updated_at")
            .map_err(|error| error.to_string())?;
        Ok(FieldNote {
            id,
            site,
            title,
            observation,
            updated_at,
            revision,
            sync_status,
        })
    }).collect();

    state.notes = match loaded_notes {
        Ok(notes) => notes,
        Err(error) => {
            state.is_loading = false;
            state.has_error = true;
            state.validation_error = false;
            state.notice = format!("A saved field note could not be read: {error}");
            return;
        }
    };
    state.next_note_id = state.notes.iter()
        .map(|note| note.id)
        .max()
        .unwrap_or(0)
        .saturating_add(1);
    state.is_loading = false;
    state.has_error = false;

    if let Some(note) = state.notes.first() {
        state.selected_note_id = note.id;
    }
}

#[fission_reducer(FieldNotesStorageFailed)]
pub fn field_notes_storage_failed(
    state: &mut FieldNotesState,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    state.is_loading = false;
    state.is_saving = false;
    state.pending_note = None;

}
```

```rust
#[fission_reducer(SaveFieldNoteToSqlite)]
pub fn save_field_note_to_sqlite(
    state: &mut FieldNotesState,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    if state.is_saving || !state.is_editing {
        return;
    }

    let site = state.site_draft.trim().to_string();
    let title = state.title_draft.trim().to_string();
    let observation = state.observation_draft.trim().to_string();
    if site.is_empty() || title.is_empty() || observation.is_empty() {
        state.notice = "Add a site, title, and observation before saving.".into();
        state.has_error = true;
        state.validation_error = true;
        return;
    }

    let is_new_note = state.is_new_note;
    let (note_id, revision) = if is_new_note {
        (state.next_note_id, 1)
    } else {
        let Some(current) = state.notes.iter()
            .find(|note| note.id == state.selected_note_id)
        else {
            state.notice = "That note is no longer available. Keep the draft and try again.".into();
            state.has_error = true;
            state.validation_error = false;
            return;
        };
        (current.id, current.revision.saturating_add(1))
    };

    let note = FieldNote {
        id: note_id,
        site,
        title,
        observation,
        updated_at: "Just now".into(),
        revision,
        sync_status: NoteSyncStatus::WaitingToSync,
    };
    let statement = SqlStatement::new(
        "INSERT INTO field_notes
            (id, site, title, observation, revision, sync_status, updated_at)
         VALUES (:id, :site, :title, :observation, :revision, 'waiting', CURRENT_TIMESTAMP)
         ON CONFLICT(id) DO UPDATE SET
            site = excluded.site,
            title = excluded.title,
            observation = excluded.observation,
            revision = excluded.revision,
            sync_status = 'waiting',
            updated_at = CURRENT_TIMESTAMP
         WHERE excluded.revision > field_notes.revision",
    )
    .bind_named(":id", note.id)
    .bind_named(":site", note.site.clone())
    .bind_named(":title", note.title.clone())
    .bind_named(":observation", note.observation.clone())
    .bind_named(":revision", i64::from(note.revision));

    state.pending_note = Some(note.clone());
    state.is_saving = true;
    state.has_error = false;
    state.validation_error = false;
    state.notice = "Saving this note to SQLite…".into();
    ctx.effects.sql().execute(statement)
        .on_ok(ActionEnvelope::from(FieldNoteStored(note.id, note.revision)))
        .on_err(ActionEnvelope::from(FieldNotesStorageFailed));
}

#[fission_reducer(FieldNoteStored)]
pub fn field_note_stored(
    state: &mut FieldNotesState,
    note_id: i64,
    revision: u32,
) {
    let Some(pending) = state.pending_note.as_ref() else { return; };
    if pending.id != note_id || pending.revision != revision {
        return;
    }
    let note = state.pending_note.take().expect("pending note was checked");
    if state.is_new_note {
        state.next_note_id = state.next_note_id.saturating_add(1);
        state.notes.push(note);
    } else if let Some(current) = state.notes.iter_mut().find(|note| note.id == note_id) {
        *current = note;
    } else {
        state.is_saving = false;
        state.has_error = true;
        state.validation_error = false;
        state.notice = "The note was saved, but it is no longer in this view. Reload the list.".into();
        return;
    }

    state.selected_note_id = note_id;
    state.site_draft.clear();
    state.title_draft.clear();
    state.observation_draft.clear();
    state.is_editing = false;
    state.is_new_note = false;
    state.is_saving = false;
    state.has_error = false;
    state.validation_error = false;
    state.notice = "Saved on this device. This note is waiting to sync.".into();
}
```

```rust
#[fission_reducer(SyncNoteSucceeded)]
pub fn on_sync_note_succeeded(
    state: &mut FieldNotesState,
    note_id: i64,
    sent_revision: u32,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    let Some(note) = state.notes.iter().find(|note| note.id == note_id) else {
        return;
    };

    if note.revision != sent_revision {
        return;
    }

    let statement = SqlStatement::new(
        "UPDATE field_notes
         SET sync_status = 'synced'
         WHERE id = :id AND revision = :revision",
    )
    .bind_named(":id", note_id)
    .bind_named(":revision", i64::from(sent_revision));

    ctx.effects.sql().execute(statement)
        .on_ok(ActionEnvelope::from(FieldNoteSyncStatusStored(note_id, sent_revision)))
        .on_err(ActionEnvelope::from(FieldNotesStorageFailed));
}

#[fission_reducer(FieldNoteSyncStatusStored)]
pub fn field_note_sync_status_stored(
    state: &mut FieldNotesState,
    note_id: i64,
    sent_revision: u32,
    ctx: &mut ReducerContext<FieldNotesState>,
) {
    let Some(result) = ctx.input.sql_execute_result() else { return; };
    if result.affected_rows == 0 {
        state.notice = "A newer saved revision was found. Reload it before syncing.".into();
        return;
    }
    let Some(note) = state.notes.iter_mut().find(|note| note.id == note_id) else {
        return;
    };
    if note.revision == sent_revision {
        note.sync_status = NoteSyncStatus::Synced;
    }
}
```

The preview’s **Save on this device** reducer updates memory because there is no native storage host. In the native app, bind the button to `SaveFieldNoteToSqlite`. It validates and snapshots the draft, disables editing during the write, and updates the visible note only after `FieldNoteStored` confirms the commit. The SQLite effect runs outside the reducer, so it doesn’t block a frame. On failure, `FieldNotesStorageFailed` re-enables the editor and keeps the draft. The sync job sends the note ID and revision; success returns both. The reducers check that revision before the write, in the SQL `WHERE` clause, and again before marking the note synced.

Test the boundary deliberately: send revision 5, edit the note to revision 6, then deliver revision 5’s success. The visible text must stay at revision 6 and remain waiting to sync. Also test an empty database, a failed local write, an offline save, and a process restart with a pending revision.

### Run the shared app on Android and iOS

Register the result reducers in `FieldNotesWorkspace::view` as shown above, then start the same mobile core on Android and iOS. `with_startup_action` dispatches the migration action after Fission builds the widget registry; `with_state_init` removes the browser preview records and shows the loading state before the first frame. The migration then loads the technician's saved notes from SQLite.

Run the target commands from the project root. `fission doctor` checks the installed toolchains, and `fission test` verifies that each generated host can launch the shared app.

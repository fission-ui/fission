A project rename changes two facts: the current name and the record explaining
what changed. If they are written separately, a failure between the writes can
leave one without the other. A transaction makes that pair the unit of work.

This small project ledger starts empty. Create a project, rename it, and inspect
the number of recorded changes. Both the browser preview and native app use
actual SQLite effects. There is no button that toggles a fake transaction result.

## Create the project and add the target

Use the [iOS setup guide](/blog/set-up-rust-ios-development-with-fission/) for
Xcode and Simulator prerequisites.

```sh
cargo install cargo-fission
fission init project-ledger
cd project-ledger
cargo add serde_yaml
fission add-target ios --project-dir .
fission add-capability storage --project-dir .
```

## Migrate, then load the ledger

Migration 1 creates projects. Migration 2 adds the audit table. Applying them
before the first query gives both a fresh database and a database at version 1
a defined path to the current schema. Do not edit a migration already applied
to users' databases; add another version.

The app disables edits until loading succeeds. A failed query is not an empty
ledger, and a partial decode is not a successful list. This teaching app checks
up to 200 projects rather than silently truncating a larger result.

use fission::prelude::*;

#[derive(Clone, Debug, PartialEq)]
pub struct Project { pub id: i64, pub name: String, pub changes: i64 }

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Phase { Loading, Ready, Writing, Refreshing, Failed }

#[derive(Clone, Debug, PartialEq)]
pub struct LedgerState {
    pub projects: Vec<Project>,
    pub draft: String,
    pub editing: Option<i64>,
    pub phase: Phase,
    pub error: Option<String>,
}
impl Default for LedgerState {
    fn default() -> Self {
        Self { projects: Vec::new(), draft: String::new(), editing: None, phase: Phase::Loading, error: None }
    }
}
impl GlobalState for LedgerState {}

pub fn checked_name(value: &str) -> Option<String> {
    let value = value.trim();
    (1..=120).contains(&value.chars().count()).then(|| value.to_owned())
}

#[fission_reducer(EditProject)]
pub fn edit_project(state: &mut LedgerState, id: i64) {
    if state.phase != Phase::Ready { return; }
    if let Some(project) = state.projects.iter().find(|project| project.id == id) {
        state.editing = Some(id);
        state.draft = project.name.clone();
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn blank_and_overlong_names_are_not_written() {
        assert!(checked_name("  ").is_none());
        assert!(checked_name(&"x".repeat(121)).is_none());
        assert_eq!(checked_name(" Harbour plan "), Some("Harbour plan".into()));
    }
    #[test]
    fn names_are_user_data_not_translation_keys() {
        assert_eq!(checked_name("ledger.title"), Some("ledger.title".into()));
        assert_eq!(checked_name("Planificación"), Some("Planificación".into()));
    }
}

use fission::prelude::*;
use crate::state::{checked_name, LedgerState, Phase, Project};

fn query(state: &mut LedgerState, cx: &mut ReducerContext<LedgerState>) {
    let loaded = cx.effects.bind(ProjectsLoaded, reduce!(projects_loaded));
    let failed = cx.effects.bind(DatabaseFailed, reduce!(database_failed));
    cx.effects.sql().query(SqlStatement::new(
        "SELECT p.id, p.name, (SELECT count(*) FROM project_changes a WHERE a.project_id = p.id) AS changes
         FROM ledger_projects p ORDER BY p.id DESC LIMIT 201"
    )).on_ok(loaded).on_err(failed);
    let _ = state;
}

#[fission_reducer(PrepareLedger)]
pub fn prepare(state: &mut LedgerState, cx: &mut ReducerContext<LedgerState>) {
    if matches!(state.phase, Phase::Writing | Phase::Refreshing) { return; }
    state.phase = Phase::Loading;
    state.error = None;
    let mut migrations = SqlMigrations::new();
    migrations.add(SqlMigration::new(1, "projects",
        "CREATE TABLE ledger_projects (id INTEGER PRIMARY KEY, name TEXT NOT NULL CHECK(length(trim(name)) BETWEEN 1 AND 120));"
    )).expect("unique migration version");
    migrations.add(SqlMigration::new(2, "project change history",
        "CREATE TABLE project_changes (
             id INTEGER PRIMARY KEY, project_id INTEGER NOT NULL REFERENCES ledger_projects(id),
             previous_name TEXT, new_name TEXT NOT NULL, changed_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
         );"
    )).expect("unique migration version");
    let ok = cx.effects.bind(LedgerPrepared, reduce!(ledger_prepared));
    let err = cx.effects.bind(DatabaseFailed, reduce!(database_failed));
    cx.effects.sql().migrate(migrations).on_ok(ok).on_err(err);
}

#[fission_reducer(LedgerPrepared)]
fn ledger_prepared(state: &mut LedgerState, cx: &mut ReducerContext<LedgerState>) { query(state, cx); }

#[fission_reducer(ProjectsLoaded)]
fn projects_loaded(state: &mut LedgerState, cx: &mut ReducerContext<LedgerState>) {
    let decoded = cx.input.sql_rows().ok_or("Missing project result".to_owned()).and_then(|rows| {
        if rows.rows.len() > 200 { return Err("This example supports at most 200 projects".into()); }
        rows.rows.into_iter().map(|row| {
            let project = Project {
                id: row.get::<i64>("id").map_err(|error| error.to_string())?,
                name: row.get::<String>("name").map_err(|error| error.to_string())?,
                changes: row.get::<i64>("changes").map_err(|error| error.to_string())?,
            };
            if project.id <= 0 || checked_name(&project.name).is_none() || project.changes < 1 {
                return Err("Malformed project record".into());
            }
            Ok(project)
        }).collect::<Result<Vec<_>, String>>()
    });
    match decoded {
        Ok(projects) => {
            if state.phase == Phase::Refreshing {
                state.draft.clear();
                state.editing = None;
            }
            state.projects = projects;
            state.phase = Phase::Ready;
        }
        Err(error) => { state.phase = Phase::Failed; state.error = Some(error); }
    }
}

pub fn save(state: &mut LedgerState, cx: &mut ReducerContext<LedgerState>) {
    if state.phase != Phase::Ready { return; }
    let Some(name) = checked_name(&state.draft) else { return; };
    if state.editing.is_none() && state.projects.len() >= 200 { return; }
    let mut transaction = SqlTransaction::new();
    match state.editing {
        None => {
            transaction.execute(SqlStatement::new("INSERT INTO ledger_projects (name) VALUES (?1)").bind(name.clone()));
            transaction.execute(SqlStatement::new(
                "INSERT INTO project_changes (project_id, previous_name, new_name) VALUES (last_insert_rowid(), NULL, ?1)"
            ).bind(name));
        }
        Some(id) => {
            transaction.execute(SqlStatement::new(
                "INSERT INTO project_changes (project_id, previous_name, new_name)
                 SELECT id, name, ?1 FROM ledger_projects WHERE id = ?2 AND name <> ?1"
            ).bind(name.clone()).bind(id));
            transaction.execute(SqlStatement::new(
                "UPDATE ledger_projects SET name = ?1 WHERE id = ?2 AND name <> ?1"
            ).bind(name).bind(id));
        }
    }
    state.phase = Phase::Writing;
    state.error = None;
    let ok = cx.effects.bind(ProjectWritten, reduce!(project_written));
    let err = cx.effects.bind(DatabaseFailed, reduce!(database_failed));
    cx.effects.sql().transaction(transaction).on_ok(ok).on_err(err);
}

#[fission_reducer(ProjectWritten)]
fn project_written(state: &mut LedgerState, cx: &mut ReducerContext<LedgerState>) {
    let valid = cx.input.sql_transaction_result().is_some_and(|result| {
        result.steps.len() == 2 && result.steps.iter().all(|step| {
            matches!(step, SqlStepResult::Execute(result) if result.affected_rows == 1)
        })
    });
    if !valid {
        state.phase = Phase::Failed;
        state.error = Some("The project changed or the expected transaction result was absent. Reload before another write.".into());
        return;
    }
    state.phase = Phase::Refreshing;
    query(state, cx);
}

#[fission_reducer(DatabaseFailed)]
fn database_failed(state: &mut LedgerState, cx: &mut ReducerContext<LedgerState>) {
    state.phase = Phase::Failed;
    state.error = Some(cx.input.sql_error().map(|error| error.to_string())
        .unwrap_or_else(|| "SQLite operation failed without a typed error".into()));
}

use fission::prelude::*;
use crate::{state::{checked_name, EditProject, edit_project, LedgerState, Phase}, storage::{prepare, save, PrepareLedger}};

fission_component! {
    pub ProjectLedger<LedgerState> {}
    view(_ledger, state, cx) {
        let _startup = cx.bind(PrepareLedger, reduce!(prepare));
        let tokens = &cx.view.env().theme.tokens;
        let ready = state.phase == Phase::Ready;
        let changed = state.editing.and_then(|id| state.projects.iter().find(|project| project.id == id))
            .is_none_or(|project| project.name != state.draft.trim());
    } =>
    SafeArea(child: Scroll(child: Container(
        Column(gap: tokens.spacing.m, children: [
            Text(cx.tr("ledger.title")).size(tokens.typography.heading2_size),
            Text(cx.tr("ledger.summary")).color(tokens.colors.text_secondary),
            if matches!(state.phase, Phase::Loading | Phase::Writing | Phase::Refreshing) {
                Spinner(motion: SpinnerMotion::Default, label: Some(cx.tr("ledger.pending")))
            },
            TextInput(
                label: Some(cx.tr("ledger.name").into()),
                bind: state.draft,
                max_length: Some(120),
                enabled: ready,
                semantics_identifier: Some("ledger.name".into()),
            ),
            Button(
                child: Text(cx.tr(if state.editing.is_some() { "ledger.rename" } else { "ledger.create" })),
                key: "write-project",
                disabled: !ready || checked_name(&state.draft).is_none() || !changed
                    || (state.editing.is_none() && state.projects.len() >= 200),
                on_press: reduce { save(state, cx); },
            ),
            if let Some(error) = &state.error {
                Column(gap: tokens.spacing.s, children: [
                    Alert(kind: AlertKind::Error, title: cx.tr("ledger.failed")),
                    Code(text: error.clone()),
                    Text(cx.tr("ledger.uncertain")),
                    Button(
                        child: Text(cx.tr("ledger.reload")),
                        key: "reload-ledger",
                        on_press: reduce {
                            state.draft.clear();
                            state.editing = None;
                            prepare(state, PrepareLedger, cx);
                        },
                    ),
                ])
            },
            if state.projects.is_empty() && ready { EmptyState(title: cx.tr("ledger.empty")) },
            for project in state.projects.iter() {
                Container(
                    Column(gap: tokens.spacing.s, children: [
                        Text(project.name.clone()).weight(tokens.typography.font_weight_semibold),
                        Text(cx.tr("ledger.changes").replace("{count}", &project.changes.to_string())),
                        Button(
                            child: Text(cx.tr("ledger.edit")),
                            key: "edit-project",
                            disabled: !ready,
                            on_press: with_reducer!(cx.build, EditProject(project.id), edit_project),
                        ),
                    ]),
                    key: project.id,
                ).padding_all(tokens.spacing.m).border(tokens.colors.border, 1.0).border_radius(tokens.radii.medium)
            },
        ])
    ).padding_all(tokens.spacing.l).max_width(720.0)))
}

pub fn create_env() -> Env {

    env.locale = Locale::from("en-US");

        ("en-US", include_str!("../i18n/en-US.yaml")),

    }
    env
}

## Bind values and commit related writes together

New projects use SQLite's generated ID. The second statement reads
`last_insert_rowid()` on that same transaction connection; it does not infer
identity from the list length. A rename records the previous database value
rather than an old UI snapshot. All user-entered text is bound as a parameter.

A failed statement rolls the transaction back. A zero-row result is different:
the statements may have run successfully but found no matching change. The
completion checks both results before reporting success and then reloads the
authoritative data. A failed or uncertain completion blocks another write; the
explicit reload action states that it discards the draft.

## Verify saved data on iOS

```sh
cargo test
fission doctor ios --project-dir .
fission devices --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
```

Test a fresh database and one with only migration 1 applied. Create and rename a
project, terminate the process and reopen it. The name and audit count should
both survive. Browser SQLite, Simulator and iPhone storage are separate; a
successful browser reload does not verify native persistence.

Use the [iPhone installation guide](/blog/install-a-fission-app-on-a-physical-iphone/)

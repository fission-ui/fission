Receiving a delivery is not just reading a barcode. The decoded value must belong to the open purchase order, and receiving another unit must not take that line beyond its ordered quantity. A camera and a keyboard are two ways to provide the SKU; they should not define two different receiving rules.

Here, the user enters an actual purchase order before receiving starts. Nothing is preloaded for the browser or hidden in a preview fixture. Counts last for this run only; durable receiving records and service-side validation are separate requirements.

## Create the Android project

Complete [Android SDK/NDK setup](/blog/set-up-rust-android-gui-development-with-fission/), then prepare [an emulator](/blog/create-and-launch-a-fission-android-emulator/) or connect [a phone](/blog/run-a-fission-app-on-a-physical-android-phone/).

```sh
cargo install cargo-fission
fission init greenway-receiving
cd greenway-receiving
cargo add serde_yaml
fission add-target android --project-dir .
fission add-capability barcode-scanner --project-dir .
```

Keep the generated `src/main.rs`. Shared state and receiving rules live in `src/app/receiving.rs`; the screen and its reusable order-entry and line components have separate files. Both native and Web entrypoints launch that same app.

The current Android barcode provider captures a still image through the camera and decodes its contents. It is not a continuous scanning view. The provider honours the requested formats and single-result choice, but currently does not apply the optional prompt or timeout, and its cancel operation does not dismiss an active capture. Do not build a time limit or a custom Cancel button around guarantees that provider does not make.

## Open an order and receive one unit at a time

The import form accepts tab-separated SKU, product and expected quantity columns. It validates the whole input before changing shared state, rejects duplicate SKUs and starts each received quantity at zero. Once an order is open, the form is removed so the user cannot accidentally replace partially received counts.

Both manual entry and the typed camera callback use `record_supplier_sku`. A successful capture does not bypass the order check, and an unreadable or unrelated label does not increment a count. Scan and manual actions are disabled whilst capture is pending; an animated spinner makes that wait visible.

use fission::prelude::*;

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct PurchaseOrderLine {
    pub sku: String,
    pub product_name: String,
    pub expected_units: u32,
    pub received_units: u32,
}

#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct ReceivingState {
    pub locale: Locale,
    pub order_reference: Option<String>,
    pub supplier_name: Option<String>,
    pub lines: Vec<PurchaseOrderLine>,
    pub scanner_busy: bool,
    pub notice: Option<ReceivingNotice>,
    pub error: Option<ReceivingIssue>,
}

impl GlobalState for ReceivingState {}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum ReceivingNotice {
    OpeningScanner,
    ScanCancelled,
    Recorded { product_name: String, received: u32, expected: u32 },
}

impl ReceivingNotice {
    pub fn translation_key(&self) -> &'static str {
        match self {
            Self::OpeningScanner => "receiving.notice.opening_scanner",
            Self::ScanCancelled => "receiving.notice.scan_cancelled",
            Self::Recorded { .. } => "receiving.notice.recorded",
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum ReceivingIssue {
    EmptySku,
    InvalidSku,
    OrderMissing,
    UnknownSku(String),
    LineFull { product_name: String, expected: u32 },
    MissingResult,
    NoLabel,
    ScannerFailed,
    CameraDenied,
    UnsupportedScanner,
    ScanTimedOut,
}

impl ReceivingIssue {
    pub fn translation_key(&self) -> &'static str {
        match self {
            Self::EmptySku => "receiving.error.empty_sku",
            Self::InvalidSku => "receiving.error.invalid_sku",
            Self::OrderMissing => "receiving.error.order_missing",
            Self::UnknownSku(_) => "receiving.error.unknown_sku",
            Self::LineFull { .. } => "receiving.error.line_full",
            Self::MissingResult => "receiving.error.missing_result",
            Self::NoLabel => "receiving.error.no_label",
            Self::ScannerFailed => "receiving.error.scanner_failed",
            Self::CameraDenied => "receiving.error.camera_denied",
            Self::UnsupportedScanner => "receiving.error.unsupported_scanner",
            Self::ScanTimedOut => "receiving.error.scan_timed_out",
        }
    }
}

#[fission_reducer(SetReceivingLocale)]
pub fn on_set_receiving_locale(state: &mut ReceivingState, locale: Locale) {
    state.locale = locale;
}

/// Apply the same checks to a manually entered SKU and a decoded barcode.
pub fn record_supplier_sku(state: &mut ReceivingState, value: &str) -> bool {
    let sku = value.trim().to_ascii_uppercase();
    if sku.is_empty() {
        state.error = Some(ReceivingIssue::EmptySku);
        state.notice = None;
        return false;
    }

    if !valid_sku(&sku) {
        state.error = Some(ReceivingIssue::InvalidSku);
        state.notice = None;
        return false;
    }

    if state.order_reference.is_none() {
        state.error = Some(ReceivingIssue::OrderMissing);
        state.notice = None;
        return false;
    }

    let Some(index) = state
        .lines
        .iter()
        .position(|line| line.sku.eq_ignore_ascii_case(&sku))
    else {
        state.error = Some(ReceivingIssue::UnknownSku(sku));
        state.notice = None;
        return false;
    };

    let result = {
        let line = &mut state.lines[index];
        if line.received_units >= line.expected_units {
            Err(ReceivingIssue::LineFull {
                product_name: line.product_name.clone(),
                expected: line.expected_units,
            })
        } else {
            line.received_units += 1;
            Ok((
                line.product_name.clone(),
                line.received_units,
                line.expected_units,
            ))
        }
    };

    let (product_name, received_units, expected_units) = match result {
        Ok(received) => received,
        Err(issue) => {
            state.error = Some(issue);
            state.notice = None;
            return false;
        }
    };

    state.error = None;
    state.notice = Some(ReceivingNotice::Recorded {
        product_name,
        received: received_units,
        expected: expected_units,
    });
    true
}

#[fission_reducer(BarcodeLabelRead)]
pub fn on_barcode_label_read(
    state: &mut ReceivingState,
    ctx: &mut ReducerContext<ReceivingState>,
) {
    if !state.scanner_busy { return; }
    state.scanner_busy = false;

    let Some(results) = ctx.input.capability_ok(SCAN_BARCODE) else {
        state.error = Some(ReceivingIssue::MissingResult);
        state.notice = None;
        return;
    };

    let Some(label) = results.items.first() else {
        state.error = Some(ReceivingIssue::NoLabel);
        state.notice = None;
        return;
    };

    record_supplier_sku(state, &label.value);
}

#[fission_reducer(BarcodeScanFailed)]
pub fn on_barcode_scan_failed(
    state: &mut ReceivingState,
    ctx: &mut ReducerContext<ReceivingState>,
) {
    if !state.scanner_busy { return; }
    state.scanner_busy = false;
    state.notice = None;

    let Some(error) = ctx.input.capability_error(SCAN_BARCODE) else {
        state.error = Some(ReceivingIssue::ScannerFailed);
        return;
    };

    if error.code == "cancelled" {
        state.error = None;
        state.notice = Some(ReceivingNotice::ScanCancelled);
        return;
    }

    state.error = Some(match error.code.as_str() {
        "permission_denied" => ReceivingIssue::CameraDenied,
        "unsupported" => ReceivingIssue::UnsupportedScanner,
        "timeout" => ReceivingIssue::ScanTimedOut,
        _ => ReceivingIssue::ScannerFailed,
    });
}

#[fission_reducer(ScanSupplierLabel)]
pub fn on_scan_supplier_label(
    state: &mut ReceivingState,
    prompt: String,
    ctx: &mut ReducerContext<ReceivingState>,
) {
    if state.scanner_busy || state.order_reference.is_none() {
        return;
    }

    state.scanner_busy = true;
    state.error = None;
    state.notice = Some(ReceivingNotice::OpeningScanner);

    let on_ok = ctx.effects.bind(
        BarcodeLabelRead,
        reduce_with!(on_barcode_label_read),
    );
    let on_err = ctx.effects.bind(
        BarcodeScanFailed,
        reduce_with!(on_barcode_scan_failed),
    );

    ctx.effects
        .barcode_scanner()
        .scan(BarcodeScanRequest {
            formats: vec![BarcodeFormat::Code128, BarcodeFormat::QrCode],
            prompt: Some(prompt),
            timeout_ms: None,
            allow_multiple: false,
            ..Default::default()
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

pub fn valid_sku(sku: &str) -> bool {
    !sku.is_empty() && sku.len() <= 64
        && sku.bytes().all(|byte| byte.is_ascii_alphanumeric() || matches!(byte, b'-' | b'_'))
}

impl ReceivingState {
    /// Load one order per run. Validation finishes before replacing any state.
    pub fn load_order(&mut self, reference: &str, supplier: &str, source: &str) -> bool {
        if self.order_reference.is_some() || self.scanner_busy
            || reference.trim().is_empty() || supplier.trim().is_empty()
            || source.len() > 64 * 1024
        {
            return false;
        }
        let mut lines = Vec::new();
        for row in source.lines().filter(|row| !row.trim().is_empty()) {
            let fields: Vec<_> = row.split('\t').map(str::trim).collect();
            if fields.len() != 3 || lines.len() >= 200 { return false; }
            let sku = fields[0].to_ascii_uppercase();
            let Ok(expected_units) = fields[2].parse::<u32>() else { return false; };
            if !valid_sku(&sku) || fields[1].is_empty()
                || !(1..=9_999).contains(&expected_units)
                || lines.iter().any(|line: &PurchaseOrderLine| line.sku == sku)
            {
                return false;
            }
            lines.push(PurchaseOrderLine {
                sku, product_name: fields[1].to_owned(), expected_units, received_units: 0,
            });
        }
        if lines.is_empty() { return false; }
        self.order_reference = Some(reference.trim().to_owned());
        self.supplier_name = Some(supplier.trim().to_owned());
        self.lines = lines;
        self.error = None;
        self.notice = None;
        true
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn invalid_order_does_not_partially_load_and_scans_respect_limits() {
        let mut state = ReceivingState::default();
        assert!(!state.load_order("PO-test", "Test supplier", "A-1\tGloves\t2\nA-1\tTea\t3"));
        assert!(state.lines.is_empty());
        assert!(state.order_reference.is_none());
        assert!(state.load_order("PO-test", "Test supplier", "A-1\tGloves\t2\nB-2\tTea\t1"));
        assert!(record_supplier_sku(&mut state, "a-1"));
        assert!(!record_supplier_sku(&mut state, "unknown"));
        assert!(record_supplier_sku(&mut state, "A-1"));
        assert!(!record_supplier_sku(&mut state, "A-1"));
        assert_eq!(state.lines[0].received_units, 2);
        assert_eq!(state.lines[1].received_units, 0);
        assert!(!state.load_order("replacement", "Supplier", "C-3\tMask\t1"));
        assert_eq!(state.order_reference.as_deref(), Some("PO-test"));
    }
}

use std::collections::HashMap;

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::Env;

const SOURCES: [(&str, &str); 2] = [
    ("en-US", include_str!("../../i18n/en-US.yaml")),
    ("es-ES", include_str!("../../i18n/es-ES.yaml")),
];

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in SOURCES {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid receiving translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

<!-- fission:preview -->

The completion actions are routing signals, not made-up barcode payloads. Success decodes `ctx.input.capability_ok(SCAN_BARCODE)`; failure decodes `ctx.input.capability_error(SCAN_BARCODE)`. Cancellation, denied access and unsupported capture leave the existing quantities intact.

The order reference and SKU format identify application records; they do not authenticate a supplier, authorise receiving, or prevent two different devices from receiving the same order concurrently. A production service must enforce those rules independently.

<!-- fission:checkpoint -->
Enter your order reference, supplier and a few real line items using the stated column format. In the browser, type a matching SKU and record one unit. Then enter a different SKU: the quantities should remain unchanged. Receive a line up to its ordered quantity and try once more; the app must reject the extra unit.

The default browser provider reports unsupported scanning. The same screen exposes that result and keeps manual entry available. It does not replace the request with a canned success or a different purchase order.

## Check the camera and recovery paths on Android

A successful browser interaction establishes the receiving rule, not Android camera behaviour. Run the installed app and use a real printed label.

```sh
cargo test
fission doctor android --project-dir .
fission run --target android --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```

Open an order containing the label's exact SKU. Capture the label, verify that only its line changes, then try an unrelated label and a line already at its ordered quantity. Test both QR and Code 128 where your device can decode them.

Deny camera access, dismiss the native capture UI, and try an unreadable photograph. Check the actual error code returned by that host; neither dismissal nor failure may add stock. Manual entry must still work after the pending state clears. An app that retries should ask again only after another deliberate user action.

Inspect `platforms/android/AndroidManifest.xml` and the app's camera permission in Android settings if the host reports denied access. Use a phone for the final camera check: an emulator's camera, autofocus and image quality are not the same evidence.

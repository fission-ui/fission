At North Gate Workshop, volunteers share drills, saws, and other equipment. When a tool is checked out, everyone at the desk needs to see who has it and when it is due back. The desk also needs a quick way to focus on tools that are available without changing the inventory.

We will build that checkout desk from four workshop tools. A reducer checks a tool out to Asha or marks it back on the shelf, while a summary reads the same inventory. The available-only filter belongs to the desk component because it changes the view, not the equipment record. This first version keeps its sample inventory in memory, so restarting the app restores the starting shelf.

## Lay out the workshop shelf

A volunteer should be able to tell at a glance which tools can leave the workshop and which ones are already with a member. Each row therefore shows a tool name, where it belongs, its current status, and the return time when it is checked out.

Start with a read-only screen so the inventory shape is easy to see before adding actions. `ToolCard` gives one tool a consistent layout, and `ToolLibraryDesk` arranges the summary and cards. Its named vertical scroll region keeps the full shelf reachable on a phone and gives TalkBack a useful description for the scroll area.

    Available,

## Check tools in and out with reducers

A checkout changes shared inventory. When a volunteer checks out the drill, the tool row and the available count should change together. Checking in Elena’s pressure washer must update the same shared record, not just remove a card from the current screen.

Keep the tool list in `ToolLibraryState`, which implements `GlobalState`. The `CheckOutTool` and `CheckInTool` actions carry the selected tool’s stable ID; their reducers reject an invalid repeat transition, update the matching status, and leave a clear notice. `ToolSummary` and `ToolCard` both read this state, so their values stay in sync.

The filter has a different job. A volunteer can focus on available tools, then show the whole shelf to check who has the rest. `available_only` is retained local state in `ToolLibraryDesk` because it changes the visible rows, not the equipment data. Replace `src/app.rs` with this version and try the drill, saw, and filter in the preview.

    Available,
    CheckedOut {
        borrower: &'static str,
        due: &'static str,
    },
}

impl ToolStatus {

}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Tool {
    pub id: u32,
    pub name: &'static str,
    pub location: &'static str,
    pub status: ToolStatus,

fn sample_tools() -> Vec<Tool> {

            name: "Cordless drill",

        },

#[derive(Clone, Debug, PartialEq)]
pub struct ToolLibraryState {
    pub tools: Vec<Tool>,
    pub notice: String,
}

impl Default for ToolLibraryState {
    fn default() -> Self {
        Self {
            tools: sample_tools(),
            notice: "Two tools are currently checked out; two are ready for workshop jobs.".to_string(),
        }
    }
}

impl GlobalState for ToolLibraryState {}

#[fission_reducer(CheckOutTool)]
pub fn on_check_out_tool(state: &mut ToolLibraryState, tool_id: u32) {
    let notice = state
        .tools
        .iter_mut()
        .find(|tool| tool.id == tool_id)
        .and_then(|tool| {
            if !tool.status.is_available() {
                return None;
            }
            tool.status = ToolStatus::CheckedOut {
                borrower: "Asha",
                due: "Friday, 5:00 pm",
            };
            Some(format!("{} checked out to Asha until Friday at 5:00 pm.", tool.name))
        });

    if let Some(notice) = notice {
        state.notice = notice;
    }
}

#[fission_reducer(CheckInTool)]
pub fn on_check_in_tool(state: &mut ToolLibraryState, tool_id: u32) {
    let notice = state
        .tools
        .iter_mut()
        .find(|tool| tool.id == tool_id)
        .and_then(|tool| {
            if tool.status.is_available() {
                return None;
            }
            tool.status = ToolStatus::Available;
            Some(format!("{} is back on the shelf.", tool.name))
        });

    if let Some(notice) = notice {
        state.notice = notice;
    }
}

fission_component! {
    pub ToolSummary<ToolLibraryState> {}
    view(_summary, library, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let available = library.tools.iter()
            .filter(|tool| tool.status.is_available())
            .count();
        let checked_out = library.tools.len() - available;
    } =>
    SemanticsRegion(
        identifier: Some("workshop-tool-summary".to_string()),
        label: Some("Workshop tool availability".to_string()),
        child: Column(gap: tokens.spacing.xs, children: [
            Text(format!("Available · {}", available)),
            Text(format!("Checked out · {}", checked_out))
                .color(tokens.colors.text_secondary),
        ]),
    )
}

fission_component! {
    pub ToolCard<ToolLibraryState> { tool: Tool }
    view(card, _library, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let available = card.tool.status.is_available();
        let status = card.tool.status.summary();
    } =>
    SemanticsRegion(
        identifier: Some(format!("workshop-tool-{}", card.tool.id)),
        label: Some(format!("{} in {}", card.tool.name, card.tool.location)),
        child: Container(
            Column(gap: tokens.spacing.s, align_items: ir_op::AlignItems::Start, children: [
                Column(gap: tokens.spacing.xs, children: [
                    Text(card.tool.name.to_string())
                        .weight(tokens.typography.font_weight_semibold),
                    Text(format!("Stored at {}", card.tool.location))
                        .color(tokens.colors.text_secondary),
                    Text(status).color(tokens.colors.text_secondary),
                ]),
                if available {
                    Button(
                        child: Text("Check out to Asha"),
                        key: "check-out-tool",
                        variant: ButtonVariant::Primary,
                        on_press: with_reducer!(
                            cx.build,
                            CheckOutTool(card.tool.id),
                            on_check_out_tool,
                        ),
                    )
                    .semantics_identifier(format!("workshop-tool.check-out.{}", card.tool.id))
                } else {
                    Button(
                        child: Text("Check in"),
                        key: "check-in-tool",
                        variant: ButtonVariant::Outline,
                        on_press: with_reducer!(
                            cx.build,
                            CheckInTool(card.tool.id),
                            on_check_in_tool,
                        ),
                    )
                    .semantics_identifier(format!("workshop-tool.check-in.{}", card.tool.id))
                },
            ]),
        )
        .padding_all(tokens.spacing.m)
        .bg(tokens.colors.surface)
        .border(tokens.colors.border, 1.0)
        .border_radius(tokens.radii.medium)
        .width_length(Length::percent(100.0)),
    )
}

fission_component! {
    pub ToolLibraryDesk<ToolLibraryState> {
        state {
            available_only: bool = false,
        }
    }
    view(desk, library, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let visible_tools: Vec<Tool> = library.tools.iter()
            .filter(|tool| !desk.available_only || tool.status.is_available())
            .cloned()
            .collect();
    } =>
    SemanticsRegion(
        identifier: Some("north-gate-tool-library".to_string()),
        label: Some("North Gate Workshop tool library".to_string()),
        child: Scroll(
            flex_grow: 1.0,
            height: cx.view.viewport_size().height,
            semantic_label: Some("Workshop tool inventory".to_string()),
            child: Container(
                Column(align_items: ir_op::AlignItems::Center, children: [
                    Container(
                        Column(gap: tokens.spacing.l, children: [
                            Column(gap: tokens.spacing.xs, children: [
                                Text("North Gate Workshop")
                                    .weight(tokens.typography.font_weight_bold),
                                Text("Workshop tool lending desk")
                                    .color(tokens.colors.text_secondary),
                            ]),
                            ToolSummary(),
                            Button(
                                child: Text(if desk.available_only {
                                    "Show all tools"
                                } else {
                                    "Available tools only"
                                }),
                                key: "toggle-available-tools",
                                variant: ButtonVariant::Outline,
                                on_press: reduce {
                                    desk.available_only = !desk.available_only;
                                },
                            )
                            .semantics_identifier("workshop-tools.toggle-available"),
                            if visible_tools.is_empty() {
                                Text("No tools are available for checkout. Show all tools to review who has the equipment.")
                            } else {
                                Column(gap: tokens.spacing.s, children: [
                                    for tool in visible_tools.iter() {
                                        ToolCard(tool.clone(), key: tool.id)
                                    },
                                ])
                            },
                            Text(library.notice.clone())
                                .color(tokens.colors.text_secondary),
                        ]),
                    )
                    .padding_all(tokens.spacing.l)
                    .bg(tokens.colors.background)
                    .width_length(Length::clamp(
                        Length::points(0.0),
                        Length::percent(100.0),
                        Length::points(760.0),
                    )),
                ]),
            )
            .width_length(Length::percent(100.0))
            .bg(tokens.colors.background),
        ),
    )
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn checking_out_an_available_tool_updates_the_shared_record() {
        let mut state = ToolLibraryState::default();

        on_check_out_tool(&mut state, 2201);

        let tool = state.tools.iter().find(|tool| tool.id == 2201).unwrap();
        assert_eq!(
            tool.status,
            ToolStatus::CheckedOut {
                borrower: "Asha",
                due: "Friday, 5:00 pm",
            }
        );
        assert_eq!(
            state.notice,
            "Cordless drill checked out to Asha until Friday at 5:00 pm."
        );
    }

    #[test]
    fn checking_in_a_tool_makes_it_available_again() {
        let mut state = ToolLibraryState::default();

        on_check_in_tool(&mut state, 2204);

        let tool = state.tools.iter().find(|tool| tool.id == 2204).unwrap();
        assert_eq!(tool.status, ToolStatus::Available);
        assert_eq!(state.notice, "Pressure washer is back on the shelf.");
    }
}

## Run the checkout desk on Android

The browser preview exercises the inventory rules without requiring an emulator. The native app uses the same `ToolLibraryDesk` and `ToolLibraryState`; the Android shell supplies the device window and generated host. Replace the generated app’s `CounterApp` references in `src/lib.rs`. The generated `src/main.rs` continues to select the Android entry point.

pub mod app;

use crate::app::{ToolLibraryDesk, ToolLibraryState};
use fission::prelude::*;

#[cfg(target_os = "android")]
const ANDROID_TEST_CONTROL_PORT: u16 = 48761;

#[cfg(any(target_os = "android", target_os = "ios"))]
fn mobile_app() -> MobileApp<ToolLibraryState, ToolLibraryDesk> {
    let app = MobileApp::<ToolLibraryState, _>::new(ToolLibraryDesk::new())
        .with_title("North Gate Workshop tool library");
    #[cfg(target_os = "android")]
    let app = app.with_test_control_port(ANDROID_TEST_CONTROL_PORT);
    app
}

#[cfg(target_arch = "wasm32")]
fn web_app() -> WebApp<ToolLibraryState, ToolLibraryDesk> {
    WebApp::<ToolLibraryState, _>::new(ToolLibraryDesk::new())
        .with_title("North Gate Workshop tool library")
}

#[cfg(not(any(target_arch = "wasm32", target_os = "android", target_os = "ios")))]
pub fn run_desktop() -> anyhow::Result<()> {
    DesktopApp::<ToolLibraryState, _>::new(ToolLibraryDesk::new()).run()
}

#[cfg(any(target_os = "android", target_os = "ios"))]
pub fn run_mobile() -> anyhow::Result<()> {
    mobile_app().run()
}

#[cfg(target_os = "android")]
#[no_mangle]
fn android_main(app_handle: AndroidApp) {
    let _ = mobile_app().run_with_android_app(app_handle);
}

#[cfg(target_arch = "wasm32")]
#[wasm_bindgen::prelude::wasm_bindgen(start)]
pub fn run_web() -> Result<(), wasm_bindgen::JsValue> {
    console_error_panic_hook::set_once();
    web_app()
        .run()
        .map_err(|error| wasm_bindgen::JsValue::from_str(&error.to_string()))
}

North Gate Workshop lends drills, saws, and other equipment to its volunteers. When someone checks out a tool, the whole desk needs to see who has it and when it is due back. Volunteers also need to filter the shelf to available tools. That filter should change what they see, not the inventory itself.

We’ll build the desk around four tools. Reducers check a tool out to Asha or mark it back on the shelf, and the summary reads the same inventory. The available-only filter belongs to the desk component because it is temporary UI state. The browser preview seeds fixture inventory so the screen has useful content; a real app starts empty and loads its stock records from its service.

## Lay out the workshop shelf

Volunteers need to see which tools are available and which are checked out.
Each row shows the tool, where it belongs, its status, and when it is due back.

Start with a read-only screen. It is easier to check the inventory layout before adding actions. `ToolCard` gives each tool the same presentation, while `ToolLibraryDesk` arranges the summary and rows from `GlobalState`. Its named scroll region keeps the whole shelf reachable on a phone and gives TalkBack a useful description. Preview data is seeded by the preview shell, not created during component conversion.

## Check tools in and out with reducers

Checking out a tool changes shared inventory. The drill row and available count should change together; checking in Elena’s pressure washer should update the same record, not just hide its card.

`ToolLibraryState` implements `GlobalState` and owns the tool list. `CheckOutTool` and `CheckInTool` carry a stable tool ID. Their reducers reject a repeated or invalid transition, update the matching record, and leave a notice. Both `ToolSummary` and `ToolCard` read the same state, so there is no second count to keep in sync by hand.

The filter is different: volunteers can focus on available tools, then show the whole shelf to check who has the rest. `available_only` is retained local state in `ToolLibraryDesk` because it changes the visible rows, not the equipment records. Replace `src/app.rs` and try the drill, saw, and filter in the preview.

    CheckedOut(&'static str),
    CheckedIn(&'static str),
}

    pub id: u32,
    pub name_key: &'static str,
    pub location_key: &'static str,
    pub status: ToolStatus,
}

#[derive(Clone, Debug, PartialEq)]
pub struct ToolLibraryState {
    pub tools: Vec<Tool>,
    pub notice: Option<ToolNotice>,
}

impl Default for ToolLibraryState {
    fn default() -> Self {
        Self {
            tools: Vec::new(),
            notice: None,
        }
    }
}

impl GlobalState for ToolLibraryState {}

#[fission_reducer(CheckOutTool)]
pub fn on_check_out_tool(state: &mut ToolLibraryState, tool_id: u32) {
    let notice = state
        .tools
        .iter_mut()
        .find(|tool| tool.id == tool_id)
        .and_then(|tool| {
            if !tool.status.is_available() {
                return None;
            }
            tool.status = ToolStatus::CheckedOut {
                borrower: "Asha",
                due: "Friday, 5:00 pm",
            };
            Some(ToolNotice::CheckedOut(tool.name_key))
        });

    if let Some(notice) = notice {
        state.notice = Some(notice);
    }
}

#[fission_reducer(CheckInTool)]
pub fn on_check_in_tool(state: &mut ToolLibraryState, tool_id: u32) {
    let notice = state
        .tools
        .iter_mut()
        .find(|tool| tool.id == tool_id)
        .and_then(|tool| {
            if tool.status.is_available() {
                return None;
            }
            tool.status = ToolStatus::Available;
            Some(ToolNotice::CheckedIn(tool.name_key))
        });

    if let Some(notice) = notice {
        state.notice = Some(notice);
    }
}

## Run the checkout desk on Android

The browser preview lets you try the inventory rules without an emulator. The Android app uses the same `ToolLibraryDesk` and `ToolLibraryState`; only the shell and host change. Replace the generated app’s `CounterApp` references in `src/lib.rs`. Leave `src/main.rs` to select the Android entry point.

## Create the project and add the target

Create a shared Rust app and add the iOS target. Fission generates the native host; keep the app behaviour in Rust.

```sh
cargo install cargo-fission
fission init ios-run-asynchronous-effects-safely-in-an-ios-ui
cd ios-run-asynchronous-effects-safely-in-an-ios-ui
fission add-target ios --project-dir .
```

## Files created by Fission

Fission creates this starter tree. Shared Rust code stays in `src/`; the generated host under `platforms/ios/` handles iOS launch and packaging.

```text
ios-run-asynchronous-effects-safely-in-an-ios-ui/
├── Cargo.toml                 # Rust package and dependencies
├── fission.toml               # app identity, targets and capabilities
├── src/
│   ├── main.rs                # generated app entrypoint
│   ├── lib.rs                 # shared app setup
│   └── app.rs                 # shared Fission screen
└── platforms/
    └── ios/                  # generated iOS host
```

Keep app behaviour in shared Rust. Add a feature module only when it creates a useful boundary, and keep iOS APIs behind the generated host.

```rust
use fission::prelude::*;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
enum TemperatureValidationIssue {
    InvalidNumber,
    OutOfRange,
}

impl TemperatureValidationIssue {
    fn translation_key(self) -> &'static str {
        match self {
            Self::InvalidNumber => "async.error.number",
            Self::OutOfRange => "async.error.range",
        }
    }
}

#[fission_effect]
async fn validate_temperature(
    request_id: u64,
    raw_temperature: String,
) -> Result<(u64, String), (u64, u8)> {
    let normalized = raw_temperature.trim().replace(',', ".");
    let temperature = normalized
        .parse::<f32>()
        .map_err(|_| (request_id, 1))?;

    if !(-40.0..=80.0).contains(&temperature) {
        return Err((request_id, 2));
    }

    Ok((request_id, format!("{temperature:.1} °C")))
}

fission_component! {
    pub CompressorTemperatureCheck<()> {
        state {
            temperature: String = "4.2".to_string(),
            latest_request: u64 = 0,
            loading: bool = false,
            checked_temperature: Option<String> = None,
            error: Option<TemperatureValidationIssue> = None,
        }
    }
    view(check, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    SemanticsRegion(
        identifier: Some("northbank.temperature-check".to_string()),
        label: Some(cx.tr("async.screen.label")),
        child: Container(
            Column(gap: tokens.spacing.m, children: [
                Text(cx.tr("async.title"))
                    .weight(tokens.typography.font_weight_bold),
                Text(cx.tr("async.description"))
                    .color(tokens.colors.text_secondary),
                Divider(),
                Column(gap: tokens.spacing.s, children: [
                    Text(cx.tr("async.work_order"))
                        .weight(tokens.typography.font_weight_semibold),
                    Text(cx.tr("async.asset"))
                        .size(tokens.typography.heading2_size),
                    Text(cx.tr("async.location"))
                        .color(tokens.colors.text_secondary),
                ]),
                TextInput(
                    label: Some(cx.tr("async.input.label").into()),
                    bind: check.temperature,
                    placeholder: Some(cx.tr("async.input.placeholder").into()),
                    required: true,
                    keyboard_type: TextInputType::Number,
                    autocorrect: false,
                    semantics_identifier: "northbank.temperature.value".to_string(),
                ),
                Button(
                    child: Text(if check.loading {
                        cx.tr("async.action.running")
                    } else {
                        cx.tr("async.action.check")
                    }),
                    key: "check-temperature",
                    variant: ButtonVariant::Primary,
                    disabled: check.loading,
                    on_press: effect validate_temperature(
                        check.latest_request + 1,
                        check.temperature.clone(),
                    ) {
                        on_start {
                            check.latest_request += 1;
                            check.loading = true;
                            check.error = None;
                        }
                        on_ok(result) {
                            if result.0 == check.latest_request {
                                check.checked_temperature = Some(result.1);
                                check.loading = false;
                            }
                        }
                        on_err(error) {
                            if error.0 == check.latest_request {
                                check.error = Some(if error.1 == 1 {
                                    TemperatureValidationIssue::InvalidNumber
                                } else {
                                    TemperatureValidationIssue::OutOfRange
                                });
                                check.loading = false;
                            }
                        }
                    },
                ),
                if check.loading {
                    Text(cx.tr("async.status.running"))
                        .color(tokens.colors.text_secondary)
                } else if let Some(error) = check.error {
                    Alert(
                        kind: AlertKind::Error,
                        title: cx.tr(error.translation_key()),
                    )
                } else if let Some(temperature) = &check.checked_temperature {
                    Alert(
                        kind: AlertKind::Success,
                        title: format!("{} {temperature}", cx.tr("async.status.saved")),
                    )
                } else {
                    Text(cx.tr("async.status.ready"))
                        .color(tokens.colors.text_secondary)
                },
            ])
        )
        .padding_all(tokens.spacing.l)
        .bg(tokens.colors.surface)
        .border(tokens.colors.border, 1.0)
        .border_radius(tokens.radii.large),
    )
}
```

```rust
mod app;

use std::collections::HashMap;

use fission::prelude::*;
use wasm_bindgen::prelude::*;

fn preview_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("i18n/en-US.yaml")),
        ("es-ES", include_str!("i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid embedded tutorial translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

#[wasm_bindgen(start)]
pub fn run() -> Result<(), JsValue> {
    console_error_panic_hook::set_once();
    WebApp::<(), _>::new(app::CompressorTemperatureCheck)
        .with_env(preview_env())
        .with_title("Northbank temperature check")
        .mount("#fission-web-mount")
        .run()
        .map_err(|error| JsValue::from_str(&error.to_string()))
}
```

## Run asynchronous effects safely in an iOS UI

Store an ID with each request so the reducer can tell whether a result still belongs to the screen. While the effect runs, show a pending state and keep existing data visible. When it finishes, dispatch a typed success or failure action; offer retry after an error, and offer cancel only if the service can actually cancel. To test the race, make two requests and have a fake service return the newer result first. The older result must not replace it, even if it arrives after navigation. Effects run outside the reducer, so never block the UI thread with sleep, file access, SQL or network work.

## Check delayed and interrupted work on iOS

In a Rust test, a fake service returns the result you choose instead of making a network request. Start two requests, return the newer result first, and then return the older one. Because the app stores the newest request ID, the reducer should ignore that stale response and keep the newer result on screen.

Also background the app while work is pending, then return to it. The loading state should finish or recover, errors should remain visible, and a retry should not require the user to repeat work that was already saved.

### Run, test and build

```sh
cargo test
fission doctor ios --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
fission build --target ios --project-dir . --release
```

`cargo test` runs Rust tests you add; the generated scaffold does not create feature-specific tests. `fission doctor` reports missing Xcode, simulator SDK or Rust targets, `fission run` launches an iOS Simulator, and `fission test` checks that the generated host can start. A release build checks the simulator package; it does not verify iPhone signing or physical-device behavior.


### Simulator and device commands

Fission’s run command discovers iOS simulators. Run these checks from the generated project root:

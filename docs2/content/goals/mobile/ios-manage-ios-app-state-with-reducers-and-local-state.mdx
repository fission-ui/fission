At Riverside Community Library, a volunteer checks books back in while another person answers questions at the desk. They both need the same loan record to say when a book is back. The returns screen also needs a way to hide completed loans while the volunteer works through the active pile.

We will build that desk from four sample loans. A typed reducer changes a loan from checked out to returned, and the totals update from the same data. The “include returned loans” choice belongs only to this screen, so closing and reopening the filter does not alter a loan. This first version keeps records in memory; when the app restarts, the sample loans return.

## Lay out the returns desk

A volunteer should not have to open a loan to identify it. Each row shows the book, the member who borrowed it, its due time, and whether it is still checked out. The totals summarize the same four sample loans, so even this read-only first version resembles a useful desk rather than a blank scaffold.

Add the loan type and two components to `src/app.rs`. `LoanCard` owns the presentation for one loan; `LibraryLoanDesk` arranges the cards and summary. The vertical scroll region uses the current app viewport height so all four loans remain reachable on a phone, and its accessible name tells VoiceOver what the region contains.

## Update the loan record with a reducer

When a book comes back, the status is no longer just a detail on this screen. The loan summary and every component reading that loan should now report the return. Put the list in `LibraryState`, which implements `GlobalState`, and make “Mark returned” a typed action. The reducer finds one loan by its stable ID, changes its status, and records a short confirmation for the desk.

The filter has a different lifetime. A volunteer may turn it on to review returns, then turn it off to focus on the books still out. That choice does not belong in `LibraryState` because it should not change what another screen sees. `LibraryLoanDesk` retains it locally, and its button only changes which rows are visible.

Replace the read-only `src/app.rs` with the version below. `LoanSummary` reads the shared records, `LoanCard` dispatches the return action, and `LibraryLoanDesk` owns the local filter. Since the cards use each loan’s ID as their key, filtering the list does not give a different book the previous row’s widget identity.

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum LoanStatus {
    CheckedOut,
    Returned,
}

impl LoanStatus {
    pub fn label(self) -> &'static str {
        match self {
            Self::CheckedOut => "On loan",
            Self::Returned => "Returned",
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Loan {
    pub id: u32,
    pub title: &'static str,
    pub borrower: &'static str,
    pub due: &'static str,
    pub status: LoanStatus,
}

fn sample_loans() -> Vec<Loan> {
    vec![
        Loan {
            id: 4102,
            title: "The Rust Programming Language",
            borrower: "Ada",
            due: "Today, 4:30 pm",
            status: LoanStatus::CheckedOut,
        },
        Loan {
            id: 4103,
            title: "The Left Hand of Darkness",
            borrower: "Mateo",
            due: "Yesterday",
            status: LoanStatus::CheckedOut,
        },
        Loan {
            id: 4104,
            title: "A Field Guide to Trees",
            borrower: "Priya",
            due: "Returned at 11:10 am",
            status: LoanStatus::Returned,
        },
        Loan {
            id: 4105,
            title: "Programming Rust",
            borrower: "Noah",
            due: "Tomorrow",
            status: LoanStatus::CheckedOut,
        },
    ]
}

#[derive(Clone, Debug, PartialEq)]
pub struct LibraryState {
    pub loans: Vec<Loan>,
    pub notice: String,
}

impl Default for LibraryState {
    fn default() -> Self {
        Self {
            loans: sample_loans(),
            notice: "The returns desk starts with three active loans and one returned book.".to_string(),
        }
    }
}

impl GlobalState for LibraryState {}

#[fission_reducer(MarkLoanReturned)]
pub fn on_mark_loan_returned(state: &mut LibraryState, loan_id: u32) {
    let notice = state
        .loans
        .iter_mut()
        .find(|loan| loan.id == loan_id)
        .and_then(|loan| {
            if loan.status == LoanStatus::Returned {
                return None;
            }
            loan.status = LoanStatus::Returned;
            Some(format!("{} is back on the shelf.", loan.title))
        });

    if let Some(notice) = notice {
        state.notice = notice;
    }
}

fission_component! {
    pub LoanSummary<LibraryState> {}
    view(_summary, library, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let checked_out = library.loans.iter()
            .filter(|loan| loan.status == LoanStatus::CheckedOut)
            .count();
        let returned = library.loans.iter()
            .filter(|loan| loan.status == LoanStatus::Returned)
            .count();
    } =>
    SemanticsRegion(
        identifier: Some("library-loan-summary".to_string()),
        label: Some("Library loan totals".to_string()),
        child: Column(gap: tokens.spacing.xs, children: [
            Text(format!("On loan · {}", checked_out)),
            Text(format!("Returned today · {}", returned))
                .color(tokens.colors.text_secondary),
        ]),
    )
}

fission_component! {
    pub LoanCard<LibraryState> { loan: Loan }
    view(card, _library, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    SemanticsRegion(
        identifier: Some(format!("library-loan-{}", card.loan.id)),
        label: Some(format!("{} loan for {}", card.loan.title, card.loan.borrower)),
        child: Container(
            Column(gap: tokens.spacing.xs, align_items: ir_op::AlignItems::Start, children: [
                Text(card.loan.title.to_string())
                    .weight(tokens.typography.font_weight_semibold),
                Text(format!("Borrowed by {}", card.loan.borrower))
                    .color(tokens.colors.text_secondary),
                Text(format!("Due: {}", card.loan.due))
                    .color(tokens.colors.text_secondary),
                Text(format!("Status: {}", card.loan.status.label()))
                    .color(tokens.colors.text_secondary),
                if card.loan.status == LoanStatus::CheckedOut {
                    Button(
                        child: Text("Mark returned"),
                        key: "mark-loan-returned",
                        variant: ButtonVariant::Primary,
                        on_press: with_reducer!(
                            cx.build,
                            MarkLoanReturned(card.loan.id),
                            on_mark_loan_returned,
                        ),
                    )
                    .semantics_identifier(format!("library-loan.return.{}", card.loan.id))
                } else {
                    Text("Returned to the shelf.")
                        .color(tokens.colors.text_secondary)
                },
            ]),
        )
        .padding_all(tokens.spacing.m)
        .bg(tokens.colors.surface)
        .border(tokens.colors.border, 1.0)
        .border_radius(tokens.radii.medium)
        .width_length(Length::percent(100.0)),
    )
}

fission_component! {
    pub LibraryLoanDesk<LibraryState> {
        state {
            show_returned: bool = false,
        }
    }
    view(desk, library, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let visible_loans: Vec<Loan> = library.loans.iter()
            .filter(|loan| desk.show_returned || loan.status != LoanStatus::Returned)
            .cloned()
            .collect();
    } =>
    SemanticsRegion(
        identifier: Some("riverside-library-returns-desk".to_string()),
        label: Some("Riverside Community Library returns desk".to_string()),
        child: Scroll(
            flex_grow: 1.0,
            height: cx.view.viewport_size().height,
            semantic_label: Some("Library loan list".to_string()),
            child: Container(
                Column(align_items: ir_op::AlignItems::Center, children: [
                    Container(
                        Column(gap: tokens.spacing.l, children: [
                            Column(gap: tokens.spacing.xs, children: [
                                Text("Riverside Community Library")
                                    .weight(tokens.typography.font_weight_bold),
                                Text("Returns desk · Tuesday afternoon")
                                    .color(tokens.colors.text_secondary),
                            ]),
                            LoanSummary(),
                            Button(
                                child: Text(if desk.show_returned {
                                    "Show active loans only"
                                } else {
                                    "Include returned loans"
                                }),
                                key: "toggle-returned-loans",
                                variant: ButtonVariant::Outline,
                                on_press: reduce {
                                    desk.show_returned = !desk.show_returned;
                                },
                            )
                            .semantics_identifier("library-loans.toggle-returned"),
                            if visible_loans.is_empty() {
                                Text("No active loans remain. Include returned loans to review the completed records.")
                            } else {
                                Column(gap: tokens.spacing.s, children: [
                                    for loan in visible_loans.iter() {
                                        LoanCard(loan.clone(), key: loan.id)
                                    },
                                ])
                            },
                            Text(library.notice.clone())
                                .color(tokens.colors.text_secondary),
                        ]),
                    )
                    .padding_all(tokens.spacing.l)
                    .bg(tokens.colors.background)
                    .width_length(Length::clamp(
                        Length::points(0.0),
                        Length::percent(100.0),
                        Length::points(760.0),
                    )),
                ]),
            )
            .width_length(Length::percent(100.0))
            .bg(tokens.colors.background),
        ),
    )
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn returning_a_loan_updates_the_shared_record() {
        let mut state = LibraryState::default();

        on_mark_loan_returned(&mut state, 4105);

        let loan = state.loans.iter().find(|loan| loan.id == 4105).unwrap();
        assert_eq!(loan.status, LoanStatus::Returned);
        assert_eq!(state.notice, "Programming Rust is back on the shelf.");
    }

    #[test]
    fn returning_an_unknown_loan_changes_nothing() {
        let mut state = LibraryState::default();
        let original = state.clone();

        on_mark_loan_returned(&mut state, 9999);

        assert_eq!(state, original);
    }
}

## Run and verify the returns desk on iOS

The same `LibraryLoanDesk` component can run in the browser and in the native iOS shell. Fission does not need a second screen written in Swift: the host starts the Rust app and supplies the device window. Replace the generated app’s `CounterApp` references in `src/lib.rs` with the library desk and its shared state. The generated `src/main.rs` continues to call `run_mobile` for iOS.

pub mod app;

use crate::app::{LibraryLoanDesk, LibraryState};
use fission::prelude::*;

#[cfg(any(target_os = "ios", target_os = "android"))]
fn mobile_app() -> MobileApp<LibraryState, LibraryLoanDesk> {
    MobileApp::<LibraryState, _>::new(LibraryLoanDesk::new())
        .with_title("Riverside Community Library returns desk")
}

#[cfg(target_arch = "wasm32")]
fn web_app() -> WebApp<LibraryState, LibraryLoanDesk> {
    WebApp::<LibraryState, _>::new(LibraryLoanDesk::new())
        .with_title("Riverside Community Library returns desk")
}

#[cfg(not(any(target_arch = "wasm32", target_os = "android", target_os = "ios")))]
pub fn run_desktop() -> anyhow::Result<()> {
    DesktopApp::<LibraryState, _>::new(LibraryLoanDesk::new()).run()
}

#[cfg(any(target_os = "ios", target_os = "android"))]
pub fn run_mobile() -> anyhow::Result<()> {
    mobile_app().run()
}

#[cfg(target_os = "android")]
#[no_mangle]
fn android_main(app_handle: AndroidApp) {
    let _ = mobile_app().run_with_android_app(app_handle);
}

#[cfg(target_arch = "wasm32")]
#[wasm_bindgen::prelude::wasm_bindgen(start)]
pub fn run_web() -> Result<(), wasm_bindgen::JsValue> {
    console_error_panic_hook::set_once();
    web_app()
        .run()
        .map_err(|error| wasm_bindgen::JsValue::from_str(&error.to_string()))
}

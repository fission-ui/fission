Returning a book changes a library record. Hiding returned books changes only what one desk displays. Both operations can make a row disappear, but they do not mean the same thing. If we put them in the same state bucket, a harmless display choice can become an accidental change to the library's data.

We will build a returns desk that starts empty and lets you enter loans yourself. A loan's return status belongs to application state because the list, totals and confirmation all describe that same fact. The unfinished entry form and the desk's filter belong to this component's retained UI state.

## Create the app

Complete [iOS setup](/blog/set-up-rust-ios-development-with-fission/) if needed, then generate the shared project.

```sh
cargo install cargo-fission
fission init riverside-library
cd riverside-library
fission add-target ios --project-dir .
cargo add serde_yaml
```

Keep the generated `src/main.rs`. The files below provide normal native and Web launchers from the outset; the browser does not inject records which the iOS app never receives.

## Give each fact one owner

`LibraryState.loans` is the authority for the session's records. The summary derives counts from it instead of keeping a second pair of mutable counters. This matters because a return cannot update the row and leave a separately stored total behind.

The reducer block calls `mark_returned`, an ordinary synchronous Rust function. It selects by record ID, ignores an unknown ID and leaves an already returned loan unchanged. The function can therefore be tested without constructing a widget or inventing a second action format.

```rust
use fission::prelude::*;

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Loan {
    pub id: u64,
    pub title: String,
    pub borrower: String,
    pub returned: bool,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct LibraryState {
    pub loans: Vec<Loan>,
    pub next_id: u64,
    pub last_returned_title: Option<String>,
    pub locale: Locale,
}

impl Default for LibraryState {
    fn default() -> Self {
        Self {
            loans: Vec::new(),
            next_id: 1,
            last_returned_title: None,
            locale: Locale::from("en-US"),
        }
    }
}

impl GlobalState for LibraryState {}

pub fn add_loan(state: &mut LibraryState, title: &str, borrower: &str) -> bool {
    let (title, borrower) = (title.trim(), borrower.trim());
    if title.is_empty() || borrower.is_empty() {
        return false;
    }
    let Some(next_id) = state.next_id.checked_add(1) else {
        return false;
    };
    state.loans.push(Loan {
        id: state.next_id,
        title: title.to_owned(),
        borrower: borrower.to_owned(),
        returned: false,
    });
    state.next_id = next_id;
    true
}

pub fn mark_returned(state: &mut LibraryState, loan_id: u64) {
    let Some(loan) = state.loans.iter_mut().find(|loan| loan.id == loan_id) else {
        return;
    };
    if loan.returned {
        return;
    }
    loan.returned = true;
    state.last_returned_title = Some(loan.title.clone());
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn returning_updates_one_record_and_is_idempotent() {
        let mut state = LibraryState::default();
        assert!(add_loan(&mut state, "Book A", "Reader A"));
        assert!(add_loan(&mut state, "Book B", "Reader B"));
        mark_returned(&mut state, 2);
        assert!(!state.loans[0].returned);
        assert!(state.loans[1].returned);
        let expected = state.clone();
        mark_returned(&mut state, 2);
        mark_returned(&mut state, 999);
        assert_eq!(state, expected);
    }

    #[test]
    fn invalid_input_does_not_allocate_an_id() {
        let mut state = LibraryState::default();
        assert!(!add_loan(&mut state, " ", "Reader"));
        assert_eq!(state.next_id, 1);
        assert!(state.loans.is_empty());
    }
}
```

```rust
use super::state::{mark_returned, LibraryState};
use fission::prelude::*;

fission_component! {
    pub LoanCard<LibraryState> {
        props { loan_id: u64 }
    }
    view(card, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let loan = state.loans.iter().find(|loan| loan.id == card.loan_id);
    } => if let Some(loan) = loan {
      SemanticsRegion(
        identifier: Some(format!("library.loan.{}", card.loan_id)),
        child: Container(
        Column(gap: tokens.spacing.s, children: [
            Text(loan.title.clone()).weight(tokens.typography.font_weight_semibold),
            Text(cx.tr("library.borrower").replace("{name}", &loan.borrower)),
            Text(if loan.returned { cx.tr("library.returned") } else { cx.tr("library.on_loan") }),
            Button(
                child: Text(cx.tr("library.return")), key: "return-loan",
                disabled: loan.returned,
                on_press: reduce { mark_returned(state, card.loan_id); },
            ),
        ]),
    )
    .padding_all(tokens.spacing.m)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium),
      )
    } else {
        Spacer()
    }
}
```

```rust
use super::{
    loan_card::LoanCard,
    state::{add_loan, LibraryState},
    summary::LoanSummary,
};
use fission::prelude::*;

fission_component! {
    pub LibraryLoanDesk<LibraryState> {
        state {
            title: String = String::new(),
            borrower: String = String::new(),
            show_returned: bool = false,
        }
    }
    view(desk, library, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let visible: Vec<_> = library.loans.iter()
            .filter(|loan| desk.show_returned || !loan.returned).collect();
    } => SafeArea(
        child: Scroll(
            child: Container(Column(gap: tokens.spacing.m, children: [
                Text(cx.tr("library.heading")).size(tokens.typography.heading2_size),
                Text(cx.tr("library.session")),
                Row(gap: tokens.spacing.s, children: [
                    Button(
                        child: Text(cx.tr("language.english")), key: "english",
                        on_press: reduce { library.locale = Locale::from("en-US"); },
                    ),
                    Button(
                        child: Text(cx.tr("language.spanish")), key: "spanish",
                        on_press: reduce { library.locale = Locale::from("es-ES"); },
                    ),
                ]),
                FormControl(
                    label: Some(cx.tr("library.title")),
                    required: true,
                    child: TextInput(
                        value: desk.title.clone(),
                        bind(on_input): to(desk.title),
                    ),
                ),
                FormControl(
                    label: Some(cx.tr("library.reader")),
                    required: true,
                    child: TextInput(
                        value: desk.borrower.clone(),
                        bind(on_input): to(desk.borrower),
                    ),
                ),
                Button(
                    child: Text(cx.tr("library.add")), key: "add-loan",
                    disabled: desk.title.trim().is_empty() || desk.borrower.trim().is_empty()
                        || library.next_id == u64::MAX,
                    on_press: reduce {
                        if add_loan(library, &desk.title, &desk.borrower) {
                            desk.title.clear();
                            desk.borrower.clear();
                        }
                    },
                ),
                LoanSummary,
                Button(
                    child: Text(if desk.show_returned { cx.tr("library.hide_returns") } else { cx.tr("library.show_returns") }),
                    key: "toggle-returns",
                    on_press: reduce { desk.show_returned = !desk.show_returned; },
                ),
                if visible.is_empty() { Text(cx.tr("library.empty")) },
                for loan in visible {
                    LoanCard(loan.id, key: loan.id)
                },
                if let Some(title) = &library.last_returned_title {
                    Text(cx.tr("library.confirmation").replace("{title}", title))
                },
            ]))
            .padding_all(tokens.spacing.l),
        ),
    )
}
```

```rust
use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid library translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

pub fn sync_env(state: &crate::app::LibraryState, env: &mut Env) {
    env.locale = state.locale.clone();
}
```

## Keep presentation state from becoming domain data

Compose's `state` section creates retained local state; it is not an ordinary mutable field on a freshly constructed widget. Here it remembers the unfinished title, borrower and filter while this desk remains mounted. None of those values claims that a loan has been recorded.

`props` has a different role. `LoanCard` receives its loan ID from the parent and reads the current record from shared state. Its action captures that small identifier rather than a second copy of the loan. The row does not keep a local `returned` flag which could disagree with the summary.

The stable key associates a card with its loan during reordering. It does not promise to retain local state after a widget is removed. Completion is safe when the filter hides a row because it belongs to `LibraryState`, not because the key secretly persists an unmounted card.

## Test the transition and then the interface

```sh
cargo test
fission doctor ios --project-dir .
fission devices --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
```

The included tests check that a return changes the intended record once and that invalid entry does not consume an ID. Run them before driving the actual screen. They do not prove the action is connected to the right row, so repeat the add, return and filter sequence in the simulator too.

Use [the simulator guide](/blog/choose-boot-and-launch-an-ios-simulator-with-fission/) for selection. Check long titles and both languages on a narrow phone; every action must remain reachable. The generated host test establishes launch, not these state transitions or the visual result.

Application state is shared, not automatically durable. This example is explicitly session-scoped and has no library server or disk persistence. A production library would obtain records from its service and enforce authorization there; [Fission Store](/blog/persist-ios-app-state-with-fission-store-and-sqlite/) is available when local data must survive restart.

At Riverside Community Library, one volunteer checks books in while another helps members. They both need to see the same return status. The returns screen also needs a way to hide completed loans while the volunteer works through the active pile.

We’ll build the desk around four preview loans. A typed reducer marks a loan returned, and the totals read from that same data. The “include returned loans” choice belongs only to this screen; changing the filter must not change a loan. The browser preview seeds its fixtures separately; a real app starts with no loaded loans and reads current records from its service.

## Lay out the returns desk

A volunteer should be able to identify a loan without opening it. Each row shows the book, borrower, due time, and current status. The totals come from the same four records, so the read-only screen is already useful rather than just a blank scaffold.

Add the loan type, shared state, and two components to `src/app.rs`. `LoanCard` presents one loan; `LibraryLoanDesk` arranges the cards and summary from `GlobalState`. The scroll region uses the app’s viewport height so every loan remains reachable on a phone. Its accessible name tells VoiceOver what the region contains. The preview seeds example loans through `with_state_init`.

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum LoanStatus {
    CheckedOut,
    Returned,
}

impl LoanStatus {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::CheckedOut => "library.status.on_loan",
            Self::Returned => "library.status.returned",
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Loan {
    pub id: u32,
    pub title: &'static str,
    pub borrower: &'static str,
    pub due: &'static str,
    pub status: LoanStatus,

#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct LibraryState {
    pub loans: Vec<Loan>,

impl GlobalState for LibraryState {}

fission_component! {

## Update the loan record with a reducer

When a book comes back, every part of the app that reads the loan should see the return. Put the list in `LibraryState` (`GlobalState`) and make **Mark returned** a typed action. Its reducer finds a loan by stable ID, updates its status, and records a confirmation for the desk.

The filter has a different lifetime. A volunteer may show returns, then hide them to focus on books still out. It doesn’t belong in `LibraryState`, because another screen should not inherit this desk’s display choice. `LibraryLoanDesk` retains the filter locally; its button only changes which rows are visible.

Replace the read-only `src/app.rs` with the version below. `LoanSummary` reads shared records, `LoanCard` dispatches the return action, and `LibraryLoanDesk` owns the local filter. Each card is keyed by loan ID, so filtering the list won’t give one book another book’s widget identity.

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, yaml) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(yaml).expect("valid Riverside Library translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum LoanStatus {
    CheckedOut,
    Returned,
}

impl LoanStatus {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::CheckedOut => "library.status.on_loan",
            Self::Returned => "library.status.returned",
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum LoanNotice {
    Returned(&'static str),
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Loan {
    pub id: u32,
    pub title: &'static str,
    pub borrower: &'static str,
    pub due: &'static str,
    pub status: LoanStatus,
}

#[derive(Clone, Debug, PartialEq)]
pub struct LibraryState {
    pub loans: Vec<Loan>,
    pub notice: Option<LoanNotice>,
}

impl Default for LibraryState {
    fn default() -> Self {
        Self {
            loans: Vec::new(),
            notice: None,
        }
    }
}

impl GlobalState for LibraryState {}

#[fission_reducer(MarkLoanReturned)]
pub fn on_mark_loan_returned(state: &mut LibraryState, loan_id: u32) {
    let notice = state
        .loans
        .iter_mut()
        .find(|loan| loan.id == loan_id)
        .and_then(|loan| {
            if loan.status == LoanStatus::Returned {
                return None;
            }
            loan.status = LoanStatus::Returned;
            Some(LoanNotice::Returned(loan.title))
        });

    if let Some(notice) = notice {
        state.notice = Some(notice);
    }
}

fission_component! {
    pub LoanSummary<LibraryState> {}
    view(_summary, library, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let checked_out = library.loans.iter()
            .filter(|loan| loan.status == LoanStatus::CheckedOut)
            .count();
        let returned = library.loans.iter()
            .filter(|loan| loan.status == LoanStatus::Returned)
            .count();
    } =>
    SemanticsRegion(
        identifier: Some("library-loan-summary".to_string()),
        label: Some(cx.tr("library.summary.a11y")),
        child: Column(gap: tokens.spacing.xs, children: [
            Text(cx.tr("library.summary.on_loan").replace("{count}", &checked_out.to_string())),
            Text(cx.tr("library.summary.returned").replace("{count}", &returned.to_string()))
                .color(tokens.colors.text_secondary),
        ]),
    )
}

fission_component! {
    pub LoanCard<LibraryState> { loan: Loan }
    view(card, _library, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let label = cx.tr("library.card.a11y")
            .replace("{title}", card.loan.title)
            .replace("{borrower}", card.loan.borrower);
    } =>
    SemanticsRegion(
        identifier: Some(format!("library-loan-{}", card.loan.id)),
        label: Some(label),
        child: Container(
            Column(gap: tokens.spacing.xs, align_items: ir_op::AlignItems::Start, children: [
                Text(card.loan.title.to_string())
                    .weight(tokens.typography.font_weight_semibold),
                Text(cx.tr("library.borrowed_by").replace("{borrower}", card.loan.borrower))
                    .color(tokens.colors.text_secondary),
                Text(cx.tr("library.due").replace("{due}", card.loan.due))
                    .color(tokens.colors.text_secondary),
                Text(cx.tr(card.loan.status.translation_key()))
                    .color(tokens.colors.text_secondary),
                if card.loan.status == LoanStatus::CheckedOut {
                    Button(
                        child: Text(cx.tr("library.mark_returned")),
                        key: "mark-loan-returned",
                        variant: ButtonVariant::Primary,
                        on_press: with_reducer!(
                            cx.build,
                            MarkLoanReturned(card.loan.id),
                            on_mark_loan_returned,
                        ),
                    )
                    .semantics_identifier(format!("library-loan.return.{}", card.loan.id))
                } else {
                    Text(cx.tr("library.returned_to_shelf"))
                        .color(tokens.colors.text_secondary)
                },
            ]),
        )
        .padding_all(tokens.spacing.m)
        .bg(tokens.colors.surface)
        .border(tokens.colors.border, 1.0)
        .border_radius(tokens.radii.medium)
        .width_length(Length::percent(100.0)),
    )
}

fission_component! {
    pub LibraryLoanDesk<LibraryState> {
        state {
            show_returned: bool = false,
        }
    }
    view(desk, library, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let visible_loans: Vec<Loan> = library.loans.iter()
            .filter(|loan| desk.show_returned || loan.status != LoanStatus::Returned)
            .cloned()
            .collect();
    } =>
    SemanticsRegion(
        identifier: Some("riverside-library-returns-desk".to_string()),
        label: Some(cx.tr("library.desk.a11y")),
        child: Scroll(
            flex_grow: 1.0,
            height: cx.view.viewport_size().height,
            semantic_label: Some(cx.tr("library.loans.a11y")),
            child: Container(
                Column(align_items: ir_op::AlignItems::Center, children: [
                    Container(
                        Column(gap: tokens.spacing.l, children: [
                            Column(gap: tokens.spacing.xs, children: [
                                Text(cx.tr("library.name"))
                                    .weight(tokens.typography.font_weight_bold),
                                Text(cx.tr("library.returns_desk"))
                                    .color(tokens.colors.text_secondary),
                            ]),
                            LoanSummary(),
                            Button(
                                child: Text(if desk.show_returned {
                                    cx.tr("library.filter.active")
                                } else {
                                    cx.tr("library.filter.all")
                                }),
                                key: "toggle-returned-loans",
                                variant: ButtonVariant::Outline,
                                on_press: reduce {
                                    desk.show_returned = !desk.show_returned;
                                },
                            )
                            .semantics_identifier("library-loans.toggle-returned"),
                            if visible_loans.is_empty() {
                                Text(cx.tr("library.empty.active"))
                            } else {
                                Column(gap: tokens.spacing.s, children: [
                                    for loan in visible_loans.iter() {
                                        LoanCard(loan.clone(), key: loan.id)
                                            .id(WidgetId::explicit(&format!("riverside.loan.{}", loan.id)))
                                    },
                                ])
                            },
                            if let Some(LoanNotice::Returned(title)) = library.notice {
                                Text(cx.tr("library.notice.returned").replace("{title}", title))
                                    .color(tokens.colors.text_secondary)
                            },
                        ]),
                    )
                    .padding_all(tokens.spacing.l)
                    .bg(tokens.colors.background)
                    .width_length(Length::clamp(
                        Length::points(0.0),
                        Length::percent(100.0),
                        Length::points(760.0),
                    )),
                ]),
            )
            .width_length(Length::percent(100.0))
            .bg(tokens.colors.background),
        ),
    )
}

#[cfg(test)]
mod tests {
    use super::*;

    fn sample_loans() -> Vec<Loan> {
        vec![
            Loan { id: 4102, title: "The Rust Programming Language", borrower: "Ada", due: "Today, 4:30 pm", status: LoanStatus::CheckedOut },
            Loan { id: 4103, title: "The Left Hand of Darkness", borrower: "Mateo", due: "Yesterday", status: LoanStatus::CheckedOut },
            Loan { id: 4104, title: "A Field Guide to Trees", borrower: "Priya", due: "Returned at 11:10 am", status: LoanStatus::Returned },
            Loan { id: 4105, title: "Programming Rust", borrower: "Noah", due: "Tomorrow", status: LoanStatus::CheckedOut },
        ]
    }

    #[test]
    fn returning_a_loan_updates_the_shared_record() {
        let mut state = LibraryState::default();
        state.loans = sample_loans();

        on_mark_loan_returned(&mut state, 4105);

        let loan = state.loans.iter().find(|loan| loan.id == 4105).unwrap();
        assert_eq!(loan.status, LoanStatus::Returned);
        assert_eq!(state.notice, Some(LoanNotice::Returned("Programming Rust")));
    }

    #[test]
    fn returning_an_unknown_loan_changes_nothing() {
        let mut state = LibraryState::default();
        let original = state.clone();

        on_mark_loan_returned(&mut state, 9999);

        assert_eq!(state, original);
    }
}

## Run and verify the returns desk on iOS

The browser and native iOS shell use the same `LibraryLoanDesk`; there is no second screen to write in Swift. The host starts the Rust app and supplies the device window. Replace the generated `CounterApp` references in `src/lib.rs` with the desk and shared state. Leave `src/main.rs` to call `run_mobile` for iOS.

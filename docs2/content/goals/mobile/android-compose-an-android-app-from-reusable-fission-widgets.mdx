## The morning inspection round

You will build the morning inspection board used by a city tree-care crew. It shows which trees need attention, where each tree is, what the inspector found, and whether a crew has been assigned. Dispatch can assign an unowned inspection to the Green Crew; the card and the summary then update together.

The repeated card is a useful boundary because every inspection needs the same information and action. The dashboard arranges those cards and calculates the counts from the shared records. That separation keeps card presentation reusable while the app state remains the source of truth.

The browser example uses three representative records so you can try the workflow before opening an emulator. Those records live only in this example. A production app would load inspections from its service or local database through an effect.

## Create the Android project

Install the Fission CLI, create the project, and add Android as a target. If this is your first Android build, follow the [Android development setup guide](/blog/set-up-rust-android-gui-development-with-fission/) first; it covers the SDK, NDK, and emulator setup.

```sh
cargo install cargo-fission
fission init urban-tree-rounds
cd urban-tree-rounds
fission add-target android --project-dir .
```

Fission generates the Android host and a Rust application shell. Keep the records, reducers, and screen in shared Rust code. The generated Android project launches and packages that shared app; it should not contain a second copy of the inspection rules.

## Give each inspection a clear card

Start with the information a field crew needs before it walks to a tree: a stable inspection number, species, location, priority, and a concise report. A named `TreeInspectionCard` keeps that presentation consistent as the daily queue grows. Its props describe one inspection, so the parent can reuse it without the card reaching into unrelated app data.

Here is the first version of the board. It is deliberately read-only: first check that the repeated records are easy to scan, then add the assignment action in the next step.

## Compose the dispatch board from reusable components

Now connect the cards to app state. The board derives its counts from the inspection records, so assigning a crew cannot leave a separate summary number out of date. `TreeInspectionCard` receives one record and binds its button to a reducer; the reducer updates that record in `TreeRoundsState`. Every card uses the same component, while each button carries the ID of the record it represents.

The `key` on each card comes from the durable inspection ID. That identity matters when the list changes: Fission can keep retained widget state with the correct inspection instead of attaching it to whichever row happens to occupy the same position.

The combined source below is kept in one file so you can build and run the example without first creating modules. Once the feature grows, move the model, reducer, card, and screen into separate files; the component boundaries remain the same.

use fission::prelude::*;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum InspectionStatus {
    NeedsCrew,
    Scheduled,
    Completed,
}

impl InspectionStatus {
    fn label(self) -> &'static str {
        match self {
            Self::NeedsCrew => "Needs a crew",
            Self::Scheduled => "Scheduled",
            Self::Completed => "Completed",
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct TreeInspection {
    pub id: u32,
    pub species: &'static str,
    pub location: &'static str,
    pub priority: &'static str,
    pub finding: &'static str,
    pub reported_by: &'static str,
    pub status: InspectionStatus,
    pub assigned_crew: Option<&'static str>,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct TreeRoundsState {
    pub inspections: Vec<TreeInspection>,
    pub notice: String,
}

impl Default for TreeRoundsState {
    fn default() -> Self {
        Self {
            inspections: vec![
                TreeInspection {
                    id: 184,
                    species: "London plane",
                    location: "Alder Street · bus shelter",
                    priority: "Urgent",
                    finding: "A large limb split above the shelter after last night’s wind.",
                    reported_by: "Maya Jones",
                    status: InspectionStatus::NeedsCrew,
                    assigned_crew: None,
                },
                TreeInspection {
                    id: 207,
                    species: "Silver birch",
                    location: "Oak Lane · north playground gate",
                    priority: "Routine",
                    finding: "Inspect the raised root near the gate and mark the path safe.",
                    reported_by: "Pavel Singh",
                    status: InspectionStatus::Scheduled,
                    assigned_crew: Some("Green Crew"),
                },
                TreeInspection {
                    id: 213,
                    species: "Common lime",
                    location: "Mason Square · east entrance",
                    priority: "Routine",
                    finding: "Seasonal inspection found no work required.",
                    reported_by: "Tree team",
                    status: InspectionStatus::Completed,
                    assigned_crew: Some("Tree Team"),
                },
            ],
            notice: "One urgent tree needs a crew before the afternoon route.".to_string(),
        }
    }
}

impl GlobalState for TreeRoundsState {}

#[cfg(test)]
#[path = "app_tests.rs"]
mod app_tests;

fn assign_tree_to_green_crew(state: &mut TreeRoundsState, inspection_id: u32) {
    let Some(inspection) = state
        .inspections
        .iter_mut()
        .find(|inspection| inspection.id == inspection_id)
    else {
        return;
    };

    if inspection.status != InspectionStatus::NeedsCrew {
        return;
    }

    inspection.status = InspectionStatus::Scheduled;
    inspection.assigned_crew = Some("Green Crew");
    state.notice = format!(
        "TREE-{} is on the Green Crew’s afternoon route.",
        inspection.id,
    );
}

#[fission_reducer(AssignTreeToGreenCrew)]
pub fn on_assign_tree_to_green_crew(state: &mut TreeRoundsState, inspection_id: u32) {
    assign_tree_to_green_crew(state, inspection_id);
}

fission_component! {
    pub TreeInspectionCard<TreeRoundsState> { inspection: TreeInspection }
    view(card, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let assign = with_reducer!(
            cx.build,
            AssignTreeToGreenCrew(card.inspection.id),
            on_assign_tree_to_green_crew,
        );
    } =>
    SemanticsRegion(
        identifier: Some(format!("tree-inspection-{}", card.inspection.id)),
        label: Some(format!(
            "Tree inspection {}: {}, {}",
            card.inspection.id,
            card.inspection.species,
            card.inspection.location,
        )),
        child: Container(
            Column(gap: tokens.spacing.s, align_items: ir_op::AlignItems::Start, children: [
                Row(gap: tokens.spacing.s, children: [
                    Text(format!("TREE-{}", card.inspection.id))
                        .weight(tokens.typography.font_weight_semibold),
                    Text(card.inspection.priority)
                        .color(tokens.colors.text_secondary),
                    Text(card.inspection.status.label())
                        .color(tokens.colors.text_secondary),
                ]),
                Text(card.inspection.species)
                    .weight(tokens.typography.font_weight_bold),
                Text(card.inspection.location)
                    .color(tokens.colors.text_secondary),
                Text(card.inspection.finding),
                Text(format!("Reported by {}", card.inspection.reported_by))
                    .color(tokens.colors.text_secondary),
                if let Some(crew) = card.inspection.assigned_crew {
                    Text(format!("Assigned to {crew}"))
                        .color(tokens.colors.text_secondary)
                } else {
                    Button(
                        child: Text("Assign to Green Crew"),
                        key: "assign-to-green-crew",
                        variant: ButtonVariant::Primary,
                        on_press: assign,
                    )
                    .semantics_identifier(format!(
                        "tree-inspection.assign.{}",
                        card.inspection.id,
                    ))
                },
            ]),
        )
        .padding_all(tokens.spacing.m)
        .bg(tokens.colors.surface)
        .border(tokens.colors.border, 1.0)
        .border_radius(tokens.radii.medium)
        .width_length(Length::percent(100.0)),
    )
}

fission_component! {
    pub TreeRoundsDashboard<TreeRoundsState> {}
    view(_dashboard, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let needs_crew = state.inspections.iter()
            .filter(|inspection| inspection.status == InspectionStatus::NeedsCrew)
            .count();
        let scheduled = state.inspections.iter()
            .filter(|inspection| inspection.status == InspectionStatus::Scheduled)
            .count();
        let completed = state.inspections.iter()
            .filter(|inspection| inspection.status == InspectionStatus::Completed)
            .count();
    } =>
    SemanticsRegion(
        identifier: Some("cedar-county-tree-rounds".to_string()),
        label: Some("Cedar County tree inspection round".to_string()),
        child: Scroll(
            flex_grow: 1.0,
            height: cx.view.viewport_size().height,
            child: Container(
                Column(align_items: ir_op::AlignItems::Center, children: [
                    Container(
                        Column(gap: tokens.spacing.m, children: [
                            Column(gap: tokens.spacing.xs, children: [
                                Text("Cedar County Urban Forestry")
                                    .weight(tokens.typography.font_weight_bold),
                                Text("Morning inspection round · Wednesday, 8 May")
                                    .color(tokens.colors.text_secondary),
                            ]),
                            Text(format!(
                                "Needs a crew · {}     Scheduled · {}     Completed · {}",
                                needs_crew,
                                scheduled,
                                completed,
                            )),
                            Text(state.notice.clone())
                                .color(tokens.colors.text_secondary),
                            Column(gap: tokens.spacing.s, children: [
                                for inspection in state.inspections.iter().cloned() {
                                    TreeInspectionCard(
                                        inspection.clone(),
                                        key: inspection.id,
                                    )
                                },
                            ]),
                        ])
                    )
                    .padding_all(tokens.spacing.m)
                    .width_length(Length::clamp(
                        Length::points(0.0),
                        Length::percent(100.0),
                        Length::points(760.0),
                    ))
                    .bg(tokens.colors.background),
                ]),
            )
            .width_length(Length::percent(100.0))
            .bg(tokens.colors.background),
        ),
    )
}

fn assigning_a_tree_updates_its_record_and_dashboard_notice() {

## Run the same shared app on Android

Replace the generated `CounterApp` wiring in `src/lib.rs` with the Android shell below. The browser and Android shells then use the same `TreeRoundsState`, reducer, and dashboard component. The browser shell makes the interaction easy to inspect; the Android shell supplies the device window and generated host. No tree-assignment logic belongs in Android-specific code.

pub mod app;

use app::{TreeRoundsDashboard, TreeRoundsState};
use fission::prelude::*;

#[cfg(target_os = "android")]
const ANDROID_TEST_CONTROL_PORT: u16 = 48763;

#[cfg(any(target_os = "android", target_os = "ios"))]
fn mobile_app() -> MobileApp<TreeRoundsState, TreeRoundsDashboard> {
    let app = MobileApp::<TreeRoundsState, _>::new(TreeRoundsDashboard::new())
        .with_title("Cedar County tree inspections");
    #[cfg(target_os = "android")]
    let app = app.with_test_control_port(ANDROID_TEST_CONTROL_PORT);
    app
}

#[cfg(target_arch = "wasm32")]
fn web_app() -> WebApp<TreeRoundsState, TreeRoundsDashboard> {
    WebApp::<TreeRoundsState, _>::new(TreeRoundsDashboard::new())
        .with_title("Cedar County tree inspections")
}

#[cfg(not(any(target_arch = "wasm32", target_os = "android", target_os = "ios")))]
pub fn run_desktop() -> anyhow::Result<()> {
    DesktopApp::<TreeRoundsState, _>::new(TreeRoundsDashboard::new())
        .with_title("Cedar County tree inspections")
        .run()
}

#[cfg(any(target_os = "android", target_os = "ios"))]
pub fn run_mobile() -> anyhow::Result<()> {
    mobile_app().run()
}

#[cfg(target_os = "android")]
#[no_mangle]
fn android_main(app_handle: AndroidApp) {
    let _ = mobile_app().run_with_android_app(app_handle);
}

#[cfg(target_arch = "wasm32")]
#[wasm_bindgen::prelude::wasm_bindgen(start)]
pub fn run_web() -> Result<(), wasm_bindgen::JsValue> {
    console_error_panic_hook::set_once();
    web_app()
        .run()
        .map_err(|error| wasm_bindgen::JsValue::from_str(&error.to_string()))
}

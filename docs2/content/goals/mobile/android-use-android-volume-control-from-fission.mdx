## Treat system volume as a shared setting

System volume is not an application preference. Changing it can affect another app, and another app or the hardware buttons can change it again. That means a value in component state is only a snapshot, not the authority for the device's current audio level.

Here, the user first reads the media stream, then explicitly chooses a small adjustment. The screen displays the level returned by Android rather than calculating a result and pretending the system accepted it. It does not play audio, change notification policy or force a muted device to become audible.

## Read the actual stream before showing a level

The initial value is unknown. Do not display zero or a made-up percentage whilst waiting for the device. The reducer marks the operation pending, requests `GET_VOLUME_LEVEL`, and its callback reads the typed response from the reducer context.

Both read and adjust helpers are defined here so the result and error handling have one authority. This first screen exposes only the read operation.

use fission::prelude::*;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Pending { Read, Adjust }

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum VolumeIssue { Unsupported, Denied, Failed }

impl VolumeIssue {
    pub fn key(self) -> &'static str {
        match self {
            Self::Unsupported => "volume.unsupported",
            Self::Denied => "volume.denied",
            Self::Failed => "volume.failed",
        }
    }
}

#[derive(Debug, Default)]
pub struct VolumeState {
    pub confirmed: Option<VolumeLevel>,
    pub pending: Option<Pending>,
    pub issue: Option<VolumeIssue>,
}

impl GlobalState for VolumeState {}

pub fn read_level(state: &mut VolumeState, ctx: &mut ReducerContext<VolumeState>) {
    if state.pending.is_some() { return; }
    state.pending = Some(Pending::Read);
    state.issue = None;
    let ok = ctx.effects.bind(VolumeRead, reduce_with!(volume_read));
    let err = ctx.effects.bind(VolumeFailed, reduce_with!(volume_failed));
    ctx.effects.volume().get_level(VolumeStream::Media).on_ok(ok).on_err(err);
}

pub fn adjust_level(
    state: &mut VolumeState,
    ctx: &mut ReducerContext<VolumeState>,
    direction: VolumeAdjustDirection,
) {
    if state.pending.is_some() || state.confirmed.is_none() { return; }
    state.pending = Some(Pending::Adjust);
    state.issue = None;
    let ok = ctx.effects.bind(VolumeAdjusted, reduce_with!(volume_adjusted));
    let err = ctx.effects.bind(VolumeFailed, reduce_with!(volume_failed));
    ctx.effects.volume().adjust_level(VolumeAdjustRequest {
        stream: VolumeStream::Media,
        direction,
        step: 5,
    }).on_ok(ok).on_err(err);
}

fn accept_level(state: &mut VolumeState, response: Option<VolumeLevel>) {
    match response {
        Some(level) if level.stream == VolumeStream::Media && level.level <= 100 => {
            state.confirmed = Some(level);
            state.issue = None;
        }
        _ => state.issue = Some(VolumeIssue::Failed),
    }
}

#[fission_reducer(VolumeRead)]
fn volume_read(state: &mut VolumeState, ctx: &mut ReducerContext<VolumeState>) {
    if state.pending != Some(Pending::Read) { return; }
    state.pending = None;
    accept_level(state, ctx.input.capability_ok(GET_VOLUME_LEVEL));
}

#[fission_reducer(VolumeAdjusted)]
fn volume_adjusted(state: &mut VolumeState, ctx: &mut ReducerContext<VolumeState>) {
    if state.pending != Some(Pending::Adjust) { return; }
    state.pending = None;
    accept_level(state, ctx.input.capability_ok(ADJUST_VOLUME_LEVEL));
}

#[fission_reducer(VolumeFailed)]
fn volume_failed(state: &mut VolumeState, ctx: &mut ReducerContext<VolumeState>) {
    let code = match state.pending.take() {
        Some(Pending::Read) => ctx.input.capability_error(GET_VOLUME_LEVEL).map(|error| error.code),
        Some(Pending::Adjust) => ctx.input.capability_error(ADJUST_VOLUME_LEVEL).map(|error| error.code),
        None => return,
    };
    state.issue = Some(match code.as_deref() {
        Some("unsupported") => VolumeIssue::Unsupported,
        Some("permission_denied") => VolumeIssue::Denied,
        _ => VolumeIssue::Failed,
    });
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn invalid_response_does_not_replace_the_last_confirmed_media_level() {
        let mut state = VolumeState::default();
        accept_level(&mut state, Some(VolumeLevel {
            stream: VolumeStream::Media, level: 40, muted: false,
        }));
        accept_level(&mut state, Some(VolumeLevel {
            stream: VolumeStream::Alarm, level: 80, muted: false,
        }));
        assert_eq!(state.confirmed.as_ref().unwrap().level, 40);
        assert_eq!(state.issue, Some(VolumeIssue::Failed));
        accept_level(&mut state, None);
        assert_eq!(state.confirmed.as_ref().unwrap().level, 40);
    }
}

use fission::prelude::*;
use crate::state::{self, VolumeState};

fission_component! {
    pub VolumeScreen<VolumeState> {}
    view(_screen, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    SafeArea(
        child: Scroll(
            child: Container(
                child: Column(gap: tokens.spacing.m, children: [
                    Text(cx.tr("volume.title")).size(tokens.typography.heading2_size),
                    Text(cx.tr("volume.context")),
                    Button(
                        child: Text(cx.tr("volume.read")),
                        key: "read-media-volume",
                        disabled: state.pending.is_some(),
                        on_press: reduce { state::read_level(state, cx); },
                    ).semantics_identifier("volume.read"),
                    if let Some(level) = &state.confirmed {
                        Column(gap: tokens.spacing.s, children: [
                            Text(cx.tr("volume.last_confirmed").replace("{level}", &level.level.to_string())),
                            Text(cx.tr(if level.muted { "volume.muted" } else { "volume.not_muted" })),
                            Text(cx.tr("volume.snapshot_help")),
                        ])
                    } else {
                        Text(cx.tr("volume.not_read"))
                    },
                    if let Some(pending) = state.pending {
                        Spinner(
                            motion: Some(SpinnerMotion::Default),
                            label: cx.tr(match pending {
                                state::Pending::Read => "volume.reading",
                                state::Pending::Adjust => "volume.adjusting",
                            }),
                        )
                    },
                    if let Some(issue) = state.issue {
                        Text(cx.tr(issue.key())).color(tokens.colors.error)
                    },
                ]),
            ).padding_all(tokens.spacing.l),
        ),
    )
}

## Apply a deliberate change and display the returned value

A local slider that immediately displays its requested position can imply success before the system has done anything. For this shared device setting, use explicit actions and update the confirmed value only from the host's result.

The request below asks for a five-percentage-point adjustment to the media stream. Android exposes discrete hardware steps, so the returned percentage may differ from that request or remain unchanged. Repeatedly adding five to the displayed value would hide that difference.

## Check the device's limits and recovery path

```sh
cargo test
fission doctor android --project-dir .
fission run --target android --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
adb devices -l
fission run --target android --device <adb-serial> --project-dir .
```

Use a phone for the final checks. Read before and after one adjustment, test a bound, and observe mute and audio-route changes. Restore the user's intended level with the normal device controls; do not automatically restore a stale snapshot when the app closes, since the user may have changed it elsewhere.

An unsupported or failed operation should preserve the last confirmed display and offer the device controls as the recovery path. A failed request is not proof that the system setting stayed unchanged: part of a host operation may have completed before an error was reported.

`cargo test` checks the response-validation rule. `fission test` checks host startup, and the release build checks packaging. None of those checks establishes actual device volume behaviour or audibility.

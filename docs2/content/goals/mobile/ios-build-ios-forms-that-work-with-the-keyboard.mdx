A keyboard choice tells iOS how a value is normally entered; it does not prove that the value is valid. Pasted text, hardware keyboards and accessibility input can all produce something the software keyboard would not normally offer.

We will build a visitor check-in draft with a name and six-digit visit code. The code stays a string so its leading zeros survive. Validation prepares a typed request in application state; it does not claim that the code is genuine or that a check-in has been saved.

## Create the project and add the target

Complete [iOS setup](/blog/set-up-rust-ios-development-with-fission/) and [simulator setup](/blog/install-and-select-xcodes-ios-simulator-tools/) first.

```sh
cargo install cargo-fission
fission init ios-build-ios-forms-that-work-with-the-keyboard
cd ios-build-ios-forms-that-work-with-the-keyboard
fission add-target ios --project-dir .
cargo add serde_yaml
```

Keep the generated `src/main.rs` and install the shared form through `src/lib.rs` below. The browser preview changes only the mount point, not the validation rules or app.

## Give the draft a clear owner and an explicit submission boundary

Typing belongs to the form's retained local state. Only a validated snapshot becomes `VisitRequest` in `GlobalState`. Later edits do not silently rewrite that prepared request.

Each field has a stable ID. The same IDs address `TextEditingController` commands for focus, selection and dismissal; there is no separate selector language or guessed widget method.

use fission::prelude::*;

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct VisitRequest {
    pub contact_name: String,
    pub access_code: String,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct VisitState {
    pub last_prepared: Option<VisitRequest>,
    pub locale: Locale,
}

impl Default for VisitState {
    fn default() -> Self {
        Self {
            last_prepared: None,
            locale: Locale::from("en-US"),
        }
    }
}

impl GlobalState for VisitState {}

pub fn name_id() -> WidgetId {
    WidgetId::explicit("visit.contact-name")
}

pub fn code_id() -> WidgetId {
    WidgetId::explicit("visit.access-code")
}

pub fn valid_code(code: &str) -> bool {
    code.len() == 6 && code.bytes().all(|byte| byte.is_ascii_digit())
}

pub fn dismiss_keyboard(cx: &mut ReducerContext<VisitState>) {
    for id in [name_id(), code_id()] {
        cx.effects
            .text_editing(TextEditingController::new(id), TextEditingCommand::Unfocus);
    }
}

pub fn prepare_request(
    state: &mut VisitState,
    cx: &mut ReducerContext<VisitState>,
    name: &str,
    code: &str,
) {
    let invalid_id = if name.trim().is_empty() {
        Some(name_id())
    } else if !valid_code(code) {
        Some(code_id())
    } else {
        None
    };
    if let Some(id) = invalid_id {
        cx.effects
            .text_editing(TextEditingController::new(id), TextEditingCommand::Focus);
        return;
    }
    state.last_prepared = Some(VisitRequest {
        contact_name: name.trim().to_owned(),
        access_code: code.to_owned(),
    });
    dismiss_keyboard(cx);
}

use super::state::{code_id, dismiss_keyboard, name_id, prepare_request, valid_code, VisitState};
use fission::prelude::*;

fission_component! {
    pub VisitForm<VisitState> {
        state {
            contact_name: String = String::new(),
            access_code: String = String::new(),
            attempted: bool = false,
        }
    }
    view(form, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let name_error = if form.attempted && form.contact_name.trim().is_empty() {
            Some(cx.tr("form.name_error"))
        } else { None };
        let code_error = if form.attempted && !valid_code(&form.access_code) {
            Some(cx.tr("form.code_error"))
        } else { None };
    } => SafeArea(
        child: Scroll(
            child: Container(
                Column(gap: tokens.spacing.m, children: [
                    Text(cx.tr("form.title")).size(tokens.typography.heading2_size),
                    Text(cx.tr("form.explanation")),
                    Row(gap: tokens.spacing.s, children: [
                        Button(
                            child: Text(cx.tr("language.english")),
                            key: "english",
                            on_press: reduce { state.locale = Locale::from("en-US"); },
                        ),
                        Button(
                            child: Text(cx.tr("language.spanish")),
                            key: "spanish",
                            on_press: reduce { state.locale = Locale::from("es-ES"); },
                        ),
                    ]),
                    FormControl(
                        label: Some(cx.tr("form.name")),
                        error: name_error,
                        required: true,
                        child: TextInput(
                            id: Some(name_id()),
                            value: form.contact_name.clone(),
                            bind(on_input): to(form.contact_name),
                            keyboard_type: TextInputType::Name,
                            text_input_action: TextInputAction::Next,
                            on_submit: reduce {
                                cx.effects.text_editing(
                                    TextEditingController::new(code_id()),
                                    TextEditingCommand::Focus,
                                );
                            },
                            semantics_identifier: Some("visit.contact-name".into()),
                        ),
                    ),
                    FormControl(
                        label: Some(cx.tr("form.code")),
                        helper: Some(cx.tr("form.code_help")),
                        error: code_error,
                        required: true,
                        child: TextInput(
                            id: Some(code_id()),
                            value: form.access_code.clone(),
                            bind(on_input): to(form.access_code),
                            keyboard_type: TextInputType::Number,
                            text_input_action: TextInputAction::Done,
                            autocorrect: false,
                            on_submit: reduce {
                                form.attempted = true;
                                prepare_request(state, cx, &form.contact_name, &form.access_code);
                            },
                            semantics_identifier: Some("visit.access-code".into()),
                        ),
                    ),
                    Button(
                        child: Text(cx.tr("form.prepare")),
                        key: "prepare-visit",
                        on_press: reduce {
                            form.attempted = true;
                            prepare_request(state, cx, &form.contact_name, &form.access_code);
                        },
                    ),
                    Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                        Button(
                            child: Text(cx.tr("form.select_code")),
                            key: "select-code",
                            on_press: reduce {
                                let controller = TextEditingController::new(code_id());
                                cx.effects.text_editing(controller, TextEditingCommand::Focus);
                                cx.effects.text_editing(controller, TextEditingCommand::SelectAll);
                            },
                        ),
                        Button(
                            child: Text(cx.tr("form.dismiss")),
                            key: "dismiss-keyboard",
                            on_press: reduce { dismiss_keyboard(cx); },
                        ),
                    ]),
                    if let Some(request) = &state.last_prepared {
                        Text(cx.tr("form.last_prepared").replace("{name}", &request.contact_name))
                    },
                    Text(cx.tr("form.scope")).color(tokens.colors.text_secondary),
                ]),
            )
            .padding_all(tokens.spacing.l)
            .bg(tokens.colors.surface),
        ),
    )
}

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid visit translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

pub fn sync_env(state: &crate::app::VisitState, env: &mut Env) {
    env.locale = state.locale.clone();
}

## Treat focus and dismissal as explicit UI operations

The name field requests a Name keyboard and a Next action. Its submit handler focuses the code field through `cx.effects.text_editing`. The code field requests Number and Done, but the validator still requires six ASCII digits. A six-character string containing letters is not a valid code.

The Select code button queues Focus then SelectAll for the same retained field. Dismiss keyboard queues Unfocus without changing either draft. Preparing a valid request also dismisses focus. Neither operation treats dismissal itself as validation success.

`SafeArea` uses the shell's window insets around display cutouts and system UI. The `Scroll` gives the form a scrollable viewport. These widgets do not, by their names alone, establish that every iOS keyboard configuration is handled: verify the focused field and actions in the actual shell whilst the software keyboard is visible.

The browser uses the same controlled text values, bindings and reducer flow. It can exercise selection, validation and focus, but it cannot qualify an iPhone's keyboard layout, composition or inset behavior.

## Check the keyboard on the intended iOS target

```sh
fission doctor ios --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
```

Follow [simulator selection](/blog/choose-boot-and-launch-an-ios-simulator-with-fission/) and [physical iPhone installation](/blog/install-a-fission-app-on-a-physical-iphone/) for the target-specific commands. On a simulator, explicitly enable the software keyboard rather than testing only the Mac's hardware keyboard.

Check the final field and prepare action at a narrow phone size, with the keyboard open, in both languages and after rotation. Select text in the middle of a value and replace it; the caret should not jump to the start. Test paste, accented names and an input method with composition. Errors and their associations should remain understandable with VoiceOver.

An occluded final field, unreachable action or lost selection is a defect to reproduce in the shell, not a reason to claim the form is qualified because its source compiled. Keep native keyboard checks separate from the browser preview and launch smoke test.

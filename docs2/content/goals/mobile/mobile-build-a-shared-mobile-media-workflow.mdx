Sharing a camera button is not the same as sharing the media workflow. The important work is deciding when permission is requested, which asset the result belongs to, how its bytes are retained and what happens when a replacement fails.

We will capture an actual inspection photo for a user-entered asset and prepare a session-local repair review. The app keeps the note, image and their reference together. It never substitutes a memory-provider image or reports a stream identifier as if it were attached evidence.

## Create the shared project

Complete [Android SDK/NDK setup](/blog/set-up-rust-android-gui-development-with-fission/) and [iOS setup](/blog/set-up-rust-ios-development-with-fission/) first.

```sh
cargo install cargo-fission
fission init mobile-build-a-shared-mobile-media-workflow
cd mobile-build-a-shared-mobile-media-workflow
fission add-target android ios --project-dir .
fission add-capability camera --project-dir .
cargo add serde --features derive
cargo add serde_yaml
```

Inspect the generated Android permission declaration and iOS `NSCameraUsageDescription`. Give the latter an accurate purpose and check the final artifact. Keep the generated `src/main.rs`; normal native and Web launchers below register the shared stream-processing job.

## Use one real capture flow

This is the bounded photo workflow developed in [the iOS capture tutorial](/blog/capture-photos-and-use-the-flashlight-on-ios/), applied to a repair inspection rather than a preloaded delivery. Its provider boundary stays target-specific, whilst the app's state transitions and image preparation remain shared.

The global draft belongs to the inspection workflow, not one disposable camera widget. A capture snapshots its asset reference; a changed reference cannot silently inherit that photo. The prepared review contains its own note and actual image snapshot, not a boolean which merely suggests that evidence exists.

use fission::core::{CameraCapture, JobCtx, JobRef, JobSpec};
use serde::{Deserialize, Serialize};

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct PhotoRequest {
    pub reference: String,
    pub capture: CameraCapture,
}
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct InspectionPhoto {
    pub reference: String,
    pub bytes: Vec<u8>,
    pub content_type: String,
}
pub struct CollectPhoto;
impl JobSpec for CollectPhoto {
    type Request = PhotoRequest;
    type Ok = InspectionPhoto;
    type Err = String;
    const NAME: &'static str = "repair.collect-photo";
}
pub const COLLECT_PHOTO: JobRef<CollectPhoto> = JobRef::new(CollectPhoto::NAME);

pub async fn collect_photo(request: PhotoRequest, cx: JobCtx) -> Result<InspectionPhoto, String> {
    let mut stream = cx
        .open_data_stream(request.capture.stream)
        .map_err(|error| error.to_string())?;
    // Consume the one-shot handle even when its metadata fails these bounds.
    let pixels = u64::from(request.capture.width) * u64::from(request.capture.height);
    if pixels == 0 || pixels > 16_000_000 {
        return Err("Unsupported image dimensions".into());
    }
    if !matches!(
        request.capture.content_type.as_str(),
        "image/jpeg" | "image/png"
    ) {
        return Err("Only JPEG and PNG arrival photos are accepted".into());
    }
    let mut bytes = Vec::new();
    while let Some(chunk) = std::future::poll_fn(|cx| stream.as_mut().poll_next(cx)).await {
        let chunk = chunk.map_err(|error| error.to_string())?;
        let length = bytes
            .len()
            .checked_add(chunk.len())
            .ok_or("Image is too large")?;
        if length > 8 * 1024 * 1024 {
            return Err("Image exceeds the eight-MiB limit".into());
        }
        bytes.extend_from_slice(&chunk);
    }
    if bytes.is_empty() {
        return Err("The camera returned an empty image".into());
    }
    Ok(InspectionPhoto {
        reference: request.reference,
        bytes,
        content_type: request.capture.content_type,
    })
}

use super::jobs::{InspectionPhoto, PhotoRequest, COLLECT_PHOTO};
use fission::prelude::*;

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct ReviewSnapshot {
    pub reference: String,
    pub note: String,
    pub photo: InspectionPhoto,
}
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct RepairState {
    pub locale: Locale,
    pub reference: String,
    pub note: String,
    pub busy: bool,
    pub status_key: String,
    pub error: Option<String>,
    pub device: Option<CameraDevice>,
    pub photo: Option<InspectionPhoto>,
    pub capture_reference: Option<String>,
    pub torch_on: bool,
    pub torch_requested: Option<bool>,
    pub review: Option<ReviewSnapshot>,
}
impl Default for RepairState {
    fn default() -> Self {
        Self {
            locale: Locale::from("en-US"),
            reference: String::new(),
            note: String::new(),
            busy: false,
            status_key: "repair.ready".into(),
            error: None,
            device: None,
            photo: None,
            capture_reference: None,
            torch_on: false,
            torch_requested: None,
            review: None,
        }
    }
}
impl GlobalState for RepairState {}

fn unexpected(state: &mut RepairState) {
    state.busy = false;
    state.capture_reference = None;
    state.torch_requested = None;
    state.status_key = "repair.unexpected".into();
}

pub fn check_camera(state: &mut RepairState, cx: &mut ReducerContext<RepairState>) {
    if state.busy || state.torch_on {
        return;
    }
    state.busy = true;
    state.error = None;
    state.status_key = "repair.permission_pending".into();
    let ok = cx
        .effects
        .bind(PermissionReturned, reduce_with!(permission_returned));
    let err = cx.effects.bind(CameraFailed, reduce_with!(camera_failed));
    cx.effects
        .camera()
        .request_permission(CameraPermissionRequest { reason: None })
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(PermissionReturned)]
fn permission_returned(state: &mut RepairState, cx: &mut ReducerContext<RepairState>) {
    match cx.input.capability_ok(REQUEST_CAMERA_PERMISSION) {
        Some(CameraPermission::Granted) => {
            state.status_key = "repair.features_pending".into();
            let ok = cx
                .effects
                .bind(FeaturesReturned, reduce_with!(features_returned));
            let err = cx.effects.bind(CameraFailed, reduce_with!(camera_failed));
            cx.effects.camera().availability().on_ok(ok).on_err(err);
        }
        Some(CameraPermission::Denied | CameraPermission::Restricted) => {
            state.busy = false;
            state.device = None;
            state.status_key = "repair.denied".into();
        }
        Some(CameraPermission::Unknown) => {
            state.busy = false;
            state.device = None;
            state.status_key = "repair.unknown".into();
        }
        None => unexpected(state),
    }
}

#[fission_reducer(FeaturesReturned)]
fn features_returned(state: &mut RepairState, cx: &mut ReducerContext<RepairState>) {
    let Some(features) = cx.input.capability_ok(GET_CAMERA_AVAILABILITY) else {
        unexpected(state);
        return;
    };
    state.busy = false;
    if features.permission != CameraPermission::Granted {
        state.device = None;
        state.status_key = "repair.denied".into();
        return;
    }
    state.device = features
        .devices
        .iter()
        .find(|device| device.facing == CameraFacing::Back)
        .or_else(|| features.devices.first())
        .cloned();
    state.status_key = if state.device.is_some() {
        "repair.camera_ready"
    } else {
        "repair.unavailable"
    }
    .into();
}

pub fn capture(state: &mut RepairState, cx: &mut ReducerContext<RepairState>) {
    if state.busy || state.reference.trim().is_empty() {
        return;
    }
    let Some(device) = state.device.clone() else {
        return;
    };
    state.capture_reference = Some(state.reference.trim().to_owned());
    state.busy = true;
    state.error = None;
    state.status_key = "repair.capture_pending".into();
    let ok = cx.effects.bind(Captured, reduce_with!(captured));
    let err = cx.effects.bind(CameraFailed, reduce_with!(camera_failed));
    cx.effects
        .camera()
        .capture_photo(CameraCaptureRequest {
            camera_id: Some(device.id),
            facing: device.facing,
            resolution: Some(CameraResolution {
                width: 1600,
                height: 1200,
            }),
            format: CameraImageFormat::Jpeg,
            flash: CameraFlashMode::Off,
            quality: Some(88),
        })
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(Captured)]
fn captured(state: &mut RepairState, cx: &mut ReducerContext<RepairState>) {
    let Some(capture) = cx.input.capability_ok(CAPTURE_PHOTO) else {
        unexpected(state);
        return;
    };
    let Some(reference) = state.capture_reference.take() else {
        unexpected(state);
        return;
    };
    state.status_key = "repair.image_pending".into();
    let ok = cx
        .effects
        .bind(PhotoCollected, reduce_with!(photo_collected));
    let err = cx.effects.bind(PhotoFailed, reduce_with!(photo_failed));
    cx.effects
        .app(COLLECT_PHOTO, PhotoRequest { reference, capture })
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(PhotoCollected)]
fn photo_collected(state: &mut RepairState, cx: &mut ReducerContext<RepairState>) {
    state.busy = false;
    match cx.input.job_ok(COLLECT_PHOTO) {
        Some(photo) => {
            state.photo = Some(photo);
            state.status_key = "repair.attached".into();
        }
        None => unexpected(state),
    }
}

#[fission_reducer(PhotoFailed)]
fn photo_failed(state: &mut RepairState, cx: &mut ReducerContext<RepairState>) {
    state.busy = false;
    state.status_key = "repair.failed".into();
    state.error = cx.input.job_err(COLLECT_PHOTO);
    if state.error.is_none() {
        unexpected(state);
    }
}

pub fn toggle_torch(state: &mut RepairState, cx: &mut ReducerContext<RepairState>) {
    if state.busy {
        return;
    }
    let Some(device) = state.device.as_ref().filter(|device| device.has_flashlight) else {
        return;
    };
    let request = CameraFlashlightRequest {
        camera_id: Some(device.id.clone()),
        enabled: !state.torch_on,
        intensity: None,
    };
    state.torch_requested = Some(request.enabled);
    state.busy = true;
    state.error = None;
    state.status_key = "repair.torch_pending".into();
    let ok = cx.effects.bind(TorchChanged, reduce_with!(torch_changed));
    let err = cx.effects.bind(CameraFailed, reduce_with!(camera_failed));
    cx.effects
        .camera()
        .set_flashlight(request)
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(TorchChanged)]
fn torch_changed(state: &mut RepairState, cx: &mut ReducerContext<RepairState>) {
    state.busy = false;
    match (
        cx.input.capability_ok(SET_CAMERA_FLASHLIGHT),
        state.torch_requested.take(),
    ) {
        (Some(()), Some(enabled)) => {
            state.torch_on = enabled;
            state.status_key = "repair.torch_changed".into();
        }
        _ => unexpected(state),
    }
}

#[fission_reducer(CameraFailed)]
fn camera_failed(state: &mut RepairState, cx: &mut ReducerContext<RepairState>) {
    state.busy = false;
    state.capture_reference = None;
    state.torch_requested = None;
    let error = cx
        .input
        .capability_error(REQUEST_CAMERA_PERMISSION)
        .or_else(|| cx.input.capability_error(GET_CAMERA_AVAILABILITY))
        .or_else(|| cx.input.capability_error(CAPTURE_PHOTO))
        .or_else(|| cx.input.capability_error(SET_CAMERA_FLASHLIGHT));
    match error {
        Some(error) => {
            state.status_key = if error.code == "unsupported" {
                "repair.unavailable"
            } else {
                "repair.failed"
            }
            .into();
            state.error = Some(format!("{}: {}", error.code, error.message));
        }
        None => unexpected(state),
    }
}

pub fn prepare_review(state: &mut RepairState) {
    if state.busy {
        return;
    }
    let Some(photo) = state.photo.as_ref() else {
        return;
    };
    let reference = state.reference.trim();
    if reference.is_empty() || state.note.trim().is_empty() || photo.reference != reference {
        return;
    }
    state.review = Some(ReviewSnapshot {
        reference: reference.to_owned(),
        note: state.note.trim().to_owned(),
        photo: photo.clone(),
    });
}

    pub RepairScreen<RepairState> {}

        let image_width = (cx.view.viewport_size().width - 2.0 * tokens.spacing.l).clamp(1.0, 560.0);
    } => SafeArea(child: Scroll(child: Container(Column(gap: tokens.spacing.m, children: [
        Text(cx.tr("repair.title")).size(tokens.typography.heading2_size),
        Text(cx.tr("repair.explanation")),

                on_press: reduce { state.locale = Locale::from("en-US"); }),
            Button(child: Text(cx.tr("language.spanish")), key: "spanish",
                on_press: reduce { state.locale = Locale::from("es-ES"); }),
        ]),
        FormControl(
            label: Some(cx.tr("repair.reference")),
            required: true,
            child: TextInput(
                value: state.reference.clone(),
                bind(on_input): to(state.reference),
            ),
        ),
        FormControl(
            label: Some(cx.tr("repair.note")),
            required: true,
            child: TextInput(
                value: state.note.clone(),
                bind(on_input): to(state.note),
                multiline: true,
                keyboard_type: TextInputType::Multiline,

        Button(child: Text(cx.tr("repair.capture")), key: "capture",
            disabled: state.busy || state.device.is_none() || state.reference.trim().is_empty(),
            on_press: reduce { capture(state, cx); }),
        if state.device.as_ref().is_some_and(|device| device.has_flashlight) {
            Button(child: Text(cx.tr(if state.torch_on { "repair.torch_off" } else { "repair.torch_on" })),
                key: "torch", disabled: state.busy,
                on_press: reduce { toggle_torch(state, cx); })
        } else { Text(cx.tr("repair.no_torch")) },
        if state.busy {
            Spinner(motion: Some(SpinnerMotion::Default), label: Some(cx.tr(&state.status_key)))

        if let Some(error) = &state.error { Code(text: error.clone()) },

    ])).padding_all(tokens.spacing.l)))

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid voice note translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

pub fn sync_env(state: &crate::app::RepairState, env: &mut Env) {
    env.locale = state.locale.clone();
}

## Treat the stream as a resource, not a success message

The camera returns metadata and a one-shot stream handle. The registered job opens that handle, reads asynchronously with an eight-MiB bound and accepts only the documented JPEG/PNG dimensions. The old photo remains visible until a complete replacement has been collected. A metadata-only result never becomes a new attachment.

Both the shell and preview register that job. Forgetting the registration would leave a valid-looking button whose completion can never produce usable evidence. Each effect callback is explicitly bound and decodes its own actual typed result; there is no manually maintained second callback registry.

Only one capture, collection or torch request is admitted at a time. This makes the small workflow's ownership clear without an unnecessary operation-ID mechanism. If you allow concurrent work or switch inspections whilst operations are pending, add an explicit request identity and reject stale completions.

The current native iOS capture uses a still-photo API, not a live viewfinder. Its cancellation method is currently a no-op. This screen therefore promises neither interactive framing nor a functioning Cancel button. A product requiring those controls needs the corresponding native capture UI and lifecycle policy before release.

fission doctor android --project-dir .
fission run --target android --project-dir .

On macOS, launch the iOS simulator:

```sh
fission doctor ios --project-dir .
fission devices --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
```

Follow [physical iPhone installation](/blog/install-a-fission-app-on-a-physical-iphone/) for a signed phone build. Test real permission grant/denial, image contents, a larger image exceeding the bound, background/foreground transitions and torch on/off where reported. Switch language and inspect small-screen scrolling with the keyboard open.

A prepared repair review is not a submitted report. Persisting or uploading it requires a separate authenticated service flow which confirms the write before the UI reports durable success. Keep that result distinct from capturing bytes into session memory.

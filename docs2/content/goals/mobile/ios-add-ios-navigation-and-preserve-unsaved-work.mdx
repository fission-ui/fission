Leaving an editor does not have to mean discarding its work. A simpler rule is to retain the draft until the user explicitly saves or discards it. That makes in-app navigation and host Back safe without trying to infer intent from a route change.

We will build a service-note app with a home route, an editor and a real discard dialog. The note starts empty and comes from the user's input. Saved content and the draft belong to application state because they must outlive either route; whether the dialog is open is local editor state.

## Create the project and add the target

Complete [iOS setup](/blog/set-up-rust-ios-development-with-fission/) first.

```sh
cargo install cargo-fission
fission init ios-add-ios-navigation-and-preserve-unsaved-work
cd ios-add-ios-navigation-and-preserve-unsaved-work
fission add-target ios --project-dir .
cargo add serde_yaml
```

Keep the generated `src/main.rs` and replace `src/lib.rs`. Every shell installs the same route handler and shared app. This is normal Router navigation, not a boolean that selects one of two disconnected mock screens.

## Build the routes around a retained draft

The Router table contains lazy component values. Only the matched route builds its screen. The route handler mirrors `ShellRouteChanged` into application state, so host history and the rendered destination use the same route value.

use fission::prelude::*;

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct NotesState {
    pub current_path: String,
    pub saved_note: String,
    pub draft: String,
    pub locale: Locale,
}

impl Default for NotesState {
    fn default() -> Self {
        Self {
            current_path: "/".into(),
            saved_note: String::new(),
            draft: String::new(),
            locale: Locale::from("en-US"),
        }
    }
}

impl GlobalState for NotesState {}

pub fn route_changed(
    state: &mut NotesState,
    action: fission::core::action::ShellRouteChanged,
    _cx: &mut ReducerContext<NotesState>,
) {
    state.current_path = action.location.pathname;
}

use super::state::NotesState;
use fission::prelude::*;

fission_component! {
    pub NoteEditor<NotesState> {
        state {
            confirm_discard: bool = false,
        }
    }
    view(editor, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let dirty = state.draft != state.saved_note;
    } => Column(gap: tokens.spacing.m, children: [
        Text(cx.tr("notes.editor")).size(tokens.typography.heading2_size),
        TextInput(
            value: state.draft.clone(),
            bind(on_input): to(state.draft),
            label: Some(TextContent::Key("notes.note_label".into())),
            multiline: true,
            semantics_identifier: Some("notes.draft".into()),
        ),
        Text(cx.tr(if dirty { "notes.unsaved" } else { "notes.no_changes" })),
        Button(
            child: Text(cx.tr("notes.save_session")),
            key: "save-session-note",
            disabled: !dirty,
            on_press: reduce { state.saved_note = state.draft.clone(); },
        ),
        Button(
            child: Text(cx.tr("notes.back")),
            key: "back-to-notes",
            on_press: reduce { cx.effects.replace_route("/"); },
        ),
        Button(
            child: Text(cx.tr("notes.discard")),
            key: "request-discard",
            disabled: !dirty,
            on_press: reduce { editor.confirm_discard = true; },
        ),
        Modal(
            id: WidgetId::explicit("notes.discard-dialog"),
            title: cx.tr("notes.discard_title"),
            is_open: editor.confirm_discard,
            on_dismiss: reduce { editor.confirm_discard = false; },
            content: Column(gap: tokens.spacing.m, children: [
                Text(cx.tr("notes.discard_explanation")),
                Button(
                    child: Text(cx.tr("notes.keep_editing")),
                    key: "keep-editing",
                    on_press: reduce { editor.confirm_discard = false; },
                ),
                Button(
                    child: Text(cx.tr("notes.confirm_discard")),
                    key: "confirm-discard",
                    on_press: reduce {
                        state.draft = state.saved_note.clone();
                        editor.confirm_discard = false;
                    },
                ),
            ]),
        ),
    ])
}

use super::editor::NoteEditor;
use super::home::NotesHome;
use super::state::NotesState;
use fission::prelude::*;

fission_component! {
    pub UnknownRoute<NotesState> {}
    view(_unknown, _state, cx) => Column(children: [
        Text(cx.tr("notes.not_found")),
        Button(
            child: Text(cx.tr("notes.home")),
            key: "recover-home",
            on_press: reduce { cx.effects.replace_route("/"); },
        ),
    ])
}

fission_component! {
    pub NotesApp<NotesState> {}
    view(_app, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let router = Router::<NotesState>::new()
            .with_path(state.current_path.clone())
            .route_component("/", NotesHome)
            .route_component("/notes/edit", NoteEditor)
            .not_found(|| UnknownRoute);
    } => SafeArea(
        child: Scroll(
            child: Container(
                Column(gap: tokens.spacing.m, children: [
                    Row(gap: tokens.spacing.s, children: [
                        Button(
                            child: Text(cx.tr("language.english")),
                            key: "english",
                            on_press: reduce { state.locale = Locale::from("en-US"); },
                        ),
                        Button(
                            child: Text(cx.tr("language.spanish")),
                            key: "spanish",
                            on_press: reduce { state.locale = Locale::from("es-ES"); },
                        ),
                    ]),
                    router,
                ]),
            )
            .padding_all(tokens.spacing.l)
            .bg(tokens.colors.surface),
        ),
    )
}

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid navigation translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

pub fn sync_env(state: &crate::app::NotesState, env: &mut Env) {
    env.locale = state.locale.clone();
}

        .mount("#fission-web-mount")
        .run()
        .map_err(|error| JsValue::from_str(&error.to_string()))
}

## Confirm destructive intent, not ordinary navigation

Back to notes replaces the current route with home and preserves the draft. Host Back also leaves the draft alone because route changes never clear it. There is no invented universal navigation-guard API here, and no promise to intercept every operating-system gesture.

Discard is different: it opens the built-in Modal. Cancelling or dismissing that dialog changes no note data. Confirming replaces the draft with the saved snapshot. If the note has never been saved, that snapshot is empty; the dialog describes the consequence before applying it.

Saving here updates session state, not a database or server. A durable product would request its normal asynchronous save and update the saved snapshot only after success, keeping the draft and error visible on failure. See [persistent iOS state](/blog/persist-ios-app-state-with-fission-store-and-sqlite/) for that separate boundary.

Web uses the supported hash routing mode. The embedded preview sets its deployment base to the current tutorial document, so changing routes stays inside that document rather than replacing it with a nonexistent site page. That preview-only mount configuration is not application routing logic.

## Check host history without confusing it with storage

```sh
fission doctor ios --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
```

Use [simulator selection](/blog/choose-boot-and-launch-an-ios-simulator-with-fission/) and [iPhone installation](/blog/install-a-fission-app-on-a-physical-iphone/) for setup. Repeat the edit/return/save/discard sequence on the actual target and test host Back where the active shell exposes it. An iOS gesture is not qualified by a browser history test.

Inspect the modal's focus and dismissal with VoiceOver, then try long notes and both languages at phone width. A launch smoke test does not drive these decisions or verify unsaved-data handling.

Reloading deliberately clears the in-memory example. Route retention is not persistence across process termination. Never describe a draft as durable merely because it survived a screen change.

A delivery coordinator copies instructions from another application and pastes them into the current delivery note. Reading the clipboard is host work: it can complete later, contain no text, or fail because access is unavailable. The screen should remain useful in all three cases.

There is a less obvious case too. The coordinator can start typing while the read is pending. Applying the earlier clipboard result unconditionally would then destroy the newer draft. We will record which draft revision the request belongs to and compare it with the current revision before accepting the result.

The small string checks in this example stay synchronous. Marking a function `async` does not make those checks faster or move CPU work off the UI thread. It is the clipboard request—not an artificially delayed validation—that crosses the effect boundary.

## Request the read without taking ownership of future edits

The draft is application data. Its `revision` changes whenever the text changes. `pending_revision` records the revision at the start of the one permitted clipboard request; it is not the current value of the text and must not change as someone types.

The starting reducer binds both completion actions before borrowing the effect builder. Each callback reads the actual result from `cx.input`. An authored action payload would carry the value supplied when the action was bound, not the value returned by the host.

The button disables additional paste requests while one is pending, but the text field remains editable. A spinner represents pending work. Empty and failed reads preserve the draft and allow another attempt.

```rust
use fission::prelude::*;

#[derive(Clone, Debug, Default, PartialEq)]
pub struct NoteState {
    pub draft: String,
    pub revision: u64,
    pub pending_revision: Option<u64>,
    pub status: &'static str,
    pub error: Option<String>,
}
impl GlobalState for NoteState {}

impl NoteState {
    pub fn edit(&mut self, text: String) {
        self.draft = text;
        self.revision += 1;
        self.status = "paste.status.editing";
        self.error = None;
    }

    pub fn begin_paste(&mut self) -> bool {
        if self.pending_revision.is_some() {
            return false;
        }
        self.pending_revision = Some(self.revision);
        self.status = "paste.status.pending";
        self.error = None;
        true
    }

    pub fn complete_paste(&mut self, result: Result<Option<String>, String>) {
        let Some(request_revision) = self.pending_revision.take() else { return };
        if request_revision != self.revision {
            self.status = "paste.status.ignored";
            return;
        }
        match result {
            Ok(Some(text)) if !text.trim().is_empty() => {
                if text.chars().count() > 2000 {
                    self.status = "paste.status.too_long";
                    return;
                }
                self.edit(text);
                self.status = "paste.status.pasted";
            }
            Ok(_) => self.status = "paste.status.empty",
            Err(error) => {
                self.status = "paste.status.failed";
                self.error = Some(error);
            }
        }
    }
}
```

```rust
use fission::prelude::*;
use crate::state::NoteState;

pub fn request_paste(state: &mut NoteState, cx: &mut ReducerContext<NoteState>) {
    if !state.begin_paste() { return; }
    let ok = cx.effects.bind(PasteCompleted, reduce_with!(paste_completed));
    let err = cx.effects.bind(PasteFailed, reduce_with!(paste_failed));
    cx.effects.clipboard().read_text().on_ok(ok).on_err(err);
}

#[fission_reducer(PasteCompleted)]
fn paste_completed(state: &mut NoteState, cx: &mut ReducerContext<NoteState>) {
    let result = cx.input.capability_ok(READ_CLIPBOARD_TEXT)
        .map(|value| value.text)
        .ok_or_else(|| "Clipboard completion had no text result".to_owned());
    state.complete_paste(result);
}

#[fission_reducer(PasteFailed)]
fn paste_failed(state: &mut NoteState, cx: &mut ReducerContext<NoteState>) {
    let error = cx.input.capability_error(READ_CLIPBOARD_TEXT)
        .map(|error| error.message)
        .or_else(|| cx.input.capability_error_message(READ_CLIPBOARD_TEXT).map(str::to_owned))
        .unwrap_or_else(|| "Clipboard read failed".to_owned());
    state.complete_paste(Err(error));
}
```

```rust
use fission::prelude::*;
use crate::{reducers::request_paste, state::NoteState};

fission_component! {
    pub DeliveryNote<NoteState> {}
    view(_note, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let status = if state.status.is_empty() { "paste.status.ready" } else { state.status };
    } =>
    Container(SafeArea(child: Scroll(child: Container(
        Column(gap: tokens.spacing.m, children: [
            Text(cx.tr("paste.title")).size(tokens.typography.heading2_size),
            Text(cx.tr("paste.summary")).color(tokens.colors.text_secondary),
            TextInput(
                label: Some(cx.tr("paste.note.label").into()),
                value: state.draft.clone(),
                multiline: true,
                min_lines: Some(4),
                max_lines: Some(8),
                max_length: Some(2000),
                semantics_identifier: Some("delivery-note.draft".into()),
                on_input: reduce {
                    if let Some(change) = cx.input.text_change() {
                        state.edit(change.new_text.clone());
                    }
                },
            ),
            Button(
                child: Text(cx.tr("paste.action")),
                key: "paste-note",
                disabled: state.pending_revision.is_some(),
                on_press: reduce { request_paste(state, cx); },
            ).semantics_identifier("delivery-note.paste"),
            if state.pending_revision.is_some() { Spinner(motion: Some(SpinnerMotion::Default), label: Some(cx.tr("paste.status.pending"))) },
            Text(cx.tr(status)),
            if let Some(error) = &state.error {
                Code(text: error.clone())
            },
            Text(cx.tr("paste.scope")).color(tokens.colors.text_secondary),
        ])
    ).padding_all(tokens.spacing.l)
     .width_length(Length::percent(100.0))
     .max_width(720.0))))
    .height_length(Length::vh(100.0))
}
```

## Prove that a late result cannot replace newer work

The host may complete too quickly to reproduce a race by hand. Test the ordering directly: begin a read, edit the draft, then deliver the old result. No sleep or live clipboard is needed, so the test is deterministic and does not read private data from the developer's machine.

The same rule applies to a network lookup or a database load that would replace editable data: capture the operation's relevant revision, then compare it in the completion reducer. Ignoring a stale completion is not cancellation. The operation has still run; this code only decides whether its result may change the current draft.

```rust
#[derive(Clone, Debug, Default, PartialEq)]
pub struct NoteState {
    pub draft: String,
    pub revision: u64,
    pub pending_revision: Option<u64>,
    pub status: &'static str,
    pub error: Option<String>,
}
impl GlobalState for NoteState {}

impl NoteState {
    pub fn edit(&mut self, text: String) {
        self.draft = text;
        self.revision += 1;
        self.status = "paste.status.editing";
        self.error = None;
    }

    pub fn begin_paste(&mut self) -> bool {
        if self.pending_revision.is_some() {
            return false;
        }
        self.pending_revision = Some(self.revision);
        self.status = "paste.status.pending";
        self.error = None;
        true
    }

    pub fn complete_paste(&mut self, result: Result<Option<String>, String>) {
        let Some(request_revision) = self.pending_revision.take() else { return };
        if request_revision != self.revision {
            self.status = "paste.status.ignored";
            return;
        }
        match result {
            Ok(Some(text)) if !text.trim().is_empty() => {
                if text.chars().count() > 2000 {
                    self.status = "paste.status.too_long";
                    return;
                }
                self.edit(text);
                self.status = "paste.status.pasted";
            }
            Ok(_) => self.status = "paste.status.empty",
            Err(error) => {
                self.status = "paste.status.failed";
                self.error = Some(error);
            }
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn unchanged_draft_accepts_the_result_once() {
        let mut state = NoteState::default();
        assert!(state.begin_paste());
        assert!(!state.begin_paste());
        state.complete_paste(Ok(Some("Leave at the staffed reception.".into())));
        assert_eq!(state.draft, "Leave at the staffed reception.");
        state.complete_paste(Ok(Some("Duplicate completion".into())));
        assert_eq!(state.draft, "Leave at the staffed reception.");
    }

    #[test]
    fn typing_during_the_read_preserves_the_newer_edit() {
        let mut state = NoteState::default();
        state.begin_paste();
        state.edit("Use the side entrance.".into());
        state.complete_paste(Ok(Some("Older copied instructions".into())));
        assert_eq!(state.draft, "Use the side entrance.");
        assert_eq!(state.status, "paste.status.ignored");
        assert!(state.pending_revision.is_none());
    }

    #[test]
    fn denied_or_empty_reads_preserve_the_existing_draft() {
        let mut state = NoteState::default();
        state.edit("Fragile parcel.".into());
        state.begin_paste();
        state.complete_paste(Err("permission_denied".into()));
        assert_eq!(state.draft, "Fragile parcel.");
        assert_eq!(state.error.as_deref(), Some("permission_denied"));
        assert!(state.begin_paste());
        state.complete_paste(Ok(None));
        assert_eq!(state.draft, "Fragile parcel.");
        assert!(state.error.is_none());
    }

    #[test]
    fn oversized_text_is_not_installed_in_the_field() {
        let mut state = NoteState::default();
        state.begin_paste();
        state.complete_paste(Ok(Some("x".repeat(2001))));
        assert!(state.draft.is_empty());
        assert_eq!(state.status, "paste.status.too_long");
    }
}
```

## Verify the real Android host

The browser preview uses its own host. Browser clipboard policy can require a secure context, focus and a user gesture; an unsupported or denied response is an outcome to handle, not permission to install a memory provider in production. Native Android clipboard behaviour must be checked on Android.

```sh
cargo test
fission doctor android --project-dir .
./platforms/android/run-emulator.sh
adb devices -l
fission run --target android --device <adb-serial> --project-dir .
fission logs --target android --device <adb-serial> --project-dir . --follow
```

The [emulator tutorial](/blog/create-and-launch-a-fission-android-emulator/) and [physical-phone tutorial](/blog/run-a-fission-app-on-a-physical-android-phone/) cover the launch prerequisites. On the selected target, copy plain text in another application, return to this app and paste it. Then try an empty clipboard and background the app during a read. Verify the actual response without assuming that the operating system leaves clipboard access unchanged while the app is in the background.

This tutorial replaces the field contents deliberately. A full editor should instead reconcile insertion at the current selection; that is a different editing contract, not something to approximate with string offsets here.

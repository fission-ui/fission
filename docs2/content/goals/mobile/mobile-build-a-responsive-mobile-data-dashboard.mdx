## Create a shared Android and iOS project

The dashboard belongs in shared Rust code. Fission generates a small host for each platform; the screen, chart and layout rules stay in the same app module so both targets present the same information.

Install the Fission CLI once, then create the project and add both mobile targets:

```sh
cargo install cargo-fission
fission init cedar-peak-solar
cd cedar-peak-solar
```

We will build a fleet overview for Cedar Peak Solar. An operator needs to compare generated energy with the expected forecast, see whether any site needs inspection, and change the time window without losing the summary. The numbers below are named sample records held in the preview; the controls update them in memory and make no network or hardware claims.

## Give each metric enough context to be useful

A dashboard number needs a label and a comparison. “318” is hard to act on; “318 MWh generated against a 336 MWh forecast” tells the operator how the fleet is performing. We will make the metric and site-status rows reusable, then compose them into the first version of the fleet screen.

The status text is part of the row, not just its colour. That keeps “Inspect” and “Telemetry delayed” understandable with assistive technology and when the screen is viewed in grayscale.

use fission::prelude::*;

fission_component! {
    pub SolarMetric<()> {
        props { label: String, value: String, detail: String }
    }
    view(metric, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(Column(gap: tokens.spacing.xs, children: [
        Text(metric.label.clone()).color(tokens.colors.text_secondary),
        Text(metric.value.clone()).weight(tokens.typography.font_weight_bold),
        Text(metric.detail.clone()).color(tokens.colors.text_secondary),
    ]))
        .padding_all(tokens.spacing.m)
        .bg(tokens.colors.surface)
        .border(tokens.colors.border, 1.0)
        .border_radius(tokens.radii.medium)
}

fission_component! {
    pub SolarSiteStatus<()> {
        props { site: String, location: String, status: String, detail: String }
    }
    view(site, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;

    SemanticsRegion(

        label: Some(format!("{} at {}: {}. {}", site.site, site.location, site.status, site.detail)),

## Add the generation trend and adapt the layout

The operator can inspect the current week or zoom out to four weeks. Keep the generated and forecast series together in one chart: separate charts would make their differences harder to compare. The text summary is calculated from the same values, so the result remains clear without relying on bar height or colour.

`Responsive` changes the composition at 920 points. On a wider window, the trend and site health sit side by side. On a phone, they stack in reading order. The chart receives a width derived from the active viewport so its labels and bars fit inside either arrangement.

The 7-day and 30-day values are named in the component because this example has no service yet. When a service is added, keep the range selection in local UI state and send the selected period through an effect; do not start a request while converting a component.

use fission::prelude::*;
use fission::charts::{Axis, BarSeries, Chart, Legend, Tooltip};

fission_component! {
    pub SolarGenerationTrend<()> {
        props { width: f32 }
        state { thirty_days: bool = false }
    }
    view(trend, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let labels = if trend.thirty_days {
            vec!["Week 1", "Week 2", "Week 3", "Week 4"]
        } else {
            vec!["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]
        };
        let generated = if trend.thirty_days {
            vec![312.0, 328.0, 341.0, 359.0]
        } else {
            vec![42.0, 38.0, 51.0, 54.0, 49.0, 36.0, 48.0]
        };
        let forecast = if trend.thirty_days {
            vec![340.0, 340.0, 360.0, 370.0]
        } else {
            vec![46.0, 45.0, 50.0, 52.0, 51.0, 42.0, 50.0]
        };
        let generated_total: u32 = generated.iter().map(|value| *value as u32).sum();
        let forecast_total: u32 = forecast.iter().map(|value| *value as u32).sum();
        let percent = (generated_total as f32 / forecast_total as f32 * 100.0).round() as u32;
        let period = if trend.thirty_days { "30 days" } else { "7 days" };
        let chart: Widget = Chart::new()
            .width(trend.width)
            .height(300.0)
            .title("Generated energy and forecast")
            .x_axis(Axis::category(labels))
            .y_axis(Axis::value())
            .legend(Legend::top_right())
            .tooltip(Tooltip::axis_trigger())
            .series(vec![
                BarSeries::new("Generated").data(generated).into(),
                BarSeries::new("Forecast").data(forecast).into(),
            ])
            .into();
    } =>
    SemanticsRegion(
        identifier: Some("cedar-peak-generation-trend".to_string()),
        label: Some("Cedar Peak Solar generated energy compared with forecast".to_string()),
        child: Container(Column(gap: tokens.spacing.m, children: [
            Row(gap: tokens.spacing.m, align_items: ir_op::AlignItems::Center, children: [
                Column(gap: tokens.spacing.xs, children: [
                    Text("Generation trend").weight(tokens.typography.font_weight_semibold),
                    Text(format!("Fleet output over {period}")).color(tokens.colors.text_secondary),
                ]),
                Spacer(flex_grow: 1.0),
                Badge(text: format!("{percent}% of forecast")),
            ]),
            Row(gap: tokens.spacing.s, children: [
                Button(
                    child: Text("7 days"),
                    key: "solar-range-seven-days",
                    variant: if trend.thirty_days { ButtonVariant::Outline } else { ButtonVariant::Primary },
                    on_press: reduce { trend.thirty_days = false; },
                ),
                Button(
                    child: Text("30 days"),
                    key: "solar-range-thirty-days",
                    variant: if trend.thirty_days { ButtonVariant::Primary } else { ButtonVariant::Outline },
                    on_press: reduce { trend.thirty_days = true; },
                ),
            ]),
            chart,
            Text(format!("{generated_total} MWh generated against a {forecast_total} MWh forecast across {period}."))
                .color(tokens.colors.text_secondary),
        ]))
            .padding_all(tokens.spacing.l)
            .bg(tokens.colors.surface)
            .border(tokens.colors.border, 1.0)
            .border_radius(tokens.radii.large),
    )
}

fission_component! {

        props { chart_width: f32 }
    }
    view(insights, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Column(gap: tokens.spacing.m, children: [
        SolarGenerationTrend(insights.chart_width, key: "solar-trend"),
        SolarFleetHealth(insights.chart_width, key: "site-health-compact"),
    ])
}

fission_component! {
    pub SolarFleetDashboard<()> {}
    view(_dashboard, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let viewport_width = cx.view.env().viewport_size.width;
        let inner_width = (viewport_width - tokens.spacing.l * 4.0).max(280.0);
        let wide_chart_width = (inner_width * 0.60 - tokens.spacing.l * 2.0).max(260.0);
        let wide_health_width = (inner_width * 0.32 - tokens.spacing.l * 2.0).max(220.0);
    } =>
    SemanticsRegion(
        identifier: Some("cedar-peak-solar-dashboard".to_string()),
        label: Some("Cedar Peak Solar fleet operations dashboard".to_string()),
        child: Container(Column(gap: tokens.spacing.l, children: [
            Row(gap: tokens.spacing.m, align_items: ir_op::AlignItems::Center, children: [
                Column(gap: tokens.spacing.xs, children: [
                    Text("Cedar Peak Solar").weight(tokens.typography.font_weight_bold),
                    Text("Fleet operations · 3 sites").color(tokens.colors.text_secondary),
                ]),
                Spacer(flex_grow: 1.0),
                Badge(text: "Sample operations data".to_string()),
            ]),
            Column(gap: tokens.spacing.xs, children: [
                Text("Generation overview").weight(tokens.typography.font_weight_bold),
                Text("Compare site output with forecast, then investigate the exceptions.")
                    .color(tokens.colors.text_secondary),
            ]),
            SolarMetricsWide(),
            Responsive::new(SolarInsightsWide {
                chart_width: wide_chart_width,
                health_width: wide_health_width,
            })
                .id(WidgetId::explicit("cedar-peak.insights"))
                .case(ResponsiveCase::max_width(
                    920.0,
                    SolarInsightsCompact { chart_width: inner_width },
                )),
        ]))
            .padding_all(tokens.spacing.l)
            .bg(tokens.colors.background),
    )
}

## Verify the dashboard on Android and iOS

The browser preview helps check the chart controls and responsive branches. It cannot prove that the app respects safe areas, that a platform text-size setting is handled well, or that a native host launches. Check both mobile targets because they share the Rust screen but use separate generated hosts.

First check that the project compiles, then run the app on an emulator or Simulator. Resize or rotate the device and inspect the header, metrics, chart labels and site rows at the largest supported text size.

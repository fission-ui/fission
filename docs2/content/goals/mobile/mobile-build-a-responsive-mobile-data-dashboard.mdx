## Compare the same observations

A solar fleet operator needs to distinguish low production from missing telemetry. Treating a missing reading as zero creates a convincing chart of a result that was never measured. Comparing reported generation with the forecast for a larger, unmatched fleet is misleading for a different reason.

This dashboard imports a report containing site/day readings and forecasts. It compares actual energy with the forecast for those same reported rows, while separately showing forecast energy awaiting telemetry. Below-forecast output is a reason to review the source and conditions, not proof that an inverter has failed.

## Preserve missing data as a separate fact

The input uses five tab-separated columns without a header:

```text
days_ago    site_id    site_name    generated_kwh    forecast_kwh
```

Use actual tab separators, whole kWh counts, and the literal machine value `missing` when an expected generation reading was not supplied. An actual measured zero is `0`; those values must not become interchangeable. The parser rejects duplicates, inconsistent names for one site ID, invalid counts and oversized input before replacing the current report.

Day 0 is the supplied reporting endpoint. The seven-day window covers offsets 0–6 and thirty days covers 0–29. Every row must refer to the same endpoint and compatible energy interval. A label does not perform calendar arithmetic or verify the source's forecast method.

use std::collections::{BTreeMap, BTreeSet};
use fission::prelude::*;

#[derive(Debug, Clone)]
pub struct SolarReading {
    pub days_ago: u8,
    pub site_id: String,
    pub site_name: String,
    pub generated_kwh: Option<u32>,
    pub forecast_kwh: u32,
}
#[derive(Debug, Clone)]
pub struct SolarReport { pub endpoint: String, pub rows: Vec<SolarReading> }
#[derive(Debug, Default)]
pub struct SolarDashboardState {
    pub report: Option<SolarReport>,
    pub import_issue: Option<&'static str>,
}
impl GlobalState for SolarDashboardState {}

pub fn parse_report(endpoint: &str, raw: &str) -> Result<SolarReport, &'static str> {
    if endpoint.trim().is_empty() || endpoint.chars().count() > 80 || raw.len() > 256 * 1024 {
        return Err("solar.invalid");
    }
    let mut rows = Vec::new();
    let mut seen = BTreeSet::new();
    let mut names: BTreeMap<String, String> = BTreeMap::new();
    for line in raw.lines().filter(|line| !line.trim().is_empty()) {
        let fields: Vec<&str> = line.split('\t').collect();
        if fields.len() != 5 || rows.len() >= 1_500 { return Err("solar.invalid"); }
        let days_ago: u8 = fields[0].trim().parse().map_err(|_| "solar.invalid")?;
        let site_id = fields[1].trim();
        let site_name = fields[2].trim();
        let generated_kwh = match fields[3].trim() {
            "missing" => None,
            text => Some(text.parse::<u32>().map_err(|_| "solar.invalid")?),
        };
        let forecast_kwh: u32 = fields[4].trim().parse().map_err(|_| "solar.invalid")?;
        if days_ago >= 30 || site_id.is_empty() || site_id.len() > 64
            || !site_id.bytes().all(|byte| byte.is_ascii_alphanumeric() || byte == b'-' || byte == b'_')
            || site_name.is_empty() || site_name.chars().count() > 80
            || generated_kwh.is_some_and(|value| value > 1_000_000_000)
            || forecast_kwh > 1_000_000_000
            || !seen.insert((days_ago, site_id.to_owned())) {
            return Err("solar.invalid");
        }
        if names.get(site_id).is_some_and(|name| name != site_name) { return Err("solar.invalid"); }
        names.insert(site_id.to_owned(), site_name.to_owned());
        rows.push(SolarReading {
            days_ago, site_id: site_id.to_owned(), site_name: site_name.to_owned(),
            generated_kwh, forecast_kwh,
        });
    }
    if rows.is_empty() { return Err("solar.empty_import"); }
    Ok(SolarReport { endpoint: endpoint.trim().to_owned(), rows })
}
impl SolarDashboardState {
    pub fn import(&mut self, endpoint: &str, raw: &str) {
        match parse_report(endpoint, raw) {
            Ok(report) => { self.report = Some(report); self.import_issue = None; }
            Err(key) => self.import_issue = Some(key),
        }
    }
}

#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub struct Totals {
    pub generated_kwh: u64,
    pub matched_forecast_kwh: u64,
    pub missing_forecast_kwh: u64,
    pub reported: usize,
    pub missing: usize,
}
impl Totals {
    pub fn percent(self) -> Option<f32> {
        (self.matched_forecast_kwh > 0)
            .then(|| self.generated_kwh as f64 / self.matched_forecast_kwh as f64 * 100.0)
            .map(|value| value as f32)
    }
    fn add(&mut self, row: &SolarReading) {
        if let Some(actual) = row.generated_kwh {
            self.generated_kwh += u64::from(actual);
            self.matched_forecast_kwh += u64::from(row.forecast_kwh);
            self.reported += 1;
        } else {
            self.missing_forecast_kwh += u64::from(row.forecast_kwh);
            self.missing += 1;
        }
    }
}
#[derive(Debug, Clone)]
pub struct SiteSummary { pub id: String, pub name: String, pub totals: Totals }
impl SolarReport {
    pub fn totals(&self, days: u8) -> Totals {
        let mut totals = Totals::default();
        for row in self.rows.iter().filter(|row| row.days_ago < days) { totals.add(row); }
        totals
    }
    pub fn daily(&self, days: u8) -> BTreeMap<u8, Totals> {
        let mut daily: BTreeMap<u8, Totals> = BTreeMap::new();
        for row in self.rows.iter().filter(|row| row.days_ago < days) {
            daily.entry(row.days_ago).or_default().add(row);
        }
        daily
    }
    pub fn chart_buckets(&self, days: u8) -> BTreeMap<u8, Totals> {
        let step = if days == 30 { 5 } else { 1 };
        let mut buckets: BTreeMap<u8, Totals> = BTreeMap::new();
        for row in self.rows.iter().filter(|row| row.days_ago < days) {
            buckets.entry(row.days_ago / step).or_default().add(row);
        }
        buckets
    }
    pub fn sites(&self, days: u8) -> Vec<SiteSummary> {
        let mut sites: BTreeMap<String, SiteSummary> = BTreeMap::new();
        for row in self.rows.iter().filter(|row| row.days_ago < days) {
            sites.entry(row.site_id.clone()).or_insert_with(|| SiteSummary {
                id: row.site_id.clone(), name: row.site_name.clone(), totals: Totals::default(),
            }).totals.add(row);
        }
        sites.into_values().collect()
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn missing_is_not_zero_and_forecast_uses_the_matching_subset() {
        let report = parse_report("Endpoint",
            "0\teast\tEast\t80\t100\n0\twest\tWest\tmissing\t900\n29\teast\tEast\t0\t50"
        ).unwrap();
        let week = report.totals(7);
        assert_eq!(week.percent(), Some(80.0));
        assert_eq!(week.missing_forecast_kwh, 900);
        assert_eq!((week.reported, week.missing), (1, 1));
        assert_eq!(report.totals(30).reported, 2);
        assert_eq!(report.chart_buckets(30).get(&5).unwrap().reported, 1);
        assert_eq!(Totals::default().percent(), None);
    }
    #[test]
    fn replacement_is_atomic_and_site_names_do_not_disagree() {
        let mut state = SolarDashboardState::default();
        state.import("Valid", "0\teast\tEast\t80\t100");
        state.import("Invalid", "0\teast\tEast\tNaN\t100");
        assert_eq!(state.report.as_ref().unwrap().endpoint, "Valid");
        assert!(parse_report("Conflicting labels",
            "0\teast\tEast\t80\t100\n1\teast\tWest\t90\t100"
        ).is_err());
    }
}

    pub SolarFleetSummary<SolarDashboardState> { props { days: u8 } }
    view(summary, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let totals = state.report.as_ref().map(|report| report.totals(summary.days));
    } =>
    if let (Some(report), Some(totals)) = (&state.report, totals) {
        Column(gap: tokens.spacing.m, children: [
            Text(report.endpoint.clone()).weight(tokens.typography.font_weight_bold),
            if totals.reported > 0 {
                Column(gap: tokens.spacing.xs, children: [
                    Text(format!("{}: {:.3}", cx.tr("solar.generated"), totals.generated_kwh as f64 / 1000.0)),
                    Text(format!("{}: {:.3}", cx.tr("solar.matched_forecast"),
                        totals.matched_forecast_kwh as f64 / 1000.0)),
                ])
            } else { Text(cx.tr("solar.no_generation")) },
            Text(format!("{}: {:.3}", cx.tr("solar.missing_forecast"),
                totals.missing_forecast_kwh as f64 / 1000.0)),
            Text(format!("{}: {} / {}", cx.tr("solar.coverage"),
                totals.reported, totals.reported + totals.missing)),
            if let Some(percent) = totals.percent() {
                Text(format!("{}: {percent:.1}%", cx.tr("solar.matched_percent")))
            } else { Text(cx.tr("solar.no_ratio")) },
            Text(cx.tr("solar.sites")).weight(tokens.typography.font_weight_bold),
            Column(gap: tokens.spacing.s, children: [
                for site in report.sites(summary.days) {
                    SolarSiteStatus(site.clone(), key: site.id.clone())
                        .id(WidgetId::explicit(&format!("solar.site.{}", site.id)))
                },
            ]),
        ])
    } else { Text(cx.tr("solar.empty")) }
}

<!-- fission:step id="responsive-dashboard" -->
## Keep the range above the responsive branches

The chart and written summary need the same selected records at every width. The page therefore owns the range once, above `Responsive`. Both independently constructed branches receive that value as a prop. Placing a separate range state inside each branch would allow resizing to change the apparent selection.

The wide branch puts the chart and site review side by side. The compact branch stacks them in the same reading order. Both are constructed from normal components, not clones of one retained widget tree. The active design-system breakpoint chooses the branch; the chart takes its available layout width rather than a hand-calculated fraction of the whole device.

Seven days uses daily bars. Thirty days uses six five-day buckets, not four weeks with two days silently dropped. A label such as `29–25` names the offsets before the report endpoint. Both series sum exactly the same reported subset within each bucket, keeping the comparison meaningful and the phone's axis readable.

fission_component! {
    pub SolarGenerationTrend<SolarDashboardState> { props { days: u8 } }
    view(trend, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let daily: Vec<(u8, Totals)> = state.report.as_ref().map(|report| {
            report.chart_buckets(trend.days).into_iter().rev()
                .filter(|(_, totals)| totals.reported > 0).collect::<Vec<(u8, Totals)>>()
        }).unwrap_or_default();
        let labels: Vec<String> = daily.iter().map(|(bucket, _)| {
            if trend.days == 30 {
                format!("{}–{}", bucket * 5 + 4, bucket * 5)
            } else {
                cx.tr("solar.days_before").replace("{days}", &bucket.to_string())
            }
        }).collect();
        let actual: Vec<f32> = daily.iter().map(|(_, totals)| totals.generated_kwh as f32 / 1000.0).collect();
        let forecast: Vec<f32> = daily.iter().map(|(_, totals)| {
            totals.matched_forecast_kwh as f32 / 1000.0
        }).collect();
        let actual_label = cx.tr("solar.generated");
        let forecast_label = cx.tr("solar.matched_forecast");
    } =>
    if daily.is_empty() { Text(cx.tr("solar.no_chart")) } else {
        SemanticsRegion(
            identifier: Some("solar.generation".to_owned()),
            label: Some(cx.tr("solar.chart")),
            child: Column(gap: tokens.spacing.m, children: [
                Chart(
                    title: Some(cx.tr("solar.chart")),
                    x_axis: Some(Axis::category(labels.iter().map(String::as_str).collect()).name(cx.tr("solar.day_axis"))),
                    y_axis: Some(Axis::value().min(0.0).name(cx.tr("solar.mwh"))),
                    legend: Some(Legend::top_right()),
                    height: Some(300.0),
                    series: vec![
                        Series::Bar(BarSeries::new(&actual_label).data(actual)),
                        Series::Bar(BarSeries::new(&forecast_label).data(forecast)),
                    ],
                ),
                Text(cx.tr("solar.chart_scope")),
            ]),
        )
    }
}

On macOS, run the same shared app through the iOS host:

```sh
fission doctor ios --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
fission build --target ios --project-dir . --release
```

The tests establish the distinction between missing and zero, matched-denominator arithmetic, offset 29 and preserving the previous report. They do not establish that the export covers every site or that a low value identifies a fault. Entirely omitted site/day rows are unknown to this app; a complete fleet coverage check would need an expected reporting schedule.

On each target, inspect an iPhone-sized view and a wider tablet view, increased text size, long site names and the soft keyboard. Confirm the chart and last site remain reachable by scrolling. Compare the written MWh totals with the source kWh values; the conversion is 1,000 kWh per MWh. Do not rely on colour alone to explain a site's status.

The source has no continuously updated clock, so the UI makes no claim about how many minutes ago telemetry arrived. Data remains in memory for this session. A live integration would introduce explicit effects, pending/error states and an identified reporting endpoint; it should not start work whilst constructing either responsive branch.

The [responsive widget reference](/reference/widgets/responsive/), [Charts reference](/reference/charts/overview/) and [state guide](/docs/guides/state-handles-and-providers/) cover the mechanisms used here. Host startup is not visual, accessibility or device qualification.

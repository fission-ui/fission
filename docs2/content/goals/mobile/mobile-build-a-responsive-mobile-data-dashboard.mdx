## Create a shared Android and iOS project

The dashboard belongs in shared Rust code. Fission generates a small host for each platform; the screen, chart and layout rules stay in the same app module so both targets present the same information.

Install the Fission CLI once, then create the project and add both mobile targets:

```sh
cargo install cargo-fission
fission init cedar-peak-solar
cd cedar-peak-solar
cargo add fission@0.15.1 --features charts
cargo add serde_yaml
```

We will build a fleet overview for Cedar Peak Solar. An operator needs to compare generated energy with the expected forecast, see whether any site needs inspection, and change the time window without losing the summary. The numbers below are named sample records held in the preview; the controls update them in memory and make no network or hardware claims.

## Give each metric enough context to be useful

A dashboard number needs a label and a comparison. “318” is hard to act on; “318 MWh generated against a 336 MWh forecast” tells the operator how the fleet is performing. We will make the metric and site-status rows reusable, then compose them into the first version of the fleet screen.

The status text is part of the row, not just its colour. That keeps “Inspect” and “Telemetry delayed” understandable with assistive technology and when the screen is viewed in grayscale.

use crate::app::{SolarDashboardData, SolarDashboardState, SolarSite, SolarSiteCondition};
use fission::i18n::Locale;
use fission::prelude::*;

fission_component! {
    pub SolarMetric<()> {
        props { label: String, value: String, detail: String }
    }
    view(metric, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(Column(gap: tokens.spacing.xs, children: [
        Text(metric.label.clone()).color(tokens.colors.text_secondary),
        Text(metric.value.clone()).weight(tokens.typography.font_weight_bold),
        Text(metric.detail.clone()).color(tokens.colors.text_secondary),
    ]))
        .padding_all(tokens.spacing.m)
        .bg(tokens.colors.surface)
        .border(tokens.colors.border, 1.0)
        .border_radius(tokens.radii.medium)
}

fission_component! {
    pub SolarSiteStatus<()> {
        props { site: SolarSite }
    }
    view(site, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let (status, detail) = match &site.site.condition {
            SolarSiteCondition::Inspect { deficit_percent } => (
                cx.tr("site.status.inspect"),
                cx.tr("site.detail.inspect")
                    .replace("{percent}", &deficit_percent.to_string()),
            ),
            SolarSiteCondition::TelemetryDelayed { minutes } => (
                cx.tr("site.status.delayed"),
                cx.tr("site.detail.delayed").replace("{minutes}", &minutes.to_string()),
            ),
            SolarSiteCondition::OnTarget => (
                cx.tr("site.status.on_target"),
                cx.tr("site.detail.on_target"),
            ),
        };
    } =>
    SemanticsRegion(
        identifier: Some(format!("cedar-peak.site.{}", site.site.id)),
        label: Some(format!("{} at {}: {}. {}", site.site.name, site.site.location, status, detail)),
        child: Container(Column(gap: tokens.spacing.xs, children: [
            Row(gap: tokens.spacing.s, align_items: ir_op::AlignItems::Center, children: [
                Column(gap: tokens.spacing.xs, children: [
                    Text(site.site.name.clone()).weight(tokens.typography.font_weight_semibold),
                    Text(site.site.location.clone()).color(tokens.colors.text_secondary),
                ]),
                Spacer(flex_grow: 1.0),
                Badge(text: status),
            ]),
            Text(detail).color(tokens.colors.text_secondary),
        ]))
            .padding_all(tokens.spacing.m)
            .bg(tokens.colors.surface)
            .border(tokens.colors.border, 1.0)
            .border_radius(tokens.radii.medium),
    )
}

fission_component! {
    pub SolarFleetSummary<SolarDashboardState> {}
    view(_summary, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let summary: Option<(&SolarDashboardData, u32, f32, f32, usize)> = state.data.as_ref().map(|data| {
            let forecast_percent = if data.forecast_today_mwh > 0.0 {
                (data.generated_today_mwh / data.forecast_today_mwh * 100.0).round() as u32
            } else {
                0
            };
            let recent_generated: f32 = data.generated_7_days.iter().sum();
            let recent_forecast: f32 = data.forecast_7_days.iter().sum();
            let sites_to_inspect = data.sites.iter()
                .filter(|site| matches!(&site.condition, SolarSiteCondition::Inspect { .. }))
                .count();
            (data, forecast_percent, recent_generated, recent_forecast, sites_to_inspect)
        });
    } =>
    if let Some((data, forecast_percent, recent_generated, recent_forecast, sites_to_inspect)) = summary {
        SemanticsRegion(
            identifier: Some("cedar-peak-fleet-summary".to_string()),
            label: Some(cx.tr("dashboard.summary.a11y")),
            child: Container(Column(gap: tokens.spacing.l, children: [
                Row(gap: tokens.spacing.m, align_items: ir_op::AlignItems::Center, children: [
                    Column(gap: tokens.spacing.xs, children: [
                        Text(cx.tr("dashboard.brand")).weight(tokens.typography.font_weight_bold),
                        Text(cx.tr("dashboard.subtitle").replace("{count}", &data.sites.len().to_string()))
                            .color(tokens.colors.text_secondary),
                    ]),
                    Spacer(flex_grow: 1.0),
                    SolarLocalePicker(),
                ]),
                Text(cx.tr("dashboard.generation_overview"))
                    .weight(tokens.typography.font_weight_bold),
                Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                    SolarMetric(
                        cx.tr("metric.generated_today"),
                        format!("{:.1} MWh", data.generated_today_mwh),
                        cx.tr("metric.generated_today.detail")
                            .replace("{percent}", &forecast_percent.to_string()),
                        key: "metric-generated-today",
                    ),
                    SolarMetric(
                        cx.tr("metric.recent_production"),
                        format!("{recent_generated:.0} MWh"),
                        cx.tr("metric.recent_production.detail")
                            .replace("{forecast}", &format!("{recent_forecast:.0}")),
                        key: "metric-recent-production",
                    ),
                    SolarMetric(
                        cx.tr("metric.sites_to_inspect"),
                        cx.tr("metric.site_count").replace("{count}", &sites_to_inspect.to_string()),
                        cx.tr("metric.sites_to_inspect.detail"),
                        key: "metric-sites-to-inspect",
                    ),
                ]),
                Column(gap: tokens.spacing.s, children: [
                    Text(cx.tr("dashboard.site_health"))
                        .weight(tokens.typography.font_weight_semibold),
                    for site in &data.sites {
                        SolarSiteStatus(
                            site.clone(),
                            key: site.id.clone(),
                        ).id(WidgetId::explicit(&site.id))
                    },
                ]),
            ]))
                .padding_all(tokens.spacing.l)
                .bg(tokens.colors.background)
                .border(tokens.colors.border, 1.0)
                .border_radius(tokens.radii.large),
        )
    } else {
        EmptyState {
            title: cx.tr("dashboard.empty.title"),
            description: Some(cx.tr("dashboard.empty.description")),
            ..Default::default()
        }
    }
}

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

const EN_US: &str = include_str!("../i18n/en-US.yaml");
const ES_ES: &str = include_str!("../i18n/es-ES.yaml");

fn load_bundle(locale: &str, source: &str) -> anyhow::Result<TranslationBundle> {
    let messages: HashMap<String, String> = serde_yaml::from_str(source)?;
    Ok(TranslationBundle {
        locale: Locale::from(locale),
        messages,
    })
}

pub fn create_env() -> anyhow::Result<Env> {
    let mut env = Env::default();
    env.i18n.add_bundle(load_bundle("en-US", EN_US)?);
    env.i18n.add_bundle(load_bundle("es-ES", ES_ES)?);
    Ok(env)
}

## Add the generation trend and adapt the layout

The operator can inspect the current week or zoom out to four weeks. Keep the generated and forecast series together in one chart: separate charts would make their differences harder to compare. The text summary is calculated from the same values, so the result remains clear without relying on bar height or colour.

`Responsive` changes the composition at 920 points. On a wider window, the trend and site health sit side by side. On a phone, they stack in reading order. The chart receives a width derived from the active viewport so its labels and bars fit inside either arrangement.

The 7-day and 30-day values are named in the component because this example has no service yet. When a service is added, keep the range selection in local UI state and send the selected period through an effect; do not start a request while converting a component.

use crate::app::SolarDashboardState;
use fission::prelude::*;
use fission::charts::axis::AxisType;
use fission::charts::{Axis, BarSeries, Chart, Legend, Tooltip};

fission_component! {
    pub SolarGenerationTrend<SolarDashboardState> {
        props { width: f32 }
        state { thirty_days: bool = false }
    }
    view(trend, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let trend_data = state.data.as_ref().map(|data| {
            let (labels, generated, forecast) = if trend.thirty_days {
                (
                    vec![cx.tr("chart.period.week1"), cx.tr("chart.period.week2"), cx.tr("chart.period.week3"), cx.tr("chart.period.week4")],
                    data.generated_30_days.clone(),
                    data.forecast_30_days.clone(),
                )
            } else {
                (
                    vec![cx.tr("chart.day.mon"), cx.tr("chart.day.tue"), cx.tr("chart.day.wed"), cx.tr("chart.day.thu"), cx.tr("chart.day.fri"), cx.tr("chart.day.sat"), cx.tr("chart.day.sun")],
                    data.generated_7_days.clone(),
                    data.forecast_7_days.clone(),
                )
            };
            let generated_total: f32 = generated.iter().sum();
            let forecast_total: f32 = forecast.iter().sum();
            let percent = if forecast_total > 0.0 {
                (generated_total / forecast_total * 100.0).round() as u32
            } else {
                0
            };
            let period = cx.tr(if trend.thirty_days { "chart.range.30" } else { "chart.range.7" });
            let chart_title = cx.tr("chart.title");
            let generated_label = cx.tr("chart.series.generated");
            let forecast_label = cx.tr("chart.series.forecast");
            let chart: Widget = Chart::new()
                .width(trend.width)
                .height(300.0)
                .title(&chart_title)
                .x_axis(Axis {
                    axis_type: AxisType::Category,
                    data: labels,
                    name: None,
                    min: None,
                    max: None,
                    boundary_gap: true,
                    inverse: false,
                    split_line: true,
                    label_rotate: None,
                })
                .y_axis(Axis::value())
                .legend(Legend::top_right())
                .tooltip(Tooltip::axis_trigger())
                .series(vec![
                    BarSeries::new(&generated_label).data(generated).into(),
                    BarSeries::new(&forecast_label).data(forecast).into(),
                ])
                .into();
            (generated_total, forecast_total, percent, period, chart)
        });
    } =>
    if let Some((generated_total, forecast_total, percent, period, chart)) = trend_data {
        SemanticsRegion(

## Verify the dashboard on Android and iOS

The browser preview helps check the chart controls and responsive branches. It cannot prove that the app respects safe areas, that a platform text-size setting is handled well, or that a native host launches. Check both mobile targets because they share the Rust screen but use separate generated hosts.

First check that the project compiles, then run the app on an emulator or Simulator. Resize or rotate the device and inspect the header, metrics, chart labels and site rows at the largest supported text size.

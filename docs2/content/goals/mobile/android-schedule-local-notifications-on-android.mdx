## Remind a crew to revisit an unresolved trail report

Juniper County’s trail crew has logged water cutting across the North Ridge path. A second crew is bringing gravel, so the inspector wants a reminder to check the bridge approach again in about fifteen minutes. If the road crew resolves the hazard early, the inspector should be able to cancel the reminder.

We’ll build that follow-up flow. The report stays editable, Android asks for permission only when the inspector chooses to schedule, and a denial does not block the form.

There’s a delivery limit to understand before using this in a product. Fission’s Android `AfterMillis` scheduler runs a cancellable timer in the app process. It can post while the process is alive, but it is not a persistent Android alarm. Android may delay it for power management, and it may not fire after the process is killed. Treat it as best-effort. A reminder that must survive process death or arrive at a precise time needs a target-specific Android scheduler.

## Create the Android project

Create the shared app, add Android, and declare the notification capability. That adds Android’s notification permission to the generated project. Keep the reminder rules and form in shared Rust code; the Android host handles platform notifications.

The CLI adds `POST_NOTIFICATIONS` to the Android manifest. Android 13 (API 33) and newer ask for that runtime permission; earlier versions do not show the same prompt. Android 8 (API 26) and newer require notifications to use a channel. Fission’s Android host creates its default channel here, and the user can still turn it off in system settings. Read Android’s [notification permission guide](https://developer.android.com/develop/ui/views/notifications/notification-permission) and [channel guide](https://developer.android.com/develop/ui/views/notifications/channels) when choosing behavior for a real app.

## Build the reminder form and notification actions

The report screen owns its trail segment and observation drafts, so retain them as local component state while the inspector edits. Permission status, in-flight work, and the returned receipt belong in `GlobalState`: they arrive asynchronously and affect other parts of the screen.

The **Enable notifications** button asks the host for access. **Refresh access status** reads the latest settings without prompting, which matters after someone answers Android’s prompt or changes settings. Keep scheduling disabled until the host confirms that alerts and scheduling are available.

pub mod translations;

use fission::prelude::*;

const REMINDER_DELAY_MS: u64 = 15 * 60 * 1_000;
const REMINDER_ID: &str = "juniper-north-ridge-follow-up";

#[derive(Debug, Default)]
pub struct TrailReminderState {
    pub locale: Locale,
    pub settings: Option<NotificationSettings>,
    pub requesting_permission: bool,
    pub checking_settings: bool,
    pub scheduling: bool,
    pub cancelling: bool,
    pub receipt: Option<NotificationReceipt>,
    pub scheduled_segment: Option<String>,
    pub notice: Option<ReminderNotice>,
    pub error: Option<ReminderIssue>,
}

impl GlobalState for TrailReminderState {}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum ReminderNotice {
    AwaitingSettingsRefresh,
    SettingsRefreshed,
    Scheduled { segment: String, scheduled: bool, delivered: bool },
    Cancelled { segment: String },
}

impl ReminderNotice {
    pub fn translation_key(&self) -> &'static str {
        match self {
            Self::AwaitingSettingsRefresh => "reminder.notice.refresh_after_prompt",
            Self::SettingsRefreshed => "reminder.notice.settings_refreshed",
            Self::Scheduled { scheduled: true, .. } => "reminder.notice.scheduled",
            Self::Scheduled { delivered: true, .. } => "reminder.notice.delivered",
            Self::Scheduled { .. } => "reminder.notice.accepted",
            Self::Cancelled { .. } => "reminder.notice.cancelled",
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum ReminderIssue {
    PermissionDenied,
    OperationFailed,
    FormIncomplete,
    SettingsRequired,
}

impl ReminderIssue {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::PermissionDenied => "reminder.error.permission_denied",
            Self::OperationFailed => "reminder.error.operation_failed",
            Self::FormIncomplete => "reminder.error.form_incomplete",
            Self::SettingsRequired => "reminder.error.settings_required",
        }
    }
}

#[fission_reducer(RequestTrailNotifications)]
fn on_request_trail_notifications(
    state: &mut TrailReminderState,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    if state.requesting_permission || state.checking_settings {
        return;
    }

    state.requesting_permission = true;
    state.notice = None;
    state.error = None;
    let on_ok = ctx.effects.bind(
        TrailNotificationPermissionRequested(NotificationSettings::default()),
        reduce_with!(on_trail_notification_permission_requested),
    );
    let on_err = ctx.effects.bind(
        TrailNotificationOperationFailed(NotificationError::default()),
        reduce_with!(on_trail_notification_operation_failed),
    );
    ctx.effects
        .notifications()
        .request_permission(NotificationPermissionRequest {
            alerts: true,
            badge: false,
            sound: true,
            provisional: false,
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(TrailNotificationPermissionRequested)]
fn on_trail_notification_permission_requested(
    state: &mut TrailReminderState,
    _settings: NotificationSettings,
) {
    state.requesting_permission = false;
    state.settings = None;
    state.notice = Some(ReminderNotice::AwaitingSettingsRefresh);
}

#[fission_reducer(RefreshTrailNotificationSettings)]
fn on_refresh_trail_notification_settings(
    state: &mut TrailReminderState,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    if state.checking_settings || state.requesting_permission {
        return;
    }

    state.checking_settings = true;
    state.notice = None;
    state.error = None;
    let on_ok = ctx.effects.bind(
        TrailNotificationSettingsLoaded(NotificationSettings::default()),
        reduce_with!(on_trail_notification_settings_loaded),
    );
    let on_err = ctx.effects.bind(
        TrailNotificationOperationFailed(NotificationError::default()),
        reduce_with!(on_trail_notification_operation_failed),
    );
    ctx.effects
        .notifications()
        .settings()
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(TrailNotificationSettingsLoaded)]
fn on_trail_notification_settings_loaded(
    state: &mut TrailReminderState,
    settings: NotificationSettings,
) {
    state.checking_settings = false;
    state.settings = Some(settings);
    state.notice = Some(ReminderNotice::SettingsRefreshed);
    state.error = None;
}

#[fission_reducer(ScheduleTrailFollowUp)]
fn on_schedule_trail_follow_up(
    state: &mut TrailReminderState,
    trail_segment: String,
    observation: String,
    title: String,
    body: String,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    if state.scheduling || state.cancelling {
        return;
    }

    let can_schedule = state
        .settings
        .as_ref()
        .map(|settings| {
            settings.permission == NotificationPermission::Granted
                && settings.alerts
                && settings.scheduling
        })
        .unwrap_or(false);

    if !can_schedule {
        state.error = Some(ReminderIssue::SettingsRequired);
        return;
    }
    if trail_segment.trim().is_empty() || observation.trim().is_empty() {
        state.error = Some(ReminderIssue::FormIncomplete);
        return;
    }

    state.scheduling = true;
    state.notice = None;
    state.error = None;
    let request = NotificationRequest {
        id: NotificationId::new(REMINDER_ID),
        title,
        body,
        schedule: NotificationSchedule::AfterMillis(REMINDER_DELAY_MS),
        ..Default::default()
    };
    let on_ok = ctx.effects.bind(
        TrailFollowUpScheduled(NotificationReceipt::default(), trail_segment.clone()),
        reduce_with!(on_trail_follow_up_scheduled),
    );
    let on_err = ctx.effects.bind(
        TrailNotificationOperationFailed(NotificationError::default()),
        reduce_with!(on_trail_notification_operation_failed),
    );
    ctx.effects
        .notifications()
        .schedule(request)
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(TrailFollowUpScheduled)]
fn on_trail_follow_up_scheduled(
    state: &mut TrailReminderState,
    receipt: NotificationReceipt,
    trail_segment: String,
) {
    state.scheduling = false;
    state.receipt = Some(receipt.clone());
    state.scheduled_segment = Some(trail_segment.clone());
    state.notice = Some(ReminderNotice::Scheduled {
        segment: trail_segment,
        scheduled: receipt.scheduled,
        delivered: receipt.delivered,
    });
    state.error = None;
}

#[fission_reducer(CancelTrailFollowUp)]
fn on_cancel_trail_follow_up(
    state: &mut TrailReminderState,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    if state.cancelling || state.scheduling {
        return;
    }
    let (Some(_receipt), Some(trail_segment)) =
        (state.receipt.as_ref(), state.scheduled_segment.clone())
    else {
        return;
    };

    state.cancelling = true;
    state.notice = None;
    state.error = None;
    let on_ok = ctx.effects.bind(
        TrailFollowUpCancelled(trail_segment),
        reduce_with!(on_trail_follow_up_cancelled),
    );
    let on_err = ctx.effects.bind(
        TrailNotificationOperationFailed(NotificationError::default()),
        reduce_with!(on_trail_notification_operation_failed),
    );
    ctx.effects
        .notifications()
        .cancel(CancelNotificationRequest {
            id: NotificationId::new(REMINDER_ID),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(TrailFollowUpCancelled)]
fn on_trail_follow_up_cancelled(state: &mut TrailReminderState, trail_segment: String) {
    state.cancelling = false;
    state.receipt = None;
    state.scheduled_segment = None;
    state.notice = Some(ReminderNotice::Cancelled {
        segment: trail_segment,
    });
    state.error = None;
}

#[fission_reducer(TrailNotificationOperationFailed)]
fn on_trail_notification_operation_failed(
    state: &mut TrailReminderState,
    error: NotificationError,
) {
    state.requesting_permission = false;
    state.checking_settings = false;
    state.scheduling = false;
    state.cancelling = false;
    state.error = Some(if error.code == "permission_denied" {
        ReminderIssue::PermissionDenied
    } else {
        ReminderIssue::OperationFailed
    });
    if error.code == "permission_denied" {
        state.settings = None;
    }
}

use std::collections::HashMap;

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::Env;

const SOURCES: [(&str, &str); 2] = [
    ("en-US", include_str!("../../i18n/en-US.yaml")),
    ("es-ES", include_str!("../../i18n/es-ES.yaml")),
];

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in SOURCES {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid reminder translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

## Check permission, delivery, and cancellation on Android

Run the generated app on an emulator or device. On API 33 or newer, choose **Enable notifications**, answer Android’s prompt, and then refresh access status. On an older release, the app may not show a runtime prompt; the settings check still tells you if notifications are blocked in the app or its channel. If access is denied, the report remains on screen and the schedule action stays disabled.

To test delivery without waiting fifteen minutes, temporarily change `REMINDER_DELAY_MS` to `10_000` (ten seconds), rebuild, and run the app. Schedule the reminder and wait with the app process alive. Schedule it once more and cancel before the delay ends; the notification should not appear. Restore the fifteen-minute value after this check.

For a settings recovery check, turn notifications off for Juniper County Trail Service in Android settings, return to the app, and refresh status. Then turn them back on and refresh again. A successful status query should enable the schedule button without asking for permission a second time.

Fission’s current Android `AfterMillis` implementation does not use `AlarmManager`; `AtUnixMillis` also becomes a process timer. Do not add `SCHEDULE_EXACT_ALARM` for this sample, and do not promise delivery after force-stop, process death, reboot, or at an exact minute. Android recommends exact alarms only for user-facing actions that truly require precise timing, and Android 12+ restricts them through special app access. For a durable reminder, add and test a native `AlarmManager` or `WorkManager` implementation that matches your delivery requirement. See Android’s [alarm scheduling guide](https://developer.android.com/develop/background-work/services/alarms).

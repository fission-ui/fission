## Remind a crew to revisit an unresolved trail report

Juniper County’s trail crew has logged water cutting across the North Ridge path. A second crew is bringing gravel, so the inspector wants a reminder to check the bridge approach again in about fifteen minutes. If the road crew resolves the hazard early, the inspector should be able to cancel the reminder.

We will build that follow-up flow. The report description stays editable, Android permission is requested only when the inspector chooses to schedule, and a denied request leaves the form usable.

There is one delivery limit to understand before you use this in a product: Fission’s current Android `AfterMillis` scheduler runs a cancellable timer in the app process. It can post while that process is alive, but it is not a persistent Android alarm and may not fire after Android kills the process or delays it for power management. Treat this as a best-effort reminder. A promise that must survive process death or arrive at a precise time needs a target-specific Android scheduler.

## Create the Android project

Create the shared app, add Android, then declare the notification capability. The capability command adds Android’s notification permission to the generated project. Keep the reminder rules and form in shared Rust code; the generated Android host handles platform notifications.

The CLI adds `POST_NOTIFICATIONS` to the Android manifest. Android 13 (API 33) and newer ask for that runtime permission; earlier versions do not show the same prompt. Android 8 (API 26) and newer require notifications to use a channel. Fission’s Android host creates its default channel here, and the user can still turn it off in system settings. Read Android’s [notification permission guide](https://developer.android.com/develop/ui/views/notifications/notification-permission) and [channel guide](https://developer.android.com/develop/ui/views/notifications/channels) when choosing behavior for a real app.

## Build the reminder form and notification actions

The form belongs to the report screen, so its trail segment and observation are retained as local component state while the inspector edits them. Permission status, in-flight work, and the returned receipt live in `GlobalState` because they arrive asynchronously and control actions elsewhere in the screen.

The **Enable notifications** button asks the host for access. The separate refresh button reads the latest settings without prompting. That second action matters when someone has just answered Android’s prompt or changed notification access in system settings. Only enable scheduling after the host reports that alerts and scheduling are available.

```rust
use fission::prelude::*;

const REMINDER_DELAY_MS: u64 = 15 * 60 * 1_000;
const REMINDER_ID: &str = "juniper-north-ridge-follow-up";

#[derive(Debug, Default)]
pub struct TrailReminderState {
    pub settings: Option<NotificationSettings>,
    pub requesting_permission: bool,
    pub checking_settings: bool,
    pub scheduling: bool,
    pub cancelling: bool,
    pub receipt: Option<NotificationReceipt>,
    pub scheduled_segment: Option<String>,
    pub notice: Option<String>,
    pub error: Option<String>,
}

impl GlobalState for TrailReminderState {}

#[fission_reducer(RequestTrailNotifications)]
fn on_request_trail_notifications(
    state: &mut TrailReminderState,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    if state.requesting_permission || state.checking_settings {
        return;
    }

    state.requesting_permission = true;
    state.notice = None;
    state.error = None;
    let on_ok = ctx.effects.bind(
        TrailNotificationPermissionRequested(NotificationSettings::default()),
        reduce_with!(on_trail_notification_permission_requested),
    );
    let on_err = ctx.effects.bind(
        TrailNotificationOperationFailed(NotificationError::default()),
        reduce_with!(on_trail_notification_operation_failed),
    );
    ctx.effects
        .notifications()
        .request_permission(NotificationPermissionRequest {
            alerts: true,
            badge: false,
            sound: true,
            provisional: false,
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(TrailNotificationPermissionRequested)]
fn on_trail_notification_permission_requested(
    state: &mut TrailReminderState,
    _settings: NotificationSettings,
) {
    state.requesting_permission = false;
    state.settings = None;
    state.notice = Some(
        "After you answer the system prompt, refresh access status to check the current setting."
            .to_string(),
    );
}

#[fission_reducer(RefreshTrailNotificationSettings)]
fn on_refresh_trail_notification_settings(
    state: &mut TrailReminderState,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    if state.checking_settings || state.requesting_permission {
        return;
    }

    state.checking_settings = true;
    state.notice = None;
    state.error = None;
    let on_ok = ctx.effects.bind(
        TrailNotificationSettingsLoaded(NotificationSettings::default()),
        reduce_with!(on_trail_notification_settings_loaded),
    );
    let on_err = ctx.effects.bind(
        TrailNotificationOperationFailed(NotificationError::default()),
        reduce_with!(on_trail_notification_operation_failed),
    );
    ctx.effects
        .notifications()
        .settings()
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(TrailNotificationSettingsLoaded)]
fn on_trail_notification_settings_loaded(
    state: &mut TrailReminderState,
    settings: NotificationSettings,
) {
    state.checking_settings = false;
    state.settings = Some(settings);
    state.notice = Some("Notification settings have been refreshed.".to_string());
    state.error = None;
}

#[fission_reducer(ScheduleTrailFollowUp)]
fn on_schedule_trail_follow_up(
    state: &mut TrailReminderState,
    trail_segment: String,
    observation: String,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    if state.scheduling || state.cancelling {
        return;
    }

    let can_schedule = state
        .settings
        .as_ref()
        .map(|settings| {
            settings.permission == NotificationPermission::Granted
                && settings.alerts
                && settings.scheduling
        })
        .unwrap_or(false);

    if !can_schedule {
        state.error = Some(
            "Refresh notification access first. Schedule only when alerts are allowed."
                .to_string(),
        );
        return;
    }

    state.scheduling = true;
    state.notice = None;
    state.error = None;
    let request = NotificationRequest {
        id: NotificationId::new(REMINDER_ID),
        title: format!("Recheck {}", trail_segment),
        body: format!("Follow up on this inspection: {}", observation),
        schedule: NotificationSchedule::AfterMillis(REMINDER_DELAY_MS),
        ..Default::default()
    };
    let on_ok = ctx.effects.bind(
        TrailFollowUpScheduled(NotificationReceipt::default(), trail_segment.clone()),
        reduce_with!(on_trail_follow_up_scheduled),
    );
    let on_err = ctx.effects.bind(
        TrailNotificationOperationFailed(NotificationError::default()),
        reduce_with!(on_trail_notification_operation_failed),
    );
    ctx.effects
        .notifications()
        .schedule(request)
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(TrailFollowUpScheduled)]
fn on_trail_follow_up_scheduled(
    state: &mut TrailReminderState,
    receipt: NotificationReceipt,
    trail_segment: String,
) {
    state.scheduling = false;
    state.receipt = Some(receipt.clone());
    state.scheduled_segment = Some(trail_segment.clone());
    state.notice = Some(if receipt.scheduled {
        format!("The follow-up for {trail_segment} is queued for about fifteen minutes from now.")
    } else if receipt.delivered {
        format!("The follow-up notification for {trail_segment} was delivered.")
    } else {
        format!("The notification host accepted the follow-up for {trail_segment}.")
    });
    state.error = None;
}

#[fission_reducer(CancelTrailFollowUp)]
fn on_cancel_trail_follow_up(
    state: &mut TrailReminderState,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    if state.cancelling || state.scheduling || state.receipt.is_none() {
        return;
    }

    state.cancelling = true;
    state.notice = None;
    state.error = None;
    let trail_segment = state
        .scheduled_segment
        .clone()
        .unwrap_or_else(|| "the trail report".to_string());
    let on_ok = ctx.effects.bind(
        TrailFollowUpCancelled(trail_segment),
        reduce_with!(on_trail_follow_up_cancelled),
    );
    let on_err = ctx.effects.bind(
        TrailNotificationOperationFailed(NotificationError::default()),
        reduce_with!(on_trail_notification_operation_failed),
    );
    ctx.effects
        .notifications()
        .cancel(CancelNotificationRequest {
            id: NotificationId::new(REMINDER_ID),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(TrailFollowUpCancelled)]
fn on_trail_follow_up_cancelled(state: &mut TrailReminderState, trail_segment: String) {
    state.cancelling = false;
    state.receipt = None;
    state.scheduled_segment = None;
    state.notice = Some(format!("The reminder for {trail_segment} has been cancelled."));
    state.error = None;
}

#[fission_reducer(TrailNotificationOperationFailed)]
fn on_trail_notification_operation_failed(
    state: &mut TrailReminderState,
    error: NotificationError,
) {
    state.requesting_permission = false;
    state.checking_settings = false;
    state.scheduling = false;
    state.cancelling = false;
    state.error = Some(if error.code == "permission_denied" {
        "Notifications are off. Enable them in Android settings, then refresh access status."
            .to_string()
    } else if error.message.trim().is_empty() {
        "The notification host could not complete that action. Refresh status or try again."
            .to_string()
    } else {
        format!("The reminder could not be updated: {}", error.message)
    });
    if error.code == "permission_denied" {
        state.settings = None;
    }
}

fission_component! {
    pub TrailFollowUpPlanner<TrailReminderState> {
        state {
            trail_segment: String = "North Ridge · Timber bridge".to_string(),
            observation: String = "Water is cutting across the path beside the bridge.".to_string(),
        }
    }
    view(planner, app, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let request_access = with_reducer!(
            cx.build,
            RequestTrailNotifications,
            on_request_trail_notifications
        );
        let refresh_settings = with_reducer!(
            cx.build,
            RefreshTrailNotificationSettings,
            on_refresh_trail_notification_settings
        );
        let schedule_follow_up = with_reducer!(
            cx.build,
            ScheduleTrailFollowUp(
                planner.trail_segment.clone(),
                planner.observation.clone()
            ),
            on_schedule_trail_follow_up
        );
        let cancel_follow_up = with_reducer!(
            cx.build,
            CancelTrailFollowUp,
            on_cancel_trail_follow_up
        );
        let settings = app.settings.as_ref();
        let access_granted = settings
            .map(|settings| {
                settings.permission == NotificationPermission::Granted
                    && settings.alerts
                    && settings.scheduling
            })
            .unwrap_or(false);
        let permission_message = match settings {
            Some(settings) if !settings.scheduling => {
                "This host cannot schedule notifications. The report remains available."
                    .to_string()
            }
            Some(settings) if settings.permission == NotificationPermission::Denied => {
                "Notifications are off. Enable them in Android settings, then refresh this status."
                    .to_string()
            }
            Some(settings) if settings.permission == NotificationPermission::Unsupported => {
                "Notifications are not available on this host. The report remains available."
                    .to_string()
            }
            Some(settings)
                if settings.permission == NotificationPermission::Granted && !settings.alerts =>
            {
                "Notification access is granted, but alerts are off. Turn alerts on in Android settings, then refresh this status."
                    .to_string()
            }
            Some(settings)
                if settings.permission == NotificationPermission::Granted && settings.alerts =>
            {
                "Notifications are on. You can schedule the follow-up below.".to_string()
            }
            Some(settings) if settings.permission == NotificationPermission::Provisional => {
                "The host granted provisional notification access.".to_string()
            }
            Some(_) => {
                "Access has not been granted. Choose Enable notifications, then refresh this status."
                    .to_string()
            }
            None => {
                "Access has not been checked. Refresh status before scheduling a reminder."
                    .to_string()
            }
        };
        let (operation_message, operation_failed) = if let Some(error) = &app.error {
            (error.clone(), true)
        } else if let Some(notice) = &app.notice {
            (notice.clone(), false)
        } else if app.scheduling {
            ("Scheduling the follow-up…".to_string(), false)
        } else if app.cancelling {
            ("Cancelling the follow-up…".to_string(), false)
        } else {
            ("No follow-up reminder is scheduled.".to_string(), false)
        };
        let can_enable = !access_granted
            && !app.requesting_permission
            && !app.checking_settings;
        let can_schedule = access_granted
            && app.receipt.is_none()
            && !app.scheduling
            && !app.cancelling;
    } =>
    SemanticsRegion(
        identifier: Some("juniper-trail-follow-up".to_string()),
        label: Some("Juniper County trail follow-up reminder".to_string()),
        child: Scroll(
            flex_grow: 1.0,
            height: cx.view.viewport_size().height,
            child: Container(
                Column(align_items: ir_op::AlignItems::Center, children: [
                    Container(
                        Column(gap: tokens.spacing.m, children: [
                            Column(gap: tokens.spacing.xs, children: [
                                Text("Juniper County Trail Service")
                                    .weight(tokens.typography.font_weight_bold),
                                Text("Follow-up · Afternoon inspection")
                                    .color(tokens.colors.text_secondary),
                            ]),
                            Text("Revisit an unresolved trail report")
                                .weight(tokens.typography.font_weight_bold),
                            Text("Keep the crew’s observation in the reminder so the right work is easy to recognise.")
                                .color(tokens.colors.text_secondary),
                            TextInput(
                                label: Some("Trail segment".into()),
                                bind: planner.trail_segment,
                                required: true,
                                semantics_identifier: "trail-follow-up.segment".to_string(),
                            ),
                            TextInput(
                                label: Some("What needs a second look?".into()),
                                bind: planner.observation,
                                multiline: true,
                                required: true,
                                helper_text: Some("This text appears in the notification.".into()),
                                semantics_identifier: "trail-follow-up.observation".to_string(),
                            ),
                            Text("Reminder time · about 15 minutes after scheduling")
                                .color(tokens.colors.text_secondary),
                            Text(permission_message)
                                .color(if access_granted {
                                    tokens.colors.success
                                } else {
                                    tokens.colors.text_secondary
                                }),
                            Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                                Button(
                                    child: Text(if app.requesting_permission {
                                        "Waiting for Android…"
                                    } else {
                                        "Enable notifications"
                                    }),
                                    key: "request-trail-notification-access",
                                    variant: ButtonVariant::Outline,
                                    disabled: !can_enable,
                                    on_press: request_access,

                                    child: Text(if app.checking_settings {
                                        "Checking access…"
```

## Check permission, delivery, and cancellation on Android

Run the generated app on an emulator or device. On API 33 or newer, choose **Enable notifications**, answer Android’s prompt, and then refresh access status. On an older release, the app may not show a runtime prompt; the settings check still tells you if notifications are blocked in the app or its channel. If access is denied, the report remains on screen and the schedule action stays disabled.

To test delivery without waiting fifteen minutes, temporarily change `REMINDER_DELAY_MS` to `10_000` (ten seconds), rebuild, and run the app. Schedule the reminder and wait with the app process alive. Schedule it once more and cancel before the delay ends; the notification should not appear. Restore the fifteen-minute value after this check.

For a settings recovery check, turn notifications off for Juniper County Trail Service in Android settings, return to the app, and refresh status. Then turn them back on and refresh again. A successful status query should enable the schedule button without asking for permission a second time.

Fission’s current Android `AfterMillis` implementation does not use `AlarmManager`; `AtUnixMillis` also becomes a process timer. Do not add `SCHEDULE_EXACT_ALARM` for this sample, and do not promise delivery after force-stop, process death, reboot, or at an exact minute. Android recommends exact alarms only for user-facing actions that truly require precise timing, and Android 12+ restricts them through special app access. For a durable reminder, add and test a native `AlarmManager` or `WorkManager` implementation that matches your delivery requirement. See Android’s [alarm scheduling guide](https://developer.android.com/develop/background-work/services/alarms).

## A reminder is not the report

A trail crew may need to revisit a hazard after another team has brought equipment. A short reminder can help with that handover, but it cannot be the authority for whether the work is complete or the path is safe.

Here, the inspector enters a trail segment and observation, requests notification access, and schedules one follow-up. The draft remains usable without that access. Notification text is deliberately generic: the observation and location need not appear on the lock screen. The app keeps the report in memory only; neither scheduling nor cancelling saves it.

There is also a delivery boundary. Fission's Android delayed scheduler uses a cancellable timer in the app process, not a persistent Android alarm. If that process dies, the pending timer is lost. This is appropriate for demonstrating a best-effort session reminder, not for promising durable or precisely timed delivery.

## Store the receipt that the host actually returns

The local fields are editable drafts. Permission settings, a pending request and its receipt belong to shared state because they outlive an individual input event. The callback actions carry only intentional request context, such as the segment being scheduled; settings, receipts and errors are decoded from the effect input, never supplied as default action payloads.

All operations share one in-flight gate. This prevents a permission refresh from clearing a scheduling error or a second request from replacing the first callback's meaning. The single stable ID names this app's active follow-up slot. It does not support an arbitrary collection of reminders.

use fission::prelude::*;

const REMINDER_DELAY_MS: u64 = 15 * 60 * 1_000;
const REMINDER_ID: &str = "trail-follow-up.active";

#[derive(Debug, Default)]
pub struct TrailReminderState {
    pub locale: Locale,
    pub settings: Option<NotificationSettings>,
    pub requesting_permission: bool,
    pub checking_settings: bool,
    pub scheduling: bool,
    pub cancelling: bool,
    pub receipt: Option<NotificationReceipt>,
    pub scheduled_segment: Option<String>,
    pub notice: Option<ReminderNotice>,
    pub error: Option<ReminderIssue>,
}

impl GlobalState for TrailReminderState {}
impl TrailReminderState {
    pub fn busy(&self) -> bool {
        self.requesting_permission || self.checking_settings || self.scheduling || self.cancelling
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum ReminderNotice {
    AwaitingSettingsRefresh,
    SettingsRefreshed,
    Scheduled { segment: String, scheduled: bool, delivered: bool },
    Cancelled { segment: String },
}

impl ReminderNotice {
    pub fn translation_key(&self) -> &'static str {
        match self {
            Self::AwaitingSettingsRefresh => "reminder.notice.refresh_after_prompt",
            Self::SettingsRefreshed => "reminder.notice.settings_refreshed",
            Self::Scheduled { scheduled: true, .. } => "reminder.notice.scheduled",
            Self::Scheduled { delivered: true, .. } => "reminder.notice.delivered",
            Self::Scheduled { .. } => "reminder.notice.accepted",
            Self::Cancelled { .. } => "reminder.notice.cancelled",
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum ReminderIssue {
    PermissionDenied,
    OperationFailed,
    FormIncomplete,
    SettingsRequired,
}

impl ReminderIssue {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::PermissionDenied => "reminder.error.permission_denied",
            Self::OperationFailed => "reminder.error.operation_failed",
            Self::FormIncomplete => "reminder.error.form_incomplete",
            Self::SettingsRequired => "reminder.error.settings_required",
        }
    }
}

#[fission_reducer(RequestTrailNotifications)]
pub fn on_request_trail_notifications(
    state: &mut TrailReminderState,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    if state.busy() {
        return;
    }

    state.requesting_permission = true;
    state.notice = None;
    state.error = None;
    let on_ok = ctx.effects.bind(
        TrailNotificationPermissionRequested,
        reduce_with!(on_trail_notification_permission_requested),
    );
    let on_err = ctx.effects.bind(
        TrailNotificationOperationFailed,
        reduce_with!(on_trail_notification_operation_failed),
    );
    ctx.effects
        .notifications()
        .request_permission(NotificationPermissionRequest {
            alerts: true,
            badge: false,
            sound: true,
            provisional: false,
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(TrailNotificationPermissionRequested)]
pub fn on_trail_notification_permission_requested(
    state: &mut TrailReminderState,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    if ctx.input.capability_ok(REQUEST_NOTIFICATION_PERMISSION).is_none() {
        state.requesting_permission = false;
        state.error = Some(ReminderIssue::OperationFailed);
        return;
    }
    state.requesting_permission = false;
    state.settings = None;
    state.notice = Some(ReminderNotice::AwaitingSettingsRefresh);
}

#[fission_reducer(RefreshTrailNotificationSettings)]
pub fn on_refresh_trail_notification_settings(
    state: &mut TrailReminderState,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    if state.busy() {
        return;
    }

    state.checking_settings = true;
    state.notice = None;
    state.error = None;
    let on_ok = ctx.effects.bind(
        TrailNotificationSettingsLoaded,
        reduce_with!(on_trail_notification_settings_loaded),
    );
    let on_err = ctx.effects.bind(
        TrailNotificationOperationFailed,
        reduce_with!(on_trail_notification_operation_failed),
    );
    ctx.effects
        .notifications()
        .settings()
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(TrailNotificationSettingsLoaded)]
pub fn on_trail_notification_settings_loaded(
    state: &mut TrailReminderState,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    state.checking_settings = false;
    let Some(settings) = ctx.input.capability_ok(GET_NOTIFICATION_SETTINGS) else {
        state.settings = None;
        state.error = Some(ReminderIssue::OperationFailed);
        return;
    };
    state.settings = Some(settings);
    state.notice = Some(ReminderNotice::SettingsRefreshed);
    state.error = None;
}

#[fission_reducer(ScheduleTrailFollowUp)]
pub fn on_schedule_trail_follow_up(
    state: &mut TrailReminderState,
    trail_segment: String,
    observation: String,
    title: String,
    body: String,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    if state.busy() || state.receipt.is_some() {
        return;
    }

    let can_schedule = state
        .settings
        .as_ref()
        .map(|settings| {
            settings.permission == NotificationPermission::Granted
                && settings.alerts
                && settings.scheduling
        })
        .unwrap_or(false);

    if !can_schedule {
        state.error = Some(ReminderIssue::SettingsRequired);
        return;
    }
    if trail_segment.trim().is_empty() || observation.trim().is_empty() {
        state.error = Some(ReminderIssue::FormIncomplete);
        return;
    }

    state.scheduling = true;
    state.notice = None;
    state.error = None;
    let request = NotificationRequest {
        id: NotificationId::new(REMINDER_ID),
        title,
        body,
        schedule: NotificationSchedule::AfterMillis(REMINDER_DELAY_MS),
        ..Default::default()
    };
    let on_ok = ctx.effects.bind(
        TrailFollowUpScheduled(trail_segment.clone()),
        reduce_with!(on_trail_follow_up_scheduled),
    );
    let on_err = ctx.effects.bind(
        TrailNotificationOperationFailed,
        reduce_with!(on_trail_notification_operation_failed),
    );
    ctx.effects
        .notifications()
        .schedule(request)
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(TrailFollowUpScheduled)]
pub fn on_trail_follow_up_scheduled(
    state: &mut TrailReminderState,
    trail_segment: String,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    state.scheduling = false;
    let Some(receipt) = ctx.input.capability_ok(SCHEDULE_NOTIFICATION) else {
        state.error = Some(ReminderIssue::OperationFailed);
        return;
    };
    if receipt.id != NotificationId::new(REMINDER_ID) || (!receipt.scheduled && !receipt.delivered) {
        state.error = Some(ReminderIssue::OperationFailed);
        return;
    }
    state.receipt = Some(receipt.clone());
    state.scheduled_segment = Some(trail_segment.clone());
    state.notice = Some(ReminderNotice::Scheduled {
        segment: trail_segment,
        scheduled: receipt.scheduled,
        delivered: receipt.delivered,
    });
    state.error = None;
}

#[fission_reducer(CancelTrailFollowUp)]
pub fn on_cancel_trail_follow_up(
    state: &mut TrailReminderState,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    if state.busy() {
        return;
    }
    let (Some(_receipt), Some(trail_segment)) =
        (state.receipt.as_ref(), state.scheduled_segment.clone())
    else {
        return;
    };

    state.cancelling = true;
    state.notice = None;
    state.error = None;
    let on_ok = ctx.effects.bind(
        TrailFollowUpCancelled(trail_segment),
        reduce_with!(on_trail_follow_up_cancelled),
    );
    let on_err = ctx.effects.bind(
        TrailNotificationOperationFailed,
        reduce_with!(on_trail_notification_operation_failed),
    );
    ctx.effects
        .notifications()
        .cancel(CancelNotificationRequest {
            id: NotificationId::new(REMINDER_ID),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(TrailFollowUpCancelled)]
pub fn on_trail_follow_up_cancelled(
    state: &mut TrailReminderState, trail_segment: String, ctx: &mut ReducerContext<TrailReminderState>,
) {
    state.cancelling = false;
    if ctx.input.capability_ok(CANCEL_NOTIFICATION).is_none() {
        state.error = Some(ReminderIssue::OperationFailed);
        return;
    }
    state.receipt = None;
    state.scheduled_segment = None;
    state.notice = Some(ReminderNotice::Cancelled {
        segment: trail_segment,
    });
    state.error = None;
}

#[fission_reducer(TrailNotificationOperationFailed)]
pub fn on_trail_notification_operation_failed(
    state: &mut TrailReminderState,
    ctx: &mut ReducerContext<TrailReminderState>,
) {
    let error = ctx.input.capability_error(REQUEST_NOTIFICATION_PERMISSION)
        .or_else(|| ctx.input.capability_error(GET_NOTIFICATION_SETTINGS))
        .or_else(|| ctx.input.capability_error(SCHEDULE_NOTIFICATION))
        .or_else(|| ctx.input.capability_error(CANCEL_NOTIFICATION));
    let denied = error.as_ref().is_some_and(|error| error.code == "permission_denied");
    state.requesting_permission = false;
    state.checking_settings = false;
    state.scheduling = false;
    state.cancelling = false;
    state.error = Some(if denied {
        ReminderIssue::PermissionDenied
    } else {
        ReminderIssue::OperationFailed
    });
    if denied {
        state.settings = None;
    }
}


#[cfg(test)]
mod tests {

            on_refresh_trail_notification_settings

            .map(|settings| {
                settings.permission == NotificationPermission::Granted

                    && settings.scheduling

            Some(settings) if !settings.scheduling => {
                cx.tr("reminder.permission.unsupported_scheduling")

                cx.tr("reminder.permission.denied")
            }
            Some(settings) if settings.permission == NotificationPermission::Unsupported => {
                cx.tr("reminder.permission.unsupported")
            }
            Some(settings)
                if settings.permission == NotificationPermission::Granted && !settings.alerts =>
            {
                cx.tr("reminder.permission.alerts_off")

            {
                cx.tr("reminder.permission.granted")

                cx.tr("reminder.permission.provisional")

                cx.tr("reminder.permission.not_granted")

            && !app.busy();

    } =>

                                    .weight(tokens.typography.font_weight_bold),
                                Text(cx.tr("reminder.subtitle"))
                                    .color(tokens.colors.text_secondary),
                            ]),
                            Row(gap: tokens.spacing.xs, children: [
                                Button(
                                    child: Text(cx.tr("locale.english")),

use std::collections::HashMap;
use fission::prelude::*;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid checked-in translations");
        env.i18n.add_bundle(TranslationBundle { locale: Locale::from(locale), messages });
    }
    env
}

## Separate scheduling, posting and attention

```sh
cargo test
fission doctor android --project-dir .
adb devices -l
fission run --target android --device <adb-serial> --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```

Check denial, grant and later settings changes on API 33 or newer. On earlier releases, there may be no runtime prompt. The current settings query checks app-level notification permission, not the individual channel's importance, so a reported grant does not prove the default channel will display an alert. Test that channel in Android Settings as well.

For a short delivery check, temporarily set `REMINDER_DELAY_MS` to `10_000`, rebuild and keep the process alive. Schedule once and observe the notification. Schedule again and cancel before the delay; verify no new notification appears. Restore the fifteen-minute interval afterwards. Cancellation cannot undo a notification someone already saw.

Force-stop the app in a separate run to establish the timer's boundary. The scheduler has no durable alarm record and discards a later posting failure; the earlier receipt will not become a delivery acknowledgment in this UI. Do not add an exact-alarm permission to make that timer look reliable. A delivery requirement that survives process death needs an actual Android scheduling integration, with its own policy and tests.

The default native notification here does not attach report navigation to a tap. Open the app normally to review the draft, and remember that a process restart loses it. Editing the draft after scheduling also does not update an already queued request. Those behaviours should remain explicit rather than hidden behind a confirmation message.

Record permission, channel settings, timer acceptance, actual posting and cancellation separately. None proves the hazard was resolved. A durable report and a durable reminder remain separate product decisions.

Packing is not just a list of names. A row needs a quantity, and its status must distinguish gear that is still on the shelf from gear already in the bag. In this tutorial, we will build Harbour Trail, a checklist that shows each item's category and quantity, marks gear as packed, and hides completed rows while you finish the rest.

The item list is shared application data because both the summary and the rows read it. The remaining-items filter only changes this screen, so it belongs to the component. We will keep those two lifetimes separate, then use stable item IDs so filtering cannot redirect an action to a different row.

The final app starts empty and lets the user create a weekend-hike checklist from a small curated template. That is an explicit creation action, not a fabricated saved trip. Newly created gear starts unpacked. The documentation preview seeds a partly packed trip separately so you can try both states. Nothing is persisted in this first app; reloading starts again.

## Create an Android project

Fission generates the Android host; the checklist stays in shared Rust code. If you have not set up the Android SDK and NDK yet, start with the [Android toolchain setup guide](/blog/set-up-rust-android-gui-development-with-fission/).

## Give the packing task a clear first screen

Each row needs enough detail to make “done” mean something. The name tells you what to find, the category groups related gear, and the quantity makes clear whether one or both bottles are packed. A text status keeps the information clear without relying on colour.

Start with an item record and five essentials to check before setting out. The preview shell supplies these sample items as component props; the component itself only renders the data it receives. In the next step, the shared app state owns checklist changes and the preview shell seeds that state for the browser. The first stage displays an empty native list; the next stage adds the user action that creates a new checklist.

```rust
use crate::state::{PackItem};

fission_component! {
    pub PackingChecklist<()> { props { items: Vec<PackItem> } }
    view(checklist, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let items = &checklist.items;
        let packed = items.iter().filter(|item| item.packed).count();
        let remaining = items.len() - packed;
    } =>
    SemanticsRegion(
        identifier: Some("packing-checklist".to_string()),
        label: Some(cx.tr("pack.accessibility.label")),
        child: SafeArea(
            child: Scroll(
                flex_grow: 1.0,
                semantic_label: Some(cx.tr("pack.accessibility.label")),
                child: Container(
                    Column(
                        align_items: ir_op::AlignItems::Center,
                        children: [
                            Container(
                                Column(gap: tokens.spacing.l, children: [
                                    Column(gap: tokens.spacing.xs, children: [
                                        Text(cx.tr("pack.title"))
                                            .weight(tokens.typography.font_weight_bold),
                                        Text(cx.tr("pack.subtitle"))
                                            .color(tokens.colors.text_secondary),
                                    ]),
                                    Column(gap: tokens.spacing.xs, children: [
                                        Text(format!("{} {}/{}", cx.tr("pack.summary.packed"), packed, items.len()))
                                            .weight(tokens.typography.font_weight_semibold),
                                        Text(format!("{} {}", remaining, cx.tr("pack.summary.remaining")))
                                            .color(tokens.colors.text_secondary),
                                    ]),
                                    if items.is_empty() {
                                        Text(cx.tr("pack.empty"))
                                            .color(tokens.colors.text_secondary)
                                    } else {
                                        Column(gap: tokens.spacing.s, children: [
                                            for item in items.iter() {
                                                PackItemRow(item.clone(), key: item.id)
                                            },
                                        ])
                                    },
                                ]),
                            )
                            .padding_all(tokens.spacing.l)
                            .bg(tokens.colors.background)
                            .width_length(Length::clamp(
                                Length::points(0.0),
                                Length::percent(100.0),
                                Length::points(900.0),
                            )),
                        ],
                    ),
                )
                .width_length(Length::percent(100.0))
                .bg(tokens.colors.background),
            ),
        ),
    )
}
```

## Mark gear packed and focus on what remains

The summary and each row need the same packed status, so the item list belongs in shared application state. An inline `reduce` block changes one item by its stable ID and updates the confirmation. The “show only what is left” control affects this screen alone, so keep it in the checklist component's retained local state. The creation button builds a fresh template only when the list is empty; it cannot overwrite a trip already in progress.

Each row uses the reusable `PackItemRow` component. Its item ID keeps the row's identity stable when filtering removes completed gear. After the generated reducer runs, the action changes from “Mark packed” to “Unpack item”, so the next step is always clear.

```rust
use fission::prelude::*;
use crate::state::{fresh_hiking_list, PackItem, PackListState};
use crate::widgets::PackItemRow;

fission_component! {
    pub PackingChecklist<PackListState> {
        state {
            only_unpacked: bool = false,
        }
    }
    view(checklist, app, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let packed = app.items.iter().filter(|item| item.packed).count();

        let visible_items: Vec<PackItem> = app.items.iter()
            .filter(|item| !checklist.only_unpacked || !item.packed)
            .cloned()
            .collect();
        let feedback = app.last_change
            .and_then(|(item_id, packed)| {
                let item = app.items.iter().find(|item| item.id == item_id)?;
                Some(format!(
                    "{} {}",
                    cx.tr(if packed { "pack.feedback.packed" } else { "pack.feedback.unpacked" }),
                    cx.tr(&item.name_key),
                ))
            })
            .unwrap_or_else(|| cx.tr("pack.feedback.ready"));
    } =>
    SemanticsRegion(
        identifier: Some("packing-checklist".to_string()),
        label: Some(cx.tr("pack.accessibility.label")),
        child: SafeArea(
            child: Scroll(
                flex_grow: 1.0,
                semantic_label: Some(cx.tr("pack.accessibility.label")),
                child: Container(
                    Column(
                        align_items: ir_op::AlignItems::Center,
                        children: [
                            Container(
                                Column(gap: tokens.spacing.l, children: [
                                    Column(gap: tokens.spacing.xs, children: [
                                        Text(cx.tr("pack.title"))
                                            .weight(tokens.typography.font_weight_bold),
                                        Text(cx.tr("pack.subtitle"))
                                            .color(tokens.colors.text_secondary),
                                    ]),
                                    Column(gap: tokens.spacing.xs, children: [
                                        Text(format!("{} {}/{}", cx.tr("pack.summary.packed"), packed, app.items.len()))
                                            .weight(tokens.typography.font_weight_semibold),
                                        Text(format!("{} {}", remaining, cx.tr("pack.summary.remaining")))
                                            .color(tokens.colors.text_secondary),
                                    ]),
                                    Button(
                                        child: Text(cx.tr(if checklist.only_unpacked {
                                            "pack.filter.all"
                                        } else {
                                            "pack.filter.remaining"
                                        })),
                                        key: "toggle-remaining-filter",
                                        variant: ButtonVariant::Outline,
                                        on_press: reduce {
                                            checklist.only_unpacked = !checklist.only_unpacked;
                                        },
                                    ),
                                    if app.items.is_empty() {
                                        Button(
                                            child: Text(cx.tr("pack.create")),
                                            key: "create-packing-list",
                                            on_press: reduce {
                                                if app.items.is_empty() {
                                                    app.items = fresh_hiking_list();
                                                    app.last_change = None;
                                                }
                                            },
                                        )
                                    },

                                        Text(cx.tr(if app.items.is_empty() { "pack.empty" } else { "pack.complete" }))

                                            for item in visible_items.iter() {
                                                PackItemRow(item.clone(), key: item.id)
                                            },
                                        ])
                                    },
                                    Text(feedback).color(tokens.colors.text_secondary),
                                ]),
                            )
```

```rust
use serde::{Deserialize, Serialize};
use fission::prelude::*;

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct PackItem {
    pub id: u32,
    pub name_key: String,
    pub category_key: String,
    pub quantity: u32,
    pub packed: bool,
}

#[derive(Clone, Debug, Default, PartialEq)]
pub struct PackListState {
    pub items: Vec<PackItem>,
    pub last_change: Option<(u32, bool)>,
}
impl GlobalState for PackListState {}

pub fn fresh_hiking_list() -> Vec<PackItem> {
    [
        (11, "pack.item.water_filter", "pack.category.water", 1),
        (12, "pack.item.bottles", "pack.category.water", 2),
        (13, "pack.item.first_aid", "pack.category.safety", 1),
        (14, "pack.item.rain_shell", "pack.category.clothing", 1),
        (15, "pack.item.headlamp", "pack.category.lighting", 1),
    ].into_iter().map(|(id, name, category, quantity)| PackItem {
        id, name_key: name.into(), category_key: category.into(),
        quantity, packed: false,
    }).collect()
}

impl PackListState {
    pub fn toggle_packed(&mut self, item_id: u32) {
        let Some(item) = self.items.iter_mut().find(|item| item.id == item_id) else { return };
        item.packed = !item.packed;
        self.last_change = Some((item.id, item.packed));
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn a_new_trip_has_unique_ids_and_no_assumed_packed_gear() {
        let items = fresh_hiking_list();
        let ids: std::collections::HashSet<_> = items.iter().map(|item| item.id).collect();
        assert_eq!(ids.len(), items.len());
        assert!(items.iter().all(|item| !item.packed && item.quantity > 0));
    }

    #[test]
    fn toggling_one_item_does_not_change_other_gear() {
        let mut state = PackListState { items: fresh_hiking_list(), ..Default::default() };
        state.toggle_packed(13);
        assert_eq!(state.items.iter().filter(|item| item.packed).map(|item| item.id).collect::<Vec<_>>(), vec![13]);
        state.toggle_packed(13);
        assert!(state.items.iter().all(|item| !item.packed));
    }

    #[test]
    fn a_missing_item_does_not_record_a_change() {
        let mut state = PackListState::default();
        state.toggle_packed(999);
        assert_eq!(state.last_change, None);
    }
}
```

## Run the checklist on Android

The component and reducer stay in shared Rust. Fission's Android target supplies the native shell, so the emulator and browser preview use the same checklist rules. The browser preview seeds sample rows for this tutorial. On Android, create a fresh weekend list with the visible creation action; its five items start unpacked. The Android build is still a native app, not a web page inside a browser.

Run these commands from the project root. Start with the emulator, then repeat the pack and unpack flow on a connected phone when you need to check a device build.

<Tabs>
<TabItem label="Run and build">
```sh
fission doctor android --project-dir .
fission run --target android --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```
</TabItem>
<TabItem label="Shared startup">
The `src/lib.rs` from step two already wires the same component and state into the native launchers. Keep `preview/fixtures.rs` out of that startup path. On a new Android launch, choose “Create a weekend packing list” to create five unpacked items.
</TabItem>
<TabItem label="Choose a connected device">
```sh
adb devices -l
fission run --target android --device <adb-serial> --project-dir .
```
</TabItem>
</Tabs>

Rotate the emulator and increase its system font by one step. The packed labels, quantities, and actions should stay visible and easy to tap. Tapping one row should change only that item and update the summary straight away. This checks the shared state and Android layout; there are no hardware permissions in this app to test.

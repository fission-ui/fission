Before a weekend hike, the final check is easy to get wrong: water treatment is packed, but did the spare batteries make it into the bag? We will build Harbour Trail, a small checklist that shows the quantity and category of each essential item, marks gear as packed, and can hide completed rows while you finish the remaining work.

The checklist is intentionally small enough to understand in one sitting, but it behaves like a real task. The summary changes with each item, the action label tells you what the next tap will do, and the list can return a packed item if you take it back out. Its data stays in memory for this first app; later tutorials can add persistence without changing the checklist’s basic interaction.

## Create an Android project

Fission generates the native Android host while the checklist itself remains ordinary shared Rust code. If the Android SDK and NDK are not ready yet, follow the [Android toolchain setup guide](/blog/set-up-rust-android-gui-development-with-fission/) first.

## Give the packing task a clear first screen

A checklist row needs enough context to prevent a vague “done” tap. The item name says what to find, its category groups similar gear, and the quantity prevents “bottles” from hiding whether one or both are packed. A text status keeps the state understandable without relying on a colored icon.

For the first screen, define the item record and render the five essentials a small hiking group checks before setting out. The completed water filter and rain shell make the progress summary meaningful at first launch; the remaining bottle, first-aid kit, and headlamp give us clear next actions in the following step.

use fission::prelude::*;

#[derive(Clone, Debug, PartialEq)]
pub struct PackItem {
    pub id: u32,
    pub name: &'static str,
    pub category: &'static str,
    pub quantity: u32,
    pub packed: bool,
}

fn starter_items() -> Vec<PackItem> {
    vec![
        PackItem { id: 11, name: "Water filter", category: "Water", quantity: 1, packed: true },
        PackItem { id: 12, name: "Insulated bottles", category: "Water", quantity: 2, packed: false },
        PackItem { id: 13, name: "First-aid kit", category: "Safety", quantity: 1, packed: false },
        PackItem { id: 14, name: "Rain shell", category: "Clothing", quantity: 1, packed: true },
        PackItem { id: 15, name: "Headlamp and spare batteries", category: "Lighting", quantity: 1, packed: false },
    ]
}

fission_component! {
    pub PackItemRow<()> { item: PackItem }
    view(row, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(
        Column(gap: tokens.spacing.xs, children: [
            Text(row.item.name).weight(tokens.typography.font_weight_semibold),
            Text(format!(
                "{} · {} {}",
                row.item.category,
                row.item.quantity,
                if row.item.quantity == 1 { "item" } else { "items" }
            )).color(tokens.colors.text_secondary),
            Text(if row.item.packed { "Packed" } else { "Still to pack" }),
        ]),
    )
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
}

fission_component! {
    pub PackingChecklist<()> {}
    view(_checklist, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let items = starter_items();
        let packed = items.iter().filter(|item| item.packed).count();
        let remaining = items.len() - packed;
    } =>
    SemanticsRegion(
        identifier: Some("packing-checklist".to_string()),
        label: Some("Harbour trail packing checklist".to_string()),
        child: Container(
            Column(gap: tokens.spacing.l, children: [
                Column(gap: tokens.spacing.xs, children: [
                    Text("Harbour Trail · Weekend pack")
                        .weight(tokens.typography.font_weight_bold),
                    Text("A five-item essentials check before leaving the trailhead.")
                        .color(tokens.colors.text_secondary),
                ]),
                Column(gap: tokens.spacing.xs, children: [
                    Text(format!("{} of {} packed", packed, items.len()))
                        .weight(tokens.typography.font_weight_semibold),
                    Text(format!("{} still to pack", remaining))
                        .color(tokens.colors.text_secondary),
                ]),
                Column(gap: tokens.spacing.s, children: [
                    for item in items.iter() {
                        PackItemRow(item.clone(), key: item.id)
                    },
                ]),
            ]),
        )
        .padding_all(tokens.spacing.l)
        .bg(tokens.colors.background),
    )
}

## Mark gear packed and focus on what remains

The item list is shared application data because both the summary and each row need the same packed flag. A typed reducer changes that flag by stable item ID, then updates a short confirmation. Search and filter choices only change this screen, so the “show only what is left” switch belongs in the checklist component’s retained local state.

Each row is a reusable PackItemRow component. Giving repeated rows the item’s ID keeps their identity stable when the filter removes completed gear. The action changes from “Mark packed” to “Unpack item” after the reducer updates the state, so the next available action stays clear.

use fission::prelude::*;

#[derive(Clone, Debug, PartialEq)]
pub struct PackItem {
    pub id: u32,
    pub name: &'static str,
    pub category: &'static str,
    pub quantity: u32,
    pub packed: bool,
}

fn starter_items() -> Vec<PackItem> {
    vec![
        PackItem { id: 11, name: "Water filter", category: "Water", quantity: 1, packed: true },
        PackItem { id: 12, name: "Insulated bottles", category: "Water", quantity: 2, packed: false },
        PackItem { id: 13, name: "First-aid kit", category: "Safety", quantity: 1, packed: false },
        PackItem { id: 14, name: "Rain shell", category: "Clothing", quantity: 1, packed: true },
        PackItem { id: 15, name: "Headlamp and spare batteries", category: "Lighting", quantity: 1, packed: false },
    ]
}

#[derive(Clone, Debug, PartialEq)]
pub struct PackListState {
    pub items: Vec<PackItem>,
    pub feedback: String,
}

impl Default for PackListState {
    fn default() -> Self {
        Self {
            items: starter_items(),
            feedback: "Check each item as it goes into your pack.".to_string(),
        }
    }
}
impl GlobalState for PackListState {}

#[fission_reducer(TogglePacked)]
pub fn on_toggle_packed(state: &mut PackListState, item_id: u32) {
    let changed = state.items.iter_mut().find(|item| item.id == item_id).map(|item| {
        item.packed = !item.packed;
        (item.name, item.packed)
    });
    if let Some((name, packed)) = changed {
        state.feedback = if packed {
            format!("{} marked packed.", name)
        } else {
            format!("{} moved back to the packing list.", name)
        };
    }
}

fission_component! {
    pub PackItemRow<PackListState> { item: PackItem }
    view(row, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(
        Row(gap: tokens.spacing.m, wrap: ir_op::FlexWrap::Wrap, children: [
            Column(gap: tokens.spacing.xs, children: [
                Text(row.item.name).weight(tokens.typography.font_weight_semibold),
                Text(format!(
                    "{} · {} {}",
                    row.item.category,
                    row.item.quantity,
                    if row.item.quantity == 1 { "item" } else { "items" }
                )).color(tokens.colors.text_secondary),
                Text(if row.item.packed { "Packed" } else { "Still to pack" }),
            ]),
            Spacer(flex_grow: 1.0),
            Button(
                child: Text(if row.item.packed { "Unpack item" } else { "Mark packed" }),
                key: "toggle-packed",
                variant: if row.item.packed { ButtonVariant::Outline } else { ButtonVariant::Primary },
                on_press: with_reducer!(
                    cx.build,
                    TogglePacked(row.item.id),
                    on_toggle_packed,
                ),
            ),
        ]),
    )
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
}

fission_component! {
    pub PackingChecklist<PackListState> {
        state {
            only_unpacked: bool = false,
        }
    }
    view(checklist, app, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let packed = app.items.iter().filter(|item| item.packed).count();
        let remaining = app.items.len() - packed;
        let visible_items: Vec<PackItem> = app.items.iter()
            .filter(|item| !checklist.only_unpacked || !item.packed)
            .cloned()
            .collect();
    } =>
    SemanticsRegion(
        identifier: Some("packing-checklist".to_string()),
        label: Some("Harbour trail packing checklist".to_string()),
        child: Container(
            Column(gap: tokens.spacing.l, children: [
                Column(gap: tokens.spacing.xs, children: [
                    Text("Harbour Trail · Weekend pack")
                        .weight(tokens.typography.font_weight_bold),
                    Text("Check the essentials before leaving the trailhead.")
                        .color(tokens.colors.text_secondary),
                ]),
                Column(gap: tokens.spacing.xs, children: [
                    Text(format!("{} of {} packed", packed, app.items.len()))
                        .weight(tokens.typography.font_weight_semibold),
                    Text(format!("{} still to pack", remaining))
                        .color(tokens.colors.text_secondary),
                ]),
                Button(
                    child: Text(if checklist.only_unpacked {
                        "Show the full checklist"
                    } else {
                        "Show only what is left"
                    }),
                    key: "toggle-remaining-filter",
                    variant: ButtonVariant::Outline,
                    on_press: reduce {
                        checklist.only_unpacked = !checklist.only_unpacked;
                    },
                ),
                if visible_items.is_empty() {
                    Text("Everything on this checklist is packed.")
                } else {
                    Column(gap: tokens.spacing.s, children: [
                        for item in visible_items.iter() {
                            PackItemRow(item.clone(), key: item.id)
                        },
                    ])
                },
                Text(app.feedback.clone()).color(tokens.colors.text_secondary),
            ]),
        )
        .padding_all(tokens.spacing.l)
        .bg(tokens.colors.background),
    )
}

## Run the checklist on Android

The component and reducer stay in shared Rust code. Fission’s Android target supplies a native shell, so the emulator and browser preview exercise the same checklist rules. The sample list resets when the process starts because we have not added storage; the Android build is still a real native app, not a web page wrapped in a browser.

Run the checks from the project root. Use the emulator for the first pass, then repeat the pack/unpack flow on a connected phone if the task is part of a device release.

<Tabs>
<TabItem label="Run and build">
```sh
fission doctor android --project-dir .
fission run --target android --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```
</TabItem>
<TabItem label="Choose a connected device">
```sh
adb devices -l
fission run --target android --device <adb-serial> --project-dir .
```
</TabItem>
</Tabs>

Rotate the emulator and scale its system font up one step. The packed labels, item quantities, and row actions should stay visible and tappable. A tap must change only the selected item, leave other rows intact, and update the packed summary immediately. These checks cover the task’s shared state and Android layout; they do not claim to test hardware permissions, which this checklist does not use.

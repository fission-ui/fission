The last check before a weekend hike is easy to get wrong. The water filter is packed—but are the spare batteries? In this tutorial, we will build Harbour Trail, a checklist that shows each item's category and quantity, marks gear as packed, and hides completed rows while you finish the rest.

The checklist is small, but it behaves like a real task. Its summary updates as you pack, the button tells you what will happen next, and you can put an item back on the list if it comes out of the bag. The data stays in memory for now; we can add persistence later without changing these interactions. The browser preview gets sample gear from its preview shell. The shared component never invents production data, so a native app with no loaded checklist shows an honest empty state.

## Create an Android project

Fission generates the Android host; the checklist stays in shared Rust code. If you have not set up the Android SDK and NDK yet, start with the [Android toolchain setup guide](/blog/set-up-rust-android-gui-development-with-fission/).

## Give the packing task a clear first screen

Each row needs enough detail to make “done” mean something. The name tells you what to find, the category groups related gear, and the quantity makes clear whether one or both bottles are packed. A text status keeps the information clear without relying on colour.

Start with an item record and five essentials to check before setting out. The preview shell supplies these sample items as component props; the component itself only renders the data it receives. In the next step, the shared app state owns checklist changes and the preview shell seeds that state for the browser. A native app can instead load its own checklist and show the empty state until one is available.

```rust
use std::collections::HashMap;

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use serde::{Deserialize, Serialize};

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, yaml) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(yaml).expect("valid Harbour Trail translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}
#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct PackItem {
    pub id: u32,
    pub name_key: String,
    pub category_key: String,
    pub quantity: u32,
    pub packed: bool,
}

fission_component! {
    pub PackItemRow<()> { item: PackItem }
    view(row, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(
        Column(gap: tokens.spacing.xs, children: [
            Text(cx.tr(&row.item.name_key)).weight(tokens.typography.font_weight_semibold),
            Text(format!(
                "{} · {} {}",
                cx.tr(&row.item.category_key),
                row.item.quantity,
                cx.tr(if row.item.quantity == 1 { "pack.unit.one" } else { "pack.unit.many" })
            )).color(tokens.colors.text_secondary),
            Text(cx.tr(if row.item.packed { "pack.status.packed" } else { "pack.status.remaining" })),
        ]),
    )
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
    .width_length(Length::percent(100.0))
}

fission_component! {
    pub PackingChecklist<()> { items: Vec<PackItem> }
    view(checklist, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let items = &checklist.items;
        let packed = items.iter().filter(|item| item.packed).count();
        let remaining = items.len() - packed;
    } =>
    SemanticsRegion(
        identifier: Some("packing-checklist".to_string()),
        label: Some(cx.tr("pack.accessibility.label")),
        child: SafeArea(
            child: Scroll(
                flex_grow: 1.0,
                semantic_label: Some(cx.tr("pack.accessibility.label")),
                child: Container(
                    Column(
                        align_items: ir_op::AlignItems::Center,
                        children: [
                            Container(
                                Column(gap: tokens.spacing.l, children: [
                                    Column(gap: tokens.spacing.xs, children: [
                                        Text(cx.tr("pack.title"))
                                            .weight(tokens.typography.font_weight_bold),
                                        Text(cx.tr("pack.subtitle"))
                                            .color(tokens.colors.text_secondary),
                                    ]),
                                    Column(gap: tokens.spacing.xs, children: [
                                        Text(format!("{} {}/{}", cx.tr("pack.summary.packed"), packed, items.len()))
                                            .weight(tokens.typography.font_weight_semibold),
                                        Text(format!("{} {}", remaining, cx.tr("pack.summary.remaining")))
                                            .color(tokens.colors.text_secondary),
                                    ]),
                                    if items.is_empty() {
                                        Text(cx.tr("pack.empty"))
                                            .color(tokens.colors.text_secondary)
                                    } else {
                                        Column(gap: tokens.spacing.s, children: [
                                            for item in items.iter() {
                                                PackItemRow(item.clone(), key: item.id)
                                            },
                                        ])
                                    },
                                ]),
                            )
                            .padding_all(tokens.spacing.l)
                            .bg(tokens.colors.background)
                            .width_length(Length::clamp(
                                Length::points(0.0),
                                Length::percent(100.0),
                                Length::points(900.0),
                            )),
                        ],
                    ),
                )
                .width_length(Length::percent(100.0))
                .bg(tokens.colors.background),
            ),
        ),
    )
}
```

## Mark gear packed and focus on what remains

The summary and each row need the same packed status, so the item list belongs in shared application state. An inline `reduce` block changes one item by its stable ID and updates the confirmation. The “show only what is left” switch affects this screen alone, so keep it in the checklist component's retained local state.

Each row uses the reusable `PackItemRow` component. Its item ID keeps the row's identity stable when filtering removes completed gear. After the generated reducer runs, the action changes from “Mark packed” to “Unpack item”, so the next step is always clear.

```rust
use std::collections::HashMap;

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use serde::{Deserialize, Serialize};

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, yaml) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(yaml).expect("valid Harbour Trail translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct PackItem {
    pub id: u32,
    pub name_key: String,
    pub category_key: String,
    pub quantity: u32,
    pub packed: bool,
}

#[derive(Clone, Debug, Default, PartialEq)]
pub struct PackListState {
    pub items: Vec<PackItem>,
    pub last_change: Option<(u32, bool)>,
}
impl GlobalState for PackListState {}

fission_component! {
    pub PackItemRow<PackListState> { item: PackItem }
    view(row, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(
        Column(gap: tokens.spacing.s, align_items: ir_op::AlignItems::Start, children: [
            Column(gap: tokens.spacing.xs, children: [
                Text(cx.tr(&row.item.name_key)).weight(tokens.typography.font_weight_semibold),
                Text(format!(
                    "{} · {} {}",
                    cx.tr(&row.item.category_key),
                    row.item.quantity,
                    cx.tr(if row.item.quantity == 1 { "pack.unit.one" } else { "pack.unit.many" })
                )).color(tokens.colors.text_secondary),
                Text(cx.tr(if row.item.packed { "pack.status.packed" } else { "pack.status.remaining" })),
            ]),
            Button(
                child: Text(cx.tr(if row.item.packed { "pack.action.unpack" } else { "pack.action.mark" })),
                key: "toggle-packed",
                variant: if row.item.packed {
                    ButtonVariant::Outline
                } else {
                    ButtonVariant::Primary
                },
                on_press: reduce {
                    if let Some(item) = state.items.iter_mut().find(|item| item.id == row.item.id) {
                        item.packed = !item.packed;
                        let packed = item.packed;
                        state.last_change = Some((row.item.id, packed));
                    }
                },
            ),
        ]),
    )
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
    .width_length(Length::percent(100.0))
}

fission_component! {
    pub PackingChecklist<PackListState> {
        state {
            only_unpacked: bool = false,
        }
    }
    view(checklist, app, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let packed = app.items.iter().filter(|item| item.packed).count();
        let remaining = app.items.len() - packed;
        let visible_items: Vec<PackItem> = app.items.iter()
            .filter(|item| !checklist.only_unpacked || !item.packed)
            .cloned()
            .collect();
        let feedback = app.last_change
            .and_then(|(item_id, packed)| {
                let item = app.items.iter().find(|item| item.id == item_id)?;
                Some(format!(
                    "{} {}",
                    cx.tr(if packed { "pack.feedback.packed" } else { "pack.feedback.unpacked" }),
                    cx.tr(&item.name_key),
                ))
            })
            .unwrap_or_else(|| cx.tr("pack.feedback.ready"));
    } =>
    SemanticsRegion(
        identifier: Some("packing-checklist".to_string()),
        label: Some(cx.tr("pack.accessibility.label")),
        child: SafeArea(
            child: Scroll(
                flex_grow: 1.0,
                semantic_label: Some(cx.tr("pack.accessibility.label")),
                child: Container(
                    Column(
                        align_items: ir_op::AlignItems::Center,
                        children: [
                            Container(
                                Column(gap: tokens.spacing.l, children: [
                                    Column(gap: tokens.spacing.xs, children: [
                                        Text(cx.tr("pack.title"))
                                            .weight(tokens.typography.font_weight_bold),
                                        Text(cx.tr("pack.subtitle"))
                                            .color(tokens.colors.text_secondary),
                                    ]),
                                    Column(gap: tokens.spacing.xs, children: [
                                        Text(format!("{} {}/{}", cx.tr("pack.summary.packed"), packed, app.items.len()))
                                            .weight(tokens.typography.font_weight_semibold),
                                        Text(format!("{} {}", remaining, cx.tr("pack.summary.remaining")))
                                            .color(tokens.colors.text_secondary),
                                    ]),
                                    Button(
                                        child: Text(cx.tr(if checklist.only_unpacked {
                                            "pack.filter.all"
                                        } else {
                                            "pack.filter.remaining"
                                        })),
                                        key: "toggle-remaining-filter",
                                        variant: ButtonVariant::Outline,
                                        on_press: reduce {
                                            checklist.only_unpacked = !checklist.only_unpacked;
                                        },
                                    ),
                                    if visible_items.is_empty() {
                                        Text(cx.tr(if app.items.is_empty() { "pack.empty" } else { "pack.complete" }))
                                    } else {
                                        Column(gap: tokens.spacing.s, children: [
                                            for item in visible_items.iter() {
                                                PackItemRow(item.clone(), key: item.id)
                                            },
                                        ])
                                    },
                                    Text(feedback).color(tokens.colors.text_secondary),
                                ]),
                            )
                            .padding_all(tokens.spacing.l)
                            .bg(tokens.colors.background)
                            .width_length(Length::clamp(
                                Length::points(0.0),
                                Length::percent(100.0),
                                Length::points(900.0),
                            )),
                        ],
                    ),
                )
                .width_length(Length::percent(100.0))
                .bg(tokens.colors.background),
            ),
        ),
    )
}
```

## Run the checklist on Android

The component and reducer stay in shared Rust. Fission's Android target supplies the native shell, so the emulator and browser preview use the same checklist rules. The browser preview seeds sample rows for this tutorial; the native app starts empty until real checklist data is loaded. The Android build is still a native app, not a web page inside a browser.

Run these commands from the project root. Start with the emulator, then repeat the pack and unpack flow on a connected phone when you need to check a device build.

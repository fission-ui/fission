The last check before a weekend hike is easy to get wrong. The water filter is packed—but are the spare batteries? In this tutorial, we will build Harbour Trail, a checklist that shows each item's category and quantity, marks gear as packed, and hides completed rows while you finish the rest.

The checklist is small, but it behaves like a real task. Its summary updates as you pack, the button tells you what will happen next, and you can put an item back on the list if it comes out of the bag. The data stays in memory for now; we can add persistence later without changing these interactions.

## Create an Android project

Fission generates the Android host; the checklist stays in shared Rust code. If you have not set up the Android SDK and NDK yet, start with the [Android toolchain setup guide](/blog/set-up-rust-android-gui-development-with-fission/).

## Give the packing task a clear first screen

Each row needs enough detail to make “done” mean something. The name tells you what to find, the category groups related gear, and the quantity makes clear whether one or both bottles are packed. A text status keeps the information clear without relying on colour.

Start with an item record and five essentials to check before setting out. Two items are already packed, so the summary is useful on first launch. The remaining bottle, first-aid kit, and headlamp give us clear actions to add in the next step.

```rust
use fission::prelude::*;

#[derive(Clone, Debug, PartialEq)]
pub struct PackItem {
    pub id: u32,
    pub name: &'static str,
    pub category: &'static str,
    pub quantity: u32,
    pub packed: bool,
}

fn starter_items() -> Vec<PackItem> {
    vec![
        PackItem { id: 11, name: "Water filter", category: "Water", quantity: 1, packed: true },
        PackItem { id: 12, name: "Insulated bottles", category: "Water", quantity: 2, packed: false },
        PackItem { id: 13, name: "First-aid kit", category: "Safety", quantity: 1, packed: false },
        PackItem { id: 14, name: "Rain shell", category: "Clothing", quantity: 1, packed: true },
        PackItem { id: 15, name: "Headlamp and spare batteries", category: "Lighting", quantity: 1, packed: false },
    ]
}

fission_component! {
    pub PackItemRow<()> { item: PackItem }
    view(row, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(
        Column(gap: tokens.spacing.xs, children: [
            Text(row.item.name).weight(tokens.typography.font_weight_semibold),
            Text(format!(
                "{} · {} {}",
                row.item.category,
                row.item.quantity,
                if row.item.quantity == 1 { "item" } else { "items" }
            )).color(tokens.colors.text_secondary),
            Text(if row.item.packed { "Packed" } else { "Still to pack" }),
        ]),
    )
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
    .width_length(Length::percent(100.0))
}

fission_component! {
    pub PackingChecklist<()> {}
    view(_checklist, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let items = starter_items();
        let packed = items.iter().filter(|item| item.packed).count();
        let remaining = items.len() - packed;
    } =>
    SemanticsRegion(
        identifier: Some("packing-checklist".to_string()),
        label: Some("Harbour trail packing checklist".to_string()),
        child: Container(
            Column(
                align_items: ir_op::AlignItems::Center,
                children: [
                    Container(
                        Column(gap: tokens.spacing.l, children: [
                            Column(gap: tokens.spacing.xs, children: [
                                Text("Harbour Trail · Weekend pack")
                                    .weight(tokens.typography.font_weight_bold),
                                Text("A five-item essentials check before leaving the trailhead.")
                                    .color(tokens.colors.text_secondary),
                            ]),
                            Column(gap: tokens.spacing.xs, children: [
                                Text(format!("{} of {} packed", packed, items.len()))
                                    .weight(tokens.typography.font_weight_semibold),
                                Text(format!("{} still to pack", remaining))
                                    .color(tokens.colors.text_secondary),
                            ]),
                            Column(gap: tokens.spacing.s, children: [
                                for item in items.iter() {
                                    PackItemRow(item.clone(), key: item.id)
                                },
                            ]),
                        ]),
                    )
                    .padding_all(tokens.spacing.l)
                    .bg(tokens.colors.background)
                    .width_length(Length::clamp(
                        Length::points(0.0),
                        Length::percent(100.0),
                        Length::points(900.0),
                    )),
                ],
            ),
        )
        .width_length(Length::percent(100.0))
        .bg(tokens.colors.background),
    )
}
```

## Mark gear packed and focus on what remains

The summary and each row need the same packed status, so the item list belongs in shared application state. A typed reducer changes one item by its stable ID and updates the confirmation. The “show only what is left” switch affects this screen alone, so keep it in the checklist component's retained local state.

Each row uses the reusable `PackItemRow` component. Its item ID keeps the row's identity stable when filtering removes completed gear. After the reducer runs, the action changes from “Mark packed” to “Unpack item”, so the next step is always clear.

```rust
use fission::prelude::*;

#[derive(Clone, Debug, PartialEq)]
pub struct PackItem {
    pub id: u32,
    pub name: &'static str,
    pub category: &'static str,
    pub quantity: u32,
    pub packed: bool,
}

fn starter_items() -> Vec<PackItem> {
    vec![
        PackItem { id: 11, name: "Water filter", category: "Water", quantity: 1, packed: true },
        PackItem { id: 12, name: "Insulated bottles", category: "Water", quantity: 2, packed: false },
        PackItem { id: 13, name: "First-aid kit", category: "Safety", quantity: 1, packed: false },
        PackItem { id: 14, name: "Rain shell", category: "Clothing", quantity: 1, packed: true },
        PackItem { id: 15, name: "Headlamp and spare batteries", category: "Lighting", quantity: 1, packed: false },
    ]
}

#[derive(Clone, Debug, PartialEq)]
pub struct PackListState {
    pub items: Vec<PackItem>,
    pub feedback: String,
}

impl Default for PackListState {
    fn default() -> Self {
        Self {
            items: starter_items(),
            feedback: "Check each item as it goes into your pack.".to_string(),
        }
    }
}
impl GlobalState for PackListState {}

#[fission_reducer(TogglePacked)]
pub fn on_toggle_packed(state: &mut PackListState, item_id: u32) {
    let changed = state.items.iter_mut().find(|item| item.id == item_id).map(|item| {
        item.packed = !item.packed;
        (item.name, item.packed)
    });
    if let Some((name, packed)) = changed {
        state.feedback = if packed {
            format!("{} marked packed.", name)
        } else {
            format!("{} moved back to the packing list.", name)
        };
    }
}

fission_component! {
    pub PackItemRow<PackListState> { item: PackItem }
    view(row, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(
        Column(gap: tokens.spacing.s, align_items: ir_op::AlignItems::Start, children: [
            Column(gap: tokens.spacing.xs, children: [
                Text(row.item.name).weight(tokens.typography.font_weight_semibold),
                Text(format!(
                    "{} · {} {}",
                    row.item.category,
                    row.item.quantity,
                    if row.item.quantity == 1 { "item" } else { "items" }
                )).color(tokens.colors.text_secondary),
                Text(if row.item.packed { "Packed" } else { "Still to pack" }),
            ]),
            Button(
                child: Text(if row.item.packed { "Unpack item" } else { "Mark packed" }),
                key: "toggle-packed",
                variant: if row.item.packed {
                    ButtonVariant::Outline
                } else {
                    ButtonVariant::Primary
                },
                on_press: with_reducer!(
                    cx.build,
                    TogglePacked(row.item.id),
                    on_toggle_packed,
                ),
            ),
        ]),
    )
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
    .width_length(Length::percent(100.0))
}

fission_component! {
    pub PackingChecklist<PackListState> {
        state {
            only_unpacked: bool = false,
        }
    }
    view(checklist, app, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let packed = app.items.iter().filter(|item| item.packed).count();
        let remaining = app.items.len() - packed;
        let visible_items: Vec<PackItem> = app.items.iter()
            .filter(|item| !checklist.only_unpacked || !item.packed)
            .cloned()
            .collect();
    } =>
    SemanticsRegion(
        identifier: Some("packing-checklist".to_string()),
        label: Some("Harbour trail packing checklist".to_string()),
        child: Container(
            Column(
                align_items: ir_op::AlignItems::Center,
                children: [
                    Container(
                        Column(gap: tokens.spacing.l, children: [
                            Column(gap: tokens.spacing.xs, children: [
                                Text("Harbour Trail · Weekend pack")
                                    .weight(tokens.typography.font_weight_bold),
                                Text("Check the essentials before leaving the trailhead.")
                                    .color(tokens.colors.text_secondary),
                            ]),
                            Column(gap: tokens.spacing.xs, children: [
                                Text(format!("{} of {} packed", packed, app.items.len()))
                                    .weight(tokens.typography.font_weight_semibold),
                                Text(format!("{} still to pack", remaining))
                                    .color(tokens.colors.text_secondary),
                            ]),
                            Button(
                                child: Text(if checklist.only_unpacked {
                                    "Show the full checklist"
                                } else {
                                    "Show only what is left"
                                }),
                                key: "toggle-remaining-filter",
                                variant: ButtonVariant::Outline,
                                on_press: reduce {
                                    checklist.only_unpacked = !checklist.only_unpacked;
                                },
                            ),
                            if visible_items.is_empty() {
                                Text("Everything on this checklist is packed.")
                            } else {
                                Column(gap: tokens.spacing.s, children: [
                                    for item in visible_items.iter() {
                                        PackItemRow(item.clone(), key: item.id)
                                    },
                                ])
                            },
                            Text(app.feedback.clone()).color(tokens.colors.text_secondary),
                        ]),
                    )
                    .padding_all(tokens.spacing.l)
                    .bg(tokens.colors.background)
                    .width_length(Length::clamp(
                        Length::points(0.0),
                        Length::percent(100.0),
                        Length::points(900.0),
                    )),
                ],
            ),
        )
        .width_length(Length::percent(100.0))
        .bg(tokens.colors.background),
    )
}
```

## Run the checklist on Android

The component and reducer stay in shared Rust. Fission's Android target supplies the native shell, so the emulator and browser preview use the same checklist rules. The sample list resets when the app restarts because we have not added storage. The Android build is still a native app, not a web page inside a browser.

Run these commands from the project root. Start with the emulator, then repeat the pack and unpack flow on a connected phone when you need to check a device build.

<Tabs>
<TabItem label="Run and build">
```sh
fission doctor android --project-dir .
fission run --target android --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```
</TabItem>
<TabItem label="Wire the shared app">
`fission init` points `src/lib.rs` at the starter `CounterApp`. Replace that wiring with the checklist so Android and the other targets start the same component and state:

```rust
pub mod app;

use crate::app::{PackListState, PackingChecklist};
use fission::prelude::*;

#[cfg(target_os = "android")]
const ANDROID_TEST_CONTROL_PORT: u16 = 48761;

#[cfg(any(target_os = "android", target_os = "ios"))]
fn mobile_app() -> MobileApp<PackListState, PackingChecklist> {
    let app = MobileApp::<PackListState, _>::new(PackingChecklist::new())
        .with_title("Harbour Trail packing checklist");
    #[cfg(target_os = "android")]
    let app = app.with_test_control_port(ANDROID_TEST_CONTROL_PORT);
    app
}

#[cfg(target_arch = "wasm32")]
fn web_app() -> WebApp<PackListState, PackingChecklist> {
    WebApp::<PackListState, _>::new(PackingChecklist::new())
        .with_title("Harbour Trail packing checklist")
}

#[cfg(not(any(target_arch = "wasm32", target_os = "android", target_os = "ios")))]
pub fn run_desktop() -> anyhow::Result<()> {
    DesktopApp::<PackListState, _>::new(PackingChecklist::new()).run()
}

#[cfg(any(target_os = "android", target_os = "ios"))]
pub fn run_mobile() -> anyhow::Result<()> {
    mobile_app().run()
}

#[cfg(target_os = "android")]
#[no_mangle]
fn android_main(app_handle: AndroidApp) {
    let _ = mobile_app().run_with_android_app(app_handle);
}

#[cfg(target_arch = "wasm32")]
#[wasm_bindgen::prelude::wasm_bindgen(start)]
pub fn run_web() -> Result<(), wasm_bindgen::JsValue> {
    console_error_panic_hook::set_once();
    web_app()
        .run()
        .map_err(|error| wasm_bindgen::JsValue::from_str(&error.to_string()))
}
```

Before a technician opens a cold-room inspection, they need to know whether the temperature probe is nearby. This tutorial builds that discovery screen: it requests Bluetooth permission, scans for devices advertising the standard Environmental Sensing service, and displays the names and signal strengths the host actually returns.

This is a scan, not a pairing tutorial. The current Android provider can request permission and discover devices; its connection and characteristic operations return `unsupported`. The example does not invent a temperature reading or claim a probe is connected. Keep that boundary visible in the UI until the target has a provider that supports the next operation.

## Create the Android project

Add the Android target and Bluetooth capability. Fission records the capability and generates the permission declarations for the Android host.

```sh
cargo install cargo-fission
fission init northbank-probe-finder
cd northbank-probe-finder
cargo add serde_yaml
fission add-target android --project-dir .
fission add-capability bluetooth --project-dir .
```

The screen, state, and reducers stay in shared Rust. The generated Android host handles platform startup and permission requests.

## Give the technician a useful scan-results screen

Show the site and the service being searched for, then list the device name and signal strength returned by Bluetooth. Do not display the device address: the user does not need it to recognise a probe, and it is a persistent identifier.

The browser checkpoint starts with two clearly labelled sample devices so you can review the layout. They are not hardware results. The Android app itself starts empty until the host returns a scan result.

## Request permission, then scan for the service

Start host work from a reducer, not while converting the screen. The flow is ordered: ask the Android host for Bluetooth permission, scan only after it returns `Granted`, then put the typed `BluetoothScanResult` into state. A denial is different from a scan error and from a successful scan with no matching devices.

The scan asks for the Bluetooth SIG Environmental Sensing service UUID. A device appears only if it advertises a matching service and the host reports it. The example never treats a sample name as a sensor reading.

```rust
use fission::prelude::*;

const ENVIRONMENTAL_SENSING_SERVICE: &str = "0000181a-0000-1000-8000-00805f9b34fb";

#[derive(Debug, Default)]
pub struct ProbeFinderState {
    pub permission: BluetoothPermission,
    pub scan_pending: bool,
    pub scan_complete: bool,
    pub devices: Vec<BluetoothDevice>,
    pub error_code: Option<String>,
}

impl GlobalState for ProbeFinderState {}

#[fission_reducer(ScanNearbyProbes)]
pub fn scan_nearby_probes(
    state: &mut ProbeFinderState,
    ctx: &mut ReducerContext<ProbeFinderState>,
) {
    state.scan_pending = true;
    state.scan_complete = false;
    state.devices.clear();
    state.error_code = None;

    let ok = ctx.effects.bind(
        ProbePermissionReceived,
        reduce_with!(probe_permission_received),
    );
    let err = ctx.effects.bind(
        ProbePermissionFailed,
        reduce_with!(probe_permission_failed),
    );
    ctx.effects
        .bluetooth()
        .request_permission(BluetoothPermissionRequest {
            reason: Some("Find the temperature probe for this inspection".into()),
        })
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(ProbePermissionReceived)]
pub fn probe_permission_received(
    state: &mut ProbeFinderState,
    ctx: &mut ReducerContext<ProbeFinderState>,
) {
    let Some(permission) = ctx.input.capability_ok(REQUEST_BLUETOOTH_PERMISSION) else {
        state.scan_pending = false;
        state.error_code = Some("missing_permission_result".into());
        return;
    };
    state.permission = permission;
    if permission != BluetoothPermission::Granted {
        state.scan_pending = false;
        if permission == BluetoothPermission::Unknown {
            state.error_code = Some("permission_unknown".into());
        }
        return;
    }

    let ok = ctx.effects.bind(
        ProbeScanReceived,
        reduce_with!(probe_scan_received),
    );
    let err = ctx.effects.bind(
        ProbeScanFailed,
        reduce_with!(probe_scan_failed),
    );
    ctx.effects
        .bluetooth()
        .scan_devices(BluetoothScanRequest {
            service_uuids: vec![ENVIRONMENTAL_SENSING_SERVICE.into()],
            timeout_ms: Some(5_000),
            include_paired: true,
            allow_duplicates: false,
        })
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(ProbePermissionFailed)]
pub fn probe_permission_failed(
    state: &mut ProbeFinderState,
    ctx: &mut ReducerContext<ProbeFinderState>,
) {
    state.scan_pending = false;
    state.error_code = Some(
        ctx.input
            .capability_error(REQUEST_BLUETOOTH_PERMISSION)
            .map(|error| error.code)
            .unwrap_or_else(|| "permission_request_failed".into()),
    );
}

#[fission_reducer(ProbeScanReceived)]
pub fn probe_scan_received(
    state: &mut ProbeFinderState,
    ctx: &mut ReducerContext<ProbeFinderState>,
) {
    state.scan_pending = false;
    if let Some(result) = ctx.input.capability_ok(SCAN_BLUETOOTH_DEVICES) {
        state.scan_complete = true;
        state.devices = result.devices;
    } else {
        state.scan_complete = false;
        state.error_code = Some("missing_scan_result".into());
    }
}

#[fission_reducer(ProbeScanFailed)]
pub fn probe_scan_failed(
    state: &mut ProbeFinderState,
    ctx: &mut ReducerContext<ProbeFinderState>,
) {
    state.scan_pending = false;
    state.error_code = Some(
        ctx.input
            .capability_error(SCAN_BLUETOOTH_DEVICES)
            .map(|error| error.code)
            .unwrap_or_else(|| "scan_failed".into()),
    );
}

pub fn callback_registry() -> ActionRegistry<ProbeFinderState> {
    let mut registry = ActionRegistry::new();
    registry.register(reduce_with!(probe_permission_received));
    registry.register(reduce_with!(probe_permission_failed));
    registry.register(reduce_with!(probe_scan_received));
    registry.register(reduce_with!(probe_scan_failed));
    registry
}

fission_component! {
    pub ProbeDeviceRow<()> { device: BluetoothDevice }
    view(row, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let name = row.device.name.clone().unwrap_or_else(|| cx.tr("probe.unnamed").into());
        let signal = match row.device.rssi {
            Some(dbm) => format!("{} {dbm} dBm", cx.tr("probe.signal")),
            None => cx.tr("probe.signal_unavailable").into(),
        };
    } =>
    Container(Column(gap: tokens.spacing.xs, children: [
        Text(name).weight(tokens.typography.font_weight_semibold),
        Text(signal).color(tokens.colors.text_secondary),
        Text(cx.tr("probe.low_energy")).color(tokens.colors.text_secondary),
    ]))
    .padding_all(tokens.spacing.m)
    .bg(tokens.colors.surface)
    .border(tokens.colors.border, 1.0)
    .border_radius(tokens.radii.medium)
}

fission_component! {
    pub ProbeFinderScreen<ProbeFinderState> {}
    view(_screen, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let scan = with_reducer!(cx.build, ScanNearbyProbes, scan_nearby_probes);
        let status = if state.scan_pending {
            cx.tr("probe.scanning")
        } else if state.error_code.as_deref() == Some("unsupported") {
            cx.tr("probe.unsupported")
        } else if state.error_code.as_deref() == Some("permission_unknown") {
            cx.tr("probe.permission_unknown")
        } else if state.error_code.is_some() {
            cx.tr("probe.failed")
        } else if matches!(state.permission, BluetoothPermission::Denied | BluetoothPermission::Restricted) {
            cx.tr("probe.permission_denied")
        } else if state.scan_complete && state.devices.is_empty() {
            cx.tr("probe.scan_complete")
        } else if state.devices.is_empty() {
            cx.tr("probe.ready")
        } else {
            format!("{} {}", cx.tr("probe.results"), state.devices.len())
        };
        let results_message = if state.scan_pending {
                cx.tr("probe.results_waiting")
            } else if state.scan_complete {
                cx.tr("probe.no_results")
            } else if state.error_code.is_some()
                || matches!(state.permission, BluetoothPermission::Denied | BluetoothPermission::Restricted)
            {
                cx.tr("probe.results_unavailable")
            } else {
                cx.tr("probe.results_empty")
        };
    } =>
    SemanticsRegion(
        identifier: Some("northbank-probe-finder".into()),
        label: Some(cx.tr("probe.title")),
        child: Container(Column(gap: tokens.spacing.l, children: [
            Column(gap: tokens.spacing.xs, children: [
                Text(cx.tr("probe.site")).weight(tokens.typography.font_weight_bold),
                Text(cx.tr("probe.title")).size(tokens.typography.heading2_size),
                Text(cx.tr("probe.description")).color(tokens.colors.text_secondary),
            ]),
            Container(Column(gap: tokens.spacing.m, children: [
                Text(cx.tr("probe.service")).weight(tokens.typography.font_weight_semibold),
                Button(
                    child: Text(if state.scan_pending { cx.tr("probe.scanning") } else { cx.tr("probe.action") }),
                    key: "scan-nearby-probes",
                    variant: ButtonVariant::Primary,
                    disabled: state.scan_pending,
                    loading: state.scan_pending,
                    on_press: scan,
                ),
                SemanticsRegion(
                    identifier: Some("probe-scan-status".into()),
                    label: Some(cx.tr("probe.status_label")),
                    child: Text(status),
                ),
                if state.devices.is_empty() {
                    Text(results_message)
                } else {
                    Column(gap: tokens.spacing.s, children: [
                        for device in state.devices.iter() {
                            ProbeDeviceRow(device.clone(), key: device.id.clone())
                        },
                    ])
                },
            ]))
            .padding_all(tokens.spacing.l)
            .bg(tokens.colors.surface)
            .border(tokens.colors.border, 1.0)
            .border_radius(tokens.radii.large),
        ]))
        .padding_all(tokens.spacing.l)
        .bg(tokens.colors.background)
        .width_length(Length::clamp(
            Length::points(0.0),
            Length::percent(100.0),
            Length::points(720.0),
        )),
    )
}
```

```sh
fission doctor android --project-dir .

adb devices -l
```

Test these cases separately: permission granted with a matching sensor nearby; permission denied; Bluetooth disabled; and a successful scan with no matching devices. The screen should never show stale results as the latest scan. If permission was denied, explain how to enable it in Android settings instead of retrying the prompt in a loop.

The Android host currently implements permission requests and scanning. Bluetooth connection, characteristic read/write, and pairing are separate operations and are not implemented by this host yet. Do not add a “connected” state until you supply and test a provider that supports it.

For the full request contract, see the [Bluetooth capability reference](/reference/capabilities/bluetooth/). For Android SDK, NDK, emulator, and phone setup, start with [Set up Rust Android GUI development with Fission](/blog/set-up-rust-android-gui-development-with-fission/).

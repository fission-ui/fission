## Keep identity with the item, not its position

A row's position tells us where it is displayed. It does not tell us which record it represents. That difference becomes important as soon as a list can be searched or reordered: the first visible item is no longer necessarily the first item that was created.

Here, we build a packing list from items the user enters. Each record receives an ID once. The record owns its packed state in `GlobalState`, whilst the row owns only a temporary expanded reminder. This separates two concerns which are easy to confuse: stable identity prevents state moving to another mounted row; it does not make unmounted local state permanent.

## Build a list with real records

The allocator below is enough for records created during one app run. An app that loads shared or persisted records should use those records' durable IDs instead. Never generate a new row ID during every build or derive it from translated text.

The row receives explicit props and the parent supplies `key: item.id`. That key establishes the Compose component's retained scope. The explicit `WidgetId` also names the rendered row; setting an ID after constructing an unkeyed component is not a replacement for the Compose key.

```rust
use fission::prelude::*;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct PackingItem {
    pub id: u64,
    pub description: String,
    pub packed: bool,
}

#[derive(Debug)]
pub struct PackingState {
    pub items: Vec<PackingItem>,
    next_id: u64,
}

impl Default for PackingState {
    fn default() -> Self { Self { items: Vec::new(), next_id: 1 } }
}
impl GlobalState for PackingState {}

impl PackingState {
    pub fn add(&mut self, description: &str) -> bool {
        let description = description.trim();
        if description.is_empty() { return false; }
        let Some(next) = self.next_id.checked_add(1) else { return false; };
        self.items.push(PackingItem {
            id: self.next_id,
            description: description.to_owned(),
            packed: false,
        });
        self.next_id = next;
        true
    }

    pub fn toggle_packed(&mut self, id: u64) {
        if let Some(item) = self.items.iter_mut().find(|item| item.id == id) {
            item.packed = !item.packed;
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn identity_is_allocated_once_and_actions_target_the_id() {
        let mut state = PackingState::default();
        assert!(!state.add(" "));
        assert!(state.add("USB charger"));
        assert!(state.add("Rain jacket"));
        let first_id = state.items[0].id;
        let second_id = state.items[1].id;
        state.items.reverse();
        state.toggle_packed(first_id);
        assert!(state.items.iter().find(|item| item.id == first_id).unwrap().packed);
        assert!(!state.items.iter().find(|item| item.id == second_id).unwrap().packed);
        state.toggle_packed(999); // An old event cannot recreate a removed record.
        assert_eq!(state.items.len(), 2);
    }
}
```

```rust
use fission::prelude::*;
use crate::state::PackingState;

fission_component! {
    pub PackingRow<PackingState> {
        props {
            item_id: u64,
            description: String,
            packed: bool,
        }
        state { expanded: bool = false }
    }
    view(row, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Card(
        child: Column(gap: tokens.spacing.s, children: [
            Text(row.description.clone()).weight(tokens.typography.font_weight_bold),
            Text(cx.tr(if row.packed { "packing.packed" } else { "packing.unpacked" })),
            Wrap(spacing: tokens.spacing.s, children: [
                Button(
                    child: Text(cx.tr(if row.packed { "packing.unpack" } else { "packing.pack" })),
                    key: "toggle-packed",
                    on_press: reduce { state.toggle_packed(row.item_id); },
                ).semantics_identifier(format!("packing.{}.toggle", row.item_id)),
                Button(
                    child: Text(cx.tr(if row.expanded { "packing.close" } else { "packing.details" })),
                    key: "toggle-details",
                    on_press: reduce { row.expanded = !row.expanded; },
                ).semantics_identifier(format!("packing.{}.details", row.item_id)),
            ]),
            if row.expanded {
                Text(cx.tr("packing.details_help"))
            },
        ]),
    )
}
```

```rust
use fission::prelude::*;
use crate::row::PackingRow;
use crate::state::PackingState;

fission_component! {
    pub PackingApp<PackingState> {
        state {
            draft: String = String::new(),
            invalid: bool = false,
        }
    }
    view(app, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    SafeArea(
        child: Scroll(
            child: Container(
                child: Column(gap: tokens.spacing.m, children: [
                    Text(cx.tr("packing.title")).size(tokens.typography.heading2_size),
                    Text(cx.tr("packing.scope")),
                    TextInput(
                        label: Some(cx.tr("packing.new_item").into()),
                        bind: app.draft,
                        semantics_identifier: "packing.draft".to_string(),
                    ),
                    Button(
                        child: Text(cx.tr("packing.add")),
                        key: "add-item",
                        on_press: reduce {
                            if state.add(&app.draft) {
                                app.draft.clear();
                                app.invalid = false;
                            } else {
                                app.invalid = true;
                            }
                        },
                    ).semantics_identifier("packing.add"),
                    if app.invalid { Text(cx.tr("packing.invalid")) },
                    if state.items.is_empty() { Text(cx.tr("packing.empty")) },
                    for item in &state.items {
                        PackingRow(
                            item.id,
                            item.description.clone(),
                            item.packed,
                            key: item.id,
                        ).id(WidgetId::explicit(&format!("packing-row.{}", item.id)))
                    },
                ]),
            ).padding_all(tokens.spacing.l),
        ),
    )
}
```

## Filter and reorder without changing record identity

Search changes the visible collection, not the records. Reversing that collection changes presentation order without allocating new IDs. A button still targets the record ID captured by its row, rather than whichever item now occupies an old position.

Replace only the screen. State, row and shell modules stay as they were.

```rust
use fission::prelude::*;
use crate::row::PackingRow;
use crate::state::PackingState;

fission_component! {
    pub PackingApp<PackingState> {
        state {
            draft: String = String::new(),
            invalid: bool = false,
            query: String = String::new(),
            reverse: bool = false,
        }
    }
    view(app, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let query = app.query.trim().to_lowercase();
        let mut visible: Vec<_> = state.items.iter()
            .filter(|item| item.description.to_lowercase().contains(&query))
            .collect();
        if app.reverse { visible.reverse(); }
    } =>
    SafeArea(
        child: Scroll(
            child: Container(
                child: Column(gap: tokens.spacing.m, children: [
                    Text(cx.tr("packing.title")).size(tokens.typography.heading2_size),
                    Text(cx.tr("packing.scope")),
                    TextInput(
                        label: Some(cx.tr("packing.new_item").into()),
                        bind: app.draft,
                        semantics_identifier: "packing.draft".to_string(),
                    ),
                    Button(
                        child: Text(cx.tr("packing.add")),
                        key: "add-item",
                        on_press: reduce {
                            if state.add(&app.draft) {
                                app.draft.clear();
                                app.invalid = false;
                            } else {
                                app.invalid = true;
                            }
                        },
                    ).semantics_identifier("packing.add"),
                    if app.invalid { Text(cx.tr("packing.invalid")) },
                    TextInput(
                        label: Some(cx.tr("packing.search").into()),
                        bind: app.query,
                        semantics_identifier: "packing.search".to_string(),
                    ),
                    Button(
                        child: Text(cx.tr("packing.reverse")),
                        key: "reverse-items",
                        on_press: reduce { app.reverse = !app.reverse; },
                    ).semantics_identifier("packing.reverse"),
                    if visible.is_empty() { Text(cx.tr("packing.no_matches")) },
                    for item in visible {
                        PackingRow(
                            item.id,
                            item.description.clone(),
                            item.packed,
                            key: item.id,
                        ).id(WidgetId::explicit(&format!("packing-row.{}", item.id)))
                    },
                ]),
            ).padding_all(tokens.spacing.l),
        ),
    )
}
```

<!-- fission:checkpoint -->
The list now has one authority for each fact: the record owns packed status; the parent owns the search and order controls; each mounted row owns its reminder. A stable key connects those boundaries without treating a list position as identity.

The list is in memory only. Persistent or multi-device IDs and storage are separate requirements, not something a widget ID supplies.

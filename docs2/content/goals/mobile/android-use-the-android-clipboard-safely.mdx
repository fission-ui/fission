## Share the intended value, not the whole screen

A clipboard is a hand-off to other applications, not private application storage. That distinction matters even when the text looks harmless: a work-order reference can reveal information about a customer or a job. Here, the user enters a reference and chooses when to copy it. A separate private note is never part of that request.

The second step adds paste. Clipboard text is external input, so the app checks its format before changing the reference. A failure preserves the existing fields instead of clearing work the user has already done. Checking the format does not prove that the work order exists or that this user may open it; those are separate application checks.

## Create the project and add Android

Clipboard text access is part of Fission's shell. It does not need an additional capability declaration. Add the YAML parser used for the checked-in translations.

```sh
cargo install cargo-fission
fission init android-use-the-android-clipboard-safely
cd android-use-the-android-clipboard-safely
fission add-target android --project-dir .
cargo add serde_yaml
```

For SDK/NDK setup, follow [the Android setup tutorial](/blog/set-up-rust-android-gui-development-with-fission/). Launch [an emulator](/blog/create-and-launch-a-fission-android-emulator/) or connect [an Android phone](/blog/run-a-fission-app-on-a-physical-android-phone/) before the native checks below. Keep the generated `src/main.rs`; replace the shared library entrypoint so the Android app runs this screen, not the starter counter.

## Copy one validated reference

The state owns the reference and the current clipboard operation. The private note belongs to the screen's retained local state because no other screen or effect needs it. The copy reducer takes an owned snapshot of the reference, not the component or its private note.

The pending operation also prevents two requests from overlapping. That keeps completion handling small: this example needs one outstanding clipboard operation, not a queue or a second copy of the clipboard.

use fission::prelude::*;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Operation { Copy, Paste }

#[derive(Debug, Default, Clone, Copy, PartialEq, Eq)]
pub enum Notice {
    #[default]
    Ready,
    Copied,
    Pasted,
    InvalidReference,
    EmptyClipboard,
    Unsupported,
    Denied,
    Failed,
}

impl Notice {
    pub fn key(self) -> &'static str {
        match self {
            Self::Ready => "handoff.ready",
            Self::Copied => "handoff.copied",
            Self::Pasted => "handoff.pasted",
            Self::InvalidReference => "handoff.invalid",
            Self::EmptyClipboard => "handoff.empty",
            Self::Unsupported => "handoff.unsupported",
            Self::Denied => "handoff.denied",
            Self::Failed => "handoff.failed",
        }
    }
}

#[derive(Debug, Default)]
pub struct ClipboardState {
    pub reference: String,
    pub pending: Option<Operation>,
    pub notice: Notice,
}

impl GlobalState for ClipboardState {}

pub fn valid_reference(input: &str) -> bool {
    let Some(number) = input.strip_prefix("WO-") else { return false; };
    !number.is_empty()
        && number.len() <= 12
        && number.bytes().all(|byte| byte.is_ascii_digit())
}

pub fn copy_reference(state: &mut ClipboardState, ctx: &mut ReducerContext<ClipboardState>) {
    if state.pending.is_some() { return; }
    let reference = state.reference.trim().to_owned();
    if !valid_reference(&reference) {
        state.notice = Notice::InvalidReference;
        return;
    }
    state.pending = Some(Operation::Copy);
    state.notice = Notice::Ready;
    let ok = ctx.effects.bind(ReferenceCopied, reduce_with!(reference_copied));
    let err = ctx.effects.bind(ClipboardFailed, reduce_with!(clipboard_failed));
    ctx.effects.clipboard()
        .write_text(ClipboardWriteTextRequest { text: reference })
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(ReferenceCopied)]
fn reference_copied(state: &mut ClipboardState, ctx: &mut ReducerContext<ClipboardState>) {
    if state.pending != Some(Operation::Copy) { return; }
    state.pending = None;
    state.notice = if ctx.input.capability_ok(WRITE_CLIPBOARD_TEXT).is_some() {
        Notice::Copied
    } else {
        Notice::Failed
    };
}

#[fission_reducer(ClipboardFailed)]
fn clipboard_failed(state: &mut ClipboardState, ctx: &mut ReducerContext<ClipboardState>) {
    let code = match state.pending.take() {
        Some(Operation::Copy) => ctx.input.capability_error(WRITE_CLIPBOARD_TEXT)
            .map(|error| error.code),
        Some(Operation::Paste) => ctx.input.capability_error(READ_CLIPBOARD_TEXT)
            .map(|error| error.code),
        None => return,
    };
    state.notice = match code.as_deref() {
        Some("unsupported") => Notice::Unsupported,
        Some("permission_denied") | Some("not_allowed") => Notice::Denied,
        _ => Notice::Failed,
    };
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn accepts_only_the_reference_format() {
        assert!(valid_reference("WO-1048"));
        for input in ["", "WO-", "WO-a", "WO-1\nprivate note", "WO-１２", "WO-1234567890123"] {
            assert!(!valid_reference(input), "accepted invalid reference format");
        }
    }
}

fission_component! {

        state { private_note: String = String::new() }

                    TextInput(
                        label: Some(cx.tr("handoff.reference").into()),
                        helper_text: Some(cx.tr("handoff.format").into()),
                        enabled: state.pending.is_none(),
                        bind: state.reference,
                        semantics_identifier: "handoff.reference".to_string(),
                    ),
                    TextInput(
                        label: Some(cx.tr("handoff.note").into()),
                        helper_text: Some(cx.tr("handoff.note_help").into()),
                        multiline: true,
                        bind: screen.private_note,
                        semantics_identifier: "handoff.private-note".to_string(),
                    ),
                    Button(
                        child: Text(cx.tr("handoff.copy")),
                        key: "copy-reference",
                        disabled: state.pending.is_some(),
                        on_press: reduce { state::copy_reference(state, cx); },
                    ).semantics_identifier("handoff.copy"),
                    if let Some(operation) = state.pending {
                        Spinner(
                            motion: Some(SpinnerMotion::Default),
                            label: cx.tr(match operation {
                                state::Operation::Copy => "handoff.copying",
                                state::Operation::Paste => "handoff.pasting",
                            }),
                        )
                    } else {
                        Text(cx.tr(state.notice.key()))
                    },
                ]),
            ).padding_all(tokens.spacing.l),
        ),
    )
}

## Paste without trusting the clipboard

Paste runs only after a deliberate user action. Do not read the clipboard during startup, on a timer or whenever a field receives focus. Apart from unnecessary access, that would replace the reference when the user had not asked for a change.

The successful callback receives `ClipboardText` from `ctx.input`. Only a matching reference reaches application state; empty text and other clipboard contents leave the current value alone. In particular, the error message does not echo rejected clipboard text, which might contain a password or another application's private data.

Replace `src/state.rs` with the version below. The screen adds a Paste action; native and Web entrypoints remain unchanged.

pub enum Notice {

    Ready,
    Copied,
    Pasted,
    InvalidReference,
    EmptyClipboard,
    Unsupported,
    Denied,
    Failed,
}

    pub fn key(self) -> &'static str {
        match self {
            Self::Ready => "handoff.ready",
            Self::Copied => "handoff.copied",
            Self::Pasted => "handoff.pasted",
            Self::InvalidReference => "handoff.invalid",
            Self::EmptyClipboard => "handoff.empty",
            Self::Unsupported => "handoff.unsupported",
            Self::Denied => "handoff.denied",
            Self::Failed => "handoff.failed",
        }
    }
}

#[derive(Debug, Default)]
pub struct ClipboardState {
    pub reference: String,
    pub pending: Option<Operation>,
    pub notice: Notice,
}

impl GlobalState for ClipboardState {}

pub fn valid_reference(input: &str) -> bool {

        && number.bytes().all(|byte| byte.is_ascii_digit())

    if state.pending.is_some() { return; }
    let reference = state.reference.trim().to_owned();
    if !valid_reference(&reference) {
        state.notice = Notice::InvalidReference;
        return;
    }
    state.pending = Some(Operation::Copy);
    state.notice = Notice::Ready;
    let ok = ctx.effects.bind(ReferenceCopied, reduce_with!(reference_copied));
    let err = ctx.effects.bind(ClipboardFailed, reduce_with!(clipboard_failed));
    ctx.effects.clipboard()
        .write_text(ClipboardWriteTextRequest { text: reference })
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(ReferenceCopied)]
fn reference_copied(state: &mut ClipboardState, ctx: &mut ReducerContext<ClipboardState>) {
    if state.pending != Some(Operation::Copy) { return; }
    state.pending = None;
    state.notice = if ctx.input.capability_ok(WRITE_CLIPBOARD_TEXT).is_some() {
        Notice::Copied
    } else {
        Notice::Failed
    };
}

#[fission_reducer(ClipboardFailed)]
fn clipboard_failed(state: &mut ClipboardState, ctx: &mut ReducerContext<ClipboardState>) {
    let code = match state.pending.take() {
        Some(Operation::Copy) => ctx.input.capability_error(WRITE_CLIPBOARD_TEXT)
            .map(|error| error.code),
        Some(Operation::Paste) => ctx.input.capability_error(READ_CLIPBOARD_TEXT)
            .map(|error| error.code),
        None => return,
    };
    state.notice = match code.as_deref() {
        Some("unsupported") => Notice::Unsupported,
        Some("permission_denied") | Some("not_allowed") => Notice::Denied,
        _ => Notice::Failed,
    };
}

pub fn paste_reference(state: &mut ClipboardState, ctx: &mut ReducerContext<ClipboardState>) {
    if state.pending.is_some() { return; }
    state.pending = Some(Operation::Paste);
    state.notice = Notice::Ready;
    let ok = ctx.effects.bind(ReferencePasted, reduce_with!(reference_pasted));
    let err = ctx.effects.bind(ClipboardFailed, reduce_with!(clipboard_failed));
    ctx.effects.clipboard().read_text().on_ok(ok).on_err(err);
}

#[fission_reducer(ReferencePasted)]
fn reference_pasted(state: &mut ClipboardState, ctx: &mut ReducerContext<ClipboardState>) {
    if state.pending != Some(Operation::Paste) { return; }
    state.pending = None;
    match ctx.input.capability_ok(READ_CLIPBOARD_TEXT) {
        Some(ClipboardText { text: Some(text) }) if valid_reference(text.trim()) => {
            state.reference = text.trim().to_owned();
            state.notice = Notice::Pasted;
        }
        Some(ClipboardText { text: None }) => state.notice = Notice::EmptyClipboard,
        Some(ClipboardText { text: Some(text) }) if text.trim().is_empty() => {
            state.notice = Notice::EmptyClipboard;
        }
        Some(_) => state.notice = Notice::InvalidReference,
        None => state.notice = Notice::Failed,
    }
}

## Check the Android host, not just the Web preview

Run the same screen on an emulator and a phone. Android and a browser have different clipboard policies; a successful browser request is not evidence for native behaviour.

```sh
cargo test
fission doctor android --project-dir .
fission devices --target android --project-dir .
fission run --target android --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```

Check copy and paste with the app in the foreground, an empty clipboard, unrelated text, and the host's denied or unsupported result where available. Verify the private note never enters the copied text and remains editable after failure. Do not use real credentials or customer notes as test clipboard content.

The format test runs without a device. `fission test` checks the generated host can launch, but neither command proves the clipboard interaction works. Complete the manual cross-application checks before relying on the feature.

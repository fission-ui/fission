A trail report needs a recognisable segment and a useful description. Coordinates can help the next crew find a fallen tree, but requiring them would make the whole report depend on permission, location services and a returned position.

Here, those are separate concerns. The report starts empty and remains editable without location. The user requests foreground access only when a map pin is useful, checks the permission after the Android prompt, and then explicitly asks for a position. Nothing is saved or sent to a service in this example.

## Create the Android project

Use [SDK/NDK setup](/blog/set-up-rust-android-gui-development-with-fission/) before launching on [an emulator](/blog/create-and-launch-a-fission-android-emulator/) or [a phone](/blog/run-a-fission-app-on-a-physical-android-phone/).

```sh
cargo install cargo-fission
fission init juniper-trail-reports
cd juniper-trail-reports
fission add-target android --project-dir .
fission add-capability geolocation --project-dir .
cargo add serde_yaml
```

Keep the generated `src/main.rs`. Shared state owns the draft and confirmed permission; the shell only configures and launches the same application. Locale is also state, mirrored into `Env` for both targets rather than selected independently by each widget.

## Preserve the report whilst permission changes

The callback action carries no invented permission or error. Completion reducers decode the actual typed result from `ctx.input`; binding an action with `Unknown` or a default error would preserve that placeholder instead of replacing it with the host response.

A permission request is not itself a grant. The current Android provider asks for OS permission and immediately returns its current snapshot, potentially before the user answers. That is why the interface keeps **Request location access** and **Refresh access status** separate. An explicit check does not reopen the prompt.

use fission::prelude::*;

#[derive(Debug)]
pub struct TrailReportState {
    pub locale: Locale,
    pub trail_segment: String,
    pub observation: String,
    pub permission: GeolocationPermission,
    pub permission_pending: bool,
    pub location_pending: bool,
    pub position: Option<GeolocationPosition>,
    pub issue: Option<TrailIssue>,
}

impl Default for TrailReportState {
    fn default() -> Self {
        Self {
            locale: Locale::from("en-US"), trail_segment: String::new(),
            observation: String::new(), permission: GeolocationPermission::Unknown,
            permission_pending: false, location_pending: false, position: None, issue: None,
        }
    }
}
impl GlobalState for TrailReportState {}
impl TrailReportState {
    pub fn apply_permission(&mut self, permission: GeolocationPermission) {
        self.permission = permission;
        if permission != GeolocationPermission::Granted { self.position = None; }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum TrailIssue {
    PermissionRequestFailed,
    PermissionRefreshFailed,
    PermissionRequired,
    PositionDenied,
    PositionUnsupported,
    PositionTimedOut,
    PositionUnavailable,
    PositionFailed,
}

impl TrailIssue {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::PermissionRequestFailed => "trail.error.permission_request",
            Self::PermissionRefreshFailed => "trail.error.permission_refresh",
            Self::PermissionRequired => "trail.error.permission_required",
            Self::PositionDenied => "trail.error.position_denied",
            Self::PositionUnsupported => "trail.error.position_unsupported",
            Self::PositionTimedOut => "trail.error.position_timeout",
            Self::PositionUnavailable => "trail.error.position_unavailable",
            Self::PositionFailed => "trail.error.position_failed",
        }
    }
}

#[fission_reducer(SetTrailLocale)]
pub fn on_set_trail_locale(state: &mut TrailReportState, locale: Locale) {
    state.locale = locale;
}

#[fission_reducer(TrailPermissionReceived)]
pub fn on_trail_permission_received(
    state: &mut TrailReportState, ctx: &mut ReducerContext<TrailReportState>,
) {
    state.permission_pending = false;
    match ctx.input.capability_ok(REQUEST_GEOLOCATION_PERMISSION)
        .or_else(|| ctx.input.capability_ok(GET_GEOLOCATION_PERMISSION)) {
        Some(permission) => {
            state.apply_permission(permission);
            state.issue = None;
        }
        None => {
            state.permission = GeolocationPermission::Unknown;
            state.issue = Some(TrailIssue::PermissionRefreshFailed);
        }
    }
}

#[fission_reducer(TrailPermissionRequestFailed)]
pub fn on_trail_permission_request_failed(state: &mut TrailReportState) {
    state.permission_pending = false;
    state.issue = Some(TrailIssue::PermissionRequestFailed);
}

#[fission_reducer(TrailPermissionRefreshFailed)]
pub fn on_trail_permission_refresh_failed(state: &mut TrailReportState) {
    state.permission_pending = false;
    state.issue = Some(TrailIssue::PermissionRefreshFailed);
}

#[fission_reducer(RequestTrailPermission)]
pub fn on_request_trail_permission(
    state: &mut TrailReportState,
    ctx: &mut ReducerContext<TrailReportState>,
) {
    if state.permission_pending || state.location_pending {
        return;
    }
    state.permission_pending = true;
    state.issue = None;
    let on_ok = ctx.effects.bind(
        TrailPermissionReceived,
        reduce_with!(on_trail_permission_received),
    );
    let on_err = ctx.effects.bind(
        TrailPermissionRequestFailed,
        reduce_with!(on_trail_permission_request_failed),
    );
    ctx.effects
        .geolocation()
        .request_permission(GeolocationPermissionRequest {
            precise: true,
            background: false,
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(RefreshTrailPermission)]
pub fn on_refresh_trail_permission(
    state: &mut TrailReportState,
    ctx: &mut ReducerContext<TrailReportState>,
) {
    if state.permission_pending || state.location_pending {
        return;
    }
    state.permission_pending = true;
    state.issue = None;
    let on_ok = ctx.effects.bind(
        TrailPermissionReceived,
        reduce_with!(on_trail_permission_received),
    );
    let on_err = ctx.effects.bind(
        TrailPermissionRefreshFailed,
        reduce_with!(on_trail_permission_refresh_failed),
    );
    ctx.effects
        .geolocation()
        .permission()
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(TrailPositionReceived)]
pub fn on_trail_position_received(
    state: &mut TrailReportState,
    ctx: &mut ReducerContext<TrailReportState>,
) {
    state.location_pending = false;
    if let Some(position) = ctx.input.capability_ok(GET_CURRENT_POSITION) {
        state.position = Some(position);
        state.issue = None;
    } else {
        state.issue = Some(TrailIssue::PositionUnavailable);
    }
}

#[fission_reducer(TrailPositionFailed)]
pub fn on_trail_position_failed(
    state: &mut TrailReportState,
    ctx: &mut ReducerContext<TrailReportState>,
) {
    state.location_pending = false;
    let error = ctx.input.capability_error(GET_CURRENT_POSITION);
    let Some(error) = error else {
        state.issue = Some(TrailIssue::PositionFailed);
        return;
    };
    if error.code == "permission_denied" {
        state.apply_permission(GeolocationPermission::Denied);
    }
    state.issue = Some(match error.code.as_str() {
        "permission_denied" => TrailIssue::PositionDenied,
        "unsupported" => TrailIssue::PositionUnsupported,
        "timeout" => TrailIssue::PositionTimedOut,
        "position_unavailable" => TrailIssue::PositionUnavailable,
        _ => TrailIssue::PositionFailed,
    });
}

#[fission_reducer(AddTrailMapPin)]
pub fn on_add_trail_map_pin(
    state: &mut TrailReportState,
    ctx: &mut ReducerContext<TrailReportState>,
) {
    if state.location_pending || state.permission_pending {
        return;
    }
    if state.permission != GeolocationPermission::Granted {
        state.issue = Some(TrailIssue::PermissionRequired);
        return;
    }
    state.location_pending = true;
    state.issue = None;
    let on_ok = ctx.effects.bind(
        TrailPositionReceived,
        reduce_with!(on_trail_position_received),
    );
    let on_err = ctx.effects.bind(
        TrailPositionFailed,
        reduce_with!(on_trail_position_failed),
    );
    ctx.effects
        .geolocation()
        .current_position(GeolocationPositionRequest {
            high_accuracy: true,
            timeout_ms: Some(10_000),
            maximum_age_ms: Some(30_000),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}


#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn optional_location_does_not_initialise_or_destroy_report_text() {
        let mut report = TrailReportState::default();
        report.trail_segment = "Ridge trail".into();

    }
}

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid checked-in translations");
        env.i18n.add_bundle(TranslationBundle { locale: Locale::from(locale), messages });
    }
    env
}

## Verify denial and a later settings change

```sh
cargo test
fission doctor android --project-dir .
adb devices -l
fission run --target android --device <adb-serial> --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```

Begin with this app's location permission disabled in Android Settings. Enter report text, request access and decline. After the dialog closes, refresh the status: adding a pin should remain unavailable whilst the report remains editable. Grant foreground access, recheck, then request the position. Repeat after revoking access; a failed lookup must not erase the report or silently submit its previous pin.

Permission and position accuracy are different facts. Android can grant coarse access, and the returned accuracy is part of the result, not a fixed promise made by the interface. The one-shot provider may return an eligible recent position; this is not continuous tracking. Do not log a user's coordinates to diagnose button behaviour.

Inspect the generated manifest and retain only permissions the feature requires. A one-time map pin does not justify background location. Emulator tests can exercise the prompt and supplied emulator position; a physical walk and real location-service conditions are separate checks. No build command proves those outcomes.

Android's [runtime permission guidance](https://developer.android.com/training/permissions/requesting) explains the OS policy. The [Geolocation reference](/reference/capabilities/geolocation/) defines Fission's portable request and result types.

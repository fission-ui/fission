Juniper County's trail crew records hazards during afternoon inspections. A report needs a trail segment and a clear description even when a phone has no signal or its user declines location access. A map pin is useful for a washout or fallen tree, but it must not block the report.

The app below keeps the report text in `GlobalState` and asks for a position only after **Request location access** and **Add map pin**. The browser preview uses Fission's `MemoryGeolocationHost`: it returns a documented test position through the real capability path, but it does not ask the browser for permission or claim to prove Android behavior. The Android app uses its native provider. In both cases this example keeps changes in memory only; there is no persistence or county-service upload.

## Create the Android project

Create the shared Rust app, add Android as a target, declare geolocation, and add the YAML parser used for the checked-in English and Spanish messages.

```sh
cargo install cargo-fission
fission init juniper-trail-reports
cd juniper-trail-reports
fission add-target android --project-dir .
fission add-capability geolocation --project-dir .
cargo add serde_yaml
```

The report screen and reducers stay in shared Rust code. The generated Android host handles the operating-system permission and location provider; it does not duplicate the report rules.

## Build the report and optional location flow

Start with an empty report in native builds. The preview seeds one example trail segment so the screen has something useful to try; that fixture is not part of the Android app. Text fields, permission state, and a returned position all live in `GlobalState`, while reducers request the host operation and handle success or failure.

use fission::prelude::*;

pub mod translations;

#[derive(Debug, Default)]
pub struct TrailReportState {
    pub locale: Locale,
    pub trail_segment: String,
    pub observation: String,
    pub permission: GeolocationPermission,
    pub permission_pending: bool,
    pub location_pending: bool,
    pub position: Option<GeolocationPosition>,
    pub issue: Option<TrailIssue>,
}

impl GlobalState for TrailReportState {}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum TrailIssue {
    PermissionRequestFailed,
    PermissionRefreshFailed,
    PermissionRequired,
    PositionDenied,
    PositionUnsupported,
    PositionTimedOut,
    PositionUnavailable,
    PositionFailed,
}

impl TrailIssue {
    fn translation_key(self) -> &'static str {
        match self {
            Self::PermissionRequestFailed => "trail.error.permission_request",
            Self::PermissionRefreshFailed => "trail.error.permission_refresh",
            Self::PermissionRequired => "trail.error.permission_required",
            Self::PositionDenied => "trail.error.position_denied",
            Self::PositionUnsupported => "trail.error.position_unsupported",
            Self::PositionTimedOut => "trail.error.position_timeout",
            Self::PositionUnavailable => "trail.error.position_unavailable",
            Self::PositionFailed => "trail.error.position_failed",
        }
    }
}

#[fission_reducer(SetTrailLocale)]
pub fn on_set_trail_locale(state: &mut TrailReportState, locale: Locale) {
    state.locale = locale;
}

#[fission_reducer(TrailSegmentChanged)]
pub fn on_trail_segment_changed(
    state: &mut TrailReportState,
    ctx: &mut ReducerContext<TrailReportState>,
) {
    let Some(change) = ctx.input.text_change() else {
        return;
    };
    state.trail_segment = change.new_text.clone();
}

#[fission_reducer(TrailObservationChanged)]
pub fn on_trail_observation_changed(
    state: &mut TrailReportState,
    ctx: &mut ReducerContext<TrailReportState>,
) {
    let Some(change) = ctx.input.text_change() else {
        return;
    };
    state.observation = change.new_text.clone();
}

#[fission_reducer(TrailPermissionReceived)]
pub fn on_trail_permission_received(
    state: &mut TrailReportState,
    permission: GeolocationPermission,
) {
    state.permission_pending = false;
    state.permission = permission;
    state.issue = None;
}

#[fission_reducer(TrailPermissionRequestFailed)]
pub fn on_trail_permission_request_failed(state: &mut TrailReportState) {
    state.permission_pending = false;
    state.issue = Some(TrailIssue::PermissionRequestFailed);
}

#[fission_reducer(TrailPermissionRefreshFailed)]
pub fn on_trail_permission_refresh_failed(state: &mut TrailReportState) {
    state.permission_pending = false;
    state.issue = Some(TrailIssue::PermissionRefreshFailed);
}

#[fission_reducer(RequestTrailPermission)]
pub fn on_request_trail_permission(
    state: &mut TrailReportState,
    ctx: &mut ReducerContext<TrailReportState>,
) {
    if state.permission_pending {
        return;
    }
    state.permission_pending = true;
    state.issue = None;
    let on_ok = ctx.effects.bind(
        TrailPermissionReceived(GeolocationPermission::Unknown),
        reduce_with!(on_trail_permission_received),
    );
    let on_err = ctx.effects.bind(
        TrailPermissionRequestFailed,
        reduce_with!(on_trail_permission_request_failed),
    );
    ctx.effects
        .geolocation()
        .request_permission(GeolocationPermissionRequest {
            precise: true,
            background: false,
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(RefreshTrailPermission)]
pub fn on_refresh_trail_permission(
    state: &mut TrailReportState,
    ctx: &mut ReducerContext<TrailReportState>,
) {
    if state.permission_pending {
        return;
    }
    state.permission_pending = true;
    state.issue = None;
    let on_ok = ctx.effects.bind(
        TrailPermissionReceived(GeolocationPermission::Unknown),
        reduce_with!(on_trail_permission_received),
    );
    let on_err = ctx.effects.bind(
        TrailPermissionRefreshFailed,
        reduce_with!(on_trail_permission_refresh_failed),
    );
    ctx.effects
        .geolocation()
        .permission()
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(TrailPositionReceived)]
pub fn on_trail_position_received(
    state: &mut TrailReportState,
    ctx: &mut ReducerContext<TrailReportState>,
) {
    state.location_pending = false;
    if let Some(position) = ctx.input.capability_ok(GET_CURRENT_POSITION) {
        state.position = Some(position);
        state.issue = None;
    } else {
        state.issue = Some(TrailIssue::PositionUnavailable);
    }
}

#[fission_reducer(TrailPositionFailed)]
pub fn on_trail_position_failed(
    state: &mut TrailReportState,
    error: GeolocationError,
) {
    state.location_pending = false;
    if error.code == "permission_denied" {
        state.permission = GeolocationPermission::Denied;
    }
    state.issue = Some(match error.code.as_str() {
        "permission_denied" => TrailIssue::PositionDenied,
        "unsupported" => TrailIssue::PositionUnsupported,
        "timeout" => TrailIssue::PositionTimedOut,
        "position_unavailable" => TrailIssue::PositionUnavailable,
        _ => TrailIssue::PositionFailed,
    });
}

#[fission_reducer(AddTrailMapPin)]
pub fn on_add_trail_map_pin(
    state: &mut TrailReportState,
    ctx: &mut ReducerContext<TrailReportState>,
) {
    if state.location_pending {
        return;
    }
    if state.permission != GeolocationPermission::Granted {
        state.issue = Some(TrailIssue::PermissionRequired);
        return;
    }
    state.location_pending = true;
    state.issue = None;
    let on_ok = ctx.effects.bind(
        TrailPositionReceived,
        reduce_with!(on_trail_position_received),
    );
    let on_err = ctx.effects.bind(
        TrailPositionFailed(GeolocationError::default()),
        reduce_with!(on_trail_position_failed),
    );
    ctx.effects
        .geolocation()
        .current_position(GeolocationPositionRequest {
            high_accuracy: true,
            timeout_ms: Some(10_000),
            maximum_age_ms: Some(30_000),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

use std::collections::HashMap;

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::Env;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../../i18n/en-US.yaml")),
        ("es-ES", include_str!("../../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid trail-report translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

## Verify grant, denial, and a later settings change

The preview demonstrates the typed capability flow, not Android hardware or its permission dialog. Use an Android emulator to test the generated permission declaration and the OS prompt. Start from a fresh install or reset this app’s location permission in Android Settings. Request access and choose **Don’t allow**. Confirm the report remains usable and that **Add map pin** stays disabled. Reset the permission, allow foreground access, refresh the status after the system prompt closes, and then add the pin.

Open the app’s location permission in Android Settings, change it, and return to the report. Refresh the status and verify the screen reflects the new host response without prompting again. A granted position is still only in app memory here; persist or submit it through a separate effect only when the product requires that behavior.

```sh
fission doctor android --project-dir .
fission run --target android --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```

Inspect the generated manifest before release and keep only the permissions this workflow needs. A one-time map pin does not need background location. Android's [runtime permission guidance](https://developer.android.com/training/permissions/requesting) recommends asking in context and degrading gracefully when a permission is declined. See the [Geolocation reference](/reference/capabilities/geolocation/) for the provider contract.

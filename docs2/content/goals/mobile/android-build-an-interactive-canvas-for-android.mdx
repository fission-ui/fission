An inspection plan has two kinds of state. Its steps and their positions describe the document. Pan and zoom describe how someone is looking at that document. Moving the camera should not rewrite the plan, and moving a step should not change which step it is.

Here, we build a small plan editor rather than a picture of a workflow. The user adds the steps, selects them and moves them. Fission's `InfiniteCanvas` supplies the retained canvas interaction; we do not recreate touch hit testing or camera transforms in the screen.

The plan lasts for this app run. It does not execute the inspection, capture photographs or persist a work order.

## Create actual steps, then select and move them

The draft belongs to the form. Adding a step validates the text and creates a record in app state. Each record receives a stable ID once; the suggested initial position can use the current list length, but identity cannot.

Canvas interaction callbacks arrive through `cx.input.canvas_interaction()`. The reducer only applies changes to known nodes. An action cannot create an arbitrary node merely by naming an unknown ID.

use fission::prelude::*;

#[derive(Clone, Debug, PartialEq)]
pub struct InspectionStep {
    pub key: String,
    pub id: CanvasNodeId,
    pub title: String,
    pub detail: String,
    pub bounds: LayoutRect,
}

#[derive(Clone, Debug, PartialEq)]
pub struct InspectionCanvasState {
    pub steps: Vec<InspectionStep>,
    pub selected_step: Option<CanvasNodeId>,
    next_id: u64,
}
impl Default for InspectionCanvasState {
    fn default() -> Self {
        Self { steps: Vec::new(), selected_step: None, next_id: 1 }
    }
}
impl GlobalState for InspectionCanvasState {}

impl InspectionCanvasState {
    pub fn add_step(&mut self, title: String, detail: String) -> bool {
        if title.trim().is_empty() || detail.trim().is_empty() { return false; }
        let Some(next) = self.next_id.checked_add(1) else { return false };
        let key = format!("inspection-step.{}", self.next_id);
        let id = CanvasNodeId::explicit(&key);
        let column = (self.steps.len() % 3) as f32;
        let row = (self.steps.len() / 3) as f32;
        self.steps.push(InspectionStep {
            key,
            id,
            title: title.trim().to_owned(),
            detail: detail.trim().to_owned(),
            bounds: LayoutRect::new(column * 240.0, row * 160.0, 200.0, 120.0),
        });
        self.selected_step = Some(id);
        self.next_id = next;
        true
    }

    pub fn move_selected(&mut self, x: f32, y: f32) {
        if let Some(step) = self.steps.iter_mut().find(|step| Some(step.id) == self.selected_step) {
            step.bounds.origin.x += x;
            step.bounds.origin.y += y;
        }
    }
    pub fn remove_selected(&mut self) {
        self.steps.retain(|step| Some(step.id) != self.selected_step);
        self.selected_step = None;
    }
}

#[fission_reducer(SelectInspectionStep)]
pub fn select_inspection_step(state: &mut InspectionCanvasState, id: CanvasNodeId) {
    if state.steps.iter().any(|step| step.id == id) {
        state.selected_step = Some(id);
    }
}

#[fission_reducer(EditInspectionCanvas)]
pub fn edit_inspection_canvas(
    state: &mut InspectionCanvasState,
    cx: &mut ReducerContext<InspectionCanvasState>,
) {
    let Some(interaction) = cx.input.canvas_interaction() else { return };
    match interaction.kind {
        CanvasInteractionKind::SelectNode { node_id }
            if interaction.phase == CanvasInteractionPhase::Activate =>
        {
            let id = CanvasNodeId::from_u128(node_id);
            if state.steps.iter().any(|step| step.id == id) { state.selected_step = Some(id); }
        }
        CanvasInteractionKind::MoveNode { .. }
            if interaction.phase == CanvasInteractionPhase::Update =>
        {
            for change in &interaction.node_changes {
                if let Some(step) = state.steps.iter_mut().find(|step| step.id.0 == change.node_id) {
                    step.bounds = change.after;
                }
            }
        }
        _ => {}
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn removing_an_earlier_step_does_not_change_the_remaining_id() {
        let mut state = InspectionCanvasState::default();
        state.add_step("Isolate equipment".into(), "Use the approved safety procedure".into());
        state.add_step("Inspect filter".into(), "Record visible damage".into());
        let second = state.steps[1].id;
        state.selected_step = Some(state.steps[0].id);
        state.remove_selected();
        assert_eq!(state.steps[0].id, second);
        state.add_step("Review evidence".into(), "Review the inspection record".into());
        assert_ne!(state.steps[1].id, second);
    }

    #[test]
    fn a_blank_title_leaves_the_plan_unchanged() {
        let mut state = InspectionCanvasState::default();
        assert!(!state.add_step(" ".into(), "A detail".into()));
        assert!(state.steps.is_empty());
    }
}

use fission::prelude::*;


use crate::card::InspectionStepCard;
use crate::state::{
    InspectionCanvasState, EditInspectionCanvas, edit_inspection_canvas,
    SelectInspectionStep, select_inspection_step,
};

fission_component! {
    pub App<InspectionCanvasState> {
        state {
            title: String = String::new(),
            detail: String = String::new(),
            invalid: bool = false,
        }
    }
    view(draft, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let edit = with_reducer!(cx.build, EditInspectionCanvas, edit_inspection_canvas);
        let selected = state.selected_step.into_iter().collect::<std::collections::BTreeSet<_>>();
        let nodes = state.steps.iter().map(|step| {
            let mut node = InfiniteCanvasNode::new(
                step.id,
                step.bounds,
                Widget::from(InspectionStepCard::new(
                    step.title.clone(),
                    step.detail.clone(),
                    state.selected_step == Some(step.id),
                )).id(WidgetId::explicit(&format!("{}.card", step.key))),
            );
            node.resizable = false;
            node
        }).collect::<Vec<_>>();
    } =>
    Container(SafeArea(child: Scroll(child:
        Container(Column(gap: tokens.spacing.m, children: [
            Text(cx.tr("canvas.title")).size(tokens.typography.heading1_size),
            Text(cx.tr("canvas.description")),
            TextInput(label: Some(cx.tr("canvas.new_title").into()), bind: draft.title,
                required: true, semantics_identifier: "canvas.draft.title".to_string()),
            TextInput(label: Some(cx.tr("canvas.new_detail").into()), bind: draft.detail,
                required: true, semantics_identifier: "canvas.draft.detail".to_string()),
            Button(
                child: Text(cx.tr("canvas.add")),
                key: "add-step",
                on_press: reduce {
                    if state.add_step(draft.title.clone(), draft.detail.clone()) {
                        draft.title.clear();
                        draft.detail.clear();
                        draft.invalid = false;
                    } else { draft.invalid = true; }
                },
            ).semantics_identifier("canvas.add-step"),
            if draft.invalid { Text(cx.tr("canvas.invalid")).color(tokens.colors.error) },
            if let Some(step) = state.steps.iter().find(|step| Some(step.id) == state.selected_step) {
                Column(gap: tokens.spacing.s, children: [
                    Text(step.title.clone()).weight(tokens.typography.font_weight_semibold),
                    Text(step.detail.clone()),
                ])
            },
            Container(
                if state.steps.is_empty() {
                    EmptyState(title: cx.tr("canvas.empty"),
                        description: Some(cx.tr("canvas.empty_help")))
                } else {
                    InfiniteCanvas(
                        id: Some(WidgetId::explicit("inspection.plan")),
                        nodes: nodes,

                        selected_nodes: selected,
                        selection_policy: CanvasSelectionPolicy::Single,
                        grid: Some(CanvasGrid::lines(32.0, tokens.colors.border, 1.0)),
                        min_scale: 0.25,
                        max_scale: 3.0,
                        actions: InfiniteCanvasActions {
                            on_selection_change: Some(edit.clone()),
                            on_node_move: Some(edit),
                            ..Default::default()
                        },
                    )
                }
            ).height(360.0).border(tokens.colors.border, 1.0),
        ]))
        .padding_all(tokens.spacing.l)
        .width_length(Length::percent(100.0))
        .max_width(1040.0),
    )))
    .height_length(Length::vh(100.0))
}

## Add relationships and a non-gesture editing path

The connectors describe the sequence in which steps were added. Moving a card changes its geometry, not that sequence. Edge identity comes from its two endpoint IDs, so it remains attached when either endpoint moves.

A canvas cannot be the only way to edit the plan. The labelled buttons below it use the same selected-step state as tapping a node. Movement and removal are ordinary reducers, so someone who cannot perform a precise drag can still arrange the plan.

Replace only the screen; state, card and shells stay shared:

use crate::state::{

    SelectInspectionStep, select_inspection_step,
};

fission_component! {
    pub App<InspectionCanvasState> {
        state {
            title: String = String::new(),
            detail: String = String::new(),
            invalid: bool = false,
        }
    }
    view(draft, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let edit = with_reducer!(cx.build, EditInspectionCanvas, edit_inspection_canvas);

                end_marker: None,

                        draft.title.clear();
                        draft.detail.clear();
                        draft.invalid = false;

                    EmptyState(title: cx.tr("canvas.empty"),

                        id: Some(WidgetId::explicit("inspection.plan")),
                        nodes: nodes,
                        edges: edges,
                        selected_nodes: selected,
                        selection_policy: CanvasSelectionPolicy::Single,
                        grid: Some(CanvasGrid::lines(32.0, tokens.colors.border, 1.0)),
                        min_scale: 0.25,
                        max_scale: 3.0,
                        actions: InfiniteCanvasActions {
                            on_selection_change: Some(edit.clone()),
                            on_node_move: Some(edit),
                            ..Default::default()
                        },
                    )
                }
            ).height(360.0).border(tokens.colors.border, 1.0),
            if let Some(step) = state.steps.iter().find(|step| Some(step.id) == state.selected_step) {
                Column(gap: tokens.spacing.s, children: [
                    Text(step.title.clone()).weight(tokens.typography.font_weight_semibold),
                    Text(step.detail.clone()),
                ])
            },
            Text(cx.tr("canvas.step_list")).weight(tokens.typography.font_weight_semibold),
            Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                for step in &state.steps {
                    Button(
                        child: Text(step.title.clone()),
                        key: step.key.clone(),

## Verify touch interaction on Android

The browser is useful for the editor's state transitions, but it cannot establish how one-finger dragging and multi-touch zoom feel on a phone. Test the installed app on an emulator and a physical device:

```sh
cargo test
fission doctor android --project-dir .
fission devices --project-dir .
fission run --target android --device <device-id> --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```

Check an empty plan, several overlapping nodes, the configured zoom limits, large text and rotation. Pan the viewport without selecting a different record, then move a node without unexpectedly panning the viewport. Repeat selection and movement using the ordinary buttons.

The compact cards limit their text to two lines per field; the selected record's full text remains outside the canvas. This keeps a long description from painting over another node without discarding the description from the document.

The tests check validation and stable IDs after removal. They do not prove touch, camera clipping, accessibility or visual layout; those need the rendered target.

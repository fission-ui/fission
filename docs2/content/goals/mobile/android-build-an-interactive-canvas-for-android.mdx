## Create the project and add the target

Create the project and add the target used by this guide. Fission generates the native host; the app and its behaviour stay in shared Rust code.

```sh
cargo install cargo-fission
fission init android-build-an-interactive-canvas-for-android
cd android-build-an-interactive-canvas-for-android
fission add-target android --project-dir .
cargo add serde_yaml
```

## Files created by Fission

This is the starter tree Fission generates. Keep shared app code in `src/`; the generated platform files handle native launch and packaging.

```text
android-build-an-interactive-canvas-for-android/
├── Cargo.toml                 # Rust package and dependencies
├── fission.toml               # app identity, targets and capabilities
├── src/
│   ├── main.rs                # generated app entrypoint
│   ├── lib.rs                 # shared app setup
│   └── app.rs                 # shared Fission screen
└── platforms/
    └── android/              # generated Android host
```

Keep the screen, shared state, reducers and reusable `fission_component!` components in the Rust project. Add a feature-specific state, service or effect module only when it gives the feature a useful boundary. The generated platform files handle native launch and packaging; shared components do not need to import platform APIs.

## Build an interactive canvas for Android

Keep the document model separate from the camera transform: selection and node edits belong to product state, while pan and zoom describe the current viewport. Assign each drawn item a stable ID so selecting an item still selects the same item after an insert or reorder. Put keyboard and touch actions on the same semantic command path, and provide a readable list or inspector as an alternative to precise canvas gestures. Test an empty canvas, a dense canvas, zoom limits, a selected item after reorder, and a narrow screen. Use the [interactive canvas reference](/reference/widgets/infinite-canvas/) for the public widget contract.

The browser preview uses a sample work order seeded by the preview host. The app’s normal state starts empty and can be populated from the selected work order; the sample is not production data. The canvas reports gestures through the reducer, while the buttons below it provide a non-gesture way to select a step.

<!-- fission:file path="src/state.rs" -->
```rust
use fission::prelude::*;

#[derive(Debug, Clone)]
pub struct InspectionStep {
    pub key: &'static str,
    pub id: CanvasNodeId,
    pub title: &'static str,
    pub detail: &'static str,
    pub bounds: LayoutRect,
}

impl InspectionStep {
    pub fn new(
        key: &'static str,
        title: &'static str,
        detail: &'static str,
        bounds: LayoutRect,
    ) -> Self {
        Self { key, id: CanvasNodeId::explicit(key), title, detail, bounds }
    }
}

#[derive(Debug, Default)]
pub struct InspectionCanvasState {
    pub steps: Vec<InspectionStep>,
    pub selected_step: Option<CanvasNodeId>,
}

impl GlobalState for InspectionCanvasState {}

#[fission_reducer(SelectInspectionStep)]
pub fn select_inspection_step(state: &mut InspectionCanvasState, step: CanvasNodeId) {
    state.selected_step = Some(step);
}

#[fission_reducer(EditInspectionCanvas)]
pub fn edit_inspection_canvas(
    state: &mut InspectionCanvasState,
    ctx: &mut ReducerContext<InspectionCanvasState>,
) {
    let Some(interaction) = ctx.input.canvas_interaction().cloned() else {
        return;
    };

    match interaction.kind {
        CanvasInteractionKind::SelectNode { node_id }
            if interaction.phase == CanvasInteractionPhase::Activate =>
        {
            state.selected_step = Some(CanvasNodeId::from_u128(node_id));
        }
        CanvasInteractionKind::MoveNode { .. }
            if interaction.phase == CanvasInteractionPhase::Update =>
        {
            for change in interaction.node_changes {
                if let Some(step) = state.steps.iter_mut().find(|step| step.id.0 == change.node_id) {
                    step.bounds = change.after;
                }
            }
        }
        _ => {}
    }
}
```

```rust
use fission::op::{Fill, LineCap, LineJoin, Stroke};
use fission::prelude::*;

use crate::state::{
    edit_inspection_canvas, select_inspection_step, EditInspectionCanvas,
    InspectionCanvasState, SelectInspectionStep,
};

fission_component! {
    pub InspectionStepCard<()> {
        props {
            identifier: String,
            title: String,
            detail: String,
            selected: bool,
        }
    }
    view(card, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    SemanticsRegion(
        identifier: Some(card.identifier.clone()),
        label: Some(card.title.clone()),
        child: Container(Column(gap: tokens.spacing.xs, children: [
            Text(card.title.clone()).weight(tokens.typography.font_weight_semibold),
            Text(card.detail.clone()).size(tokens.typography.font_size_sm)
                .color(tokens.colors.text_secondary),
        ]))
        .padding_all(tokens.spacing.m)
        .bg(if card.selected { tokens.colors.primary_subtle } else { tokens.colors.surface })
        .border(if card.selected { tokens.colors.primary } else { tokens.colors.border }, 1.0)
        .border_radius(tokens.radii.medium),
    )
}

fission_component! {
    pub App<InspectionCanvasState>
    view(_app, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let edit = with_reducer!(cx.build, EditInspectionCanvas, edit_inspection_canvas);
        let selected_nodes = state.selected_step.into_iter().collect();
        let nodes = state.steps.iter().map(|step| {
            let selected = state.selected_step == Some(step.id);
            let mut node = InfiniteCanvasNode::new(
                step.id,
                step.bounds,
                Widget::from(InspectionStepCard::new(
                    format!("inspection-step-{}", step.key),
                    cx.tr(step.title),
                    cx.tr(step.detail),
                    selected,
                )),
            );
            node.resizable = false;
            node
        }).collect::<Vec<_>>();
        let edges = state.steps.windows(2).map(|steps| {
            let (from, to) = (&steps[0], &steps[1]);
            InfiniteCanvasEdge {
                id: CanvasEdgeId::explicit(&format!("wo-1048-{}-to-{}", from.key, to.key)),
                from: CanvasEdgeEndpoint::Node { node: from.id, anchor: CanvasNodeAnchor::Right },
                to: CanvasEdgeEndpoint::Node { node: to.id, anchor: CanvasNodeAnchor::Left },
                route: CanvasEdgeRoute::Straight,
                stroke: Stroke {
                    fill: Fill::Solid(tokens.colors.primary),
                    width: 2.0,
                    dash_array: None,
                    dash_offset: 0.0,
                    line_cap: LineCap::Round,
                    line_join: LineJoin::Round,
                    trim: None,
                },
                start_marker: None,
                end_marker: None,
                label: Some(CanvasEdgeLabel::new(
                    Text(cx.tr("canvas.edge")).size(tokens.typography.font_size_sm),
                )),
            }
        }).collect::<Vec<_>>();
        let step_buttons = state.steps.iter().map(|step| {
            let action = with_reducer!(
                cx.build,
                SelectInspectionStep(step.id),
                select_inspection_step,
            );
            Button {
                id: Some(WidgetId::explicit(&format!("inspection-step-{}", step.key))),
                child: Some(Text::new(cx.tr(step.title)).into()),
                on_press: Some(action),
                ..Default::default()
            }
            .into()
        }).collect::<Vec<_>>();
        let selected_title = state.steps.iter()
            .find(|step| Some(step.id) == state.selected_step)
            .map(|step| cx.tr(step.title))
            .unwrap_or_else(|| cx.tr("canvas.none_selected"));
    } =>
    SemanticsRegion(
        identifier: Some("canvas-workflow".to_string()),
        label: Some(cx.tr("canvas.title")),
        child: Container(Column(gap: tokens.spacing.m, children: [
            Column(gap: tokens.spacing.xs, children: [
                Text(cx.tr("canvas.title")).weight(tokens.typography.font_weight_bold),
                Text(cx.tr("canvas.description")),
            ]),
            Container(
                if state.steps.is_empty() {
                    Column(gap: tokens.spacing.xs, children: [
                        Text(cx.tr("canvas.empty.title")).weight(tokens.typography.font_weight_semibold),
                        Text(cx.tr("canvas.empty.description")).color(tokens.colors.text_secondary),
                    ])
                } else {
                    InfiniteCanvas(
                        id: Some(WidgetId::explicit("northbank.wo-1048.inspection-plan")),
                        nodes: nodes,
                        edges: edges,
                        selected_nodes: selected_nodes,
                        selection_policy: CanvasSelectionPolicy::Single,
                        snap: CanvasSnap { enabled: true, spacing: 16.0, threshold: 4.0 },
                        grid: Some(CanvasGrid::lines(32.0, tokens.colors.border, 1.0)),
                        actions: InfiniteCanvasActions {
                            on_selection_change: Some(edit.clone()),
                            on_node_move: Some(edit),
                            ..Default::default()
                        },
                        ..Default::default()
                    )
                }
            )
                .height(320.0)
                .bg(tokens.colors.background)
                .border(tokens.colors.border, 1.0)
                .border_radius(tokens.radii.medium),
            Text(format!("{}: {}", cx.tr("canvas.selected"), selected_title))
                .color(tokens.colors.text_secondary),
            Text(cx.tr("canvas.step_list")).weight(tokens.typography.font_weight_semibold),
            Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: step_buttons),
        ]))
        .padding_all(tokens.spacing.l)
        .bg(tokens.colors.surface)
        .border(tokens.colors.border, 1.0)
        .border_radius(tokens.radii.large),
    )
}
```

## Verify the user task on Android

On an Android emulator, repeat the feature path described above and check the expected result. If this task has an unavailable, denied or failure path, run that path too and confirm the screen offers a way to continue. The browser preview demonstrates component state only; the commands below verify the native host.

Use LiveTest with the semantic identifiers shown in the component to confirm focus and action behavior. If this screen adapts to window size, repeat the flow at a narrow phone width and a wider display.

### Run, test and build

```sh
cargo test
fission doctor android --project-dir .
fission run --target android --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```

`cargo test` runs Rust tests you add; the generated scaffold does not create feature-specific tests. `fission doctor` reports missing Android tools, `fission run` launches the selected emulator or connected device, and `fission test` checks that the generated host can start. A release build checks packaging, but none of these commands proves a physical permission or hardware flow works.

A delivery address does not become meaningless because a phone cannot locate itself. Location is useful as additional evidence, but treating it as a prerequisite would stop a courier from preparing a handoff indoors, after a denied permission request or when the provider has no position available.

Here, the screen keeps the named stop and handoff notes, then lets the courier attach a one-time pin. The position includes its reported accuracy so that the courier can judge its usefulness. Nothing in this example tracks the driver in the background or submits a delivery record.

This requires two separate results: permission to request a position, and the position returned by a later request. A permission grant is not itself evidence that the device has found a location.

## Create the project and add the target

Complete the [iOS toolchain setup](/blog/set-up-rust-ios-development-with-fission/) and [simulator launch guide](/blog/choose-boot-and-launch-an-ios-simulator-with-fission/) first.

```sh
fission init delivery-handoff
cd delivery-handoff
fission add-target ios --project-dir .
fission add-capability geolocation --project-dir .
cargo add serde_yaml
fission doctor ios --project-dir .
```

The capability command adds `NSLocationWhenInUseUsageDescription` to the generated iOS configuration. Review `platforms/ios/Info.plist` and replace its generic explanation with the reason this app needs location. For example:

```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>Add an optional location pin to the delivery handoff you are preparing.</string>
```

Keep that explanation consistent with what the app actually does. This tutorial does not add a background-location mode or an always-authorised workflow.

## Request access, then inspect the current result

The iOS provider queues its permission prompt on the main queue and returns the permission state it already knows. That response may precede the user's answer. A completed request must therefore not be presented as a grant: after answering, use **Refresh access status** before requesting a pin.

The browser provider behaves differently. It can report that permission is undecided, then prompt during the position lookup itself. The shared reducer permits that browser path without treating an undecided native permission as approval.

Buttons use inline `reduce` handlers for their synchronous work. Completion reducers decode `cx.input.capability_ok(...)` and `capability_error(...)`. The callback actions do not contain an invented position or a default error that might be mistaken for the host's response.

use fission::prelude::*;

#[derive(Debug, Default)]
pub struct DeliveryHandoffState {
    pub locale: Locale,
    pub permission: Option<GeolocationPermission>,
    pub permission_busy: bool,
    pub permission_message: Option<PermissionMessage>,
    pub locating: bool,
    pub position: Option<GeolocationPosition>,
    pub location_message: Option<LocationMessage>,
}

impl GlobalState for DeliveryHandoffState {}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum PermissionMessage {
    Requesting,
    Checking,
    Granted,
    Denied,
    Prompt,
    Unsupported,
    Unknown,
    CheckFailed,
}

impl PermissionMessage {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::Requesting => "handoff.permission.requesting",
            Self::Checking => "handoff.permission.checking",
            Self::Granted => "handoff.permission.granted",
            Self::Denied => "handoff.permission.denied",
            Self::Prompt => "handoff.permission.prompt",
            Self::Unsupported => "handoff.permission.unsupported",
            Self::Unknown => "handoff.permission.unknown",
            Self::CheckFailed => "handoff.permission.check_failed",
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum LocationMessage {
    Finding,
    Captured,
    AccessRequired,
    Denied,
    Unsupported,
    TimedOut,
    Unavailable,
    Failed,
}

impl LocationMessage {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::Finding => "handoff.location.finding",
            Self::Captured => "handoff.location.captured",
            Self::AccessRequired => "handoff.location.access_required",
            Self::Denied => "handoff.location.denied",
            Self::Unsupported => "handoff.location.unsupported",
            Self::TimedOut => "handoff.location.timeout",
            Self::Unavailable => "handoff.location.unavailable",
            Self::Failed => "handoff.location.failed",
        }
    }
}


#[fission_reducer(LocationPermissionUpdated)]
fn permission_updated(state: &mut DeliveryHandoffState, cx: &mut ReducerContext<DeliveryHandoffState>) {
    state.permission_busy = false;
    let permission = cx.input.capability_ok(REQUEST_GEOLOCATION_PERMISSION)
        .or_else(|| cx.input.capability_ok(GET_GEOLOCATION_PERMISSION));
    state.permission = permission;
    state.permission_message = Some(match permission {
        Some(GeolocationPermission::Granted) => PermissionMessage::Granted,
        Some(GeolocationPermission::Denied) => PermissionMessage::Denied,
        Some(GeolocationPermission::Prompt) => PermissionMessage::Prompt,
        Some(GeolocationPermission::Unsupported) => PermissionMessage::Unsupported,
        Some(GeolocationPermission::Unknown) | None => PermissionMessage::Unknown,
    });
}

#[fission_reducer(LocationPermissionFailed)]
fn permission_failed(state: &mut DeliveryHandoffState) {
    state.permission_busy = false;
    state.permission_message = Some(PermissionMessage::CheckFailed);
}

pub fn request_access(state: &mut DeliveryHandoffState, cx: &mut ReducerContext<DeliveryHandoffState>) {
    if state.permission_busy || state.locating { return; }
    state.permission_busy = true;
    state.permission_message = Some(PermissionMessage::Requesting);
    let ok = cx.effects.bind(LocationPermissionUpdated, reduce_with!(permission_updated));
    let err = cx.effects.bind(LocationPermissionFailed, reduce_with!(permission_failed));
    cx.effects.geolocation()
        .request_permission(GeolocationPermissionRequest { precise: true, background: false })
        .on_ok(ok).on_err(err);
}

pub fn refresh_access(state: &mut DeliveryHandoffState, cx: &mut ReducerContext<DeliveryHandoffState>) {
    if state.permission_busy || state.locating { return; }
    state.permission_busy = true;
    state.permission_message = Some(PermissionMessage::Checking);
    let ok = cx.effects.bind(LocationPermissionUpdated, reduce_with!(permission_updated));
    let err = cx.effects.bind(LocationPermissionFailed, reduce_with!(permission_failed));
    cx.effects.geolocation().permission().on_ok(ok).on_err(err);
}

#[fission_reducer(HandoffPinCaptured)]
fn pin_captured(state: &mut DeliveryHandoffState, cx: &mut ReducerContext<DeliveryHandoffState>) {
    state.locating = false;
    if let Some(position) = cx.input.capability_ok(GET_CURRENT_POSITION) {
        state.position = Some(position);
        state.location_message = Some(LocationMessage::Captured);
    } else {
        state.location_message = Some(LocationMessage::Failed);
    }
}

#[fission_reducer(HandoffPinFailed)]
fn pin_failed(state: &mut DeliveryHandoffState, cx: &mut ReducerContext<DeliveryHandoffState>) {
    state.locating = false;
    let error = cx.input.capability_error(GET_CURRENT_POSITION);
    let code = error.as_ref().map(|error| error.code.as_str()).unwrap_or("");
    if code == "permission_denied" {
        state.permission = Some(GeolocationPermission::Denied);
        state.permission_message = Some(PermissionMessage::Denied);
    }
    state.location_message = Some(match code {
        "permission_denied" => LocationMessage::Denied,
        "unsupported" => LocationMessage::Unsupported,
        "timeout" => LocationMessage::TimedOut,
        "position_unavailable" | "unavailable" => LocationMessage::Unavailable,
        _ => LocationMessage::Failed,
    });
}

pub fn may_request_position(permission: Option<GeolocationPermission>, browser: bool) -> bool {
    permission == Some(GeolocationPermission::Granted)
        || (browser && permission == Some(GeolocationPermission::Prompt))
}

pub fn add_pin(state: &mut DeliveryHandoffState, cx: &mut ReducerContext<DeliveryHandoffState>) {
    if state.locating || state.permission_busy { return; }
    if !may_request_position(state.permission, cfg!(target_arch = "wasm32")) {
        state.location_message = Some(LocationMessage::AccessRequired);
        return;
    }
    state.locating = true;
    state.location_message = Some(LocationMessage::Finding);
    let ok = cx.effects.bind(HandoffPinCaptured, reduce_with!(pin_captured));
    let err = cx.effects.bind(HandoffPinFailed, reduce_with!(pin_failed));
    cx.effects.geolocation()
        .current_position(GeolocationPositionRequest {
            high_accuracy: true, timeout_ms: Some(10_000), maximum_age_ms: Some(30_000),
        }).on_ok(ok).on_err(err);
}

#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn only_the_browser_may_prompt_as_part_of_position_lookup() {
        assert!(!may_request_position(Some(GeolocationPermission::Prompt), false));
        assert!(may_request_position(Some(GeolocationPermission::Prompt), true));
    }
    #[test]
    fn absent_or_denied_access_never_enables_a_position_request() {
        for permission in [None, Some(GeolocationPermission::Denied), Some(GeolocationPermission::Unknown),
                           Some(GeolocationPermission::Unsupported)] {
            assert!(!may_request_position(permission, false));
            assert!(!may_request_position(permission, true));
        }
        assert!(may_request_position(Some(GeolocationPermission::Granted), false));
    }
}

use std::collections::HashMap;

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::Env;

const SOURCES: [(&str, &str); 2] = [
    ("en-US", include_str!("../../i18n/en-US.yaml")),
    ("es-ES", include_str!("../../i18n/es-ES.yaml")),
];

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in SOURCES {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid handoff translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

## Verify the native request on iOS

```sh
cargo test
fission run --target ios --project-dir .
```

The tests exercise the app's permission gate: undecided access may trigger a browser lookup, but not a native one. They do not pretend to open the iOS prompt.

In the simulator, supply a location using the simulator's location controls, then repeat with no simulated location. On an iPhone, check the first-use prompt, denial, a later change in Settings and an unavailable position. The text draft must survive every attempt, and neither permission checks nor position requests should leave the screen permanently pending.

Use the [physical iPhone guide](/blog/install-a-fission-app-on-a-physical-iphone/) for signing, Developer Mode and installation. `fission run --target ios` launches the simulator; packaging an IPA is a separate operation:

```sh
fission package --project-dir . --target ios --format ipa --release
```

A successful simulator build establishes neither an iPhone permission result nor the usefulness of its location. Verify those through the actual user action on the device.

Motion is useful when it explains where a panel came from or where it went. It should not decide whether a piece of work is complete. Those are separate concerns: the reducer changes state, and the widget presents that state with or without a transition.

Here, an engineer can consult a compressor inspection procedure in a drawer and record that the filter has been checked. Opening the procedure does not complete the inspection. Closing an animation midway must not clear the recorded check.

## Create the project and add the target

Complete [Android SDK and NDK setup](/blog/set-up-rust-android-gui-development-with-fission/) and either [create an emulator](/blog/create-and-launch-a-fission-android-emulator/) or [connect a phone](/blog/run-a-fission-app-on-a-physical-android-phone/) first.

```sh
fission init android-add-responsive-motion-to-an-android-fission-app
cd android-add-responsive-motion-to-an-android-fission-app
cargo add serde_yaml
fission add-target android --project-dir .
```

Keep the generated `src/main.rs`. Replace `src/lib.rs` so both Android and the Web preview run the inspection component, not the scaffold counter. The shared translation module installs English and Spanish in every shell.

## Make the state change correct without motion

Use the built-in `Drawer` because this is an edge-attached overlay, not a box whose position we need to animate by hand. It already owns the backdrop and dismissal interaction. Initially we explicitly select `DrawerMotion::None` so the behaviour can be checked without animation.

The procedure is illustrative maintenance copy, not a substitute for the equipment manufacturer's safety instructions. The checkbox records a statement by the user; opening the procedure is not evidence that the physical inspection happened.

```rust
use fission::prelude::*;

fission_component! {
    pub InspectionInstructions<()> {
        state {
            instructions_open: bool = false,
            reduce_panel_motion: bool = false,
            filter_checked: bool = false,
        }
    }
    view(inspection, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(SafeArea(child: Scroll(child:
        Container(Column(gap: tokens.spacing.m, children: [
            Text(cx.tr("inspection.title")).size(tokens.typography.heading1_size),
            Text(cx.tr("inspection.context")).color(tokens.colors.text_secondary),
            Checkbox(
                label: Some(cx.tr("inspection.filter_checked")),
                checked: inspection.filter_checked,
                bind(on_toggle): to(inspection.filter_checked),
            ),
            Text(cx.tr(if inspection.filter_checked {
                "inspection.checked"
            } else {
                "inspection.pending"
            })),
            Button(
                child: Text(cx.tr("inspection.open")),
                key: "open-instructions",
                on_press: reduce { inspection.instructions_open = true; },
            ).semantics_identifier("inspection.instructions.open"),
            Drawer(
                id: WidgetId::explicit("inspection.instructions"),
                side: DrawerSide::Right,
                is_open: inspection.instructions_open,
                motion: Some(DrawerMotion::None),
                on_dismiss: reduce { inspection.instructions_open = false; },
                dismiss_semantics_identifier: "inspection.instructions.dismiss".to_string(),
                content: SafeArea(child: Scroll(child:
                    Container(Column(gap: tokens.spacing.m, children: [
                        Text(cx.tr("inspection.instructions.title"))
                            .size(tokens.typography.heading2_size),
                        Text(cx.tr("inspection.instructions.one")),
                        Text(cx.tr("inspection.instructions.two")),
                        Text(cx.tr("inspection.instructions.three")),
                        Button(
                            child: Text(cx.tr("inspection.close")),
                            key: "close-instructions",
                            on_press: reduce { inspection.instructions_open = false; },
                        ).semantics_identifier("inspection.instructions.close"),
                    ])).padding_all(tokens.spacing.l),
                )),
            ),
        ]))
        .padding_all(tokens.spacing.l)
        .width_length(Length::percent(100.0))
        .max_width(720.0),
    )))
    .height_length(Length::vh(100.0))
}
```

```rust
pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid checked-in translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}
```

## Let the drawer own its transition

Now enable the drawer's built-in side-slide and fade preset. We do not add a timer, delay the reducer or hold a view handle until an animation completes. The stable drawer ID lets Fission associate the entering and exiting surface with the same retained widget.

A local reduced-motion switch makes both paths easy to exercise. It sets `DrawerMotion::None` for this panel, not a second implementation of the inspection. Fission's broader `MotionPreference::Reduced` environment setting also resolves declared motion immediately; `WidgetMotion::Off` only disables defaults on widgets whose motion was left unset.

## Check interruption, resizing and the Android host

The Web shell reads the browser's reduced-motion preference. This checkout does not automatically map Android's system animation setting into `Env.motion_preference`; do not claim that changing an Android setting has exercised that integration. The explicit panel switch above works on both targets. An app-wide Android preference can be stored in app state and mapped to the environment through the normal shell configuration.

Run on an emulator or phone:

```sh
fission doctor android --project-dir .
fission devices --project-dir .
fission run --target android --device <device-id> --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```

Resize or rotate with the panel open, background and resume the app, and repeat the rapid open/dismiss sequence. Check that the drawer remains within the viewport and its content can scroll at a larger font size. These are rendered interaction checks; compilation cannot establish them.

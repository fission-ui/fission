This guide builds a short training-video screen for a plant survey app. Fission’s `Video` widget owns video playback state and connects it to the Android host player. It is not an audio-only player; if your app needs background music or audio playback without video, use an app-owned native module until Fission adds a standalone audio API.

The preview uses a public MP4 sample so it can play in the browser. Replace it with a video you own before shipping. A network video needs connectivity; bundle a checked-in asset when the screen must work offline.

## Create the Android project

```sh
cargo install cargo-fission
fission init harbour-plant-survey
cd harbour-plant-survey
cargo add serde_yaml
fission add-target android --project-dir .
```

Fission creates the Android host under `platforms/android/`. Keep the player, controls, and screen in shared Rust code; don’t reach into the generated host to control playback.

## Add the video surface and its controls

The survey team uses the clip to compare a plant’s growth stage before recording a field observation. The video has an explicit ID because both control actions must address this exact surface. The runtime owns playback state; the buttons send its typed play and pause actions.

```rust
use fission::prelude::*;

const SAMPLE_VIDEO_URL: &str =
    "https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4";

fission_component! {
    pub PlantSurveyPlayer<()> {}
    view(_screen, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let video_width = (cx.view.viewport_size().width - 2.0 * tokens.spacing.l)
            .clamp(1.0, 640.0);
        let video_id = WidgetId::explicit("plant-survey.growth-reference");
        let controls = cx.build.video_controls(video_id);
        let video = Video::network(SAMPLE_VIDEO_URL)
            .id(video_id)
            .size(video_width, video_width * 9.0 / 16.0)
            .semantic_label(cx.tr("player.video.label"));
    } =>
    SemanticsRegion(
        identifier: Some("plant-survey.player".to_string()),
        label: Some(cx.tr("player.screen.label")),
        child: Container(
            Column(gap: tokens.spacing.m, children: [
                Column(gap: tokens.spacing.xs, children: [
                    Text(cx.tr("player.app.title"))
                        .weight(tokens.typography.font_weight_bold),
                    Text(cx.tr("player.app.subtitle"))
                        .color(tokens.colors.text_secondary),
                ]),
                Divider(),
                Text(cx.tr("player.clip.title"))
                    .weight(tokens.typography.font_weight_semibold),
                Container(video)
                    .width(video_width)
                    .height(video_width * 9.0 / 16.0)
                    .border(tokens.colors.border, 1.0)
                    .border_radius(tokens.radii.medium),
                Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                    Button(
                        child: Text(cx.tr("player.action.play")),
                        key: "play-growth-video",
                        variant: ButtonVariant::Primary,
                        on_press: Some(controls.play()),
                    ),
                    Button(
                        child: Text(cx.tr("player.action.pause")),
                        key: "pause-growth-video",
                        variant: ButtonVariant::Outline,
                        on_press: Some(controls.pause()),
                    ),
                ]),
                Text(cx.tr("player.scope"))
                    .color(tokens.colors.text_secondary),
            ])
        )
        .padding_all(tokens.spacing.l)
        .bg(tokens.colors.surface)
        .border(tokens.colors.border, 1.0)
        .border_radius(tokens.radii.large),
    )
}
```

```rust
mod app;

use fission::prelude::*;
use wasm_bindgen::prelude::*;

fn load_bundle(locale: &str, source: &str) -> TranslationBundle {
    TranslationBundle {
        locale: Locale::from(locale),
        messages: serde_yaml::from_str(source).expect("valid tutorial translations"),
    }
}

fn preview_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    env.i18n.add_bundle(load_bundle("en-US", include_str!("i18n/en-US.yaml")));
    env.i18n.add_bundle(load_bundle("es-ES", include_str!("i18n/es-ES.yaml")));
    env
}

#[wasm_bindgen(start)]
pub fn run() -> Result<(), JsValue> {
    console_error_panic_hook::set_once();
    WebApp::<(), _>::new(app::PlantSurveyPlayer)
        .with_env(preview_env())
        .with_title("Harbour Plant Survey")
        .mount("#fission-web-mount")
        .run()
        .map_err(|error| JsValue::from_str(&error.to_string()))
}
```

## Verify playback on Android

Run the app on an emulator or phone with a network connection:

```sh
fission doctor android --project-dir .
fission devices --project-dir .
fission run --target android --project-dir .
```

On the device, start the clip and check the host video surface, then pause and resume it. While it is playing, background the app and play audio in another app; return to the survey and verify the player is still in a sensible state. Repeat with a network interruption. A network source cannot play offline, so package a local asset when field use requires playback without connectivity.

Fission’s runtime handles the video play/pause actions and Android’s native video backend. `VideoAudioOptions::playback()` requests foreground video playback behavior; it does not turn the widget into a general-purpose background audio service. For phone calls, focus loss, and app lifecycle transitions, test on the Android version you intend to support.

```sh
cargo test
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```

`fission test` checks that the generated Android host starts. It does not validate codecs, network availability, or audio focus on a physical phone.

## Create the project and add the target

```sh
cargo install cargo-fission
fission init mobile-build-a-localised-mobile-settings-app-with-a-design-system
cd mobile-build-a-localised-mobile-settings-app-with-a-design-system
fission add-target android ios --project-dir .
```

## Files created by Fission

Fission generates the Android and iOS hosts alongside the shared Rust project:

```text
mobile-build-a-localised-mobile-settings-app-with-a-design-system/
├── Cargo.toml                 # Rust package and dependencies
├── fission.toml               # app identity, targets and capabilities
├── src/
│   ├── main.rs                # generated app entrypoint
│   ├── lib.rs                 # shared app setup
│   └── app.rs                 # shared Fission screen
└── platforms/
    ├── android/              # generated Android host
    └── ios/                  # generated iOS host
```

Keep the selected theme and locale in shared app state. The Android and iOS hosts launch and package the same settings screen.

Add `build.rs` and an app-local `design/dsp.json` plus `design/tokens.json` when you create the design system below. The build script generates the Rust type; the JSON stays as the design source.

fn main() {
    let manifest_dir = PathBuf::from(std::env::var("CARGO_MANIFEST_DIR").unwrap());
    let dsp_path = manifest_dir.join("design/dsp.json");

    fission_design_system_codegen::generate(
        fission_design_system_codegen::Config::new(dsp_path)
            .out_file("mobile_settings_design_system.rs")
            .type_name("MobileSettingsDesignSystem")
            .crate_path("fission::theme"),
    )
    .expect("failed to generate the settings design system");
}

use fission::prelude::*;
use fission::i18n::Locale;

include!(concat!(env!("OUT_DIR"), "/mobile_settings_design_system.rs"));

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct SettingsState {
    pub locale: Locale,
    pub theme_mode: DesignMode,
}

impl Default for SettingsState {
    fn default() -> Self {
        Self {
            locale: Locale::from("en-US"),
            theme_mode: DesignMode::Light,
        }
    }
}

impl GlobalState for SettingsState {}

fission_component! {
    pub MobileSettingsApp<SettingsState>
    view(_settings, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    SemanticsRegion(
        identifier: Some("fieldwork.settings".to_string()),
        label: Some(cx.tr("settings.title")),
        child: SafeArea(
            child: Scroll(
                semantic_label: Some(cx.tr("settings.title")),
                flex_grow: 1.0,
                child: Some(Container(
                    Column(gap: tokens.spacing.m, children: [
                        Row(gap: tokens.spacing.m, align_items: ir_op::AlignItems::Center, children: [
                            Column(gap: tokens.spacing.xs, children: [
                                Text(cx.tr("settings.brand"))
                                    .size(tokens.typography.heading2_size),
                                Badge(text: cx.tr("settings.session_only")),
                            ]),
                            Spacer(flex_grow: 1.0),
                        ]),
                        Divider(),
                        Row(gap: tokens.spacing.s, align_items: ir_op::AlignItems::Center, children: [
                            Column(gap: tokens.spacing.xs, children: [
                                Text(cx.tr("settings.appearance"))
                                    .weight(tokens.typography.font_weight_semibold),
                                Text(cx.tr(if state.theme_mode == DesignMode::Dark {
                                "settings.dark_selected"
                            } else {
                                "settings.light_selected"
                            }))
                                .color(tokens.colors.text_secondary),
                            ]),
                            Spacer(flex_grow: 1.0),
                            Switch(
                                checked: state.theme_mode == DesignMode::Dark,
                                key: "toggle-theme",
                                on_toggle: reduce {
                                    state.theme_mode = if state.theme_mode == DesignMode::Dark {
                                        DesignMode::Light
                                    } else {
                                        DesignMode::Dark
                                    };
                                },
                                semantics_identifier: Some("fieldwork.settings.theme".to_string()),
                            ),
                        ]),
                        Divider(),
                        Column(gap: tokens.spacing.xs, children: [
                            Text(cx.tr("settings.language"))
                                .weight(tokens.typography.font_weight_semibold),
                            Text(cx.tr(if state.locale == Locale::from("es-ES") {
                                "settings.spanish"
                            } else {
                                "settings.english"
                            }))
                            .color(tokens.colors.text_secondary),
                            Row(gap: tokens.spacing.s, children: [
                                Button(
                                    child: Text(cx.tr("settings.english")),
                                    key: "locale-en-US",
                                    variant: if state.locale == Locale::from("en-US") {
                                        ButtonVariant::Primary
                                    } else {
                                        ButtonVariant::Outline
                                    },
                                    on_press: reduce {
                                        state.locale = Locale::from("en-US");
                                    },
                                ).semantics_identifier("fieldwork.settings.locale.en-US"),
                                Button(
                                    child: Text(cx.tr("settings.spanish")),
                                    key: "locale-es-ES",
                                    variant: if state.locale == Locale::from("es-ES") {
                                        ButtonVariant::Primary
                                    } else {
                                        ButtonVariant::Outline
                                    },
                                    on_press: reduce {
                                        state.locale = Locale::from("es-ES");
                                    },
                                ).semantics_identifier("fieldwork.settings.locale.es-ES"),
                            ]),
                        ]),
                        Text(cx.tr("settings.applies"))
                            .color(tokens.colors.text_secondary),
                    ]))
                    .padding_all(tokens.spacing.l)
                    .bg(tokens.colors.surface)
                    .border(tokens.colors.border, 1.0)
                    .border_radius(tokens.radii.large),
                ),
            ),
        ),
    )
}

mod app;
mod translations;

use fission::prelude::*;
use wasm_bindgen::prelude::*;

#[wasm_bindgen(start)]
pub fn run() -> Result<(), JsValue> {
    console_error_panic_hook::set_once();
    WebApp::<app::SettingsState, _>::new(app::MobileSettingsApp)
        .with_env(translations::create_env())
        .with_design_system::<app::MobileSettingsDesignSystem>(DesignMode::Light)
        .with_sync_env(|state, env| {
            env.locale = state.locale.clone();
            env.theme = app::MobileSettingsDesignSystem::theme(state.theme_mode);
        })
        .with_title("Fieldwork Settings")
        .mount("#fission-web-mount")
        .run()
        .map_err(|error| JsValue::from_str(&error.to_string()))
}

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

const SOURCES: [(&str, &str); 2] = [
    ("en-US", include_str!("../i18n/en-US.yaml")),
    ("es-ES", include_str!("../i18n/es-ES.yaml")),
];

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in SOURCES {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid tutorial translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

## Build a localised mobile settings app with a design system

Put the app's DSP and token files in `design/`, generate a typed design system from `build.rs`, and install it when the app starts. This small package changes a button recipe and defines the light/dark colours, then inherits the other component recipes from Fission's default system. Read spacing, type and colour from `Env` in the component. Keep theme and locale in app state, then synchronize both presentation inputs. Include English and Spanish bundles and check the longest translated setting labels at a large font scale on Android and iOS. The choices apply immediately but this example does not persist them between launches; use a Store effect when that is part of the app's requirements. See the [design system](/docs/guides/design-system/) and [theming and i18n](/docs/guides/theming-and-i18n/) guides.

This preview is the settings screen, not a separate demo card. The selected theme and locale live in `GlobalState`, the view reads theme tokens from `Env`, and changing the locale changes `cx.tr` output. The preview loads the checked-in English and Spanish bundles. These settings apply for the current app session only: there is no Save button and no persistence effect. It does not call a native provider or operating-system API.

## Check translated text on Android and iOS

Switch between the configured languages and read every screen in the task. Long translations should wrap without hiding buttons, field errors or status messages; user-visible strings should come from translation keys rather than hard-coded component text.

Check the largest supported text size as well. Keep labels and actions understandable when they wrap to multiple lines, and verify that changing the locale updates the active Fission environment.

### Run, test and build

```sh
cargo test
fission doctor android --project-dir .
fission run --target android --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```

`cargo test` runs Rust tests you add for reducer or stale-completion rules; the generated scaffold does not create those feature tests. `fission doctor` checks each target’s toolchain, `fission run` launches its emulator or Simulator, and `fission test` checks that the generated host can start. A release build validates packaging, not real hardware behavior.


### Run the shared project on both mobile targets

Run both target checks from the generated project root:

```sh
fission doctor android --project-dir .
fission run --target android --project-dir .
fission doctor ios --project-dir .
fission run --target ios --project-dir .
fission test --target android --project-dir .
fission test --target ios --project-dir .
```

Extracting a component should make its responsibility clearer. It is not useful to move half a screen into a helper function if the caller still needs to understand its hidden state and unrelated application dependencies.

We will build a journey-plan editor with two uses of the same summary: one follows the draft, whilst the other shows the last prepared plan. The summary presents the values it receives; the parent decides when to prepare a snapshot. No route lookup or reservation is implied by entering two place names.

## Create the app

Follow [iOS setup](/blog/set-up-rust-ios-development-with-fission/) if needed.

```sh
cargo install cargo-fission
fission init ios-compose-an-ios-app-from-reusable-fission-widgets
cd ios-compose-an-ios-app-from-reusable-fission-widgets
fission add-target ios --project-dir .
cargo add serde_yaml
```

Keep the generated `src/main.rs`. The normal `src/lib.rs` below starts this shared app on native and Web targets; the documentation preview only supplies a mount point.

## Extract at the boundary between responsibilities

`JourneyFact` renders one labelled value. Its label is `TextContent`, so a caller can provide a translation key rather than forcing English into a reusable component. The place name is user data and is not a translation key.

`JourneySummary` groups the two facts and owns only whether its optional details are open. The screen owns draft input and the Prepare action. The prepared journey belongs to application state so it remains a snapshot rather than another view of mutable draft fields.

```rust
    pub locale: Locale,

            locale: Locale::from("en-US"),

    }

impl GlobalState for JourneyState {}
```

```rust
            ),

                key: "destination",

                key: "toggle-details",
                on_press: reduce { summary.show_details = !summary.show_details; },
            ),

        ]),
```

```rust
use super::{
    state::{Journey, JourneyState},
    summary::JourneySummary,
};
use fission::prelude::*;

fission_component! {
    pub JourneyScreen<JourneyState> {
        state {
            origin: String = String::new(),
            destination: String = String::new(),
        }
    }
    view(screen, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } => SafeArea(
        child: Scroll(
            child: Container(Column(gap: tokens.spacing.m, children: [
                Text(cx.tr("journey.heading")).size(tokens.typography.heading2_size),
                Text(cx.tr("journey.explanation")),
                Row(gap: tokens.spacing.s, children: [
                    Button(
                        child: Text(cx.tr("language.english")), key: "english",
                        on_press: reduce { state.locale = Locale::from("en-US"); },
                    ),
                    Button(
                        child: Text(cx.tr("language.spanish")), key: "spanish",
                        on_press: reduce { state.locale = Locale::from("es-ES"); },
                    ),
                ]),
                FormControl(
                    label: Some(cx.tr("journey.origin")),
                    required: true,
                    child: TextInput(
                        value: screen.origin.clone(),
                        bind(on_input): to(screen.origin),
                    ),
                ),
                FormControl(
                    label: Some(cx.tr("journey.destination")),
                    required: true,
                    child: TextInput(
                        value: screen.destination.clone(),
                        bind(on_input): to(screen.destination),
                    ),
                ),
                if !screen.origin.trim().is_empty() && !screen.destination.trim().is_empty() {
                    Column(gap: tokens.spacing.s, children: [
                        Text(cx.tr("journey.draft")),
                        JourneySummary(
                            Journey {
                                origin: screen.origin.trim().to_owned(),
                                destination: screen.destination.trim().to_owned(),
                            },
                            key: "draft-summary",
                        ),
                    ])
                },
                Button(
                    child: Text(cx.tr("journey.prepare")), key: "prepare-journey",
                    disabled: screen.origin.trim().is_empty() || screen.destination.trim().is_empty(),
                    on_press: reduce {
                        state.prepared = Some(Journey {
                            origin: screen.origin.trim().to_owned(),
                            destination: screen.destination.trim().to_owned(),
                        });
                    },
                ),
                if let Some(journey) = &state.prepared {
                    Column(gap: tokens.spacing.s, children: [
                        Text(cx.tr("journey.prepared")),
                        JourneySummary(journey.clone(), key: "prepared-summary"),
                    ])
                },
            ]))
            .padding_all(tokens.spacing.l),
        ),
    )
}
```

```rust
use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid journey translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

pub fn sync_env(state: &crate::app::JourneyState, env: &mut Env) {
    env.locale = state.locale.clone();
}
```

## Make required input visible at the call site

Both summaries use the same component definition. They receive a fully specified `Journey` through the supported positional constructor, with a different stable key for each role. The component does not invent an empty journey through `Default`, and its local details flag is not shared between instances.

The labels inside `JourneyFact` follow the current locale because they remain translation keys. There is no need to translate the component's supplied place names or duplicate the component for Spanish. Switching language should change the interface without changing the plan.

Keys identify retained instances; they do not turn local state into persistence. Clearing a field removes the draft summary from the tree, so its local disclosure state may be discarded. That is appropriate for an optional panel. If disclosure were a product choice that must survive removal, it would need an owner with that longer lifetime.

All content is scrollable, but that still needs a rendered check for clipping, focus and keyboard behavior.

The generated host test checks launch, not component independence. Drive the controls before treating the example as qualified. The plan is in memory only; a reload clears it, and no transport service has been called.

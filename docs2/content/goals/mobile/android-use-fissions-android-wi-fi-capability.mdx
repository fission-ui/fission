## Discovery is not a connection

An inspection report may be ready to upload whilst the phone is still offline. The useful question at that point is whether the expected site network appears in Android's results, not whether the application can manufacture an upload confirmation.

This screen takes the expected prefix from the user, checks Wi-Fi and permission, then requests matching network results. It never asks for a password. The Android provider does not implement connecting or disconnecting; use Android Settings for those operations. A matching name does not authenticate an access point, and a successful scan does not establish internet access.

## Create the shared app

Complete [SDK/NDK setup](/blog/set-up-rust-android-gui-development-with-fission/), then prepare [an emulator](/blog/create-and-launch-a-fission-android-emulator/) or [a phone](/blog/run-a-fission-app-on-a-physical-android-phone/).

```sh
cargo install cargo-fission
fission init android-use-fissions-android-wi-fi-capability
cd android-use-fissions-android-wi-fi-capability
fission add-target android --project-dir .
fission add-capability wifi --project-dir .
cargo add serde_yaml
```

Keep the generated `src/main.rs`. Shared state owns confirmed provider results; the component owns the editable prefix. The same library runs natively and in Web, using the real target provider rather than a memory host.

## Ask, recheck, then scan

Permission requests and permission results are different events. The current Android provider returns a permission snapshot immediately after requesting the OS dialog; it does not wait for the user's answer. Consequently, the screen asks the user to finish that dialog and explicitly check again. It does not chain a scan onto an assumed grant.

There is a second boundary worth making explicit. The provider calls `startScan` and immediately reads `getScanResults`; it does not wait for a fresh scan broadcast, check whether that request was accepted, or enforce `timeout_ms`. Results can therefore be cached or empty. Present the returned count as precisely that, not as proof that nearby networks were exhaustively searched.

use fission::prelude::*;

#[derive(Debug, Default)]
pub struct NetworkCheck {
    pub availability: Option<WifiAvailability>,
    pub networks: Option<Vec<WifiNetwork>>,
    pub scan_prefix: Option<String>,
    pub pending: bool,
    pub issue: Option<&'static str>,
}
impl GlobalState for NetworkCheck {}

impl NetworkCheck {
    pub fn can_scan(&self) -> bool {
        !self.pending && self.availability.as_ref().is_some_and(|value| {
            value.enabled && value.permission == WifiPermission::Granted
        })
    }
}

pub fn check_wifi(state: &mut NetworkCheck, ctx: &mut ReducerContext<NetworkCheck>) {
    if state.pending { return; }
    state.pending = true;
    state.issue = None;
    let ok = ctx.effects.bind(WifiChecked, reduce_with!(wifi_checked));
    let err = ctx.effects.bind(WifiCheckFailed, reduce_with!(wifi_check_failed));
    ctx.effects.wifi().availability().on_ok(ok).on_err(err);
}

#[fission_reducer(WifiChecked)]
pub fn wifi_checked(state: &mut NetworkCheck, ctx: &mut ReducerContext<NetworkCheck>) {
    state.pending = false;
    match ctx.input.capability_ok(GET_WIFI_AVAILABILITY) {
        Some(value) => state.availability = Some(value),
        None => state.issue = Some("wifi.missing"),
    }
}
#[fission_reducer(WifiCheckFailed)]
pub fn wifi_check_failed(state: &mut NetworkCheck, ctx: &mut ReducerContext<NetworkCheck>) {
    state.pending = false;
    state.issue = Some(match ctx.input.capability_error(GET_WIFI_AVAILABILITY) {
        Some(error) if error.code == "unsupported" => "wifi.unsupported",
        _ => "wifi.failed",
    });
}

#[fission_reducer(RequestWifiAccess)]
pub fn request_wifi_access(
    state: &mut NetworkCheck, reason: String, ctx: &mut ReducerContext<NetworkCheck>,
) {
    if state.pending { return; }
    state.pending = true;
    state.issue = None;
    let ok = ctx.effects.bind(WifiAccessReceived, reduce_with!(wifi_access_received));
    let err = ctx.effects.bind(WifiAccessFailed, reduce_with!(wifi_access_failed));
    ctx.effects.wifi().request_permission(WifiPermissionRequest { reason: Some(reason) })
        .on_ok(ok).on_err(err);
}
#[fission_reducer(WifiAccessReceived)]
pub fn wifi_access_received(state: &mut NetworkCheck, ctx: &mut ReducerContext<NetworkCheck>) {
    state.pending = false;
    if ctx.input.capability_ok(REQUEST_WIFI_PERMISSION).is_none() {
        state.issue = Some("wifi.missing");
    } else {
        // Android may still be displaying its prompt. Do not treat this snapshot
        // as the user's eventual answer; Check Wi-Fi reads permission again.
        state.availability = None;
        state.issue = Some("wifi.recheck");
    }
}
#[fission_reducer(WifiAccessFailed)]
pub fn wifi_access_failed(state: &mut NetworkCheck, ctx: &mut ReducerContext<NetworkCheck>) {
    state.pending = false;
    state.issue = Some(match ctx.input.capability_error(REQUEST_WIFI_PERMISSION) {
        Some(error) if error.code == "unsupported" => "wifi.unsupported",
        _ => "wifi.failed",
    });
}

pub fn scan_wifi(state: &mut NetworkCheck, prefix: String, ctx: &mut ReducerContext<NetworkCheck>) {
    if !state.can_scan() || prefix.trim().is_empty() { return; }
    state.pending = true;
    state.issue = None;
    state.networks = None;
    let prefix = prefix.trim().to_owned();
    state.scan_prefix = Some(prefix.clone());
    let ok = ctx.effects.bind(WifiScanned, reduce_with!(wifi_scanned));
    let err = ctx.effects.bind(WifiScanFailed, reduce_with!(wifi_scan_failed));
    ctx.effects.wifi().scan_networks(WifiScanRequest {
        ssid_prefix: Some(prefix),
        include_hidden: false,
        timeout_ms: Some(5_000),
    }).on_ok(ok).on_err(err);
}
#[fission_reducer(WifiScanned)]
pub fn wifi_scanned(state: &mut NetworkCheck, ctx: &mut ReducerContext<NetworkCheck>) {
    state.pending = false;
    match ctx.input.capability_ok(SCAN_WIFI_NETWORKS) {
        Some(value) => state.networks = Some(value.networks),
        None => state.issue = Some("wifi.missing"),
    }
}
#[fission_reducer(WifiScanFailed)]
pub fn wifi_scan_failed(state: &mut NetworkCheck, ctx: &mut ReducerContext<NetworkCheck>) {
    state.pending = false;
    state.issue = Some(match ctx.input.capability_error(SCAN_WIFI_NETWORKS) {
        Some(error) if error.code == "unsupported" => "wifi.unsupported",
        Some(error) if error.code == "permission_denied" => {
            state.availability = None;
            "wifi.denied"
        }
        _ => "wifi.failed",
    });
}

#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn scanning_requires_enabled_wifi_and_a_confirmed_permission() {
        let mut state = NetworkCheck::default();
        assert!(!state.can_scan());
        state.availability = Some(WifiAvailability {
            enabled: true, permission: WifiPermission::Denied, connected_network: None,
        });
        assert!(!state.can_scan());
        state.availability.as_mut().unwrap().permission = WifiPermission::Granted;
        assert!(state.can_scan());
        state.pending = true;
        assert!(!state.can_scan());
    }
}

use fission::prelude::*;
use crate::state::*;

fission_component! {
    pub UploadNetworkScreen<NetworkCheck> {
        state { network_prefix: String = String::new() }
    }
    view(screen, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let request = with_reducer!(
            cx.build, RequestWifiAccess(cx.tr("wifi.reason")), request_wifi_access
        );
    } =>
    SafeArea(child: Scroll(child: Container(
        Column(gap: tokens.spacing.m, children: [
            Text(cx.tr("wifi.title")).size(tokens.typography.heading2_size),
            Text(cx.tr("wifi.context")),
            TextInput(
                label: Some(cx.tr("wifi.prefix").into()),
                helper_text: Some(cx.tr("wifi.prefix_help").into()),
                bind: screen.network_prefix,
                read_only: state.pending,
                semantics_identifier: "wifi.prefix".to_owned(),
            ),
            Button(
                child: Text(cx.tr("wifi.check")),
                key: "wifi.check", disabled: state.pending,
                on_press: reduce { check_wifi(state, cx); },
            ),
            Button(
                child: Text(cx.tr("wifi.request")),
                key: "wifi.request", disabled: state.pending,
                on_press: request,
            ),
            if let Some(value) = &state.availability {
                Column(gap: tokens.spacing.s, children: [
                    Text(cx.tr(if value.enabled { "wifi.enabled" } else { "wifi.disabled" })),
                    Text(cx.tr(if value.permission == WifiPermission::Granted {
                        "wifi.granted"
                    } else { "wifi.not_granted" })),
                ])
            },
            Button(
                child: Text(cx.tr("wifi.scan")),
                key: "wifi.scan",
                disabled: !state.can_scan() || screen.network_prefix.trim().is_empty(),
                on_press: reduce { scan_wifi(state, screen.network_prefix.clone(), cx); },
            ),
            if state.pending {
                Spinner(motion: Some(SpinnerMotion::Default), label: cx.tr("wifi.pending"))
            },
            if let Some(issue) = state.issue {
                Text(cx.tr(issue)).color(tokens.colors.text_secondary)
            },
            if let Some(networks) = &state.networks {
                Column(gap: tokens.spacing.s, children: [
                    if let Some(prefix) = &state.scan_prefix {
                        Text(format!("{}: {}", cx.tr("wifi.results_for"), prefix))
                    },
                    Text(format!("{} {}", cx.tr("wifi.returned"), networks.len())),
                    Text(cx.tr("wifi.cached")),
                ])
            },
            Text(cx.tr("wifi.boundary")),
        ])
    ).padding_all(tokens.spacing.l)))
}

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid checked-in translations");
        env.i18n.add_bundle(TranslationBundle { locale: Locale::from(locale), messages });
    }
    env
}

## Check the Android conditions separately

```sh
cargo test
fission doctor android --project-dir .
adb devices -l
fission run --target android --device <adb-serial> --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```

On a phone, check with Wi-Fi disabled, with access denied, and after changing permission in Settings. Complete the permission prompt before rechecking. Compare the expected prefix with Android Settings and repeat after waiting; Android can throttle scans, and cached results need not change immediately. An empty result must not erase the editable prefix or claim that no network exists.

The provider's permission predicate accepts nearby-device or location grants depending on Android version. That check is not a guarantee that every OS scanning prerequisite is satisfied: location settings and platform restrictions can still reject the operation. Keep the explicit failure path. Do not collect or log SSIDs and BSSIDs merely to debug the interface.

The Web preview exercises the form and its actual unsupported result; it cannot demonstrate native Wi-Fi discovery. Unit tests establish the app's gating rule, not Android's permission behaviour. Build, install, scan freshness and real-device behaviour require their own evidence.

## Separate the interface language from application content

Changing language should change the interface, not rewrite what the user entered. The distinction is easy to lose if a reducer stores a translated error message: that message stays in the old language after the rest of the screen changes.

Here, the selected locale belongs to `GlobalState`. A single shell callback mirrors it into `Env`, and components resolve message keys whilst building the current view. The second step adds a service-enquiry draft so we can check a long action label, a validation error and an empty state in both languages. Preparing the enquiry is a local review; this example does not claim to submit it.

## Create the project

Complete [Android SDK/NDK setup](/blog/set-up-rust-android-gui-development-with-fission/) and prepare [an emulator](/blog/create-and-launch-a-fission-android-emulator/) or [a phone](/blog/run-a-fission-app-on-a-physical-android-phone/).

```sh
fission init android-localise-a-fission-android-app
cd android-localise-a-fission-android-app
fission add-target android --project-dir .
cargo add serde_yaml
```

Keep the generated `src/main.rs`. Both native and Web entrypoints below install the same bundles and the same environment synchronisation. There is no second locale registry in the screen.

## Load both bundles and switch the active locale

Translation keys describe meaning, not location. For example, `enquiry.invalid` still makes sense if the form moves to another screen. Keep both bundles in checked-in files so changes can be reviewed and tested.

The language selector changes app state through a reducer. `with_sync_env` then updates the active locale for every component; widgets do not need their own language-switching logic.

```rust
use fission::prelude::*;

#[derive(Debug)]
pub struct EnquiryState {
    pub locale: Locale,
    pub prepared_subject: Option<String>,
}

impl Default for EnquiryState {
    fn default() -> Self {
        Self { locale: Locale::from("en-US"), prepared_subject: None }
    }
}
impl GlobalState for EnquiryState {}

impl EnquiryState {
    pub fn prepare(&mut self, subject: &str) -> bool {
        let subject = subject.trim();
        if subject.chars().count() < 5 { return false; }
        self.prepared_subject = Some(subject.to_owned());
        true
    }
}
```

```rust
use std::collections::HashMap;
use fission::prelude::*;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid checked-in translations");
        env.i18n.add_bundle(TranslationBundle { locale: Locale::from(locale), messages });
    }
    env
}

pub fn sync_env(state: &crate::state::EnquiryState, env: &mut Env) {
    env.locale = state.locale.clone();
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn checked_in_locales_have_the_same_keys_and_no_empty_messages() {
        let english: HashMap<String, String> =
            serde_yaml::from_str(include_str!("../i18n/en-US.yaml")).unwrap();
        let spanish: HashMap<String, String> =
            serde_yaml::from_str(include_str!("../i18n/es-ES.yaml")).unwrap();
        let mut english_keys: Vec<_> = english.keys().collect();
        let mut spanish_keys: Vec<_> = spanish.keys().collect();
        english_keys.sort();
        spanish_keys.sort();
        assert_eq!(english_keys, spanish_keys);
        assert!(english.values().chain(spanish.values()).all(|message| !message.trim().is_empty()));
    }

    #[test]
    fn switching_locale_changes_messages_without_changing_user_content() {
        let mut state = crate::state::EnquiryState::default();
        assert!(state.prepare("Repair the door handle"));
        let mut env = create_env();
        let english = env.tr("enquiry.title");
        state.locale = Locale::from("es-ES");
        sync_env(&state, &mut env);
        assert_ne!(english, env.tr("enquiry.title"));
        assert_eq!(state.prepared_subject.as_deref(), Some("Repair the door handle"));
    }
}
```

## Keep drafts intact whilst labels and errors change

The enquiry draft is retained local UI state. Preparing a valid subject puts it into shared state for review, but changing language does neither. Error state is represented by `attempted` and the current validation result, not by an English error string.

The Spanish action is deliberately longer. Let it take the space it needs; shortening every translation to match the English width hides the layout problem rather than solving it.

```rust
use fission::prelude::*;
use crate::state::EnquiryState;

fission_component! {
    pub EnquiryDraft<EnquiryState> {
        state {
            subject: String = String::new(),
            attempted: bool = false,
        }
    }
    view(draft, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let invalid = draft.attempted && draft.subject.trim().chars().count() < 5;
    } =>
    Column(gap: tokens.spacing.m, children: [
        TextInput(
            label: Some(cx.tr("enquiry.subject").into()),
            helper_text: Some(cx.tr("enquiry.subject_help").into()),
            error_text: if invalid { Some(cx.tr("enquiry.invalid").into()) } else { None },
            validation_message: if invalid { Some(cx.tr("enquiry.invalid")) } else { None },
            required: true,
            bind: draft.subject,
            semantics_identifier: "enquiry.subject".to_string(),
        ),
        Button(
            child: Text(cx.tr("enquiry.prepare")),
            key: "prepare-enquiry",
            on_press: reduce {
                draft.attempted = true;
                if state.prepare(&draft.subject) { draft.attempted = false; }
            },
        ).semantics_identifier("enquiry.prepare"),
        if let Some(subject) = &state.prepared_subject {
            Card(child: Column(gap: tokens.spacing.s, children: [
                Text(cx.tr("enquiry.prepared")).weight(tokens.typography.font_weight_semibold),
                Text(subject.clone()),
                Text(cx.tr("enquiry.not_sent")),
            ]))
        } else {
            EmptyState(
                title: cx.tr("enquiry.empty"),
                description: cx.tr("enquiry.empty_help"),
            )
        },
    ])
}
```

## Check real layouts and missing messages

```sh
cargo test
fission doctor android --project-dir .
fission run --target android --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```

Repeat the error and review flows on a narrow phone and a wider emulator window. Increase Android's text size and check that the form remains scrollable, the actions remain reachable and nothing essential is clipped. The Web preview cannot prove Android text scaling or TalkBack behaviour.

Fission's basic bundle registry looks up the exact locale and key. A missing message is rendered as its key; there is no automatic English fallback, plural-rule engine or translation of user-entered content in this example. Add tests and an explicit application policy when those requirements become relevant.

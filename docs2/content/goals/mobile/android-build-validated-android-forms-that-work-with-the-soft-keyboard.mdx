## Build a native seedling pickup request

A pickup request is only useful if the nursery can act on it. Meadowline Native Plants receives requests from local restoration crews. A useful request needs a contact name, a reply address, the seedling species, and the number of plants to prepare. If a quantity is missing or too large for one tray, staff should see what to fix before they plan the pickup.

In this tutorial, you will build that request form in shared Rust code. The form starts blank; enter details and check the draft to see field validation. The preview does not send a request or hold nursery stock. The Android steps show how to check the real software keyboard, focus order, and window resizing.

The distinction matters because a valid draft is not a reservation. The draft belongs to this form whilst the person is editing. A real accepted request becomes durable nursery data and should be sent to a service through an asynchronous effect. Keeping that boundary clear lets us learn the form behavior without pretending a browser-only example placed an order.

## Arrange the fields in the order a nursery needs them

Start with the information Meadowline uses to prepare a pickup. Name and email come first because staff need to know who is collecting the plants and how to reach them. Species and quantity follow because they determine which tray to prepare. The pickup note is optional and can hold a site name or an accessibility request.

The form opens blank, just as a new request should. Enter a few details and use **Clear form** if you want to discard the local draft. At this stage the form only reflects the values; validation comes next.

use fission::prelude::*;

fission_component! {
    pub SeedlingReservationForm<()> {
    state {
        customer_name: String = String::new(),
        reply_email: String = String::new(),
        species: String = String::new(),
        quantity: String = String::new(),
        pickup_note: String = String::new(),
    }
    }
    view(form, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    SemanticsRegion(
        identifier: Some("seedling-reservation-form".to_string()),
        label: Some(cx.tr("reservation.form.label")),
        child: SafeArea(child: Scroll(
            flex_grow: 1.0,
            height: cx.view.viewport_size().height,
            child: Container(
                Column(align_items: ir_op::AlignItems::Center, children: [
                    Container(
                        Column(gap: tokens.spacing.m, children: [
                            Column(gap: tokens.spacing.xs, children: [
                                Text(cx.tr("reservation.brand"))
                                    .weight(tokens.typography.font_weight_bold),
                                Text(cx.tr("reservation.subtitle"))
                                    .color(tokens.colors.text_secondary),
                            ]),
                            Text(cx.tr("reservation.pickup_site"))
                                .color(tokens.colors.text_secondary),
                            TextInput(
                                label: Some(cx.tr("reservation.customer_name").into()),
                                bind: form.customer_name,
                                required: true,
                                semantics_identifier: "reservation.customer-name".to_string(),
                            ),
                            TextInput(
                                label: Some(cx.tr("reservation.reply_email").into()),
                                bind: form.reply_email,
                                placeholder: Some(cx.tr("reservation.email_placeholder").into()),
                                required: true,
                                semantics_identifier: "reservation.reply-email".to_string(),
                            ),
                            TextInput(
                                label: Some(cx.tr("reservation.species").into()),
                                bind: form.species,
                                required: true,
                                semantics_identifier: "reservation.species".to_string(),
                            ),
                            TextInput(
                                label: Some(cx.tr("reservation.quantity").into()),
                                bind: form.quantity,
                                required: true,
                                semantics_identifier: "reservation.quantity".to_string(),
                            ),
                            TextInput(
                                label: Some(cx.tr("reservation.pickup_note").into()),
                                bind: form.pickup_note,
                                multiline: true,
                                semantics_identifier: "reservation.pickup-note".to_string(),
                            ),
                            Button(
                                child: Text(cx.tr("reservation.clear")),
                                key: "clear-form",
                                variant: ButtonVariant::Outline,
                                on_press: reduce {
                                    form.customer_name.clear();
                                    form.reply_email.clear();
                                    form.species.clear();
                                    form.quantity.clear();
                                    form.pickup_note.clear();
                                },
                            )
                            .semantics_identifier("reservation.clear".to_string()),
                            Text(cx.tr("reservation.not_sent"))
                                .color(tokens.colors.text_secondary),
                        ])
                    )
                    .padding_all(tokens.spacing.l)
                    .width_length(Length::clamp(
                        Length::points(0.0),
                        Length::percent(100.0),
                        Length::points(680.0),
                    ))
                    .bg(tokens.colors.surface)
                    .border(tokens.colors.border, 1.0)
                    .border_radius(tokens.radii.medium),
                ]),
            )
            .width_length(Length::percent(100.0))
            .bg(tokens.colors.background),
        )),
    )

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, yaml) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(yaml).expect("valid Meadowline translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

## Choose the right keyboard and validate each field

A name field benefits from name-aware capitalization; an email field should open an email keyboard; and the quantity field should request a numeric keyboard. Setting the return action to **Next** gives Android a useful way to move through the first fields. The final quantity field uses **Done**, while the optional pickup note allows a new line.

The reservation rules belong in one validation module so field errors, the summary and tests agree. `validate_fields` produces all field results from one pass; the form does not repeat a second set of validation predicates. This nursery accepts between one and twenty-four seedlings in a pickup tray. It also needs a non-empty customer name and species, plus an email address with a basic local-part and domain shape. That email check catches common typing mistakes; a production service still needs its own address verification.

Replace the earlier `src/app.rs` with this version. The error text is attached to the field that needs attention, and the result summary is derived from the current draft, so editing a value after a failed check does not leave a stale message on screen.

use fission::prelude::*;
use crate::validation::{validate_fields, ReservationError};

#[cfg(test)]
#[path = "app_tests.rs"]
mod app_tests;

fission_component! {
    pub SeedlingReservationForm<()> {
    state {
        customer_name: String = String::new(),
        reply_email: String = String::new(),
        species: String = String::new(),
        quantity: String = String::new(),
        pickup_note: String = String::new(),
        validation_requested: bool = false,
    }
    }
    view(form, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let validation = validate_fields(
            &form.customer_name,
            &form.reply_email,
            &form.species,
            &form.quantity,
        );
        let result = validation.result();
        let name_invalid = form.validation_requested && validation.name.is_some();
        let email_invalid = form.validation_requested && validation.email.is_some();
        let species_invalid = form.validation_requested && validation.species.is_some();
        let quantity_invalid = form.validation_requested && validation.quantity.is_err();
    } =>
    SemanticsRegion(
        identifier: Some("seedling-reservation-form".to_string()),
        label: Some(cx.tr("reservation.form.label")),
        child: SafeArea(child: Scroll(
            flex_grow: 1.0,
            height: cx.view.viewport_size().height,
            child: Container(
                Column(align_items: ir_op::AlignItems::Center, children: [
                    Container(
                        Column(gap: tokens.spacing.m, children: [
                            Column(gap: tokens.spacing.xs, children: [
                                Text(cx.tr("reservation.brand"))
                                    .weight(tokens.typography.font_weight_bold),
                                Text(cx.tr("reservation.subtitle"))
                                    .color(tokens.colors.text_secondary),
                            ]),
                            Text(cx.tr("reservation.pickup_site"))
                                .color(tokens.colors.text_secondary),
                            TextInput(
                                label: Some(cx.tr("reservation.customer_name").into()),
                                bind: form.customer_name,
                                required: true,
                                keyboard_type: TextInputType::Name,
                                text_input_action: TextInputAction::Next,
                                error_text: if name_invalid {
                                    Some(cx.tr("reservation.error.customer_name").into())
                                } else {
                                    None
                                },
                                validation_message: if name_invalid {
                                    Some(cx.tr("reservation.error.customer_name"))
                                } else {
                                    None
                                },
                                semantics_identifier: "reservation.customer-name".to_string(),
                            ),
                            TextInput(
                                label: Some(cx.tr("reservation.reply_email").into()),
                                bind: form.reply_email,
                                placeholder: Some(cx.tr("reservation.email_placeholder").into()),
                                required: true,
                                keyboard_type: TextInputType::EmailAddress,
                                text_input_action: TextInputAction::Next,
                                error_text: if email_invalid {
                                    Some(cx.tr("reservation.error.email").into())
                                } else {
                                    None
                                },
                                validation_message: if email_invalid {
                                    Some(cx.tr("reservation.error.email"))
                                } else {
                                    None
                                },
                                semantics_identifier: "reservation.reply-email".to_string(),
                            ),
                            TextInput(
                                label: Some(cx.tr("reservation.species").into()),
                                bind: form.species,
                                required: true,
                                text_input_action: TextInputAction::Next,
                                error_text: if species_invalid {
                                    Some(cx.tr("reservation.error.species").into())
                                } else {
                                    None
                                },
                                validation_message: if species_invalid {
                                    Some(cx.tr("reservation.error.species"))
                                } else {
                                    None
                                },
                                semantics_identifier: "reservation.species".to_string(),
                            ),
                            TextInput(
                                label: Some(cx.tr("reservation.quantity").into()),
                                bind: form.quantity,
                                required: true,
                                keyboard_type: TextInputType::Number,
                                text_input_action: TextInputAction::Done,
                                helper_text: Some(cx.tr("reservation.quantity_help").into()),
                                error_text: if quantity_invalid {
                                    Some(cx.tr(if validation.quantity == Err(ReservationError::QuantityOutOfRange) {
                                        "reservation.error.quantity_range"
                                    } else {
                                        "reservation.error.quantity_invalid"
                                    }).into())
                                } else {
                                    None
                                },
                                validation_message: if quantity_invalid {
                                    Some(cx.tr(if validation.quantity == Err(ReservationError::QuantityOutOfRange) {
                                        "reservation.error.quantity_range"
                                    } else {
                                        "reservation.error.quantity_invalid"
                                    }))
                                } else {
                                    None
                                },
                                semantics_identifier: "reservation.quantity".to_string(),
                            ),
                            TextInput(
                                label: Some(cx.tr("reservation.pickup_note").into()),
                                bind: form.pickup_note,
                                multiline: true,
                                text_input_action: TextInputAction::Newline,
                                helper_text: Some(cx.tr("reservation.pickup_note_help").into()),
                                semantics_identifier: "reservation.pickup-note".to_string(),
                            ),
                            Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                                Button(
                                    child: Text(cx.tr("reservation.check")),
                                    key: "check-pickup-request",
                                    variant: ButtonVariant::Primary,
                                    on_press: reduce { form.validation_requested = true; },
                                )
                                .semantics_identifier("reservation.check".to_string()),
                                Button(
                                    child: Text(cx.tr("reservation.clear")),
                                    key: "clear-form",
                                    variant: ButtonVariant::Outline,
                                    on_press: reduce {
                                        form.customer_name.clear();
                                        form.reply_email.clear();
                                        form.species.clear();
                                        form.quantity.clear();
                                        form.pickup_note.clear();
                                        form.validation_requested = false;
                                    },
                                )
                                .semantics_identifier("reservation.clear".to_string()),
                            ]),
                            if form.validation_requested {
                                match result {
                                    Ok(_) => Text(cx.tr("reservation.ready"))
                                    .color(tokens.colors.success),
                                    Err(error) => Text(cx.tr(error.translation_key()))
                                        .color(tokens.colors.error),
                                }
                            } else {
                                Text(cx.tr("reservation.not_sent"))
                                    .color(tokens.colors.text_secondary)
                            },
                        ])
                    )
                    .padding_all(tokens.spacing.l)
                    .width_length(Length::clamp(
                        Length::points(0.0),
                        Length::percent(100.0),
                        Length::points(680.0),
                    ))
                    .bg(tokens.colors.surface)
                    .border(tokens.colors.border, 1.0)
                    .border_radius(tokens.radii.medium),
                ]),
            )
            .width_length(Length::percent(100.0))
            .bg(tokens.colors.background),
        )),
    )
}

use crate::validation::{validate_fields, validate_reservation, ReservationError};

#[test]
fn accepts_a_complete_pickup_request() {
    assert_eq!(
        validate_reservation(
            "Maya Chen",
            "maya.chen@example.org",
            "Coast live oak",
            "12",
        ),
        Ok(12),
    );
}

#[test]
fn rejects_missing_contact_details_and_invalid_quantities() {
    assert_eq!(
        validate_reservation("", "maya.chen@example.org", "Coast live oak", "12"),
        Err(ReservationError::CustomerNameRequired),
    );
    assert_eq!(
        validate_reservation("Maya Chen", "maya@", "Coast live oak", "12"),
        Err(ReservationError::EmailInvalid),
    );
    assert_eq!(
        validate_reservation("Maya Chen", "maya.chen@example.org", "Coast live oak", "0"),
        Err(ReservationError::QuantityOutOfRange),
    );
    assert_eq!(
        validate_reservation("Maya Chen", "maya.chen@example.org", "Coast live oak", "25"),
        Err(ReservationError::QuantityOutOfRange),
    );
}

#[test]
fn field_errors_share_the_same_validation_result() {
    let fields = validate_fields("", "not-an-email", "", "1.5");
    assert_eq!(fields.name, Some(ReservationError::CustomerNameRequired));
    assert_eq!(fields.email, Some(ReservationError::EmailInvalid));
    assert_eq!(fields.species, Some(ReservationError::SpeciesRequired));
    assert_eq!(fields.quantity, Err(ReservationError::QuantityInvalid));
    assert_eq!(fields.result(), Err(ReservationError::CustomerNameRequired));
}

pub fn email_has_basic_shape(value: &str) -> bool {
    let value = value.trim();
    let Some((local, domain)) = value.split_once('@') else {
        return false;
    };

    !value.chars().any(char::is_whitespace)
        && !local.is_empty()
        && !domain.is_empty()
        && !domain.contains('@')
        && domain.contains('.')
        && !domain.starts_with('.')
        && !domain.ends_with('.')
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum ReservationError {
    CustomerNameRequired,
    EmailInvalid,
    SpeciesRequired,
    QuantityInvalid,
    QuantityOutOfRange,
}

impl ReservationError {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::CustomerNameRequired => "reservation.error.customer_name",
            Self::EmailInvalid => "reservation.error.email",
            Self::SpeciesRequired => "reservation.error.species",
            Self::QuantityInvalid => "reservation.error.quantity_invalid",
            Self::QuantityOutOfRange => "reservation.error.quantity_range",
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct ReservationValidation {
    pub name: Option<ReservationError>,
    pub email: Option<ReservationError>,
    pub species: Option<ReservationError>,
    pub quantity: Result<u32, ReservationError>,
}

impl ReservationValidation {
    pub fn result(self) -> Result<u32, ReservationError> {
        if let Some(error) = self.name.or(self.email).or(self.species) {
            return Err(error);
        }
        self.quantity
    }
}

pub fn validate_fields(
    customer_name: &str,
    reply_email: &str,
    species: &str,
    quantity: &str,
) -> ReservationValidation {
    ReservationValidation {
        name: customer_name.trim().is_empty().then_some(ReservationError::CustomerNameRequired),
        email: (!email_has_basic_shape(reply_email)).then_some(ReservationError::EmailInvalid),
        species: species.trim().is_empty().then_some(ReservationError::SpeciesRequired),
        quantity: quantity.trim().parse::<u32>()
            .map_err(|_| ReservationError::QuantityInvalid)
            .and_then(|quantity| {
                if (1..=24).contains(&quantity) { Ok(quantity) }
                else { Err(ReservationError::QuantityOutOfRange) }
            }),
    }
}

pub fn validate_reservation(
    customer_name: &str,
    reply_email: &str,
    species: &str,
    quantity: &str,
) -> Result<u32, ReservationError> {
    validate_fields(customer_name, reply_email, species, quantity).result()
}

## Check the form with the Android keyboard open

The browser lets you verify labels, validation, and the pickup summary. The soft keyboard belongs to the Android host, so check that part on an emulator or phone. Start with a narrow emulator: tap the customer name, use **Next** to move through email and species, then enter a quantity. Confirm that the focused field and **Check pickup request** remain reachable as the keyboard opens. Dismiss the keyboard and make sure the draft is still present.

Repeat the flow with a long species name and a multi-line pickup note. Rotate the emulator while a field is focused, then check that the text and selection are still usable. A keyboard closing is not a successful form submission; only the checked values and their field errors tell you whether the request is ready.

The sample has no inventory service, so **Check pickup request** validates a local draft. In a production reservation flow, dispatch the validated request through an asynchronous effect, show a pending state while the nursery service responds, and only then report that stock was actually held.

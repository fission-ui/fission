## Build a native seedling pickup request

Meadowline Native Plants receives requests from neighborhood restoration crews. A useful request needs a contact name, a reply address, the seedling species, and the number of plants to prepare. If a quantity is missing or too large for one tray, staff should see what to fix before they plan the pickup.

In this tutorial, you will build that request form in shared Rust code. The browser example opens with a sample draft so the result is easy to inspect; edit the fields and submit to see the form’s validation. The preview does not hold nursery stock. The Android steps show how to check the real software keyboard, focus order, and window resizing.

The draft belongs to this form while the person is editing. A real accepted request becomes durable nursery data and should be sent to a service through an asynchronous effect. Keeping that boundary clear lets us learn the form behavior without pretending a browser-only example placed an order.

## Arrange the fields in the order a nursery needs them

Start with the information Meadowline uses to prepare a pickup. Name and email come first because staff need to know who is collecting the plants and how to reach them. Species and quantity follow because they determine which tray to prepare. The pickup note is optional and can hold a site name or an accessibility request.

The preview begins with a sample draft from Maya Chen. Change any field, then choose **Review pickup request**. At this stage the form only reflects the values; validation comes next.

## Choose the right keyboard and validate each field

A name field benefits from name-aware capitalization; an email field should open an email keyboard; and the quantity field should request a numeric keyboard. Setting the return action to **Next** gives Android a useful way to move through the first fields. The final quantity field uses **Done**, while the optional pickup note allows a new line.

The reservation rules belong in one function so the form and its tests agree. This nursery accepts between one and twenty-four seedlings in a pickup tray. It also needs a non-empty customer name and species, plus an email address with a basic local-part and domain shape. That email check catches common typing mistakes; a production service still needs its own address verification.

Replace the earlier `src/app.rs` with this version. The error text is attached to the field that needs attention, and the result summary is derived from the current draft, so editing a value after a failed check does not leave a stale message on screen.

```rust
use fission::prelude::*;

#[cfg(test)]
#[path = "app_tests.rs"]
mod app_tests;

pub fn email_has_basic_shape(value: &str) -> bool {
    let value = value.trim();
    let Some((local, domain)) = value.split_once('@') else {
        return false;
    };

    !value.chars().any(char::is_whitespace)
        && !local.is_empty()
        && !domain.is_empty()
        && !domain.contains('@')
        && domain.contains('.')
        && !domain.starts_with('.')
        && !domain.ends_with('.')
}

pub fn validate_reservation(
    customer_name: &str,
    reply_email: &str,
    species: &str,
    quantity: &str,
) -> Result<u32, &'static str> {
    if customer_name.trim().is_empty() {
        return Err("Enter the name staff should use for this pickup.");
    }
    if !email_has_basic_shape(reply_email) {
        return Err("Enter an email with a name and a complete domain.");
    }
    if species.trim().is_empty() {
        return Err("Enter the species the nursery should prepare.");
    }

    let quantity = quantity
        .trim()
        .parse::<u32>()
        .map_err(|_| "Enter a whole number from 1 to 24.")?;
    if !(1..=24).contains(&quantity) {
        return Err("A pickup tray holds between 1 and 24 seedlings.");
    }

    Ok(quantity)
}

fission_component! {
    pub SeedlingReservationForm<()> {
    state {
        customer_name: String = "Maya Chen".to_string(),
        reply_email: String = "maya.chen@example.org".to_string(),
        species: String = "Coast live oak".to_string(),
        quantity: String = "12".to_string(),
        pickup_note: String = "Cedar Point restoration site".to_string(),
        reviewed: bool = false,
    }
    }
    view(form, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let result = validate_reservation(
            &form.customer_name,
            &form.reply_email,
            &form.species,
            &form.quantity,
        );
        let name_invalid = form.reviewed && form.customer_name.trim().is_empty();
        let email_invalid = form.reviewed && !email_has_basic_shape(&form.reply_email);
        let species_invalid = form.reviewed && form.species.trim().is_empty();
        let quantity_value = form.quantity.trim().parse::<u32>().ok();
        let quantity_invalid = form.reviewed && !matches!(quantity_value, Some(1..=24));
    } =>
    SemanticsRegion(
        identifier: Some("seedling-reservation-form".to_string()),
        label: Some("Meadowline Native Plants pickup request".to_string()),
        child: Scroll(
            flex_grow: 1.0,
            height: cx.view.viewport_size().height,
            child: Container(
                Column(align_items: ir_op::AlignItems::Center, children: [
                    Container(
                        Column(gap: tokens.spacing.m, children: [
                            Column(gap: tokens.spacing.xs, children: [
                                Text("Meadowline Native Plants")
                                    .weight(tokens.typography.font_weight_bold),
                                Text("Community restoration pickup request")
                                    .color(tokens.colors.text_secondary),
                            ]),
                            Text("Pickup site · Cedar Point Nursery")
                                .color(tokens.colors.text_secondary),
                            TextInput(
                                label: Some("Customer name".into()),
                                bind: form.customer_name,
                                required: true,
                                keyboard_type: TextInputType::Name,
                                text_input_action: TextInputAction::Next,
                                error_text: if name_invalid {
                                    Some("Enter the name staff should use for this pickup.".into())
                                } else {
                                    None
                                },
                                semantics_identifier: "reservation.customer-name".to_string(),
                            ),
                            TextInput(
                                label: Some("Reply email".into()),
                                bind: form.reply_email,
                                placeholder: Some("name@example.org".into()),
                                required: true,
                                keyboard_type: TextInputType::EmailAddress,
                                text_input_action: TextInputAction::Next,
                                error_text: if email_invalid {
                                    Some("Enter an email with a name and a complete domain.".into())
                                } else {
                                    None
                                },
                                semantics_identifier: "reservation.reply-email".to_string(),
                            ),
                            TextInput(
                                label: Some("Seedling species".into()),
                                bind: form.species,
                                required: true,
                                text_input_action: TextInputAction::Next,
                                error_text: if species_invalid {
                                    Some("Enter the species the nursery should prepare.".into())
                                } else {
                                    None
                                },
                                semantics_identifier: "reservation.species".to_string(),
                            ),
                            TextInput(
                                label: Some("Number of seedlings".into()),
                                bind: form.quantity,
                                required: true,
                                keyboard_type: TextInputType::Number,
                                text_input_action: TextInputAction::Done,
                                helper_text: Some("One pickup tray holds 1 to 24 seedlings.".into()),
                                error_text: if quantity_invalid {
                                    Some("Enter a whole number from 1 to 24.".into())
                                } else {
                                    None
                                },
                                semantics_identifier: "reservation.quantity".to_string(),
                            ),
                            TextInput(
                                label: Some("Pickup note (optional)".into()),
                                bind: form.pickup_note,
                                multiline: true,
                                text_input_action: TextInputAction::Newline,
                                helper_text: Some("For example, the restoration site or an access note.".into()),
                                semantics_identifier: "reservation.pickup-note".to_string(),
                            ),
                            Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                                Button(
                                    child: Text("Check pickup request"),
                                    key: "check-pickup-request",
                                    variant: ButtonVariant::Primary,
                                    on_press: reduce { form.reviewed = true; },
                                )
                                .semantics_identifier("reservation.check".to_string()),
                                Button(
                                    child: Text("Restore sample draft"),
                                    key: "restore-sample-draft",
                                    variant: ButtonVariant::Outline,
                                    on_press: reduce {
                                        form.customer_name = "Maya Chen".to_string();
                                        form.reply_email = "maya.chen@example.org".to_string();
                                        form.species = "Coast live oak".to_string();
                                        form.quantity = "12".to_string();
                                        form.pickup_note = "Cedar Point restoration site".to_string();
                                        form.reviewed = false;
                                    },
                                ),
                            ]),
                            if form.reviewed {
                                match result {
                                    Ok(quantity) => Text(format!(
                                        "Pickup request looks complete: {} {} seedlings for {}.",
                                        quantity,
                                        form.species.trim(),
                                        form.customer_name.trim(),
                                    ))
                                    .color(tokens.colors.success),
                                    Err(message) => Text(message.to_string())
                                        .color(tokens.colors.error),
                                }
                            } else {
                                Text("The sample draft is local to this screen until you send it to a service.")
                                    .color(tokens.colors.text_secondary)
                            },
                        ])
                    )
                    .padding_all(tokens.spacing.l)
                    .width_length(Length::clamp(
                        Length::points(0.0),
                        Length::percent(100.0),
                        Length::points(680.0),
                    ))
                    .bg(tokens.colors.surface)
                    .border(tokens.colors.border, 1.0)
                    .border_radius(tokens.radii.medium),
                ]),
            )
            .width_length(Length::percent(100.0))
            .bg(tokens.colors.background),
        ),
    )
}
```

```rust
use super::*;

#[test]
fn accepts_a_complete_pickup_request() {
    assert_eq!(
        validate_reservation(
            "Maya Chen",
            "maya.chen@example.org",
            "Coast live oak",
            "12",
        ),
        Ok(12),
    );
}

#[test]
fn rejects_missing_contact_details_and_invalid_quantities() {
    assert_eq!(
        validate_reservation("", "maya.chen@example.org", "Coast live oak", "12"),
        Err("Enter the name staff should use for this pickup."),
    );
    assert_eq!(
        validate_reservation("Maya Chen", "maya@", "Coast live oak", "12"),
        Err("Enter an email with a name and a complete domain."),
    );
    assert_eq!(
        validate_reservation("Maya Chen", "maya.chen@example.org", "Coast live oak", "0"),
        Err("A pickup tray holds between 1 and 24 seedlings."),
    );
    assert_eq!(
        validate_reservation("Maya Chen", "maya.chen@example.org", "Coast live oak", "25"),
        Err("A pickup tray holds between 1 and 24 seedlings."),
    );
}
```

## Check the form with the Android keyboard open

The browser lets you verify labels, validation, and the pickup summary. The soft keyboard belongs to the Android host, so check that part on an emulator or phone. Start with a narrow emulator: tap the customer name, use **Next** to move through email and species, then enter a quantity. Confirm that the focused field and **Check pickup request** remain reachable as the keyboard opens. Dismiss the keyboard and make sure the draft is still present.

Repeat the flow with a long species name and a multi-line pickup note. Rotate the emulator while a field is focused, then check that the text and selection are still usable. A keyboard closing is not a successful form submission; only the checked values and their field errors tell you whether the request is ready.

The sample has no inventory service, so **Check pickup request** validates a local draft. In a production reservation flow, dispatch the validated request through an asynchronous effect, show a pending state while the nursery service responds, and only then report that stock was actually held.

A shelf label identifies a product; it does not tell us how many units are physically there. Likewise, entering a count should not silently overwrite the system quantity before somebody has reviewed the difference.

We will create a real count sheet from user input, lock its baseline, select products by scanning or manual entry, and stage physical counts with optional actual photo evidence. For example, enter a tarp with baseline 18, then stage 17. The proposal is −1 whilst the baseline remains 18. Neither the native app nor the browser depends on a preview-only stock fixture.

## Keep baseline, proposal and evidence distinct

The sheet accepts up to fifty unique SKUs, with an explicit ASCII case-insensitive identifier policy. Quantities are whole units from zero to 100000. Once counting starts, the baseline cannot be edited through this workflow. A real service integration should load and version the authoritative sheet rather than trust user input as server stock.

Scanning and manual entry use the same selection rule. Neither changes quantities. A selected product gets its own keyed count panel, so another product does not inherit the previous product's unsubmitted draft. The proposed count belongs to the record and survives closing that panel.

The photo request snapshots the selected SKU. Its job consumes actual image bytes before attaching them to that product. Replacements preserve the previous image on failure, and the whole sheet has a sixteen-MiB photo budget in addition to the job's per-image bound.

use fission::core::{CameraCapture, JobCtx, JobRef, JobSpec};
use serde::{Deserialize, Serialize};

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct PhotoRequest {
    pub reference: String,
    pub capture: CameraCapture,
}
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize)]
pub struct ShelfPhoto {
    pub reference: String,
    pub bytes: Vec<u8>,
    pub content_type: String,
}
pub struct CollectPhoto;
impl JobSpec for CollectPhoto {
    type Request = PhotoRequest;
    type Ok = ShelfPhoto;
    type Err = String;
    const NAME: &'static str = "inventory.collect-photo";
}
pub const COLLECT_PHOTO: JobRef<CollectPhoto> = JobRef::new(CollectPhoto::NAME);

pub async fn collect_photo(request: PhotoRequest, cx: JobCtx) -> Result<ShelfPhoto, String> {
    let mut stream = cx
        .open_data_stream(request.capture.stream)
        .map_err(|error| error.to_string())?;
    // Consume the one-shot handle even when its metadata fails these bounds.
    let pixels = u64::from(request.capture.width) * u64::from(request.capture.height);
    if pixels == 0 || pixels > 16_000_000 {
        return Err("Unsupported image dimensions".into());
    }
    if !matches!(
        request.capture.content_type.as_str(),
        "image/jpeg" | "image/png"
    ) {
        return Err("Only JPEG and PNG arrival photos are accepted".into());
    }
    let mut bytes = Vec::new();
    while let Some(chunk) = std::future::poll_fn(|cx| stream.as_mut().poll_next(cx)).await {
        let chunk = chunk.map_err(|error| error.to_string())?;
        let length = bytes
            .len()
            .checked_add(chunk.len())
            .ok_or("Image is too large")?;
        if length > 8 * 1024 * 1024 {
            return Err("Image exceeds the eight-MiB limit".into());
        }
        bytes.extend_from_slice(&chunk);
    }
    if bytes.is_empty() {
        return Err("The camera returned an empty image".into());
    }
    Ok(ShelfPhoto {
        reference: request.reference,
        bytes,
        content_type: request.capture.content_type,
    })
}

use super::jobs::{PhotoRequest, ShelfPhoto, COLLECT_PHOTO};
use fission::prelude::*;

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct Product {
    pub sku: String,
    pub name: String,
    pub bin: String,
    pub baseline: u32,
    pub proposed: Option<u32>,
    pub photo: Option<ShelfPhoto>,
}
#[derive(Clone, Debug, PartialEq, Eq)]
pub struct InventoryState {
    pub locale: Locale,
    pub products: Vec<Product>,
    pub locked: bool,
    pub selected: Option<String>,
    pub busy: bool,
    pub capture_sku: Option<String>,
    pub status_key: String,
    pub diagnostic: Option<String>,
}
impl Default for InventoryState {
    fn default() -> Self {
        Self {
            locale: Locale::from("en-US"),
            products: Vec::new(),
            locked: false,
            selected: None,
            busy: false,
            capture_sku: None,
            status_key: "inventory.ready".into(),
            diagnostic: None,
        }
    }
}
impl GlobalState for InventoryState {}

pub fn units(input: &str) -> Option<u32> {
    let input = input.trim();
    if input.is_empty() || !input.bytes().all(|byte| byte.is_ascii_digit()) {
        return None;
    }
    input.parse::<u32>().ok().filter(|value| *value <= 100_000)
}
pub fn normalized_sku(input: &str) -> Option<String> {
    let input = input.trim();
    if input.is_empty()
        || input.len() > 48
        || !input
            .bytes()
            .all(|byte| byte.is_ascii_alphanumeric() || b"-_.".contains(&byte))
    {
        return None;
    }
    Some(input.to_ascii_uppercase())
}
pub fn add_product(
    state: &mut InventoryState,
    sku: &str,
    name: &str,
    bin: &str,
    quantity: &str,
) -> bool {
    if state.locked || state.products.len() >= 50 {
        return false;
    }
    let (Some(sku), Some(baseline)) = (normalized_sku(sku), units(quantity)) else {
        return false;
    };
    if name.trim().is_empty()
        || bin.trim().is_empty()
        || state.products.iter().any(|product| product.sku == sku)
    {
        return false;
    }
    state.products.push(Product {
        sku,
        name: name.trim().to_owned(),
        bin: bin.trim().to_owned(),
        baseline,
        proposed: None,
        photo: None,
    });
    true
}
pub fn select_product(state: &mut InventoryState, input: &str) {
    if state.busy || !state.locked {
        return;
    }
    state.diagnostic = None;
    let sku = normalized_sku(input);
    if let Some(product) = state
        .products
        .iter()
        .find(|product| Some(&product.sku) == sku.as_ref())
    {
        state.selected = Some(product.sku.clone());
        state.status_key = "inventory.selected".into();
    } else {
        state.status_key = "inventory.unknown_sku".into();
    }
}
pub fn stage_count(state: &mut InventoryState, sku: &str, input: &str) -> bool {
    if state.busy || !state.locked {
        return false;
    }
    let Some(count) = units(input) else {
        return false;
    };
    let Some(product) = state.products.iter_mut().find(|product| product.sku == sku) else {
        return false;
    };
    product.proposed = Some(count);
    state.status_key = "inventory.staged".into();
    true
}

pub fn scan(state: &mut InventoryState, cx: &mut ReducerContext<InventoryState>) {
    if state.busy || !state.locked {
        return;
    }
    state.busy = true;
    state.diagnostic = None;
    state.status_key = "inventory.scan_pending".into();
    let ok = cx.effects.bind(SkuScanned, reduce_with!(sku_scanned));
    let err = cx.effects.bind(ScanFailed, reduce_with!(scan_failed));
    cx.effects
        .barcode_scanner()
        .scan(BarcodeScanRequest {
            formats: vec![BarcodeFormat::Code128, BarcodeFormat::QrCode],
            allow_multiple: false,
            prompt: None,
            timeout_ms: Some(20_000),
            ..Default::default()
        })
        .on_ok(ok)
        .on_err(err);
}
#[fission_reducer(SkuScanned)]
fn sku_scanned(state: &mut InventoryState, cx: &mut ReducerContext<InventoryState>) {
    state.busy = false;
    let Some(results) = cx.input.capability_ok(SCAN_BARCODE) else {
        state.status_key = "inventory.unexpected".into();
        return;
    };
    match results.items.first() {
        Some(result) => select_product(state, &result.value),
        None => state.status_key = "inventory.no_code".into(),
    }
}
#[fission_reducer(ScanFailed)]
fn scan_failed(state: &mut InventoryState, cx: &mut ReducerContext<InventoryState>) {
    state.busy = false;
    match cx.input.capability_error(SCAN_BARCODE) {
        Some(error) => {
            state.status_key = "inventory.scan_failed".into();
            state.diagnostic = Some(format!("{}: {}", error.code, error.message));
        }
        None => state.status_key = "inventory.unexpected".into(),
    }
}

pub fn capture_photo(
    state: &mut InventoryState,
    sku: &str,
    cx: &mut ReducerContext<InventoryState>,
) {
    if state.busy {
        return;
    }
    if !state.products.iter().any(|product| product.sku == sku) {
        return;
    }
    state.capture_sku = Some(sku.to_owned());
    state.busy = true;
    state.diagnostic = None;
    state.status_key = "inventory.permission_pending".into();
    let ok = cx
        .effects
        .bind(PermissionReturned, reduce_with!(permission_returned));
    let err = cx.effects.bind(CameraFailed, reduce_with!(camera_failed));
    cx.effects
        .camera()
        .request_permission(CameraPermissionRequest { reason: None })
        .on_ok(ok)
        .on_err(err);
}
#[fission_reducer(PermissionReturned)]
fn permission_returned(state: &mut InventoryState, cx: &mut ReducerContext<InventoryState>) {
    match cx.input.capability_ok(REQUEST_CAMERA_PERMISSION) {
        Some(CameraPermission::Granted) => {
            state.status_key = "inventory.photo_pending".into();
            let ok = cx.effects.bind(PhotoCaptured, reduce_with!(photo_captured));
            let err = cx.effects.bind(CameraFailed, reduce_with!(camera_failed));
            cx.effects
                .camera()
                .capture_photo(CameraCaptureRequest {
                    camera_id: None,
                    facing: CameraFacing::Back,
                    resolution: Some(CameraResolution {
                        width: 1600,
                        height: 1200,
                    }),
                    format: CameraImageFormat::Jpeg,
                    flash: CameraFlashMode::Off,
                    quality: Some(85),
                })
                .on_ok(ok)
                .on_err(err);
        }
        Some(
            CameraPermission::Denied | CameraPermission::Restricted | CameraPermission::Unknown,
        ) => {
            state.busy = false;
            state.capture_sku = None;
            state.status_key = "inventory.denied".into();
        }
        None => {
            state.busy = false;
            state.capture_sku = None;
            state.status_key = "inventory.unexpected".into();
        }
    }
}
#[fission_reducer(PhotoCaptured)]
fn photo_captured(state: &mut InventoryState, cx: &mut ReducerContext<InventoryState>) {
    let capture = cx.input.capability_ok(CAPTURE_PHOTO);
    let sku = state.capture_sku.take();
    let (Some(capture), Some(reference)) = (capture, sku) else {
        state.busy = false;
        state.status_key = "inventory.unexpected".into();
        return;
    };
    state.status_key = "inventory.image_pending".into();
    let ok = cx
        .effects
        .bind(PhotoCollected, reduce_with!(photo_collected));
    let err = cx.effects.bind(PhotoFailed, reduce_with!(photo_failed));
    cx.effects
        .app(COLLECT_PHOTO, PhotoRequest { reference, capture })
        .on_ok(ok)
        .on_err(err);
}
#[fission_reducer(PhotoCollected)]
fn photo_collected(state: &mut InventoryState, cx: &mut ReducerContext<InventoryState>) {
    state.busy = false;
    let Some(photo) = cx.input.job_ok(COLLECT_PHOTO) else {
        state.status_key = "inventory.unexpected".into();
        return;
    };
    let existing_bytes: usize = state
        .products
        .iter()
        .filter(|product| product.sku != photo.reference)
        .filter_map(|product| product.photo.as_ref())
        .map(|photo| photo.bytes.len())
        .sum();
    if existing_bytes + photo.bytes.len() > 16 * 1024 * 1024 {
        state.status_key = "inventory.photo_budget".into();
        return;
    }
    let Some(product) = state
        .products
        .iter_mut()
        .find(|product| product.sku == photo.reference)
    else {
        state.status_key = "inventory.unexpected".into();
        return;
    };
    product.photo = Some(photo);
    state.status_key = "inventory.photo_attached".into();
}
#[fission_reducer(PhotoFailed)]
fn photo_failed(state: &mut InventoryState, cx: &mut ReducerContext<InventoryState>) {
    state.busy = false;
    state.status_key = "inventory.photo_failed".into();
    state.diagnostic = cx.input.job_err(COLLECT_PHOTO);
    if state.diagnostic.is_none() {
        state.status_key = "inventory.unexpected".into();
    }
}
#[fission_reducer(CameraFailed)]
fn camera_failed(state: &mut InventoryState, cx: &mut ReducerContext<InventoryState>) {
    state.busy = false;
    state.capture_sku = None;
    let error = cx
        .input
        .capability_error(REQUEST_CAMERA_PERMISSION)
        .or_else(|| cx.input.capability_error(CAPTURE_PHOTO));
    match error {
        Some(error) => {
            state.status_key = "inventory.photo_failed".into();
            state.diagnostic = Some(format!("{}: {}", error.code, error.message));
        }
        None => state.status_key = "inventory.unexpected".into(),
    }
}

use super::state::{add_product, normalized_sku, units, InventoryState};
use fission::prelude::*;

fission_component! {
    pub SheetSetup<InventoryState> {
        state {
            sku: String = String::new(),
            name: String = String::new(),
            bin: String = String::new(),
            baseline: String = String::new(),
            attempted: bool = false,
        }
    }
    view(form, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let sku_error = (form.attempted && (normalized_sku(&form.sku).is_none()
            || state.products.iter().any(|product| Some(product.sku.clone()) == normalized_sku(&form.sku))))
            .then(|| cx.tr("inventory.sku_error"));
        let name_error = (form.attempted && form.name.trim().is_empty()).then(|| cx.tr("inventory.required"));
        let bin_error = (form.attempted && form.bin.trim().is_empty()).then(|| cx.tr("inventory.required"));
        let count_error = (form.attempted && units(&form.baseline).is_none()).then(|| cx.tr("inventory.units_error"));
    } => Column(gap: tokens.spacing.s, children: [
        Text(cx.tr("inventory.setup")),
        FormControl(label: Some(cx.tr("inventory.sku")), required: true, error: sku_error,
            child: TextInput(value: form.sku.clone(), bind(on_input): to(form.sku))),
        FormControl(label: Some(cx.tr("inventory.name")), required: true, error: name_error,
            child: TextInput(value: form.name.clone(), bind(on_input): to(form.name))),
        FormControl(label: Some(cx.tr("inventory.bin")), required: true, error: bin_error,
            child: TextInput(value: form.bin.clone(), bind(on_input): to(form.bin))),
        FormControl(label: Some(cx.tr("inventory.baseline")), required: true, error: count_error,
            child: TextInput(value: form.baseline.clone(), bind(on_input): to(form.baseline),
                keyboard_type: TextInputType::Number)),
        Button(child: Text(cx.tr("inventory.add")), key: "add-product", disabled: state.products.len() >= 50,
            on_press: reduce {
                form.attempted = true;
                if add_product(state, &form.sku, &form.name, &form.bin, &form.baseline) {
                    form.sku.clear(); form.name.clear(); form.bin.clear(); form.baseline.clear();
                    form.attempted = false;
                }
            }),
        Button(child: Text(cx.tr("inventory.lock")), key: "lock-sheet", disabled: state.products.is_empty(),
            on_press: reduce { state.locked = true; }),
    ])
}

use super::state::{capture_photo, select_product, stage_count, units, InventoryState};

                .weight(tokens.typography.font_weight_semibold),

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid voice note translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

pub fn sync_env(state: &crate::app::InventoryState, env: &mut Env) {
    env.locale = state.locale.clone();
}

<!-- fission:step id="verify-mobile-hosts" -->
## Verify scanning and camera recovery without weakening the count rule

The normal browser provider may return a real camera image or an unsupported scan result; this app does not hide those results behind a fake “native capabilities available” flag. Manual SKU entry and product buttons remain useful recovery paths.

On iOS, the current barcode provider captures a still image and decodes it; it does not open a live scanner viewfinder. Its camera failures are wrapped as `camera_error`, and its scan cancellation/timeout support is currently limited. Do not promise distinct native cancellation or timeout behaviour which the provider has not implemented. The error diagnostic records the actual result whilst the count remains usable.

Run each native target with its configured toolchain:

```sh
cargo test --lib
fission doctor android --project-dir .
fission run --target android --project-dir .
fission test --target android --project-dir .
fission doctor ios --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
```

Use [an Android phone](/blog/run-a-fission-app-on-a-physical-android-phone/) and [a signed iPhone build](/blog/install-a-fission-app-on-a-physical-iphone/) for real labels and camera evidence. Test an expected label, an unknown SKU, denial, unavailable hardware, a failed photo replacement and switching between products. The source tests prove only the count rule; a simulator launch proves neither scanner accuracy nor a physical photograph.

Inspect the actual image, not just its dimensions. A stored one-shot stream handle would not be evidence available to the user. The snapshot here remains session-local; committing a stock adjustment or uploading evidence needs an authenticated, authorized service flow and its confirmed completion.

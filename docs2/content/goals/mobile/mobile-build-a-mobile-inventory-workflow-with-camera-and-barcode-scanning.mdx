At Cedar Ridge Outfitters, the closing team checks the shelves in aisle C before the weekly stock report is sent. The inventory system says there are **18 Trail tarps** in bin **C-12**. A staff member scans the shelf label, counts the units by hand, and finds 17. They attach a quick shelf photo so the morning manager can investigate the missing tarp.

Keep the count staged: **17 does not overwrite 18**. The app records the proposed count and its difference for the stock-review service. Staff can enter a blurry label manually, a camera denial does not block the count, and an unknown SKU cannot change another product’s quantity.

The browser preview does not pretend to scan a label or take a shelf photo. Use the manual SKU field there to select a real item from the count sheet, enter the quantity you found, and stage the difference. In the Android and iOS app, the same screen adds the native scanner and camera actions. Those actions go through Fission capabilities, so the operating system can ask for permission and return an actual result.

## Create the shared mobile project

Add both mobile targets and declare the camera and barcode capabilities. Live scanning uses camera access, so the CLI updates the native configuration needed by each target:

## Scan a product and stage its count

The app uses an inventory sheet containing the product’s current system quantity. Scanning chooses a row; it does not change stock. When a camera is unavailable, the employee can choose **Count this item** or enter the SKU from its label. After selecting a product, they type the physical count and stage the difference. Keeping those actions separate prevents a camera result from silently changing an inventory record.

Open the tabs in order. First, define the product and staged-evidence state. Then follow the reducers that request a scan, ask for camera permission, and record the results. The final tabs show the screen component and the memory providers that make the browser example interactive.

use fission::prelude::*;

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct PhotoEvidence {
    pub stream: DataStreamId,
    pub byte_len: Option<u64>,
    pub content_type: String,
    pub width: u32,
    pub height: u32,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct InventoryProduct {
    pub sku: String,
    pub name: String,
    pub bin: String,
    pub on_hand: u32,
    pub physical_count: Option<u32>,
    pub evidence: Option<PhotoEvidence>,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct InventoryFeedback {
    key: &'static str,
    values: Vec<(&'static str, String)>,
}

impl InventoryFeedback {
    pub fn new(key: &'static str) -> Self {
        Self { key, values: Vec::new() }
    }

    pub fn with(mut self, name: &'static str, value: impl ToString) -> Self {
        self.values.push((name, value.to_string()));
        self
    }

    pub fn resolve(&self, mut translate: impl FnMut(&str) -> String) -> String {
        let mut message = translate(self.key);
        for (name, value) in &self.values {
            message = message.replace(&format!("{{{name}}}"), value);
        }
        message
    }
}

#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct InventoryState {
    pub products: Vec<InventoryProduct>,
    pub selected_sku: Option<String>,
    pub native_capabilities_available: bool,
    pub scan_busy: bool,
    pub camera_busy: bool,
    pub message: Option<InventoryFeedback>,
    pub error: Option<InventoryFeedback>,
}

impl GlobalState for InventoryState {}

#[fission_reducer(SelectInventoryProduct)]
pub fn on_select_inventory_product(state: &mut InventoryState, sku: String) {
    if state.scan_busy || state.camera_busy {
        return;
    }

    let sku = sku.trim().to_ascii_uppercase();
    let Some((name, bin, on_hand)) = state
        .products
        .iter()
        .find(|product| product.sku == sku)
        .map(|product| (product.name.clone(), product.bin.clone(), product.on_hand))
    else {
        state.error = Some(
            InventoryFeedback::new("inventory.error.unknown_sku")
                .with("sku", &sku),
        );
        state.message = None;
        return;
    };

    state.selected_sku = Some(sku);
    state.error = None;
    state.message = Some(
        InventoryFeedback::new("inventory.message.product_selected")
            .with("name", name)
            .with("bin", bin)
            .with("on_hand", on_hand),
    );
}

#[fission_reducer(ScanShelfLabel)]
pub fn on_scan_shelf_label(
    state: &mut InventoryState,
    prompt: String,
    ctx: &mut ReducerContext<InventoryState>,
) {
    if state.scan_busy || state.camera_busy || state.selected_sku.is_some() {
        return;
    }

    state.scan_busy = true;
    state.error = None;
    state.message = Some(InventoryFeedback::new("inventory.message.scanner_opening"));

    let on_ok = ctx.effects.bind(
        InventorySkuRead,
        reduce_with!(on_inventory_sku_read),
    );
    let on_err = ctx.effects.bind(
        InventoryScanFailed,
        reduce_with!(on_inventory_scan_failed),
    );

    ctx.effects
        .barcode_scanner()
        .scan(BarcodeScanRequest {
            formats: vec![BarcodeFormat::Code128, BarcodeFormat::QrCode],
            prompt: Some(prompt),
            timeout_ms: Some(20_000),
            allow_multiple: false,
            ..Default::default()
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(InventorySkuRead)]
pub fn on_inventory_sku_read(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    state.scan_busy = false;
    let Some(results) = ctx.input.capability_ok(SCAN_BARCODE) else {
        state.message = None;
        state.error = Some(InventoryFeedback::new("inventory.error.scanner_no_code"));
        return;
    };
    let Some(result) = results.items.first() else {
        state.message = None;
        state.error = Some(InventoryFeedback::new("inventory.error.scanner_no_read"));
        return;
    };

    let sku = result.value.trim().to_ascii_uppercase();
    if let Some(product) = state.products.iter().find(|product| product.sku == sku) {
        state.selected_sku = Some(sku.clone());
        state.error = None;
        state.message = Some(
            InventoryFeedback::new("inventory.message.scanned_product_selected")
                .with("name", &product.name)
                .with("bin", &product.bin)
                .with("on_hand", product.on_hand),
        );
    } else {
        state.message = None;
        state.error = Some(
            InventoryFeedback::new("inventory.error.unknown_sku_review")
                .with("sku", sku),
        );
    }
}

#[fission_reducer(InventoryScanFailed)]
pub fn on_inventory_scan_failed(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    state.scan_busy = false;
    state.message = None;
    let Some(error) = ctx.input.capability_error(SCAN_BARCODE) else {
        state.error = Some(InventoryFeedback::new("inventory.error.scanner_stopped"));
        return;
    };

    state.error = Some(match error.code.as_str() {
        "cancelled" | "canceled" | "user_cancel" => InventoryFeedback::new("inventory.error.scan_cancelled"),
        "permission_denied" => InventoryFeedback::new("inventory.error.scan_permission_denied"),
        "unsupported" | "unavailable" => InventoryFeedback::new("inventory.error.scan_unavailable"),
        "timeout" => InventoryFeedback::new("inventory.error.scan_timeout"),
        _ => InventoryFeedback::new("inventory.error.scan_failed"),
    });
}

fn queue_shelf_photo_capture(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    state.camera_busy = true;
    state.error = None;
    state.message = Some(InventoryFeedback::new("inventory.message.camera_opening"));

    let on_ok = ctx.effects.bind(
        ShelfPhotoCaptured,
        reduce_with!(on_shelf_photo_captured),
    );
    let on_err = ctx.effects.bind(
        ShelfPhotoCaptureFailed,
        reduce_with!(on_shelf_photo_capture_failed),
    );

    ctx.effects
        .camera()
        .capture_photo(CameraCaptureRequest {
            facing: CameraFacing::Back,
            resolution: Some(CameraResolution { width: 1280, height: 720 }),
            format: CameraImageFormat::Jpeg,
            flash: CameraFlashMode::Auto,
            quality: Some(85),
            ..Default::default()
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(CaptureShelfPhoto)]
pub fn on_capture_shelf_photo(
    state: &mut InventoryState,
    reason: String,
    ctx: &mut ReducerContext<InventoryState>,
) {
    if state.camera_busy || state.scan_busy {
        return;
    }
    if state.selected_sku.is_none() {
        state.error = Some(InventoryFeedback::new("inventory.error.select_before_photo"));
        state.message = None;
        return;
    }

    state.camera_busy = true;
    state.error = None;
    state.message = Some(InventoryFeedback::new("inventory.message.camera_permission_checking"));
    let on_ok = ctx.effects.bind(
        CameraPermissionReceived,
        reduce_with!(on_camera_permission_received),
    );
    let on_err = ctx.effects.bind(
        CameraPermissionFailed,
        reduce_with!(on_camera_permission_failed),
    );

    ctx.effects
        .camera()
        .request_permission(CameraPermissionRequest {
            reason: Some(reason),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(CameraPermissionReceived)]
pub fn on_camera_permission_received(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    let Some(permission) = ctx.input.capability_ok(REQUEST_CAMERA_PERMISSION) else {
        state.camera_busy = false;
        state.message = None;
        state.error = Some(InventoryFeedback::new("inventory.error.permission_no_result"));
        return;
    };

    match permission {
        CameraPermission::Granted => queue_shelf_photo_capture(state, ctx),
        CameraPermission::Denied | CameraPermission::Restricted => {
            state.camera_busy = false;
            state.message = None;
            state.error = Some(InventoryFeedback::new("inventory.error.camera_denied"));
        }
        CameraPermission::Unknown => {
            state.camera_busy = false;
            state.message = None;
            state.error = Some(InventoryFeedback::new("inventory.error.camera_permission_unknown"));
        }
    }
}

#[fission_reducer(CameraPermissionFailed)]
pub fn on_camera_permission_failed(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    state.camera_busy = false;
    state.message = None;
    let Some(error) = ctx.input.capability_error(REQUEST_CAMERA_PERMISSION) else {
        state.error = Some(InventoryFeedback::new("inventory.error.permission_request_incomplete"));
        return;
    };
    state.error = Some(match error.code.as_str() {
        "permission_denied" => InventoryFeedback::new("inventory.error.camera_denied"),
        "unsupported" | "unavailable" => InventoryFeedback::new("inventory.error.camera_unavailable"),
        _ => InventoryFeedback::new("inventory.error.permission_request_failed"),
    });
}

#[fission_reducer(ShelfPhotoCaptured)]
pub fn on_shelf_photo_captured(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    state.camera_busy = false;
    let Some(capture) = ctx.input.capability_ok(CAPTURE_PHOTO) else {
        state.message = None;
        state.error = Some(InventoryFeedback::new("inventory.error.photo_empty"));
        return;
    };
    let Some(sku) = state.selected_sku.clone() else {
        state.message = None;
        state.error = Some(InventoryFeedback::new("inventory.error.photo_stale_selection"));
        return;
    };
    let Some(product) = state.products.iter_mut().find(|product| product.sku == sku) else {
        state.message = None;
        state.error = Some(InventoryFeedback::new("inventory.error.photo_product_missing"));
        return;
    };

    product.evidence = Some(PhotoEvidence {
        stream: capture.stream,
        byte_len: capture.byte_len,
        content_type: capture.content_type,
        width: capture.width,
        height: capture.height,
    });
    state.error = None;
    state.message = Some(
        InventoryFeedback::new("inventory.message.photo_attached")
            .with("name", &product.name),
    );
}

#[fission_reducer(ShelfPhotoCaptureFailed)]
pub fn on_shelf_photo_capture_failed(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    state.camera_busy = false;
    state.message = None;
    let Some(error) = ctx.input.capability_error(CAPTURE_PHOTO) else {
        state.error = Some(InventoryFeedback::new("inventory.error.photo_empty"));
        return;
    };
    state.error = Some(match error.code.as_str() {
        "permission_denied" => InventoryFeedback::new("inventory.error.camera_denied"),
        "cancelled" | "canceled" | "user_cancel" => InventoryFeedback::new("inventory.error.photo_cancelled"),
        "unsupported" | "unavailable" => InventoryFeedback::new("inventory.error.camera_unavailable"),
        _ => InventoryFeedback::new("inventory.error.photo_failed"),
    });
}

fission_component! {

            product: InventoryProduct,
            selected: bool,

use fission::prelude::*;

use crate::app::InventoryFeedback;
use crate::app::inventory::{
    on_capture_shelf_photo, on_scan_shelf_label, InventoryState, ScanShelfLabel,
    CaptureShelfPhoto,
};
use crate::app::widgets::inventory_product_row::InventoryProductRow;

fission_component! {
    pub InventoryCountScreen<InventoryState> {
        state {
            manual_sku: String = String::new(),
            physical_count: String = String::new(),
        }
    }
    view(screen, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let scan_label = with_reducer!(
            cx.build,
            ScanShelfLabel(cx.tr("inventory.prompt.scan")),
            on_scan_shelf_label,
        );
        let capture_photo = with_reducer!(
            cx.build,
            CaptureShelfPhoto(cx.tr("inventory.prompt.camera")),
            on_capture_shelf_photo,
        );
        let selected = state.selected_sku.as_deref();
        let selected_product = state.products.iter().find(|product| {
            Some(product.sku.as_str()) == selected
        });
        let counted_products = state.products.iter()
            .filter(|product| product.physical_count.is_some())
            .count();
        let evidence_photos = state.products.iter()
            .filter(|product| product.evidence.is_some())
            .count();
        let feedback_message = state.message.as_ref()
            .map(|feedback| feedback.resolve(|key| cx.tr(key)));
        let feedback_error = state.error.as_ref()
            .map(|feedback| feedback.resolve(|key| cx.tr(key)));
    } =>
    SemanticsRegion(
        identifier: Some("cedar-ridge-cycle-count".to_string()),
        label: Some(cx.tr("inventory.semantics.screen")),
        child: Container(
            Row(children: [
                Spacer(flex_grow: 1.0),
                Container(
                    Column(gap: tokens.spacing.l, children: [
                        Column(gap: tokens.spacing.xs, children: [
                            Text(cx.tr("inventory.title"))
                                .weight(tokens.typography.font_weight_bold),
                            Text(cx.tr("inventory.subtitle"))
                                .color(tokens.colors.text_secondary),
                        ]),
                        Row(gap: tokens.spacing.m, wrap: ir_op::FlexWrap::Wrap, children: [
                            Text(cx.tr("inventory.summary.counted")
                                .replace("{counted}", &counted_products.to_string())
                                .replace("{total}", &state.products.len().to_string())),
                            Text(cx.tr("inventory.summary.photos")
                                .replace("{count}", &evidence_photos.to_string())),
                        ]),
                        if state.selected_sku.is_none() {
                            Column(gap: tokens.spacing.s, children: [
                                Text(cx.tr("inventory.sheet.title"))
                                    .weight(tokens.typography.font_weight_semibold),
                                if state.products.is_empty() {
                                    Text(cx.tr("inventory.sheet.empty"))
                                        .color(tokens.colors.text_secondary)
                                } else {
                                    Column(gap: tokens.spacing.s, children: [
                                        for product in state.products.iter() {
                                            InventoryProductRow(
                                                product.clone(),
                                                selected == Some(product.sku.as_str()),
                                                key: product.sku.clone(),
                                            ).id(WidgetId::explicit(&format!("inventory.product.{}", product.sku)))
                                        }
                                    ])
                                },
                            ])
                        },
                        if state.selected_sku.is_none()
                            && state.native_capabilities_available
                            && !state.products.is_empty()
                        {
                            Column(gap: tokens.spacing.s, children: [
                                Button(
                                    child: Text(if state.scan_busy {
                                        cx.tr("inventory.status.scanner_waiting")
                                    } else {
                                        cx.tr("inventory.action.scan")
                                    }),
                                    key: "scan-shelf-label",
                                    variant: ButtonVariant::Primary,
                                    disabled: state.scan_busy || state.camera_busy,
                                    on_press: scan_label,
                                )
                                .semantics_identifier("inventory.scan-shelf-label".to_string()),
                                Text(cx.tr("inventory.scan.explainer"))
                                    .color(tokens.colors.text_secondary),
                            ])
                        } else if state.selected_sku.is_none() {
                            if state.products.is_empty() {
                                Text(cx.tr("inventory.sheet.load_before_scan"))
                                    .color(tokens.colors.text_secondary)
                            } else {
                                Text(cx.tr("inventory.scan.browser_help"))
                                    .color(tokens.colors.text_secondary)
                            }
                        } else {
                            Text(cx.tr("inventory.count.help"))
                                .color(tokens.colors.text_secondary)
                        },
                        if state.selected_sku.is_none() && !state.products.is_empty() {
                            Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                                TextInput(
                                    label: Some(cx.tr("inventory.field.manual_sku").into()),
                                    bind: screen.manual_sku,
                                    placeholder: Some(cx.tr("inventory.field.manual_sku.placeholder").into()),
                                    enabled: !state.scan_busy && !state.camera_busy,
                                    semantics_identifier: "inventory.manual-sku".to_string(),
                                ),
                                Button(
                                    child: Text(cx.tr("inventory.action.open_item")),
                                    key: "open-manual-sku",
                                    variant: ButtonVariant::Outline,
                                    disabled: state.scan_busy || state.camera_busy,
                                    on_press: reduce {
                                        let sku = screen.manual_sku.trim().to_ascii_uppercase();
                                        if sku.is_empty() {
                                            state.error = Some(InventoryFeedback::new("inventory.error.enter_sku"));
                                            state.message = None;
                                        } else if state.products.iter().any(|product| product.sku == sku) {
                                            state.selected_sku = Some(sku.clone());
                                            state.error = None;
                                            state.message = Some(
                                                InventoryFeedback::new("inventory.message.manual_product_selected")
                                                    .with("sku", &sku),
                                            );
                                            screen.manual_sku.clear();
                                        } else {
                                            state.error = Some(
                                                InventoryFeedback::new("inventory.error.unknown_sku_review")
                                                    .with("sku", sku),
                                            );
                                            state.message = None;
                                        }
                                    },
                                )
                                .semantics_identifier("inventory.open-manual-sku".to_string()),
                            ])
                        },
                        if let Some(product) = selected_product {
                            Column(gap: tokens.spacing.s, children: [
                                Text(cx.tr("inventory.count.title")
                                    .replace("{name}", &product.name)
                                    .replace("{bin}", &product.bin))
                                    .weight(tokens.typography.font_weight_semibold),
                                TextInput(
                                    label: Some(cx.tr("inventory.field.physical_count").into()),
                                    bind: screen.physical_count,
                                    placeholder: Some(cx.tr("inventory.field.physical_count.placeholder").into()),
                                    keyboard_type: TextInputType::Number,
                                    semantics_identifier: "inventory.physical-count".to_string(),
                                ),

                                        child: Text(cx.tr("inventory.action.stage_count")),
                                        key: "stage-physical-count",
                                        variant: ButtonVariant::Primary,
                                        disabled: screen.physical_count.trim().is_empty() || state.camera_busy,
                                        on_press: reduce {
                                            let parsed_count = screen.physical_count.trim().parse::<u32>();
                                            match parsed_count {
                                                Ok(count) => {
                                                    if let Some(sku) = state.selected_sku.clone() {
                                                        if let Some(product) = state.products.iter_mut()
                                                            .find(|product| product.sku == sku)
                                                        {
                                                            let previous = product.on_hand;
                                                            product.physical_count = Some(count);
                                                            let difference = i64::from(count) - i64::from(previous);
                                                            state.error = None;
                                                            state.message = Some(
                                                                InventoryFeedback::new("inventory.message.count_staged")
                                                                    .with("count", count)
                                                                    .with("previous", previous)
                                                                    .with("difference", format!("{difference:+}")),
                                                            );
                                                            screen.physical_count.clear();
                                                        }
                                                    }
                                                }
                                                Err(_) => {
                                                    state.error = Some(InventoryFeedback::new("inventory.error.count_whole_number"));

                                                }

                                    Text(cx.tr("inventory.evidence.optional"))
                                        .color(tokens.colors.text_secondary)
                                } else {
                                    Text(cx.tr("inventory.evidence.browser_unavailable"))
                                        .color(tokens.colors.text_secondary)

                                    child: Text(cx.tr("inventory.action.finish_item")),
                                    key: "finish-counted-item",
                                    variant: ButtonVariant::Outline,

                                        state.message = Some(InventoryFeedback::new("inventory.message.count_remains_staged"));
                                        state.error = None;
                                        screen.manual_sku.clear();
                                        screen.physical_count.clear();
                                    },
                                )
                                .semantics_identifier("inventory.next-item".to_string()),
                            ])
                        },
                        if let Some(message) = &feedback_message {
                            Text(message.clone()).color(tokens.colors.text_secondary)
                        },
                        if let Some(error) = &feedback_error {
                            Text(error.clone()).color(tokens.colors.error)
                        },
                        if state.selected_sku.is_none() {
                            Text(cx.tr("inventory.count.review_notice"))
                                .color(tokens.colors.text_secondary)

                .padding_all(tokens.spacing.l)

                    Length::points(0.0),
                    Length::percent(100.0),

                .bg(tokens.colors.surface)

                .border_radius(tokens.radii.large),
                Spacer(flex_grow: 1.0),
            ]),

The scanner and camera results are read from `ReducerContext.input` with `capability_ok(SCAN_BARCODE)` and `capability_ok(CAPTURE_PHOTO)`. Their unit actions only route each host response to the correct reducer. If the operation fails, the corresponding reducer reads `capability_error(...)` and leaves the product’s saved quantity alone. `native_capabilities_available` is set by the app shell: it keeps native actions out of the web preview, where the browser has no access to Fission's Android or iOS host providers. The sample rows are preview-only. A production app should load its assigned count sheet through its inventory service and show the empty state until that load completes; never ship these fixture rows as the native app's starting stock.

The camera returns a `DataStreamId`, not an image-sized byte vector in app state. This example keeps the handle with the selected product and shows its metadata. A production upload should pass that handle to an asynchronous job or service, then persist the resulting storage reference with the staged count.

At Cedar Ridge Outfitters, the closing team checks the shelves in aisle C before the weekly stock report is sent. The inventory system says there are **18 Trail tarps** in bin **C-12**. A staff member scans the shelf label, counts the units by hand, and finds 17. They attach a quick shelf photo so the morning manager can investigate the missing tarp.

The important part is that **17 does not immediately overwrite 18**. The app records a proposed count and its difference, then leaves it ready for the normal stock-review service. A blurry label can be entered manually, a camera denial does not block the count, and an unknown SKU cannot change another product’s quantity.

In the browser preview, Fission’s memory scanner returns the tarp SKU and its memory camera returns a small PNG. Those hosts exercise the same capability reducers used by the Android and iOS app without requesting device permissions. The preview displays the photo metadata rather than pretending that its generated image is a real shelf photograph.

## Create the shared mobile project

Add both mobile targets and declare the camera and barcode capabilities. Live scanning uses camera access, so the CLI updates the native configuration needed by each target:

`inventory.rs` owns the inventory facts and reducers. The count field and manual SKU field are short-lived drafts owned by the screen component. The generated hosts own Android and iOS permission prompts; the shared Rust code asks Fission to scan or capture and handles the typed result.

## Scan a product and stage its count

The app uses an inventory sheet containing the product’s current system quantity. Scanning chooses a row; it does not change stock. After that, the employee types the physical count and stages the difference. Keeping those actions separate prevents a camera result from silently changing an inventory record.

Open the tabs in order. First, define the product and staged-evidence state. Then follow the reducers that request a scan, ask for camera permission, and record the results. The final tabs show the screen component and the memory providers that make the browser example interactive.

use fission::prelude::*;

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct PhotoEvidence {
    pub stream: DataStreamId,
    pub byte_len: Option<u64>,
    pub content_type: String,
    pub width: u32,
    pub height: u32,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct InventoryProduct {
    pub sku: String,
    pub name: String,
    pub bin: String,
    pub on_hand: u32,
    pub physical_count: Option<u32>,
    pub evidence: Option<PhotoEvidence>,
}

#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct InventoryState {
    pub products: Vec<InventoryProduct>,
    pub selected_sku: Option<String>,
    pub scan_busy: bool,
    pub camera_busy: bool,
    pub message: Option<String>,
    pub error: Option<String>,
}

impl GlobalState for InventoryState {}

#[fission_reducer(ScanShelfLabel)]
pub fn on_scan_shelf_label(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    if state.scan_busy || state.camera_busy || state.selected_sku.is_some() {
        return;
    }

    state.scan_busy = true;
    state.error = None;
    state.message = Some("Opening the label scanner…".to_string());

    let on_ok = ctx.effects.bind(
        InventorySkuRead,
        reduce_with!(on_inventory_sku_read),
    );
    let on_err = ctx.effects.bind(
        InventoryScanFailed,
        reduce_with!(on_inventory_scan_failed),
    );

    ctx.effects
        .barcode_scanner()
        .scan(BarcodeScanRequest {
            formats: vec![BarcodeFormat::Code128, BarcodeFormat::QrCode],
            prompt: Some("Scan the SKU on the shelf label".into()),
            timeout_ms: Some(20_000),
            allow_multiple: false,
            ..Default::default()
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(InventorySkuRead)]
pub fn on_inventory_sku_read(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    state.scan_busy = false;
    let Some(results) = ctx.input.capability_ok(SCAN_BARCODE) else {
        state.message = None;
        state.error = Some("The scanner returned no product code. Enter the SKU printed on the shelf label.".to_string());
        return;
    };
    let Some(result) = results.items.first() else {
        state.message = None;
        state.error = Some("No label was read. Keep the code inside the scan frame or enter the SKU manually.".to_string());
        return;
    };

    let sku = result.value.trim().to_ascii_uppercase();
    if let Some(product) = state.products.iter().find(|product| product.sku == sku) {
        state.selected_sku = Some(sku.clone());
        state.error = None;
        state.message = Some(format!(
            "{} in bin {} selected. Enter the physical shelf total below; saved stock is {}.",
            product.name, product.bin, product.on_hand
        ));
    } else {
        state.message = None;
        state.error = Some(format!(
            "{sku} is not on this cycle-count sheet. Check the label or ask the inventory lead before changing stock."
        ));
    }
}

#[fission_reducer(InventoryScanFailed)]
pub fn on_inventory_scan_failed(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    state.scan_busy = false;
    state.message = None;
    let Some(error) = ctx.input.capability_error(SCAN_BARCODE) else {
        state.error = Some("The scanner stopped before returning a result. Enter the SKU manually and continue the count.".to_string());
        return;
    };

    state.error = Some(match error.code.as_str() {
        "cancelled" | "canceled" | "user_cancel" => {
            "Scanning was cancelled. No inventory changed; enter the SKU manually or scan again.".to_string()
        }
        "permission_denied" => {
            "Camera access was denied. Enter the SKU manually, or enable camera access in system settings.".to_string()
        }
        "unsupported" | "unavailable" => {
            "This device cannot scan a live label. Enter the SKU manually to continue the count.".to_string()
        }
        "timeout" => {
            "The label was not read in time. Improve the light or enter the SKU manually.".to_string()
        }
        _ => "The label could not be read. No inventory changed; check the code and try again.".to_string(),
    });
}

fn queue_shelf_photo_capture(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    state.camera_busy = true;
    state.error = None;
    state.message = Some("Opening the camera for shelf evidence…".to_string());

    let on_ok = ctx.effects.bind(
        ShelfPhotoCaptured,
        reduce_with!(on_shelf_photo_captured),
    );
    let on_err = ctx.effects.bind(
        ShelfPhotoCaptureFailed,
        reduce_with!(on_shelf_photo_capture_failed),
    );

    ctx.effects
        .camera()
        .capture_photo(CameraCaptureRequest {
            facing: CameraFacing::Back,
            resolution: Some(CameraResolution { width: 1280, height: 720 }),
            format: CameraImageFormat::Jpeg,
            flash: CameraFlashMode::Auto,
            quality: Some(85),
            ..Default::default()
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(CaptureShelfPhoto)]
pub fn on_capture_shelf_photo(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    if state.camera_busy || state.scan_busy {
        return;
    }
    if state.selected_sku.is_none() {
        state.error = Some("Select a product before attaching its shelf photo.".to_string());
        state.message = None;
        return;
    }

    state.camera_busy = true;
    state.error = None;
    state.message = Some("Checking camera access…".to_string());
    let on_ok = ctx.effects.bind(
        CameraPermissionReceived,
        reduce_with!(on_camera_permission_received),
    );
    let on_err = ctx.effects.bind(
        CameraPermissionFailed,
        reduce_with!(on_camera_permission_failed),
    );

    ctx.effects
        .camera()
        .request_permission(CameraPermissionRequest {
            reason: Some("Attach a shelf photo to this stock-count review".into()),
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(CameraPermissionReceived)]
pub fn on_camera_permission_received(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    let Some(permission) = ctx.input.capability_ok(REQUEST_CAMERA_PERMISSION) else {
        state.camera_busy = false;
        state.message = None;
        state.error = Some("The camera did not return a permission result. You can still stage the count without a photo.".to_string());
        return;
    };

    match permission {
        CameraPermission::Granted => queue_shelf_photo_capture(state, ctx),
        CameraPermission::Denied | CameraPermission::Restricted => {
            state.camera_busy = false;
            state.message = None;
            state.error = Some("Camera access was not granted. Continue without a photo, or enable it in system settings.".to_string());
        }
        CameraPermission::Unknown => {
            state.camera_busy = false;
            state.message = None;
            state.error = Some("The camera permission is still unknown. Continue without a photo or try the request again.".to_string());
        }
    }
}

#[fission_reducer(CameraPermissionFailed)]
pub fn on_camera_permission_failed(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    state.camera_busy = false;
    state.message = None;
    let Some(error) = ctx.input.capability_error(REQUEST_CAMERA_PERMISSION) else {
        state.error = Some("The camera permission request did not finish. You can stage the count without a photo.".to_string());
        return;
    };
    state.error = Some(match error.code.as_str() {
        "permission_denied" => "Camera access was denied. Continue without a photo or enable camera access in system settings.".to_string(),
        "unsupported" | "unavailable" => "This device cannot capture a shelf photo. Continue with the stock count without evidence.".to_string(),
        _ => "The camera permission request failed. Continue without a photo or try again.".to_string(),
    });
}

#[fission_reducer(ShelfPhotoCaptured)]
pub fn on_shelf_photo_captured(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    state.camera_busy = false;
    let Some(capture) = ctx.input.capability_ok(CAPTURE_PHOTO) else {
        state.message = None;
        state.error = Some("The camera returned no photo. The count is still available without evidence.".to_string());
        return;
    };
    let Some(sku) = state.selected_sku.clone() else {
        state.message = None;
        state.error = Some("The selected product changed before the camera finished. Take the photo again for the current item.".to_string());
        return;
    };
    let Some(product) = state.products.iter_mut().find(|product| product.sku == sku) else {
        state.message = None;
        state.error = Some("This product is no longer on the cycle-count sheet. No photo was attached.".to_string());
        return;
    };

    product.evidence = Some(PhotoEvidence {
        stream: capture.stream,
        byte_len: capture.byte_len,
        content_type: capture.content_type,
        width: capture.width,
        height: capture.height,
    });
    state.error = None;
    state.message = Some(format!("Shelf photo attached to {}. The image stays in a runtime-owned stream until the app uploads it.", product.name));
}

#[fission_reducer(ShelfPhotoCaptureFailed)]
pub fn on_shelf_photo_capture_failed(
    state: &mut InventoryState,
    ctx: &mut ReducerContext<InventoryState>,
) {
    state.camera_busy = false;
    state.message = None;
    let Some(error) = ctx.input.capability_error(CAPTURE_PHOTO) else {
        state.error = Some("The camera did not return a photo. You can still stage the count without evidence.".to_string());
        return;
    };
    state.error = Some(match error.code.as_str() {
        "permission_denied" => "Camera access was denied. Continue the count without a photo, or enable camera access in system settings.".to_string(),
        "cancelled" | "canceled" | "user_cancel" => "The photo was cancelled. No count changed; try again or continue without evidence.".to_string(),
        "unsupported" | "unavailable" => "This device cannot capture a photo. Continue the count without evidence.".to_string(),
        _ => "The photo could not be captured. Continue without evidence or try again.".to_string(),
    });
}

use fission::prelude::*;

use crate::app::InventoryProduct;

fission_component! {
    pub InventoryProductRow<InventoryState> {
        props {
            product: InventoryProduct,
            selected: bool,
        }

    view(row, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let count_summary = if let Some(count) = row.product.physical_count {
            let difference = i64::from(count) - i64::from(row.product.on_hand);

        } else {
            format!("{} units in the system", row.product.on_hand)
        };
    } =>
    SemanticsRegion(
        identifier: Some(format!("inventory.product.{}", row.product.sku.to_ascii_lowercase())),
        label: Some(format!("{}, SKU {}, bin {}", row.product.name, row.product.sku, row.product.bin)),
        child: Container(
            Column(gap: tokens.spacing.xs, children: [
                Row(gap: tokens.spacing.m, wrap: ir_op::FlexWrap::Wrap, children: [
                    Text(row.product.name.clone())
                        .weight(tokens.typography.font_weight_semibold),
                    if row.selected {
                        Text("Selected for this count")
                            .color(tokens.colors.text_secondary)
                    } else {
                        Text("Cycle-count item")
                            .color(tokens.colors.text_secondary)
                    },
                ]),
                Text(format!("SKU {} · Bin {}", row.product.sku, row.product.bin)),
                Text(count_summary)
                    .color(tokens.colors.text_secondary),
                if let Some(evidence) = &row.product.evidence {
                    Text(format!(
                        "Photo attached · {} × {} · {}",
                        evidence.width, evidence.height, evidence.content_type
                    ))
                    .color(tokens.colors.text_secondary)
                },
            ])
        )
        .padding_all(tokens.spacing.m)
        .bg(tokens.colors.background)
        .border(tokens.colors.border, 1.0)
        .border_radius(tokens.radii.medium),
    )
}

use fission::prelude::*;

use crate::app::inventory::{
    on_capture_shelf_photo, on_scan_shelf_label, InventoryState, ScanShelfLabel,
    CaptureShelfPhoto,
};
use crate::app::widgets::inventory_product_row::InventoryProductRow;

fission_component! {
    pub InventoryCountScreen<InventoryState> {
        state {
            manual_sku: String = String::new(),

            Some(product.sku.as_str()) == selected

            .filter(|product| product.evidence.is_some())

    } =>
    SemanticsRegion(
        identifier: Some("cedar-ridge-cycle-count".to_string()),
        label: Some("Cedar Ridge Outfitters shelf inventory count".to_string()),
        child: Container(
            Row(children: [
                Spacer(flex_grow: 1.0),
                Container(
                    Column(gap: tokens.spacing.l, children: [
                        Column(gap: tokens.spacing.xs, children: [
                            Text("Cedar Ridge · cycle count")
                                .weight(tokens.typography.font_weight_bold),
                            Text("Closing check · Aisle C · Thursday, 6:15 pm")
                                .color(tokens.colors.text_secondary),
                        ]),
                        Row(gap: tokens.spacing.m, wrap: ir_op::FlexWrap::Wrap, children: [
                            Text(format!("{} of {} items counted", counted_products, state.products.len())),
                            Text(format!("{} shelf photos attached", evidence_photos)),
                        ]),
                        if state.selected_sku.is_none() {
                            Column(gap: tokens.spacing.s, children: [
                                Text("Cycle-count sheet")
                                    .weight(tokens.typography.font_weight_semibold),
                                if state.products.is_empty() {
                                    Text("Load a cycle-count sheet before scanning shelf labels.")
                                        .color(tokens.colors.text_secondary)
                                } else {
                                    Column(gap: tokens.spacing.s, children: [
                                        for product in state.products.iter() {
                                            InventoryProductRow(
                                                product.clone(),
                                                selected == Some(product.sku.as_str()),
                                                key: product.sku.clone(),

                                    ])
                                },
                            ])
                        },
                        if state.selected_sku.is_none() {
                            Column(gap: tokens.spacing.s, children: [
                                Button(
                                    child: Text(if state.scan_busy {
                                        "Waiting for scanner…"
                                    } else {
                                        "Scan shelf label"
                                    }),
                                    key: "scan-shelf-label",
                                    variant: ButtonVariant::Primary,
                                    disabled: state.scan_busy || state.camera_busy,
                                    on_press: scan_label,
                                )
                                .semantics_identifier("inventory.scan-shelf-label".to_string()),
                                Text("A scan selects a product. It does not change the saved quantity.")
                                    .color(tokens.colors.text_secondary),
                            ])
                        } else {
                            Text("Count this item, then finish to return to the sheet.")
                                .color(tokens.colors.text_secondary)
                        },
                        if state.selected_sku.is_none() {
                            Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                                TextInput(
                                    label: Some("Enter the shelf SKU manually".into()),
                                    bind: screen.manual_sku,
                                    placeholder: Some("For example, LMP-308".into()),
                                    enabled: !state.scan_busy && !state.camera_busy,
                                    semantics_identifier: "inventory.manual-sku".to_string(),
                                ),
                                Button(
                                    child: Text("Open item"),
                                    key: "open-manual-sku",
                                    variant: ButtonVariant::Outline,
                                    disabled: state.scan_busy || state.camera_busy,
                                    on_press: reduce {
                                        let sku = screen.manual_sku.trim().to_ascii_uppercase();

                                .semantics_identifier("inventory.open-manual-sku".to_string()),
                            ])
                        },
                        if let Some(product) = selected_product {
                            Column(gap: tokens.spacing.s, children: [
                                Text(format!("Count {} in bin {}", product.name, product.bin))
                                    .weight(tokens.typography.font_weight_semibold),
                                TextInput(
                                    label: Some("Units physically on the shelf".into()),
                                    bind: screen.physical_count,
                                    placeholder: Some("Count each unit before entering the total".into()),
                                    keyboard_type: TextInputType::Number,
                                    semantics_identifier: "inventory.physical-count".to_string(),

                                                            screen.physical_count.clear();
                                                        }
                                                    }
                                                }
                                                Err(_) => {
                                                    state.error = Some("Enter a whole number of units, including 0 if the bin is empty.".to_string());
                                                    state.message = None;
                                                }
                                            }
                                        },
                                    )
                                    .semantics_identifier("inventory.stage-count".to_string()),
                                    Button(
                                        child: Text(if state.camera_busy {
                                            "Opening camera…"
                                        } else if product.evidence.is_some() {
                                            "Retake shelf photo"
                                        } else {
                                            "Photograph shelf"
                                        }),
                                        key: "capture-shelf-photo",
                                        variant: ButtonVariant::Outline,
                                        disabled: state.camera_busy || state.scan_busy,
                                        on_press: capture_photo,
                                    )
                                    .semantics_identifier("inventory.capture-shelf-photo".to_string()),
                                ]),

                                    Text(format!("Evidence attached: {} × {} {}{}", evidence.width, evidence.height, evidence.content_type, evidence.byte_len.map(|size| format!(" · {size} bytes")).unwrap_or_default()))

                                        state.message = Some("Count remains staged. Choose or scan the next SKU.".to_string());
                                        state.error = None;
                                        screen.manual_sku.clear();
                                        screen.physical_count.clear();
                                    },
                                )
                                .semantics_identifier("inventory.next-item".to_string()),
                            ])
                        },
                        if let Some(message) = &state.message {
                            Text(message.clone()).color(tokens.colors.text_secondary)
                        },
                        if let Some(error) = &state.error {
                            Text(error.clone()).color(tokens.colors.error)
                        },

The scanner and camera results are read from `ReducerContext.input` with `capability_ok(SCAN_BARCODE)` and `capability_ok(CAPTURE_PHOTO)`. Their unit actions only route each host response to the correct reducer. If the operation fails, the corresponding reducer reads `capability_error(...)` and leaves the product’s saved quantity alone.

The camera returns a `DataStreamId`, not an image-sized byte vector in app state. This example keeps the handle with the selected product and shows its metadata. A production upload should pass that handle to an asynchronous job or service, then persist the resulting storage reference with the staged count.

## Verify camera and scanner recovery on Android and iOS

The browser preview uses memory providers, so it cannot show a real permission prompt, camera viewfinder, autofocus, or barcode decoder. Test those host behaviors on a simulator or device after the project is configured.

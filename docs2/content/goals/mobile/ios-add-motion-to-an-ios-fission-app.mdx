Motion can explain that a review dialog has opened, but it cannot be the thing which makes a note confirmed. If confirmation waits for an animation callback, an interrupted transition becomes a data problem.

We will build a handover-note review flow using Fission's built-in `Modal` and its motion preset. The reducer changes the state immediately. Motion presents that change, whilst focus, dismissal and dialog semantics remain the standard widget's responsibility.

## Create the shared app

Complete [iOS setup](/blog/set-up-rust-ios-development-with-fission/) if needed.

```sh
cargo install cargo-fission
fission init ios-add-motion-to-an-ios-fission-app
cd ios-add-motion-to-an-ios-fission-app
fission add-target ios --project-dir .
cargo add serde_yaml
```

Keep the generated `src/main.rs`. Both normal native and Web entrypoints below start the same review flow.

## Choose widget-owned motion before writing custom tracks

The modal already has stable internal slots, enter/exit motion and a dismissal boundary. Rebuilding those with a positioned container and opacity timer would make the example longer whilst losing the widget's normal behavior.

The draft and open/closed flag are local UI state. A confirmed version is a snapshot in application state. Closing the dialog cancels review, not the draft; changing the draft later does not silently edit the already confirmed version.

pub struct ReviewState {
    pub locale: Locale,
    pub animate: bool,
    pub approved_note: Option<String>,
}

    fn default() -> Self {
        Self {
            locale: Locale::from("en-US"),
            animate: false,
            approved_note: None,
        }
    }
}
impl GlobalState for ReviewState {}

use super::state::ReviewState;
use fission::prelude::*;

fission_component! {
    pub ReviewScreen<ReviewState> {
        state {
            draft: String = String::new(),
            review_open: bool = false,
        }
    }
    view(screen, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } => SafeArea(
        child: Scroll(
            child: Container(Column(gap: tokens.spacing.m, children: [
                Text(cx.tr("review.heading")).size(tokens.typography.heading2_size),
                Text(cx.tr("review.explanation")),
                Row(gap: tokens.spacing.s, children: [
                    Button(
                        child: Text(cx.tr("language.english")), key: "english",
                        on_press: reduce { state.locale = Locale::from("en-US"); },
                    ),
                    Button(
                        child: Text(cx.tr("language.spanish")), key: "spanish",
                        on_press: reduce { state.locale = Locale::from("es-ES"); },
                    ),
                ]),
                Button(
                    child: Text(if state.animate { cx.tr("review.motion_off") } else { cx.tr("review.motion_on") }),
                    key: "toggle-animation",
                    on_press: reduce { state.animate = !state.animate; },
                ),
                TextInput(
                    value: screen.draft.clone(), bind(on_input): to(screen.draft),
                    label: Some(TextContent::Key("review.note".into())),
                    multiline: true, keyboard_type: TextInputType::Multiline,
                ),
                Button(
                    child: Text(cx.tr("review.open")), key: "open-review",
                    disabled: screen.draft.trim().is_empty(),
                    on_press: reduce { screen.review_open = true; },
                ),
                if let Some(note) = &state.approved_note {
                    Column(gap: tokens.spacing.s, children: [
                        Text(cx.tr("review.approved")).weight(tokens.typography.font_weight_semibold),
                        Text(note.clone()),
                        Text(cx.tr("review.session")).color(tokens.colors.text_secondary),
                    ])
                },
                Modal(
                    title: cx.tr("review.dialog_title"),
                    is_open: screen.review_open,
                    motion: Some(if state.animate { ModalMotion::Default } else { ModalMotion::None }),
                    on_dismiss: reduce { screen.review_open = false; },
                    content: Column(gap: tokens.spacing.m, children: [
                        Text(screen.draft.clone()),
                        Text(cx.tr("review.dialog_help")),
                        Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                            Button(
                                child: Text(cx.tr("review.keep_editing")), key: "keep-editing",
                                on_press: reduce { screen.review_open = false; },
                            ),
                            Button(
                                child: Text(cx.tr("review.confirm")), key: "confirm-note",
                                on_press: reduce {
                                    state.approved_note = Some(screen.draft.trim().to_owned());
                                    screen.review_open = false;
                                },
                            ),
                        ]),
                    ]),
                ),
            ]))
            .padding_all(tokens.spacing.l),
        ),
    )
}

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid review translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

pub fn sync_env(state: &crate::app::ReviewState, env: &mut Env) {
    env.locale = state.locale.clone();
    env.widget_motion = if state.animate {
        WidgetMotion::Standard
    } else {
        WidgetMotion::Off
    };
    // Do not overwrite a host-supplied Reduced motion preference.
}

## Keep preference, presentation and completion separate

The app begins with its widget motion disabled. Enabling it selects `ModalMotion::Default`; disabling it selects `ModalMotion::None`. `Env.widget_motion` applies the same app choice to widgets whose motion has not been set explicitly. We leave `Env.motion_preference` alone, so a host-reported reduced-motion preference still takes precedence.

There is a current platform boundary worth stating clearly. Fission's Web shell reads `prefers-reduced-motion`, but the current native iOS shell does not synchronize the iOS Reduce Motion setting into `Env.motion_preference`. This example therefore provides an explicit in-app choice and defaults to no animation. Do not describe that as automatic native accessibility integration.

Confirmation does not depend on a duration or frame count. Its reducer copies the note and closes the dialog in the same synchronous transition. A closing animation may still be visible, but it is not an authority for whether the note was confirmed.

## Verify interrupted and reduced-motion behavior on the target

```sh
fission doctor ios --project-dir .
fission devices --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
```

Select a simulator with [the simulator guide](/blog/choose-boot-and-launch-an-ios-simulator-with-fission/). Check open, backdrop dismissal, explicit Keep editing and Confirm in both languages. Repeat at narrow widths and with longer notes, then background and resume the app during a transition. The final state must remain useful even if intermediate frames were never displayed.

On iOS, verify the app's no-animation choice directly; toggling the system Reduce Motion setting alone does not prove the currently missing native synchronization. On Web, test the browser's reduced-motion preference as well as the app toggle. These are separate evidence paths.

A launch smoke test does not inspect animation, focus restoration or interrupted transitions. Use a real rendered target and check those interactions before calling the workflow qualified. The example is session-only: a confirmed note is not a network delivery or disk save.

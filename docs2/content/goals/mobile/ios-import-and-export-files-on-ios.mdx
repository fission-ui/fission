An inspection visit produces two different kinds of document: the report already supplied for the job and the handover note written by the engineer. The app needs access to both, but it should not assume that a file name gives it permission to read or replace a document.

Here, the user selects the folder for a visit. The app reads a report from that folder and saves a separate note beside it. iOS supplies access through its document picker. The provider manages the security-scoped resource; a display name is not an unrestricted path into the device. This distinction matters: the directory handle represents access granted by the provider, whereas the name shown on screen is only a label.

The example keeps that grant for the current run. It does not claim to restore access after a restart or upload inspection evidence to a server.

## Choose the inspection folder

The first useful operation is selecting a folder. A cancelled picker is not a failed read and must not remove a folder the user had already selected. Keep those outcomes distinct.

The reducer marks the operation pending and requests the picker. Its completion reducers decode the capability result supplied by Fission; they do not substitute a fabricated success value or a default error.

```rust
use fission::prelude::*;

#[derive(Clone, Debug, PartialEq)]
pub struct FilesState {
    pub directory: Option<DirectoryHandle>,
    pub busy: bool,
    pub status_key: String,
    pub error: Option<String>,
}

impl Default for FilesState {
    fn default() -> Self {
        Self {
            directory: None,
            busy: false,
            status_key: "files.status.choose".into(),
            error: None,
        }
    }
}
impl GlobalState for FilesState {}

pub fn choose_directory(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    if state.busy {
        return;
    }
    state.busy = true;
    state.error = None;
    state.status_key = "files.status.choosing".into();

    let ok = cx.effects.bind(DirectoryChosen, reduce_with!(directory_chosen));
    let err = cx.effects.bind(DirectoryFailed, reduce_with!(directory_failed));
    cx.effects.file_system()
        .pick_directory(PickDirectoryRequest {
            access: FileSystemAccessMode::ReadWrite,
            persistence_key: None,
        })
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(DirectoryChosen)]
pub fn directory_chosen(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.status_key = "files.status.unexpected".into();
    if let Some(result) = cx.input.capability_ok(PICK_DIRECTORY) {
        if let Some(directory) = result.directory {
            state.directory = Some(directory);
            state.status_key = "files.status.selected".into();
        } else {
            state.status_key = "files.status.cancelled".into();
        }
    }
}

#[fission_reducer(DirectoryFailed)]
pub fn directory_failed(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.status_key = "files.status.failed".into();
    state.error = cx.input.capability_error(PICK_DIRECTORY)
        .map(|error| format!("{}: {}", error.code, error.message))
        .or_else(|| cx.input.capability_error_message(PICK_DIRECTORY).map(str::to_owned));
}
```

## Read the report and save a separate note

A large report should not become a large value in application state. The read operation supplies a stream identifier; a registered asynchronous job consumes its chunks and returns only the byte and line counts. Reducers remain synchronous throughout.

The note is different: it is already a small text draft owned by the screen. The write request takes an owned snapshot of that text and sets `overwrite: false`. An existing document therefore produces an error instead of being replaced.

Replace the screen, state and shell setup below, and add `src/jobs.rs`. The translations from step one remain unchanged.

```rust
use crate::jobs::{ReportRequest, ReportSummary, INSPECT_REPORT};
use fission::prelude::*;

#[derive(Clone, Debug, PartialEq)]
pub struct FilesState {
    pub directory: Option<DirectoryHandle>,
    pub busy: bool,
    pub status_key: String,
    pub error: Option<String>,
    pub summary: Option<ReportSummary>,
    pub written_bytes: Option<u64>,
}

impl Default for FilesState {
    fn default() -> Self {
        Self {
            directory: None,
            busy: false,
            status_key: "files.status.choose".into(),
            error: None,
            summary: None,
            written_bytes: None,
        }
    }
}
impl GlobalState for FilesState {}

pub fn choose_directory(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    if state.busy {
        return;
    }
    state.busy = true;
    state.error = None;
    state.status_key = "files.status.choosing".into();

    let ok = cx.effects.bind(DirectoryChosen, reduce_with!(directory_chosen));
    let err = cx.effects.bind(DirectoryFailed, reduce_with!(directory_failed));
    cx.effects.file_system()
        .pick_directory(PickDirectoryRequest {
            access: FileSystemAccessMode::ReadWrite,
            persistence_key: None,
        })
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(DirectoryChosen)]
pub fn directory_chosen(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.status_key = "files.status.unexpected".into();
    if let Some(result) = cx.input.capability_ok(PICK_DIRECTORY) {
        if let Some(directory) = result.directory {
            state.directory = Some(directory);
            state.summary = None;
            state.written_bytes = None;
            state.status_key = "files.status.selected".into();
        } else {
            state.status_key = "files.status.cancelled".into();
        }
    }
}

#[fission_reducer(DirectoryFailed)]
pub fn directory_failed(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.status_key = "files.status.failed".into();
    state.error = cx.input.capability_error(PICK_DIRECTORY)
        .map(|error| format!("{}: {}", error.code, error.message))
        .or_else(|| cx.input.capability_error_message(PICK_DIRECTORY).map(str::to_owned));
}

pub fn is_file_name(name: &str) -> bool {
    !name.is_empty()
        && name == name.trim()
        && name != "."
        && name != ".."
        && !name.chars().any(|ch| matches!(ch, '/' | '\\' | ':' | '\0'))
}

pub fn read_report(state: &mut FilesState, name: String, cx: &mut ReducerContext<FilesState>) {
    if state.busy {
        return;
    }
    let Some(directory) = state.directory.as_ref() else {
        state.status_key = "files.status.choose".into();
        return;
    };
    if !is_file_name(&name) {
        state.status_key = "files.status.invalid_name".into();
        return;
    }
    let location = FileSystemLocation::directory(directory.id, name);
    state.busy = true;
    state.error = None;
    state.summary = None;
    state.status_key = "files.status.reading".into();

    let ok = cx.effects.bind(ReportOpened, reduce_with!(report_opened));
    let err = cx.effects.bind(ReadFailed, reduce_with!(read_failed));
    cx.effects.file_system().read(ReadFileRequest { location }).on_ok(ok).on_err(err);
}

#[fission_reducer(ReportOpened)]
pub fn report_opened(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    let Some(result) = cx.input.capability_ok(READ_FILE) else {
        state.busy = false;
        state.status_key = "files.status.unexpected".into();
        return;
    };
    let ok = cx.effects.bind(ReportInspected, reduce_with!(report_inspected));
    let err = cx.effects.bind(InspectionFailed, reduce_with!(inspection_failed));
    cx.effects.app(INSPECT_REPORT, ReportRequest { stream: result.stream }).on_ok(ok).on_err(err);
}

#[fission_reducer(ReadFailed)]
pub fn read_failed(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.status_key = "files.status.failed".into();
    state.error = cx.input.capability_error(READ_FILE)
        .map(|error| format!("{}: {}", error.code, error.message))
        .or_else(|| cx.input.capability_error_message(READ_FILE).map(str::to_owned));
}

#[fission_reducer(ReportInspected)]
pub fn report_inspected(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.summary = cx.input.job_ok(INSPECT_REPORT);
    state.status_key = if state.summary.is_some() {
        "files.status.read"
    } else {
        "files.status.unexpected"
    }.into();
}

#[fission_reducer(InspectionFailed)]
pub fn inspection_failed(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.status_key = "files.status.failed".into();
    state.error = cx.input.job_err(INSPECT_REPORT)
        .or_else(|| cx.input.job_error_message(INSPECT_REPORT).map(str::to_owned));
}

pub fn export_note(
    state: &mut FilesState,
    name: String,
    note: String,
    cx: &mut ReducerContext<FilesState>,
) {
    if state.busy {
        return;
    }
    let Some(directory) = state.directory.as_ref() else {
        state.status_key = "files.status.choose".into();
        return;
    };
    if !is_file_name(&name) {
        state.status_key = "files.status.invalid_name".into();
        return;
    }
    if note.trim().is_empty() {
        state.status_key = "files.status.empty_note".into();
        return;
    }
    let location = FileSystemLocation::directory(directory.id, name);
    state.busy = true;
    state.error = None;
    state.written_bytes = None;
    state.status_key = "files.status.writing".into();

    let ok = cx.effects.bind(NoteWritten, reduce_with!(note_written));
    let err = cx.effects.bind(WriteFailed, reduce_with!(write_failed));
    cx.effects.file_system().write(WriteFileRequest {
        location,
        source: FileWriteSource::Bytes(note.into_bytes()),
        create_parents: false,
        overwrite: false,
    }).on_ok(ok).on_err(err);
}

#[fission_reducer(NoteWritten)]
pub fn note_written(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.written_bytes = cx.input.capability_ok(WRITE_FILE).map(|result| result.byte_len);
    state.status_key = if state.written_bytes.is_some() {
        "files.status.written"
    } else {
        "files.status.unexpected"
    }.into();
}

#[fission_reducer(WriteFailed)]
pub fn write_failed(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.status_key = "files.status.failed".into();
```

```rust
use fission::core::{DataStreamId, JobCtx, JobRef, JobSpec};
use serde::{Deserialize, Serialize};

#[derive(Clone, Debug, Serialize, Deserialize)]
pub struct ReportRequest {
    pub stream: DataStreamId,
}

#[derive(Clone, Debug, PartialEq, Serialize, Deserialize)]
pub struct ReportSummary {
    pub bytes: u64,
    pub lines: u64,
}

pub struct InspectReport;
impl JobSpec for InspectReport {
    type Request = ReportRequest;
    type Ok = ReportSummary;
    type Err = String;
    const NAME: &'static str = "inspection.files.inspect-report";
}
pub const INSPECT_REPORT: JobRef<InspectReport> = JobRef::new(InspectReport::NAME);

pub async fn inspect_report(request: ReportRequest, cx: JobCtx) -> Result<ReportSummary, String> {
    let mut stream = cx.open_data_stream(request.stream).map_err(|error| error.to_string())?;
    let mut bytes = 0_u64;
    let mut lines = 0_u64;
    let mut ends_with_newline = true;

    while let Some(chunk) = std::future::poll_fn(|cx| stream.as_mut().poll_next(cx)).await {
        let chunk = chunk.map_err(|error| error.to_string())?;
        bytes = bytes.checked_add(chunk.len() as u64).ok_or("Report is too large")?;
        lines = lines.checked_add(chunk.iter().filter(|byte| **byte == b'\n').count() as u64)
            .ok_or("Report has too many lines")?;
        if !chunk.is_empty() {
            ends_with_newline = chunk.ends_with(b"\n");
        }
    }
    if bytes > 0 && !ends_with_newline {
        lines = lines.checked_add(1).ok_or("Report has too many lines")?;
    }
    Ok(ReportSummary { bytes, lines })
}
```

There are three useful boundaries here. Text drafts belong to the component; the selected directory and completed operation results belong to shared state; stream processing belongs to the asynchronous job. The job receives a stream identifier, not a live component or reducer context.

Only one operation is admitted at a time. The screen disables its controls whilst it is busy, and the reducers check that condition too. As a result, a late report result cannot replace a result for a newly selected folder. A screen that permits concurrent reads would instead need an operation identity and stale-result checks.

File-name validation deliberately accepts one name, not an arbitrary relative path. This is an application input rule, not a replacement for the provider's access enforcement. The line counter counts newline-delimited records, including a final non-empty line without a newline; it does not parse Markdown or assume the report is valid UTF-8.

```rust
use crate::jobs::{ReportRequest, ReportSummary, INSPECT_REPORT};
use fission::prelude::*;

#[derive(Clone, Debug, PartialEq)]
pub struct FilesState {
    pub directory: Option<DirectoryHandle>,
    pub busy: bool,
    pub status_key: String,
    pub error: Option<String>,
    pub summary: Option<ReportSummary>,
    pub written_bytes: Option<u64>,
}

impl Default for FilesState {
    fn default() -> Self {
        Self {
            directory: None,
            busy: false,
            status_key: "files.status.choose".into(),
            error: None,
            summary: None,
            written_bytes: None,
        }
    }
}
impl GlobalState for FilesState {}

pub fn choose_directory(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    if state.busy {
        return;
    }
    state.busy = true;
    state.error = None;
    state.status_key = "files.status.choosing".into();

    let ok = cx.effects.bind(DirectoryChosen, reduce_with!(directory_chosen));
    let err = cx.effects.bind(DirectoryFailed, reduce_with!(directory_failed));
    cx.effects.file_system()
        .pick_directory(PickDirectoryRequest {
            access: FileSystemAccessMode::ReadWrite,
            persistence_key: None,
        })
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(DirectoryChosen)]
pub fn directory_chosen(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.status_key = "files.status.unexpected".into();
    if let Some(result) = cx.input.capability_ok(PICK_DIRECTORY) {
        if let Some(directory) = result.directory {
            state.directory = Some(directory);
            state.summary = None;
            state.written_bytes = None;
            state.status_key = "files.status.selected".into();
        } else {
            state.status_key = "files.status.cancelled".into();
        }
    }
}

#[fission_reducer(DirectoryFailed)]
pub fn directory_failed(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.status_key = "files.status.failed".into();
    state.error = cx.input.capability_error(PICK_DIRECTORY)
        .map(|error| format!("{}: {}", error.code, error.message))
        .or_else(|| cx.input.capability_error_message(PICK_DIRECTORY).map(str::to_owned));
}

pub fn is_file_name(name: &str) -> bool {
    !name.is_empty()
        && name == name.trim()
        && name != "."
        && name != ".."
        && !name.chars().any(|ch| matches!(ch, '/' | '\\' | ':' | '\0'))
}

pub fn read_report(state: &mut FilesState, name: String, cx: &mut ReducerContext<FilesState>) {
    if state.busy {
        return;
    }
    let Some(directory) = state.directory.as_ref() else {
        state.status_key = "files.status.choose".into();
        return;
    };
    if !is_file_name(&name) {
        state.status_key = "files.status.invalid_name".into();
        return;
    }
    let location = FileSystemLocation::directory(directory.id, name);
    state.busy = true;
    state.error = None;
    state.summary = None;
    state.status_key = "files.status.reading".into();

    let ok = cx.effects.bind(ReportOpened, reduce_with!(report_opened));
    let err = cx.effects.bind(ReadFailed, reduce_with!(read_failed));
    cx.effects.file_system().read(ReadFileRequest { location }).on_ok(ok).on_err(err);
}

#[fission_reducer(ReportOpened)]
pub fn report_opened(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    let Some(result) = cx.input.capability_ok(READ_FILE) else {
        state.busy = false;
        state.status_key = "files.status.unexpected".into();
        return;
    };
    let ok = cx.effects.bind(ReportInspected, reduce_with!(report_inspected));
    let err = cx.effects.bind(InspectionFailed, reduce_with!(inspection_failed));
    cx.effects.app(INSPECT_REPORT, ReportRequest { stream: result.stream }).on_ok(ok).on_err(err);
}

#[fission_reducer(ReadFailed)]
pub fn read_failed(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.status_key = "files.status.failed".into();
    state.error = cx.input.capability_error(READ_FILE)
        .map(|error| format!("{}: {}", error.code, error.message))
        .or_else(|| cx.input.capability_error_message(READ_FILE).map(str::to_owned));
}

#[fission_reducer(ReportInspected)]
pub fn report_inspected(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.summary = cx.input.job_ok(INSPECT_REPORT);
    state.status_key = if state.summary.is_some() {
        "files.status.read"
    } else {
        "files.status.unexpected"
    }.into();
}

#[fission_reducer(InspectionFailed)]
pub fn inspection_failed(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.status_key = "files.status.failed".into();
    state.error = cx.input.job_err(INSPECT_REPORT)
        .or_else(|| cx.input.job_error_message(INSPECT_REPORT).map(str::to_owned));
}

pub fn export_note(
    state: &mut FilesState,
    name: String,
    note: String,
    cx: &mut ReducerContext<FilesState>,
) {
    if state.busy {
        return;
    }
    let Some(directory) = state.directory.as_ref() else {
        state.status_key = "files.status.choose".into();
        return;
    };
    if !is_file_name(&name) {
        state.status_key = "files.status.invalid_name".into();
        return;
    }
    if note.trim().is_empty() {
        state.status_key = "files.status.empty_note".into();
        return;
    }
    let location = FileSystemLocation::directory(directory.id, name);
    state.busy = true;
    state.error = None;
    state.written_bytes = None;
    state.status_key = "files.status.writing".into();

    let ok = cx.effects.bind(NoteWritten, reduce_with!(note_written));
    let err = cx.effects.bind(WriteFailed, reduce_with!(write_failed));
    cx.effects.file_system().write(WriteFileRequest {
        location,
        source: FileWriteSource::Bytes(note.into_bytes()),
        create_parents: false,
        overwrite: false,
    }).on_ok(ok).on_err(err);
}

#[fission_reducer(NoteWritten)]
pub fn note_written(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.written_bytes = cx.input.capability_ok(WRITE_FILE).map(|result| result.byte_len);
    state.status_key = if state.written_bytes.is_some() {
        "files.status.written"
    } else {
        "files.status.unexpected"
    }.into();
}

#[fission_reducer(WriteFailed)]
pub fn write_failed(state: &mut FilesState, cx: &mut ReducerContext<FilesState>) {
    state.busy = false;
    state.status_key = "files.status.failed".into();
    state.error = cx.input.capability_error(WRITE_FILE)
        .map(|error| format!("{}: {}", error.code, error.message))
        .or_else(|| cx.input.capability_error_message(WRITE_FILE).map(str::to_owned));
}
```

The simulator run does not establish that an iPhone's Files providers and permissions behave the same way. Create an `inspection.md` file in an accessible folder in Files, then install a development-signed build on an iPhone using the linked device guide. Packaging requires the Apple signing setup described there:

```sh

```

Install through Xcode's Devices and Simulators window. Do not treat a successful simulator launch as a physical-device check.

Check an empty report, a report whose final line has no newline, cancellation and a missing document. Where your provider allows it, also check read-only access or a location that becomes unavailable. Each failure must stop the spinner and leave the note draft available for a retry. Open an exported note in another app and compare its contents; a success label alone is not verification.

This leaves the app with a working document boundary, not a full inspection system. Persistent access restoration, background uploads and an audit trail each introduce different ownership and failure requirements. Add them when the workflow needs them rather than suggesting that a directory picker provides them automatically.

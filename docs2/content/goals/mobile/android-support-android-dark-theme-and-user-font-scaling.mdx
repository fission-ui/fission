## Create the project and add the target

Create the project and add the target used by this guide. Fission generates the native host; the app and its behaviour stay in shared Rust code.

```sh
cargo install cargo-fission
fission init android-support-android-dark-theme-and-user-font-scaling
cd android-support-android-dark-theme-and-user-font-scaling
cargo add serde_yaml
fission add-target android --project-dir .
```

## Files created by Fission

This is the starter tree Fission generates. Keep shared app code in `src/`; the generated platform files handle native launch and packaging.

```text
android-support-android-dark-theme-and-user-font-scaling/
├── Cargo.toml                 # Rust package and dependencies
├── fission.toml               # app identity, targets and capabilities
├── src/
│   ├── main.rs                # generated app entrypoint
│   ├── lib.rs                 # shared app setup
│   └── app.rs                 # shared Fission screen
└── platforms/
    └── android/              # generated Android host
```

Keep the screen, shared state, reducers and reusable `fission_component!` components in the Rust project. Add a feature-specific state, service or effect module only when it gives the feature a useful boundary. The generated platform files handle native launch and packaging; shared components do not need to import platform APIs.

```rust
use fission::prelude::*;

fission_component! {
    pub AndroidSupportAndroidDarkThemeAndUserFontScaling<()> {
        state {
            large_text: bool = false,
        }
    }
    view(screen, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let reading_size = if screen.large_text {
            tokens.typography.body_medium_size * 1.4
        } else {
            tokens.typography.body_medium_size
        };
        let status = if screen.large_text {
            cx.tr("preview.status.done")
        } else {
            cx.tr("preview.status.ready")
        };
        let action = if screen.large_text {
            cx.tr("preview.action.undo")
        } else {
            cx.tr("preview.action.start")
        };
    } =>
    SemanticsRegion(
        identifier: Some("android-support-android-dark-theme-and-user-font-scaling".to_string()),
        label: Some(cx.tr("preview.title")),
        child: Container(
            Column(gap: tokens.spacing.m, children: [
                Row(gap: tokens.spacing.m, align_items: ir_op::AlignItems::Center, children: [
                    Column(gap: tokens.spacing.xs, children: [
                        Text(cx.tr("preview.app.name"))
                            .weight(tokens.typography.font_weight_bold),
                        Text(cx.tr("preview.route"))
                            .color(tokens.colors.text_secondary),
                    ]),
                    Spacer(flex_grow: 1.0),
                    Badge(text: status),
                ]),
                Divider(),
                Text(cx.tr("preview.title"))
                    .size(tokens.typography.heading2_size),
                Text(cx.tr("preview.summary"))
                    .color(tokens.colors.text_secondary),
                Container(
                    Column(gap: tokens.spacing.s, children: [
                        Text(cx.tr("preview.context.title"))
                            .weight(tokens.typography.font_weight_semibold),
                        Text(cx.tr("preview.context.one")).size(reading_size),
                        Text(cx.tr("preview.context.two")).size(reading_size),
                        Text(cx.tr("preview.result"))
                            .size(reading_size)
                            .color(tokens.colors.text_secondary),
                    ])
                )
                .padding_all(tokens.spacing.m)
                .bg(tokens.colors.background)
                .border(tokens.colors.border, 1.0)
                .border_radius(tokens.radii.medium),
                Button(
                    child: Text(action),
                    key: "large_text",
                    variant: ButtonVariant::Primary,
                    on_press: reduce {
                        screen.large_text = !screen.large_text;
                    },
                ),
                Text(if screen.large_text {
                    cx.tr("preview.state.active")
                } else {
                    cx.tr("preview.state.idle")
                })
                .color(tokens.colors.text_secondary),
            ])
        )
        .padding_all(tokens.spacing.l)
        .bg(tokens.colors.surface)
        .border(tokens.colors.border, 1.0)
        .border_radius(tokens.radii.large),
    )
}
```

```rust
mod app;

use fission::prelude::*;
use wasm_bindgen::prelude::*;

fn load_bundle(locale: &str, source: &str) -> TranslationBundle {
    TranslationBundle {
        locale: Locale::from(locale),
        messages: serde_yaml::from_str(source).expect("valid tutorial translations"),
    }
}

fn preview_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    env.i18n
        .add_bundle(load_bundle("en-US", include_str!("i18n/en-US.yaml")));
    env.i18n
        .add_bundle(load_bundle("es-ES", include_str!("i18n/es-ES.yaml")));
    env
}

#[wasm_bindgen(start)]
pub fn run() -> Result<(), JsValue> {
    console_error_panic_hook::set_once();
    WebApp::<(), _>::new(app::AndroidSupportAndroidDarkThemeAndUserFontScaling)
        .with_env(preview_env())
        .with_title("Northbank Field Service")
        .mount("#fission-web-mount")
        .run()
        .map_err(|error| JsValue::from_str(&error.to_string()))
}
```

## Support Android dark theme and user font scaling

Read colours, type sizes, spacing and component properties from the active design-system tokens rather than maintaining parallel light/dark constants in each component. Store a user theme override in GlobalState and mirror it into Env; let system appearance apply when the preference is Automatic. Keep layouts flexible when text grows, and do not truncate essential labels to fit a fixed card. Test light, dark, high contrast and the largest supported font scale on a real target.

## Check the layout and system settings on Android

Run the same screen at a narrow phone width and a wider window. Resize or rotate while it is open, then change the system text size and appearance where this tutorial covers them. Content should reflow without clipping essential controls or status messages.

Use real platform insets for safe-area checks and let Fission’s responsive layout choose the arrangement. Avoid fixing a problem with device-specific padding that breaks the other sizes.

### Run, test and build

```sh
cargo test
fission doctor android --project-dir .
fission run --target android --project-dir .
fission test --target android --project-dir .
fission build --target android --project-dir . --release
```

`cargo test` runs Rust tests you add; the generated scaffold does not create feature-specific tests. `fission doctor` reports missing Android tools, `fission run` launches the selected emulator or connected device, and `fission test` checks that the generated host can start. A release build checks packaging, but none of these commands proves a physical permission or hardware flow works.

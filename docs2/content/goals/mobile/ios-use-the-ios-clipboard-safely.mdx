A clipboard is shared with other applications. That makes copying a public work reference a different operation from copying the entire screen, which may contain a private note. The safest boundary is to make the copy action receive only the field that is meant to leave the app.

We will build a screen where the user enters both values. One explicit action copies the reference; another explicitly reads clipboard text. The private note remains local UI memory and never becomes an argument to the clipboard effect. There are no startup reads, automatic polling or simulated clipboard providers.

## Create the project and add the target

Complete [iOS setup](/blog/set-up-rust-ios-development-with-fission/) first. Clipboard text is available through the normal shell, so this example does not add a capability declaration.

```sh
cargo install cargo-fission
fission init ios-use-the-ios-clipboard-safely
cd ios-use-the-ios-clipboard-safely
fission add-target ios --project-dir .
cargo add serde_yaml
```

Keep the generated `src/main.rs` and replace `src/lib.rs` below. The normal native and Web launchers must install the same shared app as the preview, not leave the generated counter running.

## Make the copied field an explicit input

The reference belongs to shared hand-off state. The private note belongs to this screen's retained local state; other screens and the clipboard service do not need access to it. That separation prevents accidental inclusion in the copy request without requiring the service to filter a whole work-order object.

use fission::prelude::*;

#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub enum ClipboardStatus {
    #[default]
    Idle,
    Writing,
    Reading,
    WriteAccepted,
    ReadText,
    Empty,
    Failed,
    InvalidResult,
}

impl ClipboardStatus {
    pub fn pending(&self) -> bool {
        matches!(self, Self::Writing | Self::Reading)
    }

    pub fn message_key(&self) -> &'static str {
        match self {
            Self::Idle => "clipboard.idle",
            Self::Writing => "clipboard.writing",
            Self::Reading => "clipboard.reading",
            Self::WriteAccepted => "clipboard.write_accepted",
            Self::ReadText => "clipboard.read_text",
            Self::Empty => "clipboard.empty",
            Self::Failed => "clipboard.failed",
            Self::InvalidResult => "clipboard.invalid",
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct ClipboardState {
    pub public_reference: String,
    pub last_pasted: Option<String>,
    pub status: ClipboardStatus,
    pub locale: Locale,
}

impl Default for ClipboardState {
    fn default() -> Self {
        Self {
            public_reference: String::new(),
            last_pasted: None,
            status: ClipboardStatus::Idle,
            locale: Locale::from("en-US"),
        }
    }
}

impl GlobalState for ClipboardState {}

pub fn copy_reference(state: &mut ClipboardState, cx: &mut ReducerContext<ClipboardState>) {
    if state.status.pending() || state.public_reference.trim().is_empty() {
        return;
    }
    state.status = ClipboardStatus::Writing;
    let ok = cx
        .effects
        .bind(CopyAccepted, reduce_with!(on_copy_accepted));
    let err = cx.effects.bind(CopyFailed, reduce_with!(on_copy_failed));
    cx.effects
        .clipboard()
        .write_text(ClipboardWriteTextRequest {
            text: state.public_reference.clone(),
        })
        .on_ok(ok)
        .on_err(err);
}

pub fn paste_reference(state: &mut ClipboardState, cx: &mut ReducerContext<ClipboardState>) {
    if state.status.pending() {
        return;
    }
    state.status = ClipboardStatus::Reading;
    let ok = cx
        .effects
        .bind(PasteReceived, reduce_with!(on_paste_received));
    let err = cx.effects.bind(PasteFailed, reduce_with!(on_paste_failed));
    cx.effects.clipboard().read_text().on_ok(ok).on_err(err);
}

#[fission_reducer(CopyAccepted)]
fn on_copy_accepted(state: &mut ClipboardState, cx: &mut ReducerContext<ClipboardState>) {
    state.status = if cx.input.capability_ok(WRITE_CLIPBOARD_TEXT).is_some() {
        ClipboardStatus::WriteAccepted
    } else {
        ClipboardStatus::InvalidResult
    };
}

#[fission_reducer(CopyFailed)]
fn on_copy_failed(state: &mut ClipboardState, cx: &mut ReducerContext<ClipboardState>) {
    state.status = if cx.input.capability_error(WRITE_CLIPBOARD_TEXT).is_some() {
        ClipboardStatus::Failed
    } else {
        ClipboardStatus::InvalidResult
    };
}

#[fission_reducer(PasteReceived)]
fn on_paste_received(state: &mut ClipboardState, cx: &mut ReducerContext<ClipboardState>) {
    let Some(result) = cx.input.capability_ok(READ_CLIPBOARD_TEXT) else {
        state.status = ClipboardStatus::InvalidResult;
        return;
    };
    state.last_pasted = result.text.filter(|text| !text.is_empty());
    state.status = if state.last_pasted.is_some() {
        ClipboardStatus::ReadText
    } else {
        ClipboardStatus::Empty
    };
}

#[fission_reducer(PasteFailed)]
fn on_paste_failed(state: &mut ClipboardState, cx: &mut ReducerContext<ClipboardState>) {
    state.status = if cx.input.capability_error(READ_CLIPBOARD_TEXT).is_some() {
        ClipboardStatus::Failed
    } else {
        ClipboardStatus::InvalidResult
    };
}

use super::state::{copy_reference, paste_reference, ClipboardState};
use fission::prelude::*;

fission_component! {
    pub ClipboardScreen<ClipboardState> {
        state {
            private_note: String = String::new(),
        }
    }
    view(screen, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let pending = state.status.pending();
    } => SafeArea(
        child: Scroll(
            child: Container(
                Column(gap: tokens.spacing.m, children: [
                    Text(cx.tr("clipboard.title"))
                        .size(tokens.typography.heading2_size),
                    Text(cx.tr("clipboard.explanation"))
                        .color(tokens.colors.text_secondary),
                    Row(gap: tokens.spacing.s, children: [
                        Button(
                            child: Text(cx.tr("language.english")),
                            key: "english",
                            on_press: reduce { state.locale = Locale::from("en-US"); },
                        ),
                        Button(
                            child: Text(cx.tr("language.spanish")),
                            key: "spanish",
                            on_press: reduce { state.locale = Locale::from("es-ES"); },
                        ),
                    ]),
                    FormControl(
                        label: Some(cx.tr("clipboard.reference")),
                        required: true,
                        child: TextInput(
                            value: state.public_reference.clone(),
                            bind(on_input): to(state.public_reference),
                            semantics_identifier: Some("clipboard.reference".into()),
                        ),
                    ),
                    TextInput(
                        value: screen.private_note.clone(),
                        bind(on_input): to(screen.private_note),
                        label: Some(TextContent::Key("clipboard.private_note".into())),
                        helper_text: Some(TextContent::Key("clipboard.private_help".into())),
                        multiline: true,
                        semantics_identifier: Some("clipboard.private-note".into()),
                    ),
                    Button(
                        child: Text(cx.tr("clipboard.copy")),
                        key: "copy-reference",
                        disabled: pending || state.public_reference.trim().is_empty(),
                        on_press: reduce { copy_reference(state, cx); },
                    ),
                    Button(
                        child: Text(cx.tr("clipboard.paste")),
                        key: "paste-reference",
                        disabled: pending,
                        on_press: reduce { paste_reference(state, cx); },
                    ),
                    if pending {
                        Spinner(
                            motion: Some(SpinnerMotion::Default),
                            label: Some(cx.tr(state.status.message_key())),
                        )
                    },
                    Text(cx.tr(state.status.message_key())),
                    if let Some(text) = &state.last_pasted {
                        Column(gap: tokens.spacing.s, children: [
                            Text(cx.tr("clipboard.last_pasted")),
                            TextInput(
                                value: text.clone(),
                                read_only: true,
                                multiline: true,
                                label: Some(TextContent::Key("clipboard.pasted_text".into())),
                            ),
                        ])
                    },
                ]),
            )
            .padding_all(tokens.spacing.l)
            .bg(tokens.colors.surface),
        ),
    )
}

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid clipboard translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

pub fn sync_env(state: &crate::app::ClipboardState, env: &mut Env) {
    env.locale = state.locale.clone();
}

## Keep consent, requests and completions separate

Copying queues `WRITE_CLIPBOARD_TEXT` with the public reference alone. Reading queues `READ_CLIPBOARD_TEXT` only after the user's action. Both bind unit completion actions through `cx.effects.bind`, and their reducers inspect the typed `cx.input`. The host does not return clipboard contents through a made-up action constructor.

The status prevents overlapping clipboard operations and the real spinner describes pending work. A failure preserves the reference, private note and last successful read. The last-read label matters: keeping an older value without identifying it could imply a failed read returned fresh text.

On iOS, the shell uses `UIPasteboard`. On Web, the normal host uses the browser's clipboard API, whose secure-context, user-activation and permission rules still apply. A browser or embedded frame can reject access; this example does not bypass that policy. It does not install `MemoryClipboardHost`.

The current native text provider can retain an in-process fallback when the system clipboard cannot be read, and a write acknowledgement is not an independent cross-app readback. Therefore treat the result as a host operation result, not a verified guarantee that another application can retrieve the text. Verify that behavior separately on the target.

## Check the real iOS hand-off

Use [the simulator workflow](/blog/choose-boot-and-launch-an-ios-simulator-with-fission/) and [physical iPhone installation](/blog/install-a-fission-app-on-a-physical-iphone/) for target setup rather than repeating signing instructions here.

```sh
fission doctor ios --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
```

Copy nonsensitive text in the app and paste it into a separate app. Then copy text elsewhere and explicitly read it in this screen. Confirm that an empty clipboard or an access failure does not replace the private note or reference. On an iPhone, check any system paste disclosure rather than assuming the simulator's behavior proves it.

Do not use this flow for passwords, authentication tokens or a promise of clipboard secrecy. The app does not implement an expiry policy, cross-device clipboard restrictions or secure erasure. Its narrower guarantee is visible in the code: the private note is never passed to the copy effect.

Test blank references, rapid presses, a language change and failed reads over a previous successful result. Native, Web and cross-app tests establish different evidence; compilation alone establishes none of the clipboard interactions.

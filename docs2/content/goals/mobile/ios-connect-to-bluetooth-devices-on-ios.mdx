A probe's printed label can identify a draft inspection, but it cannot stand in for a Bluetooth measurement. Keeping those meanings separate lets the technician continue a legitimate manual step without making the app claim work it has not done.

Fission's default iOS host has no Bluetooth provider. This page's stated goal is to handle that unsupported path and retain a validated manual label, not to implement native Bluetooth. The example deliberately uses the same unsupported provider on Web, so its preview cannot create a misleading successful scan.

## Create the app

Complete [iOS setup](/blog/set-up-rust-ios-development-with-fission/) if needed.

```sh
cargo install cargo-fission
fission init northbank-ios-probe-check
cd northbank-ios-probe-check
fission add-target ios --project-dir .
cargo add serde_yaml
```

No Bluetooth permission is requested by this unsupported provider. Installing an actual provider later requires its own capability configuration, privacy setup and device checks; that work is not supplied by the manual label field.

Keep the generated `src/main.rs`. The normal shared library below starts the same screen and providers as the documentation preview.

## Model outcomes which cannot contradict each other

One `ScanStatus` replaces a collection of independent pending, complete, failed and unsupported booleans. The screen cannot therefore be both scanning and successfully finished because one callback forgot to clear a flag.

The manual draft belongs to the component. Its confirmed label belongs to application state for the next local workflow step. The label rule rejects empty, excessively long or control-character input; it does not establish that a physical probe exists or that the user selected the correct one.

use fission::prelude::*;

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum ScanStatus {
    Idle,
    Pending,
    Unsupported,
    Failed,
    Returned(Vec<BluetoothDevice>),
}

impl ScanStatus {
    pub fn key(&self) -> &'static str {
        match self {
            Self::Idle => "probe.idle",
            Self::Pending => "probe.pending",
            Self::Unsupported => "probe.unsupported",
            Self::Failed => "probe.failed",
            Self::Returned(devices) if devices.is_empty() => "probe.empty",
            Self::Returned(_) => "probe.returned",
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct ProbeState {
    pub locale: Locale,
    pub scan: ScanStatus,
    pub error: Option<String>,
    pub confirmed_label: Option<String>,
}

impl Default for ProbeState {
    fn default() -> Self {
        Self {
            locale: Locale::from("en-US"),
            scan: ScanStatus::Idle,
            error: None,
            confirmed_label: None,
        }
    }
}
impl GlobalState for ProbeState {}

pub fn valid_label(label: &str) -> bool {
    let label = label.trim();
    !label.is_empty() && label.chars().count() <= 64 && !label.chars().any(char::is_control)
}

pub fn scan(state: &mut ProbeState, cx: &mut ReducerContext<ProbeState>) {
    if state.scan == ScanStatus::Pending {
        return;
    }
    state.scan = ScanStatus::Pending;
    state.error = None;
    let ok = cx.effects.bind(ScanReturned, reduce_with!(scan_returned));
    let err = cx.effects.bind(ScanFailed, reduce_with!(scan_failed));
    cx.effects
        .bluetooth()
        .scan_devices(BluetoothScanRequest {
            service_uuids: vec!["0000181a-0000-1000-8000-00805f9b34fb".into()],
            timeout_ms: Some(4_000),
            include_paired: true,
            allow_duplicates: false,
        })
        .on_ok(ok)
        .on_err(err);
}

#[fission_reducer(ScanReturned)]
fn scan_returned(state: &mut ProbeState, cx: &mut ReducerContext<ProbeState>) {
    state.scan = match cx.input.capability_ok(SCAN_BLUETOOTH_DEVICES) {
        Some(result) => ScanStatus::Returned(result.devices),
        None => ScanStatus::Failed,
    };
}

#[fission_reducer(ScanFailed)]
fn scan_failed(state: &mut ProbeState, cx: &mut ReducerContext<ProbeState>) {
    let error = cx.input.capability_error(SCAN_BLUETOOTH_DEVICES);
    state.scan = if error
        .as_ref()
        .is_some_and(|error| error.code == "unsupported")
    {
        ScanStatus::Unsupported
    } else {
        ScanStatus::Failed
    };
    state.error = error
        .map(|error| format!("{}: {}", error.code, error.message))
        .or_else(|| {
            cx.input
                .capability_error_message(SCAN_BLUETOOTH_DEVICES)
                .map(str::to_owned)
        });
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn label_rule_accepts_text_not_a_fake_probe_read() {
        assert!(valid_label(" CR-204 "));
        assert!(valid_label("Sonda Álvarez"));
        assert!(!valid_label(" "));
        assert!(!valid_label("probe\nsecond-line"));
        assert!(!valid_label(&"x".repeat(65)));
    }
}

use super::state::{scan, valid_label, ProbeState, ScanStatus};
use fission::prelude::*;

fission_component! {
    pub ProbeScreen<ProbeState> {
        state {
            label: String = String::new(),
            attempted: bool = false,
        }
    }
    view(form, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let error = (form.attempted && !valid_label(&form.label))
            .then(|| cx.tr("probe.invalid_label"));
    } => SafeArea(
        child: Scroll(
            child: Container(Column(gap: tokens.spacing.m, children: [
                Text(cx.tr("probe.heading")).size(tokens.typography.heading2_size),
                Text(cx.tr("probe.explanation")),
                Row(gap: tokens.spacing.s, children: [
                    Button(
                        child: Text(cx.tr("language.english")), key: "english",
                        on_press: reduce { state.locale = Locale::from("en-US"); },
                    ),
                    Button(
                        child: Text(cx.tr("language.spanish")), key: "spanish",
                        on_press: reduce { state.locale = Locale::from("es-ES"); },
                    ),
                ]),
                Button(
                    child: Text(cx.tr("probe.scan")), key: "scan-probe",
                    disabled: state.scan == ScanStatus::Pending,
                    on_press: reduce { scan(state, cx); },
                ),
                if state.scan == ScanStatus::Pending {
                    Spinner(motion: Some(SpinnerMotion::Default), label: Some(cx.tr("probe.pending")))
                },
                Text(cx.tr(state.scan.key())),
                if let Some(error) = &state.error { Code(text: error.clone()) },
                if let ScanStatus::Returned(devices) = &state.scan {
                    Text(cx.tr("probe.count").replace("{count}", &devices.len().to_string()))
                },
                Divider(),
                FormControl(
                    label: Some(cx.tr("probe.label")),
                    helper: Some(cx.tr("probe.label_help")),
                    error: error, required: true,
                    child: TextInput(
                        value: form.label.clone(), bind(on_input): to(form.label),
                        semantics_identifier: Some("probe.label".into()),
                    ),
                ),
                Button(
                    child: Text(cx.tr("probe.confirm")), key: "confirm-label",
                    on_press: reduce {
                        form.attempted = true;
                        if valid_label(&form.label) {
                            state.confirmed_label = Some(form.label.trim().to_owned());
                        }
                    },
                ),
                if let Some(label) = &state.confirmed_label {
                    Column(gap: tokens.spacing.s, children: [
                        Text(cx.tr("probe.confirmed")),
                        Text(label.clone()),
                    ])
                },
                Text(cx.tr("probe.session")).color(tokens.colors.text_secondary),
            ]))
            .padding_all(tokens.spacing.l),
        ),
    )
}

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid probe translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

pub fn sync_env(state: &crate::app::ProbeState, env: &mut Env) {
    env.locale = state.locale.clone();
}

## Keep discovery, connection and measurement separate

The reducer requests the typed scan and binds unit completion actions. Each completion decodes its actual `cx.input`. A supported custom host may return devices later, but those records are not a connection handle or a temperature sample.

The request filters for the Environmental Sensing service. It is not a guarantee that every discovered device has the expected measurement format. A complete sensor workflow would still need a real iOS provider, permission handling, connection, characteristic selection, decoding and disconnection.

The normal launchers explicitly install `UnsupportedBluetoothHost` to keep this tutorial's fallback deterministic across targets without simulating success. Do not leave that override in an app which is supposed to use a real installed Bluetooth provider. Replace it as part of the separately qualified integration, not as a silent preview trick.

## Verify the fallback on iOS before adding a provider

```sh
cargo test
fission doctor ios --project-dir .
fission devices --project-dir .
fission run --target ios --project-dir .
fission test --target ios --project-dir .
```

Use [the simulator guide](/blog/choose-boot-and-launch-an-ios-simulator-with-fission/) for selection. The included test checks the app-owned label rule; the simulator can check this unsupported flow and the form. It cannot prove radio discovery or sensor accuracy.

Check the field label and error with VoiceOver, both languages and larger text. `FormControl` supplies the visible and semantic validation relationship instead of drawing an error beneath an unrelated input.

If you add an actual Bluetooth host, follow [the iPhone installation guide](/blog/install-a-fission-app-on-a-physical-iphone/) and qualify its permission, no-device, disconnection and device-specific measurement paths. Keep test providers inside test infrastructure. A memory host returning a convincing probe name does not implement that native work.

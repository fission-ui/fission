## Give the dispatcher a report they can reason about

A punctuality chart is useful only if its percentages mean the same thing. Averaging a quiet day's rate with a busy day's rate gives both days equal weight, even though they represent different numbers of departures. A fleet headline needs the total on-time departures divided by the total scheduled departures.

This dashboard imports actual route/day counts and derives both the written review and chart from them. It does not invent a live shift, delayed vehicles or reasons for disruption. A route with late departures is a reason to inspect the source report, not evidence that the app knows which vehicle needs dispatching.

Complete the [iOS development setup](/blog/set-up-rust-ios-development-with-fission/) before using Xcode's Simulator or a connected phone. Run iOS build commands on macOS with the required Apple tooling.

## Import one report atomically

The import has four tab-separated columns, without a header:

```text
days_ago    route    scheduled    on_time
```

The spaces above describe the columns; the input requires actual tab separators. Day 0 is the supplied report's endpoint, not the computer's current date. All rows must use that same endpoint and the same definition of on-time, such as departures within the operator's agreed five-minute window.

Each route/day pair occurs once. Counts must be non-negative, scheduled departures must be positive, and on-time departures cannot exceed them. Validation builds a new report first; one bad row leaves the existing report intact. The bounds are intentional: 30 days, 1,000 rows and 128 KiB of input.

use std::collections::{BTreeMap, BTreeSet};
use fission::prelude::*;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct DepartureDay {
    pub days_ago: u8,
    pub route: String,
    pub scheduled: u32,
    pub on_time: u32,
}
#[derive(Debug, Clone)]
pub struct TransitReport { pub endpoint: String, pub rows: Vec<DepartureDay> }
#[derive(Debug, Default)]
pub struct TransitDashboardState {
    pub report: Option<TransitReport>,
    pub import_issue: Option<&'static str>,
}
impl GlobalState for TransitDashboardState {}

pub fn parse_report(endpoint: &str, raw: &str) -> Result<TransitReport, &'static str> {
    if endpoint.trim().is_empty() || endpoint.chars().count() > 80 || raw.len() > 128 * 1024 {
        return Err("transit.invalid");
    }
    let mut rows = Vec::new();
    let mut keys = BTreeSet::new();
    for line in raw.lines().filter(|line| !line.trim().is_empty()) {
        let fields: Vec<&str> = line.split('\t').collect();
        if fields.len() != 4 || rows.len() >= 1_000 { return Err("transit.invalid"); }
        let days_ago: u8 = fields[0].trim().parse().map_err(|_| "transit.invalid")?;
        let route = fields[1].trim();
        let scheduled: u32 = fields[2].trim().parse().map_err(|_| "transit.invalid")?;
        let on_time: u32 = fields[3].trim().parse().map_err(|_| "transit.invalid")?;
        if days_ago >= 30 || route.is_empty() || route.chars().count() > 64
            || scheduled == 0 || scheduled > 1_000_000 || on_time > scheduled
            || !keys.insert((days_ago, route.to_owned())) { return Err("transit.invalid"); }
        rows.push(DepartureDay { days_ago, route: route.to_owned(), scheduled, on_time });
    }
    if rows.is_empty() { return Err("transit.empty_import"); }
    Ok(TransitReport { endpoint: endpoint.trim().to_owned(), rows })
}

impl TransitDashboardState {
    pub fn import(&mut self, endpoint: &str, raw: &str) -> bool {
        match parse_report(endpoint, raw) {
            Ok(report) => { self.report = Some(report); self.import_issue = None; true }
            Err(key) => { self.import_issue = Some(key); false }
        }
    }
}

#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
pub struct Counts { pub scheduled: u64, pub on_time: u64 }
impl Counts {
    pub fn rate(self) -> Option<f32> {
        (self.scheduled > 0).then(|| self.on_time as f64 / self.scheduled as f64 * 100.0)
            .map(|value| value as f32)
    }
    fn add(&mut self, row: &DepartureDay) {
        self.scheduled += u64::from(row.scheduled);
        self.on_time += u64::from(row.on_time);
    }
}
impl TransitReport {
    pub fn daily_counts(&self, days: u8) -> BTreeMap<u8, Counts> {
        let mut grouped: BTreeMap<u8, Counts> = BTreeMap::new();
        for row in self.rows.iter().filter(|row| row.days_ago < days) {
            grouped.entry(row.days_ago).or_default().add(row);
        }
        grouped
    }
    pub fn chart_counts(&self, days: u8) -> BTreeMap<u8, Counts> {
        let step = if days == 30 { 5 } else { 1 };
        let mut grouped: BTreeMap<u8, Counts> = BTreeMap::new();
        for row in self.rows.iter().filter(|row| row.days_ago < days) {
            grouped.entry(row.days_ago / step).or_default().add(row);
        }
        grouped
    }
    pub fn routes(&self, days: u8) -> BTreeMap<String, Counts> {
        let mut grouped: BTreeMap<String, Counts> = BTreeMap::new();
        for row in self.rows.iter().filter(|row| row.days_ago < days) {
            grouped.entry(row.route.clone()).or_default().add(row);
        }
        grouped
    }
    pub fn counts(&self, days: u8) -> Counts {
        let mut counts = Counts::default();
        for row in self.rows.iter().filter(|row| row.days_ago < days) { counts.add(row); }
        counts
    }
}

#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn rates_weight_departures_and_ranges_include_the_oldest_day() {
        let report = parse_report("Reporting endpoint", "0\tA\t10\t10\n1\tB\t90\t0\n29\tA\t20\t20").unwrap();
        assert_eq!(report.counts(7).rate(), Some(10.0));
        assert_eq!(report.counts(30).scheduled, 120);
        assert_eq!(report.chart_counts(30).get(&0).unwrap().rate(), Some(10.0));
        assert_eq!(report.chart_counts(30).get(&5).unwrap().rate(), Some(100.0));
        assert_eq!(report.daily_counts(7).len(), 2);
        assert_eq!(report.daily_counts(30).len(), 3);
        assert_eq!(Counts::default().rate(), None);
    }
    #[test]
    fn invalid_replacement_preserves_the_previous_report() {
        let mut state = TransitDashboardState::default();
        assert!(state.import("First report", "0\tA\t10\t9"));
        assert!(!state.import("Invalid", "0\tA\t10\t11"));
        assert_eq!(state.report.as_ref().unwrap().endpoint, "First report");
        assert!(parse_report("Duplicate", "0\tA\t10\t9\n0\tA\t10\t9").is_err());
    }
}

    pub TransitSummary<TransitDashboardState> { props { days: u8 } }

                    RouteReviewRow(route.clone(), counts, key: route.clone())
                        .id(WidgetId::explicit(&format!("transit.route.{route}")))
                },
            ]),
        ])
    } else { Text(cx.tr("transit.empty")) }

## Plot the same counts without inventing missing days

The seven-day chart groups supplied route rows by day. At thirty days it uses six five-day buckets, so the labels remain readable on a phone. Each bar divides the on-time count by the scheduled count for its own bucket; the headline uses those counts across the whole selected window. It is not an arithmetic mean of bar heights. A label such as `29–25` means days 29 through 25 before the reporting endpoint.

A seven-day window includes offsets 0–6, and a thirty-day window includes 0–29. Four weekly samples would not be a thirty-day daily series. Missing days are omitted and coverage is shown, rather than drawing them as zero-percent punctuality. Missing routes within a supplied day remain a source-data limitation, so the display consistently says reported departures.

Only the page owns the retained range choice. It supplies that choice to the chart and written summary, preventing them from quietly describing different windows.

use fission::prelude::*;
use fission::charts::{Axis, BarSeries, Chart, Series};
use crate::state::TransitDashboardState;

fission_component! {
    pub RoutePunctualityTrend<TransitDashboardState> { props { days: u8 } }
    view(trend, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let daily = state.report.as_ref().map(|report| report.chart_counts(trend.days))
            .unwrap_or_default();
        let labels: Vec<String> = daily.keys().rev().map(|bucket| {
            if trend.days == 30 {
                format!("{}–{}", bucket * 5 + 4, bucket * 5)
            } else {
                cx.tr("transit.days_before").replace("{days}", &bucket.to_string())
            }
        }).collect();
        let rates: Vec<f32> = daily.values().rev().filter_map(|counts| counts.rate()).collect();
        let coverage = state.report.as_ref().map(|report| report.daily_counts(trend.days).len()).unwrap_or(0);
        let title = cx.tr("transit.chart");
        let series_label = cx.tr("transit.on_time");
    } =>
    if coverage == 0 {
        Text(cx.tr("transit.no_window"))
    } else {
        SemanticsRegion(
            identifier: Some("transit.punctuality".to_owned()),
            label: Some(cx.tr("transit.chart")),
            child: Column(gap: tokens.spacing.s, children: [
                Chart(
                    title: Some(title),
                    x_axis: Some(Axis::category(labels.iter().map(String::as_str).collect()).name(cx.tr("transit.day_axis"))),
                    y_axis: Some(Axis::value().min(0.0).max(100.0).name(cx.tr("transit.percent"))),
                    height: Some(300.0),
                    series: vec![Series::Bar(BarSeries::new(&series_label).data(rates))],
                ),
                Text(format!("{}: {coverage}/{}", cx.tr("transit.coverage"), trend.days)),
                Text(cx.tr("transit.missing")),
            ]),
        )
    }
}

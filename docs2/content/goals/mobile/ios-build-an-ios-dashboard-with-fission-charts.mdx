## Create the iOS project

Create the shared Rust app and add its iOS host:

```sh
cargo install cargo-fission
fission init ios-build-an-ios-dashboard-with-fission-charts
cd ios-build-an-ios-dashboard-with-fission-charts
fission add-target ios --project-dir .
cargo add fission@0.15.1 --features charts
cargo add serde_yaml
```

The generated host handles launch and packaging. Keep the dashboard and its state in shared Rust code; the browser preview and iOS app use the same components.

## Give the dispatcher a clear view of the shift

At 8:42, Central depot is preparing its next wave of departures. The dispatcher needs to know how many trips are scheduled, whether vehicles are leaving on time, and which routes need help. We’ll build that screen for Northstar Transit. The preview uses sample records in memory; it does not make a hidden service call.

Keep the screen focused on decisions. Three metrics summarise today’s operation, and the route review section gives the dispatcher a next step for the two most urgent items. `TransitMetric` and `RouteReviewRow` are named components because they are useful, reusable parts of this screen; they also keep the dashboard readable.

#[derive(Clone, Debug, PartialEq)]

    pub id: String,
    pub route_key: &'static str,
    pub departure_key: &'static str,
    pub detail_key: &'static str,
    pub status: RouteStatus,
}

    pub departures_today: u32,
    pub active_routes: u32,
    pub on_time_percent_today: u32,
    pub weekly_change_points: i32,
    pub active_delays: u32,
    pub routes_needing_review: u32,
    pub on_time_7_days: Vec<f32>,
    pub on_time_30_days: Vec<f32>,
    pub route_reviews: Vec<RouteRecord>,
}

#[derive(Clone, Debug, PartialEq)]
pub struct TransitDashboardState {
    pub locale: Locale,
    pub data: Option<TransitData>,
}

impl Default for TransitDashboardState {

        Self { locale: Locale::from("en-US"), data: None }

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

const EN_US: &str = include_str!("../i18n/en-US.yaml");
const ES_ES: &str = include_str!("../i18n/es-ES.yaml");

fn load_bundle(locale: &str, source: &str) -> anyhow::Result<TranslationBundle> {
    let messages: HashMap<String, String> = serde_yaml::from_str(source)?;
    Ok(TranslationBundle {
        locale: Locale::from(locale),
        messages,
    })
}

pub fn create_env() -> anyhow::Result<Env> {
    let mut env = Env::default();
    env.i18n.add_bundle(load_bundle("en-US", EN_US)?);
    env.i18n.add_bundle(load_bundle("es-ES", ES_ES)?);
    Ok(env)
}

## Compare on-time departures across a date range

The shift metrics show what is happening now. They don’t tell the dispatcher whether today is unusual. For that, we’ll plot the percentage of scheduled departures that left within five minutes. A percentage is more useful than a raw trip count because the number of scheduled services changes every day.

The **7 days** and **30 days** buttons select sample data for that window. The badge and sentence use the same values as the bars, so the chart and summary cannot drift apart when the range changes. This selection belongs to this component, so retained local state is the right fit. If several screens later share a date filter, move it into app state and load the matching data through an effect.

use crate::app::TransitOperationsDashboard;
use crate::state::TransitDashboardState;
use fission::prelude::*;
use fission::charts::axis::AxisType;
use fission::charts::{Axis, BarSeries, Chart, Legend, Tooltip};

fission_component! {
    pub RoutePunctualityTrend<TransitDashboardState> {
        props { width: f32 }
        state { thirty_days: bool = false }
    }
    view(trend, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let trend_data: Option<(u32, String, Widget)> = state.data.as_ref().map(|data| {
            let (labels, rates) = if trend.thirty_days {
                (
                    vec![cx.tr("chart.period.week1"), cx.tr("chart.period.week2"), cx.tr("chart.period.week3"), cx.tr("chart.period.week4")],
                    data.on_time_30_days.clone(),
                )
            } else {
                (
                    vec![cx.tr("chart.day.mon"), cx.tr("chart.day.tue"), cx.tr("chart.day.wed"), cx.tr("chart.day.thu"), cx.tr("chart.day.fri"), cx.tr("chart.day.sat"), cx.tr("chart.day.sun")],
                    data.on_time_7_days.clone(),
                )
            };
            let average = if rates.is_empty() {
                0
            } else {
                (rates.iter().sum::<f32>() / rates.len() as f32).round() as u32
            };
            let period = cx.tr(if trend.thirty_days { "chart.range.30" } else { "chart.range.7" });
            let chart_title = cx.tr("chart.title");
            let rate_label = cx.tr("chart.series.rate");
            let chart: Widget = Chart::new()
                .width(trend.width)
                .height(320.0)
                .title(&chart_title)
                .x_axis(Axis {
                    axis_type: AxisType::Category,
                    data: labels,
                    name: None,
                    min: None,
                    max: None,
                    boundary_gap: true,
                    inverse: false,
                    split_line: true,
                    label_rotate: None,
                })
                .y_axis(Axis::value().min(0.0).max(100.0))
                .legend(Legend::top_right())
                .tooltip(Tooltip::axis_trigger())
                .series(vec![fission::charts::Series::Bar(
                    BarSeries::new(&rate_label).data(rates),
                )])
                .into();
            (average, period, chart)
        });
    } =>
    if let Some((average, period, chart)) = trend_data {
        SemanticsRegion(
            identifier: Some("northstar-on-time-departures".to_string()),
            label: Some(cx.tr("chart.a11y")),
            child: Container(Column(gap: tokens.spacing.m, children: [
                Row(gap: tokens.spacing.m, align_items: ir_op::AlignItems::Center, children: [
                    Column(gap: tokens.spacing.xs, children: [
                        Text(cx.tr("chart.heading")).weight(tokens.typography.font_weight_semibold),
                        Text(cx.tr("chart.subtitle").replace("{period}", &period))
                            .color(tokens.colors.text_secondary),
                    ]),
                    Spacer(flex_grow: 1.0),
                    Badge(text: cx.tr("chart.average").replace("{percent}", &average.to_string())),
                ]),
                Row(gap: tokens.spacing.s, children: [
                    Button(
                        child: Text(cx.tr("chart.range.7")),
                        key: "range-seven-days",
                        variant: if trend.thirty_days { ButtonVariant::Outline } else { ButtonVariant::Primary },
                        on_press: reduce { trend.thirty_days = false; },
                    ).semantics_identifier("northstar.range.7-days"),
                    Button(
                        child: Text(cx.tr("chart.range.30")),
                        key: "range-thirty-days",
                        variant: if trend.thirty_days { ButtonVariant::Primary } else { ButtonVariant::Outline },
                        on_press: reduce { trend.thirty_days = true; },
                    ).semantics_identifier("northstar.range.30-days"),
                ]),
                chart,
                Text(cx.tr("chart.summary").replace("{percent}", &average.to_string()))
                    .color(tokens.colors.text_secondary),
            ]))
                .padding_all(tokens.spacing.l)
                .bg(tokens.colors.surface)
                .border(tokens.colors.border, 1.0)
                .border_radius(tokens.radii.large),
        )
    } else {
        EmptyState {
            title: cx.tr("dashboard.empty.title"),
            description: Some(cx.tr("dashboard.empty.description")),
            ..Default::default()
        }
    }
}

The metric cards should wrap into readable rows, route notes should keep their status, and chart labels should remain legible. fission doctor ios --project-dir .

`fission doctor` checks for missing Xcode tools and Rust targets, `fission run` launches a simulator, and `fission test` checks that the generated host starts. A simulator build does not verify signing or behaviour on a physical device.

Before a refund is submitted, a manager may need to confirm that the person holding the device is still present. That is a local verification step, not a second account system. We will enter a refund review, ask the host which authentication options exist, and preserve that review when verification is unavailable or cancelled.

That device check is only one part of the decision. A successful result means the host verified its current local user; it does not prove an account identity to a server or authorize a refund. The refund API still has to check the signed-in manager, their role, and the amount. This screen stops at **ready for server review** so a local check cannot be mistaken for a completed refund.

The browser cannot open a standalone Face ID or Touch ID prompt through this capability. Fission's Web host reports that local verification is unavailable; the screen explains that account sign-in is the alternative, rather than pretending to perform that separate flow. You can inspect the unavailable state and confirm the review stays unchanged. The iOS shell in this checkout also lacks a LocalAuthentication provider, so this guide does not pretend a successful prompt exists.

## Create the iOS app and declare the capability

Install the CLI, create the shared Rust project, add the iOS target, and declare that the app intends to use biometric authentication:

The CLI records `biometric` in `fission.toml` and adds the Face ID usage description to the generated iOS property list. iOS shows that description when an app requests Face ID. It does not install the provider that performs authentication; we’ll check that platform boundary before trying the app on a device.

The draft and prepared review are part of the approval flow, so application state owns them alongside device availability and the eventual response. The form does not replace a valid review until all fields pass validation. A local open/closed menu would belong to retained component state instead.

The example uses USD and a period as its decimal separator, storing exact cents rather than floating-point money. A multi-currency product needs its normal currency and locale rules rather than extending this parser by guesswork. No field creates a server refund ID: that remains the server's responsibility.

## Build the approval screen and wait for the host result

The screen checks whether authentication is available before enabling **Verify manager**. That avoids opening a prompt the device cannot complete. Pressing the button starts a request from a reducer; it returns immediately while Fission waits for the host.

The tabs show how app state, screen, and normal native/Web launchers fit together. Enter the refund details rather than relying on a seeded review that only exists in the browser. A production app would load those details from its authenticated refund service; entering them here does not authorize or submit anything. The Web host returns its normal unavailable-biometric result, so the recovery state is real rather than a simulated authentication success.

use fission::prelude::*;

#[derive(Clone, Debug, PartialEq, Eq)]
pub struct RefundDraft {
    pub order_reference: String,
    pub customer_name: String,
    pub amount_cents: u32,
    pub reason: String,
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum BiometricMethod {
    Face,
    Fingerprint,
    Iris,
    DeviceCredential,
    Other,
}

impl BiometricMethod {
    pub fn translation_key(&self) -> &'static str {
        match self {
            Self::Face => "refund.method.face",
            Self::Fingerprint => "refund.method.fingerprint",
            Self::Iris => "refund.method.iris",
            Self::DeviceCredential => "refund.method.device_credential",
            Self::Other => "refund.method.other",
        }
    }
}

#[derive(Clone, Debug, PartialEq, Eq)]
pub enum RefundNotice {
    CheckingDevice,
    DeviceAvailable,
    DeviceUnavailable,
    AvailabilityFailed,
    CheckDeviceFirst,
    NoCredential,
    RefundMissing,
    WaitingForPrompt,
    ResultMissing,
    NotVerified,
    Verified(BiometricMethod),
    PromptCancelled,
    TemporarilyLocked,
    AuthenticationUnavailable,
    AuthenticationFailed,
    InvalidDraft,
}

impl RefundNotice {
    pub fn translation_key(&self) -> &'static str {
        match self {
            Self::CheckingDevice => "refund.status.checking_device",
            Self::DeviceAvailable => "refund.status.device_available",
            Self::DeviceUnavailable => "refund.status.device_unavailable",
            Self::AvailabilityFailed => "refund.status.availability_failed",
            Self::CheckDeviceFirst => "refund.status.check_device_first",
            Self::NoCredential => "refund.status.no_credential",
            Self::RefundMissing => "refund.status.refund_missing",
            Self::WaitingForPrompt => "refund.status.waiting_for_prompt",
            Self::ResultMissing => "refund.status.result_missing",
            Self::NotVerified => "refund.status.not_verified",
            Self::Verified(_) => "refund.status.verified",
            Self::PromptCancelled => "refund.status.prompt_cancelled",
            Self::TemporarilyLocked => "refund.status.temporarily_locked",
            Self::AuthenticationUnavailable => "refund.status.authentication_unavailable",
            Self::AuthenticationFailed => "refund.status.authentication_failed",
            Self::InvalidDraft => "refund.status.invalid_draft",
        }
    }
}

#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct RefundApprovalState {
    pub locale: Locale,
    pub order_input: String,
    pub customer_input: String,
    pub amount_input: String,
    pub reason_input: String,
    pub refund: Option<RefundDraft>,
    pub availability: Option<BiometricAvailability>,
    pub checking_device: bool,
    pub authenticating: bool,
    pub verified_with: Option<BiometricMethod>,
    pub message: Option<RefundNotice>,
    pub error: Option<RefundNotice>,
}

impl GlobalState for RefundApprovalState {}

fn parse_usd_cents(input: &str) -> Option<u32> {
    let input = input.trim();
    let (whole, fraction) = input.split_once('.').unwrap_or((input, ""));
    if whole.is_empty()
        || !whole.bytes().all(|byte| byte.is_ascii_digit())
        || fraction.len() > 2
        || !fraction.bytes().all(|byte| byte.is_ascii_digit())
    {
        return None;
    }
    let fraction = match fraction.len() {
        0 => 0,
        1 => fraction.parse::<u32>().ok()?.checked_mul(10)?,
        _ => fraction.parse::<u32>().ok()?,
    };
    whole
        .parse::<u32>()
        .ok()?
        .checked_mul(100)?
        .checked_add(fraction)
}

pub fn prepare_refund_review(state: &mut RefundApprovalState) {
    if state.checking_device || state.authenticating {
        return;
    }
    let Some(amount_cents) = parse_usd_cents(&state.amount_input).filter(|amount| *amount > 0)
    else {
        state.error = Some(RefundNotice::InvalidDraft);
        return;
    };
    if state.order_input.trim().is_empty()
        || state.customer_input.trim().is_empty()
        || state.reason_input.trim().is_empty()
    {
        state.error = Some(RefundNotice::InvalidDraft);
        return;
    }
    state.refund = Some(RefundDraft {
        order_reference: state.order_input.trim().to_owned(),
        customer_name: state.customer_input.trim().to_owned(),
        amount_cents,
        reason: state.reason_input.trim().to_owned(),
    });
    state.verified_with = None;
    state.message = None;
    state.error = None;
}

#[fission_reducer(SetRefundLocale)]
pub fn on_set_refund_locale(state: &mut RefundApprovalState, locale: Locale) {
    state.locale = locale;
}

pub fn format_refund_amount(amount_cents: u32) -> String {
    format!("${}.{:02}", amount_cents / 100, amount_cents % 100)
}

fn host_can_verify(availability: &BiometricAvailability) -> bool {
    availability.supported && (availability.enrolled || availability.device_credential)
}

#[fission_reducer(CheckDeviceBiometrics)]
pub fn on_check_device_biometrics(
    state: &mut RefundApprovalState,
    ctx: &mut ReducerContext<RefundApprovalState>,
) {
    if state.checking_device || state.authenticating {
        return;
    }

    state.checking_device = true;
    state.error = None;
    state.message = Some(RefundNotice::CheckingDevice);

    let on_ok = ctx.effects.bind(
        BiometricAvailabilityReceived,
        reduce_with!(on_biometric_availability_received),
    );
    let on_err = ctx.effects.bind(
        BiometricAvailabilityFailed,
        reduce_with!(on_biometric_availability_failed),
    );

    ctx.effects
        .biometrics()
        .availability()
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(BiometricAvailabilityReceived)]
pub fn on_biometric_availability_received(
    state: &mut RefundApprovalState,
    ctx: &mut ReducerContext<RefundApprovalState>,
) {
    state.checking_device = false;
    let Some(availability) = ctx.input.capability_ok(GET_BIOMETRIC_AVAILABILITY) else {
        state.availability = None;
        state.message = None;
        state.error = Some(RefundNotice::AvailabilityFailed);
        return;
    };

    let ready = host_can_verify(&availability);
    state.availability = Some(availability);
    state.error = None;
    state.message = Some(if ready {
        RefundNotice::DeviceAvailable
    } else {
        RefundNotice::DeviceUnavailable
    });
}

#[fission_reducer(BiometricAvailabilityFailed)]
pub fn on_biometric_availability_failed(
    state: &mut RefundApprovalState,
    ctx: &mut ReducerContext<RefundApprovalState>,
) {
    state.checking_device = false;
    state.availability = None;
    state.message = None;
    let Some(error) = ctx.input.capability_error(GET_BIOMETRIC_AVAILABILITY) else {
        state.error = Some(RefundNotice::AvailabilityFailed);
        return;
    };

    state.error = Some(match error.code.as_str() {
        "unsupported" | "unavailable" => RefundNotice::DeviceUnavailable,
        _ => RefundNotice::AvailabilityFailed,
    });
}

#[fission_reducer(VerifyRefundManager)]
pub fn on_verify_refund_manager(
    state: &mut RefundApprovalState,
    reason: String,
    title: String,
    subtitle: String,
    fallback_title: String,
    cancel_title: String,
    ctx: &mut ReducerContext<RefundApprovalState>,
) {
    if state.authenticating || state.verified_with.is_some() {
        return;
    }

    let Some(availability) = state.availability.as_ref() else {
        state.error = Some(RefundNotice::CheckDeviceFirst);
        state.message = None;
        return;
    };
    if !host_can_verify(availability) {
        state.error = Some(RefundNotice::NoCredential);
        state.message = None;
        return;
    }
    if state.refund.is_none() {
        state.error = Some(RefundNotice::RefundMissing);
        state.message = None;
        return;
    }

    state.authenticating = true;
    state.error = None;
    state.message = Some(RefundNotice::WaitingForPrompt);

    let on_ok = ctx.effects.bind(
        RefundManagerVerified,
        reduce_with!(on_refund_manager_verified),
    );
    let on_err = ctx.effects.bind(
        RefundManagerVerificationFailed,
        reduce_with!(on_refund_manager_verification_failed),
    );

    ctx.effects
        .biometrics()
        .authenticate(BiometricAuthenticateRequest {
            reason,
            title: Some(title),
            subtitle: Some(subtitle),
            fallback_title: Some(fallback_title),
            cancel_title: Some(cancel_title),
            allow_device_credential: true,
            required_strength: BiometricStrength::Any,
        })
        .on_ok(on_ok)
        .on_err(on_err);
}

#[fission_reducer(RefundManagerVerified)]
pub fn on_refund_manager_verified(
    state: &mut RefundApprovalState,
    ctx: &mut ReducerContext<RefundApprovalState>,
) {
    state.authenticating = false;
    let Some(result) = ctx.input.capability_ok(AUTHENTICATE_BIOMETRIC) else {
        state.verified_with = None;
        state.message = None;
        state.error = Some(RefundNotice::ResultMissing);
        return;
    };
    if !result.verified {
        state.verified_with = None;
        state.message = None;
        state.error = Some(RefundNotice::NotVerified);
        return;
    }

    let method = if result.used_device_credential {
        BiometricMethod::DeviceCredential
    } else {
        match result.kind {
            Some(BiometricKind::Face) => BiometricMethod::Face,
            Some(BiometricKind::Fingerprint) => BiometricMethod::Fingerprint,
            Some(BiometricKind::Iris) => BiometricMethod::Iris,
            Some(BiometricKind::DeviceCredential) => BiometricMethod::DeviceCredential,
            Some(BiometricKind::Unknown) | None => BiometricMethod::Other,
        }
    };
    state.verified_with = Some(method.clone());
    state.error = None;
    state.message = Some(RefundNotice::Verified(method));
}

#[fission_reducer(RefundManagerVerificationFailed)]
pub fn on_refund_manager_verification_failed(
    state: &mut RefundApprovalState,
    ctx: &mut ReducerContext<RefundApprovalState>,
) {
    state.authenticating = false;
    state.verified_with = None;
    state.message = None;
    let Some(error) = ctx.input.capability_error(AUTHENTICATE_BIOMETRIC) else {
        state.error = Some(RefundNotice::AuthenticationFailed);
        return;
    };

    state.error = Some(match error.code.as_str() {
        "cancelled" | "canceled" | "user_cancel" | "system_cancelled" => {
            RefundNotice::PromptCancelled
        }
        "locked_out" | "lockout" => RefundNotice::TemporarilyLocked,
        "not_enrolled" | "unavailable" | "unsupported" | "permission_denied" => {
            RefundNotice::AuthenticationUnavailable
        }
        _ => RefundNotice::AuthenticationFailed,
    });
}

use std::collections::HashMap;

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;

const SOURCES: [(&str, &str); 2] = [
    ("en-US", include_str!("../../i18n/en-US.yaml")),
    ("es-ES", include_str!("../../i18n/es-ES.yaml")),
];

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in SOURCES {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid refund tutorial translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

## Check the native provider before testing Face ID or Touch ID

The Rust request and browser preview are ready, but this checkout does not include an iOS biometric host. The iOS shell registers camera, barcode, geolocation, and microphone providers. Biometric requests use `UnsupportedBiometricHost` until the app registers a `BiometricHost`. Adding `biometric` to `fission.toml` creates the Face ID usage string; it does not implement LocalAuthentication.

That is why the capability matrix marks iOS biometrics as **Provider**. To run real Face ID or Touch ID, add a `BiometricHost` backed by Apple’s LocalAuthentication framework and register it with the mobile shell. It must report availability and enrollment, then return a typed success or error from the system prompt. Until then, an iOS request should return `unsupported`; keep the refund unchanged and use account sign-in.

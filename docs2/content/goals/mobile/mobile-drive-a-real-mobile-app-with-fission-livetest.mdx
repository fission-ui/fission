We’ll test a small but believable job: a technician checks a cold-room compressor, writes an inspection note, and saves it. The app is the same on Android and iOS. The browser preview lets you try the flow while reading; LiveTest drives a running mobile shell and checks the controls by their meaning, not their position on screen.

The example keeps the work order and note status in `GlobalState`, updates them through reducers, and gives the important controls stable semantic identifiers. The demo save is local to the running app. It does not claim to write a database or send a report to a service.

Create a project and add both mobile targets plus Web for the in-page preview:

```sh
cargo install cargo-fission
fission init northbank-field-service
cd northbank-field-service
fission add-target android ios web --project-dir .
cargo add serde_yaml@0.9
```

The source you’ll add to the project is organised like this:

```text
northbank-field-service/
├── Cargo.toml
├── fission.toml
└── src/
    ├── main.rs             # generated target entrypoint
    ├── app.rs
    ├── lib.rs
    ├── translations.rs
    └── i18n/
        ├── en-US.yaml
        └── es-ES.yaml
```

Keep the shared screen and reducers in Rust. The generated `platforms/android/` and `platforms/ios/` directories are hosts; don’t move app behaviour into their generated files.

## Build the inspection screen

The first version gives the technician the work order, one check, and a place to leave a note. The primary action records the pressure check; the note is saved as a separate step so each change is easy to test.

Use the active theme for spacing, colour, and type. Keep the visible labels separate from the identifiers LiveTest uses, so translating the screen does not break the test.

```rust
use fission::prelude::*;

#[derive(Debug, Default, Clone, Copy, PartialEq, Eq)]
enum NoteStatus {
    #[default]
    Draft,
    Empty,
    Saved,
}

#[derive(Debug, Default, PartialEq)]
pub struct InspectionState {
    pressure_checked: bool,
    note: String,
    note_status: NoteStatus,
}

impl GlobalState for InspectionState {}

#[fission_reducer(UpdateInspectionNote)]
fn update_inspection_note(
    state: &mut InspectionState,
    ctx: &mut ReducerContext<InspectionState>,
) {
    if let Some(change) = ctx.input.text_change() {
        state.note = change.new_text.clone();
        state.note_status = NoteStatus::Draft;
    }
}

#[fission_reducer(SaveInspectionNote)]
fn save_inspection_note(state: &mut InspectionState) {
    state.note_status = if state.note.trim().is_empty() {
        NoteStatus::Empty
    } else {
        NoteStatus::Saved
    };
}

fission_component! {
    pub InspectionScreen<InspectionState> {}
    view(_screen, state, cx) {
        let tokens = &cx.view.env().theme.tokens;
        let save_note = with_reducer!(
            cx.build,
            SaveInspectionNote,
            save_inspection_note,
        );
        let update_note = with_reducer!(
            cx.build,
            UpdateInspectionNote,
            update_inspection_note,
        );
        let pressure_status = if state.pressure_checked {
            cx.tr("inspection.pressure.complete")
        } else {
            cx.tr("inspection.pressure.pending")
        };
        let note_status = match state.note_status {
            NoteStatus::Draft => cx.tr("inspection.note.draft"),
            NoteStatus::Empty => cx.tr("inspection.note.empty"),
            NoteStatus::Saved => cx.tr("inspection.note.saved"),
        };
    } =>
    SemanticsRegion(
        identifier: Some("northbank.inspection.screen".into()),
        label: Some(cx.tr("inspection.screen.label")),
        child: Container(
            Column(gap: tokens.spacing.m, children: [
                Row(
                    gap: tokens.spacing.m,
                    wrap: ir_op::FlexWrap::Wrap,
                    align_items: ir_op::AlignItems::Center,
                    children: [
                        Column(gap: tokens.spacing.xs, flex_grow: 1.0, children: [
                            Text(cx.tr("app.name"))
                                .weight(tokens.typography.font_weight_bold),
                            Text(cx.tr("inspection.route"))
                                .color(tokens.colors.text_secondary),
                        ]),
                        Badge(text: cx.tr("inspection.status.open")),
                    ],
                ),
                Divider(),
                Column(gap: tokens.spacing.xs, children: [
                    Text(cx.tr("inspection.order"))
                        .weight(tokens.typography.font_weight_semibold),
                    Text(cx.tr("inspection.asset"))
                        .size(tokens.typography.heading2_size),
                    Text(cx.tr("inspection.location"))
                        .color(tokens.colors.text_secondary),
                    Text(cx.tr("inspection.summary")),
                ]),
                Container(
                    Column(gap: tokens.spacing.s, children: [
                        Text(cx.tr("inspection.pressure.title"))
                            .weight(tokens.typography.font_weight_semibold),
                        Row(gap: tokens.spacing.s, children: [
                            Badge(text: pressure_status),
                            Text(cx.tr("inspection.pressure.target"))
                                .color(tokens.colors.text_secondary),
                        ]),
                        Button(
                            child: Text(if state.pressure_checked {
                                cx.tr("inspection.pressure.complete")
                            } else {
                                cx.tr("inspection.pressure.action")
                            }),
                            key: "complete-pressure-check",
                            disabled: state.pressure_checked,
                            on_press: reduce { state.pressure_checked = true; },
                        ).semantics_identifier("northbank.inspection.pressure.complete"),
                    ])
                )
                .padding_all(tokens.spacing.m)
                .bg(tokens.colors.background)
                .border(tokens.colors.border, 1.0)
                .border_radius(tokens.radii.medium),
                TextInput(
                    label: Some(cx.tr("inspection.note.label").into()),
                    placeholder: Some(cx.tr("inspection.note.placeholder").into()),
                    multiline: true,
                    required: true,
                    value: state.note.clone(),
                    on_input: update_note,
                    key: "inspection-note",
                    semantics_identifier: Some("northbank.inspection.note".into()),
                ),
                Button(
                    child: Text(cx.tr("inspection.note.save")),
                    key: "save-inspection-note",
                    variant: ButtonVariant::Primary,
                    on_press: save_note,
                ).semantics_identifier("northbank.inspection.note.save"),
                Text(note_status)
                    .color(tokens.colors.text_secondary)
                    .semantics_identifier("northbank.inspection.note.status"),
            ])
        )
        .padding_all(tokens.spacing.l)
        .bg(tokens.colors.surface)
        .border(tokens.colors.border, 1.0)
        .border_radius(tokens.radii.large),
    )
}
```

mod app;

use fission::prelude::*;
use wasm_bindgen::prelude::*;

fn preview_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, yaml) in [
        ("en-US", include_str!("i18n/en-US.yaml")),
        ("es-ES", include_str!("i18n/es-ES.yaml")),
    ] {
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages: serde_yaml::from_str(yaml)
                .unwrap_or_else(|error| panic!("invalid {locale} translations: {error}")),
        });
    }
    env
}

#[wasm_bindgen(start)]
pub fn run() -> Result<(), JsValue> {
    console_error_panic_hook::set_once();
    WebApp::<app::InspectionState, _>::new(app::InspectionScreen)
        .with_env(preview_env())
        .with_title("Northbank Field Service")
        .mount("#fission-web-mount")
        .run()
        .map_err(|error| JsValue::from_str(&error.to_string()))
}

## Drive the save flow by semantic identifier

LiveTest selectors target the semantic identifiers on the note field, save button, and status message. First save the empty field and check that the user gets a useful error. Then enter a real note and save again. This test still works if the copy is translated or the layout changes.

Add the native test-control port to the app configuration. Keep this in the development/test launch path, not in a production build that doesn’t need remote test control.

pub mod app;
pub mod translations;

use fission::prelude::*;

#[cfg(target_os = "android")]
const ANDROID_TEST_CONTROL_PORT: u16 = 48761;

#[cfg(any(target_os = "android", target_os = "ios"))]
fn mobile_app() -> MobileApp<app::InspectionState, app::InspectionScreen> {
    let app = MobileApp::<app::InspectionState, _>::new(app::InspectionScreen)
        .with_env(translations::create_env())
        .with_title("Northbank Field Service");
    #[cfg(all(target_os = "android", debug_assertions))]
    let app = app.with_test_control_port(ANDROID_TEST_CONTROL_PORT);
    app
}

#[cfg(any(target_os = "android", target_os = "ios"))]
pub fn run_mobile() -> anyhow::Result<()> {
    mobile_app().run()
}

#[cfg(not(any(target_arch = "wasm32", target_os = "android", target_os = "ios")))]
pub fn run_desktop() -> anyhow::Result<()> {
    DesktopApp::<app::InspectionState, _>::new(app::InspectionScreen)
        .with_env(translations::create_env())
        .with_title("Northbank Field Service")
        .run()
}

#[cfg(target_os = "android")]
#[no_mangle]
fn android_main(app_handle: AndroidApp) {
    let _ = mobile_app().run_with_android_app(app_handle);
}

#[cfg(target_arch = "wasm32")]
fn web_app() -> WebApp<app::InspectionState, app::InspectionScreen> {
    WebApp::<app::InspectionState, _>::new(app::InspectionScreen)
        .with_env(translations::create_env())
        .with_title("Northbank Field Service")
        .mount("#fission-web-mount")
}

#[cfg(target_arch = "wasm32")]
#[wasm_bindgen::prelude::wasm_bindgen(start)]
pub fn run_web() -> Result<(), wasm_bindgen::JsValue> {
    console_error_panic_hook::set_once();
    web_app()
        .run()
        .map_err(|error| wasm_bindgen::JsValue::from_str(&error.to_string()))
}

Run the target and check that the control server is ready:

```sh
fission doctor android --project-dir .
fission run --target android --project-dir .
curl --fail-with-body http://127.0.0.1:48761/health
```

The Android launch script forwards host port `48761` to the app on the emulator. For iOS, pass that port to the Simulator process:

```sh
FISSION_TEST_CONTROL_PORT=48761 fission run --target ios --project-dir .
curl --fail-with-body http://127.0.0.1:48761/health
```

The generated iOS Simulator script passes the environment variable to the app. Then send the same sequence of commands to either target:

```sh
curl --fail-with-body http://127.0.0.1:48761/cmd \
  -H 'content-type: application/json' \
  -d '{"cmd":"TapSelector","query":{"selector":{"kind":"semantic_identifier","identifier":"northbank.inspection.note.save"}}}'

curl --fail-with-body http://127.0.0.1:48761/cmd \
  -H 'content-type: application/json' \
  -d '{"cmd":"WaitForVisible","query":{"selector":{"kind":"semantic_identifier","identifier":"northbank.inspection.note.status"},"timeout_ms":5000}}'

curl --fail-with-body http://127.0.0.1:48761/cmd \
  -H 'content-type: application/json' \
  -d '{"cmd":"WaitForText","text":"Add a note before saving.","timeout_ms":5000}'

curl --fail-with-body http://127.0.0.1:48761/cmd \
  -H 'content-type: application/json' \
  -d '{"cmd":"FillText","query":{"selector":{"kind":"semantic_identifier","identifier":"northbank.inspection.note"}},"text":"Pressure stable at 2.2 bar; no leak found."}'

curl --fail-with-body http://127.0.0.1:48761/cmd \
  -H 'content-type: application/json' \
  -d '{"cmd":"TapSelector","query":{"selector":{"kind":"semantic_identifier","identifier":"northbank.inspection.note.save"}}}'

curl --fail-with-body http://127.0.0.1:48761/cmd \
  -H 'content-type: application/json' \
  -d '{"cmd":"WaitForText","text":"Note saved for this session.","timeout_ms":5000}'
```

The final command should leave the status at **Note saved for this session**. In a real app, the reducer would request a Store or service effect and show success only after its completion action confirms the write. Don’t label an in-memory state change as durable storage.

## Test the layer that can catch the bug

Use reducer tests for save rules, headless tests for the semantic tree, and LiveTest for the running shell’s input and focus behavior. You don’t need a device for every assertion; use one when the behavior depends on the operating system.

```sh
cargo test
fission doctor android --project-dir .
fission test --target android --project-dir .
fission doctor ios --project-dir .
fission test --target ios --project-dir .
```

Run the manual LiveTest sequence above when you change mobile text input, keyboard handling, focus, scrolling, or a user journey that must work on the native shell. Use a physical phone only for behavior a simulator cannot prove, such as a real permission prompt or hardware capability.

Read [Testing Fission apps](/docs/learn/testing/), [LiveTest API](/docs/test-and-debug/live-test-api/), and [mobile toolchain setup](/docs/learn/mobile-toolchain-setup/) for the full test and device setup details.

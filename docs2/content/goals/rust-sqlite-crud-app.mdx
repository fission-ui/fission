The reading list needs to answer three simple questions: what should I read next, where did I stop, and what have I finished? We’ll build Harbour Reads for a small book club. Each entry stores the title, author, total pages, and pages read. The app derives “Want to read”, “Reading”, or “Finished” from that record, so a separate status can’t get out of sync.

The browser preview starts with four sample books. You can add a book, search and filter, record progress, and remove an entry. Then we’ll move those changes behind Fission’s asynchronous SQLite effects. The preview uses in-memory records so you can try the workflow without configuring browser storage; the runnable Web app starts by loading its saved library and uses the SQLite reducers in the final step, with the same fields and actions.

## Create the Web project and enable storage

Scaffold the Web target and add Fission’s storage capability. It selects SQLite for Web, installs the worker and browser assets, and configures the local server headers the browser requires.

## Shape the library around a reader’s next decision

Start with the book record and the details that help a reader choose what to read next. Page counts make progress measurable, and the author helps distinguish books with similar titles. Derive “Finished” from the page counters; don’t keep another status field that can disagree with them.

The migration enforces the same rules if another screen or job writes to the table: no blank names, zero-page books, negative progress, or progress beyond the last page. The title index gives a larger library a useful starting point for title searches.

use fission::sql::{SqlMigration, SqlMigrations};

pub fn reading_list_migrations() -> anyhow::Result<SqlMigrations> {
    let mut migrations = SqlMigrations::new();
    migrations.add(SqlMigration::new(
        1,
        "create reading books",
        "CREATE TABLE reading_books (
            id INTEGER PRIMARY KEY,
            title TEXT NOT NULL CHECK (length(trim(title)) > 0),
            author TEXT NOT NULL CHECK (length(trim(author)) > 0),
            total_pages INTEGER NOT NULL CHECK (total_pages > 0),
            pages_read INTEGER NOT NULL DEFAULT 0
                CHECK (pages_read >= 0 AND pages_read <= total_pages),
            added_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
        );
        CREATE INDEX reading_books_title_idx
            ON reading_books(title COLLATE NOCASE);",
    ))?;
    Ok(migrations)
}

## Add books, search the library, and log a reading session

The create form needs enough information to make a useful record. Keep title and author while the book is being added, and parse the page count as a positive integer before accepting it. An invalid value leaves the library alone and explains what to fix.

Search and status filters are local to the dashboard; they only change what this screen shows. The library itself lives in app state. Rows use stable book IDs, so adding or removing a book won’t make Fission treat a different one as the same widget. The progress action records a reading session and stops at the last page. Removing an entry updates the list and confirms which title was removed.

This step uses in-memory reducers so the preview responds to each action. In the runnable app, keep the same actions and replace their in-memory updates with the parameterized SQL effects in the next step.

#[derive(Clone, Debug, PartialEq)]
pub struct ReadingBook {
    pub id: u32,
    pub title: String,
    pub author: String,
    pub total_pages: u32,
    pub pages_read: u32,
}

fn book_count(count: usize, one: &str, many: &str) -> String {
    format!("{} {}", count, if count == 1 { one } else { many })
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum ReadingStatus {
    WantToRead,
    Reading,
    Finished,
}

impl ReadingStatus {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::WantToRead => "reading.status.want_to_read",
            Self::Reading => "reading.status.reading",
            Self::Finished => "reading.status.finished",
        }
    }
}

fn reading_status(book: &ReadingBook) -> ReadingStatus {
    if book.pages_read == 0 {
        ReadingStatus::WantToRead
    } else if book.pages_read >= book.total_pages {
        ReadingStatus::Finished
    } else {
        ReadingStatus::Reading
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum ReadingFilter {
    All,
    Reading,
    WantToRead,
    Finished,
}

fn matches_book(book: &ReadingBook, query: &str, filter: ReadingFilter) -> bool {
    let status = reading_status(book);
    (query.is_empty()
        || book.title.to_lowercase().contains(query)
        || book.author.to_lowercase().contains(query))
        && match filter {
            ReadingFilter::All => true,
            ReadingFilter::Reading => status == ReadingStatus::Reading,
            ReadingFilter::WantToRead => status == ReadingStatus::WantToRead,
            ReadingFilter::Finished => status == ReadingStatus::Finished,
        }
}

#[derive(Clone, Debug, PartialEq)]
pub struct ReadingListState {
    pub books: Vec<ReadingBook>,
    pub next_book_id: u32,
    pub title_draft: String,
    pub author_draft: String,
    pub page_count_draft: String,
    pub notice: String,
    pub has_error: bool,
    pub is_loading: bool,
    pub is_saving: bool,
}

impl Default for ReadingListState {
    fn default() -> Self {
        Self {
            books: Vec::new(),
            next_book_id: 1,
            title_draft: String::new(),
            author_draft: String::new(),
            page_count_draft: String::new(),
            notice: "reading.notice.ready".into(),
            has_error: false,
            is_loading: false,
            is_saving: false,
        }
    }
}
impl GlobalState for ReadingListState {}

#[fission_reducer(AddBook)]
pub fn on_add_book(state: &mut ReadingListState) {
    let title = state.title_draft.trim().to_string();
    let author = state.author_draft.trim().to_string();
    let total_pages = match state.page_count_draft.trim().parse::<u32>() {
        Ok(value) if value > 0 => value,
        _ => {
            state.notice = "reading.error.invalid_pages".into();
            state.has_error = true;
            return;
        }
    };
    if title.is_empty() || author.is_empty() {
        state.notice = "reading.error.required_fields".into();
        state.has_error = true;
        return;
    }

    let id = state.next_book_id;
    state.next_book_id = state.next_book_id.saturating_add(1);
    state.books.push(ReadingBook { id, title, author, total_pages, pages_read: 0 });
    state.title_draft.clear();
    state.author_draft.clear();
    state.page_count_draft.clear();
    state.notice = "reading.notice.book_added".into();
    state.has_error = false;
}

#[fission_reducer(LogPages)]
pub fn on_log_pages(state: &mut ReadingListState, book_id: u32, pages: u32) {
    let Some(book) = state.books.iter_mut().find(|book| book.id == book_id) else {
        state.notice = "reading.error.book_missing".into();
        state.has_error = true;
        return;
    };
    book.pages_read = book.pages_read.saturating_add(pages).min(book.total_pages);
    state.notice = "reading.notice.progress_saved".into();
    state.has_error = false;
}

#[fission_reducer(RemoveBook)]
pub fn on_remove_book(state: &mut ReadingListState, book_id: u32) {
    let existed = state.books.iter().any(|book| book.id == book_id);
    state.books.retain(|book| book.id != book_id);
    if existed {
        state.notice = "reading.notice.book_removed".into();
        state.has_error = false;
    } else {
        state.notice = "reading.error.book_missing".into();
        state.has_error = true;
    }
}

<!-- fission:step id="persist-and-recover" -->
## Persist each change and recover from storage errors

SQLite can take longer than one render, so reducers must not wait for it. Validate the values, mark the save pending, and queue an insert effect. A later reducer receives success or failure. Only clear the draft and reload the library after a successful insert; if SQLite fails, stop loading, keep the draft, and show a translated error rather than exposing database details.

The code tabs show migration, read, progress, delete, and insert operations. Bind every value as a parameter so a title such as <em>The Book: Volume 2</em> stays data and never becomes part of the SQL statement. Update progress and delete by database ID; titles can repeat or change. The embedded preview is explicitly seeded and in-memory so it works without the Web SQLite worker bridge; the SQL reducers remain in the extracted app source, and the runnable project below uses them with the storage capability installed.

    pub id: u32,
    pub title: String,
    pub author: String,
    pub total_pages: u32,
    pub pages_read: u32,
}

fn book_count(count: usize, one: &str, many: &str) -> String {
    format!("{} {}", count, if count == 1 { one } else { many })

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum ReadingStatus {
    WantToRead,
    Reading,
    Finished,
}

impl ReadingStatus {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::WantToRead => "reading.status.want_to_read",
            Self::Reading => "reading.status.reading",
            Self::Finished => "reading.status.finished",
        }
    }
}

fn reading_status(book: &ReadingBook) -> ReadingStatus {
    if book.pages_read == 0 {
        ReadingStatus::WantToRead
    } else if book.pages_read >= book.total_pages {
        ReadingStatus::Finished
    } else {
        ReadingStatus::Reading
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum ReadingFilter {
    All,
    Reading,
    WantToRead,
    Finished,
}

fn matches_book(book: &ReadingBook, query: &str, filter: ReadingFilter) -> bool {
    let status = reading_status(book);
    (query.is_empty()
        || book.title.to_lowercase().contains(query)
        || book.author.to_lowercase().contains(query))
        && match filter {
            ReadingFilter::All => true,
            ReadingFilter::Reading => status == ReadingStatus::Reading,
            ReadingFilter::WantToRead => status == ReadingStatus::WantToRead,
            ReadingFilter::Finished => status == ReadingStatus::Finished,
        }
}

#[fission_reducer(PrepareReadingList)]
pub fn prepare_reading_list(
    _state: &mut ReadingListState,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    let mut migrations = SqlMigrations::new();
    migrations.add(SqlMigration::new(
        1,
        "create reading books",
        "CREATE TABLE reading_books (
            id INTEGER PRIMARY KEY,
            title TEXT NOT NULL CHECK (length(trim(title)) > 0),
            author TEXT NOT NULL CHECK (length(trim(author)) > 0),
            total_pages INTEGER NOT NULL CHECK (total_pages > 0),
            pages_read INTEGER NOT NULL DEFAULT 0
                CHECK (pages_read >= 0 AND pages_read <= total_pages),
            added_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
        );
        CREATE INDEX reading_books_title_idx
            ON reading_books(title COLLATE NOCASE);",
    )).expect("migration versions are unique");

    ctx.effects.sql().migrate(migrations)
        .on_ok(ActionEnvelope::from(LoadBooks))
        .on_err(ActionEnvelope::from(DatabaseFailed));
}

use fission::prelude::*;
use fission::sql::SqlStatement;
use crate::app::{ReadingBook, ReadingListState};

#[fission_reducer(LoadBooks)]
pub fn load_books(
    state: &mut ReadingListState,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    state.is_loading = true;
    ctx.effects.sql().query(SqlStatement::new(
        "SELECT id, title, author, total_pages, pages_read
         FROM reading_books ORDER BY added_at DESC, id DESC",
    ))
    .on_ok(ActionEnvelope::from(BooksLoaded))
    .on_err(ActionEnvelope::from(DatabaseFailed));
}

#[fission_reducer(AddBook)]
pub fn on_add_book(
    state: &mut ReadingListState,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    let title = state.title_draft.trim().to_string();
    let author = state.author_draft.trim().to_string();
    let total_pages = match state.page_count_draft.trim().parse::<u32>() {
        Ok(value) if value > 0 => value,
        _ => {
            state.notice = "reading.error.invalid_pages".into();
            state.has_error = true;
            return;
        }
    };
    if title.is_empty() || author.is_empty() {
        state.notice = "reading.error.required_fields".into();
        state.has_error = true;
        return;
    }

    if state.in_memory_preview {
        let id = state.books.iter().map(|book| book.id).max().unwrap_or(0).saturating_add(1);
        state.books.push(ReadingBook { id, title, author, total_pages, pages_read: 0 });
        state.title_draft.clear();
        state.author_draft.clear();
        state.page_count_draft.clear();
        state.notice = "reading.notice.book_added".into();
        state.has_error = false;
        return;
    }

    state.is_saving = true;
    state.has_error = false;
    let statement = SqlStatement::new(
        "INSERT INTO reading_books (title, author, total_pages)
         VALUES (?1, ?2, ?3)",
    )
    .bind(title)
    .bind(author)
    .bind(i64::from(total_pages));

    ctx.effects.sql().execute(statement)
        .on_ok(ActionEnvelope::from(BookInserted))
        .on_err(ActionEnvelope::from(DatabaseFailed));
}

#[fission_reducer(BookInserted)]
pub fn book_inserted(
    state: &mut ReadingListState,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    state.is_loading = true;
    state.title_draft.clear();
    state.author_draft.clear();
    state.page_count_draft.clear();
    state.notice = "reading.notice.book_added".into();
    ctx.effects.sql().query(SqlStatement::new(
        "SELECT id, title, author, total_pages, pages_read
         FROM reading_books ORDER BY added_at DESC, id DESC",
    ))
    .on_ok(ActionEnvelope::from(BooksLoaded))
    .on_err(ActionEnvelope::from(DatabaseFailed));
}

#[fission_reducer(BooksLoaded)]
pub fn books_loaded(
    state: &mut ReadingListState,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    let Some(rows) = ctx.input.sql_rows() else { return; };
    state.books = rows.rows.iter().filter_map(|row| Some(ReadingBook {
        id: u32::try_from(row.get::<i64>("id").ok()?).ok()?,
        title: row.get::<String>("title").ok()?,
        author: row.get::<String>("author").ok()?,
        total_pages: u32::try_from(row.get::<i64>("total_pages").ok()?).ok()?,
        pages_read: u32::try_from(row.get::<i64>("pages_read").ok()?).ok()?,
    })).collect();
    state.is_loading = false;
    state.is_saving = false;
    state.has_error = false;
    if state.notice == "reading.loading" {
        state.notice = "reading.notice.ready".into();
    }
}

#[fission_reducer(LogPages)]
pub fn on_log_pages(
    state: &mut ReadingListState,
    book_id: u32,
    pages: u32,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    if state.in_memory_preview {
        let Some(book) = state.books.iter_mut().find(|book| book.id == book_id) else {
            state.notice = "reading.error.book_missing".into();
            state.has_error = true;
            return;
        };
        book.pages_read = book.pages_read.saturating_add(pages).min(book.total_pages);
        state.notice = "reading.notice.progress_saved".into();
        state.has_error = false;
        return;
    }

    state.is_saving = true;
    let statement = SqlStatement::new(
        "UPDATE reading_books
         SET pages_read = MIN(pages_read + ?1, total_pages)
         WHERE id = ?2",
    )
    .bind(i64::from(pages))
    .bind(i64::from(book_id));
    ctx.effects.sql().execute(statement)
        .on_ok(ActionEnvelope::from(ProgressSaved))
        .on_err(ActionEnvelope::from(DatabaseFailed));
}

#[fission_reducer(ProgressSaved)]
pub fn progress_saved(
    state: &mut ReadingListState,
    ctx: &mut ReducerContext<ReadingListState>,

    state.notice = "reading.notice.progress_saved".into();
    state.is_loading = true;
    ctx.effects.sql().query(SqlStatement::new(

         FROM reading_books ORDER BY added_at DESC, id DESC",
    ))
    .on_ok(ActionEnvelope::from(BooksLoaded))
    .on_err(ActionEnvelope::from(DatabaseFailed));

#[fission_reducer(RemoveBook)]
pub fn on_remove_book(
    state: &mut ReadingListState,
    book_id: u32,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    if state.in_memory_preview {
        let existed = state.books.iter().any(|book| book.id == book_id);
        state.books.retain(|book| book.id != book_id);
        if existed {
            state.notice = "reading.notice.book_removed".into();
            state.has_error = false;
        } else {
            state.notice = "reading.error.book_missing".into();
            state.has_error = true;
        }
        return;
    }

    state.is_saving = true;
    let statement = SqlStatement::new("DELETE FROM reading_books WHERE id = ?1")
        .bind(i64::from(book_id));
    ctx.effects.sql().execute(statement)
        .on_ok(ActionEnvelope::from(BookRemoved))
        .on_err(ActionEnvelope::from(DatabaseFailed));
}

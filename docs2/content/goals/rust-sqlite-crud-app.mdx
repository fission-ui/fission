A reading list is useful after the app has closed, not just while its window remains open. The app therefore needs two different kinds of state: SQLite owns the saved books and bookmarks, while the interface keeps the draft and the last list it successfully read.

We'll build Harbour Reads around that distinction. Create, read, update and delete are often shortened to CRUD. Here those operations mean adding a book, loading the library, saving the page reached and removing an entry. The saved page count determines whether a book is waiting, being read or finished; there is no separate status value to get out of step.

Every database operation uses Fission's actual SQL effect path. There is no in-memory preview branch that pretends a write succeeded. The browser needs SQLite's worker, bridge and cross-origin-isolation headers. If those are unavailable, storage fails visibly rather than silently changing to a different provider.

## Create the project and enable storage

```sh
cargo install cargo-fission
fission init harbour-reads
cd harbour-reads
cargo add serde --features derive
cargo add serde_yaml
fission add-target web --project-dir .
fission add-capability storage --project-dir .
```

Use the capability command rather than enabling only a Cargo feature. It configures the Rust provider and the Web assets together. Keep the generated `app.app_id` stable: Web storage belongs to that app on the current origin. Native startup uses the fixed “Harbour Reads” application title for its default application-data path; do not translate that storage identity.

## Load the saved library before accepting changes

Before querying, install a versioned migration. The table rejects blank names, page totals outside this example's 1–100,000 range and bookmarks beyond the last page. SQLite allocates the record IDs; a title is not an identity because different editions can share it.

The startup action runs once through the shell's reducer flow. It queues migration, then a query. Neither runs while constructing the component tree. The view can render a real animated loading state while the worker or native provider is busy.

The app reads at most 501 rows to enforce its 500-book teaching limit. Decoding is all-or-nothing. A malformed saved row is an error, not permission to drop it and show an apparently complete but smaller library. Until loading succeeds, the UI does not label an unconfirmed result as an empty library.

This first checkpoint is deliberately read-only. A new database has no books; an existing database shows its saved records. The next step adds the controls. The state already names the later write phases so the database path has one clear authority throughout the tutorial.

```rust
#[derive(Clone, Debug, PartialEq, serde::Serialize, serde::Deserialize)]
pub struct ReadingBook {
    pub id: i64,
    pub title: String,
    pub author: String,
    pub total_pages: u32,
    pub pages_read: u32,
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum ReadingStatus { WantToRead, Reading, Finished }
impl ReadingStatus {
    pub fn translation_key(self) -> &'static str {
        match self {
            Self::WantToRead => "reading.status.want_to_read",
            Self::Reading => "reading.status.reading",
            Self::Finished => "reading.status.finished",
        }
    }
}
pub fn reading_status(book: &ReadingBook) -> ReadingStatus {
    if book.pages_read == 0 { ReadingStatus::WantToRead }
    else if book.pages_read == book.total_pages { ReadingStatus::Finished }
    else { ReadingStatus::Reading }
}
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum ReadingFilter { All, Reading, WantToRead, Finished }
pub fn matches_book(book: &ReadingBook, query: &str, filter: ReadingFilter) -> bool {
    let query = query.trim().to_lowercase();
    let status = reading_status(book);
    (query.is_empty() || book.title.to_lowercase().contains(&query) || book.author.to_lowercase().contains(&query))
        && match filter {
            ReadingFilter::All => true,
            ReadingFilter::Reading => status == ReadingStatus::Reading,
            ReadingFilter::WantToRead => status == ReadingStatus::WantToRead,
            ReadingFilter::Finished => status == ReadingStatus::Finished,
        }
}
#[derive(Clone, Debug, Default, PartialEq)]
pub struct BookDraft { pub title: String, pub author: String, pub pages: String }
#[derive(Clone, Debug, PartialEq)]
pub struct BookInput { pub title: String, pub author: String, pub total_pages: u32 }
impl BookDraft {
    pub fn validate(&self) -> Result<BookInput, &'static str> {
        let title = self.title.trim();
        let author = self.author.trim();
        if title.is_empty() || author.is_empty()
            || title.chars().count() > 160 || author.chars().count() > 160 {
            return Err("reading.error.required_fields");
        }
        let total_pages = self.pages.trim().parse::<u32>().ok()
            .filter(|pages| (1..=100_000).contains(pages)).ok_or("reading.error.invalid_pages")?;
        Ok(BookInput { title: title.into(), author: author.into(), total_pages })
    }
}
pub fn parse_page(source: &str, total_pages: u32) -> Result<u32, &'static str> {
    source.trim().parse::<u32>().ok().filter(|page| *page <= total_pages)
        .ok_or("reading.error.progress")
}
```

```rust
use crate::models::{BookDraft, ReadingBook};
use fission::prelude::*;

#[derive(Clone, Debug, PartialEq)]
pub enum PendingWrite {
    Add(BookDraft),
    Progress,
    Remove,
}
#[derive(Clone, Debug, PartialEq)]
pub enum DatabasePhase {
    Loading,
    Ready,
    Executing(PendingWrite),
    Refreshing(PendingWrite),
    Failed,
}
#[derive(Clone, Debug, PartialEq)]
pub enum LibraryNotice { Info(&'static str), Error(&'static str) }
impl LibraryNotice {
    pub fn key(&self) -> &'static str { match self { Self::Info(key) | Self::Error(key) => key } }
    pub fn is_error(&self) -> bool { matches!(self, Self::Error(_)) }
}
#[derive(Clone, Debug, PartialEq)]
pub struct ReadingListState {
    pub books: Vec<ReadingBook>,
    pub title_draft: String,
    pub author_draft: String,
    pub page_count_draft: String,
    pub phase: DatabasePhase,
    pub notice: Option<LibraryNotice>,
}
impl Default for ReadingListState {
    fn default() -> Self {
        Self {
            books: Vec::new(), title_draft: String::new(), author_draft: String::new(),
            page_count_draft: String::new(), phase: DatabasePhase::Loading, notice: None,
        }
    }
}
impl GlobalState for ReadingListState {}
impl ReadingListState {
    pub fn draft(&self) -> BookDraft {
        BookDraft { title: self.title_draft.clone(), author: self.author_draft.clone(), pages: self.page_count_draft.clone() }
    }
    pub fn can_write(&self) -> bool { self.phase == DatabasePhase::Ready }
    pub fn is_busy(&self) -> bool {
        matches!(self.phase, DatabasePhase::Loading | DatabasePhase::Executing(_) | DatabasePhase::Refreshing(_))
    }
    pub fn reject(&mut self, key: &'static str) { self.notice = Some(LibraryNotice::Error(key)); }
    pub fn fail(&mut self) {
        self.phase = DatabasePhase::Failed;
        self.reject("reading.error.database");
    }
    pub fn accept_loaded(&mut self, books: Vec<ReadingBook>) {
        let previous = std::mem::replace(&mut self.phase, DatabasePhase::Ready);
        let notice = match previous {
            DatabasePhase::Refreshing(PendingWrite::Add(submitted)) => {
                // A successful old write must not erase text entered while it ran.
                if self.draft() == submitted {
                    self.title_draft.clear(); self.author_draft.clear(); self.page_count_draft.clear();
                }
                Some("reading.notice.book_added")
            }
            DatabasePhase::Refreshing(PendingWrite::Progress) => Some("reading.notice.progress_saved"),
            DatabasePhase::Refreshing(PendingWrite::Remove) => Some("reading.notice.book_removed"),
            _ => None,
        };
        self.books = books;
        self.notice = notice.map(LibraryNotice::Info);
    }
}
```

```rust
use crate::models::{BookInput, ReadingBook};
use crate::state::{DatabasePhase, ReadingListState};
use fission::prelude::*;

pub fn insert_statement(book: &BookInput) -> SqlStatement {
    SqlStatement::new("INSERT INTO reading_books (title, author, total_pages) VALUES (?1, ?2, ?3)")
        .bind(book.title.clone()).bind(book.author.clone()).bind(i64::from(book.total_pages))
}

pub fn query_books(ctx: &mut ReducerContext<ReadingListState>) {
    let ok = ctx.effects.bind(BooksLoaded, reduce_with!(books_loaded));
    let err = ctx.effects.bind(DatabaseFailed, reduce_with!(database_failed));
    ctx.effects.sql().query(SqlStatement::new(
        "SELECT id, title, author, total_pages, pages_read FROM reading_books ORDER BY id DESC LIMIT 501"
    )).on_ok(ok).on_err(err);
}

pub fn decode_books(rows: SqlRows) -> Result<Vec<ReadingBook>, &'static str> {
    if rows.rows.len() > 500 { return Err("reading.error.library_limit"); }
    rows.rows.into_iter().map(|row| {
        let book = ReadingBook {
            id: row.get("id").map_err(|_| "reading.error.records")?,
            title: row.get("title").map_err(|_| "reading.error.records")?,
            author: row.get("author").map_err(|_| "reading.error.records")?,
            total_pages: u32::try_from(row.get::<i64>("total_pages").map_err(|_| "reading.error.records")?)
                .map_err(|_| "reading.error.records")?,
            pages_read: u32::try_from(row.get::<i64>("pages_read").map_err(|_| "reading.error.records")?)
                .map_err(|_| "reading.error.records")?,
        };
        if book.id <= 0 || book.title.trim().is_empty() || book.author.trim().is_empty()
            || book.title.chars().count() > 160 || book.author.chars().count() > 160
            || !(1..=100_000).contains(&book.total_pages) || book.pages_read > book.total_pages {
            return Err("reading.error.records");
        }
        Ok(book)
    }).collect()
}

#[fission_reducer(PrepareLibrary)]
pub fn prepare_library(state: &mut ReadingListState, ctx: &mut ReducerContext<ReadingListState>) {
    if matches!(state.phase, DatabasePhase::Executing(_) | DatabasePhase::Refreshing(_)) { return; }
    state.phase = DatabasePhase::Loading;
    state.notice = None;
    let mut migrations = SqlMigrations::new();
    migrations.add(SqlMigration::new(1, "reading library",
        "CREATE TABLE reading_books (
            id INTEGER PRIMARY KEY,
            title TEXT NOT NULL CHECK (length(trim(title)) BETWEEN 1 AND 160),
            author TEXT NOT NULL CHECK (length(trim(author)) BETWEEN 1 AND 160),
            total_pages INTEGER NOT NULL CHECK (total_pages BETWEEN 1 AND 100000),
            pages_read INTEGER NOT NULL DEFAULT 0 CHECK (pages_read BETWEEN 0 AND total_pages)
        );"
    )).expect("one migration with a unique version");
    let ok = ctx.effects.bind(LibraryPrepared, reduce_with!(library_prepared));
    let err = ctx.effects.bind(DatabaseFailed, reduce_with!(database_failed));
    ctx.effects.sql().migrate(migrations)
        .on_ok(ok).on_err(err);
}

#[fission_reducer(LibraryPrepared)]
pub fn library_prepared(_state: &mut ReadingListState, ctx: &mut ReducerContext<ReadingListState>) {
    query_books(ctx);
}

#[fission_reducer(BooksLoaded)]
pub fn books_loaded(state: &mut ReadingListState, ctx: &mut ReducerContext<ReadingListState>) {
    if !matches!(state.phase, DatabasePhase::Loading | DatabasePhase::Refreshing(_)) { return; }
    match ctx.input.sql_rows().ok_or("reading.error.records").and_then(decode_books) {
        Ok(books) => state.accept_loaded(books),
        Err(key) => {
            state.phase = DatabasePhase::Failed;
            state.reject(key);
        }
    }
}

#[fission_reducer(DatabaseFailed)]
pub fn database_failed(state: &mut ReadingListState, _ctx: &mut ReducerContext<ReadingListState>) {
    state.fail();
}
```

```rust
use crate::models::{matches_book, ReadingFilter, ReadingStatus, reading_status};
use crate::state::{DatabasePhase, ReadingListState};
use crate::widgets::book_card::ReadingBookCard;
use crate::storage::{prepare_library, PrepareLibrary};
use fission::prelude::*;

fission_component! {
    pub ReadingListDashboard<ReadingListState> {
        state { search: String = String::new(), filter: ReadingFilter = ReadingFilter::All }
    }
    view(dashboard, app, cx) {
        let tokens = &cx.view.env().theme.tokens;
        // Register before the shell dispatches its one startup action.
        let prepare = with_reducer!(cx.build, PrepareLibrary, prepare_library);
        let visible = app.books.iter().filter(|book| matches_book(book, &dashboard.search, dashboard.filter)).collect::<Vec<_>>();
        let reading = app.books.iter().filter(|book| reading_status(book) == ReadingStatus::Reading).count();
        let finished = app.books.iter().filter(|book| reading_status(book) == ReadingStatus::Finished).count();
    } =>
    Container(
        Scroll(
            semantic_label: Some(cx.tr("reading.title")),
            child: Container(Column(gap: tokens.spacing.l, children: [
                Text(cx.tr("reading.title")).size(tokens.typography.heading_size).weight(tokens.typography.font_weight_bold),
                Text(cx.tr("reading.description")).color(tokens.colors.text_secondary),
                Grid(columns: vec![GridTrack::auto_fit(GridTrack::minmax(GridTrack::Points(140.0), GridTrack::Fr(1.0)))],
                    rows: vec![GridTrack::Auto], column_gap: tokens.spacing.m, row_gap: tokens.spacing.m,
                    children: [
                        Stat(label: cx.tr("reading.metric.library"), value: app.books.len().to_string()),
                        Stat(label: cx.tr("reading.metric.current"), value: reading.to_string()),
                        Stat(label: cx.tr("reading.metric.finished"), value: finished.to_string()),
                    ]),
                Text(cx.tr("reading.library.read_only")),
                if app.is_busy() {
                    Row(gap: tokens.spacing.s, children: [
                        Spinner(motion: Some(SpinnerMotion::Default), label: Some(cx.tr("reading.loading"))),
                        Text(cx.tr("reading.loading")),
                    ])
                },
                if let Some(notice) = &app.notice {
                    Alert(kind: if notice.is_error() { AlertKind::Error } else { AlertKind::Info },
                        title: cx.tr(notice.key()))
                },
                if app.phase == DatabasePhase::Failed {
                    Button(child: Text(cx.tr("reading.action.reload")), key: "reload-library",
                        on_press: prepare)
                        .semantics_identifier("reading.reload-library".to_owned())
                },
                TextInput(label: Some(cx.tr("reading.search.label").into()),
                    placeholder: Some(cx.tr("reading.search.hint").into()),
                    bind: dashboard.search, semantics_identifier: "reading.search".to_owned()),
                Row(gap: tokens.spacing.s, wrap: ir_op::FlexWrap::Wrap, children: [
                    Button(child: Text(cx.tr("reading.filter.all")), key: "all",
                        variant: if dashboard.filter == ReadingFilter::All { ButtonVariant::Primary } else { ButtonVariant::Outline },
                        on_press: reduce { dashboard.filter = ReadingFilter::All; }),
                    Button(child: Text(cx.tr("reading.filter.reading")), key: "reading",
                        variant: if dashboard.filter == ReadingFilter::Reading { ButtonVariant::Primary } else { ButtonVariant::Outline },
                        on_press: reduce { dashboard.filter = ReadingFilter::Reading; }),
                    Button(child: Text(cx.tr("reading.filter.want_to_read")), key: "queued",
                        variant: if dashboard.filter == ReadingFilter::WantToRead { ButtonVariant::Primary } else { ButtonVariant::Outline },
                        on_press: reduce { dashboard.filter = ReadingFilter::WantToRead; }),
                    Button(child: Text(cx.tr("reading.filter.finished")), key: "finished",
                        variant: if dashboard.filter == ReadingFilter::Finished { ButtonVariant::Primary } else { ButtonVariant::Outline },
                        on_press: reduce { dashboard.filter = ReadingFilter::Finished; }),
                ]),
                if app.phase == DatabasePhase::Ready && app.books.is_empty() {
                    EmptyState(title: cx.tr("reading.empty.library"))
                } else if app.phase == DatabasePhase::Ready && visible.is_empty() {
                    Column(gap: tokens.spacing.s, children: [
                        EmptyState(title: cx.tr("reading.empty.search")),
                        Button(child: Text(cx.tr("reading.action.show_all")), key: "clear-search",
                            on_press: reduce { dashboard.search.clear(); dashboard.filter = ReadingFilter::All; }),
                    ])
                } else {
                    for book in visible {
                        ReadingBookCard(book.clone(), key: book.id)
                    }
                },
            ])).width_length(Length::percent(100.0)).max_width(960.0)
                .padding_all(tokens.spacing.l).bg(tokens.colors.background),
        )
    ).height_length(Length::vh(100.0))
}
```

```rust
use std::collections::HashMap;
use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in [
        ("en-US", include_str!("../i18n/en-US.yaml")),
        ("es-ES", include_str!("../i18n/es-ES.yaml")),
    ] {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid reading-list translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}
```

## Add a book and record the page actually reached

An “add twenty pages” button does not record where the reader stopped. Each card instead accepts an absolute page number from zero through that edition's final page. This also lets someone correct an earlier bookmark. The reducer validates the value against the current record before queuing a parameterised update; the SQL statement checks the total again.

The add form snapshots its title, author and page-count draft when submitted. While the request runs, the fields remain editable, but a second database operation cannot start. On confirmed completion and refresh, the app clears the draft only if it still equals the submitted snapshot. A slow write must not erase the next book someone has started typing.

Use SQL parameters for every user value. An apostrophe, quotation mark or SQL-looking title stays data rather than becoming part of the statement. Bookmarks and removals address the database ID, not the title or current list position.

The database phase also guards the state methods. Disabling a button helps the user understand pending work, but does not itself prevent overlapping requests. This workbench serialises its own operations; it does not promise conflict resolution between independent app instances.

```rust
use crate::models::parse_page;
use crate::state::{DatabasePhase, PendingWrite, ReadingListState};
use crate::storage::{insert_statement, query_books, DatabaseFailed, database_failed};
use fission::prelude::*;

pub fn add_book(state: &mut ReadingListState, ctx: &mut ReducerContext<ReadingListState>) {
    if !state.can_write() { return; }
    if state.books.len() >= 500 { state.reject("reading.error.library_limit"); return; }
    let submitted = state.draft();
    let input = match submitted.validate() { Ok(input) => input, Err(key) => { state.reject(key); return; } };
    state.phase = DatabasePhase::Executing(PendingWrite::Add(submitted));
    state.notice = None;
    let ok = ctx.effects.bind(WriteCompleted, reduce_with!(write_completed));
    let err = ctx.effects.bind(DatabaseFailed, reduce_with!(database_failed));
    ctx.effects.sql().execute(insert_statement(&input))
        .on_ok(ok).on_err(err);
}

pub fn set_page(state: &mut ReadingListState, ctx: &mut ReducerContext<ReadingListState>, id: i64, source: &str) {
    if !state.can_write() { return; }
    let Some(book) = state.books.iter().find(|book| book.id == id) else {
        state.reject("reading.error.book_missing"); return;
    };
    let page = match parse_page(source, book.total_pages) { Ok(page) => page, Err(key) => { state.reject(key); return; } };
    state.phase = DatabasePhase::Executing(PendingWrite::Progress);
    state.notice = None;
    let ok = ctx.effects.bind(WriteCompleted, reduce_with!(write_completed));
    let err = ctx.effects.bind(DatabaseFailed, reduce_with!(database_failed));
    ctx.effects.sql().execute(SqlStatement::new(
        "UPDATE reading_books SET pages_read = ?1 WHERE id = ?2 AND total_pages >= ?1"
    ).bind(i64::from(page)).bind(id))
        .on_ok(ok).on_err(err);
}

pub fn remove_book(state: &mut ReadingListState, ctx: &mut ReducerContext<ReadingListState>, id: i64) {
    if !state.can_write() { return; }
    if !state.books.iter().any(|book| book.id == id) { state.reject("reading.error.book_missing"); return; }
    state.phase = DatabasePhase::Executing(PendingWrite::Remove);
    state.notice = None;
    let ok = ctx.effects.bind(WriteCompleted, reduce_with!(write_completed));
    let err = ctx.effects.bind(DatabaseFailed, reduce_with!(database_failed));
    ctx.effects.sql().execute(SqlStatement::new("DELETE FROM reading_books WHERE id = ?1").bind(id))
        .on_ok(ok).on_err(err);
}

#[fission_reducer(WriteCompleted)]
pub fn write_completed(state: &mut ReadingListState, ctx: &mut ReducerContext<ReadingListState>) {
    let DatabasePhase::Executing(write) = state.phase.clone() else { return; };
    if !ctx.input.sql_execute_result().is_some_and(|result| result.affected_rows == 1) {
        // A transport error or missing row is not permission to repeat an insert.
        state.fail();
        return;
    }
    state.phase = DatabasePhase::Refreshing(write);
    query_books(ctx);
}
```

<!-- fission:step id="persist-and-recover" -->
## Treat an uncertain write differently from a rejected draft

A local validation error means no request was issued. A database or transport failure can mean something else: the operation may have reached SQLite but the response or subsequent read failed. Automatically repeating an insert could then create a duplicate.

After such a failure, keep the draft and last confirmed list, disable further writes and offer a read-only reload through the normal migration/query path. Ask the reader to inspect that result before explicitly resubmitting. The app never changes providers or claims a failed refresh rolled back an earlier committed write.

A successful SQL execute must report one affected row. A missing row cannot be reported as a saved bookmark or successful removal. After a confirmed execute, reload the list before presenting the final result. Strict decoding still applies; unexpected records keep the app in its failure state instead of producing a misleading partial list.

Add focused tests for these rules. They check validation, bound parameters, record decoding and ownership of asynchronous drafts. The startup reducer must be registered unconditionally by the initial view, and each completion is explicitly bound before queuing its effect. Source tests alone do not establish that runtime flow: exercise loading, writing and reopening the real app as well.

```rust
use crate::models::{BookInput, ReadingBook};
use crate::state::{DatabasePhase, ReadingListState};
use fission::prelude::*;

pub fn insert_statement(book: &BookInput) -> SqlStatement {
    SqlStatement::new("INSERT INTO reading_books (title, author, total_pages) VALUES (?1, ?2, ?3)")
        .bind(book.title.clone()).bind(book.author.clone()).bind(i64::from(book.total_pages))
}

pub fn query_books(ctx: &mut ReducerContext<ReadingListState>) {
    let ok = ctx.effects.bind(BooksLoaded, reduce_with!(books_loaded));
    let err = ctx.effects.bind(DatabaseFailed, reduce_with!(database_failed));
    ctx.effects.sql().query(SqlStatement::new(
        "SELECT id, title, author, total_pages, pages_read FROM reading_books ORDER BY id DESC LIMIT 501"
    )).on_ok(ok).on_err(err);
}

pub fn decode_books(rows: SqlRows) -> Result<Vec<ReadingBook>, &'static str> {
    if rows.rows.len() > 500 { return Err("reading.error.library_limit"); }
    rows.rows.into_iter().map(|row| {
        let book = ReadingBook {
            id: row.get("id").map_err(|_| "reading.error.records")?,
            title: row.get("title").map_err(|_| "reading.error.records")?,
            author: row.get("author").map_err(|_| "reading.error.records")?,
            total_pages: u32::try_from(row.get::<i64>("total_pages").map_err(|_| "reading.error.records")?)
                .map_err(|_| "reading.error.records")?,
            pages_read: u32::try_from(row.get::<i64>("pages_read").map_err(|_| "reading.error.records")?)
                .map_err(|_| "reading.error.records")?,
        };
        if book.id <= 0 || book.title.trim().is_empty() || book.author.trim().is_empty()
            || book.title.chars().count() > 160 || book.author.chars().count() > 160
            || !(1..=100_000).contains(&book.total_pages) || book.pages_read > book.total_pages {
            return Err("reading.error.records");
        }
        Ok(book)
    }).collect()
}

#[fission_reducer(PrepareLibrary)]
pub fn prepare_library(state: &mut ReadingListState, ctx: &mut ReducerContext<ReadingListState>) {
    if matches!(state.phase, DatabasePhase::Executing(_) | DatabasePhase::Refreshing(_)) { return; }
    state.phase = DatabasePhase::Loading;
    state.notice = None;
    let mut migrations = SqlMigrations::new();
    migrations.add(SqlMigration::new(1, "reading library",
        "CREATE TABLE reading_books (
            id INTEGER PRIMARY KEY,
            title TEXT NOT NULL CHECK (length(trim(title)) BETWEEN 1 AND 160),
            author TEXT NOT NULL CHECK (length(trim(author)) BETWEEN 1 AND 160),
            total_pages INTEGER NOT NULL CHECK (total_pages BETWEEN 1 AND 100000),
            pages_read INTEGER NOT NULL DEFAULT 0 CHECK (pages_read BETWEEN 0 AND total_pages)
        );"
    )).expect("one migration with a unique version");
    let ok = ctx.effects.bind(LibraryPrepared, reduce_with!(library_prepared));
    let err = ctx.effects.bind(DatabaseFailed, reduce_with!(database_failed));
    ctx.effects.sql().migrate(migrations)
        .on_ok(ok).on_err(err);
}

#[fission_reducer(LibraryPrepared)]
pub fn library_prepared(_state: &mut ReadingListState, ctx: &mut ReducerContext<ReadingListState>) {
    query_books(ctx);
}

#[fission_reducer(BooksLoaded)]
pub fn books_loaded(state: &mut ReadingListState, ctx: &mut ReducerContext<ReadingListState>) {
    if !matches!(state.phase, DatabasePhase::Loading | DatabasePhase::Refreshing(_)) { return; }
    match ctx.input.sql_rows().ok_or("reading.error.records").and_then(decode_books) {
        Ok(books) => state.accept_loaded(books),
        Err(key) => {
            state.phase = DatabasePhase::Failed;
            state.reject(key);
        }
    }
}

#[fission_reducer(DatabaseFailed)]
pub fn database_failed(state: &mut ReadingListState, _ctx: &mut ReducerContext<ReadingListState>) {
    state.fail();
}
```

## Run against the actual provider

```sh
cargo test --lib
fission doctor --project-dir .
fission run --target web --project-dir .
```

Web storage requires a secure context, the generated SQLite assets and these response headers on the page and its same-origin assets:

```text
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

The CLI configures its Web development server when the storage capability is enabled. Production hosting must supply the same requirements. An embedded preview also depends on the containing documentation page's isolation policy; a static host that cannot set these headers cannot demonstrate OPFS storage correctly. Use the runnable project on a suitable host to qualify persistence until that documentation-hosting requirement is met.

The native launcher uses the same actions with its native SQLite provider. Records remain local to that installation or browser origin. This tutorial does not add account synchronisation, a shared server library or multi-writer conflict detection.

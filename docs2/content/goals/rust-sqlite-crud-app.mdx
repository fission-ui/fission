A useful reading list answers everyday questions: what did I mean to read next, where did I stop, and which books have I finished? We will build Harbour Reads, a small library for a book club that tracks those details without turning the screen into a spreadsheet. Each entry stores its title, author, total pages, and pages read. From that record the app derives “Want to read”, “Reading”, or “Finished”.

The screen begins with four sample books so you can see a believable library before entering anything. You will add a book, search and filter the list, record progress, and remove an entry. Then we will move each change behind Fission’s asynchronous SQLite effects. The interactive article preview uses in-memory records so you can exercise the workflow in a browser; the runnable Web app uses SQLite reducers shown in the final step, with the same fields and actions.

## Create the Web project and enable storage

Scaffold the Web target and ask Fission to install its storage capability. The capability selects SQLite for Web, adds the worker and browser assets, and configures the headers used by the local server.

## Shape the library around a reader’s next decision

Start with the book record and the information a reader needs to choose what to read next. A page count makes progress measurable, while keeping title and author together helps distinguish books with similar names. “Finished” is derived from the page counters; there is no separate status value that could disagree with them.

The migration below also protects the data if another screen or job writes to the same table. It rejects blank names, zero-page records, negative progress, and progress beyond the final page. The title index gives larger libraries a useful starting point for title lookup.

use fission::sql::{SqlMigration, SqlMigrations};

pub fn reading_list_migrations() -> anyhow::Result<SqlMigrations> {
    let mut migrations = SqlMigrations::new();
    migrations.add(SqlMigration::new(
        1,
        "create reading books",
        "CREATE TABLE reading_books (
            id INTEGER PRIMARY KEY,
            title TEXT NOT NULL CHECK (length(trim(title)) > 0),
            author TEXT NOT NULL CHECK (length(trim(author)) > 0),
            total_pages INTEGER NOT NULL CHECK (total_pages > 0),
            pages_read INTEGER NOT NULL DEFAULT 0
                CHECK (pages_read >= 0 AND pages_read <= total_pages),
            added_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
        );
        CREATE INDEX reading_books_title_idx
            ON reading_books(title COLLATE NOCASE);",
    ))?;
    Ok(migrations)
}

## Add books, search the library, and log a reading session

A create form needs enough information to make a useful record. The title and author stay in app state while a book is being added; the page-count field is parsed as a positive integer before the reducer accepts it. An invalid value leaves the library unchanged and explains which input needs attention.

Search and status filters are local to the dashboard because they only change what this screen shows. The library itself lives in app state. Every row uses a stable book ID, so adding or removing a record does not make Fission treat another book as the same widget. The progress action records a reading session and caps the count at the last page. A finished book cannot advance beyond its total. Removing an entry changes the list and confirms which title was removed.

This step uses in-memory reducers so the article preview responds to each action. In the runnable app, keep these action names and replace their in-memory updates with the parameterized SQL effects in the next step.

pub struct ReadingListState {
    pub books: Vec<ReadingBook>,
    pub next_book_id: u32,
    pub title_draft: String,
    pub author_draft: String,
    pub page_count_draft: String,
    pub notice: String,
    pub has_error: bool,
    pub is_loading: bool,
    pub is_saving: bool,
}

impl Default for ReadingListState {
    fn default() -> Self {
        Self {
            books: sample_books(),
            next_book_id: 105,
            title_draft: String::new(),
            author_draft: String::new(),
            page_count_draft: String::new(),
            notice: "Your reading progress is up to date.".into(),
            has_error: false,
            is_loading: false,
            is_saving: false,
        }
    }
}
impl GlobalState for ReadingListState {}

#[fission_reducer(AddBook)]
pub fn on_add_book(state: &mut ReadingListState) {
    let title = state.title_draft.trim().to_string();
    let author = state.author_draft.trim().to_string();
    let total_pages = match state.page_count_draft.trim().parse::<u32>() {
        Ok(value) if value > 0 => value,
        _ => {
            state.notice = "Enter a page count greater than zero.".into();
            state.has_error = true;
            return;
        }
    };
    if title.is_empty() || author.is_empty() {
        state.notice = "Add both the book title and its author.".into();
        state.has_error = true;
        return;
    }

    let id = state.next_book_id;
    state.next_book_id = state.next_book_id.saturating_add(1);
    state.books.push(ReadingBook { id, title, author, total_pages, pages_read: 0 });
    state.title_draft.clear();
    state.author_draft.clear();
    state.page_count_draft.clear();
    state.notice = "Book added to your reading list.".into();
    state.has_error = false;
}

#[fission_reducer(LogPages)]
pub fn on_log_pages(state: &mut ReadingListState, book_id: u32, pages: u32) {
    let Some(book) = state.books.iter_mut().find(|book| book.id == book_id) else {
        state.notice = "That book is no longer in your library.".into();
        state.has_error = true;
        return;
    };
    book.pages_read = book.pages_read.saturating_add(pages).min(book.total_pages);
    state.notice = format!(
        "{}: now at {} of {} pages.", book.title, book.pages_read, book.total_pages
    );
    state.has_error = false;
}

#[fission_reducer(RemoveBook)]
pub fn on_remove_book(state: &mut ReadingListState, book_id: u32) {
    let title = state.books.iter().find(|book| book.id == book_id).map(|book| book.title.clone());
    state.books.retain(|book| book.id != book_id);
    if let Some(title) = title {
        state.notice = format!("{} was removed from your reading list.", title);
        state.has_error = false;
    }
}

## Persist each change and recover from storage errors

A database call can outlast a render, so reducers must not wait for it. Validate the submitted values, mark the save as pending, and queue an insert effect. A later reducer receives success or failure. Only a successful insert clears the draft and reloads the library; if SQLite reports an error, the app stops the loading state, keeps the reader’s draft, and displays the provider’s message.

The code tabs show the migration, read, progress, delete, and insert operations. Bind every value as a parameter so a title such as <em>The Book: Volume 2</em> remains data rather than becoming part of the SQL statement. Progress and deletion use the database ID because titles can repeat or change.

pub fn on_add_book(state: &mut ReadingListState) {
    let title = state.title_draft.trim().to_string();
    let author = state.author_draft.trim().to_string();
    let total_pages = match state.page_count_draft.trim().parse::<u32>() {
        Ok(value) if value > 0 => value,
        _ => {
            state.notice = "Enter a page count greater than zero.".into();
            state.has_error = true;
            return;
        }
    };
    if title.is_empty() || author.is_empty() {
        state.notice = "Add both the book title and its author.".into();
        state.has_error = true;
        return;
    }

    let id = state.next_book_id;
    state.next_book_id = state.next_book_id.saturating_add(1);
    state.books.push(ReadingBook { id, title, author, total_pages, pages_read: 0 });
    state.title_draft.clear();
    state.author_draft.clear();
    state.page_count_draft.clear();
    state.notice = "Book added to your reading list.".into();
    state.has_error = false;
}

#[fission_reducer(LogPages)]
pub fn on_log_pages(state: &mut ReadingListState, book_id: u32, pages: u32) {
    let Some(book) = state.books.iter_mut().find(|book| book.id == book_id) else {
        state.notice = "That book is no longer in your library.".into();
        state.has_error = true;
        return;
    };
    book.pages_read = book.pages_read.saturating_add(pages).min(book.total_pages);
    state.notice = format!(
        "{}: now at {} of {} pages.", book.title, book.pages_read, book.total_pages
    );
    state.has_error = false;
}

#[fission_reducer(RemoveBook)]
pub fn on_remove_book(state: &mut ReadingListState, book_id: u32) {
    let title = state.books.iter().find(|book| book.id == book_id).map(|book| book.title.clone());
    state.books.retain(|book| book.id != book_id);
    if let Some(title) = title {
        state.notice = format!("{} was removed from your reading list.", title);
        state.has_error = false;
    }
}

use fission::prelude::*;
use crate::state::ReadingListState;

#[fission_reducer(PrepareReadingList)]
pub fn prepare_reading_list(
    _state: &mut ReadingListState,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    let mut migrations = SqlMigrations::new();
    migrations.add(SqlMigration::new(
        1,
        "create reading books",
        "CREATE TABLE reading_books (
            id INTEGER PRIMARY KEY,
            title TEXT NOT NULL CHECK (length(trim(title)) > 0),
            author TEXT NOT NULL CHECK (length(trim(author)) > 0),
            total_pages INTEGER NOT NULL CHECK (total_pages > 0),
            pages_read INTEGER NOT NULL DEFAULT 0
                CHECK (pages_read >= 0 AND pages_read <= total_pages),
            added_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
        );
        CREATE INDEX reading_books_title_idx
            ON reading_books(title COLLATE NOCASE);",
    )).expect("migration versions are unique");

    ctx.effects.sql().migrate(migrations)
        .on_ok(ActionEnvelope::from(LoadBooks))
        .on_err(ActionEnvelope::from(DatabaseFailed));
}

use fission::prelude::*;
use fission::sql::SqlStatement;
use crate::models::ReadingBook;
use crate::state::ReadingListState;

#[fission_reducer(LoadBooks)]
pub fn load_books(
    state: &mut ReadingListState,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    state.is_loading = true;
    ctx.effects.sql().query(SqlStatement::new(
        "SELECT id, title, author, total_pages, pages_read
         FROM reading_books ORDER BY added_at DESC, id DESC",
    ))
    .on_ok(ActionEnvelope::from(BooksLoaded))
    .on_err(ActionEnvelope::from(DatabaseFailed));
}

#[fission_reducer(AddBook)]
pub fn on_add_book(
    state: &mut ReadingListState,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    let title = state.title_draft.trim().to_string();
    let author = state.author_draft.trim().to_string();
    let total_pages = match state.page_count_draft.trim().parse::<u32>() {
        Ok(value) if value > 0 => value,
        _ => {
            state.notice = "Enter a page count greater than zero.".into();
            state.has_error = true;
            return;
        }
    };
    if title.is_empty() || author.is_empty() {
        state.notice = "Add both the book title and its author.".into();
        state.has_error = true;
        return;
    }

    state.is_saving = true;
    state.has_error = false;
    let statement = SqlStatement::new(
        "INSERT INTO reading_books (title, author, total_pages)
         VALUES (?1, ?2, ?3)",
    )
    .bind(title)
    .bind(author)
    .bind(i64::from(total_pages));

    ctx.effects.sql().execute(statement)
        .on_ok(ActionEnvelope::from(BookInserted))
        .on_err(ActionEnvelope::from(DatabaseFailed));
}

#[fission_reducer(BookInserted)]
pub fn book_inserted(
    state: &mut ReadingListState,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    state.is_saving = false;
    state.title_draft.clear();
    state.author_draft.clear();
    state.page_count_draft.clear();
    state.notice = "Book added to your reading list.".into();
    ctx.effects.sql().query(SqlStatement::new(
        "SELECT id, title, author, total_pages, pages_read
         FROM reading_books ORDER BY added_at DESC, id DESC",
    ))
    .on_ok(ActionEnvelope::from(BooksLoaded))
    .on_err(ActionEnvelope::from(DatabaseFailed));
}

#[fission_reducer(BooksLoaded)]
pub fn books_loaded(
    state: &mut ReadingListState,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    let Some(rows) = ctx.input.sql_rows() else { return; };
    state.books = rows.rows.iter().filter_map(|row| Some(ReadingBook {
        id: u32::try_from(row.get::<i64>("id").ok()?).ok()?,
        title: row.get::<String>("title").ok()?,
        author: row.get::<String>("author").ok()?,
        total_pages: u32::try_from(row.get::<i64>("total_pages").ok()?).ok()?,
        pages_read: u32::try_from(row.get::<i64>("pages_read").ok()?).ok()?,
    })).collect();
    state.is_loading = false;
    state.is_saving = false;
    state.has_error = false;
    state.notice = format!("{} books in your library.", state.books.len());
}

#[fission_reducer(LogPages)]
pub fn on_log_pages(
    state: &mut ReadingListState,
    book_id: u32,
    pages: u32,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    state.is_saving = true;
    let statement = SqlStatement::new(
        "UPDATE reading_books
         SET pages_read = MIN(pages_read + ?1, total_pages)
         WHERE id = ?2",
    )
    .bind(i64::from(pages))
    .bind(i64::from(book_id));
    ctx.effects.sql().execute(statement)
        .on_ok(ActionEnvelope::from(LoadBooks))
        .on_err(ActionEnvelope::from(DatabaseFailed));
}

#[fission_reducer(RemoveBook)]
pub fn on_remove_book(
    state: &mut ReadingListState,
    book_id: u32,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    state.is_saving = true;
    let statement = SqlStatement::new("DELETE FROM reading_books WHERE id = ?1")
        .bind(i64::from(book_id));
    ctx.effects.sql().execute(statement)
        .on_ok(ActionEnvelope::from(LoadBooks))
        .on_err(ActionEnvelope::from(DatabaseFailed));
}

#[fission_reducer(DatabaseFailed)]
pub fn database_failed(
    state: &mut ReadingListState,
    ctx: &mut ReducerContext<ReadingListState>,
) {
    state.is_loading = false;
    state.is_saving = false;
    state.has_error = true;
    state.notice = ctx.input.sql_error().map(|error| error.message)
        .unwrap_or_else(|| "The library could not be updated. Your draft is still here.".into());
}

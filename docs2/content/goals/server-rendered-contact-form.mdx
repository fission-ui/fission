Harbour Supply’s support team needs enough detail to investigate a delayed or damaged shipment without making the customer repeat the story. This walkthrough builds the form and an in-memory preview of its validation. It does not submit to a server or send email. Client-side checks are useful feedback, not a security boundary.

Install the Fission CLI and scaffold a Web project for the interactive preview:

```sh
cargo install cargo-fission
fission init harbour-contact
cd harbour-contact
cargo add serde_yaml
fission add-target web --project-dir .
```

## Project layout

```text
harbour-contact/
├── Cargo.toml                 # generated dependencies
├── fission.toml               # app identity, targets and capabilities
├── src/
│   ├── main.rs                 # generated Web entrypoint
│   ├── lib.rs                  # shared app setup
│   └── app.rs                  # form fields and local validation state
├── platforms/                  # generated host files after add-target
└── tests/                      # project-specific flow checks
```

The component owns the visible draft and correction messages. The preview checks the fields in memory and shows which value needs attention. This example does not implement a server action or message delivery; a real support form still needs server-side validation and a delivery path.

## Create labelled contact fields

Ask for details support can act on: who is writing, where to reply, which shipment needs attention, and what went wrong. Separate fields let the preview point to the answer that needs fixing.

use fission::prelude::*;
fission_component! {
    pub ContactForm<()> {
        state {
            name: String = String::new(),
            email: String = String::new(),
            subject: String = String::new(),
            message: String = String::new(),
        }
    }
    view(preview, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Container(
        Column(
            gap: tokens.spacing.m,
            children: [
                Text(cx.tr("contact.form.title")).weight(tokens.typography.font_weight_bold),
                Text(cx.tr("contact.form.detail")).color(tokens.colors.text_secondary),
                TextInput(label: Some(cx.tr("contact.name.label").into()),
                    placeholder: Some(cx.tr("contact.name.placeholder").into()),
                    required: true,
                    bind: preview.name,
                    key: "contact-name",
                    semantics_identifier: "harbour.contact.name".to_string()),
                TextInput(label: Some(cx.tr("contact.email.label").into()),
                    placeholder: Some(cx.tr("contact.email.placeholder").into()),
                    required: true,
                    bind: preview.email,
                    key: "contact-email",
                    semantics_identifier: "harbour.contact.email".to_string()),
                TextInput(label: Some(cx.tr("contact.subject.label").into()),
                    placeholder: Some(cx.tr("contact.subject.placeholder").into()),
                    required: true,
                    bind: preview.subject,
                    key: "contact-subject",
                    semantics_identifier: "harbour.contact.subject".to_string()),
                TextInput(label: Some(cx.tr("contact.message.label").into()),
                    placeholder: Some(cx.tr("contact.message.placeholder").into()),
                    required: true,
                    multiline: true,
                    min_lines: Some(4),
                    max_lines: Some(7),

                    semantics_identifier: "harbour.contact.message".to_string()),

    .padding_all(tokens.spacing.l)

    .border(tokens.colors.border, 1.0)

use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

const SOURCES: [(&str, &str); 2] = [
    ("en-US", include_str!("../i18n/en-US.yaml")),
    ("es-ES", include_str!("../i18n/es-ES.yaml")),
];

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in SOURCES {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid contact form translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}

## Validate the draft and preserve what the customer entered

This step adds local validation so the preview can show how the form should respond to incomplete details. Each field stays in the component’s retained state, and the submit reducer records a translation key for the field that needs attention. A valid draft gets a clear “ready” message, but the preview does not submit it or send email. This example does not include the server-side action or delivery path. A production form must validate the request on the server before it accepts it.

The form can be taller than a phone screen, so a vertical `Scroll` keeps every field reachable without shrinking them.

```rust
use fission::prelude::*;

fission_component! {
    pub ContactForm<()> {
        state {
            name: String = String::new(),
            email: String = String::new(),
            subject: String = String::new(),
            message: String = String::new(),
            submitted: bool = false,
            has_error: bool = false,
            error_field: String = String::new(),
            feedback: String = String::new(),
        }
    }
    view(form, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    Scroll(
        id: Some(WidgetId::explicit("harbour-contact-scroll")),
        flex_grow: 1.0,
        height: cx.view.viewport_size().height,
        semantic_label: Some(cx.tr("contact.form.semantics")),
        child: Container(Column(gap: tokens.spacing.m, children: [
            Row(gap: tokens.spacing.m, align_items: ir_op::AlignItems::Center, children: [
                Column(gap: tokens.spacing.xs, children: [
                    Text(cx.tr("contact.brand")).weight(tokens.typography.font_weight_bold),
                    Text(cx.tr("contact.team")).color(tokens.colors.text_secondary),
                ]),
                Spacer(flex_grow: 1.0),
                Badge(text: cx.tr("contact.badge")),
            ]),
            Column(gap: tokens.spacing.xs, children: [
                Text(cx.tr("contact.form.title")).weight(tokens.typography.font_weight_semibold),
                Text(cx.tr("contact.form.detail")).color(tokens.colors.text_secondary),
            ]),
            TextInput(
                label: Some(cx.tr("contact.name.label").into()),
                placeholder: Some(cx.tr("contact.name.placeholder").into()),
                required: true,
                name: Some("name".into()),
                bind: form.name,
                key: "contact-name",
                semantics_identifier: "harbour.contact.name".to_string(),
                error_text: if form.error_field == "name" { Some(cx.tr(form.feedback.as_str()).into()) } else { None },
            ),
            TextInput(
                label: Some(cx.tr("contact.email.label").into()),
                placeholder: Some(cx.tr("contact.email.placeholder").into()),
                required: true,
                name: Some("email".into()),
                keyboard_type: TextInputType::EmailAddress,
                bind: form.email,
                key: "contact-email",
                semantics_identifier: "harbour.contact.email".to_string(),
                error_text: if form.error_field == "email" { Some(cx.tr(form.feedback.as_str()).into()) } else { None },
            ),
            TextInput(
                label: Some(cx.tr("contact.subject.label").into()),
                placeholder: Some(cx.tr("contact.subject.placeholder").into()),
                required: true,
                name: Some("subject".into()),
                bind: form.subject,
                key: "contact-subject",
                semantics_identifier: "harbour.contact.subject".to_string(),
                error_text: if form.error_field == "subject" { Some(cx.tr(form.feedback.as_str()).into()) } else { None },
            ),
            TextInput(
                label: Some(cx.tr("contact.message.label").into()),
                placeholder: Some(cx.tr("contact.message.placeholder").into()),
                required: true,
                name: Some("message".into()),
                multiline: true,
                min_lines: Some(4),
                max_lines: Some(7),
                max_length: Some(2000),
                bind: form.message,
                key: "contact-message",
                semantics_identifier: "harbour.contact.message".to_string(),
                error_text: if form.error_field == "message" { Some(cx.tr(form.feedback.as_str()).into()) } else { None },
            ),
            if form.has_error || form.submitted {
                SemanticsRegion(
                    identifier: Some(if form.has_error {
                        "harbour-contact-error".to_string()
                    } else {
                        "harbour-contact-success".to_string()
                    }),
                    label: Some(cx.tr(form.feedback.as_str())),
                    child: Text(if form.has_error {
                        cx.tr("contact.error.generic")
                    } else {
                        cx.tr(form.feedback.as_str())
                    })
                        .color(tokens.colors.text_secondary),
                )
            } else {
                Text(cx.tr("contact.email.reply_note"))
                    .color(tokens.colors.text_secondary)
            },
            if form.submitted {
                Button(
                    child: Text(cx.tr("contact.action.new")),
                    key: "new-contact-message",
                    variant: ButtonVariant::Outline,
                    on_press: reduce {
                        form.name.clear();
                        form.email.clear();
                        form.subject.clear();
                        form.message.clear();
                        form.submitted = false;
                        form.has_error = false;
                        form.error_field.clear();
                        form.feedback.clear();
                    },
                )
                .semantics_identifier("harbour.contact.new-message".to_string())
            } else {
                Button(
                    child: Text(cx.tr("contact.action.send")),
                    key: "send-contact-message",
                    on_press: reduce {
                        let name = form.name.trim();
                        let email = form.email.trim();
                        let subject = form.subject.trim();
                        let message = form.message.trim();

                        if name.len() < 2 {
                            form.feedback = "contact.error.name".to_string();
                            form.error_field = "name".to_string();
                            form.has_error = true;
                            form.submitted = false;
                        } else if !email.contains('@')
                            || !email.split('@').last().unwrap_or("").contains('.')
                        {
                            form.feedback = "contact.error.email".to_string();
                            form.error_field = "email".to_string();
                            form.has_error = true;
                            form.submitted = false;
                        } else if subject.len() < 5 {
                            form.feedback = "contact.error.subject".to_string();
                            form.error_field = "subject".to_string();
                            form.has_error = true;
                            form.submitted = false;
                        } else if message.len() < 20 {
                            form.feedback = "contact.error.message".to_string();
                            form.error_field = "message".to_string();
                            form.has_error = true;
                            form.submitted = false;
                        } else {
                            form.feedback = "contact.success.preview".to_string();
                            form.has_error = false;
                            form.error_field.clear();
                            form.submitted = true;
                        }
                    },
                )
                .semantics_identifier("harbour.contact.check-message".to_string())
            },
            Text(cx.tr("contact.preview.note"))
                .color(tokens.colors.text_secondary),
        ]))
            .padding_all(tokens.spacing.l)
            .bg(tokens.colors.surface)
            .border(tokens.colors.border, 1.0)
            .border_radius(tokens.radii.large),
    )
}
```

## Keep the draft when a field needs correction

Try a short message or malformed reply address. The preview stores the translation key for the field error and keeps every entered value, so the customer can correct one answer without starting again. After the example, a real SSR app still needs a server-side validation and delivery implementation; this screen does not claim to provide one.

A dropdown that only works with a mouse is not enough for site navigation. It needs real page routes, keyboard support and links that still work when scripting is unavailable. We will build the Products menu as part of a static Rust site, then check the pointer, keyboard and touch paths in the preview.

Harbour's Products menu links to the overview, desktop apps and mobile apps. The Products label remains a normal link when the menu is closed, so a visitor does not have to discover a special interaction just to reach the overview.

Install the Fission CLI and scaffold the Static site project:

```sh
cargo install cargo-fission
fission init harbour-site --template website
cd harbour-site
cargo add serde_yaml
```

The website template gives you a Static site entrypoint in `src/main.rs`, route registration and the Web shell in `src/lib.rs`, plus separate modules for the page, navigation and footer. Add the task files as you reach them. The preview's `src/app.rs` is a separate browser app used to try the lesson; the actual website uses the template modules and `fission.toml`. Keep those two pieces separate—`preview/lib.rs` is not the website entrypoint.

### Configure the site routes and Products dropdown

The Static site template turns `[[site.nav]]` into Fission's shared navigation component. Give the parent item its own useful destination, then add the nested product links beneath it. That way pointer and keyboard users can reach the same pages.

Merge the following fields into the template’s existing `[site]` table, then add the route and navigation entries below it. Edit the existing table instead of adding a second `[site]` table:

```toml
[site]
title = "Harbour"
description = "A project hub for Harbour desktop and mobile apps."
base_url = "https://harbour.example.com"
asset_dirs = ["assets"]
generate_sitemap = true
generate_robots = true

[[site.routes]]
kind = "content"
path = "/products"
source = "content/products"
template = "fission::site::documentation"

[[site.nav]]
title = "Products"
href = "/products/"

[[site.nav.children]]
title = "Desktop apps"
href = "/products/desktop/"

[[site.nav.children]]
title = "Mobile apps"
href = "/products/mobile/"
```

Create `content/products/index.mdx`, `desktop.mdx` and `mobile.mdx`. Give each page a distinct title and search description. Fission's navigation component already owns the menu interaction and semantics, so do not add another copy of that state to the page. Check that Products still works as a link, the nested items open from both keyboard and pointer input, and every direct URL loads after a refresh.

## Render product links in the site header

The preview is Harbour's product site header with working destinations. Choose Products, Desktop apps, or Mobile apps and the page content changes; the next step turns the product links into an accessible dropdown.

```rust
use fission::prelude::*;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
enum ProductPage {
    Overview,
    Desktop,
    Mobile,
}

fission_component! {
    pub WebsiteNavigation<()> {
        state {
            active_page: ProductPage = ProductPage::Overview,
        }
    }
    view(site, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    SemanticsRegion(
        identifier: Some("harbour.site".to_string()),
        label: Some(cx.tr("site.a11y")),
        child: Container(
            Column(gap: tokens.spacing.m, children: [
                Row(gap: tokens.spacing.s, align_items: ir_op::AlignItems::Center, children: [
                    Text(cx.tr("brand")).size(tokens.typography.heading2_size),
                    Spacer(flex_grow: 1.0),
                    Button(child: Text(cx.tr("nav.products")), key: "products",
                        on_press: reduce { site.active_page = ProductPage::Overview; })
                        .semantics_identifier("harbour.nav.products"),
                    Button(child: Text(cx.tr("nav.desktop")), key: "desktop",
                        on_press: reduce { site.active_page = ProductPage::Desktop; })
                        .semantics_identifier("harbour.nav.desktop"),
                    Button(child: Text(cx.tr("nav.mobile")), key: "mobile",
                        on_press: reduce { site.active_page = ProductPage::Mobile; })
                        .semantics_identifier("harbour.nav.mobile"),
                ]),
                Divider(),
                Column(gap: tokens.spacing.s, children: [
                    Text(if site.active_page == ProductPage::Desktop {
                        cx.tr("page.desktop.title")
                    } else if site.active_page == ProductPage::Mobile {
                        cx.tr("page.mobile.title")
                    } else {
                        cx.tr("page.products.title")
                    })
                    .size(tokens.typography.heading1_size),
                    Text(if site.active_page == ProductPage::Desktop {
                        cx.tr("page.desktop.description")
                    } else if site.active_page == ProductPage::Mobile {
                        cx.tr("page.mobile.description")
                    } else {
                        cx.tr("page.products.description")
                    })
                    .color(tokens.colors.text_secondary),
                    Text(if site.active_page == ProductPage::Desktop {
                        cx.tr("page.desktop.platforms")
                    } else if site.active_page == ProductPage::Mobile {
                        cx.tr("page.mobile.platforms")
                    } else {
                        cx.tr("page.products.detail")
                    }),
                ]),
            ])
        )
        .padding_all(tokens.spacing.l)
        .bg(tokens.colors.surface)
    )
}
```

```rust
use fission::i18n::{Locale, TranslationBundle};
use fission::prelude::*;
use std::collections::HashMap;

const SOURCES: [(&str, &str); 2] = [
    ("en-US", include_str!("../i18n/en-US.yaml")),
    ("es-ES", include_str!("../i18n/es-ES.yaml")),
];

pub fn create_env() -> Env {
    let mut env = Env::default();
    env.locale = Locale::from("en-US");
    for (locale, source) in SOURCES {
        let messages: HashMap<String, String> =
            serde_yaml::from_str(source).expect("valid tutorial translations");
        env.i18n.add_bundle(TranslationBundle {
            locale: Locale::from(locale),
            messages,
        });
    }
    env
}
```

## Add an open and close state

The Products menu needs one piece of retained state: whether it is open. Keep that state in the navigation component because no other screen needs it. Use a Fission `Button` for the toggle so focus, Enter, Space and pointer activation all use the same control.

Keep the Products overview available when the menu is closed. The preview shows the menu opening and closing, then changes the page when a destination is chosen. The menu-open value belongs in the retained navigation component; shared data across routes belongs in `GlobalState` and changes through reducers.
<Tabs>

```rust
use fission::prelude::*;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
enum ProductPage {
    Overview,
    Desktop,
    Mobile,
    About,
}

fission_component! {
    pub WebsiteNavigation<()> {
        state {
            menu_open: bool = false,
            active_page: ProductPage = ProductPage::Overview,
        }
    }
    view(site, _state, cx) {
        let tokens = &cx.view.env().theme.tokens;
    } =>
    SemanticsRegion(
        identifier: Some("harbour.site".to_string()),
        label: Some(cx.tr("site.a11y")),
        child: Container(
            Column(gap: tokens.spacing.m, children: [
                Row(gap: tokens.spacing.m, align_items: ir_op::AlignItems::Center, children: [
                    Text(cx.tr("brand")).size(tokens.typography.heading2_size),
                    Spacer(flex_grow: 1.0),
                    Button(
                        child: Text(cx.tr("nav.products")),
                        key: "products-menu",
                        semantics: Some(Semantics {
                            label: Some(cx.tr("nav.products.a11y")),
                            identifier: Some("harbour.nav.products".to_string()),
                            expanded: Some(site.menu_open),
                            has_popup: Some(PopupKind::Menu),
                            ..Default::default()
                        }),
                        on_press: reduce { site.menu_open = !site.menu_open; },
                    ),
                    Button(
                        child: Text(cx.tr("nav.about")),
                        key: "about",
                        on_press: reduce {
                            site.active_page = ProductPage::About;
                            site.menu_open = false;
                        },
                    ).semantics_identifier("harbour.nav.about"),
                ]),
                if site.menu_open {
                    Container(
                        Column(gap: tokens.spacing.xs, children: [
                            Button(
                                child: Text(cx.tr("nav.overview")),
                                key: "products-overview",
                                on_press: reduce {
                                    site.active_page = ProductPage::Overview;
                                    site.menu_open = false;
                                },
                            ).semantics_identifier("harbour.nav.products.overview"),
                            Button(
                                child: Text(cx.tr("nav.desktop")),
                                key: "desktop-link",
                                on_press: reduce {
                                    site.active_page = ProductPage::Desktop;
                                    site.menu_open = false;
                                },
                            ).semantics_identifier("harbour.nav.products.desktop"),
                            Button(
                                child: Text(cx.tr("nav.mobile")),
                                key: "mobile-link",
                                on_press: reduce {
                                    site.active_page = ProductPage::Mobile;
                                    site.menu_open = false;
                                },
                            ).semantics_identifier("harbour.nav.products.mobile"),
                        ]),
                    )
                    .padding_all(tokens.spacing.s)
                    .bg(tokens.colors.surface_raised)
                    .border(tokens.colors.border, 1.0)
                    .border_radius(tokens.radii.medium)
                },
                Divider(),
                Column(gap: tokens.spacing.s, children: [
                    Text(if site.active_page == ProductPage::Desktop {
                        cx.tr("page.desktop.title")
                    } else if site.active_page == ProductPage::Mobile {
                        cx.tr("page.mobile.title")
                    } else if site.active_page == ProductPage::About {
                        cx.tr("page.about.title")
                    } else {
                        cx.tr("page.products.title")
                    })
                    .size(tokens.typography.heading1_size),
                    Text(if site.active_page == ProductPage::Desktop {
                        cx.tr("page.desktop.description")
                    } else if site.active_page == ProductPage::Mobile {
                        cx.tr("page.mobile.description")
                    } else if site.active_page == ProductPage::About {
                        cx.tr("page.about.description")
                    } else {
                        cx.tr("page.products.description")
                    })
                    .color(tokens.colors.text_secondary),
                ]),
            ])
        )
        .padding_all(tokens.spacing.l)
        .bg(tokens.colors.surface)
    )
}
```

## Keep destinations usable on phones and by keyboard

Add the three Markdown routes and check that each one has a distinct title, a useful search description, a clear first heading and a next step. The compact layout stacks the menu entries so they still fit on a phone.

Use Tab to reach the Products button, press Enter or Space to open it, then use the same keys to choose a destination. The preview models those screen changes locally; in the published site, each destination is a normal link to its own Markdown route. There is no network request in this menu, so it does not need an effect.

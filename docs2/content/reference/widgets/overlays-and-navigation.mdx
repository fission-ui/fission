# Overlays and navigation

Use these widgets when content needs to sit above the current layout or when someone needs to move around your app.

Modals, popovers, menus, tooltips, and toasts cover the first job. Tabs, accordions, breadcrumbs, pagination, and routes cover the second.

An overlay changes where content is painted, but its interaction contract is a
separate responsibility. A modal also needs focus containment and dismissal;
a popup menu needs an anchor and command navigation. Use the specific widget
when it owns that complete contract. A raw portal or positioned box does not
become a dialog merely because it covers the page.

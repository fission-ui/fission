# Input widgets

Input widgets let people change a value or trigger an action.

The important boundary is the proposed change. A control dispatches an action;
the reducer decides whether that change is valid and updates the authoritative
state or requests an effect. Rendering a checked value, a range, or a disabled
button is not a substitute for validating the corresponding transition.

## Choosing among input widgets

Use the simplest control that fits the choice.

Use a button for an action, a checkbox or switch for a yes-or-no choice, a slider for a continuous value, and a text input for free-form editing. Use a select or segmented control when the options are known. Use a combobox when people need to type and choose from suggestions.

When the interaction becomes more specialized, move to lower-level gesture, drag, or editing helpers.

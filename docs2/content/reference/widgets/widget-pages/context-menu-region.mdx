# ContextMenuRegion

`ContextMenuRegion` attaches secondary-click actions to the content they
operate on. A document row can therefore offer Copy link without making the
whole page responsible for deciding which document was clicked.

The menu model accepts child widgets, not only strings. That lets applications render translated text, icons, badges, shortcuts, or product-specific rows while Fission handles the right-click activation and menu positioning.

## Example

```rust
use fission::core::ui::{ContextMenu, ContextMenuEntry, ContextMenuItem, ContextMenuRegion};
use fission::prelude::*;

fission_component! {
    pub DocumentActions<()> {
        props {
            content: Widget,
            copy_link: ActionEnvelope,
        }
    }
    view(document, _state, cx) {
        let menu = ContextMenu::with_items([
            ContextMenuEntry::Item(
                ContextMenuItem::new(
                    "copy-link",
                    Text::new(cx.tr("documents.copy_link")),
                ).on_select(document.copy_link.clone()),
            ),
        ]);
    } =>
    ContextMenuRegion(document.content.clone(), menu)
}
```

The menu entries are typed configuration values, so setup uses their ordinary
Rust constructors. Compose constructs the region around the supplied content.
The parent binds `copy_link` to the document and uses a durable document key
when creating each `DocumentActions` instance. The clipboard reducer should
report success only after its capability completes; opening a menu has not
copied anything. Keep an ordinary visible action available where users cannot
secondary-click.

## Fields

| Field | Type | Meaning | Notes / default behavior |
| --- | --- | --- | --- |
| `id` | `Option<WidgetId>` | Stable owner identity for the region and popup state. | Use an explicit id for menus in dynamic lists. |
| `child` | `Widget` | The visible subtree that can open the menu. | Any widget can be wrapped. |
| `menu` | `ContextMenu` | The menu entries and visual configuration. | Items can contain arbitrary child widgets. |
| `enabled` | `bool` | Whether secondary-click opens the menu. | Defaults to `true`. |
| `semantics` | `Option<Semantics>` | Optional semantics for the menu region owner. | Fission sets `context_menu = true` when enabled. |

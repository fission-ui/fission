# TimelineItem

`TimelineItem` describes one event in a [`Timeline`](/reference/widgets/timeline),
such as an activity entry, message, deployment step, or support-history item.

## Example

```rust
use fission::prelude::*;

let item = TimelineItem {
    title: "Build finished".into(),
    description: Some("All checks passed on main.".into()),
    timestamp: Some("10:24".into()),
};
```

## Field table

| Field | Type | Meaning | Notes / default behavior |
| --- | --- | --- | --- |
| `title` | `String` | Main event label. | Required. |
| `description` | `Option<String>` | Supporting explanation below the title. | Defaults to `None`. |
| `timestamp` | `Option<String>` | Optional time or date label. | Defaults to `None`. Format it upstream. |

## Specific advice

Keep timestamps human-readable and consistent across items. A timeline becomes harder to scan if each item uses a different date or time format.

## Keep the event scannable

- Put the event in the title, add only decision-useful context in the description, and format the timestamp for the user's locale.
- If the entry is interactive or retained, use `TimelineLayout` and give its `TimelineEntry` a durable id.

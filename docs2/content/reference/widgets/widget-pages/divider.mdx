# Divider

`Divider` separates sections, rows, or tool groups inside one surface. It
gives the eye a break without putting every piece of content in its own card.

## Example

```rust
use fission::prelude::*;

// In view, the settings sections are independently constructed components.
Column(children: [
    general_settings,
    Divider(),
    security_settings,
])
```

## Field table

| Field | Type | Meaning | Notes / default behavior |
| --- | --- | --- | --- |
| `orientation` | `Orientation` | Whether the line runs horizontally or vertically. | Defaults to `Orientation::Horizontal`. |
| `thickness` | `Option<f32>` | Line thickness in logical points. | Uses the theme recipe, then one point. |
| `color` | `Option<Color>` | Line colour override. | Uses the theme recipe or divider token. |
| `dash_pattern` | `Option<Vec<f32>>` | Alternating painted/unpainted lengths. | Absent means a solid separator. |

## Layout behavior

A horizontal divider fills available width while its thickness determines
height; the vertical form swaps those axes. It does not consume flexible
main-axis space. The widget exposes separator semantics as well as paint,
so it communicates grouping to assistive technology too.

## Specific advice

Use dividers to clarify grouping, not to draw a line between every single thing on screen. If every row gets a divider plus a card plus extra borders, the interface usually becomes noisier instead of clearer.

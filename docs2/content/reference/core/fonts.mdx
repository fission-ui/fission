# Fonts

Fission design-system codegen can embed font files into the generated Rust design-system type.

| Type | Meaning |
| --- | --- |
| `DesignAssetManifest` | Generated manifest with logos and fonts. |
| `DesignFontAsset` | Metadata for a font declared in the DSP. |
| `PackagedFont` | Embedded font bytes plus family, weight, style, format, and axes. |
| `FontVariationAxis` | Variation axis default for variable fonts. |
| `PackagedFontStyle` | Normal or italic style metadata. |
| `DesignSystem::font_faces()` | Runtime entry point shells use to register packaged fonts. |

```rust
DesktopApp::<AppState, _>::new(App)
    .with_design_system::<AppDesignSystem>(DesignMode::Light)
    .run()
```

The desktop shell registers `AppDesignSystem::font_faces()` before rendering so text can resolve the declared family without relying on installed system fonts.

Browser delivery is a separate decision. Web, Static site and SSR use
`WebFontDelivery::None` by default: declaring packaged fonts does not by itself
put their bytes into CSS. Choose `External` to emit font URLs and let the
browser fetch them, or `Inline` to embed them explicitly. The corresponding
`fission.toml` setting controls the same delivery policy; see
[Package and use fonts](/docs/cookbook/package-and-use-fonts/) for configuration
and cache behaviour.

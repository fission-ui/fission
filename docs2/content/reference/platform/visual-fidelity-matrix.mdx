# Visual fidelity matrix

| Feature | macOS | Windows | Linux | Web | Android | iOS | Terminal | Static site | SSR |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `Responsive` viewport cases | yes | yes | yes | yes | yes | yes | degraded | yes | yes |
| Container queries | yes | yes | yes | yes | yes | yes | degraded | partial | partial |
| `Length` points/percent/clamp | yes | yes | yes | yes | yes | yes | partial | yes | yes |
| Grid `minmax`/`auto-fit` | yes | yes | yes | yes | yes | yes | degraded | yes | yes |
| Gradients and shadows | yes | yes | yes | yes | yes | yes | degraded | yes | yes |
| Backdrop blur | yes | yes | yes | browser-dependent | yes | yes | no | browser-dependent | browser-dependent |
| Packaged fonts | yes | yes | yes | yes | yes | yes | emulator-owned | opt-in CSS | opt-in CSS |
| LiveTest command API | yes | yes | yes | Chromium bridge | yes | yes | partial | website bridge | website bridge |
| Selector-based LiveTest actions | yes | yes | yes | test-build canvas | yes | yes | no | website mode | website mode |
| PNG capture | yes | yes | yes | CDP | yes | yes | yes | CDP | CDP |
| Golden image comparison | yes | yes | yes | via CDP capture | yes | yes | glyph-limited | via CDP capture | via CDP capture |

`partial` means the target implements only part of that contract. Terminal
supports coordinate/text input and PNG capture, but not selector or
deterministic-motion commands. The browser driver exposes the same command
API through Chromium: retained Web canvas control needs the test-build bridge;
Static site, SSR, and other websites use ordinary DOM website mode without a
production test endpoint. Neither claim means a production page exposes the
native app's control server.

Static site and SSR omit packaged CSS fonts by default. Choose external or
inline delivery explicitly, then verify fonts and browser-specific effects
in the actual deployed document. A matrix cell is a capability description,
not evidence that a particular app has passed visual QA on that target.

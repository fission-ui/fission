# Graphic callout

![Graphic callout screenshot](/img/charts/component-graphic-callout.png)

A callout can explain context that the values alone do not contain. For example, a queue report may be based on a provisional data snapshot. That qualification belongs beside the report whether or not a reader can hover a point.

`ChartGraphic` is plot-relative geometry. Its position does not attach the note to a particular observation.

```rust
use fission::prelude::*;
use fission::core::op::Color;
use fission::charts::{
    Axis, Chart, ChartGraphic, ChartGraphicKind, LineSeries, Series,
};

fission_component! {
    pub QualifiedQueueReport<()> {
        props {
            title: String,
            jobs_label: String,
            note: String,
            note_colour: Color,
            intervals: Vec<String>,
            waiting_jobs: Vec<f32>,
        }
    }
    view(report, _state, _cx) {
        let labels = report.intervals.iter().map(String::as_str).collect();
        let callout = ChartGraphic {
            kind: ChartGraphicKind::Text,
            x: 0.05, y: 0.05, width: 0.8, height: 0.12,
            text: Some(report.note.clone()),
            color: report.note_colour,
            stroke: None,
        };
    } => Column(children: [
        Text(report.note.clone()),
        Chart(
            title: Some(report.title.clone()),
            x_axis: Some(Axis::category(labels)),
            y_axis: Some(Axis::value().min(0.0)),
            series: vec![Series::Line(
                LineSeries::new(&report.jobs_label).data(report.waiting_jobs.clone()),
            )],
            graphics: vec![callout],
        ),
    ])
}
```

The explicit text bounds use fractions of plot width and height. This avoids treating the convenience text constructor's default dimensions as pixel sizes when the renderer interprets them as fractions.

Supply translated text, a design-system colour and aligned finite values. Inspect long translations and small viewports; a plot callout does not gain ordinary responsive text layout automatically. Keep the nearby `Text` explanation because custom-painted chart text is not a substitute for accessible document content. The image is a gallery fixture.

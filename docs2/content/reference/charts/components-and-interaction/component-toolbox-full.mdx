# Toolbox full

![Toolbox full screenshot](/img/charts/component-toolbox-full.png)

A row of labels can look like a complete toolbox without performing any operation. The current `ChartInteraction.toolbox_actions` renderer paints reset, save, zoom and brush labels, but does not route them as working commands.

Do not expose a save label and describe the report as exportable. A real export needs an application action, an asynchronous operation and an explicit result.

## Use ordinary Compose commands

The [report commands example](../analytics/analytics-toolbox-report) defines `ReportWithCommands`. Put it in `widgets/report_with_commands.rs`:

```rust
use fission::prelude::*;
use crate::widgets::report_with_commands::ReportWithCommands;

fission_component! {
    pub OrdersReportCommands<()> {
        props {
            title: String,
            orders_label: String,
            periods: Vec<String>,
            values: Vec<f32>,
            export_label: TextContent,
            reset_label: TextContent,
            export_action: ActionEnvelope,
            reset_action: ActionEnvelope,
            exporting: bool,
        }
    }
    view(report, _state, _cx) => ReportWithCommands {
        title: report.title.clone(),
        measure_label: report.orders_label.clone(),
        periods: report.periods.clone(),
        values: report.values.clone(),
        export_label: report.export_label.clone(),
        reset_label: report.reset_label.clone(),
        export_action: report.export_action.clone(),
        reset_action: report.reset_action.clone(),
        exporting: report.exporting,
    }
}
```

The parent registers actions against its actual app state. Reset updates report filters; export queues an effect with required success and failure handling. Translated labels and pending state travel through the normal widget contract.

Enable real zoom or brushing through `data_zoom` or `ChartInteraction::brush`, respectively; listing toolbox enums does not enable those behaviours. Test command activation, repeated export whilst pending, cancellation policy and failures. The gallery screenshot demonstrates styling, not a functioning full toolbox.

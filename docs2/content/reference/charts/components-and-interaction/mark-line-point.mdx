# Mark line and point

![Mark line and point screenshot](/img/charts/mark-line-point.png)

A range, a threshold and a named observation answer different questions. A temperature report can show its intended operating band, a warning threshold and a reading requiring investigation, but none of those drawings performs monitoring or proves a cause.

Keep the policy and observation selection in application logic. Pass their display projections to the chart.

```rust
use fission::prelude::*;
use fission::charts::{Axis, Chart, MarkArea, MarkLine, MarkPoint, ScatterSeries, Series};

fission_component! {
    pub AnnotatedTemperatureReadings<()> {
        props {
            title: String,
            readings_label: String,
            elapsed_label: String,
            temperature_label: String,
            explanation: TextContent,
            readings: Vec<(f32, f32)>,
            operating_band: MarkArea,
            warning: MarkLine,
            investigation: MarkPoint,
            axis_min: f32,
            axis_max: f32,
        }
    }
    view(report, _state, _cx) => Column(children: [
        Text(report.explanation.clone()),
        Chart(
            title: Some(report.title.clone()),
            x_axis: Some(Axis::value().name(report.elapsed_label.clone())),
            y_axis: Some(Axis::value().name(report.temperature_label.clone())
                .min(report.axis_min).max(report.axis_max)),
            series: vec![Series::Scatter(
                ScatterSeries::new(&report.readings_label).data(report.readings.clone()),
            )],
            mark_areas: vec![report.operating_band.clone()],
            mark_lines: vec![report.warning.clone()],
            mark_points: vec![report.investigation.clone()],
        ),
    ])
}
```

Construct the annotation records with translated names and theme-derived colours in the parent. Validate finite coordinates and ordered bounds; choose axis limits covering the observations and annotations because marks do not expand the domain automatically.

The current mark area does not paint its name, so the accompanying explanation must name the band and its limits. Test below-band, in-band and above-threshold readings, plus a selected observation removed by filtering. Keep exact values and the same annotations in accessible text. The screenshot uses a separate fixture.

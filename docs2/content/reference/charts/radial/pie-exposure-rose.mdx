# Exposure area rose

![Exposure area rose screenshot](/img/charts/pie-exposure-rose.png)

An exposure report needs a clear unit before it becomes a shape. For an operations review, outstanding contract value by supplier category is one additive measure; unrelated risk scores are not. The screenshot is from Fission's chart gallery.

## What the chart is for

Use this rose for non-overlapping categories of outstanding value in one currency. The exposure amount does not express the probability that a supplier will fail.

## Data model

`rose_type("area")` adds offset square-root radius scaling whilst segment angles still depend on total share. Painted area is not exactly proportional to the value. Prepare finite non-negative values and a positive total.

## Authoring from a Fission component

Keep contract aggregation and currency arithmetic in the report model. The parent supplies localized labels.

```rust
use fission::prelude::*;
use fission::charts::{Chart, PieSeries};

// The parent resolves display labels from its translation bundles.
fission_component! {
    pub SupplierContractExposureRose<()> {
        props {
            chart_title: String,
            series_label: String,
            outstanding_gbp_by_category: Vec<(String, f32)>,
        }
    }
    view(report, _state, _cx) {
        let values = report.outstanding_gbp_by_category.iter()
            .map(|(label, value)| (label.as_str(), *value))
            .collect();
    } => Chart(
        title: Some(report.chart_title.clone()),
        series: vec![PieSeries::new(&report.series_label)
            .data(values)
            .rose_type("area")
            .into()],
    )
}
```

## Testing and accessibility

Check contracts spanning categories so the same value is not counted twice. Provide exact amounts and reporting scope beside the chart; a bar chart is preferable when small value differences drive a decision.

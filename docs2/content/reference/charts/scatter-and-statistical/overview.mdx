# Scatter and statistical

Statistical views are useful when a simple total would hide the variation or relationship the reader needs to inspect. The chart presents prepared observations; it does not automatically calculate a correlation, detect an outlier or validate a cohort.

![Candlestick with movement screenshot](/img/charts/candlestick-volume.png)

## Variants

| Chart | Data shape | Use when |
| --- | --- | --- |
| [Candlestick with movement](./candlestick-volume) | Rows of open, close, low, high values. | Use it for market and range-over-time data. |
| [Conversion funnel](./funnel-conversion) | Ordered label/value pairs. | Use it for sales or onboarding funnels. |
| [Distribution single axis](./single-axis-distribution) | Vec&lt;(value, size)&gt;. | Use it when a second axis adds noise. |
| [Event single axis](./single-axis-events) | Vec&lt;(value, size)&gt;. | Use it for event density and distributions. |
| [Intraday candlestick](./candlestick-intraday) | Rows ordered open, close, low, high. | Use it for intraday or short-range market views. |
| [Latency boxplot](./boxplot-latency) | Five-number summary rows. | Use it when distribution matters more than averages. |
| [Market bubble chart](./scatter-bubble-market) | Vec&lt;(x, y, size)&gt;. | Use it for three-dimensional business comparisons. |
| [Product parallel coordinates](./parallel-products) | Vec&lt;Vec&lt;f32&gt;&gt; observations. | Use it for multidimensional comparison. |
| [Quality boxplot](./boxplot-quality) | Five-number summary rows. | Use it for process quality and batch comparisons. |
| [Quality parallel coordinates](./parallel-quality) | Vec&lt;Vec&lt;f32&gt;&gt; observations. | Compare prepared profiles; working filters need application controls. |
| [Recruiting funnel](./funnel-recruiting) | Ordered label/value pairs. | Use it when stage drop-off matters. |
| [Risk return scatter](./scatter-risk-return) | Vec&lt;(risk, return, exposure)&gt;. | Use it for portfolio-style comparisons. |
| [Scatter clusters](./scatter-clusters) | Vec&lt;(f32, f32)&gt;. | Inspect paired observations; clustering requires a separate analysis. |
| [Scatter outliers](./scatter-outliers) | Vec&lt;(f32, f32)&gt; plus effect scatter styling. | Use it to make exceptions visible. |

## Choosing within this family

Use scatter for paired numeric measurements, bubbles for a third non-negative size measure and boxplots for prepared five-number summaries. Candlesticks have the distinct open/close/low/high order. A funnel needs an ordered progression through one cohort, whilst parallel coordinates need dimensions on the renderer's common 0–100 scale.

Keep raw observations and stable domain IDs outside display vectors. A highlighted halo or a compact distribution does not itself establish a statistical conclusion.

## Authoring from a Fission component

A delivery report is a concrete paired-measure example. The parent prepares completed observations and localizes the title and axis labels.

```rust
use fission::prelude::*;
use fission::charts::{Axis, Chart, ScatterSeries};

// The parent resolves display labels from its translation bundles.
fission_component! {
    pub DeliveryObservationOverview<()> {
        props {
            chart_title: String,
            series_label: String,
            axis_label: String,
            axis_label_2: String,
            observations: Vec<(f32, f32)>,
        }
    }
    view(report, _state, _cx) => Chart(
        title: Some(report.chart_title.clone()),
        x_axis: Some(Axis::value().name(&report.axis_label)),
        y_axis: Some(Axis::value().name(&report.axis_label_2)),
        series: vec![ScatterSeries::new(&report.series_label)
            .data(report.observations.clone())
            .into()],
    )
}
```

## Checks

Test units, summary ordering, duplicate events and missing observations independently of rendering. Keep exact values and sample sizes available outside the plot. Then inspect overlap and clipping on the real target; visual marks cannot prove that the underlying statistics or report population are correct.

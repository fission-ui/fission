# Cartesian

Cartesian charts position values against x and y axes. The thirteen examples here use that common structure for different questions: category comparisons, ordered trends, cumulative contributions and changes that happen in discrete steps.

The choice follows from the data. Independent product categories do not imply a continuous path; equal sampling intervals do. A filled area needs a meaningful baseline, and a stack needs values that can genuinely be added.

## Compose is the widget boundary

Enable Fission's `charts` feature. Each example constructs a `Chart(...)` in a named component, with `Vec<Series>` supplied from ordinary Rust series values. `title` is `Option<String>`; axes are `Option<Axis>`; fixed width and height are optional rather than required.

Pass translated labels and a ready data snapshot from the parent. Keep authoritative money, inventory and reporting calculations outside the chart and convert only the final display projection to `f32`. Requests and persistence belong in effects and reducers, not component conversion.

## The details affect the meaning

Category positions are equally spaced. A `Vec<f32>` line does not acquire irregular timestamp positions simply because an axis is labelled as time. Missing observations need an explicit policy rather than an invented zero or an unexplained connection across a gap.

Smoothing interpolates geometry; it does not add observations. A background track spans the numeric plot range; it is not automatically a target. The current pictorial renderer also uses a fixed shape-count rule rather than arbitrary custom paths or one symbol per item. The relevant pages show those mechanisms directly.

## Checks worth keeping

Test label/value alignment, shared reporting intervals, stack reconciliation and boundary cases before looking at a screenshot. Inspect long translated labels and the actual narrow layout with LiveTest. Provide exact values, units and important conclusions in text or tables so colour, shape and hover are not the only way to understand the report.

The images above and on the variant pages are gallery fixtures. They help identify a presentation, but do not establish correctness or performance for application data.

# Radial and polar

These variants share a circular presentation but encode different relationships. A pie partitions a total, a gauge positions a percentage on a fixed arc, and a radar compares a fixed set of dimensions. Start with that relationship rather than the outline.

Keep source quantities, calculation and loading in the application model. Compose receives prepared values and localized labels, using the same reducer/effect boundaries as the rest of the app.

![Donut screenshot](/img/charts/pie-donut.png)

## Variants

| Chart | Data shape | Use when |
| --- | --- | --- |
| [Donut](./pie-donut) | Label/value pairs plus inner radius. | Present a flat composition; the centre label or total must be supplied separately. |
| [Filled radar](./radar-filled) | Metric profiles, filled by the renderer. | Compare a few profiles whilst keeping their named values available. |
| [Gauge](./gauge-basic) | One label/value pair with an expected range. | Use it when the value is read as a current instrument state. |
| [Liquid fill](./liquid-fill) | One fraction from 0 to 1; only the first entry is rendered. | Show a genuinely bounded level, with missing readings handled separately. |
| [Pie](./pie-basic) | Label/value pairs. | Use it for a small number of categories where the whole matters. |
| [Progress gauge](./gauge-progress) | One percentage on a fixed 0–100 arc. | Show measured completion only when the total work is known. |
| [Radar](./radar-basic) | Vec&lt;Vec&lt;f32&gt;&gt; where each row is one profile. | Use it for profile comparison across a fixed set of dimensions. |
| [Rose by area](./pie-rose-area) | Label/value pairs plus area rose mode. | Use it when rose slices should emphasize difference without making small values disappear. |
| [Rose by radius](./pie-rose-radius) | Label/value pairs plus radius rose mode. | Use it for presentation-heavy part-to-whole views. |

## Choosing within this family

A positive total and mutually exclusive categories are prerequisites for a composition chart. An inner radius changes presentation, not the denominator or hierarchy. Rose modes encode angle and radius together; the current area-style formula does not make painted areas exactly proportional to values.

Gauge and radar values use a fixed 0–100 scale. Liquid fill instead expects a 0–1 fraction. Both gauge and liquid fill render only the first supplied entry. Validate the input and represent unavailable state before building them rather than relying on visual clamping.

## Authoring from a Fission component

The quota calculation belongs to the parent. This component accepts one prepared percentage and localized display labels; it has no reason to own local state or start a storage request.

```rust
use fission::prelude::*;
use fission::charts::{Chart, GaugeSeries};

// The parent resolves display labels from its translation bundles.
fission_component! {
    pub QuotaOverviewGauge<()> {
        props {
            chart_title: String,
            series_label: String,
            value_label: String,
            used_percent: f32,
        }
    }
    view(report, _state, _cx) => Chart(
        title: Some(report.chart_title.clone()),
        series: vec![GaugeSeries::new(&report.series_label)
            .data(vec![(&report.value_label, report.used_percent)])
            .into()],
    )
}
```

## Checks

Test ratios, units, missing measurements and out-of-range input separately from rendering. An unavailable capacity or an unknown job total must not become a zero-valued successful observation.

Inspect labels and small differences at the intended viewport size. Keep exact values, units and the reporting snapshot accessible outside the shape. A gauge does not enforce a quota, and a radar polygon does not define an overall policy score.

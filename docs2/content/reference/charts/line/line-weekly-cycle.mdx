# Weekly cycle line

![Weekly cycle line screenshot](/img/charts/line-weekly-cycle.png)

A weekly line makes the order of working days and weekends visible. This helps a support team recognise where arrivals concentrate without replacing the actual counts with a single weekly total. The screenshot is from Fission's chart gallery.

## What the chart is for

Keep all seven days when the product operates through the weekend. Omitting quiet days would change the apparent shape and could make Monday look adjacent to Friday in a way the source timeline does not justify.

## Data model

Pass weekday labels in reporting order with one arrival count per day. If comparing an average week across several weeks, name that aggregate and keep the averaging rule outside the widget; it is different from one particular week's history.

## Authoring from a Fission component

The component receives the reporting values and labels. Fetch, aggregate and validate those inputs before constructing the chart.

```rust
use fission::prelude::*;
use fission::charts::{Axis, Chart, LineSeries};

// The parent resolves display labels from its translation bundles.
fission_component! {
    pub WeeklyCycleLineChart<()> {
        props {
            chart_title: String,
            series_label: String,
            labels: Vec<String>,
            daily_arrivals: Vec<f32>,
        }
    }
    view(report, _state, _cx) {
        let labels = report.labels.iter().map(String::as_str).collect();
    } =>
        Chart(
            title: Some(report.chart_title.clone()),
            x_axis: Some(Axis::category(labels)),
            y_axis: Some(Axis::value()),
            series: vec![
                LineSeries::new(&report.series_label)
                    .data(report.daily_arrivals.clone())
                    .into(),
            ],
        )
}
```

## Testing and accessibility

Check the week start, locale-specific weekday labels and a known zero day. Keep reporting timezone and cut-off visible, and do not turn an incomplete current day into evidence of lower demand.

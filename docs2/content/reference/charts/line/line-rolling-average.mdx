# Rolling average line

![Rolling average line screenshot](/img/charts/line-rolling-average.png)

A rolling average reduces day-to-day variation so a longer movement is easier to see. Keeping the daily values on the same chart preserves the spikes that the average would otherwise hide. The screenshot is from Fission's chart gallery.

## What the chart is for

This example uses a trailing seven-day arithmetic mean of ticket arrivals. It is a calculated series, not LineSeries::smooth(true): smoothing changes the drawn path but does not calculate a statistical average.

## Data model

Calculate the trailing series before rendering and align each result with the day whose window ends there. Choose an explicit policy for the first six days rather than silently treating unavailable earlier days as zero. Pass both prepared vectors with the common labels.

## Authoring from a Fission component

The parent supplies prepared values and matching reporting labels. Keep loading and calculation errors in that parent workflow.

```rust
use fission::prelude::*;
use fission::charts::{Axis, Chart, Legend, LineSeries};

// The parent resolves display labels from its translation bundles.
fission_component! {
    pub RollingAverageLineChart<()> {
        props {
            chart_title: String,
            series_label: String,
            comparison_series_label: String,
            labels: Vec<String>,
            daily_arrivals: Vec<f32>,
            trailing_average: Vec<f32>,
        }
    }
    view(report, _state, _cx) {
        let labels = report.labels.iter().map(String::as_str).collect();
    } =>
        Chart(
            title: Some(report.chart_title.clone()),
            x_axis: Some(Axis::category(labels)),
            y_axis: Some(Axis::value()),
            legend: Some(Legend::top_right()),
            series: vec![
                LineSeries::new(&report.series_label)
                    .data(report.daily_arrivals.clone())
                    .into(),
                LineSeries::new(&report.comparison_series_label)
                    .data(report.trailing_average.clone())
                    .into(),
            ],
        )
}
```

## Testing and accessibility

Test the window edges, a single large spike and missing daily observations. Check the numeric mean independently of rendering, and keep exact daily counts available for readers who need to investigate an incident.

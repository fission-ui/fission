# Incident volume calendar

![Incident volume calendar screenshot](/img/charts/calendar-incident-volume.png)

An incident calendar puts incident counts on the days they occurred. This is useful when an operations team needs to compare noisy periods with maintenance windows or releases without losing the gaps between those periods. The screenshot is from Fission's chart gallery.

## What the chart is for

Define which event is being counted first. Incidents opened, alerts received and incidents resolved are different measures. The example counts incidents opened; combining them would make a cell impossible to interpret.

## Data model

The series takes ISO date/count pairs. Count each incident once, in the timezone used by the operations dashboard. A long-running incident belongs to its opening day in this example; its duration needs a separate measure.

## Rust API

| Setting | Type | Meaning |
| --- | --- | --- |
| `CalendarHeatmapSeries::data` | `Vec<(&str, f32)>` | Converts date/value pairs into the series' owned `Vec<(String, f32)>`. |
| `CalendarHeatmapSeries::range` | `&str, &str` | Sets the displayed start and end dates. |
| `Chart::visual_map` | `VisualMap` | Sets the numeric colour range. |
| `Chart::series` | `Vec<Series>` | Adds the calendar series; Cartesian axes are not required. |

## Example

```rust
use fission::charts::{CalendarHeatmapSeries, Chart, VisualMap};

let chart = Chart::new()
    .title("Incidents opened per day")
    .visual_map(VisualMap::new().min(0.0).max(10.0))
    .series(vec![CalendarHeatmapSeries::new("Incidents")
        .range("2026-10-01", "2026-10-31")
        .data(vec![
            ("2026-10-01", 2.0),
            ("2026-10-02", 0.0),
            ("2026-10-03", 5.0),
        ])
        .into()]);
```

## Authoring from a Fission component

The parent supplies the daily values. This component presents them; it does not start a request during the build.

```rust
use fission::prelude::*;
use fission::charts::{CalendarHeatmapSeries, Chart, Series, VisualMap};

// The parent resolves display labels from its translation bundles.
fission_component! {
    pub IncidentVolumeCalendarChart<()> {
        props {
            chart_title: String,
            series_label: String,
            daily_values: Vec<(String, f32)>,
        }
    }
    view(calendar, _state, _cx) =>
        Chart(
            title: Some(calendar.chart_title.clone()),
            visual_map: Some(VisualMap::new().min(0.0).max(10.0)),
            series: vec![Series::CalendarHeatmap(CalendarHeatmapSeries {
                name: calendar.series_label.clone(),
                data: calendar.daily_values.clone(),
                start: Some("2026-10-01".into()),
                end: Some("2026-10-31".into()),
            })],
        )
}
```

## Interaction and accessibility

Selecting a day can filter the incident list through a reducer. Provide the count in text as well as colour, and do not imply that a quiet day was reliable when monitoring data for that day is missing.

## Testing guidance

Test days with zero incidents and dates at the edge of the displayed range. Check the aggregation separately so duplicate alert records cannot inflate the incident count. Check the rendered chart at the size it will occupy in the dashboard; correct sample values alone do not establish that the dates and values are readable.

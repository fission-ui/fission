# Commit activity calendar

![Commit activity calendar screenshot](/img/charts/calendar-commit-activity.png)

A commit calendar makes gaps and repeated bursts of repository activity visible. The date matters here: a weekend with no commits is different from a missing sample, even if both might otherwise look empty. The screenshot is from Fission's chart gallery.

## What the chart is for

Use this view to understand when changes were made, not to rank developers by output. Commit counts say nothing about the size, difficulty or quality of those changes. Keep that distinction visible if the chart appears in a team dashboard.

## Data model

Each sample pairs an ISO date with that day's commit count. Aggregate commits into days using one declared timezone before constructing the series; mixing author-local dates with server-local dates can put the same activity in different cells.

## Rust API

| Setting | Type | Meaning |
| --- | --- | --- |
| `CalendarHeatmapSeries::data` | `Vec<(&str, f32)>` | Converts date/value pairs into the series' owned `Vec<(String, f32)>`. |
| `CalendarHeatmapSeries::range` | `&str, &str` | Sets the displayed start and end dates. |
| `Chart::visual_map` | `VisualMap` | Sets the numeric colour range. |
| `Chart::series` | `Vec<Series>` | Adds the calendar series; Cartesian axes are not required. |

## Example

```rust
use fission::charts::{CalendarHeatmapSeries, Chart, VisualMap};

let chart = Chart::new()
    .title("Commits per day")
    .visual_map(VisualMap::new().min(0.0).max(15.0))
    .series(vec![CalendarHeatmapSeries::new("Commits")
        .range("2026-10-01", "2026-10-31")
        .data(vec![
            ("2026-10-01", 6.0),
            ("2026-10-02", 0.0),
            ("2026-10-03", 11.0),
        ])
        .into()]);
```

## Authoring from a Fission component

The parent supplies the daily values. This component presents them; it does not start a request during the build.

```rust
use fission::prelude::*;
use fission::charts::{CalendarHeatmapSeries, Chart, Series, VisualMap};

// The parent resolves display labels from its translation bundles.
fission_component! {
    pub CommitActivityCalendarChart<()> {
        props {
            chart_title: String,
            series_label: String,
            daily_values: Vec<(String, f32)>,
        }
    }
    view(calendar, _state, _cx) =>
        Chart(
            title: Some(calendar.chart_title.clone()),
            visual_map: Some(VisualMap::new().min(0.0).max(15.0)),
            series: vec![Series::CalendarHeatmap(CalendarHeatmapSeries {
                name: calendar.series_label.clone(),
                data: calendar.daily_values.clone(),
                start: Some("2026-10-01".into()),
                end: Some("2026-10-31".into()),
            })],
        )
}
```

## Interaction and accessibility

A selected day can open its commit list. Keep that navigation in a reducer, using the selected date to identify the records. Animation is optional: the calendar's purpose is to preserve the date relationship, not to make individual contributions appear more significant.

## Testing guidance

Check a day with no commits, a day with several commits, and commits close to midnight in the chosen timezone. A zero is a known count; an absent sample is not evidence that no work occurred. Check the rendered chart at the size it will occupy in the dashboard; correct sample values alone do not establish that the dates and values are readable.

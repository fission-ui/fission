# Geographic and route

Start with the question the report needs to answer. Regional colour compares an area-based measure; route lines compare relationships between endpoints. These are useful in the same report, but they are not interchangeable geographical models.

![Choropleth map screenshot](/img/charts/map-choropleth.png)

## Variants

| Chart | Data shape | Use when |
| --- | --- | --- |
| [Choropleth map](./map-choropleth) | Region identifiers plus values and GeoJSON geometry. | Use it for geography-first comparison. |
| [Geo lines](./geo-lines) | GeoJSON regions plus route line segments. | Use it when geography and movement need to be read together. |
| [Lines](./lines-basic) | Line segments with from/to points and a value. | Use it for routes, movement, and connection flow. |
| [Route map](./route-map) | Regions plus route segments. | Use it for logistics, traffic, or service coverage views. |


## Choose the coordinate contract first

The [choropleth component](/reference/charts/geographic-and-route/map-choropleth/) joins stable region IDs to supplied Polygon/MultiPolygon GeoJSON. A map-type name does not fetch geometry. Validate geometry and joins before rendering because malformed inputs can otherwise leave an empty picture.

The [connection component](/reference/charts/geographic-and-route/lines-basic/) uses actual `LinesSeries` values, with endpoints and one relative intensity each. It fits its own bounds; curves are schematic and are not road paths or geodesics.

**The current map and line fitting rules do not establish a shared projection.** Pages whose titles mention overlays retain their paths, but explain this gap and show paired reports instead of promising geographical alignment. See the [network composition](/reference/charts/geo-and-route/geo-network/) for the supported alternative. Exact route overlays need framework work outside these examples.

## Keep the facts independent of the drawing

Load coherent snapshots through effects and reducers, retain durable region/route IDs and provide exact values beside the chart. Translate captions and units in the parent. Choose a colour scale whose meaning stays constant across comparisons, and do not use colour as the only status signal.

Test joins, missing data, degenerate routes and report replacement before visual checks. A gallery screenshot uses separate fixtures; it does not prove navigation, data loading or coordinate alignment.

# Bar

These thirty-eight gallery variants use a small set of mechanisms: independent bars, shared stacks, signed changes, bounded tracks and explicit cumulative offsets. The useful distinction is what the reader needs to compare, not how many variations can be styled.

Build the reporting snapshot in ordinary Rust, then project it into a named Compose component. Keep labels with their values and preserve durable data IDs when sorting or selecting rows. Fetching and persistence remain in effects and reducers, outside component conversion.

## Choose the comparison

Use grouped bars when individual values need a shared baseline. Use a stack when its parts are exclusive contributions to one total. A signed delta compares against zero; a waterfall instead explains a running balance and needs an offset for every intermediate change.

A background fills the numeric plot range. Therefore, a capacity track only has a truthful endpoint when the axis maximum is an intentional limit, not the current largest reading. Where limits differ or usage exceeds them, show the amounts separately or declare the normalisation explicitly.

## The public fields used by these examples

| Chart input | Rust field type | Meaning |
| --- | --- | --- |
| `title` | `Option<String>` | A translated description of the report. |
| `x_axis`, `y_axis` | `Option<Axis>` | Category and numeric scales; swap their roles for horizontal bars. |
| `series` | `Vec<Series>` | One or more explicit `Series::Bar(...)` values. |
| `legend` | `Option<Legend>` | Identifies multiple displayed measures. |
| `width`, `height` | `Option<f32>` | Optional fixed dimensions, rather than mandatory chart sizing. |

Enable Fission's `charts` feature. The individual pages show actual `Chart(...)` composition and ordinary Rust `BarSeries` values, without a separate builder-based UI or a required `rust { ... }` escape block.

## Verify meaning as well as rendering

Test reconciliation, category/value alignment, tie-breaking and missing data before inspecting the visual result. A zero may have a small visible extent in the current renderer, so exact values and explicit empty states still matter.

Use translated labels, design-system presentation inputs and stable chart identities for repeated interactive panels. Keep the values available in text or tables and inspect long labels at mobile and desktop sizes with LiveTest. Gallery screenshots are fixtures, not proof that an application's projection or interactions are correct.

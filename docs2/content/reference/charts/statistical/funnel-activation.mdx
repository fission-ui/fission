# Activation funnel

![Activation funnel screenshot](/img/charts/funnel-activation.png)

Activation should describe a useful outcome for a defined signup cohort. Opening a screen is not equivalent to completing the task which makes the product useful. The screenshot is from Fission's chart gallery.

## What the chart is for

Here each account is counted once when it creates a workspace, adds its first project and completes its first task within a defined observation window. A pending account is not automatically a failed conversion.

## Data model

`FunnelSeries` takes ordered stage/count pairs and does not deduplicate accounts or calculate rates. Prepare counts from the same cohort and preserve the stage order rather than sorting by value.

## Authoring from a Fission component

The parent supplies the cohort report with localized stage names; registration and product actions remain normal application workflows.

```rust
use fission::prelude::*;
use fission::charts::{Chart, FunnelSeries};

// The parent resolves display labels from its translation bundles.
fission_component! {
    pub AccountActivationStages<()> {
        props {
            chart_title: String,
            series_label: String,
            accounts_by_stage: Vec<(String, f32)>,
        }
    }
    view(report, _state, _cx) {
        let values = report.accounts_by_stage.iter()
            .map(|(label, value)| (label.as_str(), *value))
            .collect();
    } => Chart(
        title: Some(report.chart_title.clone()),
        series: vec![FunnelSeries::new(&report.series_label)
            .data(values)
            .into()],
    )
}
```

## Testing and accessibility

Test duplicate actions, late completion and a still-open cohort window. Provide exact stage counts and observation dates. The funnel shows progression, not the reason accounts stopped.

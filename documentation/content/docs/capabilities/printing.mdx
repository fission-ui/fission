# Printing PDFs

Use Fission's `print_pdf` capability when the user asks to print a document your app has already generated. It accepts PDF bytes for a small document or a one-shot data stream for a larger file.

```rust
let request = PrintPdfRequest {
    pdf: FileWriteSource::Stream(pdf_stream),
    job_name: Some("Quarterly report".into()),
    ..Default::default()
};
ctx.effects.print_pdf(request)
```

Bind both success and error actions. The result can report that the host submitted a job, opened its print UI, or detected cancellation. It does not confirm that paper was printed. Keep the PDF and app-specific output record in your own persistent store before calling the capability.

Read the [PDF printing reference](/reference/capabilities/printing/) for exact request fields, target support, settings, and error codes.

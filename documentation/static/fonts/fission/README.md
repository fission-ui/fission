# Fission documentation fonts

The Platform Atlas theme packages these fonts locally so the documentation site
does not depend on a third-party font request:

- Space Grotesk Variable 5.3.0 from `@fontsource-variable/space-grotesk`
- DM Mono 5.3.0 from `@fontsource/dm-mono`

Both typefaces are distributed under the SIL Open Font License 1.1. Copyright
notices and upstream sources are recorded in `LICENSES.md`.
